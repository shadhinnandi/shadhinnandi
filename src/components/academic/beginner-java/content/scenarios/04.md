# Scenario-Based Problems

These scenarios ask you to read a short story from campus life and turn it into classes.
For each one, first find the nouns (they often become classes and fields) and the verbs
(they often become methods). Then let `main` read commands and send messages to a few
objects, instead of doing all the work itself.

In this chapter the fields are left without `private` on purpose, so you can focus on
objects, fields and methods; Chapter 05 adds encapsulation. Names in the input are single
words. Programs read input without prompts and print exactly the sample output. All fees,
rates and rules in these problems are hypothetical and invented for practice.

## Problem 1: Canteen Order Bill
**Level:** Basic

### Scenario
Karim runs the campus canteen counter at lunch time. Students order several items at
once, and Karim wants a small program that builds one order item by item and prints the
bill. The canteen gives a 10% discount on large orders. Sometimes Karim mistypes a
quantity, and those lines must not spoil the bill.

### Problem Statement
Write a class `CanteenOrder` with fields `customer`, `itemCount` (total number of pieces)
and `subtotal` (Tk). Give it the methods:

- `boolean addItem(int unitPrice, int quantity)`: adds the item and returns `true`; if
  the price or the quantity is not positive, it changes nothing and returns `false`.
- `int discount()`: 10% of the subtotal (integer division) when the subtotal is at least
  500 Tk, otherwise 0.
- `int total()`: subtotal minus discount.

**Input:** the customer's name, then an integer `n`, then `n` lines `item price quantity`.

**Output:** first `Order for <name>`. For each accepted line print
`<item> x<quantity> = <line total> Tk`; for a rejected line print `Skipped <item>`.
Then print:

```text
Items: <itemCount>
Subtotal: <subtotal> Tk
Discount: <discount> Tk
Total: <total> Tk
```

### Sample Input
```text
Rahim
4
Khichuri 120 2
Tea 15 3
Singara 10 0
Chicken-Roll 90 2
```

### Sample Output
```text
Order for Rahim
Khichuri x2 = 240 Tk
Tea x3 = 45 Tk
Skipped Singara
Chicken-Roll x2 = 180 Tk
Items: 7
Subtotal: 465 Tk
Discount: 0 Tk
Total: 465 Tk
```

### Solution
```java
import java.util.Scanner;

class CanteenOrder {
    String customer;
    int itemCount;
    int subtotal;

    boolean addItem(int unitPrice, int quantity) {
        if (unitPrice <= 0 || quantity <= 0) {
            return false;
        }
        itemCount = itemCount + quantity;
        subtotal = subtotal + unitPrice * quantity;
        return true;
    }

    int discount() {
        if (subtotal >= 500) {
            return subtotal / 10;
        }
        return 0;
    }

    int total() {
        return subtotal - discount();
    }
}

public class CanteenBill {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        CanteenOrder order = new CanteenOrder();
        order.customer = in.next();
        System.out.println("Order for " + order.customer);

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String item = in.next();
            int price = in.nextInt();
            int quantity = in.nextInt();
            if (order.addItem(price, quantity)) {
                System.out.println(item + " x" + quantity + " = " + price * quantity + " Tk");
            } else {
                System.out.println("Skipped " + item);
            }
        }

        System.out.println("Items: " + order.itemCount);
        System.out.println("Subtotal: " + order.subtotal + " Tk");
        System.out.println("Discount: " + order.discount() + " Tk");
        System.out.println("Total: " + order.total() + " Tk");
    }
}
```

### Explanation
The noun "order" becomes the class `CanteenOrder`; its state is the customer, the number
of pieces and the running subtotal. The verb "add an item" becomes `addItem`, which
updates both fields together, so they can never disagree. `discount()` and `total()` are
computed from the subtotal every time they are called instead of being stored, so they
are always up to date. A new object starts with `itemCount` and `subtotal` equal to 0
(default field values), which is exactly what an empty order needs. `main` only reads
input, sends messages to the object and prints the answers.

### Concepts Practiced
- Designing a class from a description (nouns and verbs)
- Instance fields and default values
- Instance methods that change state and return results
- Creating an object with `new` and using `.`

## Problem 2: Campus Parking Meter
**Level:** Basic

### Scenario
The campus car park has a coin meter for visitors. Each 10 Tk buys 20 minutes, and the
meter never holds more than 120 minutes of paid time. If a car stays longer than its paid
time, the overdue minutes are recorded and the guard collects a fine of 2 Tk per overdue
minute at the end. The guard wants to simulate one visit to check the rules.

### Problem Statement
Write a class `ParkingMeter` with fields `minutesLeft`, `overdueMinutes`, `totalPaid`
and `maxMinutes` (set to 120 with a field initializer). Give it the methods:

- `boolean pay(int taka)`: accepted only if `taka` is a positive multiple of 10 and the
  new paid time would not exceed `maxMinutes`. Each 10 Tk adds 20 minutes.
- `void timePasses(int minutes)`: uses up paid time; minutes beyond the paid time are
  added to `overdueMinutes` and `minutesLeft` becomes 0.
- `int fine()`: 2 Tk per overdue minute.
- `String status()`: `Left: <m> min, overdue: <o> min`.

**Input:** an integer `n`, then `n` commands: `PAY <taka>` or `WAIT <minutes>`.

**Output:** for an accepted payment print `Paid <taka> Tk. <status>`; for a refused one
print `Rejected <taka> Tk`. After `WAIT` print the status. At the end print
`Total paid: <t> Tk` and `Fine: <f> Tk`.

### Sample Input
```text
6
PAY 50
WAIT 40
PAY 25
PAY 40
WAIT 150
PAY 10
```

### Sample Output
```text
Paid 50 Tk. Left: 100 min, overdue: 0 min
Left: 60 min, overdue: 0 min
Rejected 25 Tk
Rejected 40 Tk
Left: 0 min, overdue: 90 min
Paid 10 Tk. Left: 20 min, overdue: 90 min
Total paid: 60 Tk
Fine: 180 Tk
```

### Solution
```java
import java.util.Scanner;

class ParkingMeter {
    int minutesLeft;
    int overdueMinutes;
    int totalPaid;
    int maxMinutes = 120;

    boolean pay(int taka) {
        if (taka <= 0 || taka % 10 != 0) {
            return false;
        }
        int minutes = taka / 10 * 20;
        if (minutesLeft + minutes > maxMinutes) {
            return false;
        }
        minutesLeft = minutesLeft + minutes;
        totalPaid = totalPaid + taka;
        return true;
    }

    void timePasses(int minutes) {
        if (minutes <= minutesLeft) {
            minutesLeft = minutesLeft - minutes;
        } else {
            overdueMinutes = overdueMinutes + (minutes - minutesLeft);
            minutesLeft = 0;
        }
    }

    int fine() {
        return overdueMinutes * 2;
    }

    String status() {
        return "Left: " + minutesLeft + " min, overdue: " + overdueMinutes + " min";
    }
}

public class ParkingMeterVisit {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        ParkingMeter meter = new ParkingMeter();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            int value = in.nextInt();
            if (command.equals("PAY")) {
                if (meter.pay(value)) {
                    System.out.println("Paid " + value + " Tk. " + meter.status());
                } else {
                    System.out.println("Rejected " + value + " Tk");
                }
            } else if (command.equals("WAIT")) {
                meter.timePasses(value);
                System.out.println(meter.status());
            }
        }
        System.out.println("Total paid: " + meter.totalPaid + " Tk");
        System.out.println("Fine: " + meter.fine() + " Tk");
    }
}
```

### Explanation
The meter is one object whose state is the paid time left, the overdue time and the money
collected. The rules live inside the methods: `pay` checks the coin rule and the 120-minute
cap before it changes anything, and `timePasses` splits the passing time into "paid" and
"overdue" parts. `maxMinutes` has a field initializer, so every new meter starts with the
cap already set, while the other fields start at 0. Notice in the sample that 40 Tk is
refused (80 + 80 > 120) even though it is a valid coin amount. `main` only translates
commands into method calls.

### Concepts Practiced
- Fields with default values and a field initializer
- Methods that validate before changing state
- `boolean` results that let the caller decide what to print
- Returning a `String` that describes the object's state

## Problem 3: Two Wallets, One Transfer
**Level:** Intermediate

### Scenario
Nusrat and Imran share the cost of a field trip and keep their money in a campus mobile
wallet. The wallet service charges a flat 5 Tk for every transfer and 2% (at least 5 Tk)
for every cash out. Before they trust the app, they want a simulator that checks every
operation and shows how much each of them has paid in fees.

### Problem Statement
Write a class `Wallet` with fields `owner`, `balance` and `feesPaid`, and a constructor
`Wallet(String owner, int balance)`. Methods:

- `boolean addMoney(int amount)`: refused if `amount <= 0`.
- `boolean send(Wallet receiver, int amount)`: moves `amount` to `receiver` and charges
  the sender a 5 Tk fee. Refused if the receiver is the same wallet, if `amount <= 0`, or
  if the sender's balance is less than `amount + 5`.
- `int cashOutFee(int amount)`: `amount * 2 / 100`, but at least 5.
- `boolean cashOut(int amount)`: refused if `amount <= 0` or the balance is less than
  `amount + fee`.

**Input:** two lines `name balance` (the two wallets), then `n`, then `n` commands:
`ADD <name> <amount>`, `SEND <from> <to> <amount>`, `CASHOUT <name> <amount>`.

**Output:** for each command print one line:

- `ADD`: `<name> +<amount> Tk`
- `SEND`: `<from> sent <amount> Tk to <to> (fee 5 Tk)`
- `CASHOUT`: `<name> cashed out <amount> Tk (fee <fee> Tk)`
- a refused command: `<COMMAND> refused`; a name that matches neither wallet:
  `Unknown wallet` (checked before anything else).

At the end print each wallet as `<owner>: <balance> Tk (fees <feesPaid> Tk)`.

### Sample Input
```text
Nusrat 2000
Imran 300
5
SEND Nusrat Imran 500
CASHOUT Imran 800
CASHOUT Imran 700
ADD Rafi 100
SEND Imran Imran 50
```

### Sample Output
```text
Nusrat sent 500 Tk to Imran (fee 5 Tk)
CASHOUT refused
Imran cashed out 700 Tk (fee 14 Tk)
Unknown wallet
SEND refused
Nusrat: 1495 Tk (fees 5 Tk)
Imran: 86 Tk (fees 14 Tk)
```

### Solution
```java
import java.util.Scanner;

class Wallet {
    String owner;
    int balance;
    int feesPaid;

    Wallet(String owner, int balance) {
        this.owner = owner;
        this.balance = balance;
    }

    boolean addMoney(int amount) {
        if (amount <= 0) {
            return false;
        }
        balance = balance + amount;
        return true;
    }

    boolean send(Wallet receiver, int amount) {
        int fee = 5;
        if (receiver == this || amount <= 0 || balance < amount + fee) {
            return false;
        }
        balance = balance - amount - fee;
        feesPaid = feesPaid + fee;
        receiver.balance = receiver.balance + amount;
        return true;
    }

    int cashOutFee(int amount) {
        int fee = amount * 2 / 100;
        if (fee < 5) {
            fee = 5;
        }
        return fee;
    }

    boolean cashOut(int amount) {
        if (amount <= 0) {
            return false;
        }
        int fee = cashOutFee(amount);
        if (balance < amount + fee) {
            return false;
        }
        balance = balance - amount - fee;
        feesPaid = feesPaid + fee;
        return true;
    }

    String describe() {
        return owner + ": " + balance + " Tk (fees " + feesPaid + " Tk)";
    }
}

public class WalletTransfers {
    static Wallet find(String name, Wallet first, Wallet second) {
        if (first.owner.equals(name)) {
            return first;
        }
        if (second.owner.equals(name)) {
            return second;
        }
        return null;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Wallet first = new Wallet(in.next(), in.nextInt());
        Wallet second = new Wallet(in.next(), in.nextInt());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("SEND")) {
                Wallet from = find(in.next(), first, second);
                Wallet to = find(in.next(), first, second);
                int amount = in.nextInt();
                if (from == null || to == null) {
                    System.out.println("Unknown wallet");
                } else if (from.send(to, amount)) {
                    System.out.println(from.owner + " sent " + amount + " Tk to "
                            + to.owner + " (fee 5 Tk)");
                } else {
                    System.out.println("SEND refused");
                }
            } else {
                Wallet wallet = find(in.next(), first, second);
                int amount = in.nextInt();
                if (wallet == null) {
                    System.out.println("Unknown wallet");
                } else if (command.equals("ADD")) {
                    if (wallet.addMoney(amount)) {
                        System.out.println(wallet.owner + " +" + amount + " Tk");
                    } else {
                        System.out.println("ADD refused");
                    }
                } else {
                    int fee = wallet.cashOutFee(amount);
                    if (wallet.cashOut(amount)) {
                        System.out.println(wallet.owner + " cashed out " + amount
                                + " Tk (fee " + fee + " Tk)");
                    } else {
                        System.out.println("CASHOUT refused");
                    }
                }
            }
        }
        System.out.println(first.describe());
        System.out.println(second.describe());
    }
}
```

### Explanation
There is one class `Wallet` and two objects of it. Each object has its own `balance` and
`feesPaid`, but both share the same methods. `send` is an example of objects interacting:
the sender object receives a reference to the receiver object and changes both balances
in one method, so a transfer can never take money from one side without giving it to the
other. The check `receiver == this` compares references: it is true only when both
names point to the very same wallet object. The constructor uses `this.owner = owner` to
tell the field apart from the parameter of the same name. The helper `find` returns
`null` ("no object") for an unknown name, and `main` checks for it before calling any
method.

### Concepts Practiced
- Several objects of one class, each with its own state
- A method that takes another object as a parameter
- `this` to resolve name clashes and to refer to the current object
- A basic constructor
- `null` for "no matching object"

## Problem 4: Course Sections with Waitlists
**Level:** Intermediate

### Scenario
During course registration, a course has two sections, A and B, each with a seat limit.
When a section is full, up to 3 students can join its waitlist. When an enrolled student
drops, the first waiting student is promoted automatically. Students may also ask to move
from one section to the other, which is allowed only when the other section has a free
seat. The registration office wants to replay a day of requests and see the counts.

### Problem Statement
Write a class `Section` with fields `name`, `capacity`, `enrolled`, `waiting` and
`maxWaiting` (3), and a constructor `Section(String name, int capacity)`. Methods (each
returns the result text shown below):

- `add()`: enroll if a seat is free (`enrolled`); otherwise join the waitlist if it has
  room (`waitlisted (#k)`, where `k` is the new waitlist size); otherwise
  `rejected, section and waitlist full`.
- `drop()`: `rejected, nobody enrolled` if `enrolled` is 0; otherwise one student leaves
  and, if anyone is waiting, one is promoted: `dropped, 1 promoted from waitlist`, or just
  `dropped`.
- `moveTo(Section other)`: moves one enrolled student to `other`. Refused with
  `rejected, same section`, `rejected, nobody to move` or
  `rejected, <other> has no free seat` (checked in that order). On success the student
  leaves this section (with waitlist promotion as in `drop`) and the result is
  `moved to <other>` or `moved to <other>, 1 promoted from waitlist`.
- `describe()`: `<name>: <enrolled>/<capacity> enrolled, <waiting> waiting`.

**Input:** two lines `name capacity` (sections), then `n`, then `n` commands:
`ADD <s>`, `DROP <s>`, `MOVE <from> <to>`, `SHOW`. Section names in commands are always
one of the two given names.

**Output:** for `ADD`, `DROP` and `MOVE` print the command and its section(s) followed
by `: ` and the result, e.g. `ADD A: enrolled` or `MOVE A B: moved to B`. `SHOW` prints
`describe()` of both sections.

### Sample Input
```text
A 2
B 1
9
ADD A
ADD A
ADD A
ADD B
MOVE A B
DROP A
SHOW
MOVE B A
SHOW
```

### Sample Output
```text
ADD A: enrolled
ADD A: enrolled
ADD A: waitlisted (#1)
ADD B: enrolled
MOVE A B: rejected, B has no free seat
DROP A: dropped, 1 promoted from waitlist
A: 2/2 enrolled, 0 waiting
B: 1/1 enrolled, 0 waiting
MOVE B A: rejected, A has no free seat
A: 2/2 enrolled, 0 waiting
B: 1/1 enrolled, 0 waiting
```

### Solution
```java
import java.util.Scanner;

class Section {
    String name;
    int capacity;
    int enrolled;
    int waiting;
    int maxWaiting = 3;

    Section(String name, int capacity) {
        this.name = name;
        this.capacity = capacity;
    }

    boolean hasFreeSeat() {
        return enrolled < capacity;
    }

    String add() {
        if (hasFreeSeat()) {
            enrolled++;
            return "enrolled";
        }
        if (waiting < maxWaiting) {
            waiting++;
            return "waitlisted (#" + waiting + ")";
        }
        return "rejected, section and waitlist full";
    }

    // One enrolled student leaves; returns true if someone was promoted.
    boolean removeOne() {
        enrolled--;
        if (waiting > 0) {
            waiting--;
            enrolled++;
            return true;
        }
        return false;
    }

    String drop() {
        if (enrolled == 0) {
            return "rejected, nobody enrolled";
        }
        if (removeOne()) {
            return "dropped, 1 promoted from waitlist";
        }
        return "dropped";
    }

    String moveTo(Section other) {
        if (other == this) {
            return "rejected, same section";
        }
        if (enrolled == 0) {
            return "rejected, nobody to move";
        }
        if (!other.hasFreeSeat()) {
            return "rejected, " + other.name + " has no free seat";
        }
        boolean promoted = removeOne();
        other.enrolled++;
        if (promoted) {
            return "moved to " + other.name + ", 1 promoted from waitlist";
        }
        return "moved to " + other.name;
    }

    String describe() {
        return name + ": " + enrolled + "/" + capacity + " enrolled, "
                + waiting + " waiting";
    }
}

public class SectionWaitlists {
    static Section pick(String name, Section a, Section b) {
        if (a.name.equals(name)) {
            return a;
        }
        return b;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Section a = new Section(in.next(), in.nextInt());
        Section b = new Section(in.next(), in.nextInt());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("SHOW")) {
                System.out.println(a.describe());
                System.out.println(b.describe());
            } else if (command.equals("MOVE")) {
                String fromName = in.next();
                String toName = in.next();
                Section from = pick(fromName, a, b);
                Section to = pick(toName, a, b);
                System.out.println("MOVE " + fromName + " " + toName + ": "
                        + from.moveTo(to));
            } else {
                String name = in.next();
                Section section = pick(name, a, b);
                String result;
                if (command.equals("ADD")) {
                    result = section.add();
                } else {
                    result = section.drop();
                }
                System.out.println(command + " " + name + ": " + result);
            }
        }
    }
}
```

### Explanation
Each `Section` object keeps its own counters, and all the registration rules live in its
methods. The shared step "one student leaves, maybe promote from the waitlist" is written
once in `removeOne()` and used by both `drop()` and `moveTo()`, so the promotion rule
cannot be forgotten in one of them. `moveTo` is a method of the section the student
leaves, and it receives the other section as a parameter; it checks the target's seats
by asking the target object (`other.hasFreeSeat()`) instead of reading its fields
directly. Because promotions happen immediately, a section with a free seat never has
anyone waiting, which keeps the counts consistent.

### Concepts Practiced
- Several objects of one class with independent state
- Objects interacting through a method parameter
- A private helper step reused by two methods
- Reference comparison with `==` to detect the same object

## Problem 5: Student CGPA Tracker
**Level:** Intermediate

### Scenario
Two friends, both in their first year, enter their course results through the trimester
and keep arguing about who is ahead. Their advisor wants a small tool that records each
result, computes the CGPA, shows the academic standing and settles the argument. An `F`
counts in the CGPA but gives no earned credits.

### Problem Statement
Write a class `Student` with fields `id`, `name`, `attemptedCredits`, `earnedCredits`
and `points`, and a constructor `Student(String id, String name)`. Grade points use this
hypothetical scale:

| Grade | A | A- | B+ | B | B- | C+ | C | C- | D+ | D | F |
|---|---|---|---|---|---|---|---|---|---|---|---|
| Point | 4.00 | 3.67 | 3.33 | 3.00 | 2.67 | 2.33 | 2.00 | 1.67 | 1.33 | 1.00 | 0.00 |

Store `points` as an `int` in hundredths (credits × grade point × 100) to avoid rounding
problems. Methods:

- `boolean addCourse(int credits, String grade)`: refused if credits are not 1 to 4 or
  the grade is not in the table. Credits always count as attempted; they count as earned
  unless the grade is `F`.
- `double cgpa()`: points / (100 × attempted credits), or 0 when nothing is attempted.
- `String standing()`: `No courses` if nothing attempted; `Dean's List` if CGPA ≥ 3.80
  and earned credits ≥ 9; `Probation` if CGPA < 2.00; otherwise `Good standing`.
- `boolean isAheadOf(Student other)`: higher CGPA wins; on equal CGPA, more earned
  credits wins.

**Input:** two lines `id name`, then `n`, then `n` lines `id course credits grade`.

**Output:** for each line print `<course> recorded for <name>`, or
`<course> rejected` (bad credits or grade), or `Unknown student <id>`. Then print each
student as `<name>: CGPA <x.xx>, earned <e>/<a> credits, <standing>` and finally
`Ahead: <name>` or `Ahead: nobody (tie)`.

### Sample Input

011221002 Tanvir
6

011221002 CSE1111 3 A-
011221001 MATH1151 3 B+

### Solution
```java
import java.util.Scanner;

class Student {
    String id;
    String name;
    int attemptedCredits;
    int earnedCredits;
    int points;

    Student(String id, String name) {
        this.id = id;
        this.name = name;
    }

    // Grade point in hundredths, or -1 for an unknown grade.
    int gradePoint(String grade) {
        if (grade.equals("A")) {
            return 400;
        } else if (grade.equals("A-")) {
            return 367;
        } else if (grade.equals("B+")) {
            return 333;
        } else if (grade.equals("B")) {
            return 300;
        } else if (grade.equals("B-")) {
            return 267;
        } else if (grade.equals("C+")) {
            return 233;
        } else if (grade.equals("C")) {
            return 200;
        } else if (grade.equals("C-")) {
            return 167;
        } else if (grade.equals("D+")) {
            return 133;
        } else if (grade.equals("D")) {
            return 100;
        } else if (grade.equals("F")) {
            return 0;
        }
        return -1;
    }

    boolean addCourse(int credits, String grade) {
        int gp = gradePoint(grade);
        if (gp < 0 || credits < 1 || credits > 4) {
            return false;
        }
        attemptedCredits = attemptedCredits + credits;
        if (!grade.equals("F")) {
            earnedCredits = earnedCredits + credits;
        }
        points = points + credits * gp;
        return true;
    }

    double cgpa() {
        if (attemptedCredits == 0) {
            return 0.0;
        }
        return points / (100.0 * attemptedCredits);
    }

    String standing() {
        if (attemptedCredits == 0) {
            return "No courses";
        }
        // Compare in hundredths with whole numbers: no rounding surprises.
        if (points >= 380 * attemptedCredits && earnedCredits >= 9) {
            return "Dean's List";
        }
        if (points < 200 * attemptedCredits) {
            return "Probation";
        }
        return "Good standing";
    }

    boolean isAheadOf(Student other) {
        if (cgpa() != other.cgpa()) {
            return cgpa() > other.cgpa();
        }
        return earnedCredits > other.earnedCredits;
    }

    String describe() {
        return String.format("%s: CGPA %.2f, earned %d/%d credits, %s", name, cgpa(),
                earnedCredits, attemptedCredits, standing());
    }
}

public class CgpaTracker {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Student first = new Student(in.next(), in.next());
        Student second = new Student(in.next(), in.next());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String id = in.next();
            String course = in.next();
            int credits = in.nextInt();
            String grade = in.next();
            Student student = null;
            if (first.id.equals(id)) {
                student = first;
            } else if (second.id.equals(id)) {
                student = second;
            }
            if (student == null) {
                System.out.println("Unknown student " + id);
            } else if (student.addCourse(credits, grade)) {
                System.out.println(course + " recorded for " + student.name);
            } else {
                System.out.println(course + " rejected");
            }
        }
        System.out.println(first.describe());
        System.out.println(second.describe());
        if (first.isAheadOf(second)) {
            System.out.println("Ahead: " + first.name);
        } else if (second.isAheadOf(first)) {
            System.out.println("Ahead: " + second.name);
        } else {
            System.out.println("Ahead: nobody (tie)");
        }
    }
}
```

### Explanation
`Student` holds both the data (credits and points) and the rules (grade table, CGPA,
standing). Points are stored in hundredths as an `int`, so adding results never loses
precision; the standing checks compare whole numbers (`points >= 380 * attempted` means
"CGPA ≥ 3.80") instead of comparing rounded `double` values. `cgpa()` is computed on
demand from the stored totals, so it is never out of date. `isAheadOf` lets one student
object compare itself with another, and `main` calls it in both directions to detect a
tie. Two students with the same points-per-credit get exactly the same `double` from the
same division, so the equality test is safe here.

### Concepts Practiced
- Designing a class with derived values computed by methods
- A method comparing the current object with another object
- Avoiding floating-point surprises by storing whole numbers
- `String.format` for formatted output

## Problem 6: Hostel Room Allocation

### Scenario

### Problem Statement

### Solution
```java
import java.util.Scanner;

class Resident {
    String name;
    int due;

    Resident(String name) {
        this.name = name;
    }
}

class Room {
    int number;
    int rent;
    Resident bed1;
    Resident bed2;

    Room(int number, int rent) {
        this.number = number;
        this.rent = rent;
    }

    boolean hasFreeBed() {
        return bed1 == null || bed2 == null;
    }

    void place(Resident resident) {
        if (bed1 == null) {
            bed1 = resident;
        } else {
            bed2 = resident;
        }
    }

    void remove(Resident resident) {
        if (bed1 == resident) {
            bed1 = null;
        } else if (bed2 == resident) {
            bed2 = null;
        }
    }

    Resident find(String name) {
        if (bed1 != null && bed1.name.equals(name)) {
            return bed1;
        }
        if (bed2 != null && bed2.name.equals(name)) {
            return bed2;
        }
        return null;
    }

    void billRent() {
        if (bed1 != null) {
            bed1.due = bed1.due + rent;
        }
        if (bed2 != null) {
            bed2.due = bed2.due + rent;
        }
    }

    int totalDue() {
        int sum = 0;
        if (bed1 != null) {
            sum = sum + bed1.due;
        }
        if (bed2 != null) {
            sum = sum + bed2.due;
        }
        return sum;
    }

    String bedText(Resident resident) {
        if (resident == null) {
            return "empty";
        }
        return resident.name + " (due " + resident.due + ")";
    }

    String describe() {
        return "Room " + number + ": " + bedText(bed1) + ", " + bedText(bed2);
    }
}

class Hostel {
    Room first;
    Room second;
    Room third;
    int shiftFee = 500;

    Hostel(Room first, Room second, Room third) {
        this.first = first;
        this.second = second;
        this.third = third;
    }

    Room roomByNumber(int number) {
        if (first.number == number) {
            return first;
        }
        if (second.number == number) {
            return second;
        }
        if (third.number == number) {
            return third;
        }
        return null;
    }

    Room roomOf(String name) {
        if (first.find(name) != null) {
            return first;
        }
        if (second.find(name) != null) {
            return second;
        }
        if (third.find(name) != null) {
            return third;
        }
        return null;
    }

    String checkIn(String name, int number) {
        Room current = roomOf(name);
        if (current != null) {
            return "REFUSED: " + name + " already lives in room " + current.number;
        }
        Room room = roomByNumber(number);
        if (room == null) {
            return "REFUSED: no room " + number;
        }
        if (!room.hasFreeBed()) {
            return "REFUSED: room " + number + " is full";
        }
        room.place(new Resident(name));
        return name + " checked in to room " + number;
    }

    String checkOut(String name) {
        Room room = roomOf(name);
        if (room == null) {
            return "REFUSED: " + name + " is not a resident";
        }
        Resident resident = room.find(name);
        if (resident.due > 0) {
            return "REFUSED: " + name + " must clear " + resident.due + " Tk first";
        }
        room.remove(resident);
        return name + " checked out of room " + room.number;
    }

    String shift(String name, int number) {
        Room from = roomOf(name);
        if (from == null) {
            return "REFUSED: " + name + " is not a resident";
        }
        Room to = roomByNumber(number);
        if (to == null) {
            return "REFUSED: no room " + number;
        }
        if (to == from) {
            return "REFUSED: " + name + " is already in room " + number;
        }
        if (!to.hasFreeBed()) {
            return "REFUSED: room " + number + " is full";
        }
        Resident resident = from.find(name);
        from.remove(resident);
        to.place(resident);
        resident.due = resident.due + shiftFee;
        return name + " shifted to room " + number + " (fee " + shiftFee + " Tk)";
    }

    String billAll() {
        first.billRent();
        second.billRent();
        third.billRent();
        return "Rent billed";
    }

    String pay(String name, int amount) {
        Room room = roomOf(name);
        if (room == null) {
            return "REFUSED: " + name + " is not a resident";
        }
        Resident resident = room.find(name);
        if (amount <= 0 || amount > resident.due) {
            return "REFUSED: invalid amount, due " + resident.due + " Tk";
        }
        resident.due = resident.due - amount;
        return name + " paid " + amount + " Tk, due " + resident.due + " Tk";
    }

    int totalDue() {
        return first.totalDue() + second.totalDue() + third.totalDue();
    }
}

public class HostelOffice {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Room r1 = new Room(in.nextInt(), in.nextInt());
        Room r2 = new Room(in.nextInt(), in.nextInt());
        Room r3 = new Room(in.nextInt(), in.nextInt());
        Hostel hostel = new Hostel(r1, r2, r3);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String request = in.next();
            if (request.equals("IN")) {
                String name = in.next();
                System.out.println(hostel.checkIn(name, in.nextInt()));
            } else if (request.equals("OUT")) {
                System.out.println(hostel.checkOut(in.next()));
            } else if (request.equals("SHIFT")) {
                String name = in.next();
                System.out.println(hostel.shift(name, in.nextInt()));
            } else if (request.equals("BILL")) {
                System.out.println(hostel.billAll());
            } else if (request.equals("PAY")) {
                String name = in.next();
                System.out.println(hostel.pay(name, in.nextInt()));
            } else if (request.equals("SHOW")) {
                System.out.println(r1.describe());
                System.out.println(r2.describe());
                System.out.println(r3.describe());
            }
        }
        System.out.println("Total due: " + hostel.totalDue() + " Tk");
    }
}
```

### Explanation
The story has three nouns that deserve to be classes. A `Resident` owns the money facts
(the due), a `Room` owns its beds and knows how to bill its occupants, and the `Hostel`
owns the three rooms and enforces the rules that involve more than one room. A bed field
holds a *reference* to a `Resident` object, so `SHIFT` simply moves that reference from
one room to another: the same object, with its due, now sits in the new room, and the fee
is added to it. Every request first finds the objects it needs (`roomOf`, `roomByNumber`)
and checks every rule before changing anything, so a refused request never leaves the
hostel half-changed. `main` only reads requests and prints what the hostel answers.

### Concepts Practiced
- Several cooperating classes with clear responsibilities
- Fields that refer to other objects, and `null` for "empty"
- Moving an object between containers by moving its reference
- Validating every rule before changing state

### Solution
```java
import java.util.Scanner;

class Event {
    String name;
    int regularLeft;
    int regularPrice;
    int vipLeft;
    int vipPrice;
    int revenue;

    Event(String name, int regularLeft, int regularPrice, int vipLeft, int vipPrice) {
        this.name = name;
        this.regularLeft = regularLeft;
        this.regularPrice = regularPrice;
        this.vipLeft = vipLeft;
        this.vipPrice = vipPrice;
    }

    int seatsLeft(String type) {
        if (type.equals("VIP")) {
            return vipLeft;
        }
        return regularLeft;
    }

    int price(String type) {
        if (type.equals("VIP")) {
            return vipPrice;
        }
        return regularPrice;
    }

    // A negative count gives seats back.
    void takeSeats(String type, int count) {
        if (type.equals("VIP")) {
            vipLeft = vipLeft - count;
        } else {
            regularLeft = regularLeft - count;
        }
    }

    String describe() {
        return name + ": REGULAR left " + regularLeft + ", VIP left " + vipLeft
                + ", revenue " + revenue + " Tk";
    }
}

class Customer {
    String name;
    int balance;
    int regular;
    int vip;

    Customer(String name, int balance) {
        this.name = name;
        this.balance = balance;
    }

    int held(String type) {
        if (type.equals("VIP")) {
            return vip;
        }
        return regular;
    }

    // A negative count removes tickets.
    void addTickets(String type, int count) {
        if (type.equals("VIP")) {
            vip = vip + count;
        } else {
            regular = regular + count;
        }
    }

    String describe() {
        return name + ": " + regular + " REGULAR, " + vip + " VIP, balance "
                + balance + " Tk";
    }
}

class TicketCounter {
    Event event;
    int maxPerPerson = 4;
    int refundPercent = 80;

    TicketCounter(Event event) {
        this.event = event;
    }

    boolean validType(String type) {
        return type.equals("REGULAR") || type.equals("VIP");
    }

    String buy(Customer c, String type, int qty) {
        if (!validType(type)) {
            return "REFUSED: unknown type " + type;
        }
        if (qty < 1) {
            return "REFUSED: invalid quantity";
        }
        if (c.regular + c.vip + qty > maxPerPerson) {
            return "REFUSED: limit is " + maxPerPerson + " tickets per person";
        }
        if (event.seatsLeft(type) < qty) {
            return "REFUSED: only " + event.seatsLeft(type) + " " + type + " seats left";
        }
        int cost = event.price(type) * qty;
        if (c.balance < cost) {
            return "REFUSED: needs " + cost + " Tk, has " + c.balance + " Tk";
        }
        c.balance = c.balance - cost;
        c.addTickets(type, qty);
        event.takeSeats(type, qty);
        event.revenue = event.revenue + cost;
        return c.name + " bought " + qty + " " + type + " for " + cost + " Tk";
    }

    String cancel(Customer c, String type, int qty) {
        if (!validType(type)) {
            return "REFUSED: unknown type " + type;
        }
        if (qty < 1 || qty > c.held(type)) {
            return "REFUSED: " + c.name + " holds " + c.held(type) + " " + type;
        }
        int refund = event.price(type) * qty * refundPercent / 100;
        c.balance = c.balance + refund;
        c.addTickets(type, -qty);
        event.takeSeats(type, -qty);
        event.revenue = event.revenue - refund;
        return c.name + " cancelled " + qty + " " + type + ", refund " + refund + " Tk";
    }

    String upgrade(Customer c) {
        if (c.regular == 0) {
            return "REFUSED: no REGULAR ticket to upgrade";
        }
        if (event.vipLeft == 0) {
            return "REFUSED: VIP sold out";
        }
        int difference = event.vipPrice - event.regularPrice;
        if (c.balance < difference) {
            return "REFUSED: needs " + difference + " Tk, has " + c.balance + " Tk";
        }
        c.balance = c.balance - difference;
        c.regular--;
        c.vip++;
        event.regularLeft++;
        event.vipLeft--;
        event.revenue = event.revenue + difference;
        return c.name + " upgraded 1 ticket for " + difference + " Tk";
    }
}

public class TicketSales {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Event event = new Event(in.next(), in.nextInt(), in.nextInt(),
                in.nextInt(), in.nextInt());
        Customer first = new Customer(in.next(), in.nextInt());
        Customer second = new Customer(in.next(), in.nextInt());
        TicketCounter counter = new TicketCounter(event);

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("REPORT")) {
                printReport(event, first, second);
                continue;
            }
            String name = in.next();
            Customer c = null;
            if (first.name.equals(name)) {
                c = first;
            } else if (second.name.equals(name)) {
                c = second;
            }
            String result;
            if (command.equals("UPGRADE")) {
                result = c == null ? null : counter.upgrade(c);
            } else {
                String type = in.next();
                int qty = in.nextInt();
                if (c == null) {
                    result = null;
                } else if (command.equals("BUY")) {
                    result = counter.buy(c, type, qty);
                } else {
                    result = counter.cancel(c, type, qty);
                }
            }
            if (result == null) {
                System.out.println("Unknown customer " + name);
            } else {
                System.out.println(result);
            }
        }
        printReport(event, first, second);
    }

    static void printReport(Event event, Customer first, Customer second) {
        System.out.println(event.describe());
        System.out.println(first.describe());
        System.out.println(second.describe());
    }
}
```

### Explanation
Each class answers questions about itself: the `Event` knows its seats, prices and
revenue, and a `Customer` knows the tickets and money they hold. The `TicketCounter` is
the class that knows the *rules* that involve both, so `buy`, `cancel` and `upgrade` live
there and receive the customer object as a parameter. Every method checks all its rules
first and only then updates the customer, the seats and the revenue together, which
keeps the totals consistent: seats sold plus seats left always equals the original
number. Note that the refund is calculated as `price * qty * 80 / 100`, multiplying
before dividing so integer division does not lose more than necessary.

### Concepts Practiced
- Several cooperating classes; a "rules" class that coordinates others
- Methods that take objects as parameters and update several objects
- Checking rules in a fixed order with clear refusal messages
- Integer arithmetic for money (multiply before dividing)

## Problem 8: Library Desk with Reservations
**Level:** Advanced

### Scenario
The department seminar library has two popular books and two student members, Nusrat
and Rafi, who both need them for a project. A member may hold one book at a time for 7
days. Late returns cost 10 Tk per day, and a member who owes a fine cannot borrow. A
member may reserve a book that is on loan; when it comes back, it is held for the
reserver for 2 days, and after that the hold expires. The librarian wants to replay a
couple of weeks of desk activity to check the rules.

### Problem Statement
Write classes `Book` (`code`, `title`, `borrower`, `dueDay`, `reservedFor`, `holdUntil`),
`Member` (`name`, `loan`, `fine`) and `Library` (two books, two members, `today`
starting at day 1). `borrower`, `reservedFor` and `loan` are references to other objects
or `null`.

**Input:** two lines `code title` (the title may contain spaces), one line with the two
member names, then `n` and `n` commands. Every name and code in a command is valid.

| Command | Checks (in this order) | Success text |
|---|---|---|
| `DAY d` | | `Day <today>` (plus expiry lines, see below) |
| `BORROW m b` | m has no fine; m holds no book; b not on loan; b not reserved for someone else | `<m> borrowed <title>, due day <today+7>` |
| `RETURN m b` | b is on loan to m | `<m> returned <b> on time` or `<m> returned <b> late by <k> days, fine <f> Tk` |
| `RESERVE m b` | b not already reserved; b is on loan; m is not its borrower | `<m> reserved <b>` |
| `PAY m amount` | `0 < amount <= fine` | `<m> paid <a> Tk, fine left <f> Tk` |
| `STATUS` | | one line per book, then one per member |

Refusals: `REFUSED: <m> owes <f> Tk`, `REFUSED: <m> already has <code>`,
`REFUSED: <b> is on loan to <name>`, `REFUSED: <b> is held for <name>`,
`REFUSED: <m> does not have <b>`, `REFUSED: <b> is already reserved by <name>`,
`REFUSED: <b> is available, borrow it instead`, `REFUSED: <m> already has <b>`,
`REFUSED: invalid amount`.

Extra rules:

- When a reserved book is returned, append `; held for <name> until day <today+2>` to
  the return line. Borrowing it by the reserver clears the reservation.
- `DAY d` moves `today` forward by `d`. Then, for each book (in input order) that is held
  (not on loan, reserved) with `today > holdUntil`, the reservation is removed and
  `Hold on <b> for <name> expired` is printed after the `Day` line.
- `STATUS` book line: `<b> <title>: ` followed by `on loan to <m>, due day <d>` (plus
  `, reserved by <name>` if reserved), or `held for <name> until day <d>`, or
  `available`. Member line: `<m>: has <b>, fine <f> Tk` or `<m>: has nothing, fine <f> Tk`.

### Sample Input
```text

B2 Head First Java
Nusrat Rafi
10
BORROW Nusrat B1
RESERVE Rafi B1
BORROW Rafi B1
BORROW Rafi B2
DAY 9
RETURN Nusrat B1
BORROW Nusrat B2
STATUS
PAY Nusrat 20

```

### Solution
```java
import java.util.Scanner;

class Member {
    String name;
    Book loan;
    int fine;

    Member(String name) {
        this.name = name;
    }
}

class Book {
    String code;
    String title;
    Member borrower;
    int dueDay;
    Member reservedFor;
    int holdUntil;

    Book(String code, String title) {
        this.code = code;
        this.title = title;
    }

    boolean isHeld() {
        return borrower == null && reservedFor != null;
    }

    String describe() {
        String text = code + " " + title + ": ";
        if (borrower != null) {
            text = text + "on loan to " + borrower.name + ", due day " + dueDay;
            if (reservedFor != null) {
                text = text + ", reserved by " + reservedFor.name;
            }
        } else if (reservedFor != null) {
            text = text + "held for " + reservedFor.name + " until day " + holdUntil;
        } else {
            text = text + "available";
        }
        return text;
    }
}

class Library {
    Book first;
    Book second;
    int today = 1;
    int loanDays = 7;
    int holdDays = 2;
    int finePerDay = 10;

    Library(Book first, Book second) {
        this.first = first;
        this.second = second;
    }

    String advance(int days) {
        today = today + days;
        String text = "Day " + today;
        text = text + expireHold(first);
        text = text + expireHold(second);
        return text;
    }

    String expireHold(Book b) {
        if (b.isHeld() && today > b.holdUntil) {
            String name = b.reservedFor.name;
            b.reservedFor = null;
            return "\nHold on " + b.code + " for " + name + " expired";
        }
        return "";
    }

    String borrow(Member m, Book b) {
        if (m.fine > 0) {
            return "REFUSED: " + m.name + " owes " + m.fine + " Tk";
        }
        if (m.loan != null) {
            return "REFUSED: " + m.name + " already has " + m.loan.code;
        }
        if (b.borrower != null) {
            return "REFUSED: " + b.code + " is on loan to " + b.borrower.name;
        }
        if (b.reservedFor != null && b.reservedFor != m) {
            return "REFUSED: " + b.code + " is held for " + b.reservedFor.name;
        }
        b.reservedFor = null;
        b.borrower = m;
        b.dueDay = today + loanDays;
        m.loan = b;
        return m.name + " borrowed " + b.title + ", due day " + b.dueDay;
    }

    String giveBack(Member m, Book b) {
        if (b.borrower != m) {
            return "REFUSED: " + m.name + " does not have " + b.code;
        }
        b.borrower = null;
        m.loan = null;
        String text = m.name + " returned " + b.code;
        int late = today - b.dueDay;
        if (late > 0) {
            int fine = late * finePerDay;
            m.fine = m.fine + fine;
            text = text + " late by " + late + " days, fine " + fine + " Tk";
        } else {
            text = text + " on time";
        }
        if (b.reservedFor != null) {
            b.holdUntil = today + holdDays;
            text = text + "; held for " + b.reservedFor.name + " until day " + b.holdUntil;
        }
        return text;
    }

    String reserve(Member m, Book b) {
        if (b.reservedFor != null) {
            return "REFUSED: " + b.code + " is already reserved by " + b.reservedFor.name;
        }
        if (b.borrower == null) {
            return "REFUSED: " + b.code + " is available, borrow it instead";
        }
        if (b.borrower == m) {
            return "REFUSED: " + m.name + " already has " + b.code;
        }
        b.reservedFor = m;
        return m.name + " reserved " + b.code;
    }

    String pay(Member m, int amount) {
        if (amount <= 0 || amount > m.fine) {
            return "REFUSED: invalid amount";
        }
        m.fine = m.fine - amount;
        return m.name + " paid " + amount + " Tk, fine left " + m.fine + " Tk";
    }

    String memberLine(Member m) {
        String has = "nothing";
        if (m.loan != null) {
            has = m.loan.code;
        }
        return m.name + ": has " + has + ", fine " + m.fine + " Tk";
    }
}

public class LibraryDesk {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Book b1 = new Book(in.next(), in.nextLine().trim());
        Book b2 = new Book(in.next(), in.nextLine().trim());
        Member m1 = new Member(in.next());
        Member m2 = new Member(in.next());
        Library library = new Library(b1, b2);

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("DAY")) {
                System.out.println(library.advance(in.nextInt()));
            } else if (command.equals("STATUS")) {
                System.out.println(b1.describe());
                System.out.println(b2.describe());
                System.out.println(library.memberLine(m1));
                System.out.println(library.memberLine(m2));
            } else {
                Member m = m1;
                if (m2.name.equals(in.next())) {
                    m = m2;
                }
                if (command.equals("PAY")) {
                    System.out.println(library.pay(m, in.nextInt()));
                    continue;
                }
                Book b = b1;
                if (b2.code.equals(in.next())) {
                    b = b2;
                }
                if (command.equals("BORROW")) {
                    System.out.println(library.borrow(m, b));
                } else if (command.equals("RETURN")) {
                    System.out.println(library.giveBack(m, b));
                } else {
                    System.out.println(library.reserve(m, b));
                }
            }
        }
    }
}
```

### Explanation
The design follows the story: a `Book` knows who has it and who reserved it, a `Member`
knows which book they hold and what they owe, and the `Library` knows the date and the
rules that connect them. Books and members refer to each other (`b.borrower` and
`m.loan`), and every successful borrow or return updates *both* sides in the same
method, so the two references always agree. The checks use reference comparison
(`b.borrower != m`) to ask "is this the same member object?", which is simpler and safer
than comparing names. Hold expiry is handled only when time moves (`advance`), because
that is the only moment a hold can run out. Title lines are read with `next()` for the
code and `nextLine().trim()` for the rest of the line, since titles contain spaces.

### Concepts Practiced
- Two-way references between objects that must stay consistent
- A coordinating class holding shared state (`today`) and the rules
- `null` as "no book", "no borrower" and "no reservation"
- Mixing `next()` and `nextLine()` correctly
