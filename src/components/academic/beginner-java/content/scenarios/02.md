# Scenario-Based Problems

These scenarios practise Chapter 02: `if`/`else` ladders with exact boundaries,
`switch`, and the three loops with `break` and `continue`. Read every rule for words
like "at least", "more than" and "up to": the test cases check exactly those
boundaries. All code stays inside `main` (methods come in Chapter 03).

Programs read input without prompts and print exactly the sample output. All fees,
rates and rules in these problems are hypothetical and invented for practice.

## Problem 1: Merit Fee Waiver
**Level:** Basic

### Scenario
The university gives a tuition waiver each trimester based on the previous trimester's
GPA. Students often argue at the accounts desk about the exact boundaries, so the
accounts office wants a calculator that applies the rules exactly.

### Problem Statement
Input: the number of credits taken (integer), the fee per credit (integer Tk) and the
GPA (a decimal number).

| GPA | Waiver |
|---|---|
| 3.90 or more | 100% |
| at least 3.75 (below 3.90) | 50% |
| at least 3.50 (below 3.75) | 25% |
| below 3.50 | 0% |

A GPA outside `0.00`–`4.00` or credits outside `1`–`15` are invalid: print only
`Invalid input`. Otherwise print exactly:

```text
Tuition: <credits x fee> Tk
Waiver: <percent>% (<waiver amount> Tk)
Payable: <tuition - waiver amount> Tk
```

The waiver amount is `tuition × percent / 100` in integer arithmetic.

### Sample Input
```text
12 6500 3.82
```

### Sample Output
```text
Tuition: 78000 Tk
Waiver: 50% (39000 Tk)
Payable: 39000 Tk
```

### Solution
```java
import java.util.Scanner;

public class MeritWaiver {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int credits = in.nextInt();
        int feePerCredit = in.nextInt();
        double gpa = in.nextDouble();

        if (gpa < 0.0 || gpa > 4.0 || credits < 1 || credits > 15) {
            System.out.println("Invalid input");
        } else {
            int tuition = credits * feePerCredit;
            int percent;
            if (gpa >= 3.90) {
                percent = 100;
            } else if (gpa >= 3.75) {
                percent = 50;
            } else if (gpa >= 3.50) {
                percent = 25;
            } else {
                percent = 0;
            }
            int waiver = tuition * percent / 100;
            System.out.println("Tuition: " + tuition + " Tk");
            System.out.println("Waiver: " + percent + "% (" + waiver + " Tk)");
            System.out.println("Payable: " + (tuition - waiver) + " Tk");
        }
    }
}
```

### Explanation
The validity check comes first, so the ladder only ever sees sensible values. The
ladder tests the **highest** band first; once `gpa >= 3.90` fails, the next test only
needs `gpa >= 3.75`, because the program already knows the GPA is below 3.90. That is
why each `else if` needs only one comparison. Testing the bands in the opposite order
(`>= 3.50` first) would give every good student only 25%.

### Concepts Practiced
- `if`/`else if` ladders ordered from the highest band
- Combining conditions with `||`
- Boundary values




**Expected Output**
```text

```

## Problem 2: Canteen Counter Until Closing
**Level:** Intermediate

### Scenario
The canteen manager types orders into a small program all afternoon. Each order is an
item code and a quantity. Code `0` means the canteen is closing. Mistyped codes or
quantities must not stop the program; they are reported and skipped.

### Problem Statement
Menu (use a `switch` on the code):

| Code | Item | Price (Tk) |
|---|---|---|
| 1 | Tea | 15 |
| 2 | Singara | 10 |
| 3 | Khichuri | 120 |
| 4 | Water | 20 |

Input: pairs `code quantity` until a code of `0` (the quantity after `0` is not
given). For each order:

- unknown code: print `Unknown code <code>` and skip it;
- quantity not between `1` and `20`: print `Bad quantity <quantity>` and skip it;
- otherwise print `<item> x<quantity> = <cost> Tk`.

After closing, print:

```text
Orders: <valid orders>
Pieces: <total quantity>
Sales: <total> Tk
Largest order: <item> <cost> Tk
```

The largest order is the valid order with the highest cost (the first one on a tie).
If there were no valid orders, print `No sales today` instead of these four lines.

### Sample Input
```text
1 3
3 1
7 2
2 25
2 6
4 2
0
```

### Sample Output
```text
Tea x3 = 45 Tk
Khichuri x1 = 120 Tk
Unknown code 7
Bad quantity 25
Singara x6 = 60 Tk
Water x2 = 40 Tk
Orders: 4
Pieces: 12
Sales: 265 Tk
Largest order: Khichuri 120 Tk
```

### Solution
```java
import java.util.Scanner;

public class CanteenCounter {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int orders = 0;
        int pieces = 0;
        int sales = 0;
        int largestCost = 0;
        String largestItem = "";

        while (true) {
            int code = in.nextInt();
            if (code == 0) {
                break;
            }
            int quantity = in.nextInt();

            String item;
            int price;
            switch (code) {
                case 1:
                    item = "Tea";
                    price = 15;
                    break;
                case 2:
                    item = "Singara";
                    price = 10;
                    break;
                case 3:
                    item = "Khichuri";
                    price = 120;
                    break;
                case 4:
                    item = "Water";
                    price = 20;
                    break;
                default:
                    item = "";
                    price = 0;
                    break;
            }
            if (price == 0) {
                System.out.println("Unknown code " + code);
                continue;
            }
            if (quantity < 1 || quantity > 20) {
                System.out.println("Bad quantity " + quantity);
                continue;
            }

            int cost = price * quantity;
            System.out.println(item + " x" + quantity + " = " + cost + " Tk");
            orders++;
            pieces += quantity;
            sales += cost;
            if (cost > largestCost) {
                largestCost = cost;
                largestItem = item;
            }
        }

        if (orders == 0) {
            System.out.println("No sales today");
        } else {
            System.out.println("Orders: " + orders);
            System.out.println("Pieces: " + pieces);
            System.out.println("Sales: " + sales + " Tk");
            System.out.println("Largest order: " + largestItem + " " + largestCost + " Tk");
        }
    }
}
```

### Explanation
`while (true)` with a `break` on the sentinel `0` is a clear way to write "repeat until
the closing code". The quantity is read only after checking for `0`, because no
quantity follows the sentinel. `continue` skips the rest of the loop body for a bad
order, so the totals are never touched by invalid input. Each `case` ends with
`break`; without it, execution would fall through into the next case. The largest
order uses `>` (not `>=`), so the first of several equal orders is kept.

### Concepts Practiced
- Sentinel-controlled loops with `break`
- `continue` to skip invalid input
- `switch` with `break` and `default`
- Running totals and a running maximum

## Problem 3: Savings Goal Simulator
**Level:** Intermediate

### Scenario
Sadia wants to save for a laptop. She opens a savings account with an initial deposit,
adds a fixed amount every month, and the bank adds interest every month. She wants to
know how many months it will take, and to see the balance at the end of every year.

### Problem Statement
Input: the initial deposit, the monthly deposit, the monthly interest rate in percent
(a decimal) and the goal, in that order.

Simulate month by month, starting from the initial deposit. In each month:

1. add the monthly deposit;
2. then add interest: `balance × rate / 100`.

Stop as soon as the balance is at least the goal **at the end of a month**. At the end
of every 12th month (if the simulation is still running), print
`Year <y>: Tk <balance>` with 2 decimals.

If the goal is already reached before the first month, print
`Goal already reached` and nothing else. If the goal is not reached within 120 months,
print `Goal not reached in 10 years` after the yearly lines. Otherwise finish with:

```text
Goal reached after <m> months (<y> years <r> months)
Final balance: Tk <balance>
```

### Sample Input
```text
5000 3000 0.5 80000
```

### Sample Output
```text
Year 1: Tk 42500.11
Goal reached after 24 months (2 years 0 months)
Final balance: Tk 82313.14
```

### Solution
```java
import java.util.Scanner;

public class SavingsGoal {
    public static void main(String[] args) {
        final int MAX_MONTHS = 120;

        Scanner in = new Scanner(System.in);
        double balance = in.nextDouble();
        double monthly = in.nextDouble();
        double rate = in.nextDouble();
        double goal = in.nextDouble();

        if (balance >= goal) {
            System.out.println("Goal already reached");
        } else {
            int month = 0;
            while (balance < goal && month < MAX_MONTHS) {
                month++;
                balance += monthly;
                balance += balance * rate / 100;
                if (month % 12 == 0 && balance < goal) {
                    System.out.printf("Year %d: Tk %.2f%n", month / 12, balance);
                }
            }
            if (balance < goal) {
                System.out.println("Goal not reached in 10 years");
            } else {
                System.out.printf("Goal reached after %d months (%d years %d months)%n",
                        month, month / 12, month % 12);
                System.out.printf("Final balance: Tk %.2f%n", balance);
            }
        }
    }
}
```

### Explanation
The loop condition has two parts: keep going while the goal is not reached **and** the
time limit is not used up. After the loop, checking `balance < goal` tells us which
part stopped it. The yearly line is printed only while the goal is still unreached,
which matches "if the simulation is still running"; when the goal is reached exactly at
a year's end, the final message covers it. `month / 12` and `month % 12` convert months
into years and remaining months. Deciding the order of steps inside the loop (deposit
first, then interest) is part of the specification, and a different order gives a
different answer.

### Concepts Practiced
- `while` loops with a compound condition
- Simulation of a process step by step
- Using `%` to act every 12th iteration
- Formatting money with `printf`

### Test Cases

```text

```
**Expected Output**


#### Goal is never reached

**Expected Output**


## Problem 4: Exam Hall Seat Plan
**Level:** Advanced

### Scenario
In a mixed exam hall, students from two departments sit in a checkerboard pattern so
that no two neighbours (front, back, left, right) are from the same department. The
exam office needs a printed seat plan for the hall and a summary of how many seats each
department uses.

### Problem Statement
Input: the number of rows `R` and columns `C` of the hall (each 1 to 9), then the
number of CSE students and the number of EEE students.

Seats are filled row by row, left to right. A seat where `(row + column)` is even (rows
and columns counted from 1) is a CSE seat; the others are EEE seats. CSE seats get
labels `C01`, `C02`, … in the order they are filled, EEE seats get `E01`, `E02`, …. When
a department has no students left, its remaining seats are printed as `---`.

Print a header line `     ` (5 spaces) followed by the column numbers, each in a
field of width 4 (`%4d`). Then print each row as `Row <r>` followed by the seat labels,
each in a field of width 4 (`%4s`). Finally print:

```text
CSE seated: <n>, EEE seated: <m>
Empty seats: <e>
```

If more students than seats are available for a department, also print
`Not seated: CSE <x>, EEE <y>` after these lines.

### Sample Input
```text
3 4 5 7
```

### Sample Output
```text
        1   2   3   4
Row 1 C01 E01 C02 E02
Row 2 E03 C03 E04 C04
Row 3 C05 E05 --- E06
CSE seated: 5, EEE seated: 6
Empty seats: 1
Not seated: CSE 0, EEE 1
```

### Solution
```java
import java.util.Scanner;

public class SeatPlan {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int rows = in.nextInt();
        int cols = in.nextInt();
        int cse = in.nextInt();
        int eee = in.nextInt();

        System.out.print("     ");
        for (int c = 1; c <= cols; c++) {
            System.out.printf("%4d", c);
        }
        System.out.println();

        int cseSeated = 0;
        int eeeSeated = 0;
        int empty = 0;
        for (int r = 1; r <= rows; r++) {
            System.out.print("Row " + r);
            for (int c = 1; c <= cols; c++) {
                String label;
                if ((r + c) % 2 == 0) {
                    if (cseSeated < cse) {
                        cseSeated++;
                        label = String.format("C%02d", cseSeated);
                    } else {
                        label = "---";
                        empty++;
                    }
                } else {
                    if (eeeSeated < eee) {
                        eeeSeated++;
                        label = String.format("E%02d", eeeSeated);
                    } else {
                        label = "---";
                        empty++;
                    }
                }
                System.out.printf("%4s", label);
            }
            System.out.println();
        }

        System.out.println("CSE seated: " + cseSeated + ", EEE seated: " + eeeSeated);
        System.out.println("Empty seats: " + empty);
        if (cseSeated < cse || eeeSeated < eee) {
            System.out.println("Not seated: CSE " + (cse - cseSeated) + ", EEE " + (eee - eeeSeated));
        }
    }
}
```

### Explanation
The outer loop walks the rows and the inner loop walks the seats of one row, so the
inner body runs once per seat. `(r + c) % 2 == 0` creates the checkerboard: moving one
seat left, right, up or down changes `r + c` by one and therefore flips between even
and odd. Each department has its own counter, which doubles as the next label number;
`String.format("C%02d", n)` builds the label with a two-digit number. `print` (not
`println`) keeps a row on one line, and `println()` after the inner loop ends it. Fixed
field widths (`%4d`, `%4s`) line the columns up under the header.

### Concepts Practiced
- Nested loops for a two-dimensional layout
- Using `%` to alternate a pattern
- Several counters updated in one loop
- `printf` and `String.format` field widths
