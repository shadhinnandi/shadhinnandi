# Scenario-Based Problems

These scenarios practise Chapter 11: catching the exceptions Java throws for bad input,
writing your own checked and unchecked exceptions, `throw` and `throws`, catching
specific exceptions before general ones, `finally`, and try-with-resources. Every
program reports problems on standard output and **keeps going**: one bad record must
not crash the whole run.

Programs read input without prompts and print exactly the sample output. All fees,
rates and rules in these problems are hypothetical and invented for practice.

## Problem 1: Importing Lab Marks
**Level:** Basic

### Scenario
Teaching assistants send lab marks as text lines `name marks`. Some lines have typos:
a missing number, letters instead of digits, or marks outside 0–30. The import must
skip bad lines with a clear reason and still compute the average of the good ones.

### Problem Statement
Write an unchecked exception `InvalidMarksException extends RuntimeException` and a
method `static int parseMarks(String text)` that uses `Integer.parseInt` and throws
`InvalidMarksException("marks <m> out of range")` for values outside 0–30.

Input: `n`, then `n` lines. A valid line is exactly two words: a name and the marks.
For each line print `<name>: <marks>` or `Line <i> skipped: <reason>` where the reason
is:

- `expected name and marks` if the line does not have exactly two words;
- `not a number: <text>` if `parseInt` throws `NumberFormatException`;
- the exception's message for `InvalidMarksException`.

Finally print `Imported <k> of <n>, average <avg with 2 decimals>` (average `0.00` if
nothing was imported).

### Sample Input
```text
5
Rahim 24
Nusrat twenty
Tanvir 31
Ayesha
Imran 18
```

### Sample Output
```text
Rahim: 24
Line 2 skipped: not a number: twenty
Line 3 skipped: marks 31 out of range
Line 4 skipped: expected name and marks
Imran: 18
Imported 2 of 5, average 21.00
```

### Solution
```java
import java.util.Scanner;

class InvalidMarksException extends RuntimeException {
    InvalidMarksException(String message) {
        super(message);
    }
}

public class LabMarksImport {
    static int parseMarks(String text) {
        int marks = Integer.parseInt(text);
        if (marks < 0 || marks > 30) {
            throw new InvalidMarksException("marks " + marks + " out of range");
        }
        return marks;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = Integer.parseInt(in.nextLine().trim());
        int imported = 0;
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            String[] parts = in.nextLine().trim().split("\\s+");
            try {
                if (parts.length != 2) {
                    System.out.println("Line " + i + " skipped: expected name and marks");
                    continue;
                }
                int marks = parseMarks(parts[1]);
                System.out.println(parts[0] + ": " + marks);
                imported++;
                sum += marks;
            } catch (NumberFormatException e) {
                System.out.println("Line " + i + " skipped: not a number: " + parts[1]);
            } catch (InvalidMarksException e) {
                System.out.println("Line " + i + " skipped: " + e.getMessage());
            }
        }
        double average = imported == 0 ? 0 : (double) sum / imported;
        System.out.printf("Imported %d of %d, average %.2f%n", imported, n, average);
    }
}
```

### Explanation
`Integer.parseInt` signals bad text by throwing `NumberFormatException`; the program
catches it and turns it into a readable message instead of a crash. The range rule is
the program's own, so it gets its own exception class with a message that explains the
problem; `getMessage()` returns that text. Both exceptions are unchecked
(`RuntimeException` subclasses), so the compiler does not force a `try`, but the
program chooses to catch them because it knows how to recover: skip the line. Each
catch block names the exact exception it handles, which keeps other bugs visible.

### Concepts Practiced
- Catching `NumberFormatException`
- A custom unchecked exception with a message
- Multiple `catch` blocks
- Recovering and continuing after an error

## Problem 2: ATM Withdrawals
**Level:** Intermediate

### Scenario
A campus ATM must explain every refused withdrawal precisely and must always return
the card, whether the withdrawal worked or not. The bank's rules: amounts in multiples
of 500, at most 20000 per day, and never more than the balance.

### Problem Statement
Write two **checked** exceptions:

- `InsufficientFundsException` with a `long getShortfall()` method and the message
  `insufficient funds, short by <shortfall>`;
- `DailyLimitException` with the message `daily limit 20000 exceeded`.

Write `Account.withdraw(long amount) throws InsufficientFundsException,
DailyLimitException` that throws `IllegalArgumentException("amount must be a positive
multiple of 500")` for bad amounts (unchecked), then checks the daily limit (amount
withdrawn today + this amount), then the balance.

Input: the opening balance, then `n` amounts. For each amount, in a
`try`/`catch`/`finally`:

- success: `Withdrew <a>, balance <b>`;
- `InsufficientFundsException`: `Refused: <message>`;
- `DailyLimitException` or `IllegalArgumentException` (one multi-catch):
  `Refused: <message>`;
- `finally`: `Card returned`.

### Sample Input
```text
26000
5
5000
1200
12000
4000
9000
```

### Sample Output
```text
Withdrew 5000, balance 21000
Card returned
Refused: amount must be a positive multiple of 500
Card returned
Withdrew 12000, balance 9000
Card returned
Refused: daily limit 20000 exceeded
Card returned
Refused: daily limit 20000 exceeded
Card returned
```

### Solution
```java
import java.util.Scanner;

class InsufficientFundsException extends Exception {
    private final long shortfall;

    InsufficientFundsException(long shortfall) {
        super("insufficient funds, short by " + shortfall);
        this.shortfall = shortfall;
    }

    long getShortfall() {
        return shortfall;
    }
}

class DailyLimitException extends Exception {
    DailyLimitException() {
        super("daily limit 20000 exceeded");
    }
}

class Account {
    private static final long DAILY_LIMIT = 20000;
    private long balance;
    private long withdrawnToday;

    Account(long balance) {
        this.balance = balance;
    }

    long getBalance() {
        return balance;
    }

    void withdraw(long amount) throws InsufficientFundsException, DailyLimitException {
        if (amount <= 0 || amount % 500 != 0) {
            throw new IllegalArgumentException("amount must be a positive multiple of 500");
        }
        if (withdrawnToday + amount > DAILY_LIMIT) {
            throw new DailyLimitException();
        }
        if (amount > balance) {
            throw new InsufficientFundsException(amount - balance);
        }
        balance -= amount;
        withdrawnToday += amount;
    }
}

public class CampusAtm {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Account account = new Account(in.nextLong());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            long amount = in.nextLong();
            try {
                account.withdraw(amount);
                System.out.println("Withdrew " + amount + ", balance " + account.getBalance());
            } catch (InsufficientFundsException e) {
                System.out.println("Refused: " + e.getMessage());
            } catch (DailyLimitException | IllegalArgumentException e) {
                System.out.println("Refused: " + e.getMessage());
            } finally {
                System.out.println("Card returned");
            }
        }
    }
}
```

### Explanation
`withdraw` declares its two checked exceptions with `throws`, so every caller is forced
by the compiler to handle them or pass them on. That is the point of checked
exceptions: refusals are an expected part of using an ATM, and the type system makes
sure nobody forgets them. A bad amount is a programming or input mistake, so it uses an
unchecked `IllegalArgumentException`. The multi-catch `catch (A | B e)` handles two
unrelated exceptions with one block. `finally` runs after the `try` succeeds **and**
after any `catch`, so "Card returned" is printed every time. The shortfall is stored in
a field of the exception, so a caller could use it (for example, to suggest a smaller
amount), not only print it.

### Concepts Practiced
- Custom checked exceptions with extra data
- `throws` declarations
- Multi-catch
- `finally`

## Problem 3: Course Registration Checks
**Level:** Intermediate

### Scenario
During registration week the advising system checks every request: prerequisites,
seat capacity and the credit limit. Each failure must be reported with its specific
reason, and the advisor also wants a count of failures by kind.

### Problem Statement
Write a **checked** exception `RegistrationException` and three subclasses:
`PrerequisiteException`, `SectionFullException` and `CreditLimitException`, each with
a message (see the sample).

Courses (fixed in the program):

| Code | Credits | Prerequisite | Seats |
|---|---|---|---|
| CSE1111 | 3 | none | 3 |
| CSE1112 | 1 | none | 2 |
| CSE2215 | 3 | CSE1111 | 2 |
| MAT2105 | 3 | none | 1 |

A student may take at most 7 credits. Write `void register(String code)` in a
`Student` class that throws the right exception (an unknown course code throws a plain
`RegistrationException("no course <code>")`); seats are shared by all students.

Input: `n` lines `name completed code` where `completed` is a comma-separated list of
completed courses or `-`, and `code` is the requested course. Students with the same
name are the same student. For each request print `<name> -> <code>: OK` or
`<name> -> <code>: <message>`. Catch the three subclasses **separately** to count them,
and the base class last. Finally print
`Failures: prerequisite <a>, full <b>, credits <c>, other <d>`.

### Sample Input
```text
7
Rahim CSE1111 CSE2215
Nusrat - CSE2215
Rahim CSE1111 MAT2105
Imran - MAT2105
Rahim CSE1111 CSE1112
Rahim CSE1111 CSE1111
Ayesha - EEE1001
```

### Sample Output
```text
Rahim -> CSE2215: OK
Nusrat -> CSE2215: needs CSE1111 before CSE2215
Rahim -> MAT2105: OK
Imran -> MAT2105: MAT2105 is full
Rahim -> CSE1112: OK
Rahim -> CSE1111: would have 10 credits, limit 7
Ayesha -> EEE1001: no course EEE1001
Failures: prerequisite 1, full 1, credits 1, other 1
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class RegistrationException extends Exception {
    RegistrationException(String message) {
        super(message);
    }
}

class PrerequisiteException extends RegistrationException {
    PrerequisiteException(String course, String missing) {
        super("needs " + missing + " before " + course);
    }
}

class SectionFullException extends RegistrationException {
    SectionFullException(String course) {
        super(course + " is full");
    }
}

class CreditLimitException extends RegistrationException {
    CreditLimitException(int wanted) {
        super("would have " + wanted + " credits, limit 7");
    }
}

class Course {
    final String code;
    final int credits;
    final String prerequisite;
    private int seatsLeft;

    Course(String code, int credits, String prerequisite, int seats) {
        this.code = code;
        this.credits = credits;
        this.prerequisite = prerequisite;
        this.seatsLeft = seats;
    }

    void takeSeat() throws SectionFullException {
        if (seatsLeft == 0) {
            throw new SectionFullException(code);
        }
        seatsLeft--;
    }
}

class Catalogue {
    private final ArrayList<Course> courses = new ArrayList<>();

    Catalogue() {
        courses.add(new Course("CSE1111", 3, null, 3));
        courses.add(new Course("CSE1112", 1, null, 2));
        courses.add(new Course("CSE2215", 3, "CSE1111", 2));
        courses.add(new Course("MAT2105", 3, null, 1));
    }

    Course find(String code) throws RegistrationException {
        for (Course c : courses) {
            if (c.code.equals(code)) {
                return c;
            }
        }
        throw new RegistrationException("no course " + code);
    }
}

class Student {
    private static final int MAX_CREDITS = 7;
    private final String name;
    private final String completed;
    private int credits;

    Student(String name, String completed) {
        this.name = name;
        this.completed = completed;
    }

    String getName() {
        return name;
    }

    void register(Course course) throws RegistrationException {
        if (course.prerequisite != null && !completed.contains(course.prerequisite)) {
            throw new PrerequisiteException(course.code, course.prerequisite);
        }
        if (credits + course.credits > MAX_CREDITS) {
            throw new CreditLimitException(credits + course.credits);
        }
        course.takeSeat();
        credits += course.credits;
    }
}

public class RegistrationChecks {
    static Student findOrCreate(ArrayList<Student> students, String name, String completed) {
        for (Student s : students) {
            if (s.getName().equals(name)) {
                return s;
            }
        }
        Student s = new Student(name, completed);
        students.add(s);
        return s;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Catalogue catalogue = new Catalogue();
        ArrayList<Student> students = new ArrayList<>();
        int prerequisite = 0;
        int full = 0;
        int credits = 0;
        int other = 0;

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String name = in.next();
            String completed = in.next();
            String code = in.next();
            Student s = findOrCreate(students, name, completed);
            String prefix = name + " -> " + code + ": ";
            try {
                s.register(catalogue.find(code));
                System.out.println(prefix + "OK");
            } catch (PrerequisiteException e) {
                prerequisite++;
                System.out.println(prefix + e.getMessage());
            } catch (SectionFullException e) {
                full++;
                System.out.println(prefix + e.getMessage());
            } catch (CreditLimitException e) {
                credits++;
                System.out.println(prefix + e.getMessage());
            } catch (RegistrationException e) {
                other++;
                System.out.println(prefix + e.getMessage());
            }
        }
        System.out.println("Failures: prerequisite " + prerequisite + ", full " + full
                + ", credits " + credits + ", other " + other);
    }
}
```

### Explanation
The exceptions form a small hierarchy: every specific problem **is a**
`RegistrationException`. That lets `register` declare just `throws
RegistrationException` while still throwing the specific subclasses, and lets callers
choose how specific to be. The `catch` blocks go from most specific to most general;
if `catch (RegistrationException e)` came first, the compiler would reject the later
blocks as unreachable. `takeSeat` throws `SectionFullException` from inside `Course`
and the exception travels up through `register` to `main` without any code in between:
that is exception propagation. Because the checks run in order and the seat is taken
last, a refused request never uses up a seat or credits.

### Concepts Practiced
- A hierarchy of custom checked exceptions
- Ordering `catch` blocks from specific to general
- Exceptions propagating through several methods
- Keeping state unchanged when an operation fails

## Problem 4: Loading Settings Safely
**Level:** Advanced

### Scenario
The lab booking system reads its settings from `settings.txt` when it starts. The file
is edited by hand, so it may be missing or contain mistakes. The system must never fail
to start: it uses defaults for anything missing or wrong and reports every problem with
its line number.

### Problem Statement
Settings and defaults: `labs=4` (1–20), `slotMinutes=90` (30–240), `openHour=8`
(0–23), `closeHour=20` (0–23, must be greater than `openHour`).

Write a checked exception `ConfigException(int line, String message)` whose
`getMessage()` returns `line <n>: <message>`, and a class `Settings` with
`static Settings load(String fileName)` that:

- opens the file with try-with-resources (`Scanner` on a `File`); if the file does
  not exist, catches `FileNotFoundException`, prints
  `settings.txt not found, using defaults` and returns the defaults;
- reads each line; blank lines and lines starting with `#` are ignored; every other
  line must be `key=value`;
- for each bad line, prints `Ignored <exception message>` and continues. Problems are:
  `missing '='`, `unknown key <key>`, `<key> is not a number`,
  `<key> must be <min> to <max>`;
- after reading, if `closeHour <= openHour`, prints
  `Ignored closeHour <c> not after openHour <o>, using 20` and sets `closeHour` to 20
  (and `openHour` to 8 if 20 is not after it).

Input: the program reads the file name from standard input. Print the problems (if
any) and then `labs=<a> slotMinutes=<b> openHour=<c> closeHour=<d>` and
`Slots per lab: <(close − open) × 60 / slotMinutes>`.

### Sample Input
```text
settings.txt
```
**File `settings.txt`**
```text
# lab booking settings
labs=6
slotMinutes=sixty
openHour=9

closeHour=7
colour=blue
slotMinutes=120
labs 8
```

### Sample Output
```text
Ignored line 3: slotMinutes is not a number
Ignored line 7: unknown key colour
Ignored line 9: missing '='
Ignored closeHour 7 not after openHour 9, using 20
labs=6 slotMinutes=120 openHour=9 closeHour=20
Slots per lab: 5
```

### Solution
```java
import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

class ConfigException extends Exception {
    ConfigException(int line, String message) {
        super("line " + line + ": " + message);
    }
}

class Settings {
    int labs = 4;
    int slotMinutes = 90;
    int openHour = 8;
    int closeHour = 20;

    static Settings load(String fileName) {
        Settings s = new Settings();
        try (Scanner file = new Scanner(new File(fileName))) {
            int lineNumber = 0;
            while (file.hasNextLine()) {
                String line = file.nextLine().trim();
                lineNumber++;
                if (line.isEmpty() || line.startsWith("#")) {
                    continue;
                }
                try {
                    s.apply(lineNumber, line);
                } catch (ConfigException e) {
                    System.out.println("Ignored " + e.getMessage());
                }
            }
        } catch (FileNotFoundException e) {
            System.out.println(fileName + " not found, using defaults");
        }
        if (s.closeHour <= s.openHour) {
            System.out.println("Ignored closeHour " + s.closeHour + " not after openHour "
                    + s.openHour + ", using 20");
            s.closeHour = 20;
            if (s.closeHour <= s.openHour) {
                s.openHour = 8;
            }
        }
        return s;
    }

    private void apply(int line, String text) throws ConfigException {
        int eq = text.indexOf('=');
        if (eq < 0) {
            throw new ConfigException(line, "missing '='");
        }
        String key = text.substring(0, eq).trim();
        String valueText = text.substring(eq + 1).trim();
        if (key.equals("labs")) {
            labs = number(line, key, valueText, 1, 20);
        } else if (key.equals("slotMinutes")) {
            slotMinutes = number(line, key, valueText, 30, 240);
        } else if (key.equals("openHour")) {
            openHour = number(line, key, valueText, 0, 23);
        } else if (key.equals("closeHour")) {
            closeHour = number(line, key, valueText, 0, 23);
        } else {
            throw new ConfigException(line, "unknown key " + key);
        }
    }

    private static int number(int line, String key, String text, int min, int max)
            throws ConfigException {
        int value;
        try {
            value = Integer.parseInt(text);
        } catch (NumberFormatException e) {
            throw new ConfigException(line, key + " is not a number");
        }
        if (value < min || value > max) {
            throw new ConfigException(line, key + " must be " + min + " to " + max);
        }
        return value;
    }

    @Override
    public String toString() {
        return "labs=" + labs + " slotMinutes=" + slotMinutes + " openHour=" + openHour
                + " closeHour=" + closeHour;
    }
}

public class SettingsLoader {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Settings s = Settings.load(in.next());
        System.out.println(s);
        System.out.println("Slots per lab: " + (s.closeHour - s.openHour) * 60 / s.slotMinutes);
    }
}
```

### Explanation
Three layers of handling work together. Opening the file can throw the checked
`FileNotFoundException`; `load` catches it and falls back to defaults, so a missing
file is not fatal. For each line, `apply` throws a `ConfigException` that carries the
line number, and the loop catches it **per line**, so one bad line does not stop the
others. Inside `number`, a `NumberFormatException` is caught and **translated** into a
`ConfigException` with a clearer message: low-level exceptions should be converted
into the vocabulary of your program. Try-with-resources closes the file whether the
loop finishes normally or not. Values are applied only after they pass validation, so
a bad line never leaves a half-set value behind.

### Concepts Practiced
- Handling `FileNotFoundException` with try-with-resources
- A custom checked exception carrying extra context
- Translating one exception into another
- Catching inside a loop to continue after errors
