# Scenario-Based Problems

These scenarios use only what Chapter 00 introduced: printing, simple variables and
arithmetic, and sending messages to objects Java already provides (`String`, `Math` and
`Scanner`). There are no decisions or loops yet, so every program is a straight
sequence of steps: read, compute, print.

Programs read input without prompts and print exactly the sample output. All fees,
rates and rules in these problems are hypothetical and invented for practice.

## Problem 1: Rickshaw Fare Receipt
**Level:** Basic

### Scenario
A student volunteer group runs a rickshaw service between the campus gate and the
hostels. The rickshaw pullers want a printed receipt so that passengers can see how the
fare was calculated: a fixed starting charge, a charge per kilometre and a small
charge for every minute the rickshaw waits.

### Problem Statement
The fare is `30` Tk to start, plus `15` Tk per kilometre, plus `2` Tk per waiting
minute.

Input: the passenger's name (one word), the distance in whole kilometres and the
waiting time in whole minutes, separated by spaces.

Output exactly three lines:

```text
Passenger: <name>
Distance: <km> km, waiting: <minutes> min
Fare: 30 + <distance charge> + <waiting charge> = <total> Tk
```

### Sample Input
```text
Rahim 3 10
```

### Sample Output
```text
Passenger: Rahim
Distance: 3 km, waiting: 10 min
Fare: 30 + 45 + 20 = 95 Tk
```

### Solution
```java
import java.util.Scanner;

public class RickshawReceipt {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String name = in.next();
        int km = in.nextInt();
        int minutes = in.nextInt();

        int start = 30;
        int distanceCharge = 15 * km;
        int waitingCharge = 2 * minutes;
        int total = start + distanceCharge + waitingCharge;

        System.out.println("Passenger: " + name);
        System.out.println("Distance: " + km + " km, waiting: " + minutes + " min");
        System.out.println("Fare: " + start + " + " + distanceCharge + " + "
                + waitingCharge + " = " + total + " Tk");
    }
}
```

### Explanation
The program is a straight sequence: read three values, compute three charges, print.
Each part of the fare gets its own named variable, so the receipt can show the parts
and the reader of the code can see the formula. `in.next()` reads one word and
`in.nextInt()` reads one whole number; the `Scanner` object does the reading for us.
In the last `println`, the `+` signs inside quotes are text, while the `+` between
the quoted pieces and the variables joins (concatenates) them into one string.

### Concepts Practiced
- Reading input with a `Scanner` object
- `int` variables and arithmetic
- String concatenation with `+`

## Problem 2: Orientation Badge and Email
**Level:** Intermediate

### Scenario
During orientation week, the department prints a badge for every new student and
creates a university email address. The office types the student's full name, the
department code and nothing else; the program must produce everything on the badge.

### Problem Statement
Input: the full name on the first line (two or more words separated by single spaces;
the first word is the first name and the last word is the last name), then the
department code on the second line (one word, any letter case).

Output exactly four lines:

```text
FULL NAME: <full name in upper case>
Short name: <first letter of the first name, upper case>. <last name>
Email: <first name in lower case>.<last name in lower case>@<department in lower case>.uni.edu
Letters in name: <number of characters in the full name, not counting spaces>
```

Use `String` methods only: `toUpperCase`, `toLowerCase`, `indexOf`, `lastIndexOf`,
`substring`, `replace` and `length`.

### Sample Input
```text
Nusrat Jahan Mim
CSE
```

### Sample Output
```text
FULL NAME: NUSRAT JAHAN MIM
Short name: N. Mim
Email: nusrat.mim@cse.uni.edu
Letters in name: 14
```

### Solution
```java
import java.util.Scanner;

public class OrientationBadge {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String fullName = in.nextLine();
        String department = in.nextLine();

        String firstName = fullName.substring(0, fullName.indexOf(' '));
        String lastName = fullName.substring(fullName.lastIndexOf(' ') + 1);
        String initial = firstName.substring(0, 1).toUpperCase();
        int letters = fullName.replace(" ", "").length();

        System.out.println("FULL NAME: " + fullName.toUpperCase());
        System.out.println("Short name: " + initial + ". " + lastName);
        System.out.println("Email: " + firstName.toLowerCase() + "." + lastName.toLowerCase()
                + "@" + department.toLowerCase() + ".uni.edu");
        System.out.println("Letters in name: " + letters);
    }
}
```

### Explanation
Every line asks the `String` object to do something for us: `indexOf(' ')` finds the
first space, so the text before it is the first name; `lastIndexOf(' ')` finds the
last space, so the text after it is the last name, however many middle names there
are. `substring(a, b)` returns the characters from index `a` up to, but not including,
`b`, and `substring(a)` returns everything from `a` to the end, so
`substring(0, 1).toUpperCase()` is the first letter in upper case. `replace(" ", "")`
returns a **new** string without spaces; the original `fullName` does not change,
because Java strings are immutable. `charAt(0)` returns the first character as a
`char`, which joins with text like any other value.

### Concepts Practiced
- Calling methods on `String` objects
- `indexOf`, `lastIndexOf`, `substring`
- Strings are immutable: methods return new strings
- Reading whole lines with `nextLine`

## Problem 3: Splitting the Hostel Electricity Bill
**Level:** Intermediate

### Scenario
Four students share a hostel room with its own electricity meter. At the end of every
month they read the meter, calculate the bill and split it equally. Taka coins smaller
than 1 Tk are not used, so whatever cannot be split equally is paid by the room
captain. They want a small program so that nobody argues about the arithmetic.

### Problem Statement
The bill is `units × rate + 50` Tk, where `50` is a fixed service charge and `units` is
the current reading minus the previous reading.

Input: the previous reading, the current reading, the rate per unit (whole Tk) and the
number of roommates, all integers on one line.

Each roommate pays `bill / roommates` (integer division); the room captain also pays
the remainder `bill % roommates`. Output exactly four lines:

```text
Units used: <units>
Bill: <units> x <rate> + 50 = <bill> Tk
Each of <roommates> pays: <share> Tk
Captain also pays: <remainder> Tk
```

### Sample Input
```text
1350 1595 8 4
```

### Sample Output
```text
Units used: 245
Bill: 245 x 8 + 50 = 2010 Tk
Each of 4 pays: 502 Tk
Captain also pays: 2 Tk
```

### Solution
```java
import java.util.Scanner;

public class ElectricitySplit {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int previous = in.nextInt();
        int current = in.nextInt();
        int rate = in.nextInt();
        int roommates = in.nextInt();

        int serviceCharge = 50;
        int units = current - previous;
        int bill = units * rate + serviceCharge;
        int share = bill / roommates;
        int remainder = bill % roommates;

        System.out.println("Units used: " + units);
        System.out.println("Bill: " + units + " x " + rate + " + " + serviceCharge
                + " = " + bill + " Tk");
        System.out.println("Each of " + roommates + " pays: " + share + " Tk");
        System.out.println("Captain also pays: " + remainder + " Tk");
    }
}
```

### Explanation
When both operands are `int`, `/` gives a whole-number result and throws away the
fraction, so `2010 / 4` is `502`, not `502.5`. The `%` operator gives what is left
over after that division: `2010 % 4` is `2`. Together they split an amount into equal
whole parts plus a remainder, and `share × roommates + remainder` always equals the
bill again. Chapter 01 explains integer division and `%` in detail; here they are used
for exactly the job they are good at.

### Concepts Practiced
- Integer division `/` and remainder `%`
- Named variables for each step of a calculation
- Reading several numbers from one line

## Problem 4: Walking Between Campus Buildings
**Level:** Advanced

### Scenario
The campus map uses a grid in metres with the main gate at `(0, 0)`. Walkways run only
east–west and north–south, so a student cannot walk in a straight line between two
buildings. The student welfare team wants to show, for any two buildings, the
straight-line distance, the real walkway distance and the walking time, to argue for a
new diagonal path.

### Problem Statement
Input: four integers `x1 y1 x2 y2` (coordinates of the two buildings in metres) and
the walking speed in metres per minute, all on one line.

Compute:

- the straight-line distance `sqrt((x2−x1)² + (y2−y1)²)`, rounded to one decimal place
  with `Math.round(d * 10) / 10.0`;
- the walkway distance `|x2−x1| + |y2−y1|`;
- the walking time on the walkways in whole minutes, rounded with
  `Math.round(walkway / (double) speed)`;
- the extra distance caused by the grid, `walkway − straight`, rounded to one decimal
  place the same way (use the unrounded straight distance in the subtraction).

Output exactly four lines:

```text
Straight line: <straight> m
Walkways: <walkway> m
Walking time: <minutes> min
Extra because of the grid: <extra> m
```

Use `Math.sqrt`, `Math.abs` and `Math.round`.

### Sample Input
```text
0 0 300 400 80
```

### Sample Output
```text
Straight line: 500.0 m
Walkways: 700 m
Walking time: 9 min
Extra because of the grid: 200.0 m
```

### Solution
```java
import java.util.Scanner;

public class CampusWalk {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int x1 = in.nextInt();
        int y1 = in.nextInt();
        int x2 = in.nextInt();
        int y2 = in.nextInt();
        int speed = in.nextInt();

        int dx = x2 - x1;
        int dy = y2 - y1;
        double straight = Math.sqrt(dx * dx + dy * dy);
        int walkway = Math.abs(dx) + Math.abs(dy);
        long minutes = Math.round(walkway / (double) speed);
        double extra = walkway - straight;

        System.out.println("Straight line: " + Math.round(straight * 10) / 10.0 + " m");
        System.out.println("Walkways: " + walkway + " m");
        System.out.println("Walking time: " + minutes + " min");
        System.out.println("Extra because of the grid: " + Math.round(extra * 10) / 10.0 + " m");
    }
}
```

### Explanation
`Math` is a class that bundles useful mathematical methods; you call them through the
class name, as in `Math.sqrt(...)`. `dx * dx` squares a difference (squaring also makes
negative differences positive), and `Math.abs` gives the distance along one axis
regardless of direction. In `walkway / (double) speed`, converting one operand to
`double` makes Java divide with a fraction, so `700 / 80.0` is `8.75`, which
`Math.round` turns into `9`. Rounding to one decimal place is done by scaling: multiply
by 10, round to a whole number, divide by `10.0`. The extra distance is computed from
the **unrounded** straight distance, so rounding is applied only once, at the end.

### Concepts Practiced
- Calling static methods of the `Math` class
- Converting an `int` to `double` for exact division
- Rounding with `Math.round`
- Planning a calculation as a sequence of named steps
