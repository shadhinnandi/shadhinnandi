# Scenario-Based Problems

These scenarios practise Chapter 01: primitive types, constants, casting, integer
versus floating-point arithmetic, `String` methods, formatted output with `printf`, and
one simple `if`/`else` decision. Most lost marks in this chapter come from integer
division and from formatting, so read every output rule carefully.

Programs read input without prompts and print exactly the sample output. All fees,
rates and rules in these problems are hypothetical and invented for practice.

## Problem 1: Mobile Recharge Bonus
**Level:** Basic

### Scenario
A mobile operator runs a student offer: recharges of 200 Tk or more get a 10% bonus
balance, and every recharge also gives validity days. The campus recharge shop wants a
slip printed for each customer.

### Problem Statement
Input: a phone number (one word) and the recharge amount in whole Tk.

- Bonus: if the amount is at least `200`, the bonus is `amount × 10 / 100` (integer
  arithmetic); otherwise it is `0`.
- Validity: `amount / 10` days (integer division). Amounts are always at least `10` Tk.

Output exactly:

```text
Number: <phone>
Recharge: <amount> Tk
Bonus: <bonus> Tk
Total balance added: <amount + bonus> Tk
Valid for: <days> days
```

Declare `200` and `10` (the bonus percent) as `final` constants.

### Sample Input
```text
01711223344 250
```

### Sample Output
```text
Number: 01711223344
Recharge: 250 Tk
Bonus: 25 Tk
Total balance added: 275 Tk
Valid for: 25 days
```

### Solution
```java
import java.util.Scanner;

public class RechargeSlip {
    public static void main(String[] args) {
        final int BONUS_LIMIT = 200;
        final int BONUS_PERCENT = 10;

        Scanner in = new Scanner(System.in);
        String phone = in.next();
        int amount = in.nextInt();

        int bonus;
        if (amount >= BONUS_LIMIT) {
            bonus = amount * BONUS_PERCENT / 100;
        } else {
            bonus = 0;
        }
        int days = amount / 10;

        System.out.println("Number: " + phone);
        System.out.println("Recharge: " + amount + " Tk");
        System.out.println("Bonus: " + bonus + " Tk");
        System.out.println("Total balance added: " + (amount + bonus) + " Tk");
        System.out.println("Valid for: " + days + " days");
    }
}
```

### Explanation
The phone number is read as a `String`, not an `int`: it starts with `0` and is too
long for an `int`, and we never do arithmetic with it. `final` constants give the
magic numbers names, so the rule can be changed in one place. `amount * 10 / 100` is
evaluated left to right; multiplying first keeps the precision (`250 * 10 / 100` is
`25`, while `250 / 100 * 10` would be `20`). The brackets in `(amount + bonus)` are
needed: without them, `+` would join `amount` to the text first and then append
`bonus` as more text.

### Concepts Practiced
- `final` constants
- A simple `if`/`else`
- Integer arithmetic and evaluation order
- Brackets in string concatenation

## Problem 2: When Does My Exam End?
**Level:** Intermediate

### Scenario
The exam controller's office publishes start times and durations, but students keep
miscalculating end times, especially for long lab exams and evening exams. The office
wants a tool that prints the end time in 24-hour format.

### Problem Statement
Input: the start time as `HH:MM` (24-hour, always two digits each) and the duration in
minutes (1 to 1440, so an exam lasts at most one day).

Compute the end time. If the exam ends on the next day (at or after 24:00), the hour
wraps around and the output says so.

Output exactly:

```text
Start: <HH:MM>
Duration: <h> h <m> min
End: <HH:MM>
```

followed by one more line `Ends on the next day` only if it wraps past midnight. Print
hours and minutes of times with two digits (`%02d`).

### Sample Input
```text
09:45 135
```

### Sample Output
```text
Start: 09:45
Duration: 2 h 15 min
End: 12:00
```

### Solution
```java
import java.util.Scanner;

public class ExamEndTime {
    public static void main(String[] args) {
        final int MINUTES_PER_DAY = 24 * 60;

        Scanner in = new Scanner(System.in);
        String start = in.next();
        int duration = in.nextInt();

        int startHour = Integer.parseInt(start.substring(0, 2));
        int startMinute = Integer.parseInt(start.substring(3, 5));
        int startTotal = startHour * 60 + startMinute;
        int endTotal = startTotal + duration;

        int endHour = (endTotal % MINUTES_PER_DAY) / 60;
        int endMinute = endTotal % 60;

        System.out.printf("Start: %02d:%02d%n", startHour, startMinute);
        System.out.printf("Duration: %d h %d min%n", duration / 60, duration % 60);
        System.out.printf("End: %02d:%02d%n", endHour, endMinute);
        if (endTotal >= MINUTES_PER_DAY) {
            System.out.println("Ends on the next day");
        }
    }
}
```

### Explanation
Times are easiest to work with as "minutes since midnight": `09:45` is
`9 × 60 + 45 = 585`. Adding the duration is then a single `+`, and converting back uses
`/ 60` for hours and `% 60` for minutes. `% MINUTES_PER_DAY` removes whole days, so
`25:10` becomes `01:10`. `substring(0, 2)` and `substring(3, 5)` cut the text around the
colon, and `Integer.parseInt` turns digit text into an `int`. `%02d` prints a number in
at least 2 characters, padding with a zero, which is why `5` prints as `05`.

### Concepts Practiced
- Converting between units with `/` and `%`
- `Integer.parseInt` and `substring`
- `printf` with `%02d` and `%n`
- A constant expression (`24 * 60`)

## Problem 3: Which Pack Is Cheaper?
**Level:** Intermediate

### Scenario
The campus grocery sells the same brand of tea in different pack sizes, and the bigger
pack is not always cheaper per gram. The student cooperative wants shelf labels that
show the price per 100 g and which pack is the better deal.

### Problem Statement
Input: two lines, each `name price grams` (name is one word, price and grams are whole
numbers).

For each pack print `<name>: Tk <price per 100 g> per 100 g`, where the price per 100 g
is `price × 100 / grams` computed in `double` and printed with 2 decimals.

Then print `Better deal: <name>` for the pack with the lower price per 100 g, and
`You save <percent>%` where percent is
`(higher − lower) / higher × 100`, printed with 1 decimal. If both are exactly equal,
print `Both packs cost the same per gram` instead of those two lines.

### Sample Input
```text
Small 95 200
Family 420 1000
```

### Sample Output
```text
Small: Tk 47.50 per 100 g
Family: Tk 42.00 per 100 g
Better deal: Family
You save 11.6%
```

### Solution
```java
import java.util.Scanner;

public class TeaPacks {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String name1 = in.next();
        int price1 = in.nextInt();
        int grams1 = in.nextInt();
        String name2 = in.next();
        int price2 = in.nextInt();
        int grams2 = in.nextInt();

        double per100First = (double) price1 * 100 / grams1;
        double per100Second = (double) price2 * 100 / grams2;

        System.out.printf("%s: Tk %.2f per 100 g%n", name1, per100First);
        System.out.printf("%s: Tk %.2f per 100 g%n", name2, per100Second);

        if (per100First == per100Second) {
            System.out.println("Both packs cost the same per gram");
        } else {
            String better = per100First < per100Second ? name1 : name2;
            double lower = Math.min(per100First, per100Second);
            double higher = Math.max(per100First, per100Second);
            double saving = (higher - lower) / higher * 100;
            System.out.println("Better deal: " + better);
            System.out.printf("You save %.1f%%%n", saving);
        }
    }
}
```

### Explanation
`(double) price1 * 100 / grams1` casts **before** dividing, so the division is done in
floating point: `95 × 100 / 200 = 47.5`. Without the cast, `9500 / 200` in `int`
arithmetic would give `47` and lose the half taka. The ternary operator `? :` picks one
of two values in a single expression. In a `printf` format string `%%` prints a literal
percent sign. Comparing doubles with `==` is usually risky because of rounding, but
here both values come from the same exact formula on whole numbers, so equal inputs
give exactly equal results.

### Concepts Practiced
- Casting to `double` before division
- `printf` with `%.2f`, `%.1f` and `%%`
- The ternary operator
- `Math.min` and `Math.max`

## Problem 4: Laptop Loan Instalments
**Level:** Advanced

### Scenario
The student welfare fund lends money to students to buy laptops. Students repay in
equal monthly instalments (EMI). The fund wants a calculator that shows the instalment,
the total repaid and the total interest, and it also offers interest-free loans, which
the usual formula cannot handle.

### Problem Statement
Input: the principal `P` (whole Tk), the yearly interest rate in percent (may have
decimals) and the number of months `n`.

Let `r` be the monthly rate: `yearly rate / 12 / 100`. The instalment is

```text
EMI = P × r × (1 + r)^n / ((1 + r)^n − 1)
```

computed with `Math.pow`. If the yearly rate is `0`, the EMI is simply `P / n` (in
`double`).

Output exactly:

```text
Loan: Tk <P> for <n> months at <rate>% a year
Monthly instalment: Tk <emi>
Total repaid: Tk <emi × n>
Total interest: Tk <emi × n − P>
Interest share: <interest / total repaid × 100>%
```

The rate is printed with 2 decimals; all money values with 2 decimals; the interest
share with 1 decimal.

### Sample Input
```text
60000 9 12
```

### Sample Output
```text
Loan: Tk 60000 for 12 months at 9.00% a year
Monthly instalment: Tk 5247.09
Total repaid: Tk 62965.06
Total interest: Tk 2965.06
Interest share: 4.7%
```

### Solution
```java
import java.util.Scanner;

public class LaptopLoan {
    public static void main(String[] args) {
        final int MONTHS_PER_YEAR = 12;

        Scanner in = new Scanner(System.in);
        int principal = in.nextInt();
        double yearlyRate = in.nextDouble();
        int months = in.nextInt();

        double emi;
        if (yearlyRate == 0) {
            emi = (double) principal / months;
        } else {
            double r = yearlyRate / MONTHS_PER_YEAR / 100;
            double growth = Math.pow(1 + r, months);
            emi = principal * r * growth / (growth - 1);
        }
        double totalRepaid = emi * months;
        double interest = totalRepaid - principal;
        double share = interest / totalRepaid * 100;

        System.out.printf("Loan: Tk %d for %d months at %.2f%% a year%n",
                principal, months, yearlyRate);
        System.out.printf("Monthly instalment: Tk %.2f%n", emi);
        System.out.printf("Total repaid: Tk %.2f%n", totalRepaid);
        System.out.printf("Total interest: Tk %.2f%n", interest);
        System.out.printf("Interest share: %.1f%%%n", share);
    }
}
```

### Explanation
The formula divides by `(1 + r)^n − 1`, which is `0` when the rate is `0`; in floating
point that would produce `NaN` or infinity instead of an error, so the special case is
handled first with an `if`. `Math.pow(1 + r, months)` is computed once and stored in
`growth` because it is used twice. `yearlyRate / 12 / 100` is all floating point
because `yearlyRate` is a `double`. In the zero-rate branch, `(double) principal /
months` casts before dividing so that, for example, `10000 / 3` keeps its fraction. All
rounding happens only in `printf`, so the stored values keep full precision.

### Concepts Practiced
- `double` arithmetic and `Math.pow`
- Handling a special case with `if`/`else`
- Casting before division
- Formatted output of money and percentages
