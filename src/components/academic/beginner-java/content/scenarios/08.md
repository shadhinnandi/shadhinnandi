# Scenario-Based Problems

These scenarios practise Chapter 08: arrays of primitives, two-dimensional arrays,
arrays and `ArrayList`s of objects, and above all **references**: a variable of a
class type does not hold the object itself, it refers to it, and several references
can refer to the same object. There is no exception handling yet, so programs validate
indexes before using them.

Programs read input without prompts and print exactly the sample output. All fees,
rates and rules in these problems are hypothetical and invented for practice.

## Problem 1: Class Test Statistics
**Level:** Basic

### Scenario
After a class test the course teacher wants quick statistics before uploading the
marks: the average, the highest and lowest marks, how many students scored above the
average, and how the marks are spread across grade bands.

### Problem Statement
Input: `n` (1 to 60), then `n` integer marks (0 to 20).

Store the marks in an `int[]`. Print:

```text
Average: <average with 2 decimals>
Highest: <max> (student <position>)
Lowest: <min> (student <position>)
Above average: <count>
16-20: <stars>
11-15: <stars>
6-10: <stars>
0-5: <stars>
```

Positions count from 1; for ties report the first position. Each band line shows one
`*` per student in that band (an empty band shows nothing after the colon and space).

### Sample Input
```text
8
15 18 9 20 12 4 18 11
```

### Sample Output
```text
Average: 13.38
Highest: 20 (student 4)
Lowest: 4 (student 6)
Above average: 4
16-20: ***
11-15: ***
6-10: *
0-5: *
```

### Solution
```java
import java.util.Scanner;

public class ClassTestStats {
    static String stars(int count) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < count; i++) {
            sb.append('*');
        }
        return sb.toString();
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] marks = new int[n];
        for (int i = 0; i < n; i++) {
            marks[i] = in.nextInt();
        }

        int sum = 0;
        int maxIndex = 0;
        int minIndex = 0;
        for (int i = 0; i < marks.length; i++) {
            sum += marks[i];
            if (marks[i] > marks[maxIndex]) {
                maxIndex = i;
            }
            if (marks[i] < marks[minIndex]) {
                minIndex = i;
            }
        }
        double average = (double) sum / marks.length;

        int above = 0;
        int[] bands = new int[4];
        for (int m : marks) {
            if (m > average) {
                above++;
            }
            if (m >= 16) {
                bands[0]++;
            } else if (m >= 11) {
                bands[1]++;
            } else if (m >= 6) {
                bands[2]++;
            } else {
                bands[3]++;
            }
        }

        System.out.printf("Average: %.2f%n", average);
        System.out.println("Highest: " + marks[maxIndex] + " (student " + (maxIndex + 1) + ")");
        System.out.println("Lowest: " + marks[minIndex] + " (student " + (minIndex + 1) + ")");
        System.out.println("Above average: " + above);
        String[] labels = {"16-20", "11-15", "6-10", "0-5"};
        for (int b = 0; b < bands.length; b++) {
            System.out.println(labels[b] + ": " + stars(bands[b]));
        }
    }
}
```

### Explanation
The marks are needed twice (once for the average, once to compare with it), which is
exactly why they are stored in an array instead of being read and forgotten. Keeping
the **index** of the maximum, not just its value, gives the student's position for
free; `>` (not `>=`) keeps the first position on a tie. A second small array counts the
bands, and a parallel `String[]` holds their labels, so printing is one loop. The
enhanced `for` loop is used when only the values matter, and the indexed loop when the
position matters.

### Concepts Practiced
- Creating and filling an `int[]`
- Tracking the index of a maximum and minimum
- Counting into an array of counters
- Enhanced `for` versus indexed `for`

## Problem 2: Merging Two Section Rosters
**Level:** Intermediate

### Scenario
Two sections of the same course are merged for a make-up class. Some students appear
in both lists (they were moved between sections during the add/drop period). The
coordinator needs one roster, sorted by ID, with each student exactly once.

### Problem Statement
Write a class `Student` (`id`, `name`) with a method `boolean sameIdAs(Student other)`.

Input: `a`, then `a` lines `id name` (section A), then `b`, then `b` lines (section B).
IDs are 9-digit strings.

Build an `ArrayList<Student>` with every student from A, then add each student from B
**only if** no student with the same ID is already in the list (keep the section-A
object). Sort the list by ID with a simple selection sort using `compareTo` on the ID
strings. Print `Merged roster (<k> students):`, the students as `<id> <name>`, and
`Duplicates skipped: <d>` followed by the skipped IDs separated by spaces (or `none`).

### Sample Input
```text
3
011221030 Rahim
011221005 Nusrat
011221017 Imran
3
011221017 Imran
011221002 Ayesha
011221005 Nusrat
```

### Sample Output
```text
Merged roster (4 students):
011221002 Ayesha
011221005 Nusrat
011221017 Imran
011221030 Rahim
Duplicates skipped: 2 011221017 011221005
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Student {
    private final String id;
    private final String name;

    Student(String id, String name) {
        this.id = id;
        this.name = name;
    }

    String getId() {
        return id;
    }

    boolean sameIdAs(Student other) {
        return id.equals(other.id);
    }

    @Override
    public String toString() {
        return id + " " + name;
    }
}

public class MergeRosters {
    static boolean containsId(ArrayList<Student> list, Student s) {
        for (Student existing : list) {
            if (existing.sameIdAs(s)) {
                return true;
            }
        }
        return false;
    }

    static void sortById(ArrayList<Student> list) {
        for (int i = 0; i < list.size() - 1; i++) {
            int smallest = i;
            for (int j = i + 1; j < list.size(); j++) {
                if (list.get(j).getId().compareTo(list.get(smallest).getId()) < 0) {
                    smallest = j;
                }
            }
            Student temp = list.get(i);
            list.set(i, list.get(smallest));
            list.set(smallest, temp);
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        ArrayList<Student> roster = new ArrayList<>();
        int a = in.nextInt();
        for (int i = 0; i < a; i++) {
            roster.add(new Student(in.next(), in.next()));
        }

        int b = in.nextInt();
        StringBuilder skipped = new StringBuilder();
        int duplicates = 0;
        for (int i = 0; i < b; i++) {
            Student s = new Student(in.next(), in.next());
            if (containsId(roster, s)) {
                duplicates++;
                skipped.append(' ').append(s.getId());
            } else {
                roster.add(s);
            }
        }

        sortById(roster);
        System.out.println("Merged roster (" + roster.size() + " students):");
        for (Student s : roster) {
            System.out.println(s);
        }
        System.out.println("Duplicates skipped: " + duplicates
                + (duplicates == 0 ? " none" : skipped.toString()));
    }
}
```

### Explanation
Two different `Student` objects with the same ID are **not** the same object, so
`==` would never find a duplicate; the program compares IDs with `equals` inside
`sameIdAs`. Selection sort swaps **references** inside the list with `get` and `set`;
no student object is copied or changed. `compareTo` on strings compares them
character by character, which sorts fixed-length digit IDs in numeric order. A
`StringBuilder` collects the skipped IDs so they can be printed on one line at the end.

### Concepts Practiced
- `ArrayList` of objects (`add`, `get`, `set`, `size`)
- Identity (`==`) versus equality (`equals`)
- Selection sort on references
- Searching a list of objects

## Problem 3: Seminar Hall Seat Map
**Level:** Intermediate

### Scenario
The seminar hall has 5 rows (`A` to `E`) of 8 seats. Club organisers book seats for
guests, and groups of friends want to sit together. The booking desk needs a seat map
and a way to find the first block of free seats next to each other.

### Problem Statement
Use a `boolean[5][8]` (true means booked). Commands:

- `BOOK <row><seat>` (e.g. `B3`): `Booked B3`, `B3 is already booked`, or
  `No seat B9` for an invalid seat;
- `CANCEL <row><seat>`: `Cancelled B3`, `B3 was not booked`, or `No seat ...`;
- `GROUP k`: find the first row (A to E) and the leftmost position with `k` free seats
  next to each other, book them and print `Group of <k>: <row><from>-<row><to>`, or
  `No block of <k> seats` (also for `k` outside 1 to 8);
- `MAP`: print the header `  12345678` and each row as `<row> ` followed by `X`
  (booked) or `.` (free) for each seat.

At the end print `Free seats: <f>`.

### Sample Input
```text
7
BOOK A1
BOOK A1
BOOK C9
GROUP 7
GROUP 8
CANCEL A1
MAP
```

### Sample Output
```text
Booked A1
A1 is already booked
No seat C9
Group of 7: A2-A8
Group of 8: B1-B8
Cancelled A1
  12345678
A .XXXXXXX
B XXXXXXXX
C ........
D ........
E ........
Free seats: 25
```

### Solution
```java
import java.util.Scanner;

public class SeatMap {
    static final int ROWS = 5;
    static final int SEATS = 8;
    static boolean[][] booked = new boolean[ROWS][SEATS];

    /** Returns {row, seat} (0-based) or null if the code is not a seat. */
    static int[] parse(String code) {
        if (code.length() < 2) {
            return null;
        }
        int row = code.charAt(0) - 'A';
        int seat = Integer.parseInt(code.substring(1)) - 1;
        if (row < 0 || row >= ROWS || seat < 0 || seat >= SEATS) {
            return null;
        }
        return new int[] {row, seat};
    }

    static String book(String code) {
        int[] pos = parse(code);
        if (pos == null) {
            return "No seat " + code;
        }
        if (booked[pos[0]][pos[1]]) {
            return code + " is already booked";
        }
        booked[pos[0]][pos[1]] = true;
        return "Booked " + code;
    }

    static String cancel(String code) {
        int[] pos = parse(code);
        if (pos == null) {
            return "No seat " + code;
        }
        if (!booked[pos[0]][pos[1]]) {
            return code + " was not booked";
        }
        booked[pos[0]][pos[1]] = false;
        return "Cancelled " + code;
    }

    static String group(int k) {
        if (k < 1 || k > SEATS) {
            return "No block of " + k + " seats";
        }
        for (int r = 0; r < ROWS; r++) {
            int run = 0;
            for (int s = 0; s < SEATS; s++) {
                run = booked[r][s] ? 0 : run + 1;
                if (run == k) {
                    int from = s - k + 1;
                    for (int x = from; x <= s; x++) {
                        booked[r][x] = true;
                    }
                    char row = (char) ('A' + r);
                    return "Group of " + k + ": " + row + (from + 1) + "-" + row + (s + 1);
                }
            }
        }
        return "No block of " + k + " seats";
    }

    static void printMap() {
        System.out.println("  12345678");
        for (int r = 0; r < ROWS; r++) {
            StringBuilder line = new StringBuilder();
            line.append((char) ('A' + r)).append(' ');
            for (int s = 0; s < SEATS; s++) {
                line.append(booked[r][s] ? 'X' : '.');
            }
            System.out.println(line);
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("BOOK")) {
                System.out.println(book(in.next()));
            } else if (command.equals("CANCEL")) {
                System.out.println(cancel(in.next()));
            } else if (command.equals("GROUP")) {
                System.out.println(group(in.nextInt()));
            } else {
                printMap();
            }
        }
        int free = 0;
        for (boolean[] row : booked) {
            for (boolean seat : row) {
                if (!seat) {
                    free++;
                }
            }
        }
        System.out.println("Free seats: " + free);
    }
}
```

### Explanation
A two-dimensional array is an array of arrays: `booked[r]` is one row (a `boolean[]`)
and `booked[r][s]` is one seat. New `boolean` arrays start filled with `false`, so every
seat begins free. `parse` turns a code like `B3` into two zero-based indexes and
returns `null` for anything outside the hall, so no array access can go out of bounds.
`GROUP` scans each row counting the current run of free seats; a booked seat resets
the run to 0, and when the run reaches `k` the block ends at the current seat. In the
sample, the group of 7 fits in row A (seats 2 to 8), and the group of 8 lands in row
B because row A no longer has 8 free seats next to each other.

### Concepts Practiced
- Two-dimensional arrays
- Converting codes to indexes safely
- Scanning for a run of consecutive values
- Returning a small array (or `null`) from a method

## Problem 4: Library Waitlists and Shared References
**Level:** Advanced

### Scenario
The library keeps a waitlist for each popular book. The same member can wait for
several books. When a member updates their phone number at the desk, every waitlist
must show the new number, and when a member leaves the university they must disappear
from every waitlist. The developer realises that storing **references** to one
`Member` object, instead of copies of the member's data, makes both easy.

### Problem Statement
Write:

- `Member` (`id`, `phone` with a setter);
- `Book` (`code`, `holder` — a `Member` reference or `null` — and an
  `ArrayList<Member> waitlist`);
- `Library` with `ArrayList<Member>` and `ArrayList<Book>`.

Commands (`n`, then `n` lines):

| Command | Effect and output |
|---|---|
| `JOIN id phone` | new member: `Member <id> joined` (or `<id> already exists`) |
| `ADDBOOK code` | `Book <code> added` |
| `BORROW id code` | if the book is free: `<id> borrowed <code>`; if it is held by someone else: the member joins the waitlist: `<id> waiting for <code> (position <p>)`; if the member already holds it or already waits: `<id> already in line for <code>` |
| `RETURN code` | the holder returns it; the first waiting member (if any) becomes the holder: `<code> returned, now with <id>` or `<code> returned, now free` |
| `PHONE id number` | `Phone of <id> updated` |
| `LEAVE id` | removes the member from every waitlist; a book they hold becomes free (or goes to the next waiting member); prints `<id> left` |
| `STATUS` | for every book: `<code>: holder <id> (<phone>) | waiting: <id1> (<phone1>), ...` with `holder none` and `waiting: none` when empty |

Unknown member IDs or book codes print `Unknown <id or code>`.

### Sample Input
```text
11
JOIN 101 01711000001
JOIN 102 01811000002
ADDBOOK J1
ADDBOOK P1
BORROW 101 J1
BORROW 102 J1
BORROW 102 P1
PHONE 102 01999999999
STATUS
LEAVE 101
STATUS
```

### Sample Output
```text
Member 101 joined
Member 102 joined
Book J1 added
Book P1 added
101 borrowed J1
102 waiting for J1 (position 1)
102 borrowed P1
Phone of 102 updated
J1: holder 101 (01711000001) | waiting: 102 (01999999999)
P1: holder 102 (01999999999) | waiting: none
101 left
J1: holder 102 (01999999999) | waiting: none
P1: holder 102 (01999999999) | waiting: none
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Member {
    private final String id;
    private String phone;

    Member(String id, String phone) {
        this.id = id;
        this.phone = phone;
    }

    String getId() {
        return id;
    }

    void setPhone(String phone) {
        this.phone = phone;
    }

    @Override
    public String toString() {
        return id + " (" + phone + ")";
    }
}

class Book {
    private final String code;
    private Member holder;
    private final ArrayList<Member> waitlist = new ArrayList<>();

    Book(String code) {
        this.code = code;
    }

    String getCode() {
        return code;
    }

    String borrow(Member m) {
        if (holder == m || waitlist.contains(m)) {
            return m.getId() + " already in line for " + code;
        }
        if (holder == null) {
            holder = m;
            return m.getId() + " borrowed " + code;
        }
        waitlist.add(m);
        return m.getId() + " waiting for " + code + " (position " + waitlist.size() + ")";
    }

    String giveBack() {
        holder = waitlist.isEmpty() ? null : waitlist.remove(0);
        return code + " returned, now " + (holder == null ? "free" : "with " + holder.getId());
    }

    void forget(Member m) {
        waitlist.remove(m);
        if (holder == m) {
            holder = waitlist.isEmpty() ? null : waitlist.remove(0);
        }
    }

    String status() {
        StringBuilder sb = new StringBuilder(code + ": holder ");
        sb.append(holder == null ? "none" : holder.toString());
        sb.append(" | waiting: ");
        if (waitlist.isEmpty()) {
            sb.append("none");
        }
        for (int i = 0; i < waitlist.size(); i++) {
            if (i > 0) {
                sb.append(", ");
            }
            sb.append(waitlist.get(i));
        }
        return sb.toString();
    }
}

class Library {
    private final ArrayList<Member> members = new ArrayList<>();
    private final ArrayList<Book> books = new ArrayList<>();

    Member findMember(String id) {
        for (Member m : members) {
            if (m.getId().equals(id)) {
                return m;
            }
        }
        return null;
    }

    Book findBook(String code) {
        for (Book b : books) {
            if (b.getCode().equals(code)) {
                return b;
            }
        }
        return null;
    }

    String join(String id, String phone) {
        if (findMember(id) != null) {
            return id + " already exists";
        }
        members.add(new Member(id, phone));
        return "Member " + id + " joined";
    }

    String addBook(String code) {
        books.add(new Book(code));
        return "Book " + code + " added";
    }

    String leave(Member m) {
        for (Book b : books) {
            b.forget(m);
        }
        members.remove(m);
        return m.getId() + " left";
    }

    void printStatus() {
        for (Book b : books) {
            System.out.println(b.status());
        }
    }
}

public class LibraryWaitlists {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Library lib = new Library();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("JOIN")) {
                String id = in.next();
                System.out.println(lib.join(id, in.next()));
            } else if (command.equals("ADDBOOK")) {
                System.out.println(lib.addBook(in.next()));
            } else if (command.equals("STATUS")) {
                lib.printStatus();
            } else if (command.equals("RETURN")) {
                String code = in.next();
                Book b = lib.findBook(code);
                System.out.println(b == null ? "Unknown " + code : b.giveBack());
            } else {
                String id = in.next();
                Member m = lib.findMember(id);
                String extra = command.equals("LEAVE") ? null : in.next();
                if (m == null) {
                    System.out.println("Unknown " + id);
                } else if (command.equals("LEAVE")) {
                    System.out.println(lib.leave(m));
                } else if (command.equals("PHONE")) {
                    m.setPhone(extra);
                    System.out.println("Phone of " + id + " updated");
                } else {
                    Book b = lib.findBook(extra);
                    System.out.println(b == null ? "Unknown " + extra : b.borrow(m));
                }
            }
        }
    }
}
```

### Explanation
There is exactly **one** `Member` object per person. The library's member list, every
book's `holder` field and every waitlist store references to that same object. So
`PHONE` changes one object, and every `STATUS` line that mentions the member shows the
new number, without updating any list. `waitlist.contains(m)` and
`waitlist.remove(m)` look for that object (for a class without its own `equals`, they
compare references), and `holder == m` asks "is the holder this very member?". When a
member leaves, each book removes its references to them; once no references remain,
the object is unreachable and the garbage collector can reclaim it. `remove(0)` takes
the first waiting member, which makes the `ArrayList` behave as a simple queue.

### Concepts Practiced
- Many references to one object
- `ArrayList` as a waitlist (queue)
- `null` as "no object"
- `contains` and `remove` with object references
