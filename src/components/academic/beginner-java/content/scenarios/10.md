# Scenario-Based Problems

These scenarios practise Chapter 10: code written against a superclass or an interface
that works for every subclass, abstract classes, interfaces with `default` methods, and
replacing `if`/`else` chains about types with overridden methods. In each solution,
look for the place where a new type could be added **without changing** the code that
uses the objects.

Programs read input without prompts and print exactly the sample output. All fees,
rates and rules in these problems are hypothetical and invented for practice.

## Problem 1: Tech Fest Tickets
**Level:** Basic

### Scenario
The CSE club sells tickets for its tech fest. The base price is the same for everyone,
but students pay half, alumni get 100 Tk off, and guests pay a 50 Tk service charge.
The ticket desk prints one line per ticket and the day's income.

### Problem Statement
Write an abstract class `Ticket` with the holder's name, a `static final int BASE = 400`,
an abstract `int price()` and an abstract `String category()`, plus a concrete
`String line()` returning `<name> (<category>): <price> Tk`. Subclasses:
`StudentTicket` (half price), `AlumniTicket` (base − 100) and `GuestTicket`
(base + 50).

Input: `n`, then `n` lines `S|A|G name`. Store all tickets in an
`ArrayList<Ticket>`, then print each `line()` and `Income: <total> Tk`.

### Sample Input
```text
4
S Tanvir
G Mr.Haque
A Farhana
S Mitu
```

### Sample Output
```text
Tanvir (Student): 200 Tk
Mr.Haque (Guest): 450 Tk
Farhana (Alumni): 300 Tk
Mitu (Student): 200 Tk
Income: 1150 Tk
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

abstract class Ticket {
    static final int BASE = 400;
    private final String name;

    Ticket(String name) {
        this.name = name;
    }

    abstract int price();

    abstract String category();

    String line() {
        return name + " (" + category() + "): " + price() + " Tk";
    }
}

class StudentTicket extends Ticket {
    StudentTicket(String name) {
        super(name);
    }

    @Override
    int price() {
        return BASE / 2;
    }

    @Override
    String category() {
        return "Student";
    }
}

class AlumniTicket extends Ticket {
    AlumniTicket(String name) {
        super(name);
    }

    @Override
    int price() {
        return BASE - 100;
    }

    @Override
    String category() {
        return "Alumni";
    }
}

class GuestTicket extends Ticket {
    GuestTicket(String name) {
        super(name);
    }

    @Override
    int price() {
        return BASE + 50;
    }

    @Override
    String category() {
        return "Guest";
    }
}

public class TechFestTickets {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        ArrayList<Ticket> tickets = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            String type = in.next();
            String name = in.next();
            if (type.equals("S")) {
                tickets.add(new StudentTicket(name));
            } else if (type.equals("A")) {
                tickets.add(new AlumniTicket(name));
            } else {
                tickets.add(new GuestTicket(name));
            }
        }
        int income = 0;
        for (Ticket t : tickets) {
            System.out.println(t.line());
            income += t.price();
        }
        System.out.println("Income: " + income + " Tk");
    }
}
```

### Explanation
`line()` is written once, in the abstract class, and calls the two abstract methods.
When it runs on a `StudentTicket`, `price()` and `category()` dispatch to the student
versions; on a `GuestTicket`, to the guest versions. The income loop is the same for
all tickets: it only knows the type `Ticket`. Only the input-reading code needs to know
the concrete classes, because something has to decide which object to create.

### Concepts Practiced
- Abstract classes and abstract methods
- A concrete method calling abstract methods
- A list of superclass references

## Problem 2: Best Discount at Checkout
**Level:** Intermediate

### Scenario
The campus bookshop runs several offers at the same time. The rule is simple: a
customer gets the **one** offer that saves them the most. New offers appear every
month, so the checkout code must not change when an offer is added.

### Problem Statement
Write an interface `Offer` with `long discountOn(long total)` and `String name()`, and
three classes:

- `PercentOff(percent)`: `total × percent / 100`; name `<percent>% off`;
- `FlatOff(amount, minimumSpend)`: `amount` if `total >= minimumSpend`, otherwise 0;
  name `Tk <amount> off over <minimumSpend>`;
- `CappedPercent(percent, cap)`: like `PercentOff` but never more than `cap`;
  name `<percent>% off up to Tk <cap>`.

Input: `k` offers (`PERCENT p`, `FLAT a m` or `CAPPED p c`), then `q` cart totals.
For each total print the best offer as
`Total <t>: <name> saves <d>, pay <t − d>`, or `Total <t>: no offer applies` if every
discount is 0. On a tie, the offer listed first wins.

### Sample Input
```text
3
PERCENT 8
FLAT 300 2500
CAPPED 15 200
5
800
2000
3000
6000
100
```

### Sample Output
```text
Total 800: 15% off up to Tk 200 saves 120, pay 680
Total 2000: 15% off up to Tk 200 saves 200, pay 1800
Total 3000: Tk 300 off over 2500 saves 300, pay 2700
Total 6000: 8% off saves 480, pay 5520
Total 100: 15% off up to Tk 200 saves 15, pay 85
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

interface Offer {
    long discountOn(long total);

    String name();
}

class PercentOff implements Offer {
    private final int percent;

    PercentOff(int percent) {
        this.percent = percent;
    }

    @Override
    public long discountOn(long total) {
        return total * percent / 100;
    }

    @Override
    public String name() {
        return percent + "% off";
    }
}

class FlatOff implements Offer {
    private final long amount;
    private final long minimumSpend;

    FlatOff(long amount, long minimumSpend) {
        this.amount = amount;
        this.minimumSpend = minimumSpend;
    }

    @Override
    public long discountOn(long total) {
        return total >= minimumSpend ? amount : 0;
    }

    @Override
    public String name() {
        return "Tk " + amount + " off over " + minimumSpend;
    }
}

class CappedPercent extends PercentOff {
    private final long cap;
    private final int percent;

    CappedPercent(int percent, long cap) {
        super(percent);
        this.percent = percent;
        this.cap = cap;
    }

    @Override
    public long discountOn(long total) {
        return Math.min(cap, super.discountOn(total));
    }

    @Override
    public String name() {
        return percent + "% off up to Tk " + cap;
    }
}

public class BestOffer {
    static Offer best(ArrayList<Offer> offers, long total) {
        Offer best = null;
        long bestDiscount = 0;
        for (Offer o : offers) {
            long d = o.discountOn(total);
            if (d > bestDiscount) {
                best = o;
                bestDiscount = d;
            }
        }
        return best;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int k = in.nextInt();
        ArrayList<Offer> offers = new ArrayList<>();
        for (int i = 0; i < k; i++) {
            String type = in.next();
            if (type.equals("PERCENT")) {
                offers.add(new PercentOff(in.nextInt()));
            } else if (type.equals("FLAT")) {
                long amount = in.nextLong();
                offers.add(new FlatOff(amount, in.nextLong()));
            } else {
                int percent = in.nextInt();
                offers.add(new CappedPercent(percent, in.nextLong()));
            }
        }
        int q = in.nextInt();
        for (int i = 0; i < q; i++) {
            long total = in.nextLong();
            Offer o = best(offers, total);
            if (o == null) {
                System.out.println("Total " + total + ": no offer applies");
            } else {
                long d = o.discountOn(total);
                System.out.println("Total " + total + ": " + o.name() + " saves " + d
                        + ", pay " + (total - d));
            }
        }
    }
}
```

### Explanation
`best` loops over `Offer` references and asks each one for its discount; it never
asks which kind of offer it is. Adding a "buy over 5000, get 10%" offer next month
means writing one new class; `best` and `main`'s query loop stay untouched. That is
the practical value of programming to an interface. `CappedPercent` reuses
`PercentOff` through inheritance and overrides `discountOn` with `super.discountOn` plus
a cap, so a class can both extend a class and (through it) implement an interface.
Starting `bestDiscount` at 0 and using `>` means an offer must save something to win,
and the first offer wins a tie.

### Concepts Practiced
- Programming to an interface
- Choosing the best object by asking each one
- Overriding and calling `super` in an interface implementation
- Open for extension, closed for modification

## Problem 3: Transit Passes
**Level:** Intermediate

### Scenario
The city bus company sells several kinds of passes. Each pass has its own rule for
which rides it covers and what a covered ride costs. The ticket checker on the bus
needs one routine that works for every pass.

### Problem Statement
Write an interface `Pass` with:

- `String holder()`;
- `boolean covers(int route, int hour)`;
- `int fare(int route)`: the amount charged for a covered ride;
- a `default` method `String check(int route, int hour)` returning
  `<holder>: route <r> at <h>:00 -> ` followed by `OK, pay <fare> Tk` or
  `NOT COVERED, pay 40 Tk` (the normal fare).

Classes:

- `MonthlyPass(holder)`: covers every route from 6 to 22 (inclusive); fare 0;
- `StudentPass(holder, route)`: covers only its own route, any hour; fare 10;
- `NightPass(holder)`: covers every route from 22 to 23 and from 0 to 5 (inclusive);
  fare 0; overrides `check` to add ` (night)` at the end of the line.

Input: `p` passes (`MONTHLY name`, `STUDENT name route`, `NIGHT name`), then `r` ride
lines `passIndex route hour` (pass index from 1). Print `check` for each ride, then
`Collected: <total> Tk`.

### Sample Input
```text
3
MONTHLY Rahim
STUDENT Nusrat 22
NIGHT Karim
5
1 7 8
1 7 23
2 22 23
2 16 9
3 3 1
```

### Sample Output
```text
Rahim: route 7 at 8:00 -> OK, pay 0 Tk
Rahim: route 7 at 23:00 -> NOT COVERED, pay 40 Tk
Nusrat: route 22 at 23:00 -> OK, pay 10 Tk
Nusrat: route 16 at 9:00 -> NOT COVERED, pay 40 Tk
Karim: route 3 at 1:00 -> OK, pay 0 Tk (night)
Collected: 90 Tk
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

interface Pass {
    int NORMAL_FARE = 40;

    String holder();

    boolean covers(int route, int hour);

    int fare(int route);

    default String check(int route, int hour) {
        String start = holder() + ": route " + route + " at " + hour + ":00 -> ";
        if (covers(route, hour)) {
            return start + "OK, pay " + fare(route) + " Tk";
        }
        return start + "NOT COVERED, pay " + NORMAL_FARE + " Tk";
    }

    default int charge(int route, int hour) {
        return covers(route, hour) ? fare(route) : NORMAL_FARE;
    }
}

class MonthlyPass implements Pass {
    private final String holder;

    MonthlyPass(String holder) {
        this.holder = holder;
    }

    @Override
    public String holder() {
        return holder;
    }

    @Override
    public boolean covers(int route, int hour) {
        return hour >= 6 && hour <= 22;
    }

    @Override
    public int fare(int route) {
        return 0;
    }
}

class StudentPass implements Pass {
    private final String holder;
    private final int route;

    StudentPass(String holder, int route) {
        this.holder = holder;
        this.route = route;
    }

    @Override
    public String holder() {
        return holder;
    }

    @Override
    public boolean covers(int r, int hour) {
        return r == route;
    }

    @Override
    public int fare(int r) {
        return 10;
    }
}

class NightPass implements Pass {
    private final String holder;

    NightPass(String holder) {
        this.holder = holder;
    }

    @Override
    public String holder() {
        return holder;
    }

    @Override
    public boolean covers(int route, int hour) {
        return hour >= 22 || hour <= 5;
    }

    @Override
    public int fare(int route) {
        return 0;
    }

    @Override
    public String check(int route, int hour) {
        return Pass.super.check(route, hour) + " (night)";
    }
}

public class TransitPasses {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int p = in.nextInt();
        ArrayList<Pass> passes = new ArrayList<>();
        for (int i = 0; i < p; i++) {
            String type = in.next();
            String name = in.next();
            if (type.equals("MONTHLY")) {
                passes.add(new MonthlyPass(name));
            } else if (type.equals("STUDENT")) {
                passes.add(new StudentPass(name, in.nextInt()));
            } else {
                passes.add(new NightPass(name));
            }
        }
        int r = in.nextInt();
        int collected = 0;
        for (int i = 0; i < r; i++) {
            Pass pass = passes.get(in.nextInt() - 1);
            int route = in.nextInt();
            int hour = in.nextInt();
            System.out.println(pass.check(route, hour));
            collected += pass.charge(route, hour);
        }
        System.out.println("Collected: " + collected + " Tk");
    }
}
```

### Explanation
`check` is a `default` method: it is written once in the interface and every class
gets it, yet inside it the calls to `holder()`, `covers()` and `fare()` dispatch to the
real class of the object. `NightPass` overrides the default and still reuses it with
`Pass.super.check(...)`, the syntax for calling an interface's default method. The
field `NORMAL_FARE` in the interface is automatically `public static final`, a
constant shared by all passes. The checker's loop holds a `Pass` reference and never
asks which class it is.

### Concepts Practiced
- Interfaces with `default` methods
- Overriding a default method and calling `Interface.super.method()`
- Constants in interfaces
- One routine working for every implementation

## Problem 4: Course Assessment Engine
**Level:** Advanced

### Scenario
A course combines very different assessments: quizzes where only the best attempts
count, assignments that lose marks for late submission, a final exam that must be
passed on its own, and a project. The department wants one engine that computes the
final mark and grade from any mix of assessments, without `instanceof` checks.

### Problem Statement
Write an abstract class `Assessment` with a `name`, a `weight` (percent of the final
mark), an abstract `double percent()` (0–100 achieved), a concrete
`double contribution()` = `percent() × weight / 100`, and an overridable
`boolean mustPass()` returning `false`. Subclasses:

- `QuizSet(weight, best, scores...)`: quizzes out of 10; the average of the `best`
  highest scores, as a percent;
- `Assignment(weight, marks, outOf, daysLate)`: `marks / outOf × 100`, minus 10
  percentage points per day late, at most 50 points, never below 0;
- `FinalExam(weight, marks)`: marks out of 100; `mustPass()` returns `true`;
- `Project(weight, design, code, report)`: each part out of 10, weighted 30/50/20.

Input: `k` assessments, each on one line:
`QUIZ w best n s1 ... sn`, `ASSIGN w marks outOf daysLate`, `EXAM w marks`,
`PROJECT w design code report`. The weights add up to 100.

For each assessment print `<name>: <percent>% x <weight>% = <contribution>` with
percent and contribution printed with 2 decimals (names: `Quiz`, `Assignment`, `Exam`,
`Project`). Then print `Final: <total with 2 decimals>` and `Grade: <g>` where the grade
is `A` (≥ 80), `B` (≥ 65), `C` (≥ 50), `D` (≥ 40) or `F`; but if any assessment with
`mustPass()` has a percent below 40, the grade is `F (failed <name>)`.

### Sample Input
```text
4
QUIZ 15 3 4 7 9 5 8
ASSIGN 20 34 40 2
EXAM 45 58
PROJECT 20 8 9 7
```

### Sample Output
```text
Quiz: 80.00% x 15% = 12.00
Assignment: 65.00% x 20% = 13.00
Exam: 58.00% x 45% = 26.10
Project: 83.00% x 20% = 16.60
Final: 67.70
Grade: B
```

### Solution
```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Scanner;

abstract class Assessment {
    private final String name;
    private final int weight;

    Assessment(String name, int weight) {
        this.name = name;
        this.weight = weight;
    }

    String getName() {
        return name;
    }

    abstract double percent();

    double contribution() {
        return percent() * weight / 100;
    }

    boolean mustPass() {
        return false;
    }

    String line() {
        return String.format("%s: %.2f%% x %d%% = %.2f", name, percent(), weight, contribution());
    }
}

class QuizSet extends Assessment {
    private final int[] scores;
    private final int best;

    QuizSet(int weight, int best, int[] scores) {
        super("Quiz", weight);
        this.best = best;
        this.scores = scores.clone();
    }

    @Override
    double percent() {
        int[] sorted = scores.clone();
        Arrays.sort(sorted);
        int sum = 0;
        for (int i = sorted.length - 1; i >= sorted.length - best; i--) {
            sum += sorted[i];
        }
        return sum * 10.0 / best;
    }
}

class Assignment extends Assessment {
    private final int marks;
    private final int outOf;
    private final int daysLate;

    Assignment(int weight, int marks, int outOf, int daysLate) {
        super("Assignment", weight);
        this.marks = marks;
        this.outOf = outOf;
        this.daysLate = daysLate;
    }

    @Override
    double percent() {
        double raw = marks * 100.0 / outOf;
        int penalty = Math.min(50, 10 * daysLate);
        return Math.max(0, raw - penalty);
    }
}

class FinalExam extends Assessment {
    private final int marks;

    FinalExam(int weight, int marks) {
        super("Exam", weight);
        this.marks = marks;
    }

    @Override
    double percent() {
        return marks;
    }

    @Override
    boolean mustPass() {
        return true;
    }
}

class Project extends Assessment {
    private final int design;
    private final int code;
    private final int report;

    Project(int weight, int design, int code, int report) {
        super("Project", weight);
        this.design = design;
        this.code = code;
        this.report = report;
    }

    @Override
    double percent() {
        return design * 3 + code * 5 + report * 2;
    }
}

public class AssessmentEngine {
    static String grade(double total) {
        if (total >= 80) {
            return "A";
        } else if (total >= 65) {
            return "B";
        } else if (total >= 50) {
            return "C";
        } else if (total >= 40) {
            return "D";
        }
        return "F";
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int k = in.nextInt();
        ArrayList<Assessment> parts = new ArrayList<>();
        for (int i = 0; i < k; i++) {
            String type = in.next();
            int weight = in.nextInt();
            if (type.equals("QUIZ")) {
                int best = in.nextInt();
                int[] scores = new int[in.nextInt()];
                for (int j = 0; j < scores.length; j++) {
                    scores[j] = in.nextInt();
                }
                parts.add(new QuizSet(weight, best, scores));
            } else if (type.equals("ASSIGN")) {
                int marks = in.nextInt();
                int outOf = in.nextInt();
                parts.add(new Assignment(weight, marks, outOf, in.nextInt()));
            } else if (type.equals("EXAM")) {
                parts.add(new FinalExam(weight, in.nextInt()));
            } else {
                int design = in.nextInt();
                int code = in.nextInt();
                parts.add(new Project(weight, design, code, in.nextInt()));
            }
        }

        double total = 0;
        String failed = null;
        for (Assessment a : parts) {
            System.out.println(a.line());
            total += a.contribution();
            if (a.mustPass() && a.percent() < 40 && failed == null) {
                failed = a.getName();
            }
        }
        System.out.printf("Final: %.2f%n", total);
        System.out.println("Grade: " + (failed == null ? grade(total) : "F (failed " + failed + ")"));
    }
}
```

### Explanation
Every assessment answers the same two questions, "what percent did the student
achieve?" and "must this be passed on its own?", in its own way. The engine only uses
those answers, so there is no `if (a instanceof FinalExam)` anywhere: the exam's
special rule is expressed by overriding `mustPass()`. `contribution()` and `line()` are
written once in the abstract class and rely on the overridden `percent()`. `QuizSet`
copies the scores array with `clone()` so that later changes to the caller's array
cannot change the quiz, and sorts a second copy so the original order is kept. Adding a
"lab viva" next trimester means one new subclass.

### Concepts Practiced
- Abstract classes with abstract and overridable methods
- Replacing type checks with overriding (`mustPass`)
- Template-style methods in the superclass (`line`, `contribution`)
- Defensive copying of arrays
