# Scenario-Based Problems

These scenarios practise Chapter 06: overloaded constructors chained with `this(...)`,
validation while an object is being built, the order in which fields and initializer
blocks run, copy constructors written by hand (and the difference between shallow and
deep copies), and cleaning up resources with `AutoCloseable` and try-with-resources.
Remember that Java has no destructors: `close()` is called by try-with-resources, not
by the garbage collector.

Programs read input without prompts and print exactly the sample output. All fees,
rates and rules in these problems are hypothetical and invented for practice.

## Problem 1: Student Profiles from Partial Data
**Level:** Basic

### Scenario
The admission office imports student records from three sources. Some give only the
ID and name, some add the department, and some add the CGPA as well. Every record must
become a complete `Student` object with sensible defaults.

### Problem Statement
Write a class `Student` with `private final` fields `id`, `name`, `department` and
`cgpa`, and three constructors:

- `Student(String id, String name)`: department `Undeclared`, CGPA `0.0`;
- `Student(String id, String name, String department)`: CGPA `0.0`;
- `Student(String id, String name, String department, double cgpa)`: the only
  constructor that assigns the fields. A CGPA outside 0.0–4.0 is stored as `0.0` and
  the object remembers that it was corrected.

The first two constructors must call the next one with `this(...)`. Add
`String describe()` returning `<id> <name>, <department>, CGPA <x.xx>` followed by
` (CGPA corrected)` if it was corrected.

Input: `n`, then `n` lines with 2, 3 or 4 fields separated by spaces (names are one
word). Print `describe()` for each.

### Sample Input
```text
4
011221001 Nusrat
011221002 Tanvir CSE
011221003 Ayesha EEE 3.85
011221004 Imran BBA 4.20
```

### Sample Output
```text
011221001 Nusrat, Undeclared, CGPA 0.00
011221002 Tanvir, CSE, CGPA 0.00
011221003 Ayesha, EEE, CGPA 3.85
011221004 Imran, BBA, CGPA 0.00 (CGPA corrected)
```

### Solution
```java
import java.util.Scanner;

class Student {
    private final String id;
    private final String name;
    private final String department;
    private final double cgpa;
    private final boolean corrected;

    Student(String id, String name) {
        this(id, name, "Undeclared");
    }

    Student(String id, String name, String department) {
        this(id, name, department, 0.0);
    }

    Student(String id, String name, String department, double cgpa) {
        this.id = id;
        this.name = name;
        this.department = department;
        if (cgpa < 0.0 || cgpa > 4.0) {
            this.cgpa = 0.0;
            this.corrected = true;
        } else {
            this.cgpa = cgpa;
            this.corrected = false;
        }
    }

    String describe() {
        String text = String.format("%s %s, %s, CGPA %.2f", id, name, department, cgpa);
        return corrected ? text + " (CGPA corrected)" : text;
    }
}

public class StudentImport {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = Integer.parseInt(in.nextLine().trim());
        for (int i = 0; i < n; i++) {
            String[] parts = in.nextLine().trim().split("\\s+");
            Student s;
            if (parts.length == 2) {
                s = new Student(parts[0], parts[1]);
            } else if (parts.length == 3) {
                s = new Student(parts[0], parts[1], parts[2]);
            } else {
                s = new Student(parts[0], parts[1], parts[2], Double.parseDouble(parts[3]));
            }
            System.out.println(s.describe());
        }
    }
}
```

### Explanation
Constructor chaining puts all the field assignments and the validation in one
constructor. The shorter constructors only supply defaults and pass everything on with
`this(...)`, which must be the first statement. Because the fields are `final`, the
compiler checks that every path through the main constructor assigns each of them
exactly once; that is why both branches of the `if` set `cgpa` and `corrected`.
`split("\\s+")` returns the words of a line (arrays are covered in Chapter 08; here it
is only used to count and pick the fields).

### Concepts Practiced
- Constructor overloading
- Chaining constructors with `this(...)`
- `final` fields assigned exactly once
- Validation inside a constructor

## Problem 2: Copying a Class Routine
**Level:** Intermediate

### Scenario
A student copies a friend's routine entry for the same course into their own planner
and then moves their copy to a different time. The friend complains that their routine
changed too. The planner app had a shallow copy constructor; the team wants a program
that shows the bug and the fix side by side.

### Problem Statement
Write a class `TimeSlot` (mutable: `day`, `start` with a setter `move(String day,
String start)`) and a class `RoutineEntry` (`course`, `room`, and a `TimeSlot`). Give
`RoutineEntry` two copy constructors expressed as static factory methods:

- `static RoutineEntry shallowCopy(RoutineEntry other)`: copies the reference to the
  same `TimeSlot`;
- `static RoutineEntry deepCopy(RoutineEntry other)`: creates a new `TimeSlot` with
  the same values (use a `TimeSlot(TimeSlot other)` copy constructor).

Input: the original's course, room, day and start time (one line), then the new day
and start time for the copy (one line).

Make a shallow copy and move **its** slot; print both. Then build a fresh original from
the same input, make a deep copy, move **its** slot, and print both. Output:

```text
Shallow copy:
  original: <course> <room> <day> <start>
  copy:     <course> <room> <day> <start>
Deep copy:
  original: <course> <room> <day> <start>
  copy:     <course> <room> <day> <start>
Same slot object (shallow): <true|false>
Same slot object (deep): <true|false>
```

### Sample Input
```text
CSE1115 702 Sunday 08:30
Tuesday 11:10
```

### Sample Output
```text
Shallow copy:
  original: CSE1115 702 Tuesday 11:10
  copy:     CSE1115 702 Tuesday 11:10
Deep copy:
  original: CSE1115 702 Sunday 08:30
  copy:     CSE1115 702 Tuesday 11:10
Same slot object (shallow): true
Same slot object (deep): false
```

### Solution
```java
import java.util.Scanner;

class TimeSlot {
    private String day;
    private String start;

    TimeSlot(String day, String start) {
        this.day = day;
        this.start = start;
    }

    TimeSlot(TimeSlot other) {
        this(other.day, other.start);
    }

    void move(String newDay, String newStart) {
        day = newDay;
        start = newStart;
    }

    @Override
    public String toString() {
        return day + " " + start;
    }
}

class RoutineEntry {
    private final String course;
    private final String room;
    private final TimeSlot slot;

    RoutineEntry(String course, String room, TimeSlot slot) {
        this.course = course;
        this.room = room;
        this.slot = slot;
    }

    static RoutineEntry shallowCopy(RoutineEntry other) {
        return new RoutineEntry(other.course, other.room, other.slot);
    }

    static RoutineEntry deepCopy(RoutineEntry other) {
        return new RoutineEntry(other.course, other.room, new TimeSlot(other.slot));
    }

    TimeSlot getSlot() {
        return slot;
    }

    @Override
    public String toString() {
        return course + " " + room + " " + slot;
    }
}

public class RoutineCopy {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String course = in.next();
        String room = in.next();
        String day = in.next();
        String start = in.next();
        String newDay = in.next();
        String newStart = in.next();

        RoutineEntry original = new RoutineEntry(course, room, new TimeSlot(day, start));
        RoutineEntry shallow = RoutineEntry.shallowCopy(original);
        shallow.getSlot().move(newDay, newStart);
        System.out.println("Shallow copy:");
        System.out.println("  original: " + original);
        System.out.println("  copy:     " + shallow);
        boolean sameShallow = original.getSlot() == shallow.getSlot();

        original = new RoutineEntry(course, room, new TimeSlot(day, start));
        RoutineEntry deep = RoutineEntry.deepCopy(original);
        deep.getSlot().move(newDay, newStart);
        System.out.println("Deep copy:");
        System.out.println("  original: " + original);
        System.out.println("  copy:     " + deep);
        boolean sameDeep = original.getSlot() == deep.getSlot();

        System.out.println("Same slot object (shallow): " + sameShallow);
        System.out.println("Same slot object (deep): " + sameDeep);
    }
}
```

### Explanation
Java has no built-in copy constructor; a copy is whatever your code makes it. The
shallow copy copies the **reference** stored in `slot`, so both entries point to one
`TimeSlot` object, and moving the copy's slot moves the original's too. `final` does
not help here: a `final` reference cannot be pointed elsewhere, but the object it
points to can still change. The deep copy creates a new `TimeSlot` with the same
values, so the two entries are independent. `==` on references answers "is this the
same object?", which proves the difference. Strings can be shared safely because they
are immutable; only mutable parts such as `TimeSlot` need to be copied.

### Concepts Practiced
- Writing copy constructors by hand
- Shallow copy versus deep copy
- `final` references to mutable objects
- Reference comparison with `==`

## Problem 3: Tracing Object Construction
**Level:** Intermediate

### Scenario
In a viva, students are often asked "in which order do field initializers, initializer
blocks and constructors run?". The lab instructor wants a program that prints the
exact order for a `Seminar` object built through different constructors.

### Problem Statement
Write a class `Seminar` with:

- a field `title` initialized by a method call `note("field title")` that returns
  `"Untitled"`;
- an instance initializer block that prints `  initializer block`;
- a field `seats` initialized to `note2("field seats")`, returning `30`, declared
  **after** the initializer block;
- constructors `Seminar()`, `Seminar(String title)` and `Seminar(String title, int
  seats)`. The first two chain to the next with `this(...)`. Each constructor prints
  `  constructor (<parameters>)` as its first statement **after** any `this(...)` call,
  where `<parameters>` is empty, `title` or `title, seats`. The three-argument
  constructor assigns the fields.

`note`/`note2` print `  <text>` before returning their value. A
`describe()` method returns `<title> with <seats> seats`.

Input: `n`, then `n` lines: `NONE`, `TITLE t` or `FULL t s`. For each line print
`Creating with <NONE|TITLE|FULL>:`, the trace produced while constructing, and then
`Result: <describe()>`.

### Sample Input
```text
2
NONE
FULL AI-Talk 120
```

### Sample Output
```text
Creating with NONE:
  field title
  initializer block
  field seats
  constructor (title, seats)
  constructor (title)
  constructor ()
Result: Untitled with 30 seats
Creating with FULL:
  field title
  initializer block
  field seats
  constructor (title, seats)
Result: AI-Talk with 120 seats
```

### Solution
```java
import java.util.Scanner;

class Seminar {
    private String title = note("field title");

    {
        System.out.println("  initializer block");
    }

    private int seats = note2("field seats");

    Seminar() {
        this("Untitled");
        System.out.println("  constructor ()");
    }

    Seminar(String title) {
        this(title, 30);
        System.out.println("  constructor (title)");
    }

    Seminar(String title, int seats) {
        System.out.println("  constructor (title, seats)");
        this.title = title;
        this.seats = seats;
    }

    private static String note(String text) {
        System.out.println("  " + text);
        return "Untitled";
    }

    private static int note2(String text) {
        System.out.println("  " + text);
        return 30;
    }

    String describe() {
        return title + " with " + seats + " seats";
    }
}

public class ConstructionTrace {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String kind = in.next();
            System.out.println("Creating with " + kind + ":");
            Seminar s;
            if (kind.equals("NONE")) {
                s = new Seminar();
            } else if (kind.equals("TITLE")) {
                s = new Seminar(in.next());
            } else {
                String title = in.next();
                s = new Seminar(title, in.nextInt());
            }
            System.out.println("Result: " + s.describe());
        }
    }
}
```

### Explanation
For every `new Seminar(...)`, Java first runs the field initializers and instance
initializer blocks **in the order they appear in the class**, and only then the body of
the constructor that does not start with `this(...)`. With chaining, the bodies run
from the innermost constructor outwards: `Seminar()` calls `Seminar(String)`, which
calls `Seminar(String, int)`; that body prints first, then the `(title)` body, then the
`()` body. Field initializers run only once per object, no matter how many constructors
are chained. (`note` and `note2` are `static` so they can be called before the object
is fully built; `static` is explained in Chapter 07.)

### Concepts Practiced
- Order of field initializers and initializer blocks
- Constructor chaining order
- Tracing object creation step by step

## Problem 4: Exam Paper Sets
**Level:** Advanced

### Scenario
For a mid-term exam, the course teacher prepares Set A and then creates Set B by
copying Set A and changing some questions and marks. Last trimester, editing Set B
silently changed Set A because the copy shared its question list. This time the
teacher wants a proper deep copy, and every print job must release the shared printer
as soon as it finishes.

### Problem Statement
Write:

- `QuestionSet` (mutable): three questions `q1`, `q2`, `q3` and their marks; methods
  `edit(int number, String text)`, `setMarks(int number, int marks)` (marks 1–20,
  otherwise refused), `total()`, and a copy constructor `QuestionSet(QuestionSet other)`.
- `ExamPaper`: `private final String set` and `private final QuestionSet questions`;
  a constructor and a **copy constructor** `ExamPaper(ExamPaper other, String newSet)`
  that deep-copies the questions.
- `PrintJob implements AutoCloseable`: its constructor prints
  `[printer acquired for Set <s>]`; `print(ExamPaper p)` prints the paper; `close()`
  prints `[printer released]`.

Input: three question lines for Set A, then a line with the three marks, then `n` and
`n` commands applied to **Set B** (created as a copy of Set A before the first
command): `EDIT k text...` or `MARKS k m`. Each command prints `Set B: question <k>
edited` / `Set B: question <k> marks <m>` or `Set B: marks <m> refused`. Then print
Set A and Set B, each inside its own try-with-resources `PrintJob`.

A printed paper looks like:

```text
Set <s> (total <t>)
  1. <q1> [<m1>]
  2. <q2> [<m2>]
  3. <q3> [<m3>]
```

### Sample Input
```text
Define encapsulation.
Write a copy constructor for class Point.
Explain garbage collection.
5 10 5
3
EDIT 2 Write a copy constructor for class Circle.
MARKS 3 8
MARKS 1 25
```

### Sample Output
```text
Set B: question 2 edited
Set B: question 3 marks 8
Set B: marks 25 refused
[printer acquired for Set A]
Set A (total 20)
  1. Define encapsulation. [5]
  2. Write a copy constructor for class Point. [10]
  3. Explain garbage collection. [5]
[printer released]
[printer acquired for Set B]
Set B (total 23)
  1. Define encapsulation. [5]
  2. Write a copy constructor for class Circle. [10]
  3. Explain garbage collection. [8]
[printer released]
```

### Solution
```java
import java.util.Scanner;

class QuestionSet {
    private String q1;
    private String q2;
    private String q3;
    private int m1;
    private int m2;
    private int m3;

    QuestionSet(String q1, String q2, String q3, int m1, int m2, int m3) {
        this.q1 = q1;
        this.q2 = q2;
        this.q3 = q3;
        this.m1 = m1;
        this.m2 = m2;
        this.m3 = m3;
    }

    QuestionSet(QuestionSet other) {
        this(other.q1, other.q2, other.q3, other.m1, other.m2, other.m3);
    }

    void edit(int number, String text) {
        if (number == 1) {
            q1 = text;
        } else if (number == 2) {
            q2 = text;
        } else {
            q3 = text;
        }
    }

    boolean setMarks(int number, int marks) {
        if (marks < 1 || marks > 20) {
            return false;
        }
        if (number == 1) {
            m1 = marks;
        } else if (number == 2) {
            m2 = marks;
        } else {
            m3 = marks;
        }
        return true;
    }

    int total() {
        return m1 + m2 + m3;
    }

    String lines() {
        return "  1. " + q1 + " [" + m1 + "]\n"
                + "  2. " + q2 + " [" + m2 + "]\n"
                + "  3. " + q3 + " [" + m3 + "]";
    }
}

class ExamPaper {
    private final String set;
    private final QuestionSet questions;

    ExamPaper(String set, QuestionSet questions) {
        this.set = set;
        this.questions = questions;
    }

    ExamPaper(ExamPaper other, String newSet) {
        this(newSet, new QuestionSet(other.questions));
    }

    String getSet() {
        return set;
    }

    QuestionSet getQuestions() {
        return questions;
    }

    String render() {
        return "Set " + set + " (total " + questions.total() + ")\n" + questions.lines();
    }
}

class PrintJob implements AutoCloseable {
    PrintJob(String set) {
        System.out.println("[printer acquired for Set " + set + "]");
    }

    void print(ExamPaper paper) {
        System.out.println(paper.render());
    }

    @Override
    public void close() {
        System.out.println("[printer released]");
    }
}

public class ExamPaperSets {
    static void printPaper(ExamPaper paper) {
        try (PrintJob job = new PrintJob(paper.getSet())) {
            job.print(paper);
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String q1 = in.nextLine();
        String q2 = in.nextLine();
        String q3 = in.nextLine();
        int m1 = in.nextInt();
        int m2 = in.nextInt();
        int m3 = in.nextInt();
        ExamPaper setA = new ExamPaper("A", new QuestionSet(q1, q2, q3, m1, m2, m3));
        ExamPaper setB = new ExamPaper(setA, "B");

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            int k = in.nextInt();
            if (command.equals("EDIT")) {
                setB.getQuestions().edit(k, in.nextLine().trim());
                System.out.println("Set B: question " + k + " edited");
            } else {
                int marks = in.nextInt();
                if (setB.getQuestions().setMarks(k, marks)) {
                    System.out.println("Set B: question " + k + " marks " + marks);
                } else {
                    System.out.println("Set B: marks " + marks + " refused");
                }
            }
        }
        printPaper(setA);
        printPaper(setB);
    }
}
```

### Explanation
`ExamPaper`'s copy constructor chains to the normal constructor with a **new**
`QuestionSet` built by `QuestionSet`'s own copy constructor, so Set B owns its
questions. The output proves it: Set A keeps its original question 2 and marks after
Set B is edited. Each class copies its own fields, which keeps copying logic next to
the data it copies. The printer is a resource, not memory, so it must be released at a
known moment; the garbage collector cannot promise that. `try (PrintJob job = ...)`
calls `close()` automatically when the block ends, however it ends, which is what
Java offers instead of a C++ destructor.

### Concepts Practiced
- Deep copy constructors across two classes
- Constructor chaining from a copy constructor
- `AutoCloseable` and try-with-resources
- Proving independence of copies
