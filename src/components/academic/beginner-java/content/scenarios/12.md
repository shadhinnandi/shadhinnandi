# Scenario-Based Problems

These scenarios practise Chapter 12: reading text files line by line with
`BufferedReader`, writing with `PrintWriter` and `BufferedWriter`, appending to an
existing file, object serialization, and handling missing or malformed files without
crashing. Files are read from and written to the program's working directory.

Programs read input without prompts and print exactly the sample output. A
`File name.txt` block in the input is created before the program runs; a `File` block
in the output is the file the program must create. All rules in these problems are
hypothetical and invented for practice.

## Problem 1: Attendance Defaulter List
**Level:** Basic

### Scenario
Students need at least 70% attendance to sit the final exam. The course teacher
exports attendance from the class register as a CSV file and wants a list of
defaulters to send to the exam office.

### Problem Statement
`attendance.csv` has a header line, then lines `id,name,present,total`. Read it with
a `BufferedReader` and write `defaulters.txt` with a `PrintWriter`: one line per
student whose attendance `present × 100 / total` (integer division) is below 70, as
`<id> <name> <percent>%`, in file order. If there are none, the file contains the
single line `No defaulters`.

Standard input contains the minimum percent (normally 70). Print to standard output
`Checked <k> students, <d> defaulters`.

### Sample Input
```text
70
```
**File `attendance.csv`**
```text
id,name,present,total
011221001,Rahim,25,28
011221002,Nusrat,19,28
011221003,Tanvir,14,28
011221004,Ayesha,20,28
```

### Sample Output
```text
Checked 4 students, 2 defaulters
```
**File `defaulters.txt`**
```text
011221002 Nusrat 67%
011221003 Tanvir 50%
```

### Solution
```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.Scanner;

public class AttendanceDefaulters {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int minimum = in.nextInt();
        int checked = 0;
        int defaulters = 0;

        try (BufferedReader reader = new BufferedReader(new FileReader("attendance.csv"));
             PrintWriter writer = new PrintWriter("defaulters.txt")) {
            reader.readLine(); // skip the header
            String line;
            while ((line = reader.readLine()) != null) {
                String[] f = line.split(",");
                int present = Integer.parseInt(f[2].trim());
                int total = Integer.parseInt(f[3].trim());
                int percent = present * 100 / total;
                checked++;
                if (percent < minimum) {
                    writer.println(f[0] + " " + f[1] + " " + percent + "%");
                    defaulters++;
                }
            }
            if (defaulters == 0) {
                writer.println("No defaulters");
            }
        } catch (IOException e) {
            System.out.println("Could not process attendance: " + e.getMessage());
            return;
        }
        System.out.println("Checked " + checked + " students, " + defaulters + " defaulters");
    }
}
```

### Explanation
`BufferedReader.readLine()` returns one line at a time and `null` at the end of the
file, which gives the classic `while ((line = reader.readLine()) != null)` loop. Both
the reader and the writer are declared in one try-with-resources statement, so both
are closed (and the writer's buffer is flushed to disk) when the block ends; a file
that is not closed may end up empty. The header is skipped by reading it once before
the loop. `FileReader` and `PrintWriter(String)` can throw `IOException` subclasses,
so the program catches `IOException` and reports the problem instead of crashing.

### Concepts Practiced
- Reading a text file with `BufferedReader`
- Writing a text file with `PrintWriter`
- Two resources in one try-with-resources
- Parsing CSV lines with `split`

## Problem 2: Canteen Sales Report and Log
**Level:** Intermediate

### Scenario
The canteen's till writes every sale to `sales.txt`. At closing time the manager
wants a report per item and a one-line summary appended to a running log, which
already contains the summaries of previous days.

### Problem Statement
`sales.txt` has lines `item quantity unitPrice`. Combine all lines of the same item
(keep items in the order they first appear) using an `ArrayList` of `ItemTotal`
objects. Write `report.txt` with a `BufferedWriter`:

```text
Item         Qty     Amount
<item %-12s><qty %3d><amount %11d>
...
TOTAL        <qty %3d><amount %11d>
```

(each line is built with `String.format("%-12s%3d%11d", ...)`, and the header is
written exactly as shown above). Then **append** the line `<date> sales <total> Tk`
to `log.txt` (the date is read from standard input), using
`new FileWriter("log.txt", true)`. Print `Report written: <items> items, <total> Tk`.

### Sample Input
```text
2025-03-12
```
**File `sales.txt`**
```text
Tea 10 15
Singara 25 10
Tea 6 15
Khichuri 4 120
Singara 5 10
```
**File `log.txt`**
```text
2025-03-11 sales 1630 Tk
```

### Sample Output
```text
Report written: 3 items, 1020 Tk
```
**File `report.txt`**
```text
Item         Qty     Amount
Tea          16        240
Singara      30        300
Khichuri      4        480
TOTAL        50       1020
```
**File `log.txt`**
```text
2025-03-11 sales 1630 Tk
2025-03-12 sales 1020 Tk
```

### Solution
```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.ArrayList;
import java.util.Scanner;

class ItemTotal {
    final String item;
    int quantity;
    long amount;

    ItemTotal(String item) {
        this.item = item;
    }

    void add(int qty, int unitPrice) {
        quantity += qty;
        amount += (long) qty * unitPrice;
    }
}

public class CanteenReport {
    static ItemTotal find(ArrayList<ItemTotal> totals, String item) {
        for (ItemTotal t : totals) {
            if (t.item.equals(item)) {
                return t;
            }
        }
        ItemTotal t = new ItemTotal(item);
        totals.add(t);
        return t;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String date = in.next();
        ArrayList<ItemTotal> totals = new ArrayList<>();

        try (BufferedReader reader = new BufferedReader(new FileReader("sales.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                if (line.isBlank()) {
                    continue;
                }
                String[] f = line.trim().split("\\s+");
                find(totals, f[0]).add(Integer.parseInt(f[1]), Integer.parseInt(f[2]));
            }
        } catch (IOException e) {
            System.out.println("Cannot read sales.txt");
            return;
        }

        int qty = 0;
        long total = 0;
        try (BufferedWriter out = new BufferedWriter(new FileWriter("report.txt"))) {
            out.write("Item         Qty     Amount");
            out.newLine();
            for (ItemTotal t : totals) {
                out.write(String.format("%-12s%3d%11d", t.item, t.quantity, t.amount));
                out.newLine();
                qty += t.quantity;
                total += t.amount;
            }
            out.write(String.format("%-12s%3d%11d", "TOTAL", qty, total));
            out.newLine();
        } catch (IOException e) {
            System.out.println("Cannot write report.txt");
            return;
        }

        try (PrintWriter log = new PrintWriter(new FileWriter("log.txt", true))) {
            log.println(date + " sales " + total + " Tk");
        } catch (IOException e) {
            System.out.println("Cannot append to log.txt");
            return;
        }
        System.out.println("Report written: " + totals.size() + " items, " + total + " Tk");
    }
}
```

### Explanation
Reading and writing are separate steps, each in its own try-with-resources, so each
file is closed as soon as it is no longer needed. `BufferedWriter` collects text in
memory and writes it in large chunks, which is much faster than many tiny writes;
`newLine()` writes the correct line separator. The second argument `true` in
`new FileWriter("log.txt", true)` opens the file in **append** mode, so the earlier
days stay in the log; without it the file would be emptied first. Wrapping a
`FileWriter` in a `PrintWriter` gives the convenient `println` method: a stream that
decorates another stream, which is the decorator idea from the chapter.

### Concepts Practiced
- Aggregating file data into objects
- `BufferedWriter` with `write` and `newLine`
- Appending to an existing file
- Fixed-width report formatting

## Problem 3: Saving Student Records with Serialization
**Level:** Intermediate

### Scenario
The club management app keeps its members in memory and must save them when it
closes and load them when it starts. The developer uses Java object serialization, but
a member's portal password must never be written to disk.

### Problem Statement
Write a class `Member implements Serializable` with `private static final long
serialVersionUID = 1L`, fields `id`, `name`, `points` and a `transient String
password`. Read `members.csv` (lines `id,name,points,password`), build an
`ArrayList<Member>`, and write the **whole list** to `members.ser` with one
`ObjectOutputStream.writeObject` call. Then read it back with `ObjectInputStream` into
a new list and print, for every member,
`<id> <name> <points> points, password <password>` (the password will show as
`null`), followed by `Saved and loaded <k> members, same objects: <true|false>` where
the last part is whether the first loaded member is the very same object (`==`) as the
first original member.

Standard input contains the file name `members.csv`.

### Sample Input
```text
members.csv
```
**File `members.csv`**
```text
1001,Rafi,120,rafi@123
1002,Sadia,95,sadia#88
```

### Sample Output
```text
1001 Rafi 120 points, password null
1002 Sadia 95 points, password null
Saved and loaded 2 members, same objects: false
```

### Solution
```java
import java.io.BufferedReader;
import java.io.FileInputStream;
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.FileReader;
import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.io.Serializable;
import java.util.ArrayList;
import java.util.Scanner;

class Member implements Serializable {
    private static final long serialVersionUID = 1L;

    private final String id;
    private final String name;
    private final int points;
    private final transient String password;

    Member(String id, String name, int points, String password) {
        this.id = id;
        this.name = name;
        this.points = points;
        this.password = password;
    }

    @Override
    public String toString() {
        return id + " " + name + " " + points + " points, password " + password;
    }
}

public class MemberStore {
    static ArrayList<Member> readCsv(String file) throws IOException {
        ArrayList<Member> list = new ArrayList<>();
        try (BufferedReader reader = new BufferedReader(new FileReader(file))) {
            String line;
            while ((line = reader.readLine()) != null) {
                String[] f = line.split(",");
                list.add(new Member(f[0], f[1], Integer.parseInt(f[2]), f[3]));
            }
        }
        return list;
    }

    static void save(ArrayList<Member> members, String file) throws IOException {
        try (ObjectOutputStream out = new ObjectOutputStream(new FileOutputStream(file))) {
            out.writeObject(members);
        }
    }

    @SuppressWarnings("unchecked")
    static ArrayList<Member> load(String file) throws IOException, ClassNotFoundException {
        try (ObjectInputStream in = new ObjectInputStream(new FileInputStream(file))) {
            return (ArrayList<Member>) in.readObject();
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String csv = in.next();
        try {
            ArrayList<Member> original = readCsv(csv);
            save(original, "members.ser");
            ArrayList<Member> loaded = load("members.ser");
            for (Member m : loaded) {
                System.out.println(m);
            }
            boolean same = !original.isEmpty() && original.get(0) == loaded.get(0);
            System.out.println("Saved and loaded " + loaded.size() + " members, same objects: " + same);
        } catch (FileNotFoundException e) {
            System.out.println("Cannot find " + csv);
        } catch (IOException | ClassNotFoundException e) {
            System.out.println("Storage error: " + e.getMessage());
        }
    }
}
```

### Explanation
Serialization turns an object graph into bytes: writing the `ArrayList` also writes
every `Member` it refers to, and reading it back rebuilds **new** objects with the same
data, which is why `==` is `false`. A `transient` field is skipped when writing, so the
password never reaches the disk and comes back as `null` (the default value). The
`serialVersionUID` is a version number for the class; if the class changes
incompatibly, the number tells Java that old files cannot be read. `readObject` returns
`Object`, so a cast is needed; because the compiler cannot check a generic cast at run
time, the method is marked `@SuppressWarnings("unchecked")` after we have made sure we
only ever write an `ArrayList<Member>` to this file. A missing CSV file is caught as
`FileNotFoundException` before the general multi-catch, so the message does not depend
on the operating system's wording. Serialization is convenient for
your own program's data, but never deserialize files from untrusted sources.

### Concepts Practiced
- `Serializable`, `serialVersionUID` and `transient`
- `ObjectOutputStream` and `ObjectInputStream`
- Deserialized objects are new objects
- Catching `FileNotFoundException` before other I/O errors

## Problem 4: Merging Section Mark Sheets
**Level:** Advanced

### Scenario
Two section teachers keep marks in their own CSV files. The coordinator needs one
merged sheet sorted by student ID for the result committee. Teachers' files sometimes
contain mistakes, and a student who moved sections may appear in both files; such
conflicts must be reported, not silently resolved.

### Problem Statement
Read the two file names from standard input. Each file has lines `id,name,marks`
(marks 0–100). Read both files into an `ArrayList<Record>`, then:

- a line with the wrong number of fields, non-numeric marks or marks out of range is
  written to `errors.txt` as `<file>:<line number>: <line>`;
- if an ID appears in both files with the **same** marks, keep one record;
- if an ID appears with **different** marks, write
  `conflict <id>: <marksA> vs <marksB>` to `errors.txt` and keep the **higher** mark;
- a missing input file is reported in `errors.txt` as `<file>: not found` and treated
  as empty.

Write `merged.csv` (header `id,name,marks`, then the records sorted by ID) and print
`Merged <k> students, <e> problems` where `e` is the number of lines in `errors.txt`.
If there are no problems, `errors.txt` must contain `No problems`.

### Sample Input
```text
sectionA.csv sectionB.csv
```
**File `sectionA.csv`**
```text
011221030,Rahim,72
011221005,Nusrat,88
011221017,Imran,abc
011221012,Mitu,64
```
**File `sectionB.csv`**
```text
011221012,Mitu,70
011221002,Ayesha,91
011221030,Rahim,72
011221040,Fahim
```

### Sample Output
```text
Merged 4 students, 3 problems
```
**File `merged.csv`**
```text
id,name,marks
011221002,Ayesha,91
011221005,Nusrat,88
011221012,Mitu,70
011221030,Rahim,72
```
**File `errors.txt`**
```text
sectionA.csv:3: 011221017,Imran,abc
conflict 011221012: 64 vs 70
sectionB.csv:4: 011221040,Fahim
```

### Solution
```java
import java.io.BufferedReader;
import java.io.FileNotFoundException;
import java.io.FileReader;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.ArrayList;
import java.util.Scanner;

class Record {
    final String id;
    final String name;
    int marks;

    Record(String id, String name, int marks) {
        this.id = id;
        this.name = name;
        this.marks = marks;
    }
}

class MarkSheetMerger {
    private final ArrayList<Record> records = new ArrayList<>();
    private final ArrayList<String> problems = new ArrayList<>();

    void read(String file) {
        try (BufferedReader reader = new BufferedReader(new FileReader(file))) {
            String line;
            int number = 0;
            while ((line = reader.readLine()) != null) {
                number++;
                Record r = parse(line);
                if (r == null) {
                    problems.add(file + ":" + number + ": " + line);
                } else {
                    add(r);
                }
            }
        } catch (FileNotFoundException e) {
            problems.add(file + ": not found");
        } catch (IOException e) {
            problems.add(file + ": " + e.getMessage());
        }
    }

    private static Record parse(String line) {
        String[] f = line.split(",");
        if (f.length != 3) {
            return null;
        }
        try {
            int marks = Integer.parseInt(f[2].trim());
            if (marks < 0 || marks > 100) {
                return null;
            }
            return new Record(f[0].trim(), f[1].trim(), marks);
        } catch (NumberFormatException e) {
            return null;
        }
    }

    private void add(Record r) {
        for (Record existing : records) {
            if (existing.id.equals(r.id)) {
                if (existing.marks != r.marks) {
                    problems.add("conflict " + r.id + ": " + existing.marks + " vs " + r.marks);
                    existing.marks = Math.max(existing.marks, r.marks);
                }
                return;
            }
        }
        records.add(r);
    }

    private void sortById() {
        for (int i = 1; i < records.size(); i++) {
            Record current = records.get(i);
            int j = i - 1;
            while (j >= 0 && records.get(j).id.compareTo(current.id) > 0) {
                records.set(j + 1, records.get(j));
                j--;
            }
            records.set(j + 1, current);
        }
    }

    void write(String mergedFile, String errorFile) throws IOException {
        sortById();
        try (PrintWriter out = new PrintWriter(mergedFile)) {
            out.println("id,name,marks");
            for (Record r : records) {
                out.println(r.id + "," + r.name + "," + r.marks);
            }
        }
        try (PrintWriter err = new PrintWriter(errorFile)) {
            if (problems.isEmpty()) {
                err.println("No problems");
            }
            for (String p : problems) {
                err.println(p);
            }
        }
    }

    int recordCount() {
        return records.size();
    }

    int problemCount() {
        return problems.size();
    }
}

public class MergeMarkSheets {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        MarkSheetMerger merger = new MarkSheetMerger();
        merger.read(in.next());
        merger.read(in.next());
        try {
            merger.write("merged.csv", "errors.txt");
            System.out.println("Merged " + merger.recordCount() + " students, "
                    + merger.problemCount() + " problems");
        } catch (IOException e) {
            System.out.println("Cannot write output: " + e.getMessage());
        }
    }
}
```

### Explanation
The merger object owns the data (`records`) and the problem list, and the rest of the
program only calls `read` and `write`. Each kind of failure is handled at the level that
can deal with it: a malformed **line** becomes a problem entry and reading continues; a
missing **file** is caught as `FileNotFoundException` (a subclass of `IOException`, so
it is caught first) and the merge continues with the other file. `parse` returns `null`
for any malformed line and catches `NumberFormatException` locally, so bad data never
becomes a half-built `Record`. Insertion sort moves records right until the new one
fits, which keeps the code short for a list that is already nearly sorted. Writing all
problems to a file instead of the screen gives the coordinator a document to send back
to the teachers.

### Concepts Practiced
- Reading several files with shared handling code
- Catching `FileNotFoundException` before `IOException`
- Recording problems instead of crashing
- Writing two output files
