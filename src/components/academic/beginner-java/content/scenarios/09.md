# Scenario-Based Problems

These scenarios practise Chapter 09: `extends`, calling superclass constructors with
`super(...)`, reusing and extending superclass behaviour with `super.method()`,
`protected` members, `final` methods, multilevel hierarchies, and Java's way of giving
a class several types at once: one superclass plus several interfaces.

Programs read input without prompts and print exactly the sample output. All fees,
rates and rules in these problems are hypothetical and invented for practice.

## Problem 1: University ID Cards
**Level:** Basic

### Scenario
The university prints ID cards for students and faculty. Every card shows the name and
ID; student cards add the department and credits completed, and faculty cards add the
designation. The card printer software should not repeat the common parts.

### Problem Statement
Write a class `Member` (`name`, `id`, a constructor and `String card()` returning
`<id> | <name>`), and two subclasses:

- `Student(name, id, department, credits)`: `card()` returns the member card followed
  by ` | Student, <department>, <credits> credits` and ` | Final year` if credits are at
  least 120;
- `Faculty(name, id, designation)`: `card()` returns the member card followed by
  ` | Faculty, <designation>`.

Both subclasses must call `super(...)` in their constructors and `super.card()` in
`card()`.

Input: `n`, then `n` lines `S name id department credits` or
`F name id designation` (all single words). Print every card.

### Sample Input
```text
3
S Nusrat 011221001 CSE 96
F Hasan T-1023 Lecturer
S Rafi 011191044 EEE 128
```

### Sample Output
```text
011221001 | Nusrat | Student, CSE, 96 credits
T-1023 | Hasan | Faculty, Lecturer
011191044 | Rafi | Student, EEE, 128 credits | Final year
```

### Solution
```java
import java.util.Scanner;

class Member {
    private final String name;
    private final String id;

    Member(String name, String id) {
        this.name = name;
        this.id = id;
    }

    String card() {
        return id + " | " + name;
    }
}

class Student extends Member {
    private static final int FINAL_YEAR_CREDITS = 120;
    private final String department;
    private final int credits;

    Student(String name, String id, String department, int credits) {
        super(name, id);
        this.department = department;
        this.credits = credits;
    }

    @Override
    String card() {
        String text = super.card() + " | Student, " + department + ", " + credits + " credits";
        if (credits >= FINAL_YEAR_CREDITS) {
            text += " | Final year";
        }
        return text;
    }
}

class Faculty extends Member {
    private final String designation;

    Faculty(String name, String id, String designation) {
        super(name, id);
        this.designation = designation;
    }

    @Override
    String card() {
        return super.card() + " | Faculty, " + designation;
    }
}

public class IdCards {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String type = in.next();
            String name = in.next();
            String id = in.next();
            Member m;
            if (type.equals("S")) {
                String dept = in.next();
                m = new Student(name, id, dept, in.nextInt());
            } else {
                m = new Faculty(name, id, in.next());
            }
            System.out.println(m.card());
        }
    }
}
```

### Explanation
`name` and `id` are `private` in `Member`, so the subclasses cannot touch them
directly; they pass the values up with `super(name, id)`, which must be the first
statement of the constructor. In `card()`, `super.card()` runs the **superclass**
version, and the subclass adds its own part. This is the usual way to extend behaviour
instead of replacing it. `@Override` asks the compiler to check that the method really
overrides one in the superclass, which catches spelling mistakes.

### Concepts Practiced
- `extends` and `super(...)` in constructors
- Extending a method with `super.method()`
- `@Override`
- Private superclass fields

## Problem 2: Hospital Payroll Levels
**Level:** Intermediate

### Scenario
A teaching hospital pays all staff a base salary. Doctors also earn a fee per patient
consultation, and surgeons are doctors who also earn a fee per surgery. Nurses earn a
night-shift allowance. The accounts team wants each salary slip to show the parts.

### Problem Statement
Build this hierarchy:

```text
Staff (name, base)
 ├── Doctor (+ patients × 150)
 │    └── Surgeon (+ surgeries × 5000)
 └── Nurse (+ nightShifts × 800)
```

Each class has `int monthlyPay()` and `String slip()`. A subclass computes its pay as
`super.monthlyPay()` plus its own part, and its slip as `super.slip()` plus its own
part:

- `Staff.slip()`: `<name>: base <base>`
- `Doctor` adds ` + consultations <amount>`
- `Surgeon` adds ` + surgeries <amount>`
- `Nurse` adds ` + night shifts <amount>`

Input: `n`, then `n` lines: `staff name base`, `doctor name base patients`,
`surgeon name base patients surgeries` or `nurse name base shifts`. For each print
`<slip> = <pay>`; finally print `Total payroll: <sum>`.

### Sample Input
```text
4
staff Arif 25000
doctor Imran 60000 40
surgeon Farhana 90000 25 6
nurse Mitu 30000 8
```

### Sample Output
```text
Arif: base 25000 = 25000
Imran: base 60000 + consultations 6000 = 66000
Farhana: base 90000 + consultations 3750 + surgeries 30000 = 123750
Mitu: base 30000 + night shifts 6400 = 36400
Total payroll: 251150
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Staff {
    private final String name;
    private final int base;

    Staff(String name, int base) {
        this.name = name;
        this.base = base;
    }

    int monthlyPay() {
        return base;
    }

    String slip() {
        return name + ": base " + base;
    }
}

class Doctor extends Staff {
    private static final int FEE_PER_PATIENT = 150;
    private final int patients;

    Doctor(String name, int base, int patients) {
        super(name, base);
        this.patients = patients;
    }

    @Override
    int monthlyPay() {
        return super.monthlyPay() + patients * FEE_PER_PATIENT;
    }

    @Override
    String slip() {
        return super.slip() + " + consultations " + patients * FEE_PER_PATIENT;
    }
}

class Surgeon extends Doctor {
    private static final int FEE_PER_SURGERY = 5000;
    private final int surgeries;

    Surgeon(String name, int base, int patients, int surgeries) {
        super(name, base, patients);
        this.surgeries = surgeries;
    }

    @Override
    int monthlyPay() {
        return super.monthlyPay() + surgeries * FEE_PER_SURGERY;
    }

    @Override
    String slip() {
        return super.slip() + " + surgeries " + surgeries * FEE_PER_SURGERY;
    }
}

class Nurse extends Staff {
    private static final int NIGHT_ALLOWANCE = 800;
    private final int nightShifts;

    Nurse(String name, int base, int nightShifts) {
        super(name, base);
        this.nightShifts = nightShifts;
    }

    @Override
    int monthlyPay() {
        return super.monthlyPay() + nightShifts * NIGHT_ALLOWANCE;
    }

    @Override
    String slip() {
        return super.slip() + " + night shifts " + nightShifts * NIGHT_ALLOWANCE;
    }
}

public class HospitalPayroll {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        ArrayList<Staff> staff = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            String type = in.next();
            String name = in.next();
            int base = in.nextInt();
            if (type.equals("doctor")) {
                staff.add(new Doctor(name, base, in.nextInt()));
            } else if (type.equals("surgeon")) {
                int patients = in.nextInt();
                staff.add(new Surgeon(name, base, patients, in.nextInt()));
            } else if (type.equals("nurse")) {
                staff.add(new Nurse(name, base, in.nextInt()));
            } else {
                staff.add(new Staff(name, base));
            }
        }
        int total = 0;
        for (Staff s : staff) {
            System.out.println(s.slip() + " = " + s.monthlyPay());
            total += s.monthlyPay();
        }
        System.out.println("Total payroll: " + total);
    }
}
```

### Explanation
This is **multilevel** inheritance: `Surgeon` extends `Doctor`, which extends `Staff`.
`Surgeon.monthlyPay()` calls `super.monthlyPay()`, which is `Doctor`'s version, which
in turn calls `Staff`'s version, so each level adds exactly its own part and no rule is
written twice. Constructors chain the same way: `Surgeon` passes `name`, `base` and
`patients` up to `Doctor`, which passes `name` and `base` up to `Staff`. The list holds
`Staff` references, yet each element runs its own class's methods; Chapter 10 explains
this dynamic dispatch in detail.

### Concepts Practiced
- Multilevel inheritance
- Chained `super.method()` calls
- Chained `super(...)` constructor calls
- A list of superclass references

## Problem 3: Smart Classroom Devices
**Level:** Intermediate

### Scenario
The IT office manages smart devices in classrooms. Every device has an asset tag and a
room. Some devices are on the network, some can display content, some can record. A
smart board does both display and network; a camera records and is networked; a
projector only displays. In C++ one might try to inherit from several classes; in Java
a class extends **one** class and implements as many interfaces as it needs.

### Problem Statement
Write:

- a class `Device` with `tag` and `room` and `String label()` returning
  `<tag> in <room>`;
- interfaces `Networked` (`String ip()`), `Display` (`String show(String content)`) and
  `Recorder` (`String record(int minutes)`);
- `SmartBoard extends Device implements Display, Networked`,
  `Camera extends Device implements Recorder, Networked`,
  `Projector extends Device implements Display`.

`show` returns `<label> shows <content>`; `record` returns
`<label> records <minutes> min`; `ip` returns `10.<room / 100>.<room % 100>.<n>`
(floor, room on the floor, then `n`, which is given in the input for networked
devices), so room 702 gives `10.7.2.<n>`.

Input: `n` devices (`board tag room n`, `camera tag room n`, `projector tag room`),
where `room` is a number; then a line with content to show and a number of minutes.

Keep three lists, `ArrayList<Display>`, `ArrayList<Recorder>`, `ArrayList<Networked>`,
and add each device to every list it belongs to. Print `Displays:` then each display's
`show(content)`, `Recorders:` then each recorder's `record(minutes)`, and `Network:`
then `<ip>` for each networked device, in input order. An empty group prints `  none`.
Indent each item by two spaces.

### Sample Input
```text
4
board SB-01 702 15
projector PJ-07 702
camera CM-02 315 31
board SB-02 1101 9
Welcome to CSE 1115
45
```

### Sample Output
```text
Displays:
  SB-01 in 702 shows Welcome to CSE 1115
  PJ-07 in 702 shows Welcome to CSE 1115
  SB-02 in 1101 shows Welcome to CSE 1115
Recorders:
  CM-02 in 315 records 45 min
Network:
  10.7.2.15
  10.3.15.31
  10.11.1.9
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Device {
    private final String tag;
    protected final int room;

    Device(String tag, int room) {
        this.tag = tag;
        this.room = room;
    }

    String label() {
        return tag + " in " + room;
    }
}

interface Networked {
    String ip();
}

interface Display {
    String show(String content);
}

interface Recorder {
    String record(int minutes);
}

class SmartBoard extends Device implements Display, Networked {
    private final int host;

    SmartBoard(String tag, int room, int host) {
        super(tag, room);
        this.host = host;
    }

    @Override
    public String show(String content) {
        return label() + " shows " + content;
    }

    @Override
    public String ip() {
        return "10." + room / 100 + "." + room % 100 + "." + host;
    }
}

class Camera extends Device implements Recorder, Networked {
    private final int host;

    Camera(String tag, int room, int host) {
        super(tag, room);
        this.host = host;
    }

    @Override
    public String record(int minutes) {
        return label() + " records " + minutes + " min";
    }

    @Override
    public String ip() {
        return "10." + room / 100 + "." + room % 100 + "." + host;
    }
}

class Projector extends Device implements Display {
    Projector(String tag, int room) {
        super(tag, room);
    }

    @Override
    public String show(String content) {
        return label() + " shows " + content;
    }
}

public class SmartClassroom {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        ArrayList<Display> displays = new ArrayList<>();
        ArrayList<Recorder> recorders = new ArrayList<>();
        ArrayList<Networked> network = new ArrayList<>();

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String type = in.next();
            String tag = in.next();
            int room = in.nextInt();
            if (type.equals("board")) {
                SmartBoard b = new SmartBoard(tag, room, in.nextInt());
                displays.add(b);
                network.add(b);
            } else if (type.equals("camera")) {
                Camera c = new Camera(tag, room, in.nextInt());
                recorders.add(c);
                network.add(c);
            } else {
                displays.add(new Projector(tag, room));
            }
        }
        in.nextLine();
        String content = in.nextLine();
        int minutes = in.nextInt();

        System.out.println("Displays:");
        if (displays.isEmpty()) {
            System.out.println("  none");
        }
        for (Display d : displays) {
            System.out.println("  " + d.show(content));
        }
        System.out.println("Recorders:");
        if (recorders.isEmpty()) {
            System.out.println("  none");
        }
        for (Recorder r : recorders) {
            System.out.println("  " + r.record(minutes));
        }
        System.out.println("Network:");
        if (network.isEmpty()) {
            System.out.println("  none");
        }
        for (Networked x : network) {
            System.out.println("  " + x.ip());
        }
    }
}
```

### Explanation
A `SmartBoard` **is a** `Device` (its one superclass) and also **is a** `Display` and
**is a** `Networked` device (its two interfaces). That is why the same object can be
added to two different lists: each list sees the object through a different type and
can only call that type's methods. This is multiple inheritance of **type**: Java lets
a class have many types through interfaces, while a class can still extend only one
class, which avoids the ambiguity of inheriting two different implementations of the
same method. `room` is `protected` so subclasses can build the IP address from it.
In `"10." + room / 100 + ...`, the division happens before the joining because `/`
binds more tightly than `+`.

### Concepts Practiced
- One superclass plus several interfaces
- Multiple inheritance of type
- The same object stored under different interface types
- `protected` fields

## Problem 4: Bank Account Family
**Level:** Advanced

### Scenario
A bank offers three kinds of accounts. All accounts take deposits the same way, and
the bank does not allow any account type to change that rule. Withdrawals and the
month-end processing differ by type. The bank wants the common rules in one class and
each difference in exactly one place.

### Problem Statement
Write an `Account` class (`number`, `owner`, `protected long balance`) with:

- a **`final`** method `boolean deposit(long amount)` that adds a positive amount and
  returns `true`, or returns `false` for amounts ≤ 0;
- an overridable `boolean withdraw(long amount)`: allowed if `0 < amount <= balance`;
- an overridable `String monthEnd()`: returns `no change`;
- `toString()`: `<number> <owner> <type> Tk <balance>` where `type` comes from an
  overridable `String type()` returning `Basic`.

Subclasses:

- `SavingsAccount`: must keep a minimum balance of 500 after a withdrawal; month end
  adds 1% interest (integer: `balance / 100`) and returns `interest <amount>`;
  type `Savings`.
- `StudentSavings extends SavingsAccount`: no minimum balance, but a single withdrawal
  may not exceed 2000; month end like savings; type `Student`.
- `CurrentAccount`: may go down to −5000 (overdraft); month end charges 200 Tk if the
  balance is negative and returns `overdraft fee 200`, otherwise `no change`; type
  `Current`.

Input: `n` lines `OPEN number type owner amount` (type is `basic`, `savings`,
`student` or `current`), `DEP number amount`, `WD number amount`, `MONTH` (month end
for every account in opening order, printing `<number>: <result>`) and `SHOW` (every
account's `toString()`). `DEP` and `WD` print `OK` or `REFUSED`; an unknown number
prints `No account <number>`.

### Sample Input
```text
10
OPEN 1 savings Rahim 3000
OPEN 2 student Nusrat 2500
OPEN 3 current Imran 1000
WD 1 2600
WD 2 2100
WD 2 2000
WD 3 5500
DEP 3 0
MONTH
SHOW
```

### Sample Output
```text
REFUSED
REFUSED
OK
OK
REFUSED
1: interest 30
2: interest 5
3: overdraft fee 200
1 Rahim Savings Tk 3030
2 Nusrat Student Tk 505
3 Imran Current Tk -4700
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Account {
    private final String number;
    private final String owner;
    protected long balance;

    Account(String number, String owner, long opening) {
        this.number = number;
        this.owner = owner;
        this.balance = opening;
    }

    String getNumber() {
        return number;
    }

    final boolean deposit(long amount) {
        if (amount <= 0) {
            return false;
        }
        balance += amount;
        return true;
    }

    boolean withdraw(long amount) {
        if (amount <= 0 || amount > balance) {
            return false;
        }
        balance -= amount;
        return true;
    }

    String monthEnd() {
        return "no change";
    }

    String type() {
        return "Basic";
    }

    @Override
    public String toString() {
        return number + " " + owner + " " + type() + " Tk " + balance;
    }
}

class SavingsAccount extends Account {
    private static final long MIN_BALANCE = 500;

    SavingsAccount(String number, String owner, long opening) {
        super(number, owner, opening);
    }

    @Override
    boolean withdraw(long amount) {
        if (balance - amount < MIN_BALANCE) {
            return false;
        }
        return super.withdraw(amount);
    }

    @Override
    String monthEnd() {
        long interest = balance / 100;
        deposit(interest);
        return "interest " + interest;
    }

    @Override
    String type() {
        return "Savings";
    }
}

class StudentSavings extends SavingsAccount {
    private static final long MAX_SINGLE_WITHDRAWAL = 2000;

    StudentSavings(String number, String owner, long opening) {
        super(number, owner, opening);
    }

    @Override
    boolean withdraw(long amount) {
        if (amount > MAX_SINGLE_WITHDRAWAL || amount <= 0 || amount > balance) {
            return false;
        }
        balance -= amount;
        return true;
    }

    @Override
    String type() {
        return "Student";
    }
}

class CurrentAccount extends Account {
    private static final long OVERDRAFT_LIMIT = 5000;
    private static final long OVERDRAFT_FEE = 200;

    CurrentAccount(String number, String owner, long opening) {
        super(number, owner, opening);
    }

    @Override
    boolean withdraw(long amount) {
        if (amount <= 0 || balance - amount < -OVERDRAFT_LIMIT) {
            return false;
        }
        balance -= amount;
        return true;
    }

    @Override
    String monthEnd() {
        if (balance < 0) {
            balance -= OVERDRAFT_FEE;
            return "overdraft fee " + OVERDRAFT_FEE;
        }
        return "no change";
    }

    @Override
    String type() {
        return "Current";
    }
}

public class BankFamily {
    static Account find(ArrayList<Account> accounts, String number) {
        for (Account a : accounts) {
            if (a.getNumber().equals(number)) {
                return a;
            }
        }
        return null;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        ArrayList<Account> accounts = new ArrayList<>();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("OPEN")) {
                String number = in.next();
                String type = in.next();
                String owner = in.next();
                long amount = in.nextLong();
                if (type.equals("savings")) {
                    accounts.add(new SavingsAccount(number, owner, amount));
                } else if (type.equals("student")) {
                    accounts.add(new StudentSavings(number, owner, amount));
                } else if (type.equals("current")) {
                    accounts.add(new CurrentAccount(number, owner, amount));
                } else {
                    accounts.add(new Account(number, owner, amount));
                }
            } else if (command.equals("MONTH")) {
                for (Account a : accounts) {
                    System.out.println(a.getNumber() + ": " + a.monthEnd());
                }
            } else if (command.equals("SHOW")) {
                for (Account a : accounts) {
                    System.out.println(a);
                }
            } else {
                String number = in.next();
                long amount = in.nextLong();
                Account a = find(accounts, number);
                if (a == null) {
                    System.out.println("No account " + number);
                } else {
                    boolean ok = command.equals("DEP") ? a.deposit(amount) : a.withdraw(amount);
                    System.out.println(ok ? "OK" : "REFUSED");
                }
            }
        }
    }
}
```

### Explanation
`deposit` is `final`, so no subclass can override it: every account type is
guaranteed to accept deposits in exactly the same way. `withdraw`, `monthEnd` and
`type` are meant to vary, so each subclass overrides only what is different.
`SavingsAccount.withdraw` adds its extra rule and then delegates to
`super.withdraw(amount)` for the basic checks. `StudentSavings` inherits from
`SavingsAccount` (so it gets the interest rule for free) but **replaces** the
minimum-balance rule completely, which is why it does not call
`super.withdraw(amount)`. `balance` is `protected` so the subclasses can apply their own
rules, at the price that any subclass could also misuse it; the `final` deposit method
shows the other tool: protecting a rule from being changed.

### Concepts Practiced
- `final` methods that cannot be overridden
- Extending versus replacing a superclass rule
- Multilevel inheritance (`StudentSavings` → `SavingsAccount` → `Account`)
- `protected` fields
