# Scenario-Based Problems

These scenarios practise Chapter 13: writing generic classes and methods, bounded type
parameters, generic collections (`List`, `Map`, `TreeMap`), and `Comparator`. The aim
is code that works for many types while the compiler still checks every type: no raw
types and no casts. When a map is printed, a `TreeMap` keeps the keys sorted so the
output is always the same.

Programs read input without prompts and print exactly the sample output. All rules in
these problems are hypothetical and invented for practice.

## Problem 1: Grade Pairs
**Level:** Basic

### Scenario
The results office stores small pieces of linked data everywhere: a course code with a
grade, a student ID with a CGPA, a room with a capacity. Instead of writing a new class
for every combination, a developer writes one generic `Pair`.

### Problem Statement
Write a generic class `Pair<A, B>` with `private final` fields `first` and `second`,
getters, and `toString()` returning `(<first>, <second>)`. Write a generic static
method `static <A, B> Pair<B, A> swap(Pair<A, B> p)`.

Input: `n`, then `n` lines `course grade points` (for example `CSE1111 A 4.0`).
Build a `List<Pair<String, String>>` of (course, grade) and a
`List<Pair<String, Double>>` of (course, points). Print:

```text
Grades: <list of pairs, printed with List.toString()>
Swapped: <first grade pair swapped>
Points: <list of (course, points) pairs>
Average points: <average with 2 decimals>
```

(`n` is at least 1.)

### Sample Input
```text
3
CSE1111 A 4.0
MAT1101 B+ 3.3
ENG1011 A- 3.7
```

### Sample Output
```text
Grades: [(CSE1111, A), (MAT1101, B+), (ENG1011, A-)]
Swapped: (A, CSE1111)
Points: [(CSE1111, 4.0), (MAT1101, 3.3), (ENG1011, 3.7)]
Average points: 3.67
```

### Solution
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

class Pair<A, B> {
    private final A first;
    private final B second;

    Pair(A first, B second) {
        this.first = first;
        this.second = second;
    }

    A getFirst() {
        return first;
    }

    B getSecond() {
        return second;
    }

    @Override
    public String toString() {
        return "(" + first + ", " + second + ")";
    }
}

public class GradePairs {
    static <A, B> Pair<B, A> swap(Pair<A, B> p) {
        return new Pair<>(p.getSecond(), p.getFirst());
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        List<Pair<String, String>> grades = new ArrayList<>();
        List<Pair<String, Double>> points = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            String course = in.next();
            String grade = in.next();
            double p = in.nextDouble();
            grades.add(new Pair<>(course, grade));
            points.add(new Pair<>(course, p));
        }

        double sum = 0;
        for (Pair<String, Double> p : points) {
            sum += p.getSecond();
        }
        System.out.println("Grades: " + grades);
        System.out.println("Swapped: " + swap(grades.get(0)));
        System.out.println("Points: " + points);
        System.out.printf("Average points: %.2f%n", sum / points.size());
    }
}
```

### Explanation
`Pair<A, B>` is written once; `A` and `B` are type parameters that are filled in where
the class is used, so `Pair<String, Double>` holds a `String` and a `Double`. The
compiler knows `p.getSecond()` returns a `Double` in the second list, so `sum +=` needs
no cast; Java unboxes the `Double` to a `double` automatically. The diamond `<>` in
`new Pair<>(...)` lets the compiler infer the type arguments. `swap` is a generic
**method**: its own type parameters `<A, B>` appear before the return type, and the
result type `Pair<B, A>` describes exactly what it returns.

### Concepts Practiced
- Generic classes with two type parameters
- Generic static methods
- The diamond operator and type inference
- Autoboxing and unboxing

## Problem 2: Statistics for Any Number Type
**Level:** Intermediate

### Scenario
The analytics team computes the same statistics on very different lists: whole-number
attendance counts, decimal CGPAs, even names (for the "last name alphabetically"
award). They want one average method for every number type and one maximum method for
every comparable type.

### Problem Statement
Write two generic static methods:

- `static <T extends Number> double average(List<T> values)` using `doubleValue()`;
- `static <T extends Comparable<T>> T maxOf(List<T> values)` using `compareTo`.

Input: a line `k` then `k` integers (attendance), a line `m` then `m` decimals
(CGPAs), and a line `p` then `p` names. Build a `List<Integer>`, a `List<Double>` and a
`List<String>` and print:

```text
Attendance: average <a with 2 decimals>, max <max>
CGPA: average <a with 2 decimals>, max <max>
Names: max <name>
```

If a list is empty, print `none` instead of the average and the max for it (for
example `CGPA: none`).

### Sample Input
```text
5 22 28 25 19 28
4 3.45 3.90 2.80 3.70
3 Rafi Ayesha Tanvir
```

### Sample Output
```text
Attendance: average 24.40, max 28
CGPA: average 3.46, max 3.90
Names: max Tanvir
```

### Solution
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class GenericStats {
    static <T extends Number> double average(List<T> values) {
        double sum = 0;
        for (T v : values) {
            sum += v.doubleValue();
        }
        return sum / values.size();
    }

    static <T extends Comparable<T>> T maxOf(List<T> values) {
        T best = values.get(0);
        for (T v : values) {
            if (v.compareTo(best) > 0) {
                best = v;
            }
        }
        return best;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        List<Integer> attendance = new ArrayList<>();
        int k = in.nextInt();
        for (int i = 0; i < k; i++) {
            attendance.add(in.nextInt());
        }
        List<Double> cgpas = new ArrayList<>();
        int m = in.nextInt();
        for (int i = 0; i < m; i++) {
            cgpas.add(in.nextDouble());
        }
        List<String> names = new ArrayList<>();
        int p = in.nextInt();
        for (int i = 0; i < p; i++) {
            names.add(in.next());
        }

        if (attendance.isEmpty()) {
            System.out.println("Attendance: none");
        } else {
            System.out.printf("Attendance: average %.2f, max %d%n", average(attendance), maxOf(attendance));
        }
        if (cgpas.isEmpty()) {
            System.out.println("CGPA: none");
        } else {
            System.out.printf("CGPA: average %.2f, max %.2f%n", average(cgpas), maxOf(cgpas));
        }
        System.out.println(names.isEmpty() ? "Names: none" : "Names: max " + maxOf(names));
    }
}
```

### Explanation
A bound restricts which types can be used. `<T extends Number>` promises that every
`T` is some kind of number, so `doubleValue()` is available; `average` therefore works
for `List<Integer>` and `List<Double>` but the compiler rejects `average(names)`.
`<T extends Comparable<T>>` promises that values of `T` can be compared with each other
using `compareTo`, which `Integer`, `Double` and `String` all support. Note that
`maxOf(names)` uses dictionary order, so `Tanvir` beats `Rafi`. Both methods are
written once and the compiler checks every call.

### Concepts Practiced
- Bounded type parameters with `extends`
- `Number.doubleValue()` and `Comparable.compareTo`
- One method for many element types
- Guarding against empty lists

## Problem 3: Department Summary with Maps
**Level:** Intermediate

### Scenario
The student affairs office wants a one-page summary per department: how many students,
the average CGPA and the top student. The input is a plain list of students in no
particular order.

### Problem Statement
Write a class `Student` (`id`, `name`, `department`, `cgpa`). Read `n` students
(`id name department cgpa`) and build a `Map<String, List<Student>>` (a `TreeMap`, so
departments come out in alphabetical order) that groups students by department. For
each department print:

```text
<department>: <count> students, average <avg 2 decimals>, top <name> (<cgpa 2 decimals>)
```

(top = highest CGPA; the first one read wins a tie). Then print
`Departments: <number of departments>` and `Largest: <department>` (most students;
alphabetically first on a tie).

### Sample Input
```text
6
101 Rahim CSE 3.40
102 Nusrat EEE 3.85
103 Imran CSE 3.90
104 Ayesha BBA 3.10
105 Tanvir CSE 3.65
106 Mitu EEE 3.85
```

### Sample Output
```text
BBA: 1 students, average 3.10, top Ayesha (3.10)
CSE: 3 students, average 3.65, top Imran (3.90)
EEE: 2 students, average 3.85, top Nusrat (3.85)
Departments: 3
Largest: CSE
```

### Solution
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.Scanner;
import java.util.TreeMap;

class Student {
    final String id;
    final String name;
    final String department;
    final double cgpa;

    Student(String id, String name, String department, double cgpa) {
        this.id = id;
        this.name = name;
        this.department = department;
        this.cgpa = cgpa;
    }
}

public class DepartmentSummary {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        Map<String, List<Student>> byDept = new TreeMap<>();
        for (int i = 0; i < n; i++) {
            Student s = new Student(in.next(), in.next(), in.next(), in.nextDouble());
            List<Student> group = byDept.get(s.department);
            if (group == null) {
                group = new ArrayList<>();
                byDept.put(s.department, group);
            }
            group.add(s);
        }

        String largest = null;
        int largestSize = 0;
        for (Map.Entry<String, List<Student>> entry : byDept.entrySet()) {
            List<Student> group = entry.getValue();
            double sum = 0;
            Student top = group.get(0);
            for (Student s : group) {
                sum += s.cgpa;
                if (s.cgpa > top.cgpa) {
                    top = s;
                }
            }
            System.out.printf("%s: %d students, average %.2f, top %s (%.2f)%n",
                    entry.getKey(), group.size(), sum / group.size(), top.name, top.cgpa);
            if (group.size() > largestSize) {
                largestSize = group.size();
                largest = entry.getKey();
            }
        }
        System.out.println("Departments: " + byDept.size());
        System.out.println("Largest: " + (largest == null ? "none" : largest));
    }
}
```

### Explanation
A `Map` stores values under keys; here each department name maps to the list of its
students. The first time a department is seen, `get` returns `null`, so the program
creates a new list and `put`s it into the map; later students are added to that same
list object (the map holds a reference to it). `TreeMap` keeps its keys sorted, so the
departments print alphabetically on every run, unlike `HashMap`, whose order is not
specified. `entrySet()` gives each key together with its value. Because the entries
come in alphabetical order and the size comparison uses `>`, the alphabetically first
department wins a tie for "largest".

### Concepts Practiced
- `Map<String, List<Student>>` (a generic type inside a generic type)
- `TreeMap` for sorted, predictable output
- Grouping with `get` and `put`
- Iterating over `entrySet()`

## Problem 4: One Repository for Every Entity
**Level:** Advanced

### Scenario
The library system stores books and members. Both need the same operations: add
(refusing duplicate IDs), find by ID, remove, and list in some order. Instead of
writing `BookStore` and `MemberStore` separately, the developer writes one generic
`Repository<T>` that works for anything that has an ID.

### Problem Statement
Write an interface `Identifiable` with `String getId()`, classes
`Book implements Identifiable` (`id`, `title`, `year`) and
`Member implements Identifiable` (`id`, `name`, `borrowed` count), and a generic class
`Repository<T extends Identifiable>` with:

- `boolean add(T item)` (false if an item with the same ID exists);
- `T find(String id)` (or `null`);
- `boolean remove(String id)`;
- `List<T> sorted(Comparator<T> order)`: a **new** sorted list; the repository itself
  is not changed;
- `int size()`.

Write comparators as named classes: `BookByYear` (year, then title), `MemberByBorrowed`
(most borrowed first, then ID).

Commands (`n`, then `n` lines):

- `BOOK id year title...` → `Added book <id>` or `Duplicate book <id>`;
- `MEMBER id borrowed name` → `Added member <id>` or `Duplicate member <id>`;
- `FIND id` → searches books first, then members: the item's `toString()` or
  `Not found <id>`;
- `REMOVE id` → `Removed <id>` or `Not found <id>` (books first, then members);
- `LIST` → `Books by year:` then each book, and `Members by activity:` then each member
  (indented by two spaces; `  none` when empty).

`Book.toString()` is `<id> <title> (<year>)`; `Member.toString()` is
`<id> <name>, <borrowed> borrowed`.

### Sample Input
```text
9
BOOK B1 2008 Clean Code
BOOK B2 2004 Head First Java
BOOK B1 2019 Duplicate Entry
MEMBER M1 5 Rafi
MEMBER M2 12 Sadia
MEMBER M3 5 Arif
FIND B2
REMOVE M3
LIST
```

### Sample Output
```text
Added book B1
Added book B2
Duplicate book B1
Added member M1
Added member M2
Added member M3
B2 Head First Java (2004)
Removed M3
Books by year:
  B2 Head First Java (2004)
  B1 Clean Code (2008)
Members by activity:
  M2 Sadia, 12 borrowed
  M1 Rafi, 5 borrowed
```

### Solution
```java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Scanner;

interface Identifiable {
    String getId();
}

class Book implements Identifiable {
    private final String id;
    private final String title;
    private final int year;

    Book(String id, String title, int year) {
        this.id = id;
        this.title = title;
        this.year = year;
    }

    @Override
    public String getId() {
        return id;
    }

    String getTitle() {
        return title;
    }

    int getYear() {
        return year;
    }

    @Override
    public String toString() {
        return id + " " + title + " (" + year + ")";
    }
}

class Member implements Identifiable {
    private final String id;
    private final String name;
    private final int borrowed;

    Member(String id, String name, int borrowed) {
        this.id = id;
        this.name = name;
        this.borrowed = borrowed;
    }

    @Override
    public String getId() {
        return id;
    }

    int getBorrowed() {
        return borrowed;
    }

    @Override
    public String toString() {
        return id + " " + name + ", " + borrowed + " borrowed";
    }
}

class Repository<T extends Identifiable> {
    private final List<T> items = new ArrayList<>();

    boolean add(T item) {
        if (find(item.getId()) != null) {
            return false;
        }
        items.add(item);
        return true;
    }

    T find(String id) {
        for (T item : items) {
            if (item.getId().equals(id)) {
                return item;
            }
        }
        return null;
    }

    boolean remove(String id) {
        T item = find(id);
        if (item == null) {
            return false;
        }
        items.remove(item);
        return true;
    }

    List<T> sorted(Comparator<T> order) {
        List<T> copy = new ArrayList<>(items);
        copy.sort(order);
        return copy;
    }

    int size() {
        return items.size();
    }
}

class BookByYear implements Comparator<Book> {
    @Override
    public int compare(Book a, Book b) {
        if (a.getYear() != b.getYear()) {
            return Integer.compare(a.getYear(), b.getYear());
        }
        return a.getTitle().compareTo(b.getTitle());
    }
}

class MemberByBorrowed implements Comparator<Member> {
    @Override
    public int compare(Member a, Member b) {
        if (a.getBorrowed() != b.getBorrowed()) {
            return Integer.compare(b.getBorrowed(), a.getBorrowed());
        }
        return a.getId().compareTo(b.getId());
    }
}

public class GenericRepository {
    static <T> void printAll(String heading, List<T> items) {
        System.out.println(heading);
        if (items.isEmpty()) {
            System.out.println("  none");
        }
        for (T item : items) {
            System.out.println("  " + item);
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Repository<Book> books = new Repository<>();
        Repository<Member> members = new Repository<>();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("BOOK")) {
                String id = in.next();
                int year = in.nextInt();
                String title = in.nextLine().trim();
                System.out.println(books.add(new Book(id, title, year)) ? "Added book " + id : "Duplicate book " + id);
            } else if (command.equals("MEMBER")) {
                String id = in.next();
                int borrowed = in.nextInt();
                String name = in.next();
                System.out.println(members.add(new Member(id, name, borrowed))
                        ? "Added member " + id : "Duplicate member " + id);
            } else if (command.equals("FIND")) {
                String id = in.next();
                Identifiable found = books.find(id);
                if (found == null) {
                    found = members.find(id);
                }
                System.out.println(found == null ? "Not found " + id : found.toString());
            } else if (command.equals("REMOVE")) {
                String id = in.next();
                boolean removed = books.remove(id) || members.remove(id);
                System.out.println(removed ? "Removed " + id : "Not found " + id);
            } else {
                printAll("Books by year:", books.sorted(new BookByYear()));
                printAll("Members by activity:", members.sorted(new MemberByBorrowed()));
            }
        }
    }
}
```

### Explanation
`Repository<T extends Identifiable>` is written once and used twice, as
`Repository<Book>` and `Repository<Member>`. The bound guarantees that every `T` has
`getId()`, which `add`, `find` and `remove` need. A `Repository<Book>` accepts only
books (adding a `Member` is a compile error), and `find` returns a `Book` with no cast:
that is the type safety generics add. Ordering is not built into the repository; the
caller passes a `Comparator<T>`, so the same class can sort books by year and members by
activity. `sorted` copies the list before sorting, so listing never changes the stored
order. `books.remove(id) || members.remove(id)` only tries members if the book removal
failed, because `||` stops as soon as it has an answer.

### Concepts Practiced
- A generic class with a bounded type parameter
- Interfaces as bounds (`T extends Identifiable`)
- `Comparator<T>` implementations passed as arguments
- Returning a sorted copy instead of changing internal state
