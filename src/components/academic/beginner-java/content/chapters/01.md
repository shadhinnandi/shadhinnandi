# Chapter 01: Java Fundamentals

Every Java program, from a two-line calculator to a large banking system, is built
from the same small pieces: variables that hold values, operators that combine them,
input and output, and simple decisions. This chapter teaches those pieces carefully,
because almost every bug a beginner meets later (wrong averages, strange negative
numbers, a skipped input line) comes from one of them.

**In this chapter you will learn:**

- how variables work, and why Java insists that you give every variable a type
- the 8 primitive types, `String`, literals and constants with `final`
- how values are converted: widening, narrowing casts, integer division
- arithmetic, relational and logical operators, and operator precedence
- how to read input with `Scanner`, including the `nextInt`/`nextLine` trap
- how to format output with `print`, `println`, `printf` and `String.format`
- comments, naming conventions, a first `if`/`else`, and useful `Math` and `String`
  methods

## 1. Concept Explanation

### Variables

A **variable** is a named place in memory that holds a value. The name lets you use
the value later and change it when needed.

In Java every variable has a **type**. The type says what kind of value the variable
can hold (a whole number, a decimal number, a character, text) and therefore which
operations make sense on it. The compiler checks types before the program runs, so
many mistakes are caught early.

```java
int credits;          // declaration: create a variable named credits of type int
credits = 12;         // assignment: store the value 12 in it
int courses = 4;      // declaration and initialization in one line
credits = credits + 3; // read the old value, add 3, store the result (15)
```

A picture of memory after these lines:

```text
  credits            courses
+---------+        +---------+
|   15    |        |    4    |
+---------+        +---------+
   int                int
```

> **Coming from C?** In C, an uninitialized local variable holds a "garbage value".
> Java does not allow that. A local variable must be **definitely assigned** before
> you read it, otherwise the program does not compile:
> `int total; System.out.println(total);` gives the error
> "variable total might not have been initialized".

### The 8 primitive types

Java has exactly 8 **primitive types**. A primitive variable stores the value itself,
directly. Their sizes are the same on every computer, which is part of what makes Java
programs portable.

| Type | Size | Range | Literal example | Typical use |
|---|---|---|---|---|
| `byte` | 8 bits | -128 to 127 | `(byte) 10` | raw data from files or networks |
| `short` | 16 bits | -32,768 to 32,767 | `(short) 500` | rarely used |
| `int` | 32 bits | about -2.1 to 2.1 billion | `42` | the default for whole numbers |
| `long` | 64 bits | about -9.2 to 9.2 × 10^18 | `9_000_000_000L` | very large counts, money in paisa |
| `float` | 32 bits | about ±3.4 × 10^38, ~7 digits | `2.5f` | rarely; memory-sensitive data |
| `double` | 64 bits | about ±1.8 × 10^308, ~15 digits | `3.75` | the default for decimals |
| `char` | 16 bits | `'\u0000'` to `'\uffff'` (0 to 65,535) | `'A'` | one character |
| `boolean` | not a number | `true` or `false` | `true` | conditions and yes/no flags |

Some details worth remembering:

- `int` is always 32 bits and `long` is always 64 bits, on every machine.
- A `char` is a 16-bit UTF-16 code unit. For ordinary letters and digits, one `char`
  is one character. Internally it has a numeric code (`'A'` is 65).
- `boolean` is not a number. You cannot use `0` and `1` as `false` and `true`.
- For whole numbers use `int` unless the value can exceed about 2.1 billion; then use
  `long`. For decimal numbers use `double`.

When a primitive is a **field** of an object (Chapter 04), it gets a default value
(`0`, `0.0`, `false`, or the character with code 0). A **local variable** (declared
inside a method like `main`) gets no default; you must assign it first.

### Literals

A **literal** is a value written directly in the code.

| Literal | Type | Note |
|---|---|---|
| `250` | `int` | whole numbers are `int` by default |
| `250L` | `long` | the `L` suffix makes a `long` (use capital `L`, not `l`) |
| `1_500_000` | `int` | underscores are allowed to make numbers readable |
| `3.75` | `double` | decimal numbers are `double` by default |
| `3.75f` | `float` | the `f` suffix makes a `float` |
| `'R'` | `char` | single quotes, exactly one character |
| `'\n'` | `char` | an escape: newline (also `'\t'` tab, `'\''`, `'\\'`) |
| `true` | `boolean` | also `false` |
| `"Rahim"` | `String` | double quotes, any number of characters |

### String: an object type

`String` is not a primitive. It is a **class** from the Java library, and every piece
of text is a `String` **object**. A `String` variable holds a **reference** to that
object: a value that lets the program reach the object.

```text
  name                      a String object
+--------+         +-------------------------+
|   o----|-------->|  "Nusrat"  length() = 6 |
+--------+         +-------------------------+
 reference
```

Because a `String` is an object, you send it messages by calling methods:
`name.length()`, `name.toUpperCase()`, `name.charAt(0)`.

Strings are **immutable**: once created, a `String` object never changes. A method
like `toUpperCase()` does not change the original; it returns a new `String`.

```java
String city = "Dhaka";
String loud = city.toUpperCase(); // loud is "DHAKA"
// city is still "Dhaka"
```

To compare the **contents** of two strings, always use `equals` (or
`equalsIgnoreCase`). The `==` operator compares references, that is, whether both
variables point to the very same object. Two different objects can hold the same text,
so `==` can say `false` for equal-looking strings, for example when one of them was
typed by the user.

> **Coming from C?** In C, a string is a `char` array ending with `'\0'`, and you use
> `strlen`, `strcpy` and `strcmp`. In Java a `String` is an object that knows its own
> length (`s.length()`), cannot overflow a buffer, and is compared with `s.equals(t)`.

### Constants with `final`

A **constant** is a variable whose value must not change after it is set. Mark it
with `final`. The compiler then rejects any later assignment.

```java
final double VAT_RATE = 0.15;
final int LOAN_DAYS = 14;
// VAT_RATE = 0.10;  // compile error: cannot assign a value to final variable
```

Constants remove "magic numbers" from your code. `price * VAT_RATE` explains itself;
`price * 0.15` does not. If the rate changes, you change one line.

### Naming conventions

Java does not force these rules, but every Java programmer follows them. Code that
breaks them looks wrong to other programmers.

| What | Style | Examples |
|---|---|---|
| variables, methods | `camelCase` | `totalMarks`, `studentName`, `printReceipt` |
| classes | `PascalCase` | `BillSplitter`, `String`, `Scanner` |
| constants | `UPPER_SNAKE_CASE` | `VAT_RATE`, `MAX_CREDITS` |

Also: names may contain letters, digits, `_` and `$`, cannot start with a digit, are
case-sensitive (`total` and `Total` are different), and cannot be keywords such as
`int` or `class`. Prefer meaningful names: `remainingSeats`, not `rs` or `x1`.

### Type conversion

Sometimes a value of one type must be used as another type. Java handles this in two
ways.

**Widening conversion** goes from a smaller type to a larger one. It is automatic,
because the value always fits:

```text
byte --> short --> int --> long --> float --> double
                    ^
         char ------+
```

```java
int marks = 87;
double exact = marks;   // automatic widening: exact is 87.0
long big = marks;       // automatic widening: big is 87
```

(One small catch: `long` to `float` or `double`, and `int` to `float`, are automatic
but can lose precision for very large values.)

**Narrowing conversion** goes from a larger type to a smaller one. Data can be lost,
so Java requires you to write a **cast**: the target type in parentheses.

```java
double price = 99.99;
int taka = (int) price;     // 99: the fraction is cut off, not rounded
byte small = (byte) 200;    // -56: 200 does not fit, so the bits wrap around
```

Casting a `double` to `int` **truncates toward zero**: `(int) 99.99` is `99` and
`(int) -99.99` is `-99`. If you want rounding, use `Math.round(price)`, which returns
a `long` (`100`).

### Integer division

When both operands of `/` are integers, Java does **integer division**: the result is
an integer and the fraction is thrown away.

```java
int total = 17;
int count = 5;
int a = total / count;                  // 3, not 3.4
double b = total / count;               // 3.0: the division already happened in int
double c = (double) total / count;      // 3.4: total becomes 17.0 first
double d = (double) (total / count);    // 3.0: cast applied too late
double e = total / 5.0;                 // 3.4: one double operand is enough
```

The rule: if at least one operand is a `double`, the other is widened to `double`
and the division is real division. A cast binds tighter than `/`, so
`(double) total / count` converts `total` before dividing.

### Integer overflow

An `int` cannot hold values above `2,147,483,647` (`Integer.MAX_VALUE`). If a
calculation goes past it, the result **wraps around silently** to a large negative
number. There is no error or exception.

```java
int max = Integer.MAX_VALUE;
int next = max + 1;     // -2147483648
long safe = max + 1L;   // 2147483648: the addition is done in long
```

If a result may be large (populations, money in paisa, milliseconds), use `long`.

### Converting between text and numbers

Input often arrives as text. To turn text into a number, use the parse methods:

```java
int year = Integer.parseInt("2024");          // 2024
double gpa = Double.parseDouble("3.75");      // 3.75
String text = String.valueOf(42);             // "42"
String alsoText = "" + 42;                    // "42" (concatenation)
```

`Integer.parseInt("abc")` stops the program with a `NumberFormatException`. Handling
that properly is part of Chapter 11.

### Operators

An **operator** combines values (operands) into a new value.

| Group | Operators | Example | Result |
|---|---|---|---|
| arithmetic | `+ - * /` | `7 / 2` | `3` |
| remainder | `%` | `7 % 2` | `1` |
| compound assignment | `+= -= *= /= %=` | `x += 5` | same as `x = x + 5` |
| increment, decrement | `++ --` | `count++` | adds 1 to `count` |
| relational | `< <= > >= == !=` | `marks >= 40` | `true` or `false` |
| logical | `&& \|\| !` | `a > 0 && b > 0` | `true` or `false` |

**Remainder `%`.** `a % b` is what is left after dividing `a` by `b`. It is very
useful: `n % 2 == 0` tests for even numbers, `n % 10` gives the last digit, and
`seconds % 60` gives the leftover seconds. With negative numbers the result takes the
sign of the left operand: `-7 % 3` is `-1`.

**Increment and decrement.** `x++` and `++x` both add 1 to `x`. The difference only
matters inside a larger expression:

```java
int a = 5;
int b = a++;   // postfix: b gets the OLD value 5, then a becomes 6
int c = ++a;   // prefix: a becomes 7 first, then c gets 7
```

To keep code clear, use `++` and `--` as statements on their own line.

**Compound assignment** includes a hidden cast to the variable's type:

```java
int coins = 10;
coins += 2.7;    // compiles: coins = (int) (10 + 2.7), so coins is 12
```

**Logical operators** work only on `boolean` values. `&&` (and) is `true` when both
sides are `true`; `||` (or) is `true` when at least one side is `true`; `!` (not)
flips a value. `&&` and `||` are **short-circuit** operators: if the left side
already decides the answer, the right side is not evaluated. So
`count != 0 && total / count > 50` never divides by zero.

### Precedence: who goes first

**Precedence** decides which operator is applied first in an expression with several
operators. From highest to lowest:

| Priority | Operators | Note |
|---|---|---|
| 1 | `x++` `x--` | postfix |
| 2 | `++x` `--x` `-x` `!x` `(type)` | unary operators and casts |
| 3 | `*` `/` `%` | left to right |
| 4 | `+` `-` | left to right; `+` also joins strings |
| 5 | `<` `<=` `>` `>=` | relational |
| 6 | `==` `!=` | equality |
| 7 | `&&` | logical and |
| 8 | `\|\|` | logical or |
| 9 | `=` `+=` `-=` `*=` `/=` `%=` | assignment, right to left |

```java
int r1 = 2 + 3 * 4;        // 14, because * comes before +
int r2 = (2 + 3) * 4;      // 20, parentheses first
int r3 = 20 - 6 - 4;       // 10, left to right: (20 - 6) - 4
boolean ok = 5 + 2 > 6 && 10 % 4 == 2;  // (7 > 6) && (2 == 2) is true
```

When in doubt, add parentheses. They cost nothing and help the reader.

### Expressions and string concatenation

An **expression** is anything that produces a value: `42`, `price`, `price * qty`,
`name.length() > 3`. Expressions are evaluated using precedence, then left to right.

The `+` operator means "add" for numbers and "join" when either side is a `String`.
Because `+` works left to right, the position of the string matters:

```java
System.out.println("Total: " + 2 + 3);    // Total: 23  (string first, so join, join)
System.out.println(2 + 3 + " items");     // 5 items    (add first, then join)
System.out.println("Total: " + (2 + 3));  // Total: 5   (parentheses first)
System.out.println('A' + 'B');            // 131 (two chars are added as numbers)
System.out.println("" + 'A' + 'B');       // AB
```

### Input with `Scanner`

`Scanner` is a class from the `java.util` package that reads input. You create one
`Scanner` object connected to the keyboard (`System.in`) and ask it for values.

| Method | Reads | Example input | Result |
|---|---|---|---|
| `nextInt()` | the next whole number token | `  42 ` | `42` |
| `nextDouble()` | the next decimal number token | `3.5` | `3.5` |
| `next()` | the next word (up to a space or newline) | `Rahim Uddin` | `"Rahim"` |
| `nextLine()` | the rest of the current line | `Rahim Uddin` | `"Rahim Uddin"` |

`nextInt()`, `nextDouble()` and `next()` skip spaces and newlines before a value and
read one **token** (a group of characters without spaces). `nextLine()` reads
everything up to the end of the line, including spaces, and then moves past the
newline.

**The leftover newline trap.** Suppose the input is a credit count and then a name:

```text
3⏎
Ayesha Siddiqua⏎
```

`nextInt()` reads `3` and stops **just before** the newline. A following
`nextLine()` then reads the rest of that first line, which is empty, and returns
`""`. The name is never read by it.

```text
input:     3  ⏎  A y e s h a   S i d d i q u a ⏎
              ^
              after nextInt(), the reading position is here

nextLine() reads up to the ⏎ right here -> ""   (the trap)
```

The fix: after `nextInt()` (or `nextDouble()`, `next()`), call `in.nextLine()` once
to consume the leftover end of line, then read the real line.

### Output: `print`, `println`, `printf`, `String.format`

- `System.out.print(x)` prints `x` and stays on the same line.
- `System.out.println(x)` prints `x` and then a newline.
- `System.out.printf(format, values...)` prints formatted text. Nothing is added at
  the end, so you write `%n` for a newline.
- `String.format(format, values...)` builds the same formatted text but returns it as
  a `String` instead of printing it.

A **format specifier** starts with `%` and says how to show one value:

| Specifier | Meaning | Example | Output |
|---|---|---|---|
| `%d` | whole number (`int`, `long`) | `printf("%d", 42)` | `42` |
| `%f` | decimal, 6 digits after the point | `printf("%f", 2.5)` | `2.500000` |
| `%.2f` | decimal, 2 digits, rounded | `printf("%.2f", 2.567)` | `2.57` |
| `%s` | text (any value) | `printf("%s", "Rafi")` | `Rafi` |
| `%c` | one character | `printf("%c", 'B')` | `B` |
| `%n` | newline | `printf("Hi%n")` | `Hi` + newline |
| `%5d` | width 5, right-aligned | `printf("[%5d]", 42)` | `[   42]` |
| `%05d` | width 5, padded with zeros | `printf("%05d", 42)` | `00042` |
| `%-10s` | width 10, left-aligned | `printf("[%-10s]", "Mitu")` | `[Mitu      ]` |
| `%8.2f` | width 8, 2 decimals | `printf("[%8.2f]", 3.5)` | `[    3.50]` |
| `%%` | a literal `%` sign | `printf("15%%")` | `15%` |

Widths are how you build neat receipts and tables: every row uses the same widths,
so the columns line up.

> **Coming from C?** `printf` works almost like C's. Differences: use `%f` for both
> `float` and `double` (there is no `%lf`), prefer `%n` over `\n`, and there is no
> `%i`. A mismatch such as `printf("%d", 2.5)` does not print garbage; it stops the
> program with an `IllegalFormatConversionException`.

### Comments

Comments are notes for human readers. The compiler ignores them.

```java
// A single-line comment: everything after // on this line.

/* A block comment.
   It can span several lines. */

/**
 * A documentation comment (Javadoc). It is written just before a class or a
 * method, and the javadoc tool turns it into HTML documentation.
 */
```

Good comments explain **why**, not what. `// 15% VAT is added to every bill` helps;
`// add 1 to i` does not.

### A first decision: `if` / `else`

Programs often need to choose between two actions. An `if` statement runs a block
only when a **condition** (a `boolean` expression) is `true`; the optional `else`
block runs when it is `false`.

```java
if (marks >= 40) {
    System.out.println("Pass");
} else {
    System.out.println("Retake");
}
```

Chapter 02 covers `else if`, nested conditions, `switch` and loops in full. In this
chapter one `if`/`else` at a time is enough.

> **Coming from C?** In C, any number can be a condition (`0` is false). In Java the
> condition must be a `boolean`. `if (count)` does not compile when `count` is an
> `int`; write `if (count != 0)`. This also catches the classic mistake
> `if (x = 5)`, which is a compile error in Java when `x` is an `int`.

### Useful `Math` methods

`Math` is a library class whose methods you call through the class name.

| Method | Meaning | Example | Result |
|---|---|---|---|
| `Math.abs(x)` | absolute value | `Math.abs(-7)` | `7` |
| `Math.max(a, b)` | larger value | `Math.max(3, 9)` | `9` |
| `Math.min(a, b)` | smaller value | `Math.min(3, 9)` | `3` |
| `Math.pow(a, b)` | a to the power b (`double`) | `Math.pow(2, 10)` | `1024.0` |
| `Math.sqrt(x)` | square root (`double`) | `Math.sqrt(49)` | `7.0` |
| `Math.round(x)` | nearest whole number (a `long`) | `Math.round(2.5)` | `3` |
| `Math.ceil(x)` | round up (`double`) | `Math.ceil(4.1)` | `5.0` |
| `Math.floor(x)` | round down (`double`) | `Math.floor(4.9)` | `4.0` |
| `Math.PI` | the constant pi | `Math.PI` | `3.14159...` |

### Useful `String` methods

Characters in a `String` are numbered from **0**:

```text
 "Dhaka"
  D   h   a   k   a
  0   1   2   3   4      length() = 5, last index = 4
```

| Method | Meaning | Example (`s = "Dhaka"`) | Result |
|---|---|---|---|
| `length()` | number of characters | `s.length()` | `5` |
| `charAt(i)` | the character at index `i` | `s.charAt(1)` | `'h'` |
| `toUpperCase()` | upper-case copy | `s.toUpperCase()` | `"DHAKA"` |
| `toLowerCase()` | lower-case copy | `s.toLowerCase()` | `"dhaka"` |
| `substring(b)` | from index `b` to the end | `s.substring(2)` | `"aka"` |
| `substring(b, e)` | from `b` up to, not including, `e` | `s.substring(1, 4)` | `"hak"` |
| `indexOf(t)` | first position of `t`, or `-1` | `s.indexOf("ak")` | `2` |
| `equals(t)` | same contents? | `s.equals("dhaka")` | `false` |
| `equalsIgnoreCase(t)` | same, ignoring case | `s.equalsIgnoreCase("dhaka")` | `true` |
| `trim()` | copy without spaces at both ends | `"  hi ".trim()` | `"hi"` |

A wrong index, such as `s.charAt(5)` here, stops the program with a
`StringIndexOutOfBoundsException`.

## 2. Syntax

### Declaring variables and constants

```java
int seats = 40;                 // type name = value;
double fare = 25.50;
char section = 'C';
boolean isOpen = true;
String driver = "Karim";
final int MAX_PASSENGERS = 45;  // a constant: final + UPPER_SNAKE_CASE
long route = 10L, stop = 3L;    // allowed, but one declaration per line is clearer
```

The pattern is `type name = initialValue;`. The type comes first, then the name. The
initial value is optional for a declaration, but the variable must get a value before
it is read.

### Casting

```java
double average = 72.8;
int rounded = (int) Math.round(average);  // 73: Math.round returns long, cast to int
int truncated = (int) average;            // 72: fraction removed
double ratio = (double) 7 / 2;            // 3.5: 7 becomes 7.0 before dividing
char next = (char) ('A' + 1);             // 'B': 'A' + 1 is the int 66
```

A cast is written `(targetType) expression`. It applies to the operand right after
it, so put the expression in parentheses when you mean "cast the whole result".

### Operators in statements

```java
int total = 0;
total += 50;          // total = total + 50
total -= 10;          // 40
total *= 3;           // 120
total /= 7;           // 17 (integer division)
total %= 5;           // 2
total++;              // 3
boolean even = total % 2 == 0;            // false
boolean inRange = total >= 1 && total <= 10;  // true
boolean notEven = !even;                  // true
```

### Reading input with `Scanner`

```java
import java.util.Scanner;   // at the top of the file, before the class

Scanner in = new Scanner(System.in);  // one Scanner per program
int credits = in.nextInt();
double fee = in.nextDouble();
String code = in.next();      // one word
in.nextLine();                // consume the rest of the current line
String fullName = in.nextLine();  // a whole line with spaces
```

Create one `Scanner` per program and reuse it. Programs in this course read input
without printing prompts when the output must match exactly; in your own programs you
can print a prompt with `System.out.println("Enter credits:")` before reading.

### Formatted output

```java
String name = "Fahim";
double cgpa = 3.456;
int credits = 96;
System.out.printf("%-8s|%6.2f|%4d%n", name, cgpa, credits);
// prints: Fahim   |  3.46|  96

String line = String.format("%s has %d credits", name, credits);
System.out.println(line);   // Fahim has 96 credits
```

The values after the format string fill the specifiers in order: the first value
goes to the first `%`, and so on.

### `if` / `else`

```java
if (condition) {
    // runs when condition is true
} else {
    // runs when condition is false
}
```

The condition must be a `boolean` expression and must be in parentheses. Always use
braces, even for a single statement; it prevents errors when you add lines later.

## 3. Worked Examples

All examples are complete programs. Save each in a file named after its class (for
example `StudentRecord.java`), compile with `javac StudentRecord.java`, and run with
`java StudentRecord`.

### Example 1: Student Record Card

**Problem:** Store information about one student (name, ID, trimester, credits,
library card number, attendance, CGPA, section, hostel status) in variables of
suitable types and print a small record card, including how many credits are left
before the trimester limit.

The approach: pick a type for each piece of data, use `final` constants for fixed
rules, and print each line with `println` and string concatenation.

```java
public class StudentRecord {
    public static void main(String[] args) {
        final int MAX_CREDITS = 15;
        final double MIN_GOOD_CGPA = 3.00;

        String name = "Nusrat Jahan";
        int studentId = 220145;
        byte trimester = 4;
        short creditsTaken = 12;
        long libraryCard = 9_800_000_123L;
        float attendance = 92.5f;
        double cgpa = 3.67;
        char section = 'B';
        boolean livesInHostel = true;

        int creditsLeft = MAX_CREDITS - creditsTaken;
        boolean goodStanding = cgpa >= MIN_GOOD_CGPA;

        System.out.println("Name         : " + name);
        System.out.println("Student ID   : " + studentId);
        System.out.println("Trimester    : " + trimester + ", Section " + section);
        System.out.println("Library card : " + libraryCard);
        System.out.println("Attendance   : " + attendance + "%");
        System.out.println("CGPA         : " + cgpa);
        System.out.println("Hostel       : " + livesInHostel);
        System.out.println("Credits left : " + creditsLeft + " of " + MAX_CREDITS);
        System.out.println("Good standing: " + goodStanding);
    }
}
```

**Output:**

```text
Name         : Nusrat Jahan
Student ID   : 220145
Trimester    : 4, Section B
Library card : 9800000123
Attendance   : 92.5%
CGPA         : 3.67
Hostel       : true
Credits left : 3 of 15
Good standing: true
```

**Why it works:** Each variable has a type that matches its data. The library card
number is too large for `int`, so it is a `long` with the `L` suffix. `byte` and
`short` are used here only so you see them once; in normal code `int` is the usual
choice. `MAX_CREDITS - creditsTaken` mixes `int` and `short`; the `short` is widened
and the result is an `int`. The comparison `cgpa >= MIN_GOOD_CGPA` produces a
`boolean`, which `println` shows as `true`.

### Example 2: Exam Timer

**Problem:** An online exam page stores the remaining time as a number of seconds.
Read that number and show it as `HH:MM:SS`, in whole minutes, and in hours with two
decimal places.

The approach: an hour has 3600 seconds and a minute has 60. Integer division `/`
gives "how many whole units fit", and `%` gives "what is left over".

```java
import java.util.Scanner;

public class ExamTimer {
    public static void main(String[] args) {
        final int SECONDS_PER_MINUTE = 60;
        final int SECONDS_PER_HOUR = 3600;
        Scanner in = new Scanner(System.in);

        int totalSeconds = in.nextInt();

        int hours = totalSeconds / SECONDS_PER_HOUR;
        int leftAfterHours = totalSeconds % SECONDS_PER_HOUR;
        int minutes = leftAfterHours / SECONDS_PER_MINUTE;
        int seconds = leftAfterHours % SECONDS_PER_MINUTE;

        double exactHours = (double) totalSeconds / SECONDS_PER_HOUR;

        System.out.println("Seconds left : " + totalSeconds);
        System.out.printf("Clock        : %02d:%02d:%02d%n", hours, minutes, seconds);
        System.out.println("Whole minutes: " + totalSeconds / SECONDS_PER_MINUTE);
        System.out.printf("Hours        : %.2f%n", exactHours);
    }
}
```

**Input:**

```text
7385
```

**Output:**

```text
Seconds left : 7385
Clock        : 02:03:05
Whole minutes: 123
Hours        : 2.05
```

**Why it works:** `7385 / 3600` is `2` (whole hours) and `7385 % 3600` is `185`
seconds left over. Then `185 / 60` is `3` minutes and `185 % 60` is `5` seconds. The
specifier `%02d` prints at least two digits, padding with a zero, so `3` appears as
`03`. For the hours line, the `(double)` cast makes the division real division:
`7385.0 / 3600` is `2.0513...`, which `%.2f` rounds to `2.05`.

### Example 3: Casting and Overflow Lab

**Problem:** Write a program that demonstrates, with real values, what happens in
widening conversions, narrowing casts, integer division, `char` arithmetic, parsing
and integer overflow.

Each line prints an expression next to its result, so you can compare what you
expected with what Java does.

```java
public class CastingLab {
    public static void main(String[] args) {
        int marks = 87;
        double marksAsDouble = marks;
        System.out.println("int 87 widened to double : " + marksAsDouble);

        double price = 99.99;
        System.out.println("(int) 99.99              : " + (int) price);
        System.out.println("(int) -99.99             : " + (int) -price);
        System.out.println("Math.round(99.99)        : " + Math.round(price));

        int big = 200;
        System.out.println("(byte) 200               : " + (byte) big);

        int total = 17;
        int count = 5;
        System.out.println("17 / 5                   : " + total / count);
        System.out.println("17 % 5                   : " + total % count);
        System.out.println("(double) 17 / 5          : " + (double) total / count);
        System.out.println("(double) (17 / 5)        : " + (double) (total / count));

        char grade = 'A';
        System.out.println("'A' + 1                  : " + (grade + 1));
        System.out.println("(char) ('A' + 1)         : " + (char) (grade + 1));

        int year = Integer.parseInt("2024");
        System.out.println("parseInt(\"2024\") + 1     : " + (year + 1));

        int max = Integer.MAX_VALUE;
        System.out.println("Integer.MAX_VALUE        : " + max);
        System.out.println("MAX_VALUE + 1 (int)      : " + (max + 1));
        System.out.println("MAX_VALUE + 1L (long)    : " + (max + 1L));
    }
}
```

**Output:**

```text
int 87 widened to double : 87.0
(int) 99.99              : 99
(int) -99.99             : -99
Math.round(99.99)        : 100
(byte) 200               : -56
17 / 5                   : 3
17 % 5                   : 2
(double) 17 / 5          : 3.4
(double) (17 / 5)        : 3.0
'A' + 1                  : 66
(char) ('A' + 1)         : B
parseInt("2024") + 1     : 2025
Integer.MAX_VALUE        : 2147483647
MAX_VALUE + 1 (int)      : -2147483648
MAX_VALUE + 1L (long)    : 2147483648
```

**Why it works:** Widening happens silently (`87` becomes `87.0`). A cast to `int`
cuts off the fraction toward zero, while `Math.round` rounds. `(byte) 200` keeps only
the lowest 8 bits, and as a signed byte those bits mean `-56`. With two `int`
operands, `/` is integer division; the cast must come before the division to help.
`'A' + 1` is an `int` (`66`) because `char` is widened in arithmetic; casting back to
`char` gives `'B'`. Note the parentheses in `(year + 1)` and `(max + 1)`: without
them, `+` would join strings instead of adding. Finally, `int` overflow wraps to the
most negative value without any error, while doing the sum in `long` gives the right
answer.

### Example 4: Course Registration Slip

**Problem:** Read a number of credits, a student's full name (first and last name
separated by one space), a course title, and a course code such as `cse1115`. Print a
registration slip that shows the initials, the last name, the code in upper case, the
department and number taken from the code, and whether it is a CSE course.

The input mixes numbers and whole lines, so this example must avoid the leftover
newline trap. The rest uses `String` methods to take the text apart.

```java
import java.util.Scanner;

public class RegistrationSlip {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        int credits = in.nextInt();
        in.nextLine();                        // consume the rest of the first line
        String fullName = in.nextLine();
        String courseTitle = in.nextLine();
        String code = in.next();

        int space = fullName.indexOf(" ");
        String lastName = fullName.substring(space + 1);
        String initials = "" + fullName.charAt(0) + fullName.charAt(space + 1);

        String upperCode = code.toUpperCase();
        String dept = upperCode.substring(0, 3);
        int courseNumber = Integer.parseInt(code.substring(3));
        int level = courseNumber / 1000;
        boolean isCse = dept.equalsIgnoreCase("cse");

        System.out.println("=== Registration Slip ===");
        System.out.printf("%-10s: %s (%s)%n", "Student", fullName, initials);
        System.out.printf("%-10s: %s%n", "Last name", lastName.toUpperCase());
        System.out.printf("%-10s: %s - %s%n", "Course", upperCode, courseTitle);
        System.out.printf("%-10s: %s, number %d, level %d%n", "Details",
                dept, courseNumber, level);
        System.out.printf("%-10s: %d%n", "Credits", credits);
        System.out.printf("%-10s: %d characters%n", "Title", courseTitle.length());
        System.out.println("CSE course? " + isCse);
    }
}
```

**Input:**

```text
3
Ayesha Siddiqua
Object Oriented Programming
cse1115
```

**Output:**

```text
=== Registration Slip ===
Student   : Ayesha Siddiqua (AS)
Last name : SIDDIQUA
Course    : CSE1115 - Object Oriented Programming
Details   : CSE, number 1115, level 1
Credits   : 3
Title     : 27 characters
CSE course? true
```

**Why it works:** After `nextInt()` reads `3`, the extra `in.nextLine()` throws away
the empty rest of that line, so the next `nextLine()` reads the name. `indexOf(" ")`
finds the space (index 6); the last name starts one position later. The initials
start with `""` so that `+` joins the two `char` values as text; without it,
`'A' + 'S'` would be the number 148. `substring(0, 3)` takes indexes 0, 1, 2 of the
code, and `Integer.parseInt` turns the remaining text `"1115"` into a number that can
be divided: `1115 / 1000` is `1`. A long `printf` call can be split across lines
after a comma.

### Example 5: Canteen Bill Splitter

**Problem:** A group of friends eats at the campus canteen. Read the number of
friends, the bill in Tk (with paisa), and a tip percentage. Print a neat receipt with
the tip, the total and the exact share per person. Since nobody carries paisa coins,
also show each person's share rounded **up** to whole taka and how much extra that
collects.

The approach: compute with `double`, format every amount with the same width, and use
`Math.ceil` plus a cast for the rounded share.

```java
import java.util.Scanner;

public class BillSplitter {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int friends = in.nextInt();
        double bill = in.nextDouble();
        int tipPercent = in.nextInt();

        double tip = bill * tipPercent / 100.0;
        double total = bill + tip;
        double exactShare = total / friends;
        int roundedShare = (int) Math.ceil(exactShare);
        int collected = roundedShare * friends;
        double extra = collected - total;

        String tipLabel = String.format("Tip (%d%%)", tipPercent);

        System.out.println("---- Canteen Receipt ----");
        System.out.printf("%-12s%10.2f Tk%n", "Bill", bill);
        System.out.printf("%-12s%10.2f Tk%n", tipLabel, tip);
        System.out.printf("%-12s%10.2f Tk%n", "Total", total);
        System.out.printf("%-12s%10d%n", "Friends", friends);
        System.out.printf("%-12s%10.2f Tk%n", "Exact share", exactShare);
        System.out.printf("%-12s%10d Tk%n", "Each pays", roundedShare);
        System.out.printf("%-12s%10.2f Tk%n", "Extra", extra);
    }
}
```

**Input:**

```text
4 1250.50 10
```

**Output:**

```text
---- Canteen Receipt ----
Bill           1250.50 Tk
Tip (10%)       125.05 Tk
Total          1375.55 Tk
Friends              4
Exact share     343.89 Tk
Each pays          344 Tk
Extra             0.45 Tk
```

**Why it works:** `nextInt()` and `nextDouble()` read tokens, so the three values can
be on one line. Dividing by `100.0` (a `double`) keeps the tip from being cut by
integer division. `Math.ceil(343.8875)` returns `344.0` as a `double`, and the
`(int)` cast turns it into `344` for the `%d` specifier. `String.format` builds the
label `Tip (10%)`; `%%` produces the percent sign. Every row uses `%-12s` for the
label and width 10 for the number, so the columns line up.

### Example 6: Library Fine Check

**Problem:** The campus library lends books for 14 days. A late book costs 5 Tk per
day, but the fine never exceeds 100 Tk. A student may borrow another book only if
they owe no fine and have fewer than 3 books on loan. Read the number of days a book
was kept and the number of books currently on loan, then report the fine and
whether another book can be borrowed. (These rules are invented for practice.)

The approach: compute late days and the capped fine with `Math.max` and `Math.min`,
then use `if`/`else` to choose the messages.

```java
import java.util.Scanner;

public class LibraryFine {
    public static void main(String[] args) {
        final int LOAN_DAYS = 14;
        final int FINE_PER_DAY = 5;
        final int MAX_FINE = 100;
        final int MAX_BOOKS = 3;
        Scanner in = new Scanner(System.in);

        int daysKept = in.nextInt();
        int booksOnLoan = in.nextInt();

        int daysLate = Math.max(0, daysKept - LOAN_DAYS);
        int fine = Math.min(daysLate * FINE_PER_DAY, MAX_FINE);

        if (daysLate > 0) {
            System.out.println("Late by " + daysLate + " day(s). Fine: " + fine + " Tk");
        } else {
            System.out.println("Returned on time. No fine.");
        }

        boolean canBorrow = fine == 0 && booksOnLoan < MAX_BOOKS;
        if (canBorrow) {
            System.out.println("You may borrow another book.");
        } else {
            System.out.println("Borrowing blocked: clear the fine or return a book.");
        }
    }
}
```

**Input:**

```text
35 1
```

**Output:**

```text
Late by 21 day(s). Fine: 100 Tk
Borrowing blocked: clear the fine or return a book.
```

**Why it works:** `daysKept - LOAN_DAYS` is `21`; `Math.max(0, ...)` would turn a
negative value (an early return) into `0`. `21 * 5` is `105`, and `Math.min` caps it
at `100`. The first `if` checks a relational condition. The second condition joins
two comparisons with `&&`: both must be true. Here `fine == 0` is already `false`, so
`&&` short-circuits and the right side is not even evaluated. Try the input `10 1`:
the program prints `Returned on time. No fine.` and allows borrowing.

## Common Mistakes

- **Integer division by accident.** `double avg = sum / 3;` with an `int` `sum` gives
  a whole number. Write `sum / 3.0` or `(double) sum / 3`.
- **Expecting `(int)` to round.** `(int) 2.99` is `2`. Use `Math.round` to round.
- **Forgetting the leftover newline.** `nextInt()` followed by `nextLine()` returns
  an empty string. Add one `in.nextLine()` in between.
- **Comparing strings with `==`.** Use `s.equals(t)` or `s.equalsIgnoreCase(t)`.
- **String joining instead of adding.** `"Sum: " + a + b` joins the digits. Write
  `"Sum: " + (a + b)`.
- **Missing `L` on big literals.** `long n = 3000000000;` does not compile; the
  literal is too big for `int`. Write `3_000_000_000L`.
- **Overflow in `int`.** Multiplying large `int` values silently wraps around. Use
  `long` when results can exceed about 2.1 billion.
- **Using `%d` for a `double` in `printf`.** It throws an exception at runtime. Use
  `%f` or `%.2f`, and `%d` only for whole numbers.
- **Off-by-one in `substring`.** The end index is not included:
  `"Dhaka".substring(0, 3)` is `"Dha"`.

## Summary

- A variable has a name, a type and a value; local variables must be assigned before
  they are read, so Java never shows garbage values.
- Java has 8 primitive types with fixed sizes; use `int` and `double` by default,
  `long` for very large whole numbers, `char` for one character, `boolean` for
  `true`/`false`.
- `String` is an immutable object type; call methods on it and compare contents with
  `equals`.
- `final` makes a constant; name constants in `UPPER_SNAKE_CASE`, variables in
  `camelCase` and classes in `PascalCase`.
- Widening is automatic; narrowing needs a cast and can lose data. Two `int`
  operands make `/` an integer division; `int` overflow wraps around silently.
- Precedence decides the order of operators; `+` joins strings when either side is a
  `String`; parentheses make intent clear.
- `Scanner` reads tokens with `nextInt`, `nextDouble`, `next` and whole lines with
  `nextLine`; consume the leftover newline when mixing them.
- `printf` and `String.format` use specifiers such as `%d`, `%.2f`, `%s`, `%-10s`,
  `%5d` and `%n` to produce aligned, readable output.
- An `if`/`else` chooses between two actions using a `boolean` condition.
