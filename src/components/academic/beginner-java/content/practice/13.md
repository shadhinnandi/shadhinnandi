# Practice Problems: Generic Programming

These problems practise generic classes, generic methods, bounds, wildcards, the
generic collections and `Comparable`/`Comparator`. Programs read input without prompts
and print exactly the sample output.

## Problem 1: Generic Locker Box
**Level:** Basic

### Problem Statement
Write a generic class `Box<T>` that holds at most one item. It has three methods:
`isEmpty()`, `get()` and `replace(T newItem)`, which stores the new item and returns
the item that was in the box before (`null` if the box was empty).

The program reads a locker number (an integer) on the first line and stores it in a
`Box<Integer>`. The next line has an integer `n`, followed by `n` lines, each the name
of an item (it may contain spaces). Each item is put into a `Box<String>` with
`replace`. Print `Locker <number>` first. For every item print
`Put <item> (locker was empty)` or `Put <item> (took out <old item>)`. At the end print
`Now holding: <item>`, or `Locker is empty` when `n` is 0.

### Sample Input
```text
17
3
umbrella
laptop
water bottle
```

### Sample Output
```text
Locker 17
Put umbrella (locker was empty)
Put laptop (took out umbrella)
Put water bottle (took out laptop)
Now holding: water bottle
```

### Solution
```java
import java.util.Scanner;

class Box<T> {
    private T item;

    boolean isEmpty() {
        return item == null;
    }

    T get() {
        return item;
    }

    T replace(T newItem) {
        T old = item;
        item = newItem;
        return old;
    }
}

public class LockerBox {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Box<Integer> numberBox = new Box<>();
        numberBox.replace(in.nextInt());
        int n = in.nextInt();
        in.nextLine();

        System.out.println("Locker " + numberBox.get());
        Box<String> itemBox = new Box<>();
        for (int i = 0; i < n; i++) {
            String item = in.nextLine();
            String old = itemBox.replace(item);
            if (old == null) {
                System.out.println("Put " + item + " (locker was empty)");
            } else {
                System.out.println("Put " + item + " (took out " + old + ")");
            }
        }
        if (itemBox.isEmpty()) {
            System.out.println("Locker is empty");
        } else {
            System.out.println("Now holding: " + itemBox.get());
        }
    }
}
```

### Explanation
`Box<T>` is written once and used twice: as `Box<Integer>` for the locker number and as
`Box<String>` for the items. `replace` returns a `T`, so for the item box it returns a
`String` directly, with no cast. `numberBox.replace(in.nextInt())` autoboxes the `int`
into an `Integer`. Returning `null` for "nothing was there" works because a type
argument is always a reference type. The leftover newline after `nextInt()` is consumed
before reading item names with `nextLine()`.

## Problem 2: Course Credit Pairs
**Level:** Basic

### Problem Statement
Write a generic class `Pair<A, B>` with `getFirst()`, `getSecond()` and a `toString()`
that returns `(<first>, <second>)`. Also write a generic static method
`static <A, B> Pair<B, A> swap(Pair<A, B> p)` that returns a new pair with the two parts
in the other order.

Read an integer `n`, then `n` lines, each a course code and its credits
(`CSE1115 3`). Store each line as a `Pair<String, Integer>` in a
`List<Pair<String, Integer>>`. For every pair print `<pair> swapped: <swapped pair>`.
Finally print `Total credits: <sum>`.

### Sample Input
```text
3
CSE1115 3
MAT2107 3
CSE1116 1
```

### Sample Output
```text
(CSE1115, 3) swapped: (3, CSE1115)
(MAT2107, 3) swapped: (3, MAT2107)
(CSE1116, 1) swapped: (1, CSE1116)
Total credits: 7
```

### Solution
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

class Pair<A, B> {
    private final A first;
    private final B second;

    Pair(A first, B second) {
        this.first = first;
        this.second = second;
    }

    A getFirst() {
        return first;
    }

    B getSecond() {
        return second;
    }

    @Override
    public String toString() {
        return "(" + first + ", " + second + ")";
    }
}

public class CreditPairs {
    static <A, B> Pair<B, A> swap(Pair<A, B> p) {
        return new Pair<>(p.getSecond(), p.getFirst());
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        List<Pair<String, Integer>> courses = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            String code = in.next();
            int credits = in.nextInt();
            courses.add(new Pair<>(code, credits));
        }

        int total = 0;
        for (Pair<String, Integer> course : courses) {
            Pair<Integer, String> swapped = swap(course);
            System.out.println(course + " swapped: " + swapped);
            total += course.getSecond();
        }
        System.out.println("Total credits: " + total);
    }
}
```

### Explanation
`Pair<A, B>` has two independent type parameters. The generic method `swap` declares
its own `<A, B>` before the return type; for `swap(course)` the compiler infers
`A = String` and `B = Integer`, so the result type is `Pair<Integer, String>`. The list
type `List<Pair<String, Integer>>` shows that type arguments can themselves be generic
types. `total += course.getSecond()` unboxes the `Integer` credits.

## Problem 3: Generic Search in Any List
**Level:** Basic

### Problem Statement
Write two generic static methods:

- `static <T> int firstIndexOf(List<T> items, T target)`
- `static <T> int lastIndexOf(List<T> items, T target)`

Each returns the index (0-based) of the first or last element equal to `target`, or
`-1` if there is none. Compare elements with `equals`, not `==`.

Input: an integer `n` and `n` words on the next line, then a target word; then an
integer `m` and `m` integers on the next line, then a target integer. For each target
print `<target>: first at index <i>, last at index <j>`, or `<target>: not found`.

### Sample Input
```text
6
rice dal egg rice tea dal
dal
5
1200 750 1500 750 300
750
```

### Sample Output
```text
dal: first at index 1, last at index 5
750: first at index 1, last at index 3
```

### Solution
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class GenericSearch {
    static <T> int firstIndexOf(List<T> items, T target) {
        for (int i = 0; i < items.size(); i++) {
            if (items.get(i).equals(target)) {
                return i;
            }
        }
        return -1;
    }

    static <T> int lastIndexOf(List<T> items, T target) {
        for (int i = items.size() - 1; i >= 0; i--) {
            if (items.get(i).equals(target)) {
                return i;
            }
        }
        return -1;
    }

    static <T> void report(List<T> items, T target) {
        int first = firstIndexOf(items, target);
        if (first == -1) {
            System.out.println(target + ": not found");
        } else {
            int last = lastIndexOf(items, target);
            System.out.println(target + ": first at index " + first
                    + ", last at index " + last);
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        List<String> foods = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            foods.add(in.next());
        }
        String food = in.next();

        int m = in.nextInt();
        List<Integer> prices = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            prices.add(in.nextInt());
        }
        int price = in.nextInt();

        report(foods, food);
        report(prices, price);
    }
}
```

### Explanation
The same three methods search a `List<String>` and a `List<Integer>`; `T` is inferred
at each call. `equals` is essential: the prices 750 are stored as two different
`Integer` objects, and `==` would compare references. It might even seem to work for
small numbers, because Java caches `Integer` objects from -128 to 127, and then fail for
values like 750. `report(prices, price)` autoboxes `price` so that it matches `T`.

## Problem 4: Bounded Maximum and Minimum
**Level:** Basic

### Problem Statement
Write two generic static methods with a bound:

- `static <T extends Comparable<T>> T maxOf(List<T> items)`
- `static <T extends Comparable<T>> T minOf(List<T> items)`

(Both lists in this problem are non-empty.) Read an integer `n` and `n` daily
temperatures (integers), then an integer `m` and `m` student names (one word each).
Print the highest and lowest temperature and the alphabetically last and first name,
in the format of the sample.

### Sample Input
```text
5
31 28 35 29 35
4
Imran Mitu Arif Sadia
```

### Sample Output
```text
Highest temperature: 35
Lowest temperature: 28
Last name: Sadia
First name: Arif
```

### Solution
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class BoundedMaxMin {
    static <T extends Comparable<T>> T maxOf(List<T> items) {
        T best = items.get(0);
        for (T item : items) {
            if (item.compareTo(best) > 0) {
                best = item;
            }
        }
        return best;
    }

    static <T extends Comparable<T>> T minOf(List<T> items) {
        T best = items.get(0);
        for (T item : items) {
            if (item.compareTo(best) < 0) {
                best = item;
            }
        }
        return best;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        List<Integer> temps = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            temps.add(in.nextInt());
        }
        int m = in.nextInt();
        List<String> names = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            names.add(in.next());
        }

        System.out.println("Highest temperature: " + maxOf(temps));
        System.out.println("Lowest temperature: " + minOf(temps));
        System.out.println("Last name: " + maxOf(names));
        System.out.println("First name: " + minOf(names));
    }
}
```

### Explanation
Without the bound, `item.compareTo(best)` would not compile, because a plain `T` only
has `Object` methods. `<T extends Comparable<T>>` promises that every `T` can be
compared with another `T`. `Integer` and `String` both implement their own
`Comparable`, so the methods work for both lists, and calling `maxOf` with a list of a
non-comparable class would be rejected by the compiler.

## Problem 5: Registered Courses Without Duplicates
**Level:** Basic

### Problem Statement
A student types course codes for registration, sometimes twice and in mixed case.
Read an integer `n` and `n` course codes. Convert each code to upper case and add it to
a `Set<String>` implemented by a `TreeSet`. When a code is already in the set, print
`Duplicate ignored: <CODE>`. Then print `Registered <k> courses:` followed by the codes
in sorted order, one per line.

### Sample Input
```text
7
cse1115 MAT2107 CSE1115 phy1101 mat2107 ENG1011 CSE1116
```

### Sample Output
```text
Duplicate ignored: CSE1115
Duplicate ignored: MAT2107
Registered 5 courses:
CSE1115
CSE1116
ENG1011
MAT2107
PHY1101
```

### Solution
```java
import java.util.Scanner;
import java.util.Set;
import java.util.TreeSet;

public class UniqueCourses {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        Set<String> courses = new TreeSet<>();
        for (int i = 0; i < n; i++) {
            String code = in.next().toUpperCase();
            boolean added = courses.add(code);
            if (!added) {
                System.out.println("Duplicate ignored: " + code);
            }
        }
        System.out.println("Registered " + courses.size() + " courses:");
        for (String code : courses) {
            System.out.println(code);
        }
    }
}
```

### Explanation
A `Set` never holds two equal elements. `add` returns `false` when the element was
already present, which is exactly the duplicate test we need, with no extra search.
The variable has the interface type `Set<String>`; the object is a `TreeSet`, which
keeps its elements sorted, so the final loop prints the codes in alphabetical order.
A `HashSet` would also remove duplicates, but its loop order is not predictable.

## Problem 6: Bracket Checker with a Generic Stack
**Level:** Intermediate

### Problem Statement
Write a generic class `Stack<E>` backed by an `ArrayList<E>` with `push`, `pop`,
`peek`, `isEmpty` and `size`. Use a `Stack<Character>` to check the brackets
`()`, `[]` and `{}` in expressions. Other characters are ignored.

Read an integer `n`, then `n` lines, each an expression (it may contain spaces).
Scan each expression from left to right (positions start at 1):

- an opening bracket is pushed;
- a closing bracket with an empty stack: print `<expr> -> unexpected <c> at position <p>`;
- a closing bracket that does not match the top: print
  `<expr> -> mismatch at position <p>`;
- after the scan, if `k` brackets are still open: print
  `<expr> -> missing <k> closing bracket(s)`;
- otherwise print `<expr> -> balanced`.

Stop checking an expression at its first error.

### Sample Input
```text
5
(a+b)*[c-d]
{[(x)] + y}
(a+b]
((x)
a) + (b
```

### Sample Output
```text
(a+b)*[c-d] -> balanced
{[(x)] + y} -> balanced
(a+b] -> mismatch at position 5
((x) -> missing 1 closing bracket(s)
a) + (b -> unexpected ) at position 2
```

### Solution
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

class Stack<E> {
    private final List<E> items = new ArrayList<>();

    void push(E item) {
        items.add(item);
    }

    E pop() {
        return items.remove(items.size() - 1);
    }

    E peek() {
        return items.get(items.size() - 1);
    }

    boolean isEmpty() {
        return items.isEmpty();
    }

    int size() {
        return items.size();
    }
}

public class BracketChecker {
    static boolean matches(char open, char close) {
        return (open == '(' && close == ')')
                || (open == '[' && close == ']')
                || (open == '{' && close == '}');
    }

    static String check(String expr) {
        Stack<Character> open = new Stack<>();
        for (int i = 0; i < expr.length(); i++) {
            char c = expr.charAt(i);
            if (c == '(' || c == '[' || c == '{') {
                open.push(c);
            } else if (c == ')' || c == ']' || c == '}') {
                if (open.isEmpty()) {
                    return "unexpected " + c + " at position " + (i + 1);
                }
                char top = open.pop();
                if (!matches(top, c)) {
                    return "mismatch at position " + (i + 1);
                }
            }
        }
        if (!open.isEmpty()) {
            return "missing " + open.size() + " closing bracket(s)";
        }
        return "balanced";
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        in.nextLine();
        for (int i = 0; i < n; i++) {
            String expr = in.nextLine();
            System.out.println(expr + " -> " + check(expr));
        }
    }
}
```

### Explanation
- `Stack<E>` stores elements in an `ArrayList<E>` because `new E[...]` is not allowed
  (type erasure). The top is the end of the list.
- The type argument is `Character`, not `char`: `open.push(c)` autoboxes the `char`,
  and `char top = open.pop()` unboxes it.
- The method checks `isEmpty()` before `pop()`, so the stack never has to deal with
  the empty case itself.
- `check` returns at the first error, which keeps the main loop simple: it only prints
  the expression and the verdict.

## Problem 7: Canteen Token Queue
**Level:** Intermediate

### Problem Statement
Write a generic first-in, first-out queue `LinkedQueue<E>` built from linked nodes
(not from a library collection). Use a private static nested class `Node<T>` with a
value and a reference to the next node. The queue keeps references to the `head`
(front) and `tail` (back) and a size, and offers `enqueue(E)`, `dequeue()`, `peek()`,
`isEmpty()` and `size()`.

The canteen uses a `LinkedQueue<String>`. Read an integer `n`, then `n` commands:

- `JOIN <name>`: add the name; print `<name> joined (position <size>)`.
- `SERVE`: remove the front name; print `Served <name>`, or `No one to serve`.
- `PEEK`: print `Next: <name>`, or `No one waiting`.
- `SIZE`: print `Waiting: <size>`.

### Sample Input
```text
9
JOIN Rahim
JOIN Karim
JOIN Mitu
SERVE
PEEK
SIZE
SERVE
SERVE
SERVE
```

### Sample Output
```text
Rahim joined (position 1)
Karim joined (position 2)
Mitu joined (position 3)
Served Rahim
Next: Karim
Waiting: 2
Served Karim
Served Mitu
No one to serve
```

### Solution
```java
import java.util.Scanner;

class LinkedQueue<E> {
    private static class Node<T> {
        private final T value;
        private Node<T> next;

        Node(T value) {
            this.value = value;
        }
    }

    private Node<E> head;
    private Node<E> tail;
    private int size;

    void enqueue(E value) {
        Node<E> node = new Node<>(value);
        if (tail == null) {
            head = node;
        } else {
            tail.next = node;
        }
        tail = node;
        size++;
    }

    E dequeue() {
        E value = head.value;
        head = head.next;
        if (head == null) {
            tail = null;
        }
        size--;
        return value;
    }

    E peek() {
        return head.value;
    }

    boolean isEmpty() {
        return size == 0;
    }

    int size() {
        return size;
    }
}

public class CanteenQueue {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        LinkedQueue<String> queue = new LinkedQueue<>();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("JOIN")) {
                String name = in.next();
                queue.enqueue(name);
                System.out.println(name + " joined (position " + queue.size() + ")");
            } else if (command.equals("SERVE")) {
                if (queue.isEmpty()) {
                    System.out.println("No one to serve");
                } else {
                    System.out.println("Served " + queue.dequeue());
                }
            } else if (command.equals("PEEK")) {
                if (queue.isEmpty()) {
                    System.out.println("No one waiting");
                } else {
                    System.out.println("Next: " + queue.peek());
                }
            } else if (command.equals("SIZE")) {
                System.out.println("Waiting: " + queue.size());
            }
        }
    }
}
```

### Explanation
- `Node<T>` is a static nested class, so it cannot use the outer `E`; it declares its
  own type parameter. Inside the queue, nodes are always created as `Node<E>`, so the
  types line up.
- `enqueue` links the new node after `tail`; on an empty queue the new node is both
  head and tail. `dequeue` moves `head` forward and clears `tail` when the queue
  becomes empty, otherwise `tail` would still point at a removed node.
- Both operations take constant time, unlike removing the first element of an
  `ArrayList`, which shifts every other element.
- `main` checks `isEmpty()` before `dequeue()` and `peek()`, so the queue never
  follows a `null` head.

## Problem 8: Word Statistics with Nested Maps
**Level:** Intermediate

### Problem Statement
Read an integer `n`, then `n` lines of text. A word is a run of letters; convert words
to lower case and drop every non-letter character (split each line on spaces first,
then keep only the letters of each part, and skip parts that become empty).

1. Count each word in a `Map<String, Integer>` (a `TreeMap`) and print `<word>: <count>`
   in alphabetical order.
2. Print `Most frequent: <word> (<count>)`. If several words share the highest count,
   choose the alphabetically first.
3. Group the distinct words by length in a `Map<Integer, Set<String>>` (a `TreeMap` of
   `TreeSet`s) and print `Length <k>: [<words>]` for each length, shortest first.

### Sample Input
```text
3
Java is fun, and Java is safe.
Generics make Java code safe!
Fun code is safe code.
```

### Sample Output
```text
and: 1
code: 3
fun: 2
generics: 1
is: 3
java: 3
make: 1
safe: 3
Most frequent: code (3)
Length 2: [is]
Length 3: [and, fun]
Length 4: [code, java, make, safe]
Length 8: [generics]
```

### Solution
```java
import java.util.Map;
import java.util.Scanner;
import java.util.Set;
import java.util.TreeMap;
import java.util.TreeSet;

public class WordStatistics {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        in.nextLine();

        Map<String, Integer> counts = new TreeMap<>();
        for (int i = 0; i < n; i++) {
            String[] parts = in.nextLine().toLowerCase().split(" ");
            for (String part : parts) {
                String word = part.replaceAll("[^a-z]", "");
                if (!word.isEmpty()) {
                    counts.put(word, counts.getOrDefault(word, 0) + 1);
                }
            }
        }

        String best = null;
        int bestCount = 0;
        Map<Integer, Set<String>> byLength = new TreeMap<>();
        for (Map.Entry<String, Integer> entry : counts.entrySet()) {
            String word = entry.getKey();
            int count = entry.getValue();
            System.out.println(word + ": " + count);
            if (count > bestCount) {
                best = word;
                bestCount = count;
            }
            int len = word.length();
            if (!byLength.containsKey(len)) {
                byLength.put(len, new TreeSet<>());
            }
            byLength.get(len).add(word);
        }

        if (best != null) {
            System.out.println("Most frequent: " + best + " (" + bestCount + ")");
        }
        for (Map.Entry<Integer, Set<String>> entry : byLength.entrySet()) {
            System.out.println("Length " + entry.getKey() + ": " + entry.getValue());
        }
    }
}
```

### Explanation
- `counts.getOrDefault(word, 0) + 1` avoids unboxing a `null` for a new word.
- The map is visited in alphabetical order, and the most frequent word only changes
  on a strictly larger count (`>`), so among equal counts the alphabetically first word
  wins without any extra comparison.
- `Map<Integer, Set<String>>` maps each length to a set of words. A set is created
  the first time a length appears; after that, `byLength.get(len).add(word)` adds to
  the existing set. The outer `TreeMap` sorts lengths, the inner `TreeSet`s sort words.
- `new TreeSet<>()` uses the diamond: the compiler infers `TreeSet<String>` from the
  map's value type.

## Problem 9: Bookshop Sorting with Comparators
**Level:** Intermediate

### Problem Statement
Write a class `Book` (title, author, price in Tk as `int`, year) and three comparator
classes:

- `ByPrice`: cheaper first; equal prices by title A to Z.
- `ByYearNewest`: newer first; equal years by title A to Z.
- `ByTitle`: title A to Z.

Store one object of each comparator in a `Map<String, Comparator<Book>>` under the keys
`PRICE`, `YEAR` and `TITLE`.

Input: an integer `n`, then `n` lines `title;author;price;year` (title and author may
contain spaces). Then an integer `q` and `q` order keys. For each key print
`Sorted by <KEY>:` followed by the books, each as `  <title> (<author>, <year>) <price> Tk`,
or print `Unknown order: <KEY>` if the key is not in the map. The original list must
not be changed: sort a copy each time.

### Sample Input

```text
4
Java Basics;Karim;450;2021
Data Structures;Nusrat;620;2019
Algorithms;Arif;620;2023
C Programming;Sadia;300;2019
4
PRICE
YEAR
AUTHOR
TITLE
```

### Sample Output
```text

  C Programming (Sadia, 2019) 300 Tk
  Java Basics (Karim, 2021) 450 Tk
  Algorithms (Arif, 2023) 620 Tk
  Data Structures (Nusrat, 2019) 620 Tk
Sorted by YEAR:
  Algorithms (Arif, 2023) 620 Tk
  Java Basics (Karim, 2021) 450 Tk
```

### Solution
```java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Scanner;

class Book {
    private final String title;
    private final String author;
    private final int price;
    private final int year;
```

## Problem 10: Ward Readings with Bounded Statistics
**Level:** Intermediate

### Problem Statement
A hospital ward records heart rates (whole numbers) and body temperatures (decimals).
Write a generic class `Stats<N extends Number>` that stores values in an `ArrayList<N>`
and provides `add(N)`, `count()`, `min()`, `max()` (both return `N`), `average()`
(a `double`) and `countAbove(double limit)`.

Write a static method
`static void printReport(String title, Stats<? extends Number> stats, double limit)`
that prints:

```text
<title>: <count> reading(s)
  min <min>, max <max>, average <average with 2 decimals>
  above <limit with 1 decimal>: <count above>
```

If there are no readings, it prints `<title>: no readings` instead.

Input: an integer `n` and `n` heart rates, then an integer `m` and `m` temperatures.
Report heart rates with limit 100 and temperatures with limit 38.0.

### Sample Input
```text
5
72 88 95 101 79
4
36.8 38.2 37.5 39.1
```

### Sample Output
```text
Heart rate: 5 reading(s)
  min 72, max 101, average 87.00
  above 100.0: 1
Temperature: 4 reading(s)
  min 36.8, max 39.1, average 37.90
  above 38.0: 2
```

### Solution
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

class Stats<N extends Number> {
    private final List<N> values = new ArrayList<>();

    void add(N value) {
        values.add(value);
    }

    int count() {
        return values.size();
    }

    N min() {
        N best = values.get(0);
        for (N v : values) {
            if (v.doubleValue() < best.doubleValue()) {
                best = v;
            }
        }
        return best;
    }

    N max() {
        N best = values.get(0);
        for (N v : values) {
            if (v.doubleValue() > best.doubleValue()) {
                best = v;
            }
        }
        return best;
    }

    double average() {
        double sum = 0;
        for (N v : values) {
            sum += v.doubleValue();
        }
        return sum / values.size();
    }

    int countAbove(double limit) {
        int count = 0;
        for (N v : values) {
            if (v.doubleValue() > limit) {
                count++;
            }
        }
        return count;
    }
}

public class WardReadings {
    static void printReport(String title, Stats<? extends Number> stats, double limit) {
        if (stats.count() == 0) {
            System.out.println(title + ": no readings");
            return;
        }
        System.out.println(title + ": " + stats.count() + " reading(s)");
        System.out.printf("  min %s, max %s, average %.2f%n",
                stats.min(), stats.max(), stats.average());
        System.out.printf("  above %.1f: %d%n", limit, stats.countAbove(limit));
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Stats<Integer> heart = new Stats<>();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            heart.add(in.nextInt());
        }
        Stats<Double> temperature = new Stats<>();
        int m = in.nextInt();
        for (int i = 0; i < m; i++) {
            temperature.add(in.nextDouble());
        }
        printReport("Heart rate", heart, 100);
        printReport("Temperature", temperature, 38.0);
    }
}
```

### Explanation
- The bound `N extends Number` allows `doubleValue()` on every element, so one class
  computes statistics for `Integer` and `Double` readings alike. `Stats<String>` would
  not compile.
- `min()` and `max()` return `N`, so for heart rates they return `Integer` values
  (printed as `72`) and for temperatures `Double` values (printed as `36.8`).
- `printReport` takes `Stats<? extends Number>`: it only reads from the statistics, so
  it accepts both a `Stats<Integer>` and a `Stats<Double>`. A parameter of type
  `Stats<Number>` would accept neither, because generic types are not covariant.
- `printReport("Heart rate", heart, 100)` widens the `int` 100 to `double`.

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.Scanner;
import java.util.TreeMap;

interface Entity {
    int getId();

    String describe();
}

class Student implements Entity {
    private final int id;
    private final String name;
    private final double cgpa;

    Student(int id, String name, double cgpa) {
        this.id = id;
        this.name = name;
        this.cgpa = cgpa;
    }

    @Override
    public int getId() {
        return id;
    }

    double getCgpa() {
        return cgpa;
    }

    @Override
    public String describe() {
        return String.format("%d %s (CGPA %.2f)", id, name, cgpa);
    }
}

class Book implements Entity {
    private final int id;
    private final String title;
    private final int copies;

    Book(int id, String title, int copies) {
        this.id = id;
        this.title = title;
        this.copies = copies;
    }

    @Override
    public int getId() {
        return id;
    }

    int getCopies() {
        return copies;
    }

    @Override
    public String describe() {
        return id + " " + title + " (" + copies + " copies)";
    }
}

interface Condition<T> {
    boolean test(T item);
}

class MinCgpa implements Condition<Student> {
    private final double min;

    MinCgpa(double min) {
        this.min = min;
    }

    @Override
    public boolean test(Student s) {
        return s.getCgpa() >= min;
    }
}

class InStock implements Condition<Book> {
    @Override
    public boolean test(Book b) {
        return b.getCopies() > 0;
    }
}

class Repository<T extends Entity> {
    private final String kind;
    private final Map<Integer, T> items = new TreeMap<>();

    Repository(String kind) {
        this.kind = kind;
    }

    String getKind() {
        return kind;
    }

    boolean add(T item) {
        if (items.containsKey(item.getId())) {
            return false;
        }
        items.put(item.getId(), item);
        return true;
    }

    T findById(int id) {
        return items.get(id);
    }

    boolean remove(int id) {
        return items.remove(id) != null;
    }

    List<T> findAll() {
        return new ArrayList<>(items.values());
    }

    List<T> filter(Condition<? super T> condition) {
        List<T> result = new ArrayList<>();
        for (T item : items.values()) {
            if (condition.test(item)) {
                result.add(item);
            }
        }
        return result;
    }
}

            System.out.println("  (none)");

        for (Entity e : list) {
            System.out.println("  " + e.describe());
        }
    }

    public static void main(String[] args) {

        Repository<Student> students = new Repository<>("Student");

                String title = in.next();
                int copies = in.nextInt();
```

### Explanation
- `Repository<T extends Entity>` is written once. The bound lets it call
  `item.getId()`, which is all it needs to store any kind of record by ID.
- The `TreeMap<Integer, T>` keeps records in ID order, so `findAll()` needs no sorting,
  and `items.remove(id)` returns the removed record or `null`.
- `filter` takes `Condition<? super T>` (a consumer of `T` values, following PECS). A

- The helper methods `add`, `find` and `remove` are generic methods bounded by

  the list, so it uses the wildcard `List<? extends Entity>`.
- `Condition<T>` is a generic interface you wrote yourself, the same idea as
  `Comparator<T>`.

## Problem 12: Least-Recently-Used Result Cache
**Level:** Advanced

### Problem Statement
Looking up a grade in the main records is slow, so the exam office keeps a small cache
of recent lookups. Write a generic class `Cache<K, V>` with a fixed capacity that
evicts the **least recently used** key when it is full:

- `V get(K key)`: returns the value and marks the key as most recently used, or returns
  `null` on a miss. It counts hits and misses.
- `K put(K key, V value)`: stores the pair as most recently used. If the cache is full
  and the key is new, it first removes the least recently used key and returns it;
  otherwise it returns `null`.
- `int getHits()`, `int getMisses()`, `List<K> keysByRecency()` (least recent first).

A class `ResultService` holds the records (`Map<Integer, String>`) and a
`Cache<Integer, String>`, and answers lookups.

Input: an integer `r` and `r` records `id grade`; the cache capacity `c`; an integer
`q` and `q` lines `GET id`. For each lookup print one of:

- `<id> -> <grade> (cache hit)`
- `<id> -> <grade> (loaded from records)`
- `<id> -> <grade> (loaded from records, evicted <old id>)`
- `<id>: no such student` (a miss that is not cached)

Finally print `Hits: <h>, misses: <m>` and `Cache (least to most recent): <list>`.

### Sample Input
```text
4
2001 A
2002 B+
2003 A-
2004 C
2
7
GET 2001
GET 2002
GET 2001
GET 2003
GET 2009
GET 2002
GET 2003
```

### Sample Output
```text

2002 -> B+ (loaded from records)
2001 -> A (cache hit)
2003 -> A- (loaded from records, evicted 2002)
2009: no such student
2002 -> B+ (loaded from records, evicted 2001)
2003 -> A- (cache hit)
Hits: 2, misses: 5
Cache (least to most recent): [2002, 2003]
```

### Solution
```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Scanner;
import java.util.TreeMap;

class Cache<K, V> {
    private final int capacity;
    private final Map<K, V> values = new HashMap<>();
    private final List<K> recency = new ArrayList<>();   // least recent first
    private int hits;
    private int misses;

    Cache(int capacity) {
        this.capacity = capacity;
    }

    V get(K key) {
        if (!values.containsKey(key)) {
            misses++;
            return null;
        }
        hits++;
        touch(key);
        return values.get(key);
    }

    K put(K key, V value) {
        K evicted = null;
        if (values.containsKey(key)) {
            touch(key);
        } else {
            if (values.size() == capacity) {
                evicted = recency.remove(0);
                values.remove(evicted);
            }
            recency.add(key);
        }
        values.put(key, value);
        return evicted;
    }

    private void touch(K key) {
        recency.remove(key);   // remove(Object): K is never treated as an index
        recency.add(key);
    }

    int getHits() {
        return hits;
    }

    int getMisses() {
        return misses;
    }

    List<K> keysByRecency() {
        return new ArrayList<>(recency);
    }
}

class ResultService {
    private final Map<Integer, String> records;
    private final Cache<Integer, String> cache;

    ResultService(Map<Integer, String> records, int capacity) {
        this.records = records;
        this.cache = new Cache<>(capacity);
    }

    String lookup(int id) {
        String grade = cache.get(id);
        if (grade != null) {
            return id + " -> " + grade + " (cache hit)";
        }
        grade = records.get(id);
        if (grade == null) {
            return id + ": no such student";
        }
        Integer evicted = cache.put(id, grade);
        if (evicted == null) {
            return id + " -> " + grade + " (loaded from records)";
        }
        return id + " -> " + grade + " (loaded from records, evicted " + evicted + ")";
    }

    String summary() {
        return "Hits: " + cache.getHits() + ", misses: " + cache.getMisses()
                + "\nCache (least to most recent): " + cache.keysByRecency();
    }
}

public class ResultCache {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int r = in.nextInt();
        Map<Integer, String> records = new TreeMap<>();
        for (int i = 0; i < r; i++) {
            int id = in.nextInt();
            records.put(id, in.next());
        }
        int capacity = in.nextInt();
        ResultService service = new ResultService(records, capacity);

        int q = in.nextInt();
        for (int i = 0; i < q; i++) {
            in.next();   // the word GET
            int id = in.nextInt();
            System.out.println(service.lookup(id));
        }
        System.out.println(service.summary());
    }
}
```

### Explanation
- `Cache<K, V>` knows nothing about students or grades; it could cache any key and
  value types. `ResultService` is the only class that knows the domain.
- A `HashMap` gives fast lookups. Its order is never printed; the order that matters
  (recency) is kept separately in a `List<K>`, least recent at index 0.
- `touch` moves a key to the end. Inside the generic class `recency.remove(key)` calls
  `remove(Object)`, because `K` is not `int`. In a `List<Integer>` outside a generic
  class, `list.remove(id)` with an `int` would remove by **index**: a classic trap.
- `put` returns the evicted key, so the caller can report it without the cache doing
  any printing. `Integer evicted` stays a wrapper because it may be `null`.
- Removing from the front of an `ArrayList` is fine for a small cache; a large one
  would use `LinkedHashMap`, which can keep entries in access order.

```java
import java.util.Scanner;

interface Converter<T, R> {
    R convert(T input);
}

class Result<T> {
    private final T value;
    private final String error;

    private Result(T value, String error) {
        this.value = value;
        this.error = error;
    }

    static <T> Result<T> ok(T value) {
        return new Result<>(value, null);
    }

    static <T> Result<T> fail(String error) {
        return new Result<>(null, error);
    }

    boolean isOk() {
        return error == null;
    }

    T getValue() {
        return value;
    }

    String getError() {
        return error;
    }

    <R> Result<R> map(Converter<T, R> f) {
        if (!isOk()) {
            return fail(error);
        }
        return ok(f.convert(value));
    }
}

class Registration {
    private final String name;
    private final int credits;
    private final double cgpa;

    Registration(String name, int credits, double cgpa) {
        this.name = name;
        this.credits = credits;
        this.cgpa = cgpa;
    }

    int getCredits() {
        return credits;
    }

    @Override
    public String toString() {
        return String.format("%s, %d credits, CGPA %.2f", name, credits, cgpa);
    }
}

class FeeCalculator implements Converter<Registration, Integer> {
    private static final int FEE_PER_CREDIT = 5000;

    @Override
    public Integer convert(Registration r) {
        return r.getCredits() * FEE_PER_CREDIT;
    }
}

public class RegistrationCheck {
    static Result<Integer> parseCredits(String text) {
        int credits;
        try {
            credits = Integer.parseInt(text);
        } catch (NumberFormatException e) {
            return Result.fail("credits '" + text + "' is not a whole number");
        }
        if (credits < 3 || credits > 18) {
            return Result.fail("credits '" + text + "' is outside 3-18");
        }
        return Result.ok(credits);
    }

    static Result<Double> parseCgpa(String text) {
        double cgpa;
        try {
            cgpa = Double.parseDouble(text);
        } catch (NumberFormatException e) {
            return Result.fail("CGPA '" + text + "' is not a number");
        }
        if (cgpa < 0.0 || cgpa > 4.0) {
            return Result.fail("CGPA '" + text + "' is outside 0.00-4.00");
        }
        return Result.ok(cgpa);
    }

    static Result<Registration> parse(String line) {
        String[] parts = line.split(",", -1);
        if (parts.length != 3) {
            return Result.fail("expected 3 fields, found " + parts.length);
        }
        String name = parts[0].trim();
        if (name.isEmpty()) {
            return Result.fail("name is missing");
        }
        Result<Integer> credits = parseCredits(parts[1].trim());
        if (!credits.isOk()) {
            return Result.fail(credits.getError());
        }
        Result<Double> cgpa = parseCgpa(parts[2].trim());
        if (!cgpa.isOk()) {
            return Result.fail(cgpa.getError());
        }
        return Result.ok(new Registration(name, credits.getValue(), cgpa.getValue()));
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        in.nextLine();
        int accepted = 0;
        int rejected = 0;
        long totalFees = 0;
        FeeCalculator calculator = new FeeCalculator();
        for (int i = 1; i <= n; i++) {
            Result<Registration> reg = parse(in.nextLine());
            Result<Integer> fee = reg.map(calculator);
            if (fee.isOk()) {
                accepted++;
                totalFees += fee.getValue();
                System.out.println("Line " + i + ": OK " + reg.getValue()
                        + ", fee " + fee.getValue() + " Tk");
            } else {
                rejected++;
                System.out.println("Line " + i + ": ERROR " + fee.getError());
            }
        }
        System.out.println("Accepted: " + accepted + ", rejected: " + rejected);
        System.out.println("Total fees: " + totalFees + " Tk");
    }
}
```

### Explanation
- `Result<T>` makes success and failure part of the return type. The caller cannot
  forget the error case: to get the value it has to look at the `Result` first.
- `Result.fail(...)` is a generic static method. In `parse`, its `T` is inferred from
  the return type `Result<Registration>`; in `parseCredits` the same call produces a
  `Result<Integer>`. This is type inference from the target type.
- `map` turns a `Result<Registration>` into a `Result<Integer>` using any
  `Converter<Registration, Integer>`. A failure flows through untouched, so `main` checks
  only once, at the end.
- `split(",", -1)` keeps empty trailing fields, so `"Imran,12"` reports 2 fields and
  `",9,3.00"` gives an empty name rather than a shifted line.
- `NumberFormatException` is caught and turned into a failure result, so every input
  line produces a message and the program ends normally.

## Problem 14: Contest Leaderboard with Combined Comparators
**Level:** Advanced

### Problem Statement
A programming contest ranks teams by different rules in different rounds, so the sort
order must be built from input at runtime. Write:

- `class Team` (name, problems solved, penalty minutes).
- Three basic comparators: `BySolved`, `ByPenalty`, `ByName` (all ascending).
- Two generic comparator classes that work for any type `T`:
  `Reversed<T>` (wraps a `Comparator<T>` and reverses it) and `Chain<T>` (holds a
  `List<Comparator<T>>` and uses the first one that does not return 0).

Input: an integer `n`, then `n` lines `name solved penalty`; then an integer `k` and
`k` lines, each a sort specification: one or more keys `FIELD:DIRECTION` separated by
spaces, where `FIELD` is `SOLVED`, `PENALTY` or `NAME` and `DIRECTION` is `ASC` or
`DESC`.

For each specification print `Order: <specification>`, then the teams as
`<rank>. <name> <solved> <penalty>`. Teams that compare equal under the whole
specification share a rank, and the next rank skips accordingly (1, 2, 3, 3, 5). Equal
teams keep their input order (`List.sort` is stable). If any key is invalid, print
`Invalid sort key: <key>` after the `Order:` line instead of the list.

### Sample Input
```text
5
CodeCats 5 410
ByteBuilders 6 520
NullPointers 5 380
StackSmash 5 410
LoopLegends 3 200
4
SOLVED:DESC PENALTY:ASC
NAME:ASC
SOLVED:DESC PENALTY:DESC NAME:ASC
SOLVED:DESC SCORE:ASC
```

### Sample Output
```text

1. ByteBuilders 6 520
2. NullPointers 5 380
3. CodeCats 5 410
3. StackSmash 5 410
5. LoopLegends 3 200
Order: NAME:ASC
1. ByteBuilders 6 520
2. CodeCats 5 410
3. LoopLegends 3 200
4. NullPointers 5 380
5. StackSmash 5 410
Order: SOLVED:DESC PENALTY:DESC NAME:ASC
1. ByteBuilders 6 520
2. CodeCats 5 410
3. StackSmash 5 410
4. NullPointers 5 380
5. LoopLegends 3 200
Order: SOLVED:DESC SCORE:ASC
Invalid sort key: SCORE:ASC
```

### Solution
```java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Map;
import java.util.Scanner;
import java.util.TreeMap;

class Team {
    private final String name;
    private final int solved;
    private final int penalty;

    Team(String name, int solved, int penalty) {
        this.name = name;
        this.solved = solved;
        this.penalty = penalty;
    }

    String getName() {
        return name;
    }

    int getSolved() {
        return solved;
    }

    int getPenalty() {
        return penalty;
    }

    @Override
    public String toString() {
        return name + " " + solved + " " + penalty;
    }
}

class BySolved implements Comparator<Team> {
    @Override
    public int compare(Team a, Team b) {
        return Integer.compare(a.getSolved(), b.getSolved());
    }
}

class ByPenalty implements Comparator<Team> {
    @Override
    public int compare(Team a, Team b) {
        return Integer.compare(a.getPenalty(), b.getPenalty());
    }
}

class ByName implements Comparator<Team> {
    @Override
    public int compare(Team a, Team b) {
        return a.getName().compareTo(b.getName());
    }
}

class Reversed<T> implements Comparator<T> {
    private final Comparator<T> inner;

    Reversed(Comparator<T> inner) {
        this.inner = inner;
    }

    @Override
    public int compare(T a, T b) {
        return inner.compare(b, a);
    }
}

class Chain<T> implements Comparator<T> {
    private final List<Comparator<T>> parts;

    Chain(List<Comparator<T>> parts) {
        this.parts = parts;
    }

    @Override
    public int compare(T a, T b) {
        for (Comparator<T> part : parts) {
            int result = part.compare(a, b);
            if (result != 0) {
                return result;
            }
        }
        return 0;
    }
}

public class Leaderboard {
    private static final Map<String, Comparator<Team>> FIELDS = new TreeMap<>();

    static {
        FIELDS.put("SOLVED", new BySolved());
        FIELDS.put("PENALTY", new ByPenalty());
        FIELDS.put("NAME", new ByName());
    }

    // Returns null and prints a message if a key is invalid.
    static Comparator<Team> build(String spec) {
        List<Comparator<Team>> parts = new ArrayList<>();
        for (String key : spec.trim().split(" ")) {
            String[] fd = key.split(":");
            Comparator<Team> base = fd.length == 2 ? FIELDS.get(fd[0]) : null;
            if (base == null || !(fd[1].equals("ASC") || fd[1].equals("DESC"))) {
                System.out.println("Invalid sort key: " + key);
                return null;
            }
            if (fd[1].equals("DESC")) {
                parts.add(new Reversed<>(base));
            } else {
                parts.add(base);
            }
        }
        return new Chain<>(parts);
    }

    static void printRanked(List<Team> sorted, Comparator<Team> order) {
        int rank = 1;
        for (int i = 0; i < sorted.size(); i++) {
            if (i > 0 && order.compare(sorted.get(i - 1), sorted.get(i)) != 0) {
                rank = i + 1;
            }
            System.out.println(rank + ". " + sorted.get(i));
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        List<Team> teams = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            String name = in.next();
            int solved = in.nextInt();
            int penalty = in.nextInt();
            teams.add(new Team(name, solved, penalty));
        }
        int k = in.nextInt();
        in.nextLine();
        for (int i = 0; i < k; i++) {
            String spec = in.nextLine();
            System.out.println("Order: " + spec);
            Comparator<Team> order = build(spec);
            if (order != null) {
                List<Team> sorted = new ArrayList<>(teams);
                sorted.sort(order);
                printRanked(sorted, order);
            }
        }
    }
}
```

### Explanation
- `Reversed<T>` and `Chain<T>` are generic classes that implement the generic interface
  `Comparator<T>`. They never mention `Team`, so they could sort books or students too.
  They are small versions of the library methods `Comparator.reversed()` and
  `thenComparing`.
- `build` turns text into objects: each key becomes a base comparator from the `FIELDS`
  map, wrapped in `Reversed` for `DESC`, and all of them go into one `Chain`.
- `printRanked` gives a new rank only when a team differs from the previous one under
  the same comparator; equal teams keep the previous rank, and the skipped numbers come
  from using the position `i + 1`.
- `List.sort` is guaranteed to be stable, so CodeCats stays before StackSmash when the
  specification does not separate them.
- `fd.length == 2 ? FIELDS.get(fd[0]) : null` guards against keys without a colon
  before `fd[1]` is used.

## Problem 15: Generic Binary Search Tree
**Level:** Advanced

### Problem Statement
Write a generic binary search tree `BST<T extends Comparable<T>>` with a private static
nested class `Node<E>`. Smaller values go left, larger values go right, and duplicates
are not stored. Methods:

- `boolean insert(T value)`: `false` for a duplicate;
- `boolean contains(T value)`;
- `T ceiling(T value)`: the smallest stored value that is greater than or equal to
  `value`, or `null` if there is none;
- `List<T> inOrder()`, `int size()`, `int height()` (number of nodes on the longest
  root-to-leaf path; 0 for an empty tree), `T min()`, `T max()`.

Write one generic static method
`static <T extends Comparable<T>> void process(String label, List<T> values, List<T> queries)`
that builds a tree from `values` (printing `Duplicate ignored: <v>` for duplicates),
prints the label, the in-order list, the size, height, minimum and maximum, and then for
each query prints `<q>: found`, `<q>: not found, next larger is <c>` or
`<q>: not found, nothing larger`.

Input: an integer `n` and `n` integers; an integer `q` and `q` integer queries; an
integer `m` and `m` words; an integer `p` and `p` word queries. Process the numbers with
label `Numbers`, then the words with label `Words`. Each list of values is non-empty.

### Sample Input
```text
8
50 30 70 20 40 60 80 30
3
40 65 90
5
mango apple kiwi banana apple
2
cherry kiwi
```

### Sample Output
```text
Numbers
Duplicate ignored: 30
In order: [20, 30, 40, 50, 60, 70, 80]
Size 7, height 3, min 20, max 80
40: found
65: not found, next larger is 70
90: not found, nothing larger
Words
Duplicate ignored: apple
In order: [apple, banana, kiwi, mango]
Size 4, height 4, min apple, max mango
cherry: not found, next larger is kiwi
kiwi: found
```

### Solution
```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

class BST<T extends Comparable<T>> {
    private static class Node<E> {
        private final E value;
        private Node<E> left;
        private Node<E> right;

        Node(E value) {
            this.value = value;
        }
    }

    private Node<T> root;
    private int size;

    boolean insert(T value) {
        if (root == null) {
            root = new Node<>(value);
            size++;
            return true;
        }
        Node<T> current = root;
        while (true) {
            int cmp = value.compareTo(current.value);
            if (cmp == 0) {
                return false;
            }
            if (cmp < 0) {
                if (current.left == null) {
                    current.left = new Node<>(value);
                    size++;
                    return true;
                }
                current = current.left;
            } else {
                if (current.right == null) {
                    current.right = new Node<>(value);
                    size++;
                    return true;
                }
                current = current.right;
            }
        }
    }

    boolean contains(T value) {
        Node<T> current = root;
        while (current != null) {
            int cmp = value.compareTo(current.value);
            if (cmp == 0) {
                return true;
            }
            current = cmp < 0 ? current.left : current.right;
        }
        return false;
    }

    T ceiling(T value) {
        T best = null;
        Node<T> current = root;
        while (current != null) {
            int cmp = value.compareTo(current.value);
            if (cmp == 0) {
                return current.value;
            }
            if (cmp < 0) {
                best = current.value;   // a candidate; look for a smaller one
                current = current.left;
            } else {
                current = current.right;
            }
        }
        return best;
    }

    List<T> inOrder() {
        List<T> result = new ArrayList<>();
        collect(root, result);
        return result;
    }

    private void collect(Node<T> node, List<T> result) {
        if (node == null) {
            return;
        }
        collect(node.left, result);
        result.add(node.value);
        collect(node.right, result);
    }

    int height() {
        return height(root);
    }

    private int height(Node<T> node) {
        if (node == null) {
            return 0;
        }
        return 1 + Math.max(height(node.left), height(node.right));
    }

    int size() {
        return size;
    }

    T min() {
        Node<T> current = root;
        while (current.left != null) {
            current = current.left;
        }
        return current.value;
    }

    T max() {
        Node<T> current = root;
        while (current.right != null) {
            current = current.right;
        }
        return current.value;
    }
}

public class GenericTree {
    static <T extends Comparable<T>> void process(String label, List<T> values,
            List<T> queries) {
        System.out.println(label);
        BST<T> tree = new BST<>();
        for (T v : values) {
            if (!tree.insert(v)) {
                System.out.println("Duplicate ignored: " + v);
            }
        }
        System.out.println("In order: " + tree.inOrder());
        System.out.println("Size " + tree.size() + ", height " + tree.height()
                + ", min " + tree.min() + ", max " + tree.max());
        for (T q : queries) {
            if (tree.contains(q)) {
                System.out.println(q + ": found");
            } else {
                T next = tree.ceiling(q);
                if (next == null) {
                    System.out.println(q + ": not found, nothing larger");
                } else {
                    System.out.println(q + ": not found, next larger is " + next);
                }
            }
        }
    }

    static List<Integer> readInts(Scanner in) {
        int count = in.nextInt();
        List<Integer> list = new ArrayList<>();
        for (int i = 0; i < count; i++) {
            list.add(in.nextInt());
        }
        return list;
    }

    static List<String> readWords(Scanner in) {
        int count = in.nextInt();
        List<String> list = new ArrayList<>();
        for (int i = 0; i < count; i++) {
            list.add(in.next());
        }
        return list;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        List<Integer> numbers = readInts(in);
        List<Integer> numberQueries = readInts(in);
        List<String> words = readWords(in);
        List<String> wordQueries = readWords(in);
        process("Numbers", numbers, numberQueries);
        process("Words", words, wordQueries);
    }
}
```

### Explanation
- The bound `T extends Comparable<T>` is what makes a search tree possible: every
  decision (`left` or `right`) is a `compareTo` call. The same class stores `Integer`
  and `String` values.
- `Node<E>` is a static nested class with its own type parameter; the tree always
  creates `Node<T>` objects, and `new Node<>(value)` infers the type.
- `ceiling` walks down from the root. Every time it goes left, the current value is
  larger than the query and becomes the best candidate so far; going left looks for a
  smaller candidate, going right means the current value is too small.
- `inOrder` (left, node, right) visits values in sorted order, which is why the
  printed lists are sorted. `height` is recursive: an empty subtree has height 0.
- `process` is a single generic method used for both kinds of data; the words tree has
  height 4 because `mango`, `apple`, `kiwi`, `banana` form a long path, showing that a
  BST's shape depends on the insertion order.
