# Practice Problems: Classes and Objects

These problems practise designing your own classes and making objects work together:
fields, instance methods, `new`, default values, `this`, `toString()` and objects passed
to methods. Programs read input without prompts and print exactly the sample output.

## Problem 1: Rectangle Measurements
**Level:** Basic

### Problem Statement
Write a class `Rectangle` with two `int` fields, `width` and `height`, and three
instance methods:

- `int area()`
- `int perimeter()`
- `boolean isSquare()`

The program reads two integers, the width and the height. It creates one `Rectangle`,
sets its fields, and prints three lines: `Area: <a>`, `Perimeter: <p>` and
`Square: yes` or `Square: no`.

### Sample Input
```text
4 6
```

### Sample Output
```text
Area: 24
Perimeter: 20
Square: no
```

### Solution
```java
import java.util.Scanner;

class Rectangle {
    int width;
    int height;

    int area() {
        return width * height;
    }

    int perimeter() {
        return 2 * (width + height);
    }

    boolean isSquare() {
        return width == height;
    }
}

public class RectangleMeasurements {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Rectangle r = new Rectangle();
        r.width = in.nextInt();
        r.height = in.nextInt();
        System.out.println("Area: " + r.area());
        System.out.println("Perimeter: " + r.perimeter());
        System.out.println("Square: " + (r.isSquare() ? "yes" : "no"));
    }
}
```

### Explanation
The rectangle's size is its state, so `width` and `height` are fields. Area, perimeter
and "is it a square?" are questions about that state, so they are instance methods that
read the fields directly; none of them needs parameters. `main` only creates the object,
fills it and asks it questions. Notice that `area()` is not stored in a field: it is
computed when asked, so it is always correct even if the size changes later.

## Problem 2: Hostel Resident Record
**Level:** Basic

### Problem Statement
Write a class `Resident` for the university hostel with these fields: `String name`,
`int room`, `boolean feePaid` and `double dueTk`. Give it a method `void print(String
label)` that prints one line:

`<label>: <name>, room <room>, fee paid: <feePaid>, due <dueTk> Tk`

with `dueTk` printed with two decimals.

The program creates a `Resident` and prints it with the label `Before` without setting
anything. Then it reads a name (a whole line), a room number and the amount due. It sets
the fields, sets `feePaid` to `true` exactly when the amount due is `0`, and prints the
object again with the label `After`.

### Sample Input
```text
Tanvir Ahmed
312
1500
```

### Sample Output
```text
Before: null, room 0, fee paid: false, due 0.00 Tk
After: Tanvir Ahmed, room 312, fee paid: false, due 1500.00 Tk
```

### Solution
```java
import java.util.Scanner;

class Resident {
    String name;
    int room;
    boolean feePaid;
    double dueTk;

    void print(String label) {
        System.out.printf("%s: %s, room %d, fee paid: %b, due %.2f Tk%n",
                label, name, room, feePaid, dueTk);
    }
}

public class HostelResident {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Resident r = new Resident();
        r.print("Before");

        r.name = in.nextLine();
        r.room = in.nextInt();
        r.dueTk = in.nextDouble();
        r.feePaid = r.dueTk == 0;
        r.print("After");
    }
}
```

### Explanation
The `Before` line shows the default values that `new` gives every field: `null` for the
`String`, `0` for the `int`, `false` for the `boolean` and `0.0` for the `double`. No
garbage values appear, unlike C. A local variable inside `main` would not get a default;
the compiler would reject reading it. The name is read with `nextLine()` because it can
contain spaces, and it is read first, so no leftover newline gets in the way.

## Problem 3: Canteen Tally Counters
**Level:** Basic

### Problem Statement
The canteen counts cups of tea and plates of samosa sold. Write a class `TallyCounter`
with a field `int count` and two methods:

- `void click()` adds one.
- `void undo()` removes one, but never goes below zero.

Create **two** `TallyCounter` objects, one for tea and one for samosa. The program reads
one word made of the letters `T` (tea sold), `S` (samosa sold), `t` (undo tea) and `s`
(undo samosa). Process the letters from left to right, then print `Tea: <count>` and
`Samosa: <count>`.

### Sample Input
```text
TTSTtSsssT
```

### Sample Output
```text
Tea: 3
Samosa: 0
```

### Solution
```java
import java.util.Scanner;

class TallyCounter {
    int count;

    void click() {
        count++;
    }

    void undo() {
        if (count > 0) {
            count--;
        }
    }
}

public class CanteenTally {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String events = in.next();
        TallyCounter tea = new TallyCounter();
        TallyCounter samosa = new TallyCounter();

        for (int i = 0; i < events.length(); i++) {
            char c = events.charAt(i);
            if (c == 'T') {
                tea.click();
            } else if (c == 'S') {
                samosa.click();
            } else if (c == 't') {
                tea.undo();
            } else if (c == 's') {
                samosa.undo();
            }
        }
        System.out.println("Tea: " + tea.count);
        System.out.println("Samosa: " + samosa.count);
    }
}
```

### Explanation
One class, two objects: `tea` and `samosa` each have their own `count` field, so a click
on one never changes the other. The methods are written once in the class; `tea.click()`
works on the tea object and `samosa.click()` on the samosa object. The "never below zero"
rule lives inside `undo()`, so it holds for every counter. In the sample, the third `s`
is ignored because the samosa count is already zero.

## Problem 4: Course Details with this
**Level:** Basic

### Problem Statement
Write a class `Course` with fields `code`, `title` and `credits` (an `int`). Give it:

- `void setDetails(String code, String title, int credits)`, whose parameters have the
  **same names** as the fields;
- `boolean isLab()`, which is `true` when the course has exactly 1 credit;
- `String describe()`, which returns
  `<code>: <title> (<credits> credit(s), lab|theory)`; write `1 credit` for one credit
  and `<n> credits` otherwise.

The program reads two courses. Each course is three lines: code, title, credits. Print
the description of each course on its own line.

### Sample Input
```text
CSE 1115
Object Oriented Programming
3
CSE 1116
Object Oriented Programming Laboratory
1
```

### Sample Output
```text
CSE 1115: Object Oriented Programming (3 credits, theory)
CSE 1116: Object Oriented Programming Laboratory (1 credit, lab)
```

### Solution
```java
import java.util.Scanner;

class Course {
    String code;
    String title;
    int credits;

    void setDetails(String code, String title, int credits) {
        this.code = code;
        this.title = title;
        this.credits = credits;
    }

    boolean isLab() {
        return credits == 1;
    }

    String describe() {
        String unit = credits == 1 ? " credit" : " credits";
        String kind = isLab() ? "lab" : "theory";
        return code + ": " + title + " (" + credits + unit + ", " + kind + ")";
    }
}

public class CourseDetails {
    static Course readCourse(Scanner in) {
        String code = in.nextLine();
        String title = in.nextLine();
        int credits = Integer.parseInt(in.nextLine().trim());
        Course c = new Course();
        c.setDetails(code, title, credits);
        return c;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Course first = readCourse(in);
        Course second = readCourse(in);
        System.out.println(first.describe());
        System.out.println(second.describe());
    }
}
```

### Explanation
Inside `setDetails`, the parameter `code` hides the field `code`. Writing `code = code;`
would assign the parameter to itself and leave the field `null`. `this.code` means "the
`code` field of the current object", which fixes the clash. The static helper
`readCourse` creates a new object and returns its reference, so `main` gets two separate
courses. The credits line is read with `nextLine()` and parsed, so the next `nextLine()`
does not see a leftover newline.

## Problem 5: Employee with toString
**Level:** Basic

### Problem Statement
Write a class `Employee` with fields `name`, `designation` and `int salary` (Tk per
month). Give it a method `int annualSalary()` and a method `public String toString()`
that returns `<name>, <designation>, <salary> Tk/month`.

The program reads a name, a designation (each a whole line) and a salary. Print the
employee with `System.out.println(employee)`, then print the line
`Annual salary of <name>: <annual> Tk`, then print `Saved: ` followed by the employee,
built with string concatenation.

### Sample Input
```text
Farhana Akter
Lecturer
45000
```

### Sample Output
```text
Farhana Akter, Lecturer, 45000 Tk/month
Annual salary of Farhana Akter: 540000 Tk
Saved: Farhana Akter, Lecturer, 45000 Tk/month
```

### Solution
```java
import java.util.Scanner;

class Employee {
    String name;
    String designation;
    int salary;

    int annualSalary() {
        return salary * 12;
    }

    public String toString() {
        return name + ", " + designation + ", " + salary + " Tk/month";
    }
}

public class EmployeeRecord {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Employee employee = new Employee();
        employee.name = in.nextLine();
        employee.designation = in.nextLine();
        employee.salary = in.nextInt();

        System.out.println(employee);
        System.out.println("Annual salary of " + employee.name + ": "
                + employee.annualSalary() + " Tk");
        String logLine = "Saved: " + employee;
        System.out.println(logLine);
    }
}
```

### Explanation
`System.out.println(employee)` and `"Saved: " + employee` both call `toString()`
automatically. Without it, Java would print something like `Employee@5e91993f`.
`toString()` returns the text instead of printing it, so the same text can go to the
screen, into another string, or later into a file. The header must be exactly
`public String toString()`; Chapter 09 explains that this replaces (overrides) a method
every class already has.

## Problem 6: Bank Account with Minimum Balance
**Level:** Intermediate

### Problem Statement
A student bank account must always keep at least 500 Tk. Write a class `BankAccount`
with fields `owner`, `int balance`, `int minimumBalance` (starting value 500) and
`int rejected` (how many operations were refused). Give it:

- `boolean deposit(int amount)`: refuses amounts of 0 or less.
- `boolean withdraw(int amount)`: refuses amounts of 0 or less, and any withdrawal that
  would leave less than `minimumBalance`.
- `public String toString()`: `<owner>: <balance> Tk (<rejected> rejected)`.

Every refused operation adds one to `rejected`.

Input: the owner's name (a whole line), the opening deposit, an integer `n`, then `n`
lines `D <amount>` or `W <amount>`. Make the opening deposit with `deposit` (it is not
printed). For each of the `n` operations print `OK, balance <balance> Tk` or `REJECTED`.
Finally print the account.

### Sample Input
```text
Imran Hossain
2000
5
W 1200
W 400
D 0
D 3000
W 3300
```

### Sample Output
```text
OK, balance 800 Tk
REJECTED
REJECTED
OK, balance 3800 Tk
OK, balance 500 Tk
Imran Hossain: 500 Tk (2 rejected)
```

### Solution
```java
import java.util.Scanner;

class BankAccount {
    String owner;
    int balance;
    int minimumBalance = 500;
    int rejected;

    boolean deposit(int amount) {
        if (amount <= 0) {
            rejected++;
            return false;
        }
        balance = balance + amount;
        return true;
    }

    boolean withdraw(int amount) {
        if (amount <= 0 || balance - amount < minimumBalance) {
            rejected++;
            return false;
        }
        balance = balance - amount;
        return true;
    }

    public String toString() {
        return owner + ": " + balance + " Tk (" + rejected + " rejected)";
    }
}

public class MinimumBalanceAccount {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        BankAccount account = new BankAccount();
        account.owner = in.nextLine();
        account.deposit(in.nextInt());

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String type = in.next();
            int amount = in.nextInt();
            boolean ok;
            if (type.equals("D")) {
                ok = account.deposit(amount);
            } else {
                ok = account.withdraw(amount);
            }
            if (ok) {
                System.out.println("OK, balance " + account.balance + " Tk");
            } else {
                System.out.println("REJECTED");
            }
        }
        System.out.println(account);
    }
}
```

### Explanation
- `minimumBalance = 500` is a field initializer: every new account starts with that
  value, and a different kind of account could later use another limit.
- The rule is checked inside `withdraw`, so no caller can skip it. The test
  `balance - amount < minimumBalance` allows the boundary case: withdrawing 3300 from
  3800 leaves exactly 500, which is accepted.
- The object also counts its own refusals in `rejected`. `main` does not need a separate
  counter; it only reports what the object says.
- The methods return `boolean`, so the class contains the rules and `main` decides what
  to print.

## Problem 7: Parcels in a Box
**Level:** Intermediate

### Problem Statement
A courier office packs rectangular parcels into a rectangular box (seen from above).
Write a class `Rectangle` with `int` fields `width` and `height` and these methods:

- `int area()`
- `boolean fitsInside(Rectangle other)`: the current rectangle fits in `other` without
  turning (width ≤ other's width and height ≤ other's height).
- `boolean fitsRotated(Rectangle other)`: it fits only after turning it by 90 degrees.
- `public String toString()`: `<width> x <height>`.

Input: the box's width and height, then `n`, then `n` parcels (width and height). For
each parcel print `<parcel>: fits`, `<parcel>: fits if rotated` or
`<parcel>: does not fit`. Finally print `Largest that fits: <parcel> (area <a>)` for the
parcel with the largest area that fits either way (the first one on a tie), or
`No parcel fits`.

### Sample Input
```text
10 6
4
5 8
7 4
6 12
9 6
```

### Sample Output
```text
5 x 8: fits if rotated
7 x 4: fits
6 x 12: does not fit
9 x 6: fits
Largest that fits: 9 x 6 (area 54)
```

### Solution
```java
import java.util.Scanner;

class Rectangle {
    int width;
    int height;

    int area() {
        return width * height;
    }

    boolean fitsInside(Rectangle other) {
        return this.width <= other.width && this.height <= other.height;
    }

    boolean fitsRotated(Rectangle other) {
        return this.height <= other.width && this.width <= other.height;
    }

    public String toString() {
        return width + " x " + height;
    }
}

public class ParcelsInBox {
    static Rectangle read(Scanner in) {
        Rectangle r = new Rectangle();
        r.width = in.nextInt();
        r.height = in.nextInt();
        return r;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Rectangle box = read(in);
        int n = in.nextInt();
        Rectangle best = null;

        for (int i = 0; i < n; i++) {
            Rectangle parcel = read(in);
            boolean fits = true;
            if (parcel.fitsInside(box)) {
                System.out.println(parcel + ": fits");
            } else if (parcel.fitsRotated(box)) {
                System.out.println(parcel + ": fits if rotated");
            } else {
                System.out.println(parcel + ": does not fit");
                fits = false;
            }
            if (fits && (best == null || parcel.area() > best.area())) {
                best = parcel;
            }
        }

        if (best == null) {
            System.out.println("No parcel fits");
        } else {
            System.out.println("Largest that fits: " + best + " (area " + best.area() + ")");
        }
    }
}
```

### Explanation
- `fitsInside(Rectangle other)` is a conversation between two objects of the same class:
  `this` is the parcel and `other` is the box. Writing `this.` makes the two sides of
  each comparison easy to tell apart.
- `read` creates a new `Rectangle` on every call, so each parcel is a separate object.
- `best` starts as `null`, meaning "no parcel yet". When a better parcel appears, `best`
  is set to refer to that same object; no copy is made, and the object stays alive after
  the loop because `best` still refers to it.
- The `best == null` test comes first, so `best.area()` is never called on `null`.

## Problem 8: CGPA Tracker
**Level:** Intermediate

### Problem Statement
Write a class `Student` that tracks a student's results. Fields: `name`,
`int totalCredits`, `double totalPoints` (the sum of credits × grade point). Methods:

- `boolean addCourse(int credits, double gradePoint)`: accepts the course only when
  `credits` is positive and `gradePoint` is between 0.00 and 4.00; returns whether it
  was accepted.
- `double cgpa()`: `totalPoints / totalCredits`, or `0.0` when there are no credits.
- `String standing()`: `Dean's list` when the CGPA is at least 3.80, `Good standing`
  when at least 2.00, otherwise `Probation`.

Input: the name (a whole line), `n`, then `n` lines `<credits> <gradePoint>`. For every
rejected course print `Ignored: <credits> credits with grade point <gp>` (grade point
with two decimals). Finally print
`<name>: <totalCredits> credits, CGPA <cgpa>, <standing>` with the CGPA to two decimals.
(The standing thresholds are invented for practice.)

### Sample Input
```text
Nusrat Jahan
4
3 4.00
3 3.67
3 4.50
3 3.33
```

### Sample Output
```text
Ignored: 3 credits with grade point 4.50
Nusrat Jahan: 9 credits, CGPA 3.67, Good standing
```

### Solution
```java
import java.util.Scanner;

class Student {
    String name;
    int totalCredits;
    double totalPoints;

    boolean addCourse(int credits, double gradePoint) {
        if (credits <= 0 || gradePoint < 0.0 || gradePoint > 4.0) {
            return false;
        }
        totalCredits = totalCredits + credits;
        totalPoints = totalPoints + credits * gradePoint;
        return true;
    }

    double cgpa() {
        if (totalCredits == 0) {
            return 0.0;
        }
        return totalPoints / totalCredits;
    }

    String standing() {
        double value = cgpa();
        if (value >= 3.80) {
            return "Dean's list";
        } else if (value >= 2.00) {
            return "Good standing";
        }
        return "Probation";
    }
}

public class CgpaTracker {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Student s = new Student();
        s.name = in.nextLine();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            int credits = in.nextInt();
            double gp = in.nextDouble();
            if (!s.addCourse(credits, gp)) {
                System.out.printf("Ignored: %d credits with grade point %.2f%n", credits, gp);
            }
        }
        System.out.printf("%s: %d credits, CGPA %.2f, %s%n",
                s.name, s.totalCredits, s.cgpa(), s.standing());
    }
}
```

### Explanation
The design decision here is **what to store**. The object stores the running totals,
not the CGPA itself, because the CGPA can always be computed from them. If the CGPA
were a field, every `addCourse` would have to remember to update it. `cgpa()` handles
the "no courses yet" case so it never divides by zero, and `standing()` builds on
`cgpa()` instead of repeating the formula. In the sample, the valid courses give
(12.00 + 11.01 + 9.99) / 9 = 3.666..., printed as 3.67.

## Problem 9: Campus Shuttle
**Level:** Intermediate

### Problem Statement
Write a class `Shuttle` with fields `route`, `int capacity`, `int onBoard` and
`int carried` (total passengers who boarded during the trip). Methods:

- `int alight(int wanted)`: up to `wanted` passengers get off (never more than are on
  board); returns how many actually got off.
- `int board(int wanted)`: up to `wanted` passengers get on, limited by the free seats;
  returns how many actually got on and adds them to `carried`.

Input: the route name (a whole line), the capacity, the number of stops `k`, then `k`
lines `<wantOff> <wantOn>`. At each stop passengers first get off, then get on. Print
for stop `i`: `Stop <i>: <off> off, <on> on, <left> left behind, <onBoard> on board`.
Finally print `<route> carried <carried> passengers`.

### Sample Input
```text
Campus Loop
30
4
0 20
5 18
12 4
30 0
```

### Sample Output
```text
Stop 1: 0 off, 20 on, 0 left behind, 20 on board
Stop 2: 5 off, 15 on, 3 left behind, 30 on board
Stop 3: 12 off, 4 on, 0 left behind, 22 on board
Stop 4: 22 off, 0 on, 0 left behind, 0 on board
Campus Loop carried 39 passengers
```

### Solution
```java
import java.util.Scanner;

class Shuttle {
    String route;
    int capacity;
    int onBoard;
    int carried;

    int alight(int wanted) {
        int off = Math.min(wanted, onBoard);
        onBoard = onBoard - off;
        return off;
    }

    int board(int wanted) {
        int freeSeats = capacity - onBoard;
        int on = Math.min(wanted, freeSeats);
        onBoard = onBoard + on;
        carried = carried + on;
        return on;
    }
}

public class CampusShuttle {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Shuttle bus = new Shuttle();
        bus.route = in.nextLine();
        bus.capacity = in.nextInt();
        int stops = in.nextInt();

        for (int i = 1; i <= stops; i++) {
            int wantOff = in.nextInt();
            int wantOn = in.nextInt();
            int off = bus.alight(wantOff);
            int on = bus.board(wantOn);
            int leftBehind = wantOn - on;
            System.out.println("Stop " + i + ": " + off + " off, " + on + " on, "
                    + leftBehind + " left behind, " + bus.onBoard + " on board");
        }
        System.out.println(bus.route + " carried " + bus.carried + " passengers");
    }
}
```

### Explanation
The shuttle protects its own limits: `alight` never makes `onBoard` negative and `board`
never exceeds `capacity`. Each method returns the *actual* number, which may be smaller
than the request, so `main` can report the difference without knowing the rules. The
object keeps two kinds of state: `onBoard` goes up and down, while `carried` only grows.
At stop 4, 30 passengers want to leave but only 22 are on board, so `alight` returns 22.

## Problem 10: Exam Clash Checker
**Level:** Intermediate

### Problem Statement
Write a class `Clock` that stores a time of day in `int` fields `hour` (0–23) and
`minute` (0–59), with methods:

- `void set(int hour, int minute)` (use `this`);
- `Clock copy()`: returns a **new** `Clock` with the same time;
- `void advance(int minutes)`: moves the time forward (all times in this problem stay
  within one day);
- `boolean isBefore(Clock other)`: strictly earlier than `other`;
- `public String toString()`: `HH:MM` with two digits each.

Input: two lines, one per exam: `<hour> <minute> <durationMinutes>`. For exam A and
exam B print `Exam A: <start> - <end>` and `Exam B: <start> - <end>`, then `Clash: yes`
if the two exams overlap, otherwise `Clash: no`. Two exams overlap when each one starts
before the other ends; an exam that starts exactly when the other ends does not clash.

### Sample Input
```text
9 30 90
10 45 120
```

### Sample Output
```text
Exam A: 09:30 - 11:00
Exam B: 10:45 - 12:45
Clash: yes
```

### Solution
```java
import java.util.Scanner;

class Clock {
    int hour;
    int minute;

    void set(int hour, int minute) {
        this.hour = hour;
        this.minute = minute;
    }

    Clock copy() {
        Clock c = new Clock();
        c.set(hour, minute);
        return c;
    }

    void advance(int minutes) {
        int total = hour * 60 + minute + minutes;
        hour = total / 60;
        minute = total % 60;
    }

    boolean isBefore(Clock other) {
        return this.hour * 60 + this.minute < other.hour * 60 + other.minute;
    }

    public String toString() {
        return String.format("%02d:%02d", hour, minute);
    }
}

public class ExamClash {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Clock startA = new Clock();
        startA.set(in.nextInt(), in.nextInt());
        Clock endA = startA.copy();
        endA.advance(in.nextInt());

        Clock startB = new Clock();
        startB.set(in.nextInt(), in.nextInt());
        Clock endB = startB.copy();
        endB.advance(in.nextInt());

        System.out.println("Exam A: " + startA + " - " + endA);
        System.out.println("Exam B: " + startB + " - " + endB);
        boolean clash = startA.isBefore(endB) && startB.isBefore(endA);
        System.out.println("Clash: " + (clash ? "yes" : "no"));
    }
}
```

### Explanation
- The key line is `Clock endA = startA.copy();`. Writing `Clock endA = startA;` would
  only copy the reference: advancing `endA` would also move the start time, because both
  names would refer to one object. `copy()` uses `new`, so the end time is a separate
  object.
- `isBefore` compares the current object with another `Clock` by converting both to
  minutes since midnight.
- `toString()` uses `String.format("%02d:%02d", ...)` to add leading zeros, so 9:30
  prints as `09:30`.
- The clash test `startA < endB && startB < endA` uses strict comparisons, so exams that
  only touch (one ends at 11:00, the next starts at 11:00) do not clash.

## Problem 11: Library Desk
**Level:** Advanced

### Problem Statement
The library lends books to members. Write three classes:

- `Member`: `id`, `name`, `int limit` (how many books the member may hold), `int loans`.
- `Book`: `id`, `title` and a field `Member borrower` that refers to the member who has

At the end print every book as `<id> <title>: borrowed by <name>` or

### Solution
```java
import java.util.Scanner;

class Member {
    String id;
    String name;
    int limit;
    int loans;

    Member(String id, String name, int limit) {
        this.id = id;
        this.name = name;
        this.limit = limit;
    }

    boolean canBorrow() {
        return loans < limit;
    }

    public String toString() {
        return name + ": " + loans + " of " + limit + " loans";
    }
}

class Book {
    String id;
    String title;
    Member borrower;          // null while the book is on the shelf

    Book(String id, String title) {
        this.id = id;
        this.title = title;
    }

    boolean isAvailable() {
        return borrower == null;
    }

    public String toString() {
        if (isAvailable()) {
            return id + " " + title + ": available";
        }
        return id + " " + title + ": borrowed by " + borrower.name;
    }
}

class Library {
    Book book1;
    Book book2;
    Book book3;
    Member member1;
    Member member2;

    Book findBook(String id) {
        if (book1.id.equals(id)) {
            return book1;
        } else if (book2.id.equals(id)) {
            return book2;
        } else if (book3.id.equals(id)) {
            return book3;
        }
        return null;
    }

    Member findMember(String id) {
        if (member1.id.equals(id)) {
            return member1;
        } else if (member2.id.equals(id)) {
            return member2;
        }
        return null;
    }

    String borrow(Member m, Book b) {
        if (!b.isAvailable()) {
            return b.id + " is already borrowed by " + b.borrower.name;
        }
        if (!m.canBorrow()) {
            return m.name + " has reached the limit of " + m.limit;
        }
        b.borrower = m;
        m.loans++;
        return m.name + " borrowed " + b.id;
    }

    String giveBack(Member m, Book b) {
        if (b.borrower != m) {
            return b.id + " is not borrowed by " + m.name;
        }
        b.borrower = null;
        m.loans--;
        return m.name + " returned " + b.id;
    }

    String execute(String command, String memberId, String bookId) {
        Member m = findMember(memberId);
        if (m == null) {
            return "Unknown member " + memberId;
        }
        Book b = findBook(bookId);
        if (b == null) {
            return "Unknown book " + bookId;
        }
        if (command.equals("BORROW")) {
            return borrow(m, b);
        }
        return giveBack(m, b);
    }

    void printReport() {
        System.out.println(book1);
        System.out.println(book2);
        System.out.println(book3);
        System.out.println(member1);
        System.out.println(member2);
    }
}

public class LibraryDesk {
    static Book readBook(Scanner in) {
        String id = in.next();
        String title = in.nextLine().trim();
        return new Book(id, title);
    }

    static Member readMember(Scanner in) {
        String id = in.next();
        int limit = in.nextInt();
        String name = in.nextLine().trim();
        return new Member(id, name, limit);
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Library library = new Library();
        library.book1 = readBook(in);
        library.book2 = readBook(in);
        library.book3 = readBook(in);
        library.member1 = readMember(in);
        library.member2 = readMember(in);

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            String memberId = in.next();
            String bookId = in.next();
            System.out.println(library.execute(command, memberId, bookId));
        }
        library.printReport();
    }
}
```

### Explanation
- **A field can refer to another object.** `Book.borrower` is a `Member` reference. It
  answers "who has this book?" directly, and `null` means "nobody". This is the first
  time an object *holds* another object instead of just receiving it as a parameter.
- `b.borrower != m` compares references: it asks "is the borrower this very member
  object?", which is exactly the rule for returning a book. (Comparing objects in
  general is covered in Chapter 08.)
- `Library` is the coordinator: it finds objects by ID and applies the rules in the
  required order, while `Book` and `Member` answer simple questions about themselves
  (`isAvailable()`, `canBorrow()`). Each class has one clear job.
- Find methods return `null` for unknown IDs, and `execute` checks for `null` before
  using the reference, so the program never throws a `NullPointerException`.
- With only three books, separate fields are enough. Chapter 08 replaces them with an
  `ArrayList<Book>` so the library can hold any number of books.

## Problem 12: Mobile Wallet Service
**Level:** Advanced

### Problem Statement
A mobile wallet service (invented for practice) has three customers. Write:

- `Wallet`: `number`, `owner`, `int balance`, with `boolean canPay(int amount)`,
  `void add(int amount)`, `void take(int amount)` and `toString()` returning
  `<owner> (<number>): <balance> Tk`.
- `WalletService`: holds three `Wallet` fields and `int feesCollected`, finds a wallet
  by number (`null` if unknown) and runs the commands.

Commands (amounts are integers):

- `SEND <from> <to> <amount>`: free of charge.
- `CASHOUT <number> <amount>`: fee is 2% of the amount, computed as `amount / 50`
  (integer division); the wallet must hold `amount + fee`.
- `CASHIN <number> <amount>`: free.

For each command print one line, checking in this order: any unknown number gives
`Unknown wallet <number>` (check numbers in the order they appear); an amount of 0 or

`Cannot send to the same wallet`; if the paying wallet cannot pay the total, print
`Insufficient balance`. On success print one of:

commands. At the end print the three wallets and `Fees collected: <fees> Tk`.

### Sample Input
```text

01810000002 Fahim 1200
01910000003 Sadia 0
6
SEND 01710000001 01910000003 1500
CASHOUT 01910000003 1000

```

```text

Insufficient balance

Fahim (01810000002): 1500 Tk
```

### Solution
```java
import java.util.Scanner;

class Wallet {
    String number;
    String owner;
    int balance;

    Wallet(String number, String owner, int balance) {
        this.number = number;
        this.owner = owner;
        this.balance = balance;
    }

    boolean canPay(int amount) {
        return amount <= balance;
    }

    void add(int amount) {
        balance = balance + amount;
    }

    void take(int amount) {
        balance = balance - amount;
    }

    public String toString() {
        return owner + " (" + number + "): " + balance + " Tk";
    }
}

class WalletService {
    Wallet first;
    Wallet second;
    Wallet third;
    int feesCollected;

    Wallet find(String number) {
        if (first.number.equals(number)) {
            return first;
        } else if (second.number.equals(number)) {
            return second;
        } else if (third.number.equals(number)) {
            return third;
        }
        return null;
    }

    String send(String fromNumber, String toNumber, int amount) {
        Wallet from = find(fromNumber);
        if (from == null) {
            return "Unknown wallet " + fromNumber;
        }
        Wallet to = find(toNumber);
        if (to == null) {
            return "Unknown wallet " + toNumber;
        }
        if (amount <= 0) {
            return "Invalid amount";
        }
        if (from == to) {
            return "Cannot send to the same wallet";
        }
        if (!from.canPay(amount)) {
            return "Insufficient balance";
        }
        from.take(amount);
        to.add(amount);
        return "Sent " + amount + " Tk from " + from.owner + " to " + to.owner;
    }

    String cashOut(String number, int amount) {
        Wallet w = find(number);
        if (w == null) {
            return "Unknown wallet " + number;
        }
        if (amount <= 0) {
            return "Invalid amount";
        }
        int fee = amount / 50;
        if (!w.canPay(amount + fee)) {
            return "Insufficient balance";
        }
        w.take(amount + fee);
        feesCollected = feesCollected + fee;
        return w.owner + " cashed out " + amount + " Tk (fee " + fee + " Tk)";
    }

    String cashIn(String number, int amount) {
        Wallet w = find(number);
        if (w == null) {
            return "Unknown wallet " + number;
        }
        if (amount <= 0) {
            return "Invalid amount";
        }
        w.add(amount);
        return w.owner + " cashed in " + amount + " Tk";
    }

    void printReport() {
        System.out.println(first);
        System.out.println(second);
        System.out.println(third);
        System.out.println("Fees collected: " + feesCollected + " Tk");
    }
}

public class WalletServiceDemo {
    static Wallet readWallet(Scanner in) {
        String number = in.next();
        String owner = in.next();
        int balance = in.nextInt();
        return new Wallet(number, owner, balance);
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        WalletService service = new WalletService();
        service.first = readWallet(in);
        service.second = readWallet(in);
        service.third = readWallet(in);

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            String result;
            if (command.equals("SEND")) {
                String from = in.next();
                String to = in.next();
                result = service.send(from, to, in.nextInt());
            } else if (command.equals("CASHOUT")) {
                String number = in.next();
                result = service.cashOut(number, in.nextInt());
            } else {
                String number = in.next();
                result = service.cashIn(number, in.nextInt());
            }
            System.out.println(result);
        }
        service.printReport();
    }
}
```

### Explanation
- Wallet numbers are `String`s, not `long`s: they are labels that may start with `0`,
  and nobody does arithmetic on them.
- `Wallet` knows only about its own balance (`canPay`, `add`, `take`). The fee rule and
  the fee total belong to the service, not to any one wallet, so they live in
  `WalletService`. Deciding which class owns which rule is the main design skill here.
- `from == to` compares references: after `find`, two equal numbers give the very same
  `Wallet` object, so a self-transfer is detected without comparing strings again.
- Every check happens **before** any balance changes. A refused command leaves all
  three wallets exactly as they were, as the third and fifth commands show.

## Problem 13: Department Payroll
**Level:** Advanced

### Problem Statement
A university has two departments, each with a monthly salary budget, and three
employees. Write:

- `Department`: `name`, `int budget`, `int payroll` (sum of its employees' salaries),
  `int headcount`, with `boolean canAfford(int extra)`, `void add(Employee e)`,
  `void remove(Employee e)` and `toString()`:
  `<name>: <headcount> employee(s), payroll <payroll> of <budget> Tk`.
- `Employee`: `id`, `name`, `int salary`, and a field `Department department` (`null`

department name in the commands is valid.

and `n` commands. At the end print both departments, then the three employees.

### Solution
```java
import java.util.Scanner;

class Department {
    String name;
    int budget;
    int payroll;
    int headcount;

    Department(String name, int budget) {
        this.name = name;
        this.budget = budget;
    }

    boolean canAfford(int extra) {
        return payroll + extra <= budget;
    }

    void add(Employee e) {
        payroll = payroll + e.salary;
        headcount++;
        e.department = this;
    }

    void remove(Employee e) {
        payroll = payroll - e.salary;
        headcount--;
        e.department = null;
    }

    public String toString() {
        return name + ": " + headcount + " employee(s), payroll " + payroll
                + " of " + budget + " Tk";
    }
}

class Employee {
    String id;
    String name;
    int salary;
    Department department;

    Employee(String id, String name, int salary) {
        this.id = id;
        this.name = name;
        this.salary = salary;
    }

    public String toString() {
        String where = department == null ? "no department" : department.name;
        return name + " (" + where + "): " + salary + " Tk";
    }
}

class Company {
    Department deptA;
    Department deptB;
    Employee emp1;
    Employee emp2;
    Employee emp3;

    Department findDepartment(String name) {
        if (deptA.name.equals(name)) {
            return deptA;
        }
        return deptB;
    }

    Employee findEmployee(String id) {
        if (emp1.id.equals(id)) {
            return emp1;
        } else if (emp2.id.equals(id)) {
            return emp2;
        }
        return emp3;
    }

    String hire(Employee e, Department d) {
        if (e.department != null) {
            return e.name + " already works in " + e.department.name;
        }
        if (!d.canAfford(e.salary)) {
            return d.name + " cannot afford " + e.name;
        }
        d.add(e);
        return e.name + " joined " + d.name;
    }

    String move(Employee e, Department target) {
        Department old = e.department;
        if (old == null) {
            return e.name + " has no department";
        }
        if (old == target) {
            return e.name + " already works in " + target.name;
        }
        if (!target.canAfford(e.salary)) {
            return target.name + " cannot afford " + e.name;
        }
        old.remove(e);
        target.add(e);
        return e.name + " moved from " + old.name + " to " + target.name;
    }

    String raise(Employee e, int percent) {
        Department d = e.department;
        if (d == null) {
            return e.name + " has no department";
        }
        int extra = e.salary * percent / 100;
        if (!d.canAfford(extra)) {
            return d.name + " cannot afford the raise";
        }
        d.payroll = d.payroll + extra;
        e.salary = e.salary + extra;
        return e.name + " now earns " + e.salary + " Tk";
    }

    void printReport() {
        System.out.println(deptA);
        System.out.println(deptB);
        System.out.println(emp1);
        System.out.println(emp2);
        System.out.println(emp3);
    }
}

public class DepartmentPayroll {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Company company = new Company();
        company.deptA = new Department(in.next(), in.nextInt());
        company.deptB = new Department(in.next(), in.nextInt());
        company.emp1 = new Employee(in.next(), in.next(), in.nextInt());
        company.emp2 = new Employee(in.next(), in.next(), in.nextInt());
        company.emp3 = new Employee(in.next(), in.next(), in.nextInt());

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            Employee e = company.findEmployee(in.next());
            String result;
            if (command.equals("RAISE")) {
                result = company.raise(e, in.nextInt());
            } else if (command.equals("HIRE")) {
                result = company.hire(e, company.findDepartment(in.next()));
            } else {
                result = company.move(e, company.findDepartment(in.next()));
            }
            System.out.println(result);
        }
        company.printReport();
    }
}
```

### Explanation
- The link between an employee and a department is kept **on both sides**: the
  employee's `department` field, and the department's `payroll` and `headcount`.
  `Department.add` and `remove` update both sides in one place, with `e.department =
  this` storing a reference to the current department in the employee. If `main` did
  these updates by hand, sooner or later one side would be forgotten.
- `move` checks everything first and only then calls `old.remove(e)` and
  `target.add(e)`. A refused move changes nothing.
- `old == target` compares references: "is the target the department the employee is
  already in?"
- `raise` updates the department's payroll by exactly the extra amount, so payroll
  always equals the sum of salaries. In the sample: 35000 + 7000 = 42000, then
  42000 + 8400 = 50400.
- Arguments like `new Department(in.next(), in.nextInt())` are evaluated left to right,
  so the name is read before the budget.

## Problem 14: Room Planner
**Level:** Advanced

### Problem Statement
A hostel room planner places furniture on a rectangular floor. Write three classes:

- `Rectangle`: `int` fields `width` and `height`, `int area()`,
  `boolean canHold(Rectangle other)` (the other rectangle fits on this one, turned
  either way), and `toString()` returning `<width> x <height>`.
- `Furniture`: a `name` and a `Rectangle footprint`.
- `Room`: a `Rectangle floor`, `int usedArea`, `int items`, and a field
  `Furniture largest` (the placed item with the largest footprint area; the first one
  on a tie; `null` while the room is empty). Method `String place(Furniture f)`.

Rules for `place` (checked in this order):

1. If the floor cannot hold the footprint: `<name> refused: does not fit the floor`.
2. At most 80% of the floor area may be covered (the rest is walking space). If
   `usedArea + area > floorArea * 80 / 100`: `<name> refused: not enough free space`.
3. Otherwise the item is placed: `<name> placed (<area> sq ft)`.

Input: the floor's width and height, `n`, then `n` lines `<name> <width> <height>`
(one-word names). Print one line per item. Then print
`Room <floor>: <items> items, <used> of <floorArea> sq ft used (<percent>%)` where
`percent = used * 100 / floorArea` (integer division), and finally
`Largest item: <name> <footprint>` or `Largest item: none`.

### Sample Input
```text
12 10
6
Bed 7 5
Wardrobe 4 2
Desk 5 3
Carpet 13 9
Sofa 8 4
Table 3 3
```

### Sample Output
```text
Bed placed (35 sq ft)
Wardrobe placed (8 sq ft)
Desk placed (15 sq ft)
Carpet refused: does not fit the floor
Sofa placed (32 sq ft)
Table refused: not enough free space
Room 12 x 10: 4 items, 90 of 120 sq ft used (75%)
Largest item: Bed 7 x 5
```

### Solution
```java
import java.util.Scanner;

class Rectangle {
    int width;
    int height;

    Rectangle(int width, int height) {
        this.width = width;
        this.height = height;
    }

    int area() {
        return width * height;
    }

    boolean canHold(Rectangle other) {
        boolean straight = other.width <= width && other.height <= height;
        boolean turned = other.height <= width && other.width <= height;
        return straight || turned;
    }

    public String toString() {
        return width + " x " + height;
    }
}

class Furniture {
    String name;
    Rectangle footprint;

    Furniture(String name, Rectangle footprint) {
        this.name = name;
        this.footprint = footprint;
    }
}

class Room {
    Rectangle floor;
    int usedArea;
    int items;
    Furniture largest;

    Room(Rectangle floor) {
        this.floor = floor;
    }

    int maxCovered() {
        return floor.area() * 80 / 100;
    }

    String place(Furniture f) {
        int area = f.footprint.area();
        if (!floor.canHold(f.footprint)) {
            return f.name + " refused: does not fit the floor";
        }
        if (usedArea + area > maxCovered()) {
            return f.name + " refused: not enough free space";
        }
        usedArea = usedArea + area;
        items++;
        if (largest == null || area > largest.footprint.area()) {
            largest = f;
        }
        return f.name + " placed (" + area + " sq ft)";
    }

    public String toString() {
        int total = floor.area();
        return "Room " + floor + ": " + items + " items, " + usedArea + " of " + total
                + " sq ft used (" + usedArea * 100 / total + "%)";
    }
}

public class RoomPlanner {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Room room = new Room(new Rectangle(in.nextInt(), in.nextInt()));
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String name = in.next();
            Rectangle footprint = new Rectangle(in.nextInt(), in.nextInt());
            Furniture f = new Furniture(name, footprint);
            System.out.println(room.place(f));
        }
        System.out.println(room);
        if (room.largest == null) {
            System.out.println("Largest item: none");
        } else {
            System.out.println("Largest item: " + room.largest.name + " "
                    + room.largest.footprint);
        }
    }
}
```

### Explanation
- **Reuse through objects:** both the floor and every piece of furniture are
  `Rectangle`s. The size logic (`area`, `canHold`, `toString`) is written once and used
  by `Room` and `Furniture`. An object that contains other objects as fields is called
  *composition* (a room *has a* floor; Chapter 09 compares it with inheritance).
- A chain like `room.largest.footprint` follows references from one object to the next:
  the room, then its largest furniture, then that furniture's rectangle.
- `place` checks both rules before changing anything, and keeps `largest` up to date
  with a reference to an existing `Furniture` object, the same "best so far" pattern
  as Problem 7.
- The 80% limit is computed with integers (`120 * 80 / 100 = 96`), so the Table
  (90 + 9 = 99 sq ft) is refused while the Sofa (58 + 32 = 90) was accepted.

## Problem 15: Arena Duel
**Level:** Advanced

### Problem Statement
A simple turn-based game. Write three classes:

- `Weapon`: `name`, `int damage`, `int uses` (how many hits are left).
- `Player`: `name`, `int health`, a `Weapon weapon`, and `int attacks` (how many attacks
  this player has made). Method `void attack(Player target)`.
- `Battle`: two `Player` fields and `void fight(int maxRounds)`.

Attack rules:

- If the weapon has uses left, the hit uses it (`uses` goes down by one) and deals the
  weapon's damage. Otherwise the player fights with `fists` for 2 damage.
- Every third attack of a player (its 3rd, 6th, 9th, ...) deals **double** damage.
- Health never goes below 0.

Each attack prints
`<attacker> -> <target>: <weapon or fists>, <damage> damage, <target> has <hp> HP`,
with ` (critical)` after `damage` for a doubled hit.

`fight` runs rounds numbered from 1. Each round prints `Round <r>`, then the first
player attacks, then the second player attacks if still alive. As soon as a player's
health is 0, print `<loser> is defeated. Winner: <winner>` and stop. If `maxRounds`
rounds end with both alive, print `Time up. Winner: <name>` for the player with more
health, or `Time up. Draw` when health is equal.

Input: two lines `<name> <health> <weaponName> <damage> <uses>`, then `maxRounds`.

### Sample Input
```text
Rafi 30 Sword 7 3
Sadia 34 Bow 5 6
10
```

### Sample Output
```text
Round 1
Rafi -> Sadia: Sword, 7 damage, Sadia has 27 HP
Sadia -> Rafi: Bow, 5 damage, Rafi has 25 HP
Round 2
Rafi -> Sadia: Sword, 7 damage, Sadia has 20 HP
Sadia -> Rafi: Bow, 5 damage, Rafi has 20 HP
Round 3
Rafi -> Sadia: Sword, 14 damage (critical), Sadia has 6 HP
Sadia -> Rafi: Bow, 10 damage (critical), Rafi has 10 HP
Round 4
Rafi -> Sadia: fists, 2 damage, Sadia has 4 HP
Sadia -> Rafi: Bow, 5 damage, Rafi has 5 HP
Round 5
Rafi -> Sadia: fists, 2 damage, Sadia has 2 HP
Sadia -> Rafi: Bow, 5 damage, Rafi has 0 HP
Rafi is defeated. Winner: Sadia
```

### Solution
```java
import java.util.Scanner;

class Weapon {
    String name;
    int damage;
    int uses;

    Weapon(String name, int damage, int uses) {
        this.name = name;
        this.damage = damage;
        this.uses = uses;
    }
}

class Player {
    String name;
    int health;
    Weapon weapon;
    int attacks;

    Player(String name, int health, Weapon weapon) {
        this.name = name;
        this.health = health;
        this.weapon = weapon;
    }

    boolean isAlive() {
        return health > 0;
    }

    void takeDamage(int amount) {
        health = Math.max(0, health - amount);
    }

    void attack(Player target) {
        attacks++;
        String using = "fists";
        int hit = 2;
        if (weapon.uses > 0) {
            weapon.uses--;
            using = weapon.name;
            hit = weapon.damage;
        }
        String note = "";
        if (attacks % 3 == 0) {
            hit = hit * 2;
            note = " (critical)";
        }
        target.takeDamage(hit);
        System.out.println(this.name + " -> " + target.name + ": " + using + ", " + hit
                + " damage" + note + ", " + target.name + " has " + target.health + " HP");
    }
}

class Battle {
    Player first;
    Player second;

    Battle(Player first, Player second) {
        this.first = first;
        this.second = second;
    }

    void fight(int maxRounds) {
        for (int round = 1; round <= maxRounds; round++) {
            System.out.println("Round " + round);
            first.attack(second);
            if (!second.isAlive()) {
                announce(second, first);
                return;
            }
            second.attack(first);
            if (!first.isAlive()) {
                announce(first, second);
                return;
            }
        }
        if (first.health > second.health) {
            System.out.println("Time up. Winner: " + first.name);
        } else if (second.health > first.health) {
            System.out.println("Time up. Winner: " + second.name);
        } else {
            System.out.println("Time up. Draw");
        }
    }

    void announce(Player loser, Player winner) {
        System.out.println(loser.name + " is defeated. Winner: " + winner.name);
    }
}

public class ArenaDuel {
    static Player readPlayer(Scanner in) {
        String name = in.next();
        int health = in.nextInt();
        Weapon weapon = new Weapon(in.next(), in.nextInt(), in.nextInt());
        return new Player(name, health, weapon);
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Player p1 = readPlayer(in);
        Player p2 = readPlayer(in);
        int maxRounds = in.nextInt();
        Battle battle = new Battle(p1, p2);
        battle.fight(maxRounds);
    }
}
```

### Explanation
- Each class owns its own state: a `Weapon` counts its remaining uses, a `Player` counts
  its own attacks and protects its health (`takeDamage` never goes below 0), and the
  `Battle` controls the order of turns and decides the result.
- In `attack(Player target)`, `this` is the attacker and `target` is the defender. The
  attacker changes its own weapon and counter, then *asks* the target to take damage
  instead of changing `target.health` directly.
- Every player has its own `Weapon` object, so Rafi's sword breaking (no uses left after
  three hits, then `fists`) has no effect on Sadia's bow.
- `announce(loser, winner)` is called with the arguments in the right order for each
  case, so the same method prints both possible endings.
- The game is fully deterministic, which makes it easy to test: change the input and
  trace the rounds by hand to check the "time up" and "draw" endings.
