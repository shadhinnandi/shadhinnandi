# Practice Problems: Introduction to Java and OOP

These problems use only what Chapter 00 introduces: output, simple variables and
arithmetic, messages sent to `String` and `Math`, and `Scanner` as a ready-made object.
There are no `if` statements or loops yet, so every problem is about careful

## Problem 1: Plus Means Two Things
**Level:** Basic

### Problem Statement
In Java, `+` adds numbers but joins text. Read two integers `a` and `b` (on one line)
and print exactly five lines:

1. `Sum: ` followed by `a + b`
2. `Joined: ` followed by the digits of `a` and `b` written side by side
3. the value of `a + b` followed by ` is the sum`
4. `Product: ` followed by `a * b`
5. `Difference: ` followed by `a - b`

Build every line with a single `System.out.println` call and the `+` operator. Decide
for each line whether you need parentheses.

### Sample Input
```text
7 5
```

### Sample Output
```text
Sum: 12
Joined: 75
12 is the sum
Product: 35
Difference: 2
```

### Solution
```java
import java.util.Scanner;

public class PlusTwoMeanings {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int a = in.nextInt();
        int b = in.nextInt();

        System.out.println("Sum: " + (a + b));
        System.out.println("Joined: " + a + b);
        System.out.println(a + b + " is the sum");
        System.out.println("Product: " + a * b);
        System.out.println("Difference: " + (a - b));
    }
}
```

### Explanation
- `+` is evaluated from left to right. In line 2, `"Joined: " + a` is already a
  string, so `b` is appended as text: `75`.
- In line 3 the two numbers come first, so `a + b` is ordinary addition, and only then
  is the text attached.
- Line 4 needs no parentheses because `*` has higher precedence than `+`: the product
  is computed before any joining happens.
- Line 5 *does* need parentheses. Without them, `"Difference: " + a - b` means
  `("Difference: " + a) - b`, which tries to subtract a number from a string, and the
  compiler rejects it.

## Problem 2: Name Badge Box
**Level:** Basic

### Problem Statement
The orientation desk prints name badges with a box drawn around the name. Read one
line containing a full name (it may contain spaces, and may have extra spaces before
or after it). Print the name in upper case inside a box like the sample: a border line
of `+`, dashes and `+`, then `| NAME |`, then the border again. The box must fit the
name exactly, whatever its length: there is one space on each side of the name.

### Sample Input
```text
Nusrat Jahan
```

### Sample Output
```text
+--------------+
| NUSRAT JAHAN |
+--------------+
```

### Solution
```java
import java.util.Scanner;

public class NameBadgeBox {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String name = in.nextLine().trim().toUpperCase();

        // the inside of the box is: space + name + space
        String border = "+" + "-".repeat(name.length() + 2) + "+";

        System.out.println(border);
        System.out.println("| " + name + " |");
        System.out.println(border);
    }
}
```

### Explanation
- `nextLine()` reads the whole line, so names with spaces work.
- `in.nextLine().trim().toUpperCase()` is a chain of messages: each method returns a
  new `String`, and the next message is sent to that new string. `trim()` removes the
  extra spaces at the ends, `toUpperCase()` capitalises.
- The middle line is `"| " + name + " |"`, so the inside is `name.length() + 2`
  characters wide. `"-".repeat(n)` builds a string of `n` dashes, which is exactly the
  border we need without any loop.
- The border is computed once and printed twice.

## Problem 3: Messages to One String
**Level:** Basic

### Problem Statement
Read one word. Send it several messages and print each reply in the format
`<message> -> <reply>`, exactly as in the sample: `length()`, `toUpperCase()`,
`toLowerCase()`, `charAt(0)`, `indexOf("g")`, `replace("m", "M")` and `substring(3)`.
Print `Original: <word>` first and `After all messages: <word>` last.

The word has at least 4 letters. If it contains no `g`, `indexOf` replies `-1`; that
is fine, print the reply as it is.

### Sample Input
```text
Programming
```

### Sample Output
```text
Original: Programming
length() -> 11
toUpperCase() -> PROGRAMMING
toLowerCase() -> programming
charAt(0) -> P
indexOf("g") -> 3
replace("m", "M") -> PrograMMing
substring(3) -> gramming
After all messages: Programming
```

### Solution
```java
import java.util.Scanner;

public class StringMessages {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String word = in.next();

        System.out.println("Original: " + word);
        System.out.println("length() -> " + word.length());
        System.out.println("toUpperCase() -> " + word.toUpperCase());
        System.out.println("toLowerCase() -> " + word.toLowerCase());
        System.out.println("charAt(0) -> " + word.charAt(0));
        System.out.println("indexOf(\"g\") -> " + word.indexOf("g"));
        System.out.println("replace(\"m\", \"M\") -> " + word.replace("m", "M"));
        System.out.println("substring(3) -> " + word.substring(3));
        System.out.println("After all messages: " + word);
    }
}
```

### Explanation
- Each call such as `word.toUpperCase()` sends a message to the `String` object
  `word`, and the object replies with a value. The receiver decides how to answer;
  we only see the reply.
- Indexes start at 0: in `Programming`, `P` is at 0 and the first `g` is at 3, so
  `substring(3)` starts at that `g`.
- `\"` inside a string literal prints a double quote character; it is needed to show
  `"g"` in the output.
- The last line proves that none of the messages changed `word`. Methods like
  `toUpperCase` and `replace` return *new* strings, because Java strings are
  immutable.

## Problem 4: Classroom Floor Measurements
**Level:** Basic

### Problem Statement
The facilities office is retiling a classroom. Read the room's length and width in
whole metres (two integers on one line) and print:

- `Area: <area> square metres`
- `Perimeter: <perimeter> metres`
- `Tiles needed: <n>`, where each tile is 50 cm by 50 cm (four tiles per square
  metre)
- `Diagonal: <d> cm`, the length of the room's diagonal rounded to the nearest
  centimetre

### Sample Input
```text
9 7
```

### Sample Output
```text
Area: 63 square metres
Perimeter: 32 metres
Tiles needed: 252
Diagonal: 1140 cm
```

### Solution
```java
import java.util.Scanner;

public class ClassroomFloor {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int length = in.nextInt();
        int width = in.nextInt();

        int area = length * width;
        int perimeter = 2 * (length + width);
        int tiles = area * 4;
        double diagonalMetres = Math.sqrt(length * length + width * width);

        System.out.println("Area: " + area + " square metres");
        System.out.println("Perimeter: " + perimeter + " metres");
        System.out.println("Tiles needed: " + tiles);
        System.out.println("Diagonal: " + Math.round(diagonalMetres * 100) + " cm");
    }
}
```

### Explanation
- Area, perimeter and tiles are whole-number arithmetic, so `int` is the right type.
- The diagonal comes from Pythagoras: `sqrt(9 * 9 + 7 * 7) = sqrt(130)`, about
  `11.4018` metres. `Math.sqrt` returns a `double`.
- Printing that `double` directly would show many digits. Converting to centimetres
  (`* 100`) and sending it to `Math.round` gives a clean whole number: `1140`.
- `Math.round` returns the nearest whole number. We print it straight away, so we do
  not need to store it.

## Problem 5: Mobile Wallet Transfer Slip
**Level:** Intermediate

### Problem Statement
A mobile wallet app shows a confirmation slip before money is sent. Read the sender's
phone number, the receiver's phone number (each a string of digits, at least 7 long)
and the amount in Tk (an integer), each on its own line.

Print the slip as in the sample. A phone number is masked: keep the first 3 and the
last 3 digits and replace every digit in between with `*`. The fee is 1.5% of the
amount, rounded to the nearest Tk. The total deducted is the amount plus the fee.

### Sample Input
```text
01712345678
01898765432
2400
```

### Sample Output
```text
From: 017*****678
To: 018*****432
Amount: 2400 Tk
Fee (1.5%): 36 Tk
Total deducted: 2436 Tk
```

### Solution
```java
import java.util.Scanner;

public class TransferSlip {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String sender = in.next();
        String receiver = in.next();
        int amount = in.nextInt();

        String maskedSender = sender.substring(0, 3)
                + "*".repeat(sender.length() - 6)
                + sender.substring(sender.length() - 3);
        String maskedReceiver = receiver.substring(0, 3)
                + "*".repeat(receiver.length() - 6)
                + receiver.substring(receiver.length() - 3);

        // Math.round returns a long: a whole-number type larger than int (Chapter 01)
        long fee = Math.round(amount * 1.5 / 100);
        long total = amount + fee;

        System.out.println("From: " + maskedSender);
        System.out.println("To: " + maskedReceiver);
        System.out.println("Amount: " + amount + " Tk");
        System.out.println("Fee (1.5%): " + fee + " Tk");
        System.out.println("Total deducted: " + total + " Tk");
    }
}
```

### Explanation
- The mask has three parts: `substring(0, 3)` (first three digits), a run of stars,
  and `substring(length - 3)` (last three digits). The number of stars is
  `length - 6`, so the masked number has the same length as the original, whatever
  that length is.
- Reading the phone numbers with `next()` keeps them as `String`. A phone number is
  text, not a quantity: we never do arithmetic on it, and a leading `0` must not be
  lost.
- `amount * 1.5 / 100` is a `double` (`36.0` here); `Math.round` turns it into the
  nearest whole number. `Math.round` replies with a `long`, so `fee` and `total` are
  declared `long`.
- The masking code is written twice. In Chapter 03 you will move it into a method and
  call it for each number.

## Problem 6: Campus Account Generator
**Level:** Intermediate

### Problem Statement
When a student is admitted, the IT office creates a campus account. Read two lines:

1. the full name: exactly two words separated by one space, possibly with extra
   spaces before the first word
2. the 9-digit student ID, where digits 4 to 6 are the batch number (for example in
   `011221234` the batch is `221`)

Print:

- `Name: ` and the cleaned name (no extra spaces)
- `Username: ` the name in lower case with the space replaced by a dot
- `Email: ` the username, a dot, the last 3 digits of the ID, then
  `@students.example.edu`
- `Initials: ` the first letter of each word
- `Batch: ` the batch number

### Sample Input
```text
   Nusrat Jahan
011221234
```

### Sample Output
```text
Name: Nusrat Jahan
Username: nusrat.jahan
Email: nusrat.jahan.234@students.example.edu
Initials: NJ
Batch: 221
```

### Solution
```java
import java.util.Scanner;

public class CampusAccount {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String name = in.nextLine().trim();
        String id = in.nextLine().trim();

        String username = name.toLowerCase().replace(" ", ".");
        String email = username + "." + id.substring(id.length() - 3)
                + "@students.example.edu";

        int space = name.indexOf(" ");
        String initials = name.substring(0, 1) + name.substring(space + 1, space + 2);
        String batch = id.substring(3, 6);

        System.out.println("Name: " + name);
        System.out.println("Username: " + username);
        System.out.println("Email: " + email);
        System.out.println("Initials: " + initials);
        System.out.println("Batch: " + batch);
    }
}
```

### Explanation
- `trim()` must come first: the leading spaces would otherwise end up in the username
  and shift every index.
- `name.toLowerCase().replace(" ", ".")` is a message chain. `toLowerCase()` replies
  with a new string, and `replace` is sent to that reply.
- The first letter of the second word is right after the space, so its index is
  `space + 1`. `substring(space + 1, space + 2)` cuts out exactly one character as a
  `String`.
- "Digits 4 to 6" in human counting are indexes 3, 4 and 5, which is
  `substring(3, 6)`: the end index is not included.
- The ID is kept as a `String` because it is an identifier, not a number to
  calculate with; reading it as a number would also lose the leading `0`.

## Problem 7: Rotate the Duty Roster
**Level:** Intermediate

### Problem Statement
Three hostel residents share reading-room duty on Saturday, Sunday and Monday. Each
week the roster rotates: every person moves one day later, and the Monday person moves
to Saturday.

Read three names (one word each) for Saturday, Sunday and Monday of this week. Print
this week, next week and the week after in the format of the sample. Use exactly three
variables for the days (plus one temporary variable), and change them in place.

### Sample Input
```text
Rahim Karim Sadia
```

### Sample Output
```text
This week: Sat=Rahim, Sun=Karim, Mon=Sadia
Next week: Sat=Sadia, Sun=Rahim, Mon=Karim
Week after: Sat=Karim, Sun=Sadia, Mon=Rahim
```

### Solution
```java
import java.util.Scanner;

public class DutyRoster {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String sat = in.next();
        String sun = in.next();
        String mon = in.next();
        String temp;

        System.out.println("This week: Sat=" + sat + ", Sun=" + sun + ", Mon=" + mon);

        // rotate: save Monday first, then shift from the end towards the start
        temp = mon;
        mon = sun;
        sun = sat;
        sat = temp;
        System.out.println("Next week: Sat=" + sat + ", Sun=" + sun + ", Mon=" + mon);

        temp = mon;
        mon = sun;
        sun = sat;
        sat = temp;
        System.out.println("Week after: Sat=" + sat + ", Sun=" + sun + ", Mon=" + mon);
    }
}
```

### Explanation
- A variable holds one value at a time; assigning to it destroys the old value.
  Statements run strictly from top to bottom, so the order of the assignments matters.
- If we wrote `sun = sat;` first, Sunday's old name would be lost before we copied it
  to Monday. Saving Monday in `temp` and shifting from the end (`mon = sun`, then
  `sun = sat`) means every value is copied before it is overwritten.
- `temp` finally lands in `sat`, completing the circle.
- The same four statements appear twice. A loop (Chapter 02) or a method (Chapter 03)
  would remove that repetition; for now, repeating them shows the exact sequence.

## Problem 8: Best Two of Three Quizzes
**Level:** Intermediate

### Problem Statement
A course counts the best two of three quiz marks. Read three integer marks (out of 15)
on one line and print:

- `Quizzes: a, b, c` (in input order)
- `Highest: ` the highest mark
- `Lowest: ` the lowest mark (the one that is dropped)
- `Best two total: ` the sum of the two best marks
- `Best two average: ` that sum divided by 2, as a decimal number
- `Spread: ` highest minus lowest

Solve it without `if` statements: use `Math.max` and `Math.min`.

### Sample Input
```text
8 5 9
```

### Sample Output
```text
Quizzes: 8, 5, 9
Highest: 9
Lowest: 5
Best two total: 17
Best two average: 8.5
Spread: 4
```

### Solution
```java
import java.util.Scanner;

public class BestTwoQuizzes {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int q1 = in.nextInt();
        int q2 = in.nextInt();
        int q3 = in.nextInt();

        int highest = Math.max(q1, Math.max(q2, q3));
        int lowest = Math.min(q1, Math.min(q2, q3));
        int bestTwo = q1 + q2 + q3 - lowest;
        double average = bestTwo / 2.0;

        System.out.println("Quizzes: " + q1 + ", " + q2 + ", " + q3);
        System.out.println("Highest: " + highest);
        System.out.println("Lowest: " + lowest);
        System.out.println("Best two total: " + bestTwo);
        System.out.println("Best two average: " + average);
        System.out.println("Spread: " + (highest - lowest));
    }
}
```

### Explanation
- `Math.max` takes two values, so for three values we nest the calls:
  `Math.max(q1, Math.max(q2, q3))`. The inner message is answered first, and its reply
  becomes an argument of the outer one.
- "Best two" does not require finding the second-best mark: it is simply the total
  minus the lowest mark. Rethinking the question often removes the need for
  comparisons.
- Dividing by `2.0` (not `2`) makes the result a `double`, so `17 / 2.0` is `8.5`.
  Half-marks are always exact in a `double`, so the output is clean.
- The parentheses in `(highest - lowest)` are required, as in Problem 1.

## Problem 9: Aligned Canteen Receipt
**Level:** Advanced

### Problem Statement
The canteen wants receipts with the amounts lined up on the right edge. Read three
lines, each with an item name (one word), a quantity and a unit price in Tk. Print a
receipt exactly 30 characters wide:

- a line of 30 `=`, the title `CAMPUS CANTEEN RECEIPT`, and another line of 30 `=`
- one line per item: `<name> x<qty>` on the left and the line amount
  (quantity times price) on the right, ending at column 30
- a line of 30 `-`, then `Subtotal` and `VAT 5%` lines aligned the same way; VAT is 5%
  of the subtotal rounded to the nearest Tk
- a line of 30 `=`, then `TOTAL` (subtotal plus VAT) aligned the same way

Every left part plus its amount is shorter than 30 characters.

### Sample Input
```text
Khichuri 2 60
Tea 3 15
Singara 4 10
```

### Sample Output
```text
==============================
CAMPUS CANTEEN RECEIPT
==============================
Khichuri x2                120
Tea x3                      45
Singara x4                  40
------------------------------
Subtotal                   205
VAT 5%                      10
==============================
TOTAL                      215
```

### Solution
```java
import java.util.Scanner;

public class AlignedReceipt {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int width = 30;

        String item1 = in.next();
        int qty1 = in.nextInt();
        int price1 = in.nextInt();
        String item2 = in.next();
        int qty2 = in.nextInt();
        int price2 = in.nextInt();
        String item3 = in.next();
        int qty3 = in.nextInt();
        int price3 = in.nextInt();

        int amount1 = qty1 * price1;
        int amount2 = qty2 * price2;
        int amount3 = qty3 * price3;
        int subtotal = amount1 + amount2 + amount3;
        long vat = Math.round(subtotal * 5 / 100.0);
        long total = subtotal + vat;

        String doubleRule = "=".repeat(width);
        String singleRule = "-".repeat(width);

        // each line: left text + enough spaces + right text = width characters
        String left1 = item1 + " x" + qty1;
        String right1 = "" + amount1;
        String left2 = item2 + " x" + qty2;
        String right2 = "" + amount2;
        String left3 = item3 + " x" + qty3;
        String right3 = "" + amount3;
        String rightSub = "" + subtotal;
        String rightVat = "" + vat;
        String rightTotal = "" + total;

        System.out.println(doubleRule);
        System.out.println("CAMPUS CANTEEN RECEIPT");
        System.out.println(doubleRule);
        System.out.println(left1 + " ".repeat(width - left1.length() - right1.length())
                + right1);
        System.out.println(left2 + " ".repeat(width - left2.length() - right2.length())
                + right2);
        System.out.println(left3 + " ".repeat(width - left3.length() - right3.length())
                + right3);
        System.out.println(singleRule);
        System.out.println("Subtotal" + " ".repeat(width - 8 - rightSub.length())
                + rightSub);
        System.out.println("VAT 5%" + " ".repeat(width - 6 - rightVat.length())
                + rightVat);
        System.out.println(doubleRule);
        System.out.println("TOTAL" + " ".repeat(width - 5 - rightTotal.length())
                + rightTotal);
    }
}
```

### Explanation
- **Right alignment without `printf`.** A line is `left + spaces + right`, and it must
  be exactly `width` characters. So the number of spaces is
  `width - left.length() - right.length()`, and `" ".repeat(...)` produces them.
- To measure how many characters a number takes, we first turn it into text:
  `"" + amount1` is a `String`, so `.length()` can be sent to it. (`120` has 3
  characters, `45` has 2.)
- For the fixed labels the length is known: `"Subtotal"` has 8 characters,
  `"VAT 5%"` has 6, `"TOTAL"` has 5.
- VAT: `subtotal * 5 / 100.0` is `10.25` for the sample; `Math.round` gives `10`. The
  `100.0` makes the division happen in `double` so the fraction is not lost before
  rounding.
- Storing `width` in one variable means the whole receipt can be widened by changing a
  single number.
- The program is long because the same alignment step is written six times. In
  Chapter 01 you will meet `printf("%-20s%10d")`, which aligns columns directly, and in
  Chapter 03 you will turn the repeated step into a method. Doing it by hand once
  teaches what those tools do for you.

## Problem 10: Course Record Parser
**Level:** Advanced

### Problem Statement
The registration system exports each course as one line with four fields separated by
semicolons: course code, title, credits and instructor. Fields may have extra spaces
around them, and the code may be in lower case. The code is always a department and a
number separated by one space; the instructor's name is at least two words.

Read the line and print:

- `Code: ` the code in upper case
- `Department: ` and `Number: ` the two parts of the code
- `Title: `, `Credits: `, `Instructor: ` the cleaned fields
- `Label: ` the code without its space, then ` (<credits> cr, <short name>)`, where
  the short name is the instructor's first initial, a dot, a space and their last word

### Sample Input
```text
cse 1115 ;  Object Oriented Programming ; 3 ;Ayesha Siddika Rahman
```

### Sample Output
```text
Code: CSE 1115
Department: CSE
Number: 1115
Title: Object Oriented Programming
Credits: 3
Instructor: Ayesha Siddika Rahman
Label: CSE1115 (3 cr, A. Rahman)
```

### Solution
```java
import java.util.Scanner;

public class CourseRecordParser {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String line = in.nextLine();

        // positions of the three separators
        int sep1 = line.indexOf(";");
        int sep2 = line.indexOf(";", sep1 + 1);
        int sep3 = line.indexOf(";", sep2 + 1);

        // cut out each field, then clean it
        String code = line.substring(0, sep1).trim().toUpperCase();
        String title = line.substring(sep1 + 1, sep2).trim();
        String credits = line.substring(sep2 + 1, sep3).trim();
        String instructor = line.substring(sep3 + 1).trim();

        // split the code at its space
        int codeSpace = code.indexOf(" ");
        String department = code.substring(0, codeSpace);
        String number = code.substring(codeSpace + 1);

        // short name: first letter + last word
        String lastWord = instructor.substring(instructor.lastIndexOf(" ") + 1);
        String shortName = instructor.substring(0, 1) + ". " + lastWord;

        System.out.println("Code: " + code);
        System.out.println("Department: " + department);
        System.out.println("Number: " + number);
        System.out.println("Title: " + title);
        System.out.println("Credits: " + credits);
        System.out.println("Instructor: " + instructor);
        System.out.println("Label: " + code.replace(" ", "") + " (" + credits + " cr, "
                + shortName + ")");
    }
}
```

### Explanation
- **Finding the fields.** `indexOf(";")` finds the first separator. The two-argument
  form `indexOf(";", from)` starts searching at index `from`, so starting at
  `sep1 + 1` finds the second separator, and so on. Each search builds on the previous
  answer.
- **Cutting the fields.** The text between two separators is
  `substring(sepA + 1, sepB)`: start just after one separator, stop just before the
  next. The last field runs to the end of the line, so it uses the one-argument
  `substring`.
- **Cleaning.** `trim()` is sent to each piece before it is used; otherwise
  `"  Object Oriented Programming "` would keep its spaces. The order matters for the
  code: we trim and upper-case it *before* searching for its space.
- **The short name.** `lastIndexOf(" ")` finds the *last* space, which works for
  names of two, three or more words. A plain `indexOf(" ")` would give
  `Siddika Rahman` here.
- This is exactly what parsing a line of a CSV file looks like. In Chapter 12 you will
  read such lines from files.

## Problem 11: Triangular Plot Survey
**Level:** Advanced

### Problem Statement
A triangular plot beside the campus pond needs a fence. Read the three side lengths in
whole metres (in any order, on one line; they always form a valid triangle). Print:

- `Sides (shortest to longest): ` the three sides in increasing order
- `Perimeter: <p> m`
- `Fence cost: <c> Tk` at 120 Tk per metre
- `Area: <a> square metres`, rounded to the nearest whole number
- `Height to the longest side: <h> m`, rounded to the nearest whole number

Use Heron's formula: with semi-perimeter `s = (x + y + z) / 2`, the area is
`sqrt(s * (s - x) * (s - y) * (s - z))`. The height to a side is `2 * area / side`.
Do not use `if` statements.

### Sample Input
```text
14 13 15
```

### Sample Output
```text
Sides (shortest to longest): 13 14 15
Perimeter: 42 m
Fence cost: 5040 Tk
Area: 84 square metres
Height to the longest side: 11 m
```

### Solution
```java
import java.util.Scanner;

public class TriangularPlot {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int x = in.nextInt();
        int y = in.nextInt();
        int z = in.nextInt();
        int ratePerMetre = 120;

        // order the sides without comparisons written by hand
        int shortest = Math.min(x, Math.min(y, z));
        int longest = Math.max(x, Math.max(y, z));
        int perimeter = x + y + z;
        int middle = perimeter - shortest - longest;

        // Heron's formula; s may be a half number, so it is a double
        double s = perimeter / 2.0;
        double area = Math.sqrt(s * (s - x) * (s - y) * (s - z));
        double height = 2 * area / longest;

        System.out.println("Sides (shortest to longest): " + shortest + " " + middle
                + " " + longest);
        System.out.println("Perimeter: " + perimeter + " m");
        System.out.println("Fence cost: " + perimeter * ratePerMetre + " Tk");
        System.out.println("Area: " + Math.round(area) + " square metres");
        System.out.println("Height to the longest side: " + Math.round(height) + " m");
    }
}
```

### Explanation
- **Sorting three values without `if`.** `Math.min` and `Math.max` give the smallest
  and largest. The middle one is whatever is left: total minus smallest minus largest.
  This works even when two sides are equal.
- **Why `2.0`.** For sides `3 4 6` the perimeter is 13, and `s` must be `6.5`. Writing
  `perimeter / 2.0` keeps the half; the formula would be wrong with a rounded `s`.
- For the sample, `s = 21`, so the area is `sqrt(21 * 8 * 7 * 6) = sqrt(7056) = 84`.
  The height is `2 * 84 / 15 = 11.2`, which rounds to `11`.
- The unrounded `area` is used to compute the height. Rounding only at the moment of
  printing avoids building one rounding error on top of another.
- `perimeter * ratePerMetre` needs no parentheses inside the concatenation, because
  `*` is applied before `+`.

## Problem 12: Campus Shuttle Arrival Time
**Level:** Advanced

### Problem Statement
The night shuttle leaves the campus at a given time and takes a given number of
minutes. Read three integers on one line: the departure hour (0 to 23), the departure
minute (0 to 59) and the trip length in minutes (0 to 1000). Print:

- `Departure: HH:MM`
- `Trip length: <h> h <m> min`
- `Arrival: HH:MM` on a 24-hour clock (after `23:59` comes `00:00`)

Hours and minutes in `HH:MM` always have two digits (`07:05`, not `7:5`). Do not use
`if` statements or `printf`.

### Sample Input
```text
22 45 95
```

### Sample Output
```text
Departure: 22:45
Trip length: 1 h 35 min
Arrival: 00:20
```

### Solution
```java
import java.util.Scanner;

public class ShuttleArrival {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int hour = in.nextInt();
        int minute = in.nextInt();
        int trip = in.nextInt();

        // work in "minutes since midnight", then convert back
        int start = hour * 60 + minute;
        int end = start + trip;
        int arrivalHour = end / 60 % 24;
        int arrivalMinute = end % 60;

        // two-digit text: put a 0 in front, then keep the last two characters
        String depH = "0" + hour;
        depH = depH.substring(depH.length() - 2);
        String depM = "0" + minute;
        depM = depM.substring(depM.length() - 2);
        String arrH = "0" + arrivalHour;
        arrH = arrH.substring(arrH.length() - 2);
        String arrM = "0" + arrivalMinute;
        arrM = arrM.substring(arrM.length() - 2);

        System.out.println("Departure: " + depH + ":" + depM);
        System.out.println("Trip length: " + trip / 60 + " h " + trip % 60 + " min");
        System.out.println("Arrival: " + arrH + ":" + arrM);
    }
}
```

### Explanation
- **Two new operators.** With `int` values, `/` gives the whole-number quotient and
  drops the remainder (`95 / 60` is `1`), and `%` gives the remainder (`95 % 60` is
  `35`). Chapter 01 covers both in detail.
- **One unit makes the problem easy.** Adding minutes to `22:45` is awkward, but
  `22 * 60 + 45 = 1365` minutes since midnight plus `95` is simply `1460`. Converting
  back: `1460 / 60 = 24` hours and `1460 % 60 = 20` minutes.
- **Wrapping past midnight.** `24 % 24` is `0`, so `% 24` turns hour 24 into hour 0
  (and hour 25 into 1). Without it the program would print `24:20`.
- **Leading zeros without `if`.** `"0" + 5` is `"05"` and `"0" + 45` is `"045"`.
  Keeping the last two characters gives `"05"` and `"45"`: a one-digit value gains a
  zero, a two-digit value is unchanged.
- `trip / 60 + " h "` needs no parentheses: `/` and `%` are applied before `+`, so the
  quotient is computed first and then joined to the text.
