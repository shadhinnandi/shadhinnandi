# Practice Problems: Static and Instance Members

These problems practise shared (static) data, object counters, auto-generated IDs,
constants, utility classes, factory methods, static nested classes and enums. Decide
for every field and method whether it belongs to one object or to the whole class.
Programs read input without prompts and print exactly the sample output.

## Problem 1: Library Book Counter
**Level:** Basic

### Problem Statement
Write a class `Book` with a `private final` title and a `private static int count`
that counts how many `Book` objects have been created. Increase the counter in the
constructor and give the class a static method `getCount()`.

The program first prints `Books at start: <count>`. Then it reads an integer `n` and
`n` lines, each containing a book title (titles may contain spaces). For each title it
creates a `Book` and prints `Added: <title> (books so far: <count>)`. Finally it prints
`Total books: <count>`.

### Sample Input
```text
3
Introduction to Java
Data Structures Made Easy
Discrete Mathematics
```

### Sample Output
```text
Books at start: 0
Added: Introduction to Java (books so far: 1)
Added: Data Structures Made Easy (books so far: 2)
Added: Discrete Mathematics (books so far: 3)
Total books: 3
```

### Solution
```java
import java.util.Scanner;

class Book {
    private static int count = 0;

    private final String title;

    Book(String title) {
        this.title = title;
        count++;
    }

    String getTitle() {
        return title;
    }

    static int getCount() {
        return count;
    }
}

public class BookCounter {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        System.out.println("Books at start: " + Book.getCount());
        int n = in.nextInt();
        in.nextLine(); // consume the rest of the first line
        for (int i = 0; i < n; i++) {
            Book book = new Book(in.nextLine());
            System.out.println("Added: " + book.getTitle()
                    + " (books so far: " + Book.getCount() + ")");
        }
        System.out.println("Total books: " + Book.getCount());
    }
}
```

### Explanation
- `title` is different for every book, so it is an instance field. `count` is one
  number for the whole class, so it is `static`.
- The constructor runs exactly once per `new Book(...)`, which makes it the right
  place for `count++`.
- `Book.getCount()` is called through the class name. It works even before any book
  exists, which is why the first line prints `0`.
- The variable `book` refers to a different object in every loop round, but the
  count survives because it is stored in the class, not in an object.

## Problem 2: Employee IDs with a Chosen Start
**Level:** Basic

### Problem Statement
Write a class `Employee` that gives every new employee an automatic ID of the form
`EMP-<number>`. Numbering starts at 1 by default. A static method
`startNumbering(int first)` changes the first number, but only if `first` is at least
1 and no employee has been created yet; it returns `true` on success and `false`
otherwise. A static method `peekNextId()` returns the ID the next employee would get.

Input: the first line holds the desired start number, the second line `n`, then `n`
lines each with an employee name (may contain spaces).

Output: if the start number is refused, first print
`Start <number> refused, numbering from 1`. Then print `<id> <name>` for each
employee, then `Next ID: <id>`. Finally the program tries `startNumbering(1)` again
and prints `Restart refused: IDs already issued` when it fails, or `Restarted at 1`
when it succeeds (when `n` is 0).

### Sample Input
```text
501
3
Ayesha Siddiqua
Imran Hossain
Farhana Akter
```

### Sample Output
```text
EMP-501 Ayesha Siddiqua
EMP-502 Imran Hossain
EMP-503 Farhana Akter
Next ID: EMP-504
Restart refused: IDs already issued
```

### Solution
```java
import java.util.Scanner;

class Employee {
    private static int nextNumber = 1;
    private static int created = 0;

    private final String id;
    private final String name;

    Employee(String name) {
        this.name = name;
        this.id = "EMP-" + nextNumber;
        nextNumber++;
        created++;
    }

    static boolean startNumbering(int first) {
        if (first < 1 || created > 0) {
            return false;
        }
        nextNumber = first;
        return true;
    }

    static String peekNextId() {
        return "EMP-" + nextNumber;
    }

    String describe() {
        return id + " " + name;
    }
}

public class EmployeeIds {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int start = in.nextInt();
        int n = in.nextInt();
        in.nextLine();
        if (!Employee.startNumbering(start)) {
            System.out.println("Start " + start + " refused, numbering from 1");
        }
        for (int i = 0; i < n; i++) {
            Employee e = new Employee(in.nextLine());
            System.out.println(e.describe());
        }
        System.out.println("Next ID: " + Employee.peekNextId());
        if (Employee.startNumbering(1)) {
            System.out.println("Restarted at 1");
        } else {
            System.out.println("Restart refused: IDs already issued");
        }
    }
}
```

### Explanation
- `nextNumber` and `created` are shared by all employees, so they are `private static`.
  The `id` is fixed per employee, so it is a `private final` instance field.
- `startNumbering` is static because it configures the class before any object
  exists. It protects the rule "IDs are unique": once an ID has been issued,
  restarting could hand out the same number twice, so the method refuses.
- `peekNextId()` only reads the shared counter; it does not create an employee.
- Every change of `nextNumber` happens inside the class, so no other code can break
  the numbering.

## Problem 3: Temperature Utility Class
**Level:** Basic

### Problem Statement
The campus medical centre records body temperatures in Celsius or Fahrenheit. Write a
utility class `TempUtil` with a private constructor and three static methods:
`toFahrenheit(double c)`, `toCelsius(double f)` and `isFever(double celsius)`, which
returns `true` when the temperature is at least 38.0 °C.

Input: an integer `n`, then `n` lines, each with a unit letter (`C` or `F`) and a
value. For each line print the value converted to the other unit and a note, with one
decimal place:
`<value> C = <converted> F (<note>)` or `<value> F = <converted> C (<note>)`, where
the note is `fever` or `normal`.

### Sample Input
```text
4
C 36.6
F 102.2
C 38.5
F 98.6
```

### Sample Output
```text
36.6 C = 97.9 F (normal)
102.2 F = 39.0 C (fever)
38.5 C = 101.3 F (fever)
98.6 F = 37.0 C (normal)
```

### Solution
```java
import java.util.Scanner;

final class TempUtil {
    static final double FEVER_CELSIUS = 38.0;

    private TempUtil() {
        // utility class: no objects
    }

    static double toFahrenheit(double celsius) {
        return celsius * 9 / 5 + 32;
    }

    static double toCelsius(double fahrenheit) {
        return (fahrenheit - 32) * 5 / 9;
    }

    static boolean isFever(double celsius) {
        return celsius >= FEVER_CELSIUS;
    }
}

public class FeverCheck {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String unit = in.next();
            double value = in.nextDouble();
            double celsius;
            String result;
            if (unit.equals("C")) {
                celsius = value;
                result = String.format("%.1f C = %.1f F", value,
                        TempUtil.toFahrenheit(value));
            } else {
                celsius = TempUtil.toCelsius(value);
                result = String.format("%.1f F = %.1f C", value, celsius);
            }
            String note = TempUtil.isFever(celsius) ? "fever" : "normal";
            System.out.println(result + " (" + note + ")");
        }
    }
}
```

### Explanation
- Converting a temperature needs nothing except the number itself, so the methods are
  static and `TempUtil` has no fields that change.
- The private constructor stops anyone from writing `new TempUtil()`, which would
  create a useless object. Marking the class `final` says it is not meant to be
  extended.
- The fever limit is a `static final` constant, so it has a name and is defined in
  one place.
- `isFever` always works in Celsius; for Fahrenheit input, `main` converts first.

## Problem 4: Parcel Charges with Constants
**Level:** Basic

### Problem Statement
A courier counter charges for parcels with these hypothetical rules: the first
kilogram costs 60 Tk and every further kilogram costs 25 Tk. A parcel must weigh from
1 to 20 kg. Write a class `Parcel` that stores these rules as `static final` constants
`BASE_CHARGE`, `PER_EXTRA_KG`, `MIN_WEIGHT_KG` and `MAX_WEIGHT_KG`, has an instance
field `weightKg`, and has instance methods `isAccepted()` and `charge()`.

Input: an integer `n`, then `n` integer weights. First print the rules as
`Rules: <BASE_CHARGE> Tk for the first kg, <PER_EXTRA_KG> Tk per extra kg, max
<MAX_WEIGHT_KG> kg` (on one line). Then for parcel number `k` (counting from 1) print
`Parcel <k>: <w> kg -> <charge> Tk` or `Parcel <k>: <w> kg -> rejected`. Finally print
`Total: <sum> Tk` for the accepted parcels.

### Sample Input
```text
4
1
3
25
0
```

### Sample Output
```text
Rules: 60 Tk for the first kg, 25 Tk per extra kg, max 20 kg
Parcel 1: 1 kg -> 60 Tk
Parcel 2: 3 kg -> 110 Tk
Parcel 3: 25 kg -> rejected
Parcel 4: 0 kg -> rejected
Total: 170 Tk
```

### Solution
```java
import java.util.Scanner;

class Parcel {
    static final int BASE_CHARGE = 60;
    static final int PER_EXTRA_KG = 25;
    static final int MIN_WEIGHT_KG = 1;
    static final int MAX_WEIGHT_KG = 20;

    private final int weightKg;

    Parcel(int weightKg) {
        this.weightKg = weightKg;
    }

    boolean isAccepted() {
        return weightKg >= MIN_WEIGHT_KG && weightKg <= MAX_WEIGHT_KG;
    }

    int charge() {
        return BASE_CHARGE + (weightKg - 1) * PER_EXTRA_KG;
    }
}

public class ParcelCharges {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        System.out.println("Rules: " + Parcel.BASE_CHARGE + " Tk for the first kg, "
                + Parcel.PER_EXTRA_KG + " Tk per extra kg, max "
                + Parcel.MAX_WEIGHT_KG + " kg");
        int n = in.nextInt();
        int total = 0;
        for (int k = 1; k <= n; k++) {
            int weight = in.nextInt();
            Parcel parcel = new Parcel(weight);
            if (parcel.isAccepted()) {
                System.out.println("Parcel " + k + ": " + weight + " kg -> "
                        + parcel.charge() + " Tk");
                total += parcel.charge();
            } else {
                System.out.println("Parcel " + k + ": " + weight + " kg -> rejected");
            }
        }
        System.out.println("Total: " + total + " Tk");
    }
}
```

### Explanation
- The rules are the same for every parcel and never change while the program runs, so
  they are `static final` constants with `UPPER_SNAKE_CASE` names.
- The weight differs per parcel, so it is an instance field, and `charge()` is an
  instance method that combines the object's weight with the shared constants.
- `main` reads the constants through the class name (`Parcel.BASE_CHARGE`) before any
  parcel exists. If the courier changes a rate, only one line of code changes.

## Problem 5: Traffic Light Cycle
**Level:** Basic

### Problem Statement
Write an `enum Light` with the constants `RED`, `GREEN` and `YELLOW`. In the main
class write two static methods that use a `switch` on the enum: `next(Light l)`
returns the following light (RED → GREEN → YELLOW → RED) and `seconds(Light l)`
returns how long the light stays on (RED 30, GREEN 25, YELLOW 5).

Input: a light name and an integer `k`. If the name is not one of the constants,
print `Unknown light: <name>`. Otherwise print `k` lines, starting with the given
light, each as `<LIGHT> for <s> s`, and then `Total: <sum> s`. Find the constant by
comparing the input with the `name()` of each value in `Light.values()`.

### Sample Input
```text
GREEN 4
```

### Sample Output
```text
GREEN for 25 s
YELLOW for 5 s
RED for 30 s
GREEN for 25 s
Total: 85 s
```

### Solution
```java
import java.util.Scanner;

enum Light {
    RED, GREEN, YELLOW
}

public class TrafficLight {
    static Light next(Light light) {
        switch (light) {
            case RED:
                return Light.GREEN;
            case GREEN:
                return Light.YELLOW;
            default:
                return Light.RED;
        }
    }

    static int seconds(Light light) {
        return switch (light) {
            case RED -> 30;
            case GREEN -> 25;
            case YELLOW -> 5;
        };
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String name = in.next();
        int k = in.nextInt();
        Light current = null;
        for (Light light : Light.values()) {
            if (light.name().equals(name)) {
                current = light;
            }
        }
        if (current == null) {
            System.out.println("Unknown light: " + name);
            return;
        }
        int total = 0;
        for (int i = 0; i < k; i++) {
            System.out.println(current + " for " + seconds(current) + " s");
            total += seconds(current);
            current = next(current);
        }
        System.out.println("Total: " + total + " s");
    }
}
```

### Explanation
- A light can only be one of three values, so an `enum` is safer than strings or
  numbers: `current` can never hold a misspelled light.
- `next` uses a classic `switch` (each case returns, so nothing falls through), and
  `seconds` uses a switch expression, which the compiler checks for all three
  constants.
- `Light.values()` lists the constants; comparing `name()` with the input finds the
  matching one, and `null` means "not found".
- Printing an enum value prints its name, so `current + " for "` gives `GREEN for`.

## Problem 6: Hostel Meal Rate
**Level:** Intermediate

### Problem Statement
In a hostel mess, each resident counts their own meals, but the meal rate is decided
by the manager and is the same for everybody. The bill is always calculated with the
**current** rate. Write a class `Resident` with:

- instance fields: name and number of meals;
- static fields: `mealRate` (starts at 60 Tk) and `totalMeals` (all residents);
- constants `MIN_RATE = 30` and `MAX_RATE = 150`;
- `boolean eat(int count)` (refuse `count <= 0`), `int bill()`,
  `static boolean setMealRate(int rate)` and `static int totalDue()`.

Input: three resident names on the first line, then an integer `n` and `n` commands:

- `EAT <i> <count>`: resident `i` (1 to 3) eats `count` meals; prints nothing on
  success, `No resident <i>` for a bad index, `Invalid meal count` for a bad count.
- `RATE <r>`: prints `Meal rate is now <r> Tk` or `Rate <r> rejected (allowed 30-150)`.
- `BILL`: prints `<name>: <meals> meal(s) x <rate> = <bill> Tk` for each resident,
  then `Total meals: <m>, total due: <d> Tk`.

### Sample Input
```text
Rahim Karim Tanvir
8
EAT 1 3
EAT 2 2
EAT 4 1
BILL
RATE 75
EAT 3 4
RATE 200
BILL
```

### Sample Output
```text
No resident 4
Rahim: 3 meal(s) x 60 = 180 Tk
Karim: 2 meal(s) x 60 = 120 Tk
Tanvir: 0 meal(s) x 60 = 0 Tk
Total meals: 5, total due: 300 Tk
Meal rate is now 75 Tk
Rate 200 rejected (allowed 30-150)
Rahim: 3 meal(s) x 75 = 225 Tk
Karim: 2 meal(s) x 75 = 150 Tk
Tanvir: 4 meal(s) x 75 = 300 Tk
Total meals: 9, total due: 675 Tk
```

### Solution
```java
import java.util.Scanner;

class Resident {
    static final int MIN_RATE = 30;
    static final int MAX_RATE = 150;

    private static int mealRate = 60;
    private static int totalMeals = 0;

    private final String name;
    private int meals;

    Resident(String name) {
        this.name = name;
    }

    boolean eat(int count) {
        if (count <= 0) {
            return false;
        }
        meals += count;
        totalMeals += count;
        return true;
    }

    int bill() {
        return meals * mealRate;
    }

    void printBill() {
        System.out.println(name + ": " + meals + " meal(s) x " + mealRate
                + " = " + bill() + " Tk");
    }

    static boolean setMealRate(int rate) {
        if (rate < MIN_RATE || rate > MAX_RATE) {
            return false;
        }
        mealRate = rate;
        return true;
    }

    static int totalDue() {
        return totalMeals * mealRate;
    }

    static int getTotalMeals() {
        return totalMeals;
    }
}

public class HostelMess {
    static Resident pick(int i, Resident a, Resident b, Resident c) {
        if (i == 1) {
            return a;
        } else if (i == 2) {
            return b;
        } else if (i == 3) {
            return c;
        }
        return null;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Resident a = new Resident(in.next());
        Resident b = new Resident(in.next());
        Resident c = new Resident(in.next());
        int n = in.nextInt();
        for (int k = 0; k < n; k++) {
            String command = in.next();
            if (command.equals("EAT")) {
                int i = in.nextInt();
                int count = in.nextInt();
                Resident r = pick(i, a, b, c);
                if (r == null) {
                    System.out.println("No resident " + i);
                } else if (!r.eat(count)) {
                    System.out.println("Invalid meal count");
                }
            } else if (command.equals("RATE")) {
                int rate = in.nextInt();
                if (Resident.setMealRate(rate)) {
                    System.out.println("Meal rate is now " + rate + " Tk");
                } else {
                    System.out.println("Rate " + rate + " rejected (allowed "
                            + Resident.MIN_RATE + "-" + Resident.MAX_RATE + ")");
                }
            } else if (command.equals("BILL")) {
                a.printBill();
                b.printBill();
                c.printBill();
                System.out.println("Total meals: " + Resident.getTotalMeals()
                        + ", total due: " + Resident.totalDue() + " Tk");
            }
        }
    }
}
```

### Explanation
- Meal counts differ per resident (instance fields); the rate is one value for the
  whole mess (static field). Changing it once with `Resident.setMealRate(75)` changes
  every bill, which the second `BILL` shows.
- `totalMeals` is a static running total kept up to date inside `eat`, so
  `totalDue()` can be a static method that does not need any resident object.
- The rate is `private` and changed only through `setMealRate`, which rejects values
  outside the constant limits. A public static field could be set to anything by any
  code.
- `pick` is a static helper in the main class: it needs no object, only its
  parameters. (With arrays, from Chapter 08, it would not be needed.)

## Problem 7: Fractions with a Factory Method
**Level:** Intermediate

### Problem Statement
Write an immutable class `Fraction` whose constructor is `private`. Objects are
created only through the static factory method `Fraction.of(int num, int den)`, which:

- returns `null` when `den` is 0;
- moves a negative sign to the numerator (`3/-6` becomes `-3/6`);
- reduces the fraction with a `private static int gcd(int a, int b)` helper.

Also write `static Fraction add(Fraction a, Fraction b)` and an instance method
`Fraction times(Fraction other)`, both returning new reduced fractions, and a
`toString()` that prints `num/den`, or only `num` when the denominator is 1.

Input: `n`, then `n` lines `a b op c d` meaning `a/b op c/d`, where `op` is `+` or
`*`. Print `<x> <op> <y> = <result>` using the reduced fractions, or
`Invalid fraction` when a denominator is 0.

### Sample Input
```text
4
1 2 + 1 3
2 4 * 3 9
3 -6 + 1 2
5 0 + 1 2
```

### Sample Output
```text
1/2 + 1/3 = 5/6
1/2 * 1/3 = 1/6
-1/2 + 1/2 = 0
Invalid fraction
```

### Solution
```java
import java.util.Scanner;

class Fraction {
    private final int num;
    private final int den;

    private Fraction(int num, int den) {
        this.num = num;
        this.den = den;
    }

    private static int gcd(int a, int b) {
        a = Math.abs(a);
        b = Math.abs(b);
        while (b != 0) {
            int rest = a % b;
            a = b;
            b = rest;
        }
        return a;
    }

    static Fraction of(int num, int den) {
        if (den == 0) {
            return null;
        }
        if (den < 0) {
            num = -num;
            den = -den;
        }
        int g = gcd(num, den);   // den > 0, so g >= 1
        return new Fraction(num / g, den / g);
    }

    static Fraction add(Fraction a, Fraction b) {
        return of(a.num * b.den + b.num * a.den, a.den * b.den);
    }

    Fraction times(Fraction other) {
        return of(num * other.num, den * other.den);
    }

    public String toString() {
        if (den == 1) {
            return String.valueOf(num);
        }
        return num + "/" + den;
    }
}

public class FractionCalc {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            Fraction x = Fraction.of(in.nextInt(), in.nextInt());
            String op = in.next();
            Fraction y = Fraction.of(in.nextInt(), in.nextInt());
            if (x == null || y == null) {
                System.out.println("Invalid fraction");
                continue;
            }
            Fraction result;
            if (op.equals("+")) {
                result = Fraction.add(x, y);
            } else {
                result = x.times(y);
            }
            System.out.println(x + " " + op + " " + y + " = " + result);
        }
    }
}
```

### Explanation
- Because the constructor is private, every `Fraction` passes through `of`, so every
  object is guaranteed to be valid and fully reduced. That is the main reason to use
  a factory method.
- `gcd` is a `private static` helper: it works only with its two parameters and is an
  internal detail, so outside code cannot call it.
- `add` (static, both fractions as parameters) and `times` (instance, `this` times
  `other`) show two valid styles for the same kind of operation. The instance style
  reads as `x.times(y)`; the static style treats both operands equally.
- `gcd(0, 6)` is 6, so a zero result becomes `0/1` and prints as `0`.

## Problem 8: Course Registration States
**Level:** Intermediate

### Problem Statement
A registration moves through the states of `enum RegStatus { DRAFT, SUBMITTED,
APPROVED }`. Write a class `Registration` with the constants `MIN_CREDITS = 9` and
`MAX_CREDITS = 15` (hypothetical rules), a student name, the current credits and the
current status (starting at `DRAFT` with 0 credits). The rules:

- `ADD <c>`: only in `DRAFT`; `c` must be positive and the total may not exceed
  `MAX_CREDITS`.
- `SUBMIT`: only in `DRAFT` and only with at least `MIN_CREDITS`; goes to `SUBMITTED`.
- `APPROVE`: only in `SUBMITTED`; goes to `APPROVED`.
- `RETURN`: only in `SUBMITTED`; the advisor sends it back to `DRAFT`.

Input: the student's name, then `n` and `n` commands. For a successful command print
`<command> -> <STATUS>, <credits> credits`; for a refused one print
`<command> refused (<STATUS>, <credits> credits)` (for `ADD`, the command text
includes the number). Finally print `<name>: <STATUS> - <advice>`, where the advice
comes from a `switch` on the status: `DRAFT` → `add courses and submit`, `SUBMITTED`
→ `waiting for the advisor`, `APPROVED` → `registration complete`.

### Sample Input
```text
Nusrat
12
SUBMIT
ADD 3
ADD 3
APPROVE
ADD 4
SUBMIT
ADD 3
RETURN
ADD 3
ADD 3
SUBMIT
APPROVE
```

### Sample Output
```text
SUBMIT refused (DRAFT, 0 credits)
ADD 3 -> DRAFT, 3 credits
ADD 3 -> DRAFT, 6 credits
APPROVE refused (DRAFT, 6 credits)
ADD 4 -> DRAFT, 10 credits
SUBMIT -> SUBMITTED, 10 credits
ADD 3 refused (SUBMITTED, 10 credits)
RETURN -> DRAFT, 10 credits
ADD 3 -> DRAFT, 13 credits
ADD 3 refused (DRAFT, 13 credits)
SUBMIT -> SUBMITTED, 13 credits
APPROVE -> APPROVED, 13 credits
Nusrat: APPROVED - registration complete
```

### Solution
```java
import java.util.Scanner;

enum RegStatus {
    DRAFT, SUBMITTED, APPROVED
}

class Registration {
    static final int MIN_CREDITS = 9;
    static final int MAX_CREDITS = 15;

    private final String student;
    private int credits;
    private RegStatus status = RegStatus.DRAFT;

    Registration(String student) {
        this.student = student;
    }

    boolean addCourse(int c) {
        if (status != RegStatus.DRAFT || c <= 0 || credits + c > MAX_CREDITS) {
            return false;
        }
        credits += c;
        return true;
    }

    boolean submit() {
        if (status != RegStatus.DRAFT || credits < MIN_CREDITS) {
            return false;
        }
        status = RegStatus.SUBMITTED;
        return true;
    }

    boolean approve() {
        if (status != RegStatus.SUBMITTED) {
            return false;
        }
        status = RegStatus.APPROVED;
        return true;
    }

    boolean sendBack() {
        if (status != RegStatus.SUBMITTED) {
            return false;
        }
        status = RegStatus.DRAFT;
        return true;
    }

    String state() {
        return status + ", " + credits + " credits";
    }

    String advice() {
        return switch (status) {
            case DRAFT -> "add courses and submit";
            case SUBMITTED -> "waiting for the advisor";
            case APPROVED -> "registration complete";
        };
    }

    String summary() {
        return student + ": " + status + " - " + advice();
    }
}

public class CourseRegistration {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Registration reg = new Registration(in.next());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            boolean ok;
            if (command.equals("ADD")) {
                int c = in.nextInt();
                command = command + " " + c;
                ok = reg.addCourse(c);
            } else if (command.equals("SUBMIT")) {
                ok = reg.submit();
            } else if (command.equals("APPROVE")) {
                ok = reg.approve();
            } else if (command.equals("RETURN")) {
                ok = reg.sendBack();
            } else {
                ok = false;
            }
            if (ok) {
                System.out.println(command + " -> " + reg.state());
            } else {
                System.out.println(command + " refused (" + reg.state() + ")");
            }
        }
        System.out.println(reg.summary());
    }
}
```

### Explanation
- The status can only be `DRAFT`, `SUBMITTED` or `APPROVED`; using an enum makes
  every other value impossible, and comparisons use `==`.
- Each method first checks the current state, then changes it. All rules live inside
  `Registration`, so `main` only reports what the object answered.
- The credit limits are `static final` constants: they belong to the rules of the
  university, not to one student.
- `advice()` uses a switch expression; if a new state is added to the enum later, the
  compiler reports that the switch no longer covers every constant.

## Problem 9: Lazy Printer Driver
**Level:** Intermediate

### Problem Statement
The library printer has a paper tray of 50 sheets (`static final int
TRAY_CAPACITY = 50`). Write a class `PrintJob` whose static initializer block prints
`Printer driver loaded (tray: 50 sheets)` and fills the tray (a static field
`paperLeft`). Jobs are created only through the static factory method
`submit(int pages)`, which returns `null` when `pages` is not positive or more than the
paper left. Otherwise the new job gets the next job number (1, 2, ...) and uses up its
pages.

The program first prints `Print service started`. Then it reads `n` and `n` page
counts. For each one print `Job #<k>: <p> page(s), <left> sheet(s) left` or
`Request of <p> page(s) refused`. At the end print `No jobs today` when `n` is 0 (in
that case the driver must never be loaded), otherwise
`Jobs printed: <count>, sheets left: <left>`.

### Sample Input
```text
4
20
35
25
5
```

### Sample Output
```text
Print service started
Printer driver loaded (tray: 50 sheets)
Job #1: 20 page(s), 30 sheet(s) left
Request of 35 page(s) refused
Job #2: 25 page(s), 5 sheet(s) left
Job #3: 5 page(s), 0 sheet(s) left
Jobs printed: 3, sheets left: 0
```

### Solution
```java
import java.util.Scanner;

class PrintJob {
    static final int TRAY_CAPACITY = 50;

    private static int paperLeft;
    private static int jobsPrinted;

    static {
        System.out.println("Printer driver loaded (tray: " + TRAY_CAPACITY
                + " sheets)");
        paperLeft = TRAY_CAPACITY;
        jobsPrinted = 0;
    }

    private final int number;
    private final int pages;

    private PrintJob(int pages) {
        jobsPrinted++;
        this.number = jobsPrinted;
        this.pages = pages;
        paperLeft -= pages;
    }

    static PrintJob submit(int pages) {
        if (pages <= 0 || pages > paperLeft) {
            return null;
        }
        return new PrintJob(pages);
    }

    String describe() {
        return "Job #" + number + ": " + pages + " page(s), " + paperLeft
                + " sheet(s) left";
    }

    static int getJobsPrinted() {
        return jobsPrinted;
    }

    static int getPaperLeft() {
        return paperLeft;
    }
}

public class PrinterQueue {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        System.out.println("Print service started");
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            int pages = in.nextInt();
            PrintJob job = PrintJob.submit(pages);
            if (job == null) {
                System.out.println("Request of " + pages + " page(s) refused");
            } else {
                System.out.println(job.describe());
            }
        }
        if (n == 0) {
            System.out.println("No jobs today");
        } else {
            System.out.println("Jobs printed: " + PrintJob.getJobsPrinted()
                    + ", sheets left: " + PrintJob.getPaperLeft());
        }
    }
}
```

### Explanation
- The static block runs once, at the first real use of `PrintJob`: here the first
  call of `PrintJob.submit`. That is why its message appears after
  `Print service started`, and only once even though several jobs are created.
- When `n` is 0, `main` never touches `PrintJob`, so the driver is never loaded.
  Reading `TRAY_CAPACITY` alone would not load it either: a `static final` constant
  with a fixed value is copied in by the compiler.
- `describe()` reads `paperLeft` at the moment it is called, which is right after
  the job was created, so each line shows the paper left after that job.
- The private constructor plus factory method guarantees that no job is created when
  there is not enough paper, so `paperLeft` can never become negative.

## Problem 10: Exam Hall Seat Allocator
**Level:** Intermediate

### Problem Statement
An exam hall has a capacity and rows of 3 seats (`static final int
SEATS_PER_ROW = 3`). Seats are handed out in order: row 1 seats 1-3, then row 2, and
so on, written as `R<row>-S<seat>`. Write a class `Seat` with:

- `static boolean openHall(int capacity)`: sets the shared capacity; refuses a
  capacity below 1;
- a private constructor and a static factory method `allocate(String student)` that
  returns `null` when the hall is full (or was never opened);
- `static int getAllocated()` and `static int getCapacity()`.

Input: the capacity, then `n` and `n` student names (one word each). If the capacity
is refused, print `Invalid capacity <c>` first. Then print `<name> -> <label>` or
`<name> -> no seat (hall full)` for each student. Finally print
`Seats used: <allocated> of <capacity>`.

### Sample Input
```text
5
6
Rahim
Nusrat
Karim
Ayesha
Fahim
Mitu
```

### Sample Output
```text
Rahim -> R1-S1
Nusrat -> R1-S2
Karim -> R1-S3
Ayesha -> R2-S1
Fahim -> R2-S2
Mitu -> no seat (hall full)
Seats used: 5 of 5
```

### Solution
```java
import java.util.Scanner;

class Seat {
    static final int SEATS_PER_ROW = 3;

    private static int capacity = 0;
    private static int allocated = 0;

    private final String student;
    private final String label;

    private Seat(String student, int index) {
        this.student = student;
        int row = index / SEATS_PER_ROW + 1;
        int column = index % SEATS_PER_ROW + 1;
        this.label = "R" + row + "-S" + column;
    }

    static boolean openHall(int newCapacity) {
        if (newCapacity < 1) {
            return false;
        }
        capacity = newCapacity;
        return true;
    }

    static Seat allocate(String student) {
        if (allocated >= capacity) {
            return null;
        }
        Seat seat = new Seat(student, allocated);
        allocated++;
        return seat;
    }

    String describe() {
        return student + " -> " + label;
    }

    static int getAllocated() {
        return allocated;
    }

    static int getCapacity() {
        return capacity;
    }
}

public class SeatAllocator {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int capacity = in.nextInt();
        if (!Seat.openHall(capacity)) {
            System.out.println("Invalid capacity " + capacity);
        }
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String name = in.next();
            Seat seat = Seat.allocate(name);
            if (seat == null) {
                System.out.println(name + " -> no seat (hall full)");
            } else {
                System.out.println(seat.describe());
            }
        }
        System.out.println("Seats used: " + Seat.getAllocated() + " of "
                + Seat.getCapacity());
    }
}
```

### Explanation
- `allocated` is the shared position counter: seat number 0 goes to the first
  student, 1 to the second, and so on. Integer division and `%` turn that index into
  a row and a seat (index 4 → row 2, seat 2).
- `capacity` is shared configuration: every allocation must check the same limit, so
  it is a static field, set once through a validating static method.
- The factory method decides whether a seat may be created at all; when the hall is
  full it returns `null` and the counter does not move.
- If the capacity is invalid, it stays 0, so every student correctly gets no seat.

## Problem 11: Bank with a Shared Interest Rate
**Level:** Advanced

### Problem Statement
A small bank has three accounts. Write a class `Account` with:

- auto-generated account numbers starting at 1001 (static counter);
- a shared yearly interest rate in percent (static, starts at 5.0, allowed 0 to 12,
  the maximum stored as a constant);
- a static `bankTotal` that always equals the sum of all balances;
- instance methods `deposit`, `withdraw` (both reject non-positive amounts; withdraw
  also rejects amounts above the balance) and `addInterest()`.

Write a class `Bank` that holds the three accounts, finds an account by number
(`null` if not found) and can add interest to all accounts or print them all.

Input: three lines `name opening-balance`, then `n` and `n` commands:

| Command | Success output | Failure output |
|---|---|---|
| `D <num> <amount>` | `Deposited <amount> to <num>` | `Account <num> not found` / `Invalid amount` |
| `W <num> <amount>` | `Withdrew <amount> from <num>` | `Account <num> not found` / `Cannot withdraw <amount> from <num>` |
| `RATE <r>` | `Interest rate is now <r>%` | `Rate <r>% rejected` |
| `INTEREST` | `Interest added at <r>%` | |
| `REPORT` | one line per account `<num> <name> <balance>` (name left-aligned in 8 characters, balance right-aligned in 9), then `Bank total: <total>` | |

Print all amounts, balances and rates with two decimal places.

### Sample Input
```text
Rahim 5000
Nusrat 12000
Karim 800
8
D 1001 1500
W 1003 1000
W 1004 100
RATE 4
INTEREST
RATE 15
W 1002 2000
REPORT
```

### Sample Output
```text
Deposited 1500.00 to 1001
Cannot withdraw 1000.00 from 1003
Account 1004 not found
Interest rate is now 4.00%
Interest added at 4.00%
Rate 15.00% rejected
Withdrew 2000.00 from 1002
1001 Rahim      6760.00
1002 Nusrat    10480.00
1003 Karim       832.00
Bank total: 18072.00
```

### Solution
```java
import java.util.Scanner;

class Account {
    static final double MAX_RATE = 12.0;

    private static int nextNumber = 1001;
    private static double ratePercent = 5.0;
    private static double bankTotal = 0;

    private final int number;
    private final String owner;
    private double balance;

    Account(String owner, double openingBalance) {
        this.number = nextNumber;
        nextNumber++;
        this.owner = owner;
        this.balance = openingBalance;
        bankTotal += openingBalance;
    }

    boolean deposit(double amount) {
        if (amount <= 0) {
            return false;
        }
        balance += amount;
        bankTotal += amount;
        return true;
    }

    boolean withdraw(double amount) {
        if (amount <= 0 || amount > balance) {
            return false;
        }
        balance -= amount;
        bankTotal -= amount;
        return true;
    }

    void addInterest() {
        double interest = balance * ratePercent / 100;
        balance += interest;
        bankTotal += interest;
    }

    int getNumber() {
        return number;
    }

    String describe() {
        return String.format("%d %-8s %9.2f", number, owner, balance);
    }

    static boolean setRate(double percent) {
        if (percent < 0 || percent > MAX_RATE) {
            return false;
        }
        ratePercent = percent;
        return true;
    }

    static double getRate() {
        return ratePercent;
    }

    static double getBankTotal() {
        return bankTotal;
    }
}

class Bank {
    private final Account first;
    private final Account second;
    private final Account third;

    Bank(Account first, Account second, Account third) {
        this.first = first;
        this.second = second;
        this.third = third;
    }

    Account find(int number) {
        if (first.getNumber() == number) {
            return first;
        } else if (second.getNumber() == number) {
            return second;
        } else if (third.getNumber() == number) {
            return third;
        }
        return null;
    }

    void addInterestToAll() {
        first.addInterest();
        second.addInterest();
        third.addInterest();
    }

    void printReport() {
        System.out.println(first.describe());
        System.out.println(second.describe());
        System.out.println(third.describe());
        System.out.printf("Bank total: %.2f%n", Account.getBankTotal());
    }
}

public class SmallBank {
    static Account readAccount(Scanner in) {
        String name = in.next();
        double opening = in.nextDouble();
        return new Account(name, opening);
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Bank bank = new Bank(readAccount(in), readAccount(in), readAccount(in));
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("D") || command.equals("W")) {
                int number = in.nextInt();
                double amount = in.nextDouble();
                Account acc = bank.find(number);
                if (acc == null) {
                    System.out.println("Account " + number + " not found");
                } else if (command.equals("D")) {
                    if (acc.deposit(amount)) {
                        System.out.printf("Deposited %.2f to %d%n", amount, number);
                    } else {
                        System.out.println("Invalid amount");
                    }
                } else if (acc.withdraw(amount)) {
                    System.out.printf("Withdrew %.2f from %d%n", amount, number);
                } else {
                    System.out.printf("Cannot withdraw %.2f from %d%n", amount, number);
                }
            } else if (command.equals("RATE")) {
                double rate = in.nextDouble();
                if (Account.setRate(rate)) {
                    System.out.printf("Interest rate is now %.2f%%%n", rate);
                } else {
                    System.out.printf("Rate %.2f%% rejected%n", rate);
                }
            } else if (command.equals("INTEREST")) {
                bank.addInterestToAll();
                System.out.printf("Interest added at %.2f%%%n", Account.getRate());
            } else if (command.equals("REPORT")) {
                bank.printReport();
            }
        }
    }
}
```

### Explanation
- Three kinds of data, three decisions: each account's number, owner and balance are
  instance fields; the next number, the interest rate and the bank total are static,
  because each is one value for the whole bank; `MAX_RATE` is a constant.
- `bankTotal` is updated in every method that changes a balance (constructor,
  `deposit`, `withdraw`, `addInterest`), so it stays equal to the sum of balances
  without adding them up again. Keeping it `private` makes sure no other code can
  break that rule.
- `Bank` is a normal class with instance fields: it is an object that holds the three
  accounts. Only the facts that are shared by all accounts are static.
- In the sample, interest at 4% gives Rahim 6500 + 260, Nusrat 12000 + 480 and Karim
  800 + 32; Nusrat then withdraws 2000.
- `readAccount` is called three times in the argument list; Java evaluates arguments
  from left to right, so the accounts get 1001, 1002 and 1003 in input order.

## Problem 12: Delivery Orders with Enums
**Level:** Advanced

### Problem Statement
A food delivery service handles orders one after another. Write:

- `enum Zone` with the constants `CAMPUS(30)`, `CITY(60)` and `OUTSIDE(120)`, where
  the number is the delivery fee in Tk (an enum field with a getter);
- `enum Status { PLACED, PICKED, DELIVERED, CANCELLED, RETURNED }`;
- a class `Order` with an auto-generated order number, its zone, its status (starting
  at `PLACED`) and the text of the path of statuses it went through. Orders are created
  with a static factory method `Order.create(String zoneName)` that returns `null`
  for an unknown zone (no order number is used up).

Events (one letter each): `P` picks up a `PLACED` order, `C` cancels a `PLACED`
order, `D` delivers a `PICKED` order, `F` marks a `PICKED` order as `RETURNED` (failed
delivery). Any other event, or an event that is not allowed in the current state, is
refused. Static counters in `Order` record how many orders ended `DELIVERED`,
`CANCELLED`, `RETURNED` or still open (`PLACED` or `PICKED`), and the total fees of
delivered orders.

Input: `n`, then `n` lines `<ZONE> <events>` (events is a non-empty string of
letters). For each line print `Order <k> to <ZONE>: <path>` where the path lists the
statuses joined by ` > `, followed by ` [<r> refused]` if `r > 0` events were refused;
or `Skipped: unknown zone <name>`. Finally print the four counters and the fees as in
the sample.

### Sample Input
```text
6
CITY PD
CAMPUS C
OUTSIDE PCF
MARS PD
CAMPUS PDD
CITY P
```

### Sample Output
```text
Order 1 to CITY: PLACED > PICKED > DELIVERED
Order 2 to CAMPUS: PLACED > CANCELLED
Order 3 to OUTSIDE: PLACED > PICKED > RETURNED [1 refused]
Skipped: unknown zone MARS
Order 4 to CAMPUS: PLACED > PICKED > DELIVERED [1 refused]
Order 5 to CITY: PLACED > PICKED
Delivered: 2 (fees 90 Tk)
Cancelled: 1
Returned: 1
Still open: 1
```

### Solution
```java
import java.util.Scanner;

enum Zone {
    CAMPUS(30), CITY(60), OUTSIDE(120);

    private final int fee;

    Zone(int fee) {
        this.fee = fee;
    }

    int getFee() {
        return fee;
    }
}

enum Status {
    PLACED, PICKED, DELIVERED, CANCELLED, RETURNED
}

class Order {
    private static int nextNumber = 1;
    private static int delivered = 0;
    private static int cancelled = 0;
    private static int returned = 0;
    private static int open = 0;
    private static int fees = 0;

    private final int number;
    private final Zone zone;
    private Status status = Status.PLACED;
    private String path = "PLACED";
    private int refused = 0;

    private Order(Zone zone) {
        this.number = nextNumber;
        nextNumber++;
        this.zone = zone;
    }

    static Order create(String zoneName) {
        for (Zone z : Zone.values()) {
            if (z.name().equals(zoneName)) {
                return new Order(z);
            }
        }
        return null;
    }

    void apply(char event) {
        Status next = null;
        if (status == Status.PLACED && event == 'P') {
            next = Status.PICKED;
        } else if (status == Status.PLACED && event == 'C') {
            next = Status.CANCELLED;
        } else if (status == Status.PICKED && event == 'D') {
            next = Status.DELIVERED;
        } else if (status == Status.PICKED && event == 'F') {
            next = Status.RETURNED;
        }
        if (next == null) {
            refused++;
            return;
        }
        status = next;
        path = path + " > " + next;
    }

    void finish() {
        switch (status) {
            case DELIVERED -> {
                delivered++;
                fees += zone.getFee();
            }
            case CANCELLED -> cancelled++;
            case RETURNED -> returned++;
            case PLACED, PICKED -> open++;
        }
    }

    String describe() {
        String text = "Order " + number + " to " + zone + ": " + path;
        if (refused > 0) {
            text = text + " [" + refused + " refused]";
        }
        return text;
    }

    static void printSummary() {
        System.out.println("Delivered: " + delivered + " (fees " + fees + " Tk)");
        System.out.println("Cancelled: " + cancelled);
        System.out.println("Returned: " + returned);
        System.out.println("Still open: " + open);
    }
}

public class DeliveryOrders {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String zoneName = in.next();
            String events = in.next();
            Order order = Order.create(zoneName);
            if (order == null) {
                System.out.println("Skipped: unknown zone " + zoneName);
                continue;
            }
            for (int k = 0; k < events.length(); k++) {
                order.apply(events.charAt(k));
            }
            order.finish();
            System.out.println(order.describe());
        }
        Order.printSummary();
    }
}
```

### Explanation
- Two enums model two different fixed sets: `Zone` carries data (its fee) through an
  enum field and constructor; `Status` is a plain list of states.
- `Order.create` is a factory method: it searches `Zone.values()` by name and only
  then calls the private constructor, so an unknown zone never consumes an order
  number (the next valid order after `MARS` is still number 4).
- `apply` accepts exactly the four allowed transitions and counts everything else as
  refused. In order 3, `C` is refused because a picked-up order can no longer be
  cancelled.
- The statistics are static because they describe all orders together. `finish()` is
  an instance method that adds this order's final state to the shared counters; its
  switch covers every `Status`, so a new state cannot be forgotten silently.

**Level:** Advanced

A computer shop builds laptops to order. Prices (hypothetical) are stored as

`Laptops built: <count>, sales: <total> Tk`.

### Sample Input


### Solution
```java
import java.util.Scanner;

class Laptop {
    static final int BASE_PRICE = 45000;
    static final int PER_EXTRA_8GB_RAM = 3000;
    static final int PER_EXTRA_256GB_SSD = 2500;
    static final int PER_EXTRA_YEAR = 2000;

    private static int built = 0;
    private static int sales = 0;

    private final String serial;
    private final String customer;
    private final int ramGb;
    private final int ssdGb;
    private final int warrantyYears;
    private final int price;

    private Laptop(String customer, int ramGb, int ssdGb, int warrantyYears) {
        built++;
        this.serial = String.format("LP-%02d", built);
        this.customer = customer;
        this.ramGb = ramGb;
        this.ssdGb = ssdGb;
        this.warrantyYears = warrantyYears;
        this.price = BASE_PRICE
                + (ramGb / 8 - 1) * PER_EXTRA_8GB_RAM
                + (ssdGb / 256 - 1) * PER_EXTRA_256GB_SSD
                + (warrantyYears - 1) * PER_EXTRA_YEAR;
        sales += price;
    }

    String describe() {
        return serial + " for " + customer + ": " + ramGb + " GB RAM, " + ssdGb
                + " GB SSD, " + warrantyYears + " yr warranty = " + price + " Tk";
    }

    static int getBuilt() {
        return built;
    }

    static int getSales() {
        return sales;
    }

    static class Builder {
        private final String customer;
        private int ramGb = 8;
        private int ssdGb = 256;
        private int warrantyYears = 1;
        private String problem = null;

        Builder(String customer) {
            this.customer = customer;
        }

        Builder fail(String text) {
            if (problem == null) {
                problem = text;   // keep only the first problem
            }
            return this;
        }

        Builder ram(int gb) {
            if (gb == 8 || gb == 16 || gb == 32) {
                ramGb = gb;
                return this;
            }
            return fail("RAM must be 8, 16 or 32 GB");
        }

        Builder ssd(int gb) {
            if (gb == 256 || gb == 512 || gb == 1024) {
                ssdGb = gb;
                return this;
            }
            return fail("SSD must be 256, 512 or 1024 GB");
        }

        Builder warranty(int years) {
            if (years >= 1 && years <= 3) {
                warrantyYears = years;
                return this;
            }
            return fail("warranty must be 1 to 3 years");
        }

        String getProblem() {
            return problem;
        }

        Laptop build() {
            if (problem != null) {
                return null;
            }
            return new Laptop(customer, ramGb, ssdGb, warrantyYears);
        }
    }
}

public class LaptopShop {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String customer = in.next();
            Laptop.Builder builder = new Laptop.Builder(customer);
            String option = in.next();
            while (!option.equals("END")) {
                int value = in.nextInt();
                if (option.equals("RAM")) {
                    builder.ram(value);
                } else if (option.equals("SSD")) {
                    builder.ssd(value);
                } else if (option.equals("WARRANTY")) {
                    builder.warranty(value);
                } else {
                    builder.fail("unknown option " + option);
                }
                option = in.next();
            }
            Laptop laptop = builder.build();
            if (laptop == null) {
                System.out.println("Order of " + customer + " rejected: "
                        + builder.getProblem());
            } else {
                System.out.println(laptop.describe());
            }
        }
        System.out.println("Laptops built: " + Laptop.getBuilt() + ", sales: "
                + Laptop.getSales() + " Tk");
    }
}
```

### Explanation
- A laptop has many optional settings with defaults. A constructor with many
  parameters is easy to call in the wrong order; the builder collects the settings one
  named method at a time and validates each one.
- `Builder` is a static nested class: it belongs to `Laptop` (its full name is
  `Laptop.Builder`), it needs no `Laptop` object to exist, and it may call the private
  `Laptop` constructor. So the only way to get a `Laptop` is through a validated
  builder.
- The serial number and sales total are static and updated in the constructor, which
  only runs for valid orders, so rejected orders never use up a serial.
- The prices are constants; the price formula counts "extra" units above the base
  configuration, e.g. Sadia pays 45000 + 3 × 3000 + 3 × 2500 + 2 × 2000 = 65500 Tk.

## Problem 14: Parking Garage with Two Gates
**Level:** Advanced

### Problem Statement
A campus parking garage has a north gate and a south gate. Each `Gate` object counts
its own entries, exits and turned-away cars, but all gates share the garage's
capacity (starts at 5) and the number of cars inside. Write the class `Gate` with
static `capacity` and `occupied`, a static `setCapacity(int c)` that refuses values
below 1 or below the current number of cars inside, and instance methods `enter()`,
`leave()` and `report()`.

Input: `n` commands, each one of:

- `N IN`, `S IN`: a car enters through that gate; print
  `<Gate>: car in (<occupied>/<capacity>)` or `<Gate>: FULL, car turned away`.
- `N OUT`, `S OUT`: a car leaves; print `<Gate>: car out (<occupied>/<capacity>)` or
  `<Gate>: no car to let out`.
- `CAP <c>`: print `Capacity is now <c>` or `Capacity <c> refused`.

Finally print one report line per gate:
`<Gate>: <in> in, <out> out, <away> turned away`, then `Cars inside: <occupied>`.

### Sample Input
```text
11
N IN
N IN
S IN
S OUT
CAP 1
CAP 3
S IN
N IN
N OUT
N OUT
S OUT
```

### Sample Output
```text
North: car in (1/5)
North: car in (2/5)
South: car in (3/5)
South: car out (2/5)
Capacity 1 refused
Capacity is now 3
South: car in (3/3)
North: FULL, car turned away
North: car out (2/3)
North: car out (1/3)
South: car out (0/3)
North: 2 in, 2 out, 1 turned away
South: 2 in, 2 out, 0 turned away
Cars inside: 0
```

### Solution
```java
import java.util.Scanner;

class Gate {
    private static int capacity = 5;
    private static int occupied = 0;

    private final String name;
    private int entries;
    private int exits;
    private int turnedAway;

    Gate(String name) {
        this.name = name;
    }

    static boolean setCapacity(int newCapacity) {
        if (newCapacity < 1 || newCapacity < occupied) {
            return false;
        }
        capacity = newCapacity;
        return true;
    }

    static int getOccupied() {
        return occupied;
    }

    private String fill() {
        return "(" + occupied + "/" + capacity + ")";
    }

    void enter() {
        if (occupied >= capacity) {
            turnedAway++;
            System.out.println(name + ": FULL, car turned away");
            return;
        }
        occupied++;
        entries++;
        System.out.println(name + ": car in " + fill());
    }

    void leave() {
        if (occupied == 0) {
            System.out.println(name + ": no car to let out");
            return;
        }
        occupied--;
        exits++;
        System.out.println(name + ": car out " + fill());
    }

    void report() {
        System.out.println(name + ": " + entries + " in, " + exits + " out, "
                + turnedAway + " turned away");
    }
}

public class ParkingGarage {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Gate north = new Gate("North");
        Gate south = new Gate("South");
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String first = in.next();
            if (first.equals("CAP")) {
                int c = in.nextInt();
                if (Gate.setCapacity(c)) {
                    System.out.println("Capacity is now " + c);
                } else {
                    System.out.println("Capacity " + c + " refused");
                }
                continue;
            }
            String action = in.next();
            Gate gate = first.equals("N") ? north : south;
            if (action.equals("IN")) {
                gate.enter();
            } else {
                gate.leave();
            }
        }
        north.report();
        south.report();
        System.out.println("Cars inside: " + Gate.getOccupied());
    }
}
```

### Explanation
- The number of cars inside is a fact about the garage, not about one gate: a car can
  enter at the north gate and leave at the south gate. So `occupied` and `capacity`
  are static and both gates see the same values.
- The counts per gate are instance fields, so each gate reports only its own traffic.
- `setCapacity` protects the shared state: the capacity cannot drop below the cars
  already inside (2 cars were inside when `CAP 1` came).
- A design note: static fields mean "one garage per program". If the university had
  two garages, all their gates would wrongly share one `occupied`. Then a `Garage`
  object passed to each `Gate` would be the better design. Static is right only when
  "exactly one" is truly part of the problem.

## Problem 15: Result Sheet with a Grade Enum
**Level:** Advanced

### Problem Statement
A course has three assessments with hypothetical maximum marks stored as constants:
class test 20, midterm 30 and final 50 (total 100). Write:

- `enum Grade` with constants `A(80, 4.0)`, `B(65, 3.0)`, `C(50, 2.0)`, `D(40, 1.0)`
  and `F(0, 0.0)` (minimum total and grade point), and a static method
  `Grade.fromTotal(int total)` that returns the first grade whose minimum is reached;
- a class `Student` with a private constructor, an auto-generated roll `R-01`,
  `R-02`, ... and a static factory method `create(name, ct, mid, fin)` that returns
  `null` if any mark is outside its range (no roll is used up);
- static statistics in `Student`: number of students, number passed (grade not `F`),
  sum of grade points, and the best student (highest total; the earlier student wins
  a tie).

Input: `n`, then `n` lines `name ct mid final`. Print each student as
`<roll> <name padded to 8> <total right-aligned in 3>  <grade>  <point with 2 decimals>`
or `<name>: invalid marks (CT 0-20, mid 0-30, final 0-50)`. Then print
`Students: <count>`, `Passed: <passed>`, `Average GP: <avg>` (2 decimals) and
`Highest: <name> (<total>)`; if no valid student was read, print only `Students: 0`.

### Sample Input
```text
5
Rahim 18 25 42
Nusrat 15 20 30
Karim 10 12 15
Mitu 21 25 40
Sadia 19 28 45
```

### Sample Output
```text
R-01 Rahim     85  A  4.00
R-02 Nusrat    65  B  3.00
R-03 Karim     37  F  0.00
Mitu: invalid marks (CT 0-20, mid 0-30, final 0-50)
R-04 Sadia     92  A  4.00
Students: 4
Passed: 3
Average GP: 2.75
Highest: Sadia (92)
```

### Solution
```java
import java.util.Scanner;

enum Grade {
    A(80, 4.0), B(65, 3.0), C(50, 2.0), D(40, 1.0), F(0, 0.0);

    private final int minTotal;
    private final double point;

    Grade(int minTotal, double point) {
        this.minTotal = minTotal;
        this.point = point;
    }

    double getPoint() {
        return point;
    }

    static Grade fromTotal(int total) {
        for (Grade g : values()) {   // declared from best to worst
            if (total >= g.minTotal) {
                return g;
            }
        }
        return F;
    }
}

class Student {
    static final int MAX_CT = 20;
    static final int MAX_MID = 30;
    static final int MAX_FINAL = 50;

    private static int count = 0;
    private static int passed = 0;
    private static double pointSum = 0;
    private static Student best = null;

    private final String roll;
    private final String name;
    private final int total;
    private final Grade grade;

    private Student(String name, int total) {
        count++;
        this.roll = String.format("R-%02d", count);
        this.name = name;
        this.total = total;
        this.grade = Grade.fromTotal(total);
        if (grade != Grade.F) {
            passed++;
        }
        pointSum += grade.getPoint();
        if (best == null || total > best.total) {
            best = this;
        }
    }

    private static boolean inRange(int mark, int max) {
        return mark >= 0 && mark <= max;
    }

    static Student create(String name, int ct, int mid, int fin) {
        if (!inRange(ct, MAX_CT) || !inRange(mid, MAX_MID) || !inRange(fin, MAX_FINAL)) {
            return null;
        }
        return new Student(name, ct + mid + fin);
    }

    String describe() {
        return String.format("%s %-8s %3d  %s  %.2f", roll, name, total, grade,
                grade.getPoint());
    }

    static void printSummary() {
        System.out.println("Students: " + count);
        if (count == 0) {
            return;
        }
        System.out.println("Passed: " + passed);
        System.out.printf("Average GP: %.2f%n", pointSum / count);
        System.out.println("Highest: " + best.name + " (" + best.total + ")");
    }
}

public class ResultSheet {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String name = in.next();
            int ct = in.nextInt();
            int mid = in.nextInt();
            int fin = in.nextInt();
            Student s = Student.create(name, ct, mid, fin);
            if (s == null) {
                System.out.println(name + ": invalid marks (CT 0-" + Student.MAX_CT
                        + ", mid 0-" + Student.MAX_MID + ", final 0-"
                        + Student.MAX_FINAL + ")");
            } else {
                System.out.println(s.describe());
            }
        }
        Student.printSummary();
    }
}
```

### Explanation
- `Grade` is an enum with data: each constant stores its minimum total and grade
  point. The static method `fromTotal` walks through `values()` in declaration order
  (best first) and returns the first grade reached, so the grade table lives in one
  place.
- `Student.create` is a factory method that validates all three marks against the
  constants before the private constructor runs; Mitu's invalid line therefore does
  not use up a roll number, and Sadia gets `R-04`.
- The statistics are static because they are about the whole class of students. The
  constructor updates them, and `best` is a static reference to the student object
  with the highest total; `total > best.total` (strictly greater) keeps the earlier
  student in a tie.
- Inside `Student`, the static method `printSummary` may read `best.name` even
  though `name` is private and an instance field, because it reaches it through a
  reference to an object of its own class.
- Average GP: (4.00 + 3.00 + 0.00 + 4.00) / 4 = 2.75.
