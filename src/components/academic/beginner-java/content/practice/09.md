# Practice Problems: Inheritance

These problems practise `extends`, `super`, constructor order, overriding, `protected`,
`final`, the `Object` methods, interfaces and composition, using vehicles, staff,
shapes, bank accounts and university members. Programs read input without prompts and
print exactly the sample output.

## Problem 1: Bus Trip Planner
**Level:** Basic

### Problem Statement
Write a class `Vehicle` with a private registration number and a private speed in km/h.
It has a method `travelMinutes(int distanceKm)` that returns the travel time in whole
minutes (`distanceKm * 60 / speed`, rounded down) and a method `describe()` that returns
`Vehicle <regNo>, speed <speed> km/h`.

Write a class `Bus` that extends `Vehicle` and adds the number of seats and a method
`busesNeeded(int passengers)` that returns how many buses are needed to carry that many
passengers (round up).

The input is one line `regNo speed seats`, then one line `distance passengers`. Print:

```text
<describe()>
Seats per bus: <seats>
Trip of <distance> km: <minutes> minutes
Buses needed for <passengers> passengers: <buses>
```

### Sample Input
```text
DHAKA-BA-1122 40 45
30 100
```

### Sample Output
```text
Vehicle DHAKA-BA-1122, speed 40 km/h
Seats per bus: 45
Trip of 30 km: 45 minutes
Buses needed for 100 passengers: 3
```

### Solution
```java
import java.util.Scanner;

class Vehicle {
    private String regNo;
    private int speedKmh;

    Vehicle(String regNo, int speedKmh) {
        this.regNo = regNo;
        this.speedKmh = speedKmh;
    }

    public int travelMinutes(int distanceKm) {
        return distanceKm * 60 / speedKmh;
    }

    public String describe() {
        return "Vehicle " + regNo + ", speed " + speedKmh + " km/h";
    }
}

class Bus extends Vehicle {
    private int seats;

    Bus(String regNo, int speedKmh, int seats) {
        super(regNo, speedKmh);
        this.seats = seats;
    }

    public int getSeats() {
        return seats;
    }

    public int busesNeeded(int passengers) {
        return (passengers + seats - 1) / seats;
    }
}

public class BusTripPlanner {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Bus bus = new Bus(in.next(), in.nextInt(), in.nextInt());
        int distance = in.nextInt();
        int passengers = in.nextInt();

        System.out.println(bus.describe());
        System.out.println("Seats per bus: " + bus.getSeats());
        System.out.println("Trip of " + distance + " km: "
                + bus.travelMinutes(distance) + " minutes");
        System.out.println("Buses needed for " + passengers + " passengers: "
                + bus.busesNeeded(passengers));
    }
}
```

### Explanation
`Bus` declares only what is new about a bus: the seats and `busesNeeded`. The methods
`describe()` and `travelMinutes()` are inherited from `Vehicle`, so `bus.describe()`
works even though `Bus` never defines it. The bus constructor passes the registration
number and speed to `super(...)`, because those fields are private in `Vehicle` and only
`Vehicle` can set them. `(passengers + seats - 1) / seats` is the usual integer trick
for dividing and rounding up.

## Problem 2: Student ID Card
**Level:** Basic

### Problem Statement
Write a class `Person` with private fields `name` and `phone`, a constructor that sets
both, getters, and a method `initials()` that returns the first letter of every word of
the name in upper case (`Ayesha Siddiqua Khan` gives `ASK`).

Write a class `Student` that extends `Person`, adds a private student ID and the number
of credits taken this trimester, and has a method `printIdCard()`. The `Student`
constructor must call `super(...)`. A student with 9 or more credits is `Full-time`,
otherwise `Part-time`.

Input: the full name on the first line, the phone number on the second line, then the
student ID and the credits on the third line. Output the card exactly as in the sample.

### Sample Input
```text
Ayesha Siddiqua Khan
01711000000
011-232-017 7
```

### Sample Output
```text
ID CARD
Name    : Ayesha Siddiqua Khan (ASK)
Phone   : 01711000000
ID      : 011-232-017
Credits : 7 (Part-time)
```

### Solution
```java
import java.util.Scanner;

class Person {
    private String name;
    private String phone;

    Person(String name, String phone) {
        this.name = name;
        this.phone = phone;
    }

    public String getName() {
        return name;
    }

    public String getPhone() {
        return phone;
    }

    public String initials() {
        String result = "" + name.charAt(0);
        for (int i = 1; i < name.length(); i++) {
            if (name.charAt(i - 1) == ' ' && name.charAt(i) != ' ') {
                result += name.charAt(i);
            }
        }
        return result.toUpperCase();
    }
}

class Student extends Person {
    private String studentId;
    private int credits;

    Student(String name, String phone, String studentId, int credits) {
        super(name, phone);
        this.studentId = studentId;
        this.credits = credits;
    }

    public void printIdCard() {
        String load = credits >= 9 ? "Full-time" : "Part-time";
        System.out.println("ID CARD");
        System.out.println("Name    : " + getName() + " (" + initials() + ")");
        System.out.println("Phone   : " + getPhone());
        System.out.println("ID      : " + studentId);
        System.out.println("Credits : " + credits + " (" + load + ")");
    }
}

public class StudentIdCard {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String name = in.nextLine();
        String phone = in.nextLine();
        String id = in.next();
        int credits = in.nextInt();
        Student student = new Student(name, phone, id, credits);
        student.printIdCard();
    }
}
```

### Explanation
`Person` has no no-argument constructor, so `Student` must call `super(name, phone)` as
the first statement of its constructor; without it the program does not compile.
Inside `printIdCard()` the student cannot write `name` or `phone`, because they are
private in `Person`. The fields still exist inside the `Student` object, and the
inherited getters and `initials()` give access to them. This keeps all name-related
logic in one class, ready to be reused by a future `Teacher extends Person`.

## Problem 3: Savings Deposit Bonus
**Level:** Basic

### Problem Statement
Write a class `Account` with a private account number and a private `int` balance, a
method `deposit(int amount)` (ignore amounts that are not positive), and a method
`describe()` that returns `<number> balance Tk <balance>`.

Write `SavingsAccount extends Account`. It overrides `deposit`: after a normal deposit,
any single deposit of Tk 10000 or more earns a bonus of Tk 50, and the account counts
how many bonuses it has received. It also overrides `describe()` to return the
superclass text followed by ` | savings, bonuses: <count>`. Use `@Override` and
`super`.

Input: the account number and opening balance, then `n`, then `n` deposit amounts.
After each deposit print the savings account's `describe()`. Finally print
`Plain account would have: Tk <x>`, the balance a plain `Account` with the same opening
balance and deposits would have.

### Sample Input
```text
SA-101 2000
3
5000
10000
300
```

### Sample Output
```text
SA-101 balance Tk 7000 | savings, bonuses: 0
SA-101 balance Tk 17050 | savings, bonuses: 1
SA-101 balance Tk 17350 | savings, bonuses: 1
Plain account would have: Tk 17300
```

### Solution
```java
import java.util.Scanner;

class Account {
    private String number;
    private int balance;

    Account(String number, int balance) {
        this.number = number;
        this.balance = balance;
    }

    public int getBalance() {
        return balance;
    }

    public void deposit(int amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    public String describe() {
        return number + " balance Tk " + balance;
    }
}

class SavingsAccount extends Account {
    public static final int BONUS_LIMIT = 10000;
    public static final int BONUS = 50;
    private int bonuses;

    SavingsAccount(String number, int balance) {
        super(number, balance);
    }

    @Override
    public void deposit(int amount) {
        super.deposit(amount);              // the normal deposit
        if (amount >= BONUS_LIMIT) {
            super.deposit(BONUS);           // the bonus, without another bonus check
            bonuses++;
        }
    }

    @Override
    public String describe() {
        return super.describe() + " | savings, bonuses: " + bonuses;
    }
}

public class SavingsBonus {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String number = in.next();
        int opening = in.nextInt();
        SavingsAccount savings = new SavingsAccount(number, opening);
        Account plain = new Account(number, opening);

        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            int amount = in.nextInt();
            savings.deposit(amount);
            plain.deposit(amount);
            System.out.println(savings.describe());
        }
        System.out.println("Plain account would have: Tk " + plain.getBalance());
    }
}
```

### Explanation
The balance is private in `Account`, so the subclass cannot write `balance += 50`.
Instead it calls `super.deposit(...)`, which reuses the superclass's rule (ignore
non-positive amounts) and changes the balance correctly. `describe()` is extended in the
same way: `super.describe()` builds the common part and the subclass adds its own text.
The plain `Account` object receives the same deposits and shows that only the overridden
method adds the bonus.

## Problem 4: Hospital Constructor Trace
**Level:** Basic

### Problem Statement
Build the hierarchy `Person -> Staff -> Doctor` for a hospital. `Person` stores a name,
`Staff` adds a staff ID, `Doctor` adds a department. Every constructor calls the one
above it with `super(...)`, then prints one line (two spaces, then
`Person(<name>)`, `Staff(<id>)` or `Doctor(<department>)`). A `protected static`
counter in `Person` counts how many constructor bodies of these three classes have run.

Input: `n`, then `n` lines. A line `D <name> <id> <department>` creates a doctor; a line
`S <name> <id>` creates a staff member. Before creating each object print
`Creating doctor <name>` or `Creating staff <name>`. At the end print
`Constructors run: <count>`.

### Sample Input
```text
2
D Farhana S-17 Cardiology
S Rafi S-22
```

### Sample Output
```text
Creating doctor Farhana
  Person(Farhana)
  Staff(S-17)
  Doctor(Cardiology)
Creating staff Rafi
  Person(Rafi)
  Staff(S-22)
Constructors run: 5
```

### Solution
```java
import java.util.Scanner;

class Person {
    protected static int constructorsRun = 0;
    private String name;

    Person(String name) {
        this.name = name;
        constructorsRun++;
        System.out.println("  Person(" + name + ")");
    }

    public String getName() {
        return name;
    }
}

class Staff extends Person {
    private String staffId;

    Staff(String name, String staffId) {
        super(name);
        this.staffId = staffId;
        constructorsRun++;
        System.out.println("  Staff(" + staffId + ")");
    }
}

class Doctor extends Staff {
    private String department;

    Doctor(String name, String staffId, String department) {
        super(name, staffId);
        this.department = department;
        constructorsRun++;
        System.out.println("  Doctor(" + department + ")");
    }
}

public class HospitalConstructorTrace {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String type = in.next();
            String name = in.next();
            String id = in.next();
            if (type.equals("D")) {
                String department = in.next();
                System.out.println("Creating doctor " + name);
                Doctor doctor = new Doctor(name, id, department);
                doctor.getName();
            } else {
                System.out.println("Creating staff " + name);
                Staff staff = new Staff(name, id);
                staff.getName();
            }
        }
        System.out.println("Constructors run: " + Person.constructorsRun);
    }
}
```

### Explanation
`new Doctor(...)` first calls `Staff(...)`, which first calls `Person(...)`, which
first calls `Object()`. The bodies then finish from the top down, so `Person` prints
first and `Doctor` last, even though `Doctor` was the constructor called. A plain
`Staff` object has no `Doctor` part, so only two of our constructors run for it. The
counter is `static` (one copy for the class, Chapter 07) and `protected`, so all three
constructors can update it.

## Problem 5: Course Registration Duplicates
**Level:** Basic

### Problem Statement
Write a class `Course` with a code and a title. Two courses are equal when their codes
are equal **ignoring case** (`cse1115` is the same course as `CSE1115`). Override
`equals` and `hashCode` consistently, and override `toString` to return
`<CODE in upper case> <title>`.

Input: `n`, then `n` lines, each `code title` (the title may contain spaces). Keep an
`ArrayList<Course>`. For each line print `Registered: <course>` if the course is not
yet in the list (and add it), otherwise `Already registered: <CODE>`. Finally print
`Total: <k> courses` and the list itself.

### Sample Input
```text
5
CSE1115 Object Oriented Programming
MAT2105 Linear Algebra
cse1115 OOP retake form
PHY1101 Physics
Mat2105 Linear Algebra
```

### Sample Output
```text
Registered: CSE1115 Object Oriented Programming
Registered: MAT2105 Linear Algebra
Already registered: CSE1115
Registered: PHY1101 Physics
Already registered: MAT2105
Total: 3 courses
[CSE1115 Object Oriented Programming, MAT2105 Linear Algebra, PHY1101 Physics]
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Course {
    private String code;
    private String title;

    Course(String code, String title) {
        this.code = code;
        this.title = title;
    }

    public String getCode() {
        return code.toUpperCase();
    }

    @Override
    public boolean equals(Object other) {
        if (this == other) {
            return true;
        }
        if (other == null || getClass() != other.getClass()) {
            return false;
        }
        Course that = (Course) other;
        return code.equalsIgnoreCase(that.code);
    }

    @Override
    public int hashCode() {
        return code.toUpperCase().hashCode();
    }

    @Override
    public String toString() {
        return getCode() + " " + title;
    }
}

public class CourseDuplicates {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        ArrayList<Course> registered = new ArrayList<Course>();
        for (int i = 0; i < n; i++) {
            String code = in.next();
            String title = in.nextLine().trim();
            Course course = new Course(code, title);
            if (registered.contains(course)) {
                System.out.println("Already registered: " + course.getCode());
            } else {
                registered.add(course);
                System.out.println("Registered: " + course);
            }
        }
        System.out.println("Total: " + registered.size() + " courses");
        System.out.println(registered);
    }
}
```

### Explanation
`ArrayList.contains` compares with `equals`, which every class inherits from `Object`.
The inherited version only checks whether two references point to the same object, and
every line creates a new `Course`, so without the override no duplicate would ever be
found. The override compares codes with `equalsIgnoreCase`. `hashCode` must agree:
equal courses need equal hash codes, so it hashes the upper-case code; hashing the code
as typed would give `cse1115` and `CSE1115` different hash codes and break `HashSet`.
Printing the list calls the overridden `toString()` on each element.

## Problem 6: Shape Areas
**Level:** Intermediate

### Problem Statement
Build this hierarchy: `Shape` (has a name, methods `area()` and `perimeter()` that
return 0, and a `final` method `describe()`), `Circle`, `Rectangle` and `Triangle`
extend `Shape`, and `Square` extends `Rectangle`. Each concrete shape overrides
`area()` and `perimeter()`. `describe()` returns
`<name>: area <a>, perimeter <p>` with two decimals. `Square` must reuse `Rectangle`
through a `protected` constructor that also takes the name.

Input: `n`, then `n` lines: `C r`, `R w h`, `S side` or `T a b c`. A triangle whose
sides are not positive or break the triangle inequality is not created; print
`Invalid triangle: <a> <b> <c>` (one decimal each) instead. After all lines print
`Total area: <t>` and `Largest: <name> (<area>)` with two decimals (the first one wins a
tie; skip this line if no shape was created).

### Sample Input
```text
5
C 2
R 3 4
S 2.5
T 3 4 5
T 1 2 5
```

### Sample Output
```text
Circle: area 12.57, perimeter 12.57
Rectangle: area 12.00, perimeter 14.00
Square: area 6.25, perimeter 10.00
Triangle: area 6.00, perimeter 12.00
Invalid triangle: 1.0 2.0 5.0
Total area: 36.82
Largest: Circle (12.57)
```

### Solution
```java
import java.util.Scanner;

class Shape {
    private String name;

    Shape(String name) {
        this.name = name;
    }

    public String getName() {
        return name;
    }

    public double area() {
        return 0;
    }

    public double perimeter() {
        return 0;
    }

    public final String describe() {
        return String.format("%s: area %.2f, perimeter %.2f", name, area(), perimeter());
    }
}

class Circle extends Shape {
    private double radius;

    Circle(double radius) {
        super("Circle");
        this.radius = radius;
    }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }

    @Override
    public double perimeter() {
        return 2 * Math.PI * radius;
    }
}

class Rectangle extends Shape {
    private double width;
    private double height;

    Rectangle(double width, double height) {
        this("Rectangle", width, height);
    }

    protected Rectangle(String name, double width, double height) {
        super(name);
        this.width = width;
        this.height = height;
    }

    @Override
    public double area() {
        return width * height;
    }

    @Override
    public double perimeter() {
        return 2 * (width + height);
    }
}

class Square extends Rectangle {
    Square(double side) {
        super("Square", side, side);
    }
}

class Triangle extends Shape {
    private double a;
    private double b;
    private double c;

    Triangle(double a, double b, double c) {
        super("Triangle");
        this.a = a;
        this.b = b;
        this.c = c;
    }

    public static boolean isValid(double a, double b, double c) {
        return a > 0 && b > 0 && c > 0 && a + b > c && a + c > b && b + c > a;
    }

    @Override
    public double area() {
        double s = perimeter() / 2;
        return Math.sqrt(s * (s - a) * (s - b) * (s - c));   // Heron's formula
    }

    @Override
    public double perimeter() {
        return a + b + c;
    }
}

public class ShapeAreas {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        double total = 0;
        Shape largest = null;
        for (int i = 0; i < n; i++) {
            String type = in.next();
            Shape shape = null;
            if (type.equals("C")) {
                shape = new Circle(in.nextDouble());
            } else if (type.equals("R")) {
                shape = new Rectangle(in.nextDouble(), in.nextDouble());
            } else if (type.equals("S")) {
                shape = new Square(in.nextDouble());
            } else {
                double a = in.nextDouble();
                double b = in.nextDouble();
                double c = in.nextDouble();
                if (Triangle.isValid(a, b, c)) {
                    shape = new Triangle(a, b, c);
                } else {
                    System.out.printf("Invalid triangle: %.1f %.1f %.1f%n", a, b, c);
                }
            }
            if (shape != null) {
                System.out.println(shape.describe());
                total += shape.area();
                if (largest == null || shape.area() > largest.area()) {
                    largest = shape;
                }
            }
        }
        System.out.printf("Total area: %.2f%n", total);
        if (largest != null) {
            System.out.printf("Largest: %s (%.2f)%n", largest.getName(), largest.area());
        }
    }
}
```

### Explanation
- This is hierarchical inheritance (three classes extend `Shape`) combined with
  multilevel inheritance (`Square -> Rectangle -> Shape`).
- `describe()` is written once and is `final`, so every shape prints in the same
  format. Inside it, `area()` and `perimeter()` run the overriding version of the
  object's actual class.
- `Square` adds nothing new: its constructor passes the side twice to the `protected`
  `Rectangle` constructor, which only subclasses (and the package) may use. The public
  `Rectangle(w, h)` constructor chains to it with `this(...)`.
- A `Shape` variable can hold any of the shapes because each one *is a* `Shape`
  (Chapter 10 explores this further).
- The triangle is validated with a `static` helper before it is created, so a
  `Triangle` object never holds impossible sides.

## Problem 7: Savings and Current Accounts
**Level:** Intermediate

### Problem Statement
Write a class `Account` with a `protected int balance` and methods
`deposit(int amount)` and `withdraw(int amount)` that return `true` on success. A
deposit must be positive; a withdrawal must be positive and not more than the balance.

- `SavingsAccount extends Account` overrides `withdraw`: the balance may never drop
  below Tk 1000. If the rule is satisfied it uses the superclass's `withdraw`.
- `CurrentAccount extends Account` has an overdraft limit: a positive withdrawal is
  allowed while the balance after it is not below `-limit`.

Input: the savings opening balance; the current account opening balance and its
overdraft limit; then `n` commands `<S|C> <D|W> <amount>` (S = savings, C = current,
D = deposit, W = withdraw). For each command print
`<command>: OK (balance Tk <b>)` or `<command>: REFUSED (balance Tk <b>)`. Finally print
`Final: savings Tk <s>, current Tk <c>`.

### Sample Input
```text
5000
2000 3000
7
S W 4500
S W 4000
C W 4500
C W 1000
C D 1000
S D 0
S D 200
```

### Sample Output
```text
S W 4500: REFUSED (balance Tk 5000)
S W 4000: OK (balance Tk 1000)
C W 4500: OK (balance Tk -2500)
C W 1000: REFUSED (balance Tk -2500)
C D 1000: OK (balance Tk -1500)
S D 0: REFUSED (balance Tk 1000)
S D 200: OK (balance Tk 1200)
Final: savings Tk 1200, current Tk -1500
```

### Solution
```java
import java.util.Scanner;

class Account {
    protected int balance;

    Account(int balance) {
        this.balance = balance;
    }

    public int getBalance() {
        return balance;
    }

    public boolean deposit(int amount) {
        if (amount <= 0) {
            return false;
        }
        balance += amount;
        return true;
    }

    public boolean withdraw(int amount) {
        if (amount <= 0 || amount > balance) {
            return false;
        }
        balance -= amount;
        return true;
    }
}

class SavingsAccount extends Account {
    public static final int MIN_BALANCE = 1000;

    SavingsAccount(int balance) {
        super(balance);
    }

    @Override
    public boolean withdraw(int amount) {
        if (balance - amount < MIN_BALANCE) {
            return false;
        }
        return super.withdraw(amount);       // still checks amount > 0
    }
}

class CurrentAccount extends Account {
    private int overdraftLimit;

    CurrentAccount(int balance, int overdraftLimit) {
        super(balance);
        this.overdraftLimit = overdraftLimit;
    }

    @Override
    public boolean withdraw(int amount) {
        if (amount <= 0 || balance - amount < -overdraftLimit) {
            return false;
        }
        balance -= amount;                   // may go below zero
        return true;
    }
}

public class TwoAccounts {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        SavingsAccount savings = new SavingsAccount(in.nextInt());
        CurrentAccount current = new CurrentAccount(in.nextInt(), in.nextInt());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String which = in.next();
            String action = in.next();
            int amount = in.nextInt();
            Account account;
            if (which.equals("S")) {
                account = savings;
            } else {
                account = current;
            }
            boolean ok;
            if (action.equals("D")) {
                ok = account.deposit(amount);
            } else {
                ok = account.withdraw(amount);
            }
            System.out.println(which + " " + action + " " + amount + ": "
                    + (ok ? "OK" : "REFUSED") + " (balance Tk " + account.getBalance() + ")");
        }
        System.out.println("Final: savings Tk " + savings.getBalance()
                + ", current Tk " + current.getBalance());
    }
}
```

### Explanation
`balance` is `protected`, so both subclasses can read it in their rules, and
`CurrentAccount` can make it negative, which the superclass rule would never allow.
`SavingsAccount` adds one extra check and then delegates to `super.withdraw`, so the
"amount must be positive" rule lives in one place. `CurrentAccount` must replace the
superclass rule completely, so it does not call `super.withdraw`. In `main`, the
`Account account` variable refers to whichever account the command names, and the
`withdraw` call runs that object's own version. Note the cost of `protected`: any
subclass could now break the balance rules, which is why `private` plus methods is the
usual default.

## Problem 8: Ride Fare Breakdown
**Level:** Intermediate

### Problem Statement
A ride-sharing app has three ride types in a multilevel chain:
`Ride -> AcRide -> PremiumRide`.

- `Ride`: fare = 40 + 15 per km.
- `AcRide`: the `Ride` fare plus an AC surcharge of 10% of the `Ride` fare (integer
  division).
- `PremiumRide`: the `AcRide` fare plus a premium fee of 50 plus Tk 3 per waiting
  minute.

Each class overrides `fare()`, `label()` and `printBreakdown()`, and each override
calls the superclass version with `super` and adds its own part. Breakdown lines are
indented by two spaces; the waiting line is printed only when waiting minutes are more
than 0.

Input: `n`, then `n` lines `N km`, `A km` or `P km wait`. For ride `i` print
`Ride <i> (<label>, <km> km)`, its breakdown, and `  Total: Tk <fare>`. Finally print
`All rides: Tk <sum>`.

### Sample Input
```text
4
N 5
A 12
P 5 12
P 3 0
```

### Sample Output
```text

  Total: Tk 115

  Total: Tk 242

  base 40 + 5 km x 15 = 115
  AC surcharge 10% = +11

  base 40 + 3 km x 15 = 85
```

### Solution
```java
import java.util.Scanner;

class Ride {
    public static final int BASE = 40;
    public static final int PER_KM = 15;
    private int km;

    Ride(int km) {
        this.km = km;
    }

    public int getKm() {
        return km;
    }

    public String label() {
        return "Normal";
    }

    public int fare() {
        return BASE + PER_KM * km;
    }

    public void printBreakdown() {
        // not fare(): inside Ride, fare() would run the subclass version
        int distanceFare = BASE + PER_KM * km;
        System.out.println("  base " + BASE + " + " + km + " km x " + PER_KM
                + " = " + distanceFare);
    }
}

class AcRide extends Ride {
    AcRide(int km) {
        super(km);
    }

    protected int acSurcharge() {
        return super.fare() * 10 / 100;     // always Ride's fare
    }

    @Override
    public String label() {
        return "AC";
    }

    @Override
    public int fare() {
        return super.fare() + acSurcharge();
    }

    @Override
    public void printBreakdown() {
        super.printBreakdown();
        System.out.println("  AC surcharge 10% = +" + acSurcharge());
    }
}

class PremiumRide extends AcRide {
    public static final int PREMIUM_FEE = 50;
    public static final int WAIT_RATE = 3;
    private int waitMinutes;

    PremiumRide(int km, int waitMinutes) {
        super(km);
        this.waitMinutes = waitMinutes;
    }

    @Override
    public String label() {
        return "Premium";
    }

    @Override
    public int fare() {
        return super.fare() + PREMIUM_FEE + WAIT_RATE * waitMinutes;
    }

    @Override
    public void printBreakdown() {
        super.printBreakdown();
        System.out.println("  premium fee = +" + PREMIUM_FEE);
        if (waitMinutes > 0) {
            System.out.println("  waiting " + waitMinutes + " min x " + WAIT_RATE
                    + " = +" + WAIT_RATE * waitMinutes);
        }
    }
}

public class RideFares {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            String type = in.next();
            int km = in.nextInt();
            Ride ride;
            if (type.equals("N")) {
                ride = new Ride(km);
            } else if (type.equals("A")) {
                ride = new AcRide(km);
            } else {
                ride = new PremiumRide(km, in.nextInt());
            }
            System.out.println("Ride " + i + " (" + ride.label() + ", "
                    + ride.getKm() + " km)");
            ride.printBreakdown();
            System.out.println("  Total: Tk " + ride.fare());
            sum += ride.fare();
        }
        System.out.println("All rides: Tk " + sum);
    }
}
```

### Explanation
Each level adds exactly one piece and reuses everything above it through `super`, so
the Premium breakdown is built by three methods in three classes. Two details matter:

- A `super.fare()` call always means the version in the direct superclass. In
  `AcRide.acSurcharge()` it is `Ride.fare()`, even when the object is a `PremiumRide`, so
  the surcharge is always 10% of the plain distance fare.
- A plain call `fare()` inside `Ride` would run the object's overriding version. That is
  why `Ride.printBreakdown()` computes the distance fare itself instead of calling
  `fare()`; otherwise a premium ride would print its full price on the "base" line.

## Problem 9: Campus Smart Card
**Level:** Intermediate

### Problem Statement
A campus smart card is an ID card that also works as a library pass and a shuttle pass.
Java does not allow a class to extend three classes, so model it as
`class SmartCard extends IdCard implements LibraryPass, ShuttlePass`.

- `IdCard` (class): holder name and ID; `toString()` returns `<name> (<id>)`.
- `LibraryPass` (interface): `boolean borrowBook(String title)`,
  `boolean returnBook(String title)`, `int borrowedCount()`, `String loans()`.
- `ShuttlePass` (interface): `boolean payFare(int fare)`, `void topUp(int amount)`,
  `int getBalance()`.
- `SmartCard`: at most 3 borrowed books and the same title cannot be borrowed twice;
  a fare is paid only if the balance covers it.

Input: the holder's name and ID, then the opening shuttle balance, then `n` commands:
`BORROW <title>`, `RETURN <title>` (titles may contain spaces), `TOPUP <amount>`,
`RIDE <fare>`. Output formats are shown in the sample (`OK`/`REFUSED` for borrowing,
`OK`/`NOT BORROWED` for returning, `OK`/`LOW BALANCE` for rides). At the end, using a
`LibraryPass` variable and a `ShuttlePass` variable that both refer to the card, print
`Library: <count> books <loans>` and `Shuttle: balance Tk <b>`.

### Sample Input
```text

500
10

BORROW Algorithms
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

interface LibraryPass {
    boolean borrowBook(String title);

    boolean returnBook(String title);

    int borrowedCount();

    String loans();
}

interface ShuttlePass {
    boolean payFare(int fare);

    void topUp(int amount);

    int getBalance();
}

class IdCard {
    private String holder;
    private String id;

    IdCard(String holder, String id) {
        this.holder = holder;
        this.id = id;
    }

    @Override
    public String toString() {
        return holder + " (" + id + ")";
    }
}

class SmartCard extends IdCard implements LibraryPass, ShuttlePass {
    public static final int MAX_BOOKS = 3;
    private ArrayList<String> books = new ArrayList<String>();
    private int balance;

    SmartCard(String holder, String id, int balance) {
        super(holder, id);
        this.balance = balance;
    }

    @Override
    public boolean borrowBook(String title) {
        if (books.size() == MAX_BOOKS || books.contains(title)) {
            return false;
        }
        books.add(title);
        return true;
    }

    @Override
    public boolean returnBook(String title) {
        return books.remove(title);          // false if it was not borrowed
    }

    @Override
    public int borrowedCount() {
        return books.size();
    }

    @Override
    public String loans() {
        return books.toString();
    }

    @Override
    public boolean payFare(int fare) {
        if (fare > balance) {
            return false;
        }
        balance -= fare;
        return true;
    }

    @Override
    public void topUp(int amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    @Override
    public int getBalance() {
        return balance;
    }
}

public class CampusSmartCard {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        SmartCard card = new SmartCard(in.next(), in.next(), in.nextInt());
        System.out.println("Card: " + card);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("BORROW")) {
                String title = in.nextLine().trim();
                boolean ok = card.borrowBook(title);
                System.out.println("BORROW " + title + ": " + (ok ? "OK" : "REFUSED"));
            } else if (command.equals("RETURN")) {
                String title = in.nextLine().trim();
                boolean ok = card.returnBook(title);
                System.out.println("RETURN " + title + ": " + (ok ? "OK" : "NOT BORROWED"));
            } else if (command.equals("TOPUP")) {
                int amount = in.nextInt();
                card.topUp(amount);
                System.out.println("TOPUP " + amount + ": balance Tk " + card.getBalance());
            } else {
                int fare = in.nextInt();
                String result = card.payFare(fare) ? "OK" : "LOW BALANCE";
                System.out.println("RIDE " + fare + ": " + result
                        + ", balance Tk " + card.getBalance());
            }
        }
        LibraryPass library = card;
        ShuttlePass shuttle = card;
        System.out.println("Library: " + library.borrowedCount() + " books "
                + library.loans());
        System.out.println("Shuttle: balance Tk " + shuttle.getBalance());
    }
}
```

### Explanation
`SmartCard` inherits state and code (holder, ID, `toString`) from exactly one class,
`IdCard`. From the two interfaces it inherits only *types* and the duty to implement
their methods, which is why every interface method appears with `@Override` and
`public`. Because the card *is a* `LibraryPass` and *is a* `ShuttlePass`, the same object
can be stored in variables of both interface types; the library desk would only see
library methods, and the shuttle reader only shuttle methods. `books.remove(title)`
uses `String.equals` to find the title and returns `false` when it is not in the list.

## Problem 10: Library Return Cart
**Level:** Intermediate

### Problem Statement
Returned books are stacked on a cart; the librarian always takes the top book first.
Write a class `ReturnCart` that **has** a private `ArrayList<String>` (composition) and
a fixed capacity, with methods `push(String title)` (returns `false` when full),
`pop()` and `peek()` (return `null` when empty), `size()` and `toString()` (the titles
from bottom to top in list form). Do not extend `ArrayList`: the cart must allow no

Input: the capacity, then `n`, then `n` commands: `PUSH <title>`, `POP`, `PEEK`,
`SIZE`. Print a result line for each command as in the sample (`EMPTY` when there is
nothing to pop or peek), and finally `Cart: <cart>`.

### Sample Input
```text
3
11
PUSH Clean Code
PUSH Java Basics
PEEK
PUSH Algorithms
PUSH Networking
POP
POP
SIZE
POP
POP
PUSH Databases
```

### Sample Output
```text

PUSH Java Basics: OK
PEEK: Java Basics
PUSH Algorithms: OK

POP: Algorithms
POP: Java Basics
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class ReturnCart {
    private ArrayList<String> books = new ArrayList<String>();
    private int capacity;

    ReturnCart(int capacity) {
        this.capacity = capacity;
    }

    public boolean push(String title) {
        if (books.size() == capacity) {
            return false;
        }
        books.add(title);
        return true;
    }

    public String pop() {
        if (books.isEmpty()) {
            return null;
        }
        return books.remove(books.size() - 1);
    }

    public String peek() {
        if (books.isEmpty()) {
            return null;
        }
        return books.get(books.size() - 1);
    }

    public int size() {
        return books.size();
    }

    @Override
    public String toString() {
        return books.toString();
    }
}

public class LibraryReturnCart {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        ReturnCart cart = new ReturnCart(in.nextInt());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("PUSH")) {
                String title = in.nextLine().trim();
                System.out.println("PUSH " + title + ": " + (cart.push(title) ? "OK" : "FULL"));
            } else if (command.equals("SIZE")) {
                System.out.println("SIZE: " + cart.size());
            } else {
                String title;
                if (command.equals("POP")) {
                    title = cart.pop();
                } else {
                    title = cart.peek();
                }
                System.out.println(command + ": " + (title == null ? "EMPTY" : title));
            }
        }
        System.out.println("Cart: " + cart);
    }
}
```

### Explanation
It is tempting to write `class ReturnCart extends ArrayList<String>` and get `add`,
`remove` and `size` for free. But "a cart *is a* list" would also give every caller
`add(0, title)`, `remove(index)`, `clear()` and `set(...)`, so anyone could slip a book
into the middle or ignore the capacity. With composition the list is a private field:
the cart decides which operations exist and checks the capacity in one place, and it
delegates the actual storage work to the `ArrayList`. Only `toString` is an override,
of the method every class inherits from `Object`.

## Problem 11: Monthly Payroll with Tax
**Level:** Advanced

### Problem Statement
A company has three kinds of employees:

- full-time (`F id name basic`): gross pay = basic salary;
- hourly (`H id name rate hours`): the first 160 hours are paid at `rate`; every hour
  above 160 is paid at `rate * 3 / 2` (integer arithmetic);
- commission (`C id name basic sales percent`): gross = basic + `sales * percent / 100`.

Tax is the same rule for everyone: 10% (integer division) of the part of the gross pay
above Tk 30000; nothing if the gross is Tk 30000 or less. Net = gross - tax.

Design `Employee` (the full-time employee) with `HourlyEmployee` and
`CommissionEmployee` as subclasses that override `grossPay()` and `type()`. The tax,
net and payslip-row methods must be `final` in `Employee` so no subclass can change the
tax rule. Store everyone in one `ArrayList<Employee>`.

Input: `n`, then `n` employee lines. Output: a header row, one row per employee
(format `%-4s %-8s %-10s %7d %6d %7d`, the header uses the same widths with `s`), then
`Total gross: Tk <g>`, `Total tax: Tk <t>`, `Taxpayers: <k> of <n>` and
`Highest net: <name> (Tk <net>)` (the first one wins a tie).

### Sample Input
```text
4
F E01 Karim 42000
H E02 Rafi 200 172
C E03 Nusrat 20000 150000 5
F E04 Mitu 28000
```

### Sample Output
```text
ID   Name     Type         Gross    Tax     Net
E01  Karim    Full-time    42000   1200   40800
E02  Rafi     Hourly       35600    560   35040
E03  Nusrat   Commission   27500      0   27500
E04  Mitu     Full-time    28000      0   28000
Total gross: Tk 133100
Total tax: Tk 1760
Taxpayers: 2 of 4
Highest net: Karim (Tk 40800)
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Employee {
    public static final int TAX_FREE_LIMIT = 30000;
    public static final String ROW = "%-4s %-8s %-10s %7d %6d %7d";
    private String id;
    private String name;
    private int basicSalary;

    Employee(String id, String name, int basicSalary) {
        this.id = id;
        this.name = name;
        this.basicSalary = basicSalary;
    }

    public String getName() {
        return name;
    }

    public String type() {
        return "Full-time";
    }

    public int grossPay() {
        return basicSalary;
    }

    public final int tax() {
        int gross = grossPay();
        if (gross <= TAX_FREE_LIMIT) {
            return 0;
        }
        return (gross - TAX_FREE_LIMIT) / 10;
    }

    public final int netPay() {
        return grossPay() - tax();
    }

    public final String payslipRow() {
        return String.format(ROW, id, name, type(), grossPay(), tax(), netPay());
    }
}

class HourlyEmployee extends Employee {
    public static final int REGULAR_HOURS = 160;
    private int rate;
    private int hours;

    HourlyEmployee(String id, String name, int rate, int hours) {
        super(id, name, 0);                  // no basic salary
        this.rate = rate;
        this.hours = hours;
    }

    @Override
    public String type() {
        return "Hourly";
    }

    @Override
    public int grossPay() {
        if (hours <= REGULAR_HOURS) {
            return rate * hours;
        }
        int overtime = hours - REGULAR_HOURS;
        return rate * REGULAR_HOURS + overtime * rate * 3 / 2;
    }
}

class CommissionEmployee extends Employee {
    private int sales;
    private int percent;

    CommissionEmployee(String id, String name, int basic, int sales, int percent) {
        super(id, name, basic);
        this.sales = sales;
        this.percent = percent;
    }

    @Override
    public String type() {
        return "Commission";
    }

    @Override
    public int grossPay() {
        return super.grossPay() + sales * percent / 100;
    }
}

public class PayrollWithTax {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        ArrayList<Employee> staff = new ArrayList<Employee>();
        for (int i = 0; i < n; i++) {
            String kind = in.next();
            String id = in.next();
            String name = in.next();
            if (kind.equals("F")) {
                staff.add(new Employee(id, name, in.nextInt()));
            } else if (kind.equals("H")) {
                staff.add(new HourlyEmployee(id, name, in.nextInt(), in.nextInt()));
            } else {
                staff.add(new CommissionEmployee(id, name, in.nextInt(),
                        in.nextInt(), in.nextInt()));
            }
        }

        System.out.println(String.format("%-4s %-8s %-10s %7s %6s %7s",
                "ID", "Name", "Type", "Gross", "Tax", "Net"));
        int totalGross = 0;
        int totalTax = 0;
        int taxpayers = 0;
        Employee best = null;
        for (Employee e : staff) {
            System.out.println(e.payslipRow());
            totalGross += e.grossPay();
            totalTax += e.tax();
            if (e.tax() > 0) {
                taxpayers++;
            }
            if (best == null || e.netPay() > best.netPay()) {
                best = e;
            }
        }
        System.out.println("Total gross: Tk " + totalGross);
        System.out.println("Total tax: Tk " + totalTax);
        System.out.println("Taxpayers: " + taxpayers + " of " + staff.size());
        if (best != null) {
            System.out.println("Highest net: " + best.getName()
                    + " (Tk " + best.netPay() + ")");
        }
    }
}
```

### Explanation
- **What varies, what does not.** Gross pay and the type name differ per kind, so they
  are overridable. Tax, net pay and the row format must be identical for everyone, so
  they are `final`: a subclass cannot quietly give itself a lower tax.
- `tax()` calls `grossPay()`, so for an `HourlyEmployee` it uses the hourly gross. One
  tax rule in the superclass correctly serves all subclasses.
- `CommissionEmployee` reuses the full-time calculation with `super.grossPay()`;
  `HourlyEmployee` passes 0 as basic salary and replaces the calculation.
- Rafi's pay: 160 x 200 = 32000, plus 12 overtime hours x 300 = 3600, gross 35600; tax
  is (35600 - 30000) / 10 = 560.
- One `ArrayList<Employee>` holds all three kinds because each *is an* `Employee`, and
  each `payslipRow()` call uses the object's own overrides.

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Staff {
    public static final int MAX_SHIFTS = 3;
    public static final int SHIFT_PAY = 500;
    private String id;
    private String name;
    private int baseSalary;
    private int shifts;

    Staff(String id, String name, int baseSalary) {
        this.id = id;
        this.name = name;
        this.baseSalary = baseSalary;
    }

    public String getId() {
        return id;
    }

    public String title() {
        return "Staff";
    }

    protected boolean addShift() {
        if (shifts >= MAX_SHIFTS) {
            return false;
        }
        shifts++;
        return true;
    }

    public boolean handle(String event) {
        if (event.equals("SHIFT")) {
            return addShift();
        }
        return false;                        // nobody above Staff to ask
    }

    public int monthlyPay() {
        return baseSalary + SHIFT_PAY * shifts;
    }

    public final String report() {
        return String.format("%-8s %-3s %-8s Tk %6d", title(), id, name, monthlyPay());
    }
}

class Nurse extends Staff {
    public static final int NIGHT_BONUS = 300;
    private int nights;

    Nurse(String id, String name, int baseSalary) {
        super(id, name, baseSalary);
    }

    @Override
    public String title() {
        return "Nurse";
    }

    @Override
    public boolean handle(String event) {
        if (event.equals("NIGHT")) {
            if (!addShift()) {
                return false;
            }
            nights++;
            return true;
        }
        return super.handle(event);
    }

    @Override
    public int monthlyPay() {
        return super.monthlyPay() + NIGHT_BONUS * nights;
    }
}

class Doctor extends Staff {
    public static final int CONSULT_FEE = 200;
    private int consults;

    Doctor(String id, String name, int baseSalary) {
        super(id, name, baseSalary);
    }

    @Override
    public String title() {
        return "Doctor";
    }

    @Override
    public boolean handle(String event) {
        if (event.equals("CONSULT")) {
            consults++;
            return true;
        }
        return super.handle(event);
    }

    @Override
    public int monthlyPay() {
        return super.monthlyPay() + CONSULT_FEE * consults;
```

- Every `handle` override follows the same pattern: "is this my event? If not, ask my
  superclass." A `Surgeon` therefore handles `SURGERY` itself, `CONSULT` through
  `Doctor`, and `SHIFT` through `Staff`, while a `Nurse` never reaches the `CONSULT`
  code because `Doctor` is not one of its superclasses.
- `shifts` is private, but subclasses need to add shifts under the same limit. The
  `protected` method `addShift()` gives them exactly that ability and nothing more, so
  no subclass can bypass the 3-shift rule. Ayesha's fourth shift is rejected for this
  reason.
- `monthlyPay()` is built the same way, each level adding its own earnings to
  `super.monthlyPay()`; `report()` is `final`, so all report lines look the same.
- Adding a new role later (say `Pharmacist`) means writing one subclass; `main` and
  the other classes do not change except for the line that creates it.

## Problem 13: Bank with Three Account Types
**Level:** Advanced

### Problem Statement
Build a small bank with this hierarchy:

```text
            Account
           ^       ^
           |       |
   SavingsAccount  CurrentAccount (final)
           ^
           |
   StudentAccount (final)
```

- `Account`: ID, owner, private `long` balance. `deposit` (amount must be positive),
  `withdraw` and `transferTo(Account target, long amount)` are `final`. `withdraw`
  refuses non-positive amounts and otherwise asks the overridable `protected` method
  `canWithdraw(amount)`. A transfer to the same account is refused; otherwise it is a
  withdrawal from this account followed by a deposit to the target.
- `SavingsAccount`: the balance must stay at least `minBalance()` = 500 after a
  withdrawal. At month end it earns 1% interest (integer division).
- `StudentAccount extends SavingsAccount`: `minBalance()` is 0, but one withdrawal may
  not exceed Tk 2000. It earns interest like a savings account.
- `CurrentAccount`: may go down to -5000 (overdraft). At month end, if the balance is
  negative, a fee of Tk 100 is charged.

| Command | Output |

| `OPEN <SAVINGS\|STUDENT\|CURRENT> <id> <owner> <amount>` | `OPEN <id>: OK` or `OPEN <id>: ID EXISTS` |
| `DEP <id> <amount>` / `WD <id> <amount>` | `<cmd> <id> <amount>: OK, balance Tk <b>` or `REFUSED, balance Tk <b>` |
| `TRANSFER <from> <to> <amount>` | `TRANSFER <from>-><to> <amount>: OK` or `REFUSED` |
| `MONTH` | `MONTH: interest and fees applied` |
| `REPORT` | one line per account in opening order (`%-8s %-3s %-6s Tk %6d`: type, id, owner, balance), then `Total held: Tk <sum>` |

```java
import java.util.ArrayList;
import java.util.Scanner;

class Account {
    private String id;
    private String owner;
    private long balance;

    Account(String id, String owner, long balance) {
        this.id = id;
        this.owner = owner;
        this.balance = balance;
    }

    public String getId() {
        return id;
    }

    public long getBalance() {
        return balance;
    }

    public String type() {
        return "Account";
    }

    protected void changeBalance(long delta) {
        balance += delta;
    }

    protected boolean canWithdraw(long amount) {
        return amount <= balance;
    }

    public void monthEnd() {
        // a plain account has no interest and no fee
    }

    public final boolean deposit(long amount) {
        if (amount <= 0) {
            return false;
        }
        balance += amount;
        return true;
    }

    public final boolean withdraw(long amount) {
        if (amount <= 0 || !canWithdraw(amount)) {
            return false;
        }
        balance -= amount;
        return true;
    }

    public final boolean transferTo(Account target, long amount) {
        if (target == this || !withdraw(amount)) {
            return false;
        }
        target.deposit(amount);
        return true;
    }

    @Override
    public String toString() {
        return String.format("%-8s %-3s %-6s Tk %6d", type(), id, owner, balance);
    }
}

class SavingsAccount extends Account {
    public static final int INTEREST_PERCENT = 1;

    SavingsAccount(String id, String owner, long balance) {
        super(id, owner, balance);
    }

    @Override
    public String type() {
        return "Savings";
    }

    protected long minBalance() {
        return 500;
    }

    @Override
    protected boolean canWithdraw(long amount) {
        return getBalance() - amount >= minBalance();
    }

    @Override
    public void monthEnd() {
        long interest = getBalance() * INTEREST_PERCENT / 100;
        if (interest > 0) {
            changeBalance(interest);
        }
    }
}

final class StudentAccount extends SavingsAccount {
    public static final long MAX_WITHDRAWAL = 2000;

    StudentAccount(String id, String owner, long balance) {
        super(id, owner, balance);
    }

    @Override
    public String type() {
        return "Student";
    }

    @Override
    protected long minBalance() {
        return 0;
    }

    @Override
    protected boolean canWithdraw(long amount) {
        return amount <= MAX_WITHDRAWAL && super.canWithdraw(amount);
    }
}

final class CurrentAccount extends Account {
    public static final long OVERDRAFT = 5000;
    public static final long NEGATIVE_FEE = 100;

    CurrentAccount(String id, String owner, long balance) {
        super(id, owner, balance);
    }

    @Override
    public String type() {
        return "Current";
    }

    @Override
    protected boolean canWithdraw(long amount) {
        return getBalance() - amount >= -OVERDRAFT;
    }

    @Override
    public void monthEnd() {
        if (getBalance() < 0) {
            changeBalance(-NEGATIVE_FEE);
        }
    }
}

class Bank {
    private ArrayList<Account> accounts = new ArrayList<Account>();

    public Account find(String id) {
        for (Account a : accounts) {
            if (a.getId().equals(id)) {
                return a;
            }
        }
        return null;
    }

    public boolean open(String type, String id, String owner, long amount) {
        if (find(id) != null) {
            return false;
        }
        if (type.equals("SAVINGS")) {
            accounts.add(new SavingsAccount(id, owner, amount));
        } else if (type.equals("STUDENT")) {
            accounts.add(new StudentAccount(id, owner, amount));
        } else {
            accounts.add(new CurrentAccount(id, owner, amount));
        }
        return true;
    }

    public void monthEnd() {
        for (Account a : accounts) {
            a.monthEnd();
        }
    }

    public void report() {
        long total = 0;
        for (Account a : accounts) {
            System.out.println(a);
            total += a.getBalance();
        }
        System.out.println("Total held: Tk " + total);
    }
}

public class ThreeAccountBank {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Bank bank = new Bank();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String cmd = in.next();
            if (cmd.equals("OPEN")) {
                String type = in.next();
                String id = in.next();
                String owner = in.next();
                long amount = in.nextLong();
                boolean ok = bank.open(type, id, owner, amount);
                System.out.println("OPEN " + id + ": " + (ok ? "OK" : "ID EXISTS"));
            } else if (cmd.equals("DEP") || cmd.equals("WD")) {
                String id = in.next();
                long amount = in.nextLong();
                Account a = bank.find(id);
                if (a == null) {
                    System.out.println(cmd + ": NO SUCH ACCOUNT");
                    continue;
                }
                boolean ok = cmd.equals("DEP") ? a.deposit(amount) : a.withdraw(amount);
                System.out.println(cmd + " " + id + " " + amount + ": "
                        + (ok ? "OK" : "REFUSED") + ", balance Tk " + a.getBalance());
            } else if (cmd.equals("TRANSFER")) {
                String fromId = in.next();
                String toId = in.next();
                long amount = in.nextLong();
                Account from = bank.find(fromId);
                Account to = bank.find(toId);
                if (from == null || to == null) {
                    System.out.println(cmd + ": NO SUCH ACCOUNT");
                    continue;
                }
                boolean ok = from.transferTo(to, amount);
                System.out.println("TRANSFER " + fromId + "->" + toId + " " + amount
                        + ": " + (ok ? "OK" : "REFUSED"));
            } else if (cmd.equals("MONTH")) {
                bank.monthEnd();
                System.out.println("MONTH: interest and fees applied");
            } else {
                bank.report();
            }
        }
    }
}
```

### Explanation
- **One fixed procedure, one changeable rule.** `withdraw` is `final` and always does
  the same steps; the only thing subclasses may change is the `protected` question
  `canWithdraw(amount)`. Each account type answers it differently, and
  `StudentAccount` adds its per-withdrawal limit on top of the savings rule with
  `super.canWithdraw(amount)`.
- `StudentAccount` overrides only `minBalance()` (0 instead of 500); the inherited
  savings rule uses it automatically. This is why A2 could withdraw down to Tk 0.
- `transferTo` is `final` and is built from `withdraw` and `deposit`, so a transfer
  can never break an account's withdrawal rule.
- The balance is private; subclasses change it only through `changeBalance`, used for
  interest and fees.
- `StudentAccount` and `CurrentAccount` are `final` classes: they are the leaves of the
  hierarchy, and the bank does not want anyone weakening their rules in a subclass.
- `Bank` *has* a list of accounts (composition); it is not itself an account.
- Month end: A1 earns 2020 - 2000 = 20 interest, A2 earns nothing on Tk 0, A3 is
  negative and pays the Tk 100 fee (-3500 becomes -3600).

```java
import java.util.ArrayList;
import java.util.Scanner;

class Course {
    private String code;
    private int credits;
    private int level;
    private int capacity;
    private int enrolled;

    Course(String code, int credits, int level, int capacity) {
        this.code = code;
        this.credits = credits;
        this.level = level;
        this.capacity = capacity;
    }

    public String getCode() {
        return code;
    }

    public int getCredits() {
        return credits;
    }

    public int getLevel() {
        return level;
    }

    public boolean isFull() {
        return enrolled >= capacity;
    }

    public void addSeat() {
        enrolled++;
    }

    public void freeSeat() {
        enrolled--;
    }

    @Override
    public String toString() {
        return code + ": " + enrolled + "/" + capacity;
    }
}

class Person {
    private String id;
    private String name;

    Person(String id, String name) {
        this.id = id;
        this.name = name;
    }

    public String getId() {
        return id;
    }

    public String getName() {
        return name;
    }
}

class Student extends Person {
    private ArrayList<Course> courses = new ArrayList<Course>();
    private int credits;

    Student(String id, String name) {
        super(id, name);
    }

    public String type() {
        return "Regular";
    }

    protected int maxCredits() {
        return 15;
    }

    protected boolean levelAllowed(int level) {
        return level < 500;
    }

    public final String register(Course c) {
        if (courses.contains(c)) {
            return "ALREADY REGISTERED";
        }
        if (!levelAllowed(c.getLevel())) {
            return "LEVEL NOT ALLOWED";
        }
        if (credits + c.getCredits() > maxCredits()) {
            return "CREDIT LIMIT " + maxCredits();
        }
        if (c.isFull()) {
            return "COURSE FULL";
        }
        c.addSeat();
        courses.add(c);
        credits += c.getCredits();
        return "OK";
    }

    public final String drop(Course c) {
        if (!courses.remove(c)) {
            return "NOT REGISTERED";
        }
        c.freeSeat();
        credits -= c.getCredits();
        return "OK";
    }

    @Override
    public String toString() {
        ArrayList<String> codes = new ArrayList<String>();
        for (Course c : courses) {
            codes.add(c.getCode());
        }
        return getId() + " " + getName() + " (" + type() + "): "
                + credits + " credits " + codes;
    }
}

class ProbationStudent extends Student {
    ProbationStudent(String id, String name) {
        super(id, name);
    }

    @Override
    public String type() {
        return "Probation";
    }

    @Override
    protected int maxCredits() {
        return 9;
    }

    @Override
    protected boolean levelAllowed(int level) {
        return level < 300 && super.levelAllowed(level);
    }
}

        super(id, name);
    }

    @Override
    public String type() {
        return "Graduate";
    }

    @Override
    protected int maxCredits() {
        return 12;
    }

    @Override
    protected boolean levelAllowed(int level) {
        return level >= 500;                 // replaces the undergraduate rule
    }
}

public class RegistrationRules {
    static Course findCourse(ArrayList<Course> list, String code) {
        for (Course c : list) {
            if (c.getCode().equals(code)) {
                return c;
            }
        }
        return null;
    }

    static Student findStudent(ArrayList<Student> list, String id) {
        for (Student s : list) {
            if (s.getId().equals(id)) {
                return s;
            }
        }
        return null;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        ArrayList<Course> catalog = new ArrayList<Course>();
        int m = in.nextInt();
        for (int i = 0; i < m; i++) {
            catalog.add(new Course(in.next(), in.nextInt(), in.nextInt(), in.nextInt()));
        }

        ArrayList<Student> students = new ArrayList<Student>();
        int k = in.nextInt();
        for (int i = 0; i < k; i++) {
            String type = in.next();
            String id = in.next();
            String name = in.next();
            if (type.equals("PROBATION")) {
                students.add(new ProbationStudent(id, name));
            } else if (type.equals("GRADUATE")) {
                students.add(new GraduateStudent(id, name));
            } else {
                students.add(new Student(id, name));
            }
        }

        int q = in.nextInt();
        for (int i = 0; i < q; i++) {
            String cmd = in.next();
            String id = in.next();
            String code = in.next();
            Student s = findStudent(students, id);
            Course c = findCourse(catalog, code);
            String result;
            if (s == null || c == null) {
                result = "UNKNOWN";
            } else if (cmd.equals("REG")) {
                result = s.register(c);
            } else {
                result = s.drop(c);
            }
            System.out.println(cmd + " " + id + " " + code + ": " + result);
        }

        for (Student s : students) {
            System.out.println(s);
        }
        for (Course c : catalog) {
            System.out.println(c);
        }
    }
}
```

### Explanation
- `register` is `final`: the order of the checks and the bookkeeping (seat, list,
  credits) are the same for every student and must not be changed by a subclass. The
  parts that legitimately differ, `maxCredits()` and `levelAllowed()`, are small
  `protected` methods that subclasses override.
- `ProbationStudent` *adds* a restriction on top of the normal one with
  `super.levelAllowed(level)`; `GraduateStudent` *replaces* the rule completely. Both
  are valid uses of overriding; choose based on whether the subclass rule is "the
  usual rule plus more" or "a different rule".
- The hierarchy is multilevel (`Person -> Student -> ProbationStudent`) and
  hierarchical (two subclasses of `Student`).
- `courses.contains(c)` and `courses.remove(c)` use the inherited `equals` (same
  object). That is correct here because every course exists exactly once in the
  catalog and all lookups return that same object.
- Rahim reaches 14 credits, so MAT2101 (3 more) breaks the limit of 15; after he drops
  CSE2215 it fits again.

```java
import java.util.Scanner;

class Vehicle {
    private String regNo;
    private int crossings;

    Vehicle(String regNo) {
        this.regNo = regNo;
    }

    public String getRegNo() {
        return regNo;
    }

    public int getCrossings() {
        return crossings;
    }

    public void addCrossing() {
        crossings++;
    }

    public String typeName() {
        return "Vehicle";
    }

    public int toll() {
        return 0;          // every real vehicle type overrides this
    }

    @Override
    public final boolean equals(Object other) {
        if (this == other) {
            return true;
        }
        if (other == null || !(other instanceof Vehicle)) {
            return false;
        }
        Vehicle that = (Vehicle) other;
        return regNo.equals(that.regNo);
    }

    @Override
    public final int hashCode() {
        return regNo.hashCode();
    }

    @Override
    public String toString() {
        return typeName() + " " + regNo;
    }
}

class TollPlaza {
    private ArrayList<Vehicle> seen = new ArrayList<Vehicle>();
    private int collected;

    public String cross(Vehicle v) {
        int index = seen.indexOf(v);              // uses Vehicle.equals
        if (index < 0) {
            seen.add(v);
            v.addCrossing();
            collected += v.toll();
            return "Tk " + v.toll();
        }
        Vehicle recorded = seen.get(index);
        if (!recorded.typeName().equals(v.typeName())) {
            return "REJECTED, " + v.getRegNo() + " is registered as "
                    + recorded.typeName();
        }
        recorded.addCrossing();
        int half = recorded.toll() / 2;
        collected += half;
        return "Tk " + half + " (return)";
    }

    public void printSummary() {
        System.out.println("Vehicles today: " + seen.size());
        for (Vehicle v : seen) {
            System.out.println("  " + v + " x" + v.getCrossings());
        }
        System.out.println("Total collected: Tk " + collected);
    }
}

public class TollPlazaDemo {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        TollPlaza plaza = new TollPlaza();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String type = in.next();
            String regNo = in.next();
            String result;
            if (type.equals("TRUCK")) {
                int axles = in.nextInt();
                if (axles < 2) {
                    result = "REJECTED, invalid axles " + axles;
                } else {
                    result = plaza.cross(new Truck(regNo, axles));
                }
            } else if (type.equals("BIKE")) {
                result = plaza.cross(new Motorbike(regNo));
            } else if (type.equals("EV")) {
                result = plaza.cross(new ElectricCar(regNo));
            } else {
                result = plaza.cross(new Car(regNo));
            }
            System.out.println(type + " " + regNo + ": " + result);
        }
        plaza.printSummary();
    }
}
```

### Explanation
- Every crossing creates a **new** object, so recognising a returning vehicle depends
  entirely on the overridden `equals`: `seen.indexOf(v)` finds the earlier object with
  the same registration number. With the inherited `Object.equals`, no return trip
  would ever be detected.
- `equals` and `hashCode` are `final` in `Vehicle`. Equality is decided once for the
  whole hierarchy; that is why a `Motorbike` and an `ElectricCar` with the same plate
  count as the same vehicle, and the type check in rule 2 catches the mismatch. The
  `instanceof` test (explained fully in Chapter 10) accepts any kind of `Vehicle`,
  unlike `getClass()`, which would treat different subclasses as never equal.
- The return toll is computed from the **recorded** object (`recorded.toll()`), the
  vehicle that crossed first, which is also the object whose crossing count goes up.
- `ElectricCar` builds on `Car` with `super.toll() / 2`, so if the car toll changes,
  the electric discount follows automatically.
- `TollPlaza` *has* a list of vehicles and the money collected; it is not a vehicle, so
  it does not extend anything.
