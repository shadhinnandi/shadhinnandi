# Practice Problems: Object-Oriented I/O

These problems practise reading and writing text files, byte streams, CSV parsing,
append-only logs and serialization, with the file format kept inside well-designed
classes. Files named in **File** blocks under Sample Input exist in the working
directory before the program runs; **File** blocks under Sample Output show files the
program must create. Programs read input without prompts and print exactly the sample output.

## Problem 1: Poem Line Numberer
**Level:** Basic

### Problem Statement
Read the text file `poem.txt` and write a copy called `numbered.txt` in which every
line starts with its line number, right-aligned in 3 columns, followed by ` | ` and the
original line (blank lines are numbered too). Use a `BufferedReader` for reading and a
`PrintWriter` for writing.

The program reads nothing from standard input. When it is done it prints
`Numbered <n> lines`. If a file cannot be opened, print `Cannot open file` instead.

### Sample Input
**File `poem.txt`**
```text
Rain on the tin roof of the hostel,
tea going cold beside my notes,

and the lab report still half written.
```

### Sample Output
```text
Numbered 4 lines
```
**File `numbered.txt`**
```text
  1 | Rain on the tin roof of the hostel,
  2 | tea going cold beside my notes,
  3 |
  4 | and the lab report still half written.
```

### Solution
```java
import java.io.BufferedReader;
import java.io.FileNotFoundException;
import java.io.FileReader;
import java.io.IOException;
import java.io.PrintWriter;

public class LineNumberer {
    public static void main(String[] args) {
        int count = 0;
        try (BufferedReader reader = new BufferedReader(new FileReader("poem.txt"));
             PrintWriter out = new PrintWriter("numbered.txt")) {
            String line = reader.readLine();
            while (line != null) {
                count++;
                out.printf("%3d | %s%n", count, line);
                line = reader.readLine();
            }
        } catch (FileNotFoundException e) {
            System.out.println("Cannot open file");
            return;
        } catch (IOException e) {
            System.out.println("Read error: " + e.getMessage());
            return;
        }
        System.out.println("Numbered " + count + " lines");
    }
}
```

### Explanation
Two resources are opened in one try-with-resources statement: the reader for the
source and the writer for the copy. The loop uses the standard pattern: read a line,
process it while it is not `null`, then read the next one. `printf("%3d | %s%n", ...)`
works on a `PrintWriter` exactly as on `System.out`. The success message is printed
after the try block, when both files are closed and `numbered.txt` is complete. Both
constructors throw `FileNotFoundException` when a file cannot be opened, so one catch
handles a missing poem and an unwritable copy.

## Problem 2: Canteen Menu Writer
**Level:** Basic

### Problem Statement
The canteen manager types the day's menu and wants it saved as a neat text file. Read
an integer `n`, then `n` lines, each `<price> <item name>` (the price is a whole number
of Tk; the name may contain spaces). Write `menu.txt` with a `BufferedWriter` in this
format:

- first line `Today's Menu`, second line 26 dashes;
- one line per item: the name left-aligned in 20 columns, the price right-aligned in
  3 columns, then ` Tk`;
- a last line `Cheapest: <name> (<price> Tk)` (the first one if several are equally
  cheap).

Use `newLine()` for line breaks. Finally print `Wrote <n> items to menu.txt`.

### Sample Input
```text
4
60 Khichuri with egg
10 Singara
15 Milk tea
120 Chicken biryani
```

### Sample Output
```text
Wrote 4 items to menu.txt
```
**File `menu.txt`**
```text
Today's Menu
--------------------------
Khichuri with egg    60 Tk
Singara              10 Tk
Milk tea             15 Tk
Chicken biryani     120 Tk
Cheapest: Singara (10 Tk)
```

### Solution
```java
import java.io.BufferedWriter;
import java.io.FileWriter;
import java.io.IOException;
import java.util.Scanner;

public class MenuWriter {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        String cheapestName = "";
        int cheapestPrice = Integer.MAX_VALUE;
        try (BufferedWriter writer = new BufferedWriter(new FileWriter("menu.txt"))) {
            writer.write("Today's Menu");
            writer.newLine();
            writer.write("--------------------------");
            writer.newLine();
            for (int i = 0; i < n; i++) {
                int price = in.nextInt();
                String name = in.nextLine().trim();
                writer.write(String.format("%-20s%3d Tk", name, price));
                writer.newLine();
                if (price < cheapestPrice) {
                    cheapestPrice = price;
                    cheapestName = name;
                }
            }
            writer.write("Cheapest: " + cheapestName + " (" + cheapestPrice + " Tk)");
            writer.newLine();
        } catch (IOException e) {
            System.out.println("Cannot write menu.txt");
            return;
        }
        System.out.println("Wrote " + n + " items to menu.txt");
    }
}
```

### Explanation
`BufferedWriter.write` writes only the characters you give it, so every line needs an
explicit `newLine()`, which uses the correct separator for the operating system.
`String.format` builds the aligned line first, because `BufferedWriter` has no
`printf`. The price is read with `nextInt()` and the rest of the same line with
`nextLine().trim()`, which also removes the space between price and name. The cheapest
item is tracked while writing, so the data is processed in one pass. Using `<` (not
`<=`) keeps the first of several equally cheap items.

## Problem 3: Backup Copier
**Level:** Basic

### Problem Statement
Before a lab exam, Fahim wants backups of some files. Read an integer `k` and then `k`
file names (one word each). For each name:

- if the file does not exist (check with the `File` class), print
  `<name>: not found, skipped`;
- otherwise copy it byte by byte, using `FileInputStream`/`FileOutputStream` wrapped in
  buffered streams, to `<name>.bak` and print `<name>: <bytes> bytes -> <name>.bak`.

Finally print `Backed up <c> of <k> files`. The copy must be exact for any kind of
file, so use byte streams, not readers and writers.

### Sample Input
```text
3
notes.txt
photo.png
routine.txt
```
**File `notes.txt`**
```text
OOP quiz on Sunday
Bring calculator
```
**File `routine.txt`**
```text
Sun 08:30 CSE 1115
Tue 11:00 MAT 2105
Thu 14:00 EEE 2113
```

### Sample Output
```text
notes.txt: 36 bytes -> notes.txt.bak
photo.png: not found, skipped
routine.txt: 57 bytes -> routine.txt.bak
Backed up 2 of 3 files
```
**File `notes.txt.bak`**
```text
OOP quiz on Sunday
Bring calculator
```
**File `routine.txt.bak`**
```text
Sun 08:30 CSE 1115
Tue 11:00 MAT 2105
Thu 14:00 EEE 2113
```

### Solution
```java
import java.io.BufferedInputStream;
import java.io.BufferedOutputStream;
import java.io.File;
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;
import java.util.Scanner;

public class BackupCopier {
    static long copy(File source, File target) throws IOException {
        long bytes = 0;
        try (BufferedInputStream in =
                 new BufferedInputStream(new FileInputStream(source));
             BufferedOutputStream out =
                 new BufferedOutputStream(new FileOutputStream(target))) {
            int b = in.read();
            while (b != -1) {
                out.write(b);
                bytes++;
                b = in.read();
            }
        }
        return bytes;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int k = in.nextInt();
        int copied = 0;
        for (int i = 0; i < k; i++) {
            String name = in.next();
            File source = new File(name);
            if (!source.exists()) {
                System.out.println(name + ": not found, skipped");
                continue;
            }
            try {
                long bytes = copy(source, new File(name + ".bak"));
                System.out.println(name + ": " + bytes + " bytes -> " + name + ".bak");
                copied++;
            } catch (IOException e) {
                System.out.println(name + ": copy failed");
            }
        }
        System.out.println("Backed up " + copied + " of " + k + " files");
    }
}
```

### Explanation
`File.exists()` lets the program decide *before* opening anything, so a missing file is
a normal case, not an exception. `read()` returns one byte as an `int` from 0 to 255,
or `-1` at the end, which is why `b` is an `int`. Reading one byte at a time would be
very slow on an unbuffered `FileInputStream`, but the `BufferedInputStream` decorator
fetches bytes in large blocks, so each `read()` usually comes from memory. The byte
counts include the line-feed byte at the end of every line (`notes.txt` has 34
visible characters and 2 line feeds).

## Problem 4: Rainfall Statistics
**Level:** Basic

### Problem Statement
A weather club records daily rainfall in millimetres in `rainfall.txt`. The numbers are
separated by spaces and line breaks, and volunteers sometimes typed a word such as `na`
for a missing reading. Read the file with a `Scanner` built from a `File`. Count the
integer readings and ignore every other token. Print:

```text
Readings: <count>
Total: <sum> mm
Average: <average with 2 decimals> mm
Wettest day: <largest reading> mm
Ignored tokens: <number of non-integer tokens>
```

If there are no readings, print `No readings` instead of the first four lines (still
print the ignored count). If the file is missing, print `rainfall.txt not found`. The
program reads nothing from standard input.

### Sample Input
**File `rainfall.txt`**
```text
12 0 34
5 na 18
0 0 41 7
```

### Sample Output
```text
Readings: 9
Total: 117 mm
Average: 13.00 mm
Wettest day: 41 mm
Ignored tokens: 1
```

### Solution
```java
import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class RainfallStats {
    public static void main(String[] args) {
        try (Scanner in = new Scanner(new File("rainfall.txt"))) {
            int count = 0;
            int total = 0;
            int max = 0;
            int ignored = 0;
            while (in.hasNext()) {
                if (in.hasNextInt()) {
                    int value = in.nextInt();
                    count++;
                    total += value;
                    if (count == 1 || value > max) {
                        max = value;
                    }
                } else {
                    in.next();
                    ignored++;
                }
            }
            if (count == 0) {
                System.out.println("No readings");
            } else {
                System.out.println("Readings: " + count);
                System.out.println("Total: " + total + " mm");
                System.out.printf("Average: %.2f mm%n", (double) total / count);
                System.out.println("Wettest day: " + max + " mm");
            }
            System.out.println("Ignored tokens: " + ignored);
        } catch (FileNotFoundException e) {
            System.out.println("rainfall.txt not found");
        }
    }
}
```

### Explanation
A `Scanner` reads a file token by token, without caring about line breaks, which is
exactly what this data needs. `hasNextInt()` looks at the next token without consuming
it. When the token is not an integer, `next()` must still consume it; otherwise
`hasNextInt()` would look at the same `na` forever. `new Scanner(new File(...))` throws
the checked `FileNotFoundException`, and the Scanner is closed by try-with-resources.
The `count == 1` test makes the first reading the starting maximum.

## Problem 5: Visitor Log
**Level:** Basic

### Problem Statement
The department office keeps `visitors.txt`, with lines `Visitor <k>: <name>`. Each run
of the program must **add** new visitors at the end, continuing the numbering, and must
never erase old entries.

First count the lines already in the file (if the file does not exist, the count is 0).
Then read an integer `n` and `n` names (whole lines) from standard input and append them
using `FileWriter` in append mode. Print:

```text
Previous visitors: <old count>
Added: <n>
Total visitors: <old count + n>
```

### Sample Input
```text
3
Farhana Akter
Rafi Ahmed
Mitu Das
```
**File `visitors.txt`**
```text
Visitor 1: Nusrat Jahan
Visitor 2: Imran Hossain
```

### Sample Output
```text
Previous visitors: 2
Added: 3
Total visitors: 5
```
**File `visitors.txt`**
```text
Visitor 1: Nusrat Jahan
Visitor 2: Imran Hossain
Visitor 3: Farhana Akter
Visitor 4: Rafi Ahmed
Visitor 5: Mitu Das
```

### Solution
```java
import java.io.BufferedReader;
import java.io.File;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.Scanner;

public class VisitorLog {
    static int countLines(String fileName) throws IOException {
        if (!new File(fileName).exists()) {
            return 0;
        }
        int lines = 0;
        try (BufferedReader reader = new BufferedReader(new FileReader(fileName))) {
            while (reader.readLine() != null) {
                lines++;
            }
        }
        return lines;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        in.nextLine();
        try {
            int previous = countLines("visitors.txt");
            try (PrintWriter out = new PrintWriter(new FileWriter("visitors.txt", true))) {
                for (int i = 1; i <= n; i++) {
                    out.println("Visitor " + (previous + i) + ": " + in.nextLine());
                }
            }
            System.out.println("Previous visitors: " + previous);
            System.out.println("Added: " + n);
            System.out.println("Total visitors: " + (previous + n));
        } catch (IOException e) {
            System.out.println("Log error: " + e.getMessage());
        }
    }
}
```

### Explanation
The second argument `true` of `new FileWriter("visitors.txt", true)` opens the file in
append mode: writing starts after the existing content, and the file is created if it
is missing. The program reads the file first only to learn how many visitors there
were, then closes it and reopens it for appending. `readLine()` is called once per loop
step, inside the condition, so no line is skipped. After `nextInt()`, the extra
`nextLine()` consumes the rest of the first input line, so the names are read
correctly.

## Problem 6: Merge Two Section Lists
**Level:** Intermediate

### Problem Statement
Two sections of a course have their class lists in `section1.txt` and `section2.txt`.
Each line is `<id> <name>`, and each file is already sorted by ID (ascending). A student
who changed section may appear in both files. Produce `all.txt`, the combined list
sorted by ID, with every student exactly once.

Merge the files **line by line**, without loading either file into a list: keep the
current line of each file, write the one with the smaller ID and advance only that file.
When both current lines have the same ID, write it once, print
`Duplicate: <line>` and advance both. Finally print `Merged <m> students into all.txt`.
The program reads nothing from standard input.

### Sample Input
**File `section1.txt`**
```text
1003 Ayesha Siddiqua
1007 Tanvir Hasan
1010 Rafi Ahmed
1015 Mitu Das
```
**File `section2.txt`**
```text
1001 Karim Uddin
1007 Tanvir Hasan
1008 Sadia Islam
1020 Arif Khan
1021 Farhana Akter
```

### Sample Output
```text
Duplicate: 1007 Tanvir Hasan
Merged 8 students into all.txt
```
**File `all.txt`**
```text
1001 Karim Uddin
1003 Ayesha Siddiqua
1007 Tanvir Hasan
1008 Sadia Islam
1010 Rafi Ahmed
1015 Mitu Das
1020 Arif Khan
1021 Farhana Akter
```

### Solution
```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;

public class SectionMerge {
    private final BufferedWriter writer;
    private int written;

    SectionMerge(BufferedWriter writer) {
        this.writer = writer;
    }

    static int idOf(String line) {
        return Integer.parseInt(line.substring(0, line.indexOf(' ')));
    }

    void write(String line) throws IOException {
        writer.write(line);
        writer.newLine();
        written++;
    }

    void merge(BufferedReader first, BufferedReader second) throws IOException {
        String a = first.readLine();
        String b = second.readLine();
        while (a != null && b != null) {
            int idA = idOf(a);
            int idB = idOf(b);
            if (idA < idB) {
                write(a);
                a = first.readLine();
            } else if (idB < idA) {
                write(b);
                b = second.readLine();
            } else {
                write(a);
                System.out.println("Duplicate: " + a);
                a = first.readLine();
                b = second.readLine();
            }
        }
        while (a != null) {
            write(a);
            a = first.readLine();
        }
        while (b != null) {
            write(b);
            b = second.readLine();
        }
    }

    public static void main(String[] args) {
        try (BufferedReader first = new BufferedReader(new FileReader("section1.txt"));
             BufferedReader second = new BufferedReader(new FileReader("section2.txt"));
             BufferedWriter out = new BufferedWriter(new FileWriter("all.txt"))) {
            SectionMerge merger = new SectionMerge(out);
            merger.merge(first, second);
            System.out.println("Merged " + merger.written + " students into all.txt");
        } catch (IOException e) {
            System.out.println("Merge failed: " + e.getMessage());
        }
    }
}
```

### Explanation
This is the merge step of merge sort, applied to files. At any moment the program holds
only two lines in memory, so it would work just as well for files with millions of
lines. After the main loop one file may still have lines left; since that file is
sorted and everything in it is larger than what was written, the two "drain" loops copy
the rest unchanged. The `SectionMerge` object keeps the writer and the counter together,
so the helper `write` updates both in one place. `idOf` takes the text before the first
space, which is the ID.

## Problem 7: Word Frequency Report
**Level:** Intermediate

### Problem Statement
Read `article.txt`, split it into words (a word is a run of letters; compare words in
lower case) and count how often each word occurs. Read an integer `N` from standard
input and write the `N` most frequent words to `frequency.txt`, one per line as
`<rank>. <word> <count>`. Order by count (highest first); words with equal counts are
ordered alphabetically. If there are fewer than `N` distinct words, write them all.

Design: a class `WordCount` (a word and its count, with a method
`boolean comesBefore(WordCount other)` that encodes the ordering) and a class
`FrequencyTable` that stores `WordCount` objects in an `ArrayList`, adds words, sorts
itself with insertion sort and writes the top entries to a `PrintWriter`.

Print `Total words: <t>` and `Distinct words: <d>` to standard output.

### Sample Input
```text
5
```
**File `article.txt`**
```text
The library opens at eight. The canteen opens at nine.
Students who reach the library early get a seat near the window,
and students who reach the canteen early get hot singara!
```

### Sample Output
```text
Total words: 32
Distinct words: 19
```
**File `frequency.txt`**
```text
1. the 5
2. at 2
3. canteen 2
4. early 2
5. get 2
```

### Solution
```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.ArrayList;
import java.util.Scanner;

class WordCount {
    private final String word;
    private int count = 1;

    WordCount(String word) {
        this.word = word;
    }

    String getWord() {
        return word;
    }

    int getCount() {
        return count;
    }

    void increment() {
        count++;
    }

    boolean comesBefore(WordCount other) {
        if (count != other.count) {
            return count > other.count;
        }
        return word.compareTo(other.word) < 0;
    }
}

class FrequencyTable {
    private final ArrayList<WordCount> entries = new ArrayList<WordCount>();
    private int totalWords;

    void add(String word) {
        totalWords++;
        for (WordCount entry : entries) {
            if (entry.getWord().equals(word)) {
                entry.increment();
                return;
            }
        }
        entries.add(new WordCount(word));
    }

    void sort() {
        for (int i = 1; i < entries.size(); i++) {
            WordCount current = entries.get(i);
            int j = i - 1;
            while (j >= 0 && current.comesBefore(entries.get(j))) {
                entries.set(j + 1, entries.get(j));
                j--;
            }
            entries.set(j + 1, current);
        }
    }

    void writeTop(PrintWriter out, int n) {
        for (int i = 0; i < n && i < entries.size(); i++) {
            WordCount entry = entries.get(i);
            out.println((i + 1) + ". " + entry.getWord() + " " + entry.getCount());
        }
    }

    int getTotalWords() {
        return totalWords;
    }

    int getDistinctWords() {
        return entries.size();
    }
}

public class WordFrequency {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int top = in.nextInt();
        FrequencyTable table = new FrequencyTable();
        try (BufferedReader reader = new BufferedReader(new FileReader("article.txt"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                String[] words = line.toLowerCase().split("[^a-z]+");
                for (String word : words) {
                    if (!word.isEmpty()) {
                        table.add(word);
                    }
                }
            }
        } catch (IOException e) {
            System.out.println("Cannot read article.txt");
            return;
        }
        table.sort();
        try (PrintWriter out = new PrintWriter("frequency.txt")) {
            table.writeTop(out, top);
        } catch (IOException e) {
            System.out.println("Cannot write frequency.txt");
            return;
        }
        System.out.println("Total words: " + table.getTotalWords());
        System.out.println("Distinct words: " + table.getDistinctWords());
    }
}
```

### Explanation
The regular expression `[^a-z]+` means "one or more characters that are not lower-case
letters", so splitting the lower-cased line at it removes spaces and punctuation in one
step. A line that starts with punctuation would produce an empty first piece, which is
why empty strings are skipped. The ordering rule lives in `WordCount.comesBefore`, so
the sorting code does not need to know what "more frequent" means, and changing the
rule touches one method. `FrequencyTable` hides the list completely: `main` only adds
words, sorts and asks for the report.

## Problem 8: Server Log Filter
**Level:** Intermediate

### Problem Statement
The university portal writes `server.log`, where each line is
`<time> <LEVEL> <message>` and `LEVEL` is `INFO`, `WARN` or `ERROR` (in increasing
severity). Read a minimum level from standard input and copy every line whose level is
at least that severe to `filtered.log`, unchanged. A line with fewer than three parts
or an unknown level is malformed: do not copy it.

Use an `enum Level { INFO, WARN, ERROR }` and compare severities with `ordinal()`.
Print the number of lines of each level, the number of malformed lines and a final line
`Kept <k> lines at <LEVEL> or above`. If the level typed by the user is unknown, print
`Unknown level: <text>` and stop.

### Sample Input
```text
WARN
```
**File `server.log`**
```text
09:00 INFO Server started
09:05 INFO User 1001 logged in
09:12 WARN Slow response from results service
09:13 ERROR Database connection lost
09:13 DEBUG Retrying connection
09:14 INFO Database connection restored
09:30
09:41 ERROR Payment callback timed out
09:45 WARN Disk 85% full
```

### Sample Output
```text
INFO: 3
WARN: 2
ERROR: 2
Malformed: 2
Kept 4 lines at WARN or above
```
**File `filtered.log`**
```text
09:12 WARN Slow response from results service
09:13 ERROR Database connection lost
09:41 ERROR Payment callback timed out
09:45 WARN Disk 85% full
```

### Solution
```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.Scanner;

enum Level {
    INFO, WARN, ERROR
}

class LogFilter {
    private final Level minimum;
    private final int[] perLevel = new int[Level.values().length];
    private int malformed;
    private int kept;

    LogFilter(Level minimum) {
        this.minimum = minimum;
    }

    /** Returns the level of a well-formed line, or null for a malformed one. */
    static Level parseLevel(String line) {
        String[] parts = line.split(" ", 3);
        if (parts.length < 3) {
            return null;
        }
        for (Level level : Level.values()) {
            if (level.name().equals(parts[1])) {
                return level;
            }
        }
        return null;
    }

    void process(BufferedReader reader, PrintWriter out) throws IOException {
        String line;
        while ((line = reader.readLine()) != null) {
            Level level = parseLevel(line);
            if (level == null) {
                malformed++;
                continue;
            }
            perLevel[level.ordinal()]++;
            if (level.ordinal() >= minimum.ordinal()) {
                out.println(line);
                kept++;
            }
        }
    }

    void printSummary() {
        for (Level level : Level.values()) {
            System.out.println(level + ": " + perLevel[level.ordinal()]);
        }
        System.out.println("Malformed: " + malformed);
        System.out.println("Kept " + kept + " lines at " + minimum + " or above");
    }
}

public class LogFilterApp {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String typed = in.next();
        Level minimum = LogFilter.parseLevel("00:00 " + typed + " x");
        if (minimum == null) {
            System.out.println("Unknown level: " + typed);
            return;
        }
        LogFilter filter = new LogFilter(minimum);
        try (BufferedReader reader = new BufferedReader(new FileReader("server.log"));
             PrintWriter out = new PrintWriter("filtered.log")) {
            filter.process(reader, out);
        } catch (IOException e) {
            System.out.println("Log error: " + e.getMessage());
            return;
        }
        filter.printSummary();
    }
}
```

### Explanation
`split(" ", 3)` splits into at most three parts, so the whole message (which contains
spaces) stays in the third part. The enum gives the levels a fixed order, and
`ordinal()` (0, 1, 2) turns "at least as severe" into a simple `>=`. Searching
`Level.values()` instead of calling `Level.valueOf` avoids an exception for unknown
words like `DEBUG`, which are normal in real logs. `LogFilter.process` accepts any
`BufferedReader` and `PrintWriter`, so the class does not depend on the file names;
the counters live in the object, and the array `perLevel` is indexed by ordinal. The
user's level is checked by reusing `parseLevel` on a small made-up line, so the rule for
valid level names exists only once.

## Problem 9: CSV Sales Summary
**Level:** Intermediate

### Problem Statement
The campus stationery shop exports `sales.csv` with the header
`product,quantity,unit_price` and one sale per line. Products can appear many times.
Produce `summary.csv` with the header `product,quantity,revenue`, one line per product
(in order of first appearance) with the total quantity and total revenue (2 decimals),
and a final line `TOTAL,<all quantities>,<all revenue>`.

A line is invalid when it does not have exactly 3 fields, when the quantity or price is
not a number, when the quantity is not positive or when the price is negative. For each
invalid line print `Line <n>: <reason>` (the header is line 1) and skip it, using the
reasons `expected 3 fields`, `not a number`, `quantity must be positive` and
`price cannot be negative`. Finally print `Valid sales: <v>, skipped: <s>`.

Design: a custom checked exception `InvalidSaleException`, a class `ProductTotal`, and a
class `SalesSummary` with `record(String csvLine)` and `writeCsv(PrintWriter out)`.

### Sample Input
**File `sales.csv`**
```text

Pen,10,12.00
Notebook,2,45.50
Calculator,1,850.00
Pen,five,12.00
Highlighter,4

```

### Sample Output

```text
Line 7: expected 3 fields
Line 9: quantity must be positive
Line 10: price cannot be negative
Valid sales: 5, skipped: 4
```
**File `summary.csv`**
```text
product,quantity,revenue
Notebook,5,227.50
Pen,15,180.00
Calculator,1,850.00
TOTAL,21,1257.50
```

### Solution
```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.ArrayList;

class InvalidSaleException extends Exception {
    InvalidSaleException(String message) {
        super(message);
    }
}

class ProductTotal {
    private final String name;
    private int quantity;
    private double revenue;

    ProductTotal(String name) {
        this.name = name;
    }

    String getName() {
        return name;
    }

    int getQuantity() {
        return quantity;
    }

    double getRevenue() {
        return revenue;
    }

    void add(int qty, double unitPrice) {
        quantity += qty;
        revenue += qty * unitPrice;
    }
}

class SalesSummary {
    private final ArrayList<ProductTotal> products = new ArrayList<ProductTotal>();

    void record(String csvLine) throws InvalidSaleException {
        String[] parts = csvLine.split(",");
        if (parts.length != 3) {
            throw new InvalidSaleException("expected 3 fields");
        }
        int qty;
        double price;
        try {
            qty = Integer.parseInt(parts[1].trim());
            price = Double.parseDouble(parts[2].trim());
        } catch (NumberFormatException e) {
            throw new InvalidSaleException("not a number");
        }
        if (qty <= 0) {
            throw new InvalidSaleException("quantity must be positive");
        }
        if (price < 0) {
            throw new InvalidSaleException("price cannot be negative");
        }
        find(parts[0].trim()).add(qty, price);
    }

    private ProductTotal find(String name) {
        for (ProductTotal p : products) {
            if (p.getName().equals(name)) {
                return p;
            }
        }
        ProductTotal created = new ProductTotal(name);
        products.add(created);
        return created;
    }

    void writeCsv(PrintWriter out) {
        out.println("product,quantity,revenue");
        int totalQty = 0;
        double totalRevenue = 0;
        for (ProductTotal p : products) {
            out.printf("%s,%d,%.2f%n", p.getName(), p.getQuantity(), p.getRevenue());
            totalQty += p.getQuantity();
            totalRevenue += p.getRevenue();
        }
        out.printf("TOTAL,%d,%.2f%n", totalQty, totalRevenue);
    }
}

public class SalesReport {
    public static void main(String[] args) {
        SalesSummary summary = new SalesSummary();
        int valid = 0;
        int skipped = 0;
        try (BufferedReader reader = new BufferedReader(new FileReader("sales.csv"))) {
            String line = reader.readLine();
            int lineNumber = 1;
            while ((line = reader.readLine()) != null) {
                lineNumber++;
                try {
                    summary.record(line);
                    valid++;
                } catch (InvalidSaleException e) {
                    System.out.println("Line " + lineNumber + ": " + e.getMessage());
                    skipped++;
                }
            }
        } catch (IOException e) {
            System.out.println("Cannot read sales.csv");
            return;
        }
        try (PrintWriter out = new PrintWriter("summary.csv")) {
            summary.writeCsv(out);
        } catch (IOException e) {
            System.out.println("Cannot write summary.csv");
            return;
        }
        System.out.println("Valid sales: " + valid + ", skipped: " + skipped);
    }
}
```

### Explanation
All CSV rules live in `SalesSummary.record`: it splits the line, converts the fields,
validates them and either updates a product total or throws `InvalidSaleException`
with the reason. The low-level `NumberFormatException` is translated into the
domain-level message `not a number`. `main` only reads lines, counts results and
prints messages, so one bad line never stops the report. `find` returns the existing
`ProductTotal` or creates one, which keeps products in order of first appearance. The
output is again a CSV file, so a spreadsheet can open it directly.

## Problem 10: Contact Book Saved as Text
**Level:** Intermediate

### Problem Statement
Write a contact book that remembers its contacts between runs in `contacts.txt`. Each

### Solution
```java
import java.io.BufferedReader;
import java.io.File;
import java.io.FileReader;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.ArrayList;
import java.util.Scanner;

class Contact {
    private final String name;
    private final String phone;

    Contact(String name, String phone) {
        this.name = name;
        this.phone = phone;
    }

    String getName() {
        return name;
    }

    String toLine() {
        return name + "|" + phone;
    }

    /** Returns null when the line is not in the form name|phone. */
    static Contact fromLine(String line) {
        String[] parts = line.split("\\|");
        if (parts.length != 2) {
            return null;
        }
        return new Contact(parts[0].trim(), parts[1].trim());
    }

    @Override
    public String toString() {
        return name + " (" + phone + ")";
    }
}

class ContactBook {
    private final ArrayList<Contact> contacts = new ArrayList<Contact>();

    private int indexOf(String name) {
        for (int i = 0; i < contacts.size(); i++) {
            if (contacts.get(i).getName().equals(name)) {
                return i;
            }
        }
        return -1;
    }

    boolean add(Contact c) {
        if (indexOf(c.getName()) >= 0) {
            return false;
        }
        contacts.add(c);
        return true;
    }

    boolean remove(String name) {
        int index = indexOf(name);
        if (index < 0) {
            return false;
        }
        contacts.remove(index);
        return true;
    }

    void load(String fileName) throws IOException {
        if (!new File(fileName).exists()) {
            return;
        }
        try (BufferedReader reader = new BufferedReader(new FileReader(fileName))) {
            String line;
            while ((line = reader.readLine()) != null) {
                Contact c = Contact.fromLine(line);
                if (c != null) {
                    add(c);
                }
            }
        }
    }

    void save(String fileName) throws IOException {
        try (PrintWriter out = new PrintWriter(fileName)) {
            for (Contact c : contacts) {
                out.println(c.toLine());
            }
        }
    }

    void print() {
        System.out.println("Reloaded " + contacts.size() + " contacts");
        for (Contact c : contacts) {
            System.out.println(c);
        }
    }
}

public class ContactBookApp {
    public static void main(String[] args) {
        String fileName = "contacts.txt";
        ContactBook book = new ContactBook();
        Scanner in = new Scanner(System.in);
        try {
            book.load(fileName);
            while (in.hasNextLine()) {
                String line = in.nextLine().trim();
                if (line.startsWith("ADD ")) {
                    Contact c = Contact.fromLine(line.substring(4));
                    if (c == null) {
                        System.out.println("Bad contact: " + line.substring(4));
                    } else if (book.add(c)) {
                        System.out.println("Added: " + c.getName());
                    } else {
                        System.out.println("Already exists: " + c.getName());
                    }
                } else if (line.startsWith("REMOVE ")) {
                    String name = line.substring(7).trim();
                    if (book.remove(name)) {
                        System.out.println("Removed: " + name);
                    } else {
                        System.out.println("Not found: " + name);
                    }
                }
            }
            book.save(fileName);
            ContactBook reloaded = new ContactBook();
            reloaded.load(fileName);
            reloaded.print();
        } catch (IOException e) {
            System.out.println("File error: " + e.getMessage());
        }
    }
}
```

### Explanation
The file format is known in exactly two methods: `Contact.toLine` writes a contact and
`Contact.fromLine` reads one, so they can never disagree. `split` takes a regular
expression, and `|` means "or" in regular expressions, so it must be escaped as `"\\|"`;
`split("|")` would split between every character. `ContactBook` owns the list and the
file operations, and `main` only interprets commands. Loading into a *new* object at the
end shows that everything needed was really in the file, not just in memory. `save`
rewrites the whole file because removals cannot be expressed by appending.

## Problem 11: Submission Comparator with Checksums
**Level:** Advanced

### Problem Statement
A lab instructor wants to check whether two submitted files are identical and, if not,
where they first differ. Read two file names from standard input.

1. For each file print `<name>: <size> bytes, checksum <hex>`, where the checksum is
   computed over all bytes with the **Adler-32** algorithm: start with `a = 1` and
   `b = 0`; for each byte value `v` (0 to 255) set `a = (a + v) % 65521` and
   `b = (b + a) % 65521`; the checksum is `b * 65536 + a`, printed as 8 lower-case hex
   digits (`%08x`).
2. Compare the files byte by byte and print one result line:
   - `Files are identical`, or
   - `First difference at byte <offset> (line <l>, column <c>): <x> vs <y>`, where the
     offset counts from 0, lines and columns count from 1, and `<x>`/`<y>` show each
     byte as `'<char>'` for printable characters (32 to 126), `\n` for a line feed and
     `byte <value>` otherwise, or
   - `<name> ends at byte <offset>, the other file continues` if one file is a prefix of
     the other.

If a file cannot be read, print `Cannot read <name>` and stop. Design: a class
`FileFingerprint` (name, size, checksum, built by a static `of(String name)` method)
and a class `ByteComparator`.

### Sample Input
```text
rahim.txt nusrat.txt
```
**File `rahim.txt`**
```text
int total = 0;
for (int i = 1; i <= n; i++) {
    total += i;
}
```
**File `nusrat.txt`**
```text
int total = 0;
for (int i = 1; i < n; i++) {
    total += i;
}
```

### Sample Output
```text
rahim.txt: 64 bytes, checksum 4b2c10e7
nusrat.txt: 63 bytes, checksum 3a5310aa
First difference at byte 34 (line 2, column 20): '=' vs ' '
```

### Solution
```java
import java.io.BufferedInputStream;
import java.io.FileInputStream;
import java.io.IOException;
import java.util.Scanner;

class FileFingerprint {
    private static final int MOD = 65521;

    private final String name;
    private final long size;
    private final long checksum;

    private FileFingerprint(String name, long size, long checksum) {
        this.name = name;
        this.size = size;
        this.checksum = checksum;
    }

    static FileFingerprint of(String name) throws IOException {
        long size = 0;
        long a = 1;
        long b = 0;
        try (BufferedInputStream in = new BufferedInputStream(new FileInputStream(name))) {
            int value = in.read();
            while (value != -1) {
                size++;
                a = (a + value) % MOD;
                b = (b + a) % MOD;
                value = in.read();
            }
        }
        return new FileFingerprint(name, size, b * 65536 + a);
    }

    String describe() {
        return String.format("%s: %d bytes, checksum %08x", name, size, checksum);
    }
}

class ByteComparator {
    static String show(int value) {
        if (value == '\n') {
            return "\\n";
        }
        if (value >= 32 && value <= 126) {
            return "'" + (char) value + "'";
        }
        return "byte " + value;
    }

    static String compare(String first, String second) throws IOException {
        try (BufferedInputStream a = new BufferedInputStream(new FileInputStream(first));
             BufferedInputStream b = new BufferedInputStream(new FileInputStream(second))) {
            long offset = 0;
            int line = 1;
            int column = 1;
            while (true) {
                int x = a.read();
                int y = b.read();
                if (x == -1 && y == -1) {
                    return "Files are identical";
                }
                if (x == -1) {
                    return first + " ends at byte " + offset + ", the other file continues";
                }
                if (y == -1) {
                    return second + " ends at byte " + offset + ", the other file continues";
                }
                if (x != y) {
                    return "First difference at byte " + offset + " (line " + line
                            + ", column " + column + "): " + show(x) + " vs " + show(y);
                }
                offset++;
                if (x == '\n') {
                    line++;
                    column = 1;
                } else {
                    column++;
                }
            }
        }
    }
}

public class SubmissionComparator {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String first = in.next();
        String second = in.next();
        String current = first;
        try {
            FileFingerprint f1 = FileFingerprint.of(first);
            current = second;
            FileFingerprint f2 = FileFingerprint.of(second);
            System.out.println(f1.describe());
            System.out.println(f2.describe());
            System.out.println(ByteComparator.compare(first, second));
        } catch (IOException e) {
            System.out.println("Cannot read " + current);
        }
    }
}
```

### Explanation
Both tasks need raw bytes, not characters, so the program uses byte streams decorated
with `BufferedInputStream`. A checksum summarises a whole file in one number: if two
checksums differ, the files certainly differ; if they are equal, the files are very
probably identical (Adler-32 is fast but not secure, so it detects accidents, not
cheating). Java has a ready-made `java.util.zip.Adler32` class; writing it yourself
shows that a checksum is just arithmetic over the byte stream. The comparator reads
both streams in step and tracks the line and column while the bytes are equal, which
turns a byte offset into a position a person can find in an editor. The variable
`current` remembers which file was being read, so the error message names the right
one.

## Problem 12: Inventory Saved with Serialization
**Level:** Advanced

### Problem Statement
A grocery shop stores its stock with serialization. Read `n` and then `n` lines
`<name> <quantity> <unit price>` (name is one word, numbers are integers in Tk).

`Product` is `Serializable` (declare `serialVersionUID`) with `name`, `quantity`,
`unitPrice`, and a **transient** cached field `stockValue` (`quantity * unitPrice`),
computed in the constructor by `refreshCache()`. An `InventoryFile` class must:

- `save(ArrayList<Product> products)`: write the number of products with `writeInt`,
  then each product with `writeObject`, to `inventory.dat`;
- `load()`: read the count, then that many products (cast each to `Product`), and
  return a new `ArrayList<Product>`.

The program saves the products, prints `Saved <n> products`, loads them into a new list,
prints `Loaded <n> products`, then prints `Cached value before refresh: <value>` for the
first product (to show what happened to the transient field), calls `refreshCache()` on
every loaded product and prints a table and the total:

```text
<name left-aligned in 15> <quantity right-aligned in 4> x <price right-aligned in 4> = <value right-aligned in 6>
Total stock value: <sum> Tk
```

### Sample Input
```text
4
Rice-5kg 12 450
Lentils-1kg 30 140
Soybean-Oil-1L 8 190
Sugar-1kg 25 125
```

### Sample Output
```text
Saved 4 products
Loaded 4 products
Cached value before refresh: 0
Rice-5kg          12 x  450 =   5400
Lentils-1kg       30 x  140 =   4200
Soybean-Oil-1L     8 x  190 =   1520
Sugar-1kg         25 x  125 =   3125
Total stock value: 14245 Tk
```

### Solution
```java
import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.io.Serializable;
import java.util.ArrayList;
import java.util.Scanner;

class Product implements Serializable {
    private static final long serialVersionUID = 1L;

    private final String name;
    private final int quantity;
    private final int unitPrice;
    private transient int stockValue;

    Product(String name, int quantity, int unitPrice) {
        this.name = name;
        this.quantity = quantity;
        this.unitPrice = unitPrice;
        refreshCache();
    }

    void refreshCache() {
        stockValue = quantity * unitPrice;
    }

    int getStockValue() {
        return stockValue;
    }

    String toRow() {
        return String.format("%-15s %4d x %4d = %6d", name, quantity, unitPrice, stockValue);
    }
}

class InventoryFile {
    private final String fileName;

    InventoryFile(String fileName) {
        this.fileName = fileName;
    }

    void save(ArrayList<Product> products) throws IOException {
        try (ObjectOutputStream out =
                 new ObjectOutputStream(new FileOutputStream(fileName))) {
            out.writeInt(products.size());
            for (Product p : products) {
                out.writeObject(p);
            }
        }
    }

    ArrayList<Product> load() throws IOException, ClassNotFoundException {
        ArrayList<Product> products = new ArrayList<Product>();
        try (ObjectInputStream in =
                 new ObjectInputStream(new FileInputStream(fileName))) {
            int count = in.readInt();
            for (int i = 0; i < count; i++) {
                products.add((Product) in.readObject());
            }
        }
        return products;
    }
}

public class InventoryStore {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        ArrayList<Product> products = new ArrayList<Product>();
        for (int i = 0; i < n; i++) {
            products.add(new Product(in.next(), in.nextInt(), in.nextInt()));
        }

        InventoryFile file = new InventoryFile("inventory.dat");
        try {
            file.save(products);
            System.out.println("Saved " + products.size() + " products");
            ArrayList<Product> loaded = file.load();
            System.out.println("Loaded " + loaded.size() + " products");
            if (loaded.isEmpty()) {
                return;
            }
            System.out.println("Cached value before refresh: "
                    + loaded.get(0).getStockValue());
            int total = 0;
            for (Product p : loaded) {
                p.refreshCache();
                System.out.println(p.toRow());
                total += p.getStockValue();
            }
            System.out.println("Total stock value: " + total + " Tk");
        } catch (IOException | ClassNotFoundException e) {
            System.out.println("Inventory file error: " + e.getMessage());
        }
    }
}
```

### Explanation
Writing the count first and then the objects one by one lets `load` cast each object to
`Product`, a normal checked downcast, instead of casting to `ArrayList<Product>`, which
would cause an unchecked warning. `stockValue` is `transient` because it can always be
recomputed. After loading it is `0`, not 5400: deserialization does **not** run the
constructor, so `refreshCache()` was never called for the new objects. That is why the
program refreshes every loaded product; forgetting this step is a classic bug with
transient caches. `InventoryFile` is the only class that knows about object streams, so
switching to a text format later would change one class.

```java
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.ArrayList;

class TransactionException extends Exception {
    TransactionException(String message) {
        super(message);
    }
}

class Account {
    private final int id;
    private final String name;
    private long balance;

    Account(int id, String name, long balance) {
        this.id = id;
        this.name = name;
        this.balance = balance;
    }

    int getId() {
        return id;
    }

    long getBalance() {
        return balance;
    }

    void deposit(long amount) {
        balance += amount;
    }

    void withdraw(long amount) throws TransactionException {
        if (amount > balance) {
            throw new TransactionException("insufficient funds in " + id);
        }
        balance -= amount;
    }

    String toCsvLine() {
        return id + "," + name + "," + balance;
    }
}

class Bank {
    private final ArrayList<Account> accounts = new ArrayList<Account>();

    void add(Account account) {
        accounts.add(account);
    }

    ArrayList<Account> getAccounts() {
        return accounts;
    }

    Account find(String idText) throws TransactionException {
        for (Account a : accounts) {
            if (String.valueOf(a.getId()).equals(idText.trim())) {
                return a;
            }
        }
        throw new TransactionException("unknown account " + idText.trim());
    }

    /** Applies one transaction or throws without changing anything. */
    void apply(String[] f) throws TransactionException {
        if (f.length != 5) {
            throw new TransactionException("expected 5 fields");
        }
        long amount;
        try {
            amount = Long.parseLong(f[4].trim());
        } catch (NumberFormatException e) {
            throw new TransactionException("bad amount");
        }
        if (amount <= 0) {
            throw new TransactionException("amount must be positive");
        }
        String type = f[1].trim();
        if (type.equals("DEPOSIT")) {
            find(f[2]).deposit(amount);
        } else if (type.equals("WITHDRAW")) {
            find(f[2]).withdraw(amount);
        } else if (type.equals("TRANSFER")) {
            Account from = find(f[2]);
            Account to = find(f[3]);
            from.withdraw(amount);
            to.deposit(amount);
        } else {
            throw new TransactionException("unknown type " + type);
        }
    }

    long totalMoney() {
        long sum = 0;
        for (Account a : accounts) {
            sum += a.getBalance();
        }
        return sum;
    }
}

class BankFiles {
    static Bank loadAccounts(String fileName) throws IOException {
        Bank bank = new Bank();
        try (BufferedReader reader = new BufferedReader(new FileReader(fileName))) {
            String line = reader.readLine();
            while ((line = reader.readLine()) != null) {
                String[] f = line.split(",");
                bank.add(new Account(Integer.parseInt(f[0].trim()), f[1].trim(),
                        Long.parseLong(f[2].trim())));
            }
        }
        return bank;
    }

    static void writeBalances(Bank bank, String fileName) throws IOException {
        try (PrintWriter out = new PrintWriter(fileName)) {
            out.println("id,name,balance");
            for (Account a : bank.getAccounts()) {
                out.println(a.toCsvLine());
            }
        }
    }
}

public class BankBatch {
    public static void main(String[] args) {
        int applied = 0;
        int rejected = 0;
        try {
            Bank bank = BankFiles.loadAccounts("accounts.csv");
            try (BufferedReader reader =
                     new BufferedReader(new FileReader("transactions.csv"));
                 PrintWriter errors = new PrintWriter("errors.log")) {
                String line = reader.readLine();
                while ((line = reader.readLine()) != null) {
                    String[] fields = line.split(",");
                    try {
                        bank.apply(fields);
                        applied++;
                    } catch (TransactionException e) {
                        String tx = fields.length > 0 && !fields[0].isEmpty()
                                ? fields[0] : "?";
                        errors.println(tx + ": " + e.getMessage());
                        rejected++;
                    }
                }
            }
            BankFiles.writeBalances(bank, "balances.csv");
            System.out.println("Applied: " + applied);
            System.out.println("Rejected: " + rejected);
            System.out.println("Money in bank: " + bank.totalMoney() + " Tk");
        } catch (IOException | NumberFormatException e) {
            System.out.println("Cannot process files: " + e.getMessage());
        }
    }
}
```

### Explanation
Every transaction either succeeds completely or changes nothing. For a transfer, both
accounts are looked up *before* any money moves, and `withdraw` checks the balance
before changing it, so a rejected transfer never leaves money half-moved. All rules
signal failure with `TransactionException`, so `main` handles every kind of rejection
with one `catch` and one log line. `"T1,DEPOSIT,1003,,2500".split(",")` gives five
fields, the fourth one empty, which is why the empty `to` column works. The file
formats are kept in `BankFiles` and `Account.toCsvLine`, the rules in `Bank` and
`Account`. The outer `catch` also covers `NumberFormatException`, so a corrupted
`accounts.csv` gives a message instead of a crash. The total (7200 Tk) is a useful
check: only the deposit and withdrawal change it, while transfers move money between
accounts.

## Problem 14: Game Save Slots
**Level:** Advanced

### Problem Statement
A console role-playing game saves the player in numbered slots, files `slot<k>.sav`,
using serialization. `Player` is `Serializable` with a name, a level (starting at 1),
experience points (`xp`), an `ArrayList<String>` of items and a **transient** counter
`movesThisSession`. Read commands from standard input until the input ends:

| Command | Action and output |
|---|---|
| `NEW <name>` | start a new player; print `New player <name>` |
| `PLAY <points>` | add xp and count a move; each time xp reaches 100, subtract 100, add a level and print `<name> reached level <level>` |
| `GET <item>` | add the item and count a move; print `<name> got <item>` |
| `SAVE <k>` | write the player to `slot<k>.sav`; print `Saved to slot <k>` |
| `LOAD <k>` | replace the current player with the saved one; print `Loaded slot <k>`, or `Slot <k> is empty` if the file does not exist, or `Slot <k> is damaged` if it cannot be read as a save |
| `SHOW` | print `<name> | level <l> | xp <x> | items <list> | moves <m>` |

Before the first `NEW` or successful `LOAD`, `PLAY`, `GET`, `SAVE` and `SHOW` print
`No player`. Use a `SaveManager` class for the files and a `Game` class that holds the
current player and runs the commands.

### Sample Input
```text
SHOW
NEW Nusrat
PLAY 70
GET bamboo-sword
PLAY 60
SAVE 1
PLAY 150
GET river-map
SHOW
LOAD 2
LOAD 3
LOAD 1
SHOW
```
**File `slot3.sav`**
```text
this is not a save file
```

### Sample Output
```text
No player
New player Nusrat
Nusrat got bamboo-sword
Nusrat reached level 2
Saved to slot 1
Nusrat reached level 3
Nusrat got river-map
Nusrat | level 3 | xp 80 | items [bamboo-sword, river-map] | moves 5
Slot 2 is empty
Slot 3 is damaged
Loaded slot 1
Nusrat | level 2 | xp 30 | items [bamboo-sword] | moves 0
```

### Solution
```java
import java.io.FileInputStream;
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.io.Serializable;
import java.util.ArrayList;
import java.util.Scanner;

class Player implements Serializable {
    private static final long serialVersionUID = 1L;

    private final String name;
    private int level = 1;
    private int xp;
    private final ArrayList<String> items = new ArrayList<String>();
    private transient int movesThisSession;

    Player(String name) {
        this.name = name;
    }

    void play(int points) {
        movesThisSession++;
        xp += points;
        while (xp >= 100) {
            xp -= 100;
            level++;
            System.out.println(name + " reached level " + level);
        }
    }

    void pickUp(String item) {
        movesThisSession++;
        items.add(item);
        System.out.println(name + " got " + item);
    }

    @Override
    public String toString() {
        return name + " | level " + level + " | xp " + xp + " | items " + items
                + " | moves " + movesThisSession;
    }
}

class SaveManager {
    private String fileFor(int slot) {
        return "slot" + slot + ".sav";
    }

    void save(Player player, int slot) throws IOException {
        try (ObjectOutputStream out =
                 new ObjectOutputStream(new FileOutputStream(fileFor(slot)))) {
            out.writeObject(player);
        }
    }

    Player load(int slot) throws IOException, ClassNotFoundException {
        try (ObjectInputStream in =
                 new ObjectInputStream(new FileInputStream(fileFor(slot)))) {
            return (Player) in.readObject();
        }
    }
}

class Game {
    private final SaveManager saves = new SaveManager();
    private Player player;

    void run(String command, String argument) {
        if (command.equals("NEW")) {
            player = new Player(argument);
            System.out.println("New player " + argument);
        } else if (command.equals("LOAD")) {
            load(Integer.parseInt(argument));
        } else if (player == null) {
            System.out.println("No player");
        } else if (command.equals("PLAY")) {
            player.play(Integer.parseInt(argument));
        } else if (command.equals("GET")) {
            player.pickUp(argument);
        } else if (command.equals("SAVE")) {
            save(Integer.parseInt(argument));
        } else if (command.equals("SHOW")) {
            System.out.println(player);
        } else {
            System.out.println("Unknown command " + command);
        }
    }

    private void save(int slot) {
        try {
            saves.save(player, slot);
            System.out.println("Saved to slot " + slot);
        } catch (IOException e) {
            System.out.println("Could not save slot " + slot);
        }
    }

    private void load(int slot) {
        try {
            player = saves.load(slot);
            System.out.println("Loaded slot " + slot);
        } catch (FileNotFoundException e) {
            System.out.println("Slot " + slot + " is empty");
        } catch (IOException | ClassNotFoundException | ClassCastException e) {
            System.out.println("Slot " + slot + " is damaged");
        }
    }
}

public class GameSaves {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Game game = new Game();
        while (in.hasNextLine()) {
            String line = in.nextLine().trim();
            if (line.isEmpty()) {
                continue;
            }
            int space = line.indexOf(' ');
            if (space < 0) {
                game.run(line, "");
            } else {
                game.run(line.substring(0, space), line.substring(space + 1).trim());
            }
        }
    }
}
```

### Explanation
One `writeObject(player)` saves the whole object graph: the `Player`, its `ArrayList`
and every item `String`. Loading slot 1 brings back the state at the moment of saving
(level 2, xp 30, one item), which is exactly what a save slot is for. The transient
`movesThisSession` comes back as `0`, because it describes the current session, not the
saved game. `LOAD` distinguishes three outcomes by exception type: a missing file throws
`FileNotFoundException` (caught first, because it is a subclass of `IOException`); a
file that is not a serialization stream makes the `ObjectInputStream` constructor throw
`StreamCorruptedException`, another `IOException`. If a load fails, `player` keeps its
old value, because the assignment never happens. `SaveManager` is the only class that
knows file names and streams.

## Problem 15: Wallet Ledger with Replay
**Level:** Advanced

### Problem Statement
A campus mobile-wallet prototype never stores balances directly. Instead, every
successful operation is appended to `ledger.log`, and at start-up the program
**replays** the log to rebuild all balances. Operations:

- `ADD <name> <amount>`: create the wallet if needed and add money;
- `PAY <from> <to> <amount>`: both wallets must exist and `from` must have enough;
- `WITHDRAW <name> <amount>`: the wallet must exist and have enough.

Amounts are positive whole Tk. The program:

1. Replays `ledger.log` line by line. A line that cannot be applied is corrupt: print
   `Corrupt log line <n> ignored` and continue. Then print
   `Replayed <ok> entries`.
2. Reads commands from standard input until the input ends. A command that succeeds is
   applied, appended to `ledger.log` and reported as `OK: <command>`. Otherwise print
   `Rejected: <command> (<reason>)` and do not log it. Reasons:
   `unknown command`, `wrong number of parts`, `bad amount`, `no wallet <name>`,
   `<name> has only <balance> Tk`.
3. Prints `Balances:` and every wallet as `<name left-aligned in 8> <balance
   right-aligned in 5> Tk`, sorted by name.

Use one method `apply(String command)` in a `WalletBook` class for both replay and new
commands, and a `Ledger` class that owns the file.

### Sample Input
```text

PAY Farhana Nusrat 120

SEND Karim 5
ADD Imran ten
```
**File `ledger.log`**

### Solution
```java
import java.io.BufferedReader;
import java.io.File;
import java.io.FileReader;
import java.io.FileWriter;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.ArrayList;
import java.util.Scanner;

class LedgerException extends Exception {
    LedgerException(String message) {
        super(message);
    }
}

class Wallet {
    private final String owner;
    private long balance;

    Wallet(String owner) {
        this.owner = owner;
    }

    String getOwner() {
        return owner;
    }

    long getBalance() {
        return balance;
    }

    void deposit(long amount) {
        balance += amount;
    }

    void withdraw(long amount) throws LedgerException {
        if (amount > balance) {
            throw new LedgerException(owner + " has only " + balance + " Tk");
        }
        balance -= amount;
    }
}

class WalletBook {
    private final ArrayList<Wallet> wallets = new ArrayList<Wallet>();

    private Wallet find(String owner) throws LedgerException {
        for (Wallet w : wallets) {
            if (w.getOwner().equals(owner)) {
                return w;
            }
        }
        throw new LedgerException("no wallet " + owner);
    }

    /** Keeps the list sorted by owner name. */
    private Wallet findOrCreate(String owner) {
        int i = 0;
        while (i < wallets.size() && wallets.get(i).getOwner().compareTo(owner) < 0) {
            i++;
        }
        if (i < wallets.size() && wallets.get(i).getOwner().equals(owner)) {
            return wallets.get(i);
        }
        Wallet created = new Wallet(owner);
        wallets.add(i, created);
        return created;
    }

    private static long amount(String text) throws LedgerException {
        try {
            long value = Long.parseLong(text);
            if (value <= 0) {
                throw new LedgerException("bad amount");
            }
            return value;
        } catch (NumberFormatException e) {
            throw new LedgerException("bad amount");
        }
    }

    private static void expectParts(String[] parts, int count) throws LedgerException {
        if (parts.length != count) {
            throw new LedgerException("wrong number of parts");
        }
    }

    void apply(String command) throws LedgerException {
        String[] p = command.trim().split("\\s+");
        if (p[0].equals("ADD")) {
            expectParts(p, 3);
            long value = amount(p[2]); // validate before creating a wallet
            findOrCreate(p[1]).deposit(value);
        } else if (p[0].equals("PAY")) {
            expectParts(p, 4);
            long value = amount(p[3]);
            Wallet from = find(p[1]);
            Wallet to = find(p[2]);
            from.withdraw(value);
            to.deposit(value);
        } else if (p[0].equals("WITHDRAW")) {
            expectParts(p, 3);
            long value = amount(p[2]);
            find(p[1]).withdraw(value);
        } else {
            throw new LedgerException("unknown command");
        }
    }

    void printBalances() {
        System.out.println("Balances:");
        for (Wallet w : wallets) {
            System.out.printf("%-8s %5d Tk%n", w.getOwner(), w.getBalance());
        }
    }
}

class Ledger {
    private final String fileName;

    Ledger(String fileName) {
        this.fileName = fileName;
    }

    void replay(WalletBook book) throws IOException {
        if (!new File(fileName).exists()) {
            System.out.println("Replayed 0 entries");
            return;
        }
        int ok = 0;
        int lineNumber = 0;
        try (BufferedReader reader = new BufferedReader(new FileReader(fileName))) {
            String line;
            while ((line = reader.readLine()) != null) {
                lineNumber++;
                try {
                    book.apply(line);
                    ok++;
                } catch (LedgerException e) {
                    System.out.println("Corrupt log line " + lineNumber + " ignored");
                }
            }
        }
        System.out.println("Replayed " + ok + " entries");
    }

    void append(String command) throws IOException {
        try (PrintWriter out = new PrintWriter(new FileWriter(fileName, true))) {
            out.println(command);
        }
    }
}

public class WalletLedger {
    public static void main(String[] args) {
        WalletBook book = new WalletBook();
        Ledger ledger = new Ledger("ledger.log");
        Scanner in = new Scanner(System.in);
        try {
            ledger.replay(book);
            while (in.hasNextLine()) {
                String command = in.nextLine().trim();
                if (command.isEmpty()) {
                    continue;
                }
                try {
                    book.apply(command);
                    ledger.append(command);
                    System.out.println("OK: " + command);
                } catch (LedgerException e) {
                    System.out.println("Rejected: " + command + " (" + e.getMessage() + ")");
                }
            }
            book.printBalances();
        } catch (IOException e) {
            System.out.println("Ledger error: " + e.getMessage());
        }
    }
}
```

### Explanation
The log is the single source of truth: balances exist only in memory and can always be
rebuilt by replaying the operations in order. This pattern (often called *event
sourcing*) is used by real payment and database systems, because an append-only file
is hard to damage: old lines are never rewritten. Replay and live commands go through
the same `apply` method, so the rules cannot drift apart, and a command is appended
only *after* it has succeeded, so the log never contains an operation that was
rejected. Every check happens before any balance changes (for `PAY`, both wallets are
found before the withdrawal), so a rejected command changes nothing. `findOrCreate`
inserts new wallets in sorted position, so the final listing needs no separate sort.
