# Practice Problems: Java Fundamentals

These problems practise variables, types, casting, operators, `Scanner`, formatted
output, `String` and `Math` methods, and a simple `if`/`else`; none of them needs a
loop. Programs read input without prompts and print exactly the sample output.

## Problem 1: Campus Shuttle Distance
**Level:** Basic

### Problem Statement
The campus shuttle app stores route lengths in kilometres. Read one decimal number:
the route length in km. Print four lines:

- `Distance : <km> km` with 2 decimal places
- `In miles : <miles> mi` with 2 decimal places (1 km = 0.621371 miles)
- `In metres: <m> m` rounded to the nearest whole metre
- `Shuttle time at 30 km/h: about <t> min` rounded to the nearest whole minute

Use `final` constants for the conversion factors and the speed.

### Sample Input
```text
18.45
```

### Sample Output
```text
Distance : 18.45 km
In miles : 11.46 mi
In metres: 18450 m
Shuttle time at 30 km/h: about 37 min
```

### Solution
```java
import java.util.Scanner;

public class ShuttleDistance {
    public static void main(String[] args) {
        final double MILES_PER_KM = 0.621371;
        final int METRES_PER_KM = 1000;
        final double SPEED_KMH = 30.0;
        Scanner in = new Scanner(System.in);

        double km = in.nextDouble();
        double miles = km * MILES_PER_KM;
        long metres = Math.round(km * METRES_PER_KM);
        long minutes = Math.round(km / SPEED_KMH * 60);

        System.out.printf("Distance : %.2f km%n", km);
        System.out.printf("In miles : %.2f mi%n", miles);
        System.out.println("In metres: " + metres + " m");
        System.out.println("Shuttle time at 30 km/h: about " + minutes + " min");
    }
}
```

### Explanation
- The constants give names to the numbers, so `km * MILES_PER_KM` reads like the
  formula itself.
- `18.45 * 1000` is not exactly `18450` inside the computer, because `18.45` cannot be
  stored exactly in binary; it can come out as `18449.999...`. A cast `(long)` would
  cut that down to `18449`. `Math.round` returns the nearest `long`, which is safe.
- The time is `18.45 / 30 * 60 = 36.9` minutes, and `Math.round` gives `37`.
- `printf` with `%.2f` rounds the display only; the variables keep full precision.

## Problem 2: Quiz Average and the Integer Division Trap
**Level:** Basic

### Problem Statement
Read three quiz marks (whole numbers out of 10) on one line. Print the sum, the
average computed with integer division, the real average with 2 decimal places, and
the real average rounded to the nearest whole number, exactly in the format of the
sample.

### Sample Input
```text
8 7 8
```

### Sample Output
```text
Sum            : 23
Integer average: 7
Real average   : 7.67
Rounded        : 8
```

### Solution
```java
import java.util.Scanner;

public class QuizAverage {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int quiz1 = in.nextInt();
        int quiz2 = in.nextInt();
        int quiz3 = in.nextInt();

        int sum = quiz1 + quiz2 + quiz3;
        int integerAverage = sum / 3;
        double realAverage = sum / 3.0;
        long rounded = Math.round(realAverage);

        System.out.println("Sum            : " + sum);
        System.out.println("Integer average: " + integerAverage);
        System.out.printf("Real average   : %.2f%n", realAverage);
        System.out.println("Rounded        : " + rounded);
    }
}
```

### Explanation
`sum / 3` has two `int` operands, so Java performs integer division and `23 / 3` is
`7`: the `.67` is lost, which would be unfair to the student. Writing `3.0` makes one
operand a `double`, so `sum` is widened and the division is real: `7.666...`. The
`%.2f` specifier shows it as `7.67`. `Math.round(7.666...)` gives `8`, the nearest
whole mark. Note that `(int) realAverage` would give `7`, because a cast truncates.

## Problem 3: Bus Journey Duration
**Level:** Basic

### Problem Statement
A long-distance bus company lists journey times in minutes. Read the number of
minutes (a non-negative whole number) and print it in three forms: hours and minutes,
a clock-style `HH:MM` with two digits each, and decimal hours with 2 decimal places,
exactly as in the sample.

### Sample Input
```text
515
```

### Sample Output
```text
515 minutes = 8 h 35 min
Clock format: 08:35
Decimal hours: 8.58
```

### Solution
```java
import java.util.Scanner;

public class BusJourney {
    public static void main(String[] args) {
        final int MINUTES_PER_HOUR = 60;
        Scanner in = new Scanner(System.in);

        int totalMinutes = in.nextInt();
        int hours = totalMinutes / MINUTES_PER_HOUR;
        int minutes = totalMinutes % MINUTES_PER_HOUR;
        double decimalHours = (double) totalMinutes / MINUTES_PER_HOUR;

        System.out.println(totalMinutes + " minutes = " + hours + " h " + minutes + " min");
        System.out.printf("Clock format: %02d:%02d%n", hours, minutes);
        System.out.printf("Decimal hours: %.2f%n", decimalHours);
    }
}
```

### Explanation
Integer division answers "how many whole hours fit": `515 / 60` is `8`. The remainder
operator answers "what is left": `515 % 60` is `35`. The `%02d` specifier pads with a
leading zero, so `8` prints as `08`. For the decimal hours, the `(double)` cast is
applied to `totalMinutes` before dividing, so the result keeps its fraction
(`8.5833...`), which `%.2f` rounds to `8.58`.

## Problem 4: Name Badge
**Level:** Basic

### Problem Statement
Read one line containing a person's first name and last name separated by exactly one
space. Print a badge line in upper case, the first and last names with their lengths,
and the initials with a dot after each letter, exactly as in the sample.

### Sample Input
```text
Rafi Ahmed
```

### Sample Output
```text
Badge     : RAFI AHMED
First name: Rafi (4 letters)
Last name : Ahmed (5 letters)
Initials  : R.A.
```

### Solution
```java
import java.util.Scanner;

public class NameBadge {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        String fullName = in.nextLine();

        int space = fullName.indexOf(" ");
        String firstName = fullName.substring(0, space);
        String lastName = fullName.substring(space + 1);
        String initials = "" + firstName.charAt(0) + "." + lastName.charAt(0) + ".";

        System.out.println("Badge     : " + fullName.toUpperCase());
        System.out.println("First name: " + firstName + " (" + firstName.length()
                + " letters)");
        System.out.println("Last name : " + lastName + " (" + lastName.length()
                + " letters)");
        System.out.println("Initials  : " + initials);
    }
}
```

### Explanation
`nextLine()` reads the whole line, including the space; `next()` would read only
`Rafi`. `indexOf(" ")` returns the position of the space (4). `substring(0, space)`
takes indexes 0 to 3 (the end index is not included), and `substring(space + 1)`
takes everything after the space. The initials expression starts with `""` so that
every `+` joins text; `firstName.charAt(0) + lastName.charAt(0)` alone would add the
two character codes as numbers. `toUpperCase()` returns a new string; `fullName` itself
does not change.

## Problem 5: Mobile Wallet Cash-Out
**Level:** Basic

### Problem Statement
A mobile wallet charges a cash-out fee of 1.85% of the amount (a hypothetical rate).
Read the current balance and the cash-out amount (decimal numbers, in Tk). Print the
amount, the fee and the total with 2 decimal places. If the total is not more than the
balance, print `Approved. New balance: <balance> Tk`; otherwise print
`Declined. Short by <shortfall> Tk`. Follow the sample format exactly.

### Sample Input
```text
2000 1980
```

### Sample Output
```text
Cash-out : 1980.00 Tk
Fee      : 36.63 Tk
Total    : 2016.63 Tk
Declined. Short by 16.63 Tk
```

### Solution
```java
import java.util.Scanner;

public class WalletCashOut {
    public static void main(String[] args) {
        final double FEE_PERCENT = 1.85;
        Scanner in = new Scanner(System.in);

        double balance = in.nextDouble();
        double amount = in.nextDouble();
        double fee = amount * FEE_PERCENT / 100;
        double total = amount + fee;

        System.out.printf("Cash-out : %.2f Tk%n", amount);
        System.out.printf("Fee      : %.2f Tk%n", fee);
        System.out.printf("Total    : %.2f Tk%n", total);
        if (total <= balance) {
            System.out.printf("Approved. New balance: %.2f Tk%n", balance - total);
        } else {
            System.out.printf("Declined. Short by %.2f Tk%n", total - balance);
        }
    }
}
```

### Explanation
The fee is a percentage, so it is computed with `double` arithmetic and stored in a
named constant. The condition `total <= balance` is a `boolean` expression; exactly
one of the two branches runs. The sample shows why the fee must be included: the
balance (2000) is larger than the amount (1980) but smaller than amount plus fee. With
the input `5000 2000` the program prints a fee of `37.00` and
`Approved. New balance: 2963.00 Tk`.

## Problem 6: Hostel Room Bill Split
**Level:** Intermediate

### Problem Statement
Roommates in a hostel share the monthly rent, electricity and internet bills. The
total is rounded to the nearest whole taka (the payable amount). Every roommate pays
`payable / n` taka, and the room captain also pays the leftover taka that cannot be
split evenly.

Input: the number of roommates `n` (at least 1) on the first line; on the second line
the rent (whole Tk), the electricity bill (Tk with paisa) and the internet bill (whole
Tk). Print the receipt exactly as in the sample: labels left-aligned in 12 columns,
numbers right-aligned in 10 columns, money with 2 decimals where it has paisa. The
last line checks that the payments add up to the payable amount.

### Sample Input
```text
3
12000 1843.60 1200
```

### Sample Output
```text
Rent          12000.00 Tk
Electricity    1843.60 Tk
Internet       1200.00 Tk
Total         15043.60 Tk
Payable          15044 Tk
Roommates            3
Each pays         5014 Tk
Captain pays      5016 Tk
Check            15044 Tk
```

### Solution
```java
import java.util.Scanner;

public class HostelBillSplit {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int roommates = in.nextInt();
        int rent = in.nextInt();
        double electricity = in.nextDouble();
        int internet = in.nextInt();

        double total = rent + electricity + internet;
        long payable = Math.round(total);
        long share = payable / roommates;
        long leftover = payable % roommates;
        long captainPays = share + leftover;
        long check = share * (roommates - 1) + captainPays;

        System.out.printf("%-12s%10.2f Tk%n", "Rent", (double) rent);
        System.out.printf("%-12s%10.2f Tk%n", "Electricity", electricity);
        System.out.printf("%-12s%10.2f Tk%n", "Internet", (double) internet);
        System.out.printf("%-12s%10.2f Tk%n", "Total", total);
        System.out.printf("%-12s%10d Tk%n", "Payable", payable);
        System.out.printf("%-12s%10d%n", "Roommates", roommates);
        System.out.printf("%-12s%10d Tk%n", "Each pays", share);
        System.out.printf("%-12s%10d Tk%n", "Captain pays", captainPays);
        System.out.printf("%-12s%10d Tk%n", "Check", check);
    }
}
```

### Explanation
- `rent + electricity + internet` mixes `int` and `double`; the `int` values are
  widened, so the total keeps its paisa.
- `Math.round` turns `15043.60` into the whole number `15044` (a `long`).
- Integer division and remainder split the money with nothing lost: `15044 / 3` is
  `5014` and `15044 % 3` is `2`, which goes to the captain. The check line proves
  `5014 + 5014 + 5016 = 15044`.
- `%f` needs a floating-point value, so `rent` and `internet` are cast with `(double)`
  for the `%10.2f` rows; passing an `int` to `%f` would throw an exception.
- The fixed widths `%-12s` and `%10...` make every column line up.

## Problem 7: Lucky Bus Ticket
**Level:** Intermediate

### Problem Statement
A city bus ticket has a 6-digit number, which may start with zeros (for example
`004130`). A ticket is **lucky** if the sum of its first three digits equals the sum of
its last three digits. It is a **palindrome** if it reads the same from both ends.

Read the ticket number as an integer. Print the ticket with all 6 digits, the two
half sums as shown, `Lucky ticket!` or `Not lucky.`, and `Palindrome: yes` or
`Palindrome: no`. Use only arithmetic (`/` and `%`) to get the digits.

### Sample Input
```text
385646
```

### Sample Output
```text
Ticket     : 385646
First half : 3 + 8 + 5 = 16
Second half: 6 + 4 + 6 = 16
Lucky ticket!
Palindrome: no
```

### Solution
```java
import java.util.Scanner;

public class LuckyTicket {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int ticket = in.nextInt();

        int d1 = ticket / 100000;
        int d2 = ticket / 10000 % 10;
        int d3 = ticket / 1000 % 10;
        int d4 = ticket / 100 % 10;
        int d5 = ticket / 10 % 10;
        int d6 = ticket % 10;

        int firstSum = d1 + d2 + d3;
        int secondSum = d4 + d5 + d6;

        System.out.printf("Ticket     : %06d%n", ticket);
        System.out.println("First half : " + d1 + " + " + d2 + " + " + d3
                + " = " + firstSum);
        System.out.println("Second half: " + d4 + " + " + d5 + " + " + d6
                + " = " + secondSum);

        if (firstSum == secondSum) {
            System.out.println("Lucky ticket!");
        } else {
            System.out.println("Not lucky.");
        }

        boolean palindrome = d1 == d6 && d2 == d5 && d3 == d4;
        if (palindrome) {
            System.out.println("Palindrome: yes");
        } else {
            System.out.println("Palindrome: no");
        }
    }
}
```

### Explanation
`n % 10` gives the last digit, and dividing by 10, 100, 1000, ... first shifts the
wanted digit into the last position: `385646 / 1000` is `385`, and `385 % 10` is `5`.
Precedence matters here: `/` and `%` have the same priority and are applied left to
right, so `ticket / 1000 % 10` means `(ticket / 1000) % 10`. A ticket like `004130` is
read by `nextInt()` as the number `4130`, but the arithmetic still gives the digits
`0 0 4 1 3 0`, and `%06d` prints it back with its leading zeros. The palindrome test
combines three comparisons with `&&`; all three must be true.

## Problem 8: Recipe Scaling for the Canteen
**Level:** Intermediate

### Problem Statement
The canteen's khichuri recipe for a base number of servings needs 500 g of rice,
3 eggs and 2.5 tablespoons of oil. Read the base number of servings and the wanted
number of servings (whole numbers). Print:

- the scale factor (wanted / base) with 2 decimals
- the rice in grams, rounded to the nearest gram
- the exact number of eggs with 2 decimals, and the eggs to buy (rounded **up**,
  since you cannot buy part of an egg)
- what pure integer arithmetic (`3 * wanted / base`) would give, to show the trap
- the oil in tablespoons with 2 decimals

Follow the sample format exactly.

### Sample Input
```text
4 6
```

### Sample Output
```text
Scale factor : 1.50
Rice         : 750 g
Eggs (exact) : 4.50
Eggs to buy  : 5
Integer math : 4 eggs (too few!)
Oil          : 3.75 tbsp
```

### Solution
```java
import java.util.Scanner;

public class RecipeScaling {
    public static void main(String[] args) {
        final int BASE_RICE_GRAMS = 500;
        final int BASE_EGGS = 3;
        final double BASE_OIL_TBSP = 2.5;
        Scanner in = new Scanner(System.in);

        int baseServings = in.nextInt();
        int wantedServings = in.nextInt();

        double factor = (double) wantedServings / baseServings;
        long riceGrams = Math.round(BASE_RICE_GRAMS * factor);
        double exactEggs = BASE_EGGS * factor;
        int eggsToBuy = (int) Math.ceil(exactEggs);
        int integerEggs = BASE_EGGS * wantedServings / baseServings;
        double oil = BASE_OIL_TBSP * factor;

        System.out.printf("Scale factor : %.2f%n", factor);
        System.out.println("Rice         : " + riceGrams + " g");
        System.out.printf("Eggs (exact) : %.2f%n", exactEggs);
        System.out.println("Eggs to buy  : " + eggsToBuy);
        System.out.println("Integer math : " + integerEggs + " eggs (too few!)");
        System.out.printf("Oil          : %.2f tbsp%n", oil);
    }
}
```

### Explanation
- The factor must be a real number, so `wantedServings` is cast to `double` before
  the division; without the cast, `6 / 4` would be `1` and every amount would be
  wrong.
- Different quantities need different rounding: rice is rounded to the nearest gram
  with `Math.round`, eggs are rounded up with `Math.ceil`, and oil keeps its fraction.
- `Math.ceil` returns a `double` (`5.0`), so the `(int)` cast turns it into `5`.
- `3 * 6 / 4` is evaluated left to right as `18 / 4`, which is `4` in integer
  arithmetic: half an egg short. This line is printed on purpose, to show why the
  real division matters.

## Problem 9: Class Duration Calculator
**Level:** Intermediate

### Problem Statement
Class times are written as `H:MM` or `HH:MM` in 24-hour format (for example `8:30` or
`14:05`). Read a start time and an end time (two tokens on one line). Print both times
in the `HH:MM` format together with their minute of the day (minutes since midnight).
If the end time is after the start time, print the duration as
`Duration: <h> h <mm> min (<total> minutes)` with the minutes in two digits;
otherwise print `Invalid: the class must end after it starts.`

### Sample Input
```text
8:30 11:05
```

### Sample Output
```text
Start: 08:30 (minute 510 of the day)
End  : 11:05 (minute 665 of the day)
Duration: 2 h 35 min (155 minutes)
```

### Solution
```java
import java.util.Scanner;

public class ClassDuration {
    public static void main(String[] args) {
        final int MINUTES_PER_HOUR = 60;
        Scanner in = new Scanner(System.in);
        String start = in.next();
        String end = in.next();

        int startColon = start.indexOf(":");
        int startHour = Integer.parseInt(start.substring(0, startColon));
        int startMinute = Integer.parseInt(start.substring(startColon + 1));
        int startOfDay = startHour * MINUTES_PER_HOUR + startMinute;

        int endColon = end.indexOf(":");
        int endHour = Integer.parseInt(end.substring(0, endColon));
        int endMinute = Integer.parseInt(end.substring(endColon + 1));
        int endOfDay = endHour * MINUTES_PER_HOUR + endMinute;

        String startText = String.format("%02d:%02d", startHour, startMinute);
        String endText = String.format("%02d:%02d", endHour, endMinute);
        System.out.println("Start: " + startText + " (minute " + startOfDay + " of the day)");
        System.out.println("End  : " + endText + " (minute " + endOfDay + " of the day)");

        int duration = endOfDay - startOfDay;
        if (duration > 0) {
            System.out.printf("Duration: %d h %02d min (%d minutes)%n",
                    duration / MINUTES_PER_HOUR, duration % MINUTES_PER_HOUR, duration);
        } else {
            System.out.println("Invalid: the class must end after it starts.");
        }
    }
}
```

### Explanation
The hour part may have one or two digits, so the program does not assume a fixed
position: `indexOf(":")` finds the colon, and `substring` cuts the text before and
after it. `Integer.parseInt` turns `"8"` and `"30"` into numbers. Converting both
times to "minutes since midnight" turns a clock problem into a simple subtraction;
`/` and `%` turn the difference back into hours and minutes. `String.format` builds
the normalised `08:30` text without printing it, so it can be joined into a longer
line. With the input `10:00 9:15` the duration is negative and the invalid message is
printed.

## Problem 10: Student Email Builder
**Level:** Intermediate

### Problem Statement
The IT office creates student email addresses from a name and a 10-digit student ID.
Read the name on the first line: either one word, or a first and last name separated
by one space, in any mix of upper and lower case. Read the ID on the second line.

- Display name: for two words, `LAST, First` (last name in upper case, first name with
  only its first letter capitalised); for one word, the word in upper case.
- Username: first name in lower case, then (two words only) a dot and the first letter
  of the last name in lower case, then the last 4 digits of the ID.
- Email: username followed by `@student.example.edu`.

Print the three lines exactly as in the sample.

### Sample Input
```text
tanvir AHMED
0112230457
```

### Sample Output
```text
Display name: AHMED, Tanvir
Username    : tanvir.a0457
Email       : tanvir.a0457@student.example.edu
```

### Solution
```java
import java.util.Scanner;

public class EmailBuilder {
    public static void main(String[] args) {
        final String DOMAIN = "@student.example.edu";
        Scanner in = new Scanner(System.in);
        String name = in.nextLine().trim();
        String id = in.nextLine().trim();

        String idTail = id.substring(id.length() - 4);
        int space = name.indexOf(" ");

        String displayName;
        String username;
        if (space == -1) {
            displayName = name.toUpperCase();
            username = name.toLowerCase() + idTail;
        } else {
            String first = name.substring(0, space);
            String last = name.substring(space + 1);
            String niceFirst = first.substring(0, 1).toUpperCase()
                    + first.substring(1).toLowerCase();
            displayName = last.toUpperCase() + ", " + niceFirst;
            username = first.toLowerCase() + "." + last.substring(0, 1).toLowerCase()
                    + idTail;
        }

        System.out.println("Display name: " + displayName);
        System.out.println("Username    : " + username);
        System.out.println("Email       : " + username + DOMAIN);
    }
}
```

### Explanation
- `indexOf(" ")` returns `-1` when there is no space, which is how the program tells
  one-word names from two-word names.
- `displayName` and `username` are declared before the `if` and assigned in **both**
  branches, so Java knows they always have a value when they are printed (definite
  assignment). If one branch forgot one of them, the program would not compile.
- `id.substring(id.length() - 4)` takes the last 4 characters wherever the ID ends.
  The ID stays a `String`: as an `int`, `0112230457` would lose its leading zero.
- Capitalising a word means "first letter upper case + rest lower case", built from
  two substrings. `trim()` removes stray spaces at the ends of each line.
- With the input `Imran` and `0112230099`, the program prints `IMRAN`, `imran0099` and
  `imran0099@student.example.edu`.

## Problem 11: Electricity Bill with Slabs
**Level:** Advanced

### Problem Statement
A (hypothetical) electricity tariff charges by slabs:

| Units | Rate per unit |
|---|---|
| first 75 units (1-75) | 5.00 Tk |
| next 125 units (76-200) | 7.00 Tk |
| every unit above 200 | 9.50 Tk |

A fixed demand charge of 35 Tk is added, then 5% VAT on (energy charge + demand
charge). The payable amount is the total rounded to the nearest whole taka.

Read the units consumed (a whole number, at least 1). Print the bill exactly as in the
sample: a table with the units and amount of each slab (columns 8, 8, 10 and 12 wide),
then the charges (labels in 26 columns, amounts in 12), the payable amount, the
average cost per unit (total / units, 2 decimals) and a usage line: `high` when more
than 300 units were used, otherwise `normal`. Do not use loops; `Math.min` and
`Math.max` are enough to find the units in each slab.

### Sample Input
```text
258
```

### Sample Output
```text
Units consumed: 258
Slab       Units      Rate      Amount
1-75          75      5.00      375.00
76-200       125      7.00      875.00
201+          58      9.50      551.00
Energy charge                  1801.00
Demand charge                    35.00
VAT (5%)                         91.80
Total                          1927.80
Payable (rounded)                 1928 Tk
Average per unit: 7.47 Tk
Usage level: normal
```

### Solution
```java
import java.util.Scanner;

public class ElectricityBill {
    public static void main(String[] args) {
        final int SLAB1_LIMIT = 75;
        final int SLAB2_LIMIT = 200;
        final double RATE1 = 5.00;
        final double RATE2 = 7.00;
        final double RATE3 = 9.50;
        final double DEMAND_CHARGE = 35.0;
        final double VAT_RATE = 0.05;
        final int HIGH_USAGE = 300;
        Scanner in = new Scanner(System.in);

        int units = in.nextInt();

        // Units that fall into each slab (never negative).
        int slab1Units = Math.min(units, SLAB1_LIMIT);
        int slab2Units = Math.min(Math.max(units - SLAB1_LIMIT, 0),
                SLAB2_LIMIT - SLAB1_LIMIT);
        int slab3Units = Math.max(units - SLAB2_LIMIT, 0);

        double slab1Amount = slab1Units * RATE1;
        double slab2Amount = slab2Units * RATE2;
        double slab3Amount = slab3Units * RATE3;
        double energy = slab1Amount + slab2Amount + slab3Amount;

        double subtotal = energy + DEMAND_CHARGE;
        double vat = subtotal * VAT_RATE;
        double total = subtotal + vat;
        long payable = Math.round(total);
        double averagePerUnit = total / units;

        System.out.println("Units consumed: " + units);
        System.out.printf("%-8s%8s%10s%12s%n", "Slab", "Units", "Rate", "Amount");
        System.out.printf("%-8s%8d%10.2f%12.2f%n", "1-75", slab1Units, RATE1, slab1Amount);
        System.out.printf("%-8s%8d%10.2f%12.2f%n", "76-200", slab2Units, RATE2, slab2Amount);
        System.out.printf("%-8s%8d%10.2f%12.2f%n", "201+", slab3Units, RATE3, slab3Amount);
        System.out.printf("%-26s%12.2f%n", "Energy charge", energy);
        System.out.printf("%-26s%12.2f%n", "Demand charge", DEMAND_CHARGE);
        String vatLabel = String.format("VAT (%d%%)", Math.round(VAT_RATE * 100));
        System.out.printf("%-26s%12.2f%n", vatLabel, vat);
        System.out.printf("%-26s%12.2f%n", "Total", total);
        System.out.printf("%-26s%12d Tk%n", "Payable (rounded)", payable);
        System.out.printf("Average per unit: %.2f Tk%n", averagePerUnit);

        if (units > HIGH_USAGE) {
            System.out.println("Usage level: high");
        } else {
            System.out.println("Usage level: normal");
        }
    }
}
```

### Explanation
- The key idea is computing each slab's units without any `if`:
  - slab 1 gets `min(units, 75)`;
  - slab 2 gets what is left above 75 (`max(units - 75, 0)`, never negative) but at
    most 125 units (`min(..., 125)`);
  - slab 3 gets everything above 200, or 0.
  For 258 units this gives 75, 125 and 58; for 40 units it gives 40, 0 and 0.
- Every rate and limit is a named constant, so a tariff change touches one line.
- `slabUnits * RATE` multiplies an `int` by a `double`; the `int` is widened, so the
  amounts keep their paisa.
- The VAT label is built with `String.format`; `%%` prints the percent sign, and
  `Math.round(VAT_RATE * 100)` turns `0.05` into the whole number `5` safely.
- The column widths in the header and the rows match, so the table lines up;
  `Math.round` produces the whole-taka payable amount as a `long` for `%d`.

## Problem 12: Exam Day Finder
**Level:** Advanced

### Problem Statement
Before publishing an exam routine, the exam office wants to check each date. Read a
date in the form `dd/mm/yyyy` (always 2 digits, 2 digits, 4 digits; a valid date in
the Gregorian calendar). Print:

- the date as given
- the day of the week, found with this integer formula (0 = Sunday, 1 = Monday, ...,
  6 = Saturday), where every division is integer division:
  `a = (14 - month) / 12`, `y = year - a`, `m = month + 12 * a - 2`,
  `day of week = (day + y + y/4 - y/100 + y/400 + (31 * m) / 12) % 7`
- the day of the year, with this formula (K is 1 in a leap year, 2 otherwise):
  `275 * month / 9 - K * ((month + 9) / 12) + day - 30`
- the number of days left in the year after this date
- whether the year is a leap year (`true` or `false`); a leap year is divisible by 4
  but not by 100, or divisible by 400
- `Status: weekend, choose another date` when the day is a Friday or Saturday (the
  weekend in this hypothetical university), otherwise `Status: working day`

Follow the sample format exactly. No loops and no arrays are needed.

### Sample Input
```text
15/03/2025
```

### Sample Output
```text
Date        : 15/03/2025
Day         : Saturday
Day of year : 74
Days left   : 291
Leap year   : false
Status      : weekend, choose another date
```

### Solution
```java
import java.util.Scanner;

public class ExamDayFinder {
    public static void main(String[] args) {
        // Every name is padded to 9 characters, so name number d starts at 9 * d.
        final String DAY_NAMES = "Sunday   Monday   Tuesday  "
                + "WednesdayThursday Friday   Saturday ";
        final int NAME_WIDTH = 9;
        final int FRIDAY = 5;
        final int SATURDAY = 6;
        Scanner in = new Scanner(System.in);

        String date = in.next();
        int day = Integer.parseInt(date.substring(0, 2));
        int month = Integer.parseInt(date.substring(3, 5));
        int year = Integer.parseInt(date.substring(6));

        // Day of the week (0 = Sunday ... 6 = Saturday), integer arithmetic only.
        int a = (14 - month) / 12;
        int y = year - a;
        int m = month + 12 * a - 2;
        int dayOfWeek = (day + y + y / 4 - y / 100 + y / 400 + (31 * m) / 12) % 7;
        int nameStart = dayOfWeek * NAME_WIDTH;
        String dayName = DAY_NAMES.substring(nameStart, nameStart + NAME_WIDTH).trim();

        boolean leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0;
        int k;
        int daysInYear;
        if (leap) {
            k = 1;
            daysInYear = 366;
        } else {
            k = 2;
            daysInYear = 365;
        }
        int dayOfYear = 275 * month / 9 - k * ((month + 9) / 12) + day - 30;
        int daysLeft = daysInYear - dayOfYear;

        System.out.println("Date        : " + date);
        System.out.println("Day         : " + dayName);
        System.out.println("Day of year : " + dayOfYear);
        System.out.println("Days left   : " + daysLeft);
        System.out.println("Leap year   : " + leap);
        if (dayOfWeek == FRIDAY || dayOfWeek == SATURDAY) {
            System.out.println("Status      : weekend, choose another date");
        } else {
            System.out.println("Status      : working day");
        }
    }
}
```

### Explanation
- The fixed `dd/mm/yyyy` layout lets `substring` cut the parts by position, and
  `Integer.parseInt("03")` gives `3` (a leading zero is fine).
- The weekday formula treats January and February as months 11 and 12 of the
  previous year (`a` is 1 only for them), which moves the leap day to the end of the
  "year". Every `/` is integer division on purpose; with `double` the formula would
  be wrong.
- Choosing a day name without `switch` or arrays: all names are stored in one string,
  each padded to 9 characters, so name number `d` is `substring(9 * d, 9 * d + 9)`;
  `trim()` removes the padding.
- The leap-year test shows precedence and grouping: the parentheses make the "by 4
  but not by 100" part one unit, then `||` adds the "by 400" case.
- `k` and `daysInYear` are assigned in both branches of the `if`, so they are
  definitely assigned before use.
- Checks: `15/03/2025` is day 31 + 28 + 15 = 74; with `29/02/2024` the program prints
  `Thursday`, day 60, and `Leap year   : true`.

## Problem 13: Cashier Change Breakdown
**Level:** Advanced

### Problem Statement
A shop cashier wants to know which notes and coins to give as change. Read the amount
due and the amount paid (decimal numbers in Tk, at most 2 decimal places).

If the payment is less than the amount due, print `Payment short by <x> Tk` (2
decimals) and nothing else. Otherwise print, exactly as in the sample:

- the change with 2 decimals, and the change in paisa (1 Tk = 100 paisa), computed
  with `Math.round`
- what a plain `(long)` cast of `change * 100` gives, to show the rounding trap
- for each denomination 500, 200, 100, 50, 20, 10, 5, 2 and 1 Tk, how many to give
  (always the largest possible first), as `<value> Tk x <count>` with the value
  right-aligned in 4 columns
- the paisa that remain, and the total number of notes and coins

### Sample Input
```text
1280.65 2000
```

### Sample Output
```text
Change      : 719.35 Tk
In paisa    : 71935
Cast (wrong): 71934
 500 Tk x 1
 200 Tk x 1
 100 Tk x 0
  50 Tk x 0
  20 Tk x 0
  10 Tk x 1
   5 Tk x 1
   2 Tk x 2
   1 Tk x 0
Paisa left  : 35
Notes/coins : 6
```

### Solution
```java
import java.util.Scanner;

public class CashierChange {
    public static void main(String[] args) {
        final int PAISA_PER_TAKA = 100;
        Scanner in = new Scanner(System.in);
        double due = in.nextDouble();
        double paid = in.nextDouble();

        if (paid < due) {
            System.out.printf("Payment short by %.2f Tk%n", due - paid);
        } else {
            double change = paid - due;
            long changePaisa = Math.round(change * PAISA_PER_TAKA);
            long castPaisa = (long) (change * PAISA_PER_TAKA);

            // Work in whole taka and paisa: integers have no rounding errors.
            long taka = changePaisa / PAISA_PER_TAKA;
            long paisaLeft = changePaisa % PAISA_PER_TAKA;

            long n500 = taka / 500;
            taka = taka % 500;
            long n200 = taka / 200;
            taka = taka % 200;
            long n100 = taka / 100;
            taka = taka % 100;
            long n50 = taka / 50;
            taka = taka % 50;
            long n20 = taka / 20;
            taka = taka % 20;
            long n10 = taka / 10;
            taka = taka % 10;
            long n5 = taka / 5;
            taka = taka % 5;
            long n2 = taka / 2;
            long n1 = taka % 2;

            long pieces = n500 + n200 + n100 + n50 + n20 + n10 + n5 + n2 + n1;

            System.out.printf("Change      : %.2f Tk%n", change);
            System.out.println("In paisa    : " + changePaisa);
            System.out.println("Cast (wrong): " + castPaisa);
            System.out.printf("%4d Tk x %d%n", 500, n500);
            System.out.printf("%4d Tk x %d%n", 200, n200);
            System.out.printf("%4d Tk x %d%n", 100, n100);
            System.out.printf("%4d Tk x %d%n", 50, n50);
            System.out.printf("%4d Tk x %d%n", 20, n20);
            System.out.printf("%4d Tk x %d%n", 10, n10);
            System.out.printf("%4d Tk x %d%n", 5, n5);
            System.out.printf("%4d Tk x %d%n", 2, n2);
            System.out.printf("%4d Tk x %d%n", 1, n1);
            System.out.println("Paisa left  : " + paisaLeft);
            System.out.println("Notes/coins : " + pieces);
        }
    }
}
```

### Explanation
- Most decimal fractions cannot be stored exactly in a `double`. Here
  `2000 - 1280.65` is stored as a value just below `719.35`, so `change * 100` is
  `71934.99999...`. The cast `(long)` truncates it to `71934`, one paisa short;
  `Math.round` gives the correct `71935`. The program prints both to make the trap
  visible.
- After that conversion, everything is done with whole numbers (`long`), which are
  exact. This "convert money to the smallest unit" idea is how real billing code
  avoids rounding errors.
- Each denomination uses the same two steps: `/` says how many notes fit, `%` keeps
  what is still left to pay out. The `taka = taka % 500;` lines could also be written
  with compound assignment, `taka %= 500;`.
- `%4d` right-aligns the values in 4 columns, so ` 500` and `   1` line up.
- With the input `500 300` the program prints `Payment short by 200.00 Tk`.

## Problem 14: Monthly Payslip
**Level:** Advanced

### Problem Statement
Write a payslip program for a company with these (hypothetical) rules:

- house rent allowance: 45% of the basic salary
- medical allowance: 10% of the basic salary, but at most 2500 Tk
- conveyance allowance: 1500 Tk
- overtime pay: overtime hours × hourly rate × 1.5, where the hourly rate is
  basic salary / 208 (a real division, not integer division)
- gross pay: basic + all allowances + overtime pay
- income tax: 10% of the part of the gross pay above 50000 Tk (0 if not above)
- provident fund: 5% of the basic salary
- net pay: gross pay − income tax − provident fund

Input: the employee's full name on the first line, then the basic salary (a whole
number of Tk) and the overtime hours (a decimal number) on the second line.

Print the payslip exactly as in the sample: the name in upper case, labels
left-aligned in 20 columns, amounts in 10 columns with 2 decimals. Then print the
hourly rate together with what integer division would have given, and the tax status
(`taxable (gross above 50000)` or `not taxable`).

### Sample Input
```text
Imran Hossain
42000 12.5
```

### Sample Output
```text
Payslip: IMRAN HOSSAIN
Basic salary          42000.00
House rent (45%)      18900.00
Medical (max 2500)     2500.00
Conveyance             1500.00
Overtime (12.5 h)      3786.06
Gross pay             68686.06
Income tax             1868.61
Provident fund         2100.00
Net pay               64717.45
Hourly rate: 201.92 Tk (integer division would give 201)
Tax status: taxable (gross above 50000)
```

### Solution
```java
import java.util.Scanner;

public class Payslip {
    public static void main(String[] args) {
        final double HOUSE_RENT_RATE = 0.45;
        final double MEDICAL_RATE = 0.10;
        final double MEDICAL_CAP = 2500.0;
        final double CONVEYANCE = 1500.0;
        final int WORK_HOURS_PER_MONTH = 208;
        final double OVERTIME_FACTOR = 1.5;
        final double TAX_FREE_LIMIT = 50000.0;
        final double TAX_RATE = 0.10;
        final double PF_RATE = 0.05;
        Scanner in = new Scanner(System.in);

        String name = in.nextLine();
        int basic = in.nextInt();
        double overtimeHours = in.nextDouble();

        double houseRent = basic * HOUSE_RENT_RATE;
        double medical = Math.min(basic * MEDICAL_RATE, MEDICAL_CAP);
        double hourlyRate = (double) basic / WORK_HOURS_PER_MONTH;
        int wrongHourlyRate = basic / WORK_HOURS_PER_MONTH;
        double overtimePay = overtimeHours * hourlyRate * OVERTIME_FACTOR;

        double gross = basic + houseRent + medical + CONVEYANCE + overtimePay;
        double tax = Math.max(gross - TAX_FREE_LIMIT, 0) * TAX_RATE;
        double providentFund = basic * PF_RATE;
        double net = gross - tax - providentFund;

        String overtimeLabel = String.format("Overtime (%.1f h)", overtimeHours);
        String row = "%-20s%10.2f%n";

        System.out.println("Payslip: " + name.toUpperCase());
        System.out.printf(row, "Basic salary", (double) basic);
        System.out.printf(row, "House rent (45%)", houseRent);
        System.out.printf(row, "Medical (max 2500)", medical);
        System.out.printf(row, "Conveyance", CONVEYANCE);
        System.out.printf(row, overtimeLabel, overtimePay);
        System.out.printf(row, "Gross pay", gross);
        System.out.printf(row, "Income tax", tax);
        System.out.printf(row, "Provident fund", providentFund);
        System.out.printf(row, "Net pay", net);
        System.out.printf("Hourly rate: %.2f Tk (integer division would give %d)%n",
                hourlyRate, wrongHourlyRate);

        if (gross > TAX_FREE_LIMIT) {
            System.out.println("Tax status: taxable (gross above 50000)");
        } else {
            System.out.println("Tax status: not taxable");
        }
    }
}
```

### Explanation
- The name is read first with `nextLine()`, then the numbers with `nextInt()` and
  `nextDouble()`. In this order there is no leftover-newline problem; reading the
  numbers first and the name after would need an extra `nextLine()`.
- `Math.min` applies the medical cap, and `Math.max(gross - 50000, 0)` makes the
  taxable part zero when the gross is below the limit, so no `if` is needed for the
  calculations.
- The hourly rate shows the integer division trap in a realistic place:
  `42000 / 208` is `201`, but the real rate is `201.92...`. Over 12.5 hours at 1.5×
  the difference is about 17 Tk of the employee's money.
- The format string is stored once in `row` and reused for every line, so all rows
  have the same layout. In `"House rent (45%)"` the `%` is inside a `%s` argument,
  not inside the format string, so it does not need to be written as `%%`.
- All amounts stay `double` until printing; `%10.2f` rounds only the display.

## Problem 15: Student ID Decoder
**Level:** Advanced

### Problem Statement
A (hypothetical) university writes student IDs as `DEPT-YYYY-T-NNNN`: a 3-letter
department code, the admission year, the admission trimester `T` (1, 2 or 3) and a
4-digit serial number, for example `CSE-2023-2-0157`. Students often type the ID in
lower case and with extra spaces.

Read one line, remove spaces at both ends and convert it to upper case. The ID is
**valid** when it has exactly 15 characters, `-` at indexes 3, 8 and 10, and a
trimester character between `1` and `3` (you may assume the year and serial parts are
digits whenever these checks pass).

For an invalid ID print
`Invalid ID: expected DEPT-YYYY-T-NNNN with T from 1 to 3`. For a valid ID print, as
in the sample: the cleaned ID, the department, the admission term, the serial as a
number, the expected graduation term after 12 trimesters (three trimesters per year;
the admission trimester counts as the first), and a username made of the department
in lower case, the last two digits of the year, the trimester and the 4-digit serial.

### Sample Input
```text
  cse-2023-2-0157
```

### Sample Output
```text
ID         : CSE-2023-2-0157
Department : CSE
Admitted   : trimester 2 of 2023
Serial no. : 157
Graduates  : trimester 1 of 2027 (after 12 trimesters)
Username   : cse2320157
```

### Solution
```java
import java.util.Scanner;

public class StudentIdDecoder {
    public static void main(String[] args) {
        final int ID_LENGTH = 15;
        final int TRIMESTERS_PER_YEAR = 3;
        final int PROGRAM_TRIMESTERS = 12;
        Scanner in = new Scanner(System.in);

        String id = in.nextLine().trim().toUpperCase();

        // && stops at the first false part, so charAt is only called
        // when the length is already known to be 15.
        boolean valid = id.length() == ID_LENGTH
                && id.charAt(3) == '-'
                && id.charAt(8) == '-'
                && id.charAt(10) == '-'
                && id.charAt(9) >= '1'
                && id.charAt(9) <= '3';

        if (valid) {
            String dept = id.substring(0, 3);
            int year = Integer.parseInt(id.substring(4, 8));
            int trimester = id.charAt(9) - '0';
            int serial = Integer.parseInt(id.substring(11));

            // Number every trimester since year 0, starting from 0.
            int startIndex = year * TRIMESTERS_PER_YEAR + (trimester - 1);
            int lastIndex = startIndex + PROGRAM_TRIMESTERS - 1;
            int gradYear = lastIndex / TRIMESTERS_PER_YEAR;
            int gradTrimester = lastIndex % TRIMESTERS_PER_YEAR + 1;

            String username = String.format("%s%02d%d%04d",
                    dept.toLowerCase(), year % 100, trimester, serial);

            System.out.println("ID         : " + id);
            System.out.println("Department : " + dept);
            System.out.println("Admitted   : trimester " + trimester + " of " + year);
            System.out.println("Serial no. : " + serial);
            System.out.println("Graduates  : trimester " + gradTrimester + " of "
                    + gradYear + " (after " + PROGRAM_TRIMESTERS + " trimesters)");
            System.out.println("Username   : " + username);
        } else {
            System.out.println("Invalid ID: expected DEPT-YYYY-T-NNNN with T from 1 to 3");
        }
    }
}
```

### Explanation
- `trim()` and `toUpperCase()` are chained: each returns a new `String`, and the next
  method is called on that result. The original input text is never changed.
- The validity check relies on **short-circuit** evaluation. For a short input such as
  `CSE-23`, `id.length() == 15` is `false`, so the `charAt` calls (which would throw
  `StringIndexOutOfBoundsException`) never run.
- Characters are numbers underneath: `'2' - '0'` is `2`, a quick way to turn one digit
  character into its value. Comparing `id.charAt(9) >= '1'` also works on the codes.
- `Integer.parseInt("0157")` gives `157`; `%04d` in `String.format` puts the zeros
  back for the username, and `%02d` keeps a year like 2005 as `05`.
- Graduation uses the `/` and `%` idea from time conversion: number the trimesters
  continuously (`year * 3 + (trimester - 1)`), add 11 to reach the 12th trimester,
  then split the number back into a year (`/ 3`) and a trimester (`% 3 + 1`).
  2023 trimester 2 plus 11 trimesters gives 2027 trimester 1.
