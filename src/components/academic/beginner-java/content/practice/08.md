# Practice Problems: Arrays, Object References and Collections

These problems move from array algorithms on primitive values to arrays and
`ArrayList`s of objects, aliasing, `null` handling and small management systems built
from cooperating classes. Programs read input without prompts and print exactly the
sample output.

## Problem 1: Canteen Weekly Sales
**Level:** Basic

### Problem Statement
The campus canteen records its sales (in Tk) for `n` days. Read `n` (at least 1) and
then `n` integers into an `int[]`. Print:

- `Total: <sum>`
- `Average: <average>` with 2 decimal places
- `Best day: <day> (<amount>)` for the day with the highest sales
- `Worst day: <day> (<amount>)` for the day with the lowest sales
- `Closed days: <count>` (days with sales `0`)

Days are numbered from 1. If two days tie for best or worst, report the earlier day.

### Sample Input
```text
7
4200 3850 0 5100 4975 5100 2300
```

### Sample Output
```text
Total: 25525
Average: 3646.43
Best day: 4 (5100)
Worst day: 3 (0)
Closed days: 1
```

### Solution
```java
import java.util.Scanner;

public class CanteenSales {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] sales = new int[n];
        for (int i = 0; i < n; i++) {
            sales[i] = in.nextInt();
        }

        int total = 0;
        int best = 0;      // index of the best day so far
        int worst = 0;     // index of the worst day so far
        int closed = 0;
        for (int i = 0; i < sales.length; i++) {
            total += sales[i];
            if (sales[i] > sales[best]) {
                best = i;
            }
            if (sales[i] < sales[worst]) {
                worst = i;
            }
            if (sales[i] == 0) {
                closed++;
            }
        }

        System.out.println("Total: " + total);
        System.out.printf("Average: %.2f%n", (double) total / n);
        System.out.println("Best day: " + (best + 1) + " (" + sales[best] + ")");
        System.out.println("Worst day: " + (worst + 1) + " (" + sales[worst] + ")");
        System.out.println("Closed days: " + closed);
    }
}
```

### Explanation
The array size comes from the input, so `new int[n]` is created after reading `n`.
One loop computes everything. Instead of remembering the best *amount*, the loop
remembers the best *index*, which gives both the day number (`best + 1`) and the
amount (`sales[best]`). Using strict `>` and `<` keeps the earlier day when values tie.
The `(double)` cast avoids integer division in the average.

## Problem 2: Shuttle Route Return Trip
**Level:** Basic

### Problem Statement
A campus shuttle visits `n` stops, given by their stop numbers. On the return trip it
visits them in reverse order. Write two static methods:

- `int[] reversedCopy(int[] stops)` returns a **new** array in reverse order and leaves
  `stops` unchanged;
- `void reverseInPlace(int[] stops)` reverses the given array itself by swapping.

Read `n` and the `n` stop numbers. Print the route, the reversed copy, the route again
(to show it is unchanged), then create a second variable `route` that refers to the
same array (`int[] route = stops;`), call `reverseInPlace(route)`, and print `stops`.
Use `Arrays.toString` and the labels shown.

### Sample Input
```text
5
11 24 7 39 15
```

### Sample Output
```text
Route         : [11, 24, 7, 39, 15]
Reversed copy : [15, 39, 7, 24, 11]
Route again   : [11, 24, 7, 39, 15]
After in-place: [15, 39, 7, 24, 11]
```

### Solution
```java
import java.util.Arrays;
import java.util.Scanner;

public class ShuttleReturn {
    static int[] reversedCopy(int[] stops) {
        int[] result = new int[stops.length];
        for (int i = 0; i < stops.length; i++) {
            result[i] = stops[stops.length - 1 - i];
        }
        return result;
    }

    static void reverseInPlace(int[] stops) {
        int left = 0;
        int right = stops.length - 1;
        while (left < right) {
            int temp = stops[left];
            stops[left] = stops[right];
            stops[right] = temp;
            left++;
            right--;
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] stops = new int[n];
        for (int i = 0; i < n; i++) {
            stops[i] = in.nextInt();
        }
        System.out.println("Route         : " + Arrays.toString(stops));
        System.out.println("Reversed copy : " + Arrays.toString(reversedCopy(stops)));
        System.out.println("Route again   : " + Arrays.toString(stops));

        int[] route = stops;          // alias: the same array
        reverseInPlace(route);
        System.out.println("After in-place: " + Arrays.toString(stops));
    }
}
```

### Explanation
- `reversedCopy` creates its own array with `new` and returns a reference to it, so the
  caller's array is never touched.
- `reverseInPlace` receives a copy of the reference, which still reaches the caller's
  array, so its swaps are visible after the call.
- `int[] route = stops;` copies only the reference. Reversing `route` therefore
  reverses `stops` too, which is why the last line prints the reversed route.
- The two-index swap stops when `left` meets `right`, so the middle element of an odd
  length array stays in place.

## Problem 3: Dice Roll Frequency
**Level:** Basic

### Problem Statement
In a board game club, a player records `n` dice rolls. Read `n` and then `n` integers.
Values from 1 to 6 are valid; any other value is a recording mistake. Count each face
using an array whose index is the face value. Print one line per face, `<face>: <count>`
followed by a space and `count` stars when the count is greater than 0. Then print
`Invalid: <count>` and `Most frequent: <face>` (the smallest face if several tie; if
there were no valid rolls, print `Most frequent: none`).

### Sample Input
```text
12
3 6 1 6 2 6 5 3 7 1 6 0
```

### Sample Output
```text
1: 2 **
2: 1 *
3: 2 **
4: 0
5: 1 *
6: 4 ****
Invalid: 2
Most frequent: 6
```

### Solution
```java
import java.util.Scanner;

public class DiceFrequency {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int[] count = new int[7];      // index 0 unused; 1..6 are faces
        int invalid = 0;
        for (int i = 0; i < n; i++) {
            int roll = in.nextInt();
            if (roll >= 1 && roll <= 6) {
                count[roll]++;
            } else {
                invalid++;
            }
        }

        int most = 1;
        for (int face = 1; face <= 6; face++) {
            String line = face + ": " + count[face];
            if (count[face] > 0) {
                line += " " + "*".repeat(count[face]);
            }
            System.out.println(line);
            if (count[face] > count[most]) {
                most = face;
            }
        }
        System.out.println("Invalid: " + invalid);
        if (count[most] == 0) {
            System.out.println("Most frequent: none");
        } else {
            System.out.println("Most frequent: " + most);
        }
    }
}
```

### Explanation
The value itself is used as the index: `count[roll]++` finds the right counter in one
step, with no `if` chain for six faces. The array has 7 elements so that indexes 1 to
6 exist (index 0 is simply unused). The range check comes **before** the array access;
without it, a roll of 7 would throw `ArrayIndexOutOfBoundsException`. `String.repeat`
(Java 11+) builds the bar of stars, and stars are added only for counts above zero so
no line ends with a stray space.

## Problem 4: Shop Sales Table
**Level:** Basic

### Problem Statement
A market committee records the daily sales of `s` shops over `d` days in a 2D array.
Read `s` and `d`, then `s` lines of `d` integers (row = shop, column = day). Print each
shop's row followed by its total, then a `Day` row with the column totals and the grand
total, then the best shop. Use `printf` with `%6d` for each number, as in the sample
(`Shop <i>:` labels, `|` before the total). If two shops have the same total, the
earlier shop is the best.

### Sample Input
```text
3 4
1200 900 1500 800
700 1100 600 1300
1500 1400 1000 900
```

### Sample Output
```text
Shop 1:  1200   900  1500   800 |  4400
Shop 2:   700  1100   600  1300 |  3700
Shop 3:  1500  1400  1000   900 |  4800
Day   :  3400  3400  3100  3000 | 12900
Best shop: 3 (4800)
```

### Solution
```java
import java.util.Scanner;

public class ShopSalesTable {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int shops = in.nextInt();
        int days = in.nextInt();
        int[][] sales = new int[shops][days];
        for (int r = 0; r < shops; r++) {
            for (int c = 0; c < days; c++) {
                sales[r][c] = in.nextInt();
            }
        }

        int[] dayTotal = new int[days];
        int grand = 0;
        int bestShop = 0;
        int bestTotal = -1;
        for (int r = 0; r < sales.length; r++) {
            int rowTotal = 0;
            System.out.print("Shop " + (r + 1) + ":");
            for (int c = 0; c < sales[r].length; c++) {
                System.out.printf("%6d", sales[r][c]);
                rowTotal += sales[r][c];
                dayTotal[c] += sales[r][c];
            }
            System.out.printf(" | %5d%n", rowTotal);
            grand += rowTotal;
            if (rowTotal > bestTotal) {
                bestTotal = rowTotal;
                bestShop = r + 1;
            }
        }

        System.out.print("Day   :");
        for (int total : dayTotal) {
            System.out.printf("%6d", total);
        }
        System.out.printf(" | %5d%n", grand);
        System.out.println("Best shop: " + bestShop + " (" + bestTotal + ")");
    }
}
```

### Explanation
`sales[r][c]` is "shop `r`, day `c`". Row totals are computed while printing each row,
and column totals are collected at the same time in a separate 1D array `dayTotal`,
whose elements start at `0` by default. `sales.length` is the number of rows and
`sales[r].length` the number of columns in row `r`. Both the row totals and the column
totals add up to the same grand total, which is a useful self-check.

## Problem 5: Rotating the Shuttle Start Stop
**Level:** Basic

### Problem Statement
The shuttle's list of `n` stop names is circular: after the last stop it returns to
the first. To start the route `k` stops later, every stop moves `k` places to the left
(wrapping around). Write a static method `String[] rotateLeft(String[] stops, int k)`
that returns a new rotated array; `k` may be larger than `n` or `0`.

Read `n`, then `n` single-word stop names, then `k`. Print the original array, the
rotated array (both with `Arrays.toString`), and `Starts at: <first stop of rotated>`.

### Sample Input
```text
5
Gate Library Canteen Hostel Lab
7
```

### Sample Output
```text
Original: [Gate, Library, Canteen, Hostel, Lab]
Rotated : [Canteen, Hostel, Lab, Gate, Library]
Starts at: Canteen
```

### Solution
```java
import java.util.Arrays;
import java.util.Scanner;

public class RotateStops {
    static String[] rotateLeft(String[] stops, int k) {
        int n = stops.length;
        String[] result = new String[n];
        for (int i = 0; i < n; i++) {
            result[i] = stops[(i + k) % n];
        }
        return result;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        String[] stops = new String[n];
        for (int i = 0; i < n; i++) {
            stops[i] = in.next();
        }
        int k = in.nextInt();

        String[] rotated = rotateLeft(stops, k);
        System.out.println("Original: " + Arrays.toString(stops));
        System.out.println("Rotated : " + Arrays.toString(rotated));
        System.out.println("Starts at: " + rotated[0]);
    }
}
```

### Explanation
Position `i` of the rotated array takes the stop that was `k` places further on, which
is index `(i + k) % n`. The `%` makes the index wrap around, so `k = 7` with 5 stops
behaves like `k = 2`, and `k = 0` gives an identical copy. The method builds a new
array instead of moving elements in place, so the original order is still available
afterwards. A `String[]` holds references to `String` objects, but since strings are
immutable, sharing them between the two arrays is safe.

## Problem 6: CGPA Probation List
**Level:** Intermediate

### Problem Statement
Write a class `Student` with private fields `id` (int), `name` and `cgpa` (double), a
constructor, getters and a method `boolean onProbation()` that is `true` when the CGPA
is below 2.50.

Read `n`, then `n` lines `id name cgpa` into a `Student[]`, then one more id to look
up. Print:

- `Class average: <avg>` (2 decimals)
- `Topper: <id> <name> (<cgpa>)` (the first one in input order if tied)
- `Probation:` followed by one line `  <id> <name> (<cgpa>)` per student on probation
  in input order, or `  none`
- `Lookup <id>: <name> (<cgpa>)` or `Lookup <id>: not found`

Write a static method `Student findById(Student[] list, int id)` that returns the
student or `null`. CGPAs are printed with 2 decimals.

### Sample Input
```text
6
2101 Rahim 3.45
2102 Karim 2.10
2103 Nusrat 3.90
2104 Fahim 2.49
2105 Mitu 3.90
2106 Imran 2.50
2105
```

### Sample Output
```text
Class average: 3.06
Topper: 2103 Nusrat (3.90)
Probation:
  2102 Karim (2.10)
  2104 Fahim (2.49)
Lookup 2105: Mitu (3.90)
```

### Solution
```java
import java.util.Scanner;

class Student {
    private final int id;
    private final String name;
    private final double cgpa;

    Student(int id, String name, double cgpa) {
        this.id = id;
        this.name = name;
        this.cgpa = cgpa;
    }

    int getId() {
        return id;
    }

    String getName() {
        return name;
    }

    double getCgpa() {
        return cgpa;
    }

    boolean onProbation() {
        return cgpa < 2.50;
    }
}

public class ProbationList {
    static Student findById(Student[] list, int id) {
        for (Student s : list) {
            if (s.getId() == id) {
                return s;
            }
        }
        return null;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        Student[] list = new Student[n];
        double sum = 0;
        for (int i = 0; i < n; i++) {
            list[i] = new Student(in.nextInt(), in.next(), in.nextDouble());
            sum += list[i].getCgpa();
        }
        int query = in.nextInt();

        Student top = list[0];
        for (Student s : list) {
            if (s.getCgpa() > top.getCgpa()) {
                top = s;
            }
        }
        System.out.printf("Class average: %.2f%n", sum / n);
        System.out.printf("Topper: %d %s (%.2f)%n", top.getId(), top.getName(), top.getCgpa());

        System.out.println("Probation:");
        int count = 0;
        for (Student s : list) {
            if (s.onProbation()) {
                System.out.printf("  %d %s (%.2f)%n", s.getId(), s.getName(), s.getCgpa());
                count++;
            }
        }
        if (count == 0) {
            System.out.println("  none");
        }

        Student found = findById(list, query);
        if (found == null) {
            System.out.println("Lookup " + query + ": not found");
        } else {
            System.out.printf("Lookup %d: %s (%.2f)%n", query, found.getName(), found.getCgpa());
        }
    }
}
```

### Explanation
- Every slot of the array is filled before it is used, so no `null` checks are needed
  inside the loops.
- `top` is a reference variable: assigning `top = s` does not copy a student, it just
  remembers which object is best so far.
- The probation rule lives in `Student.onProbation()`, so `main` asks the object instead
  of repeating `cgpa < 2.50` (Imran's 2.50 is not below the limit).
- `findById` returns `null` for "not found"; `main` checks that before calling
  `getName()`, which avoids a `NullPointerException`.

## Problem 7: Wallet Alias Simulator
**Level:** Intermediate

### Problem Statement
Turn aliasing puzzles into a program. There are three reference variables `A`, `B`
and `C`, stored as `Wallet[] vars = new Wallet[3]`, all `null` at the start. A
`Wallet` holds a balance (int Tk) with `getBalance()` and `add(int amount)`.

Read `n` commands:

- `NEW X amount` — `X` refers to a new wallet with that balance
- `POINT X Y` — `X = Y` (X refers to the same object as Y, or to `null`)
- `COPY X Y` — `X` refers to a new wallet with Y's current balance; if `Y` is `null`,
  print `Y is null` and do nothing
- `ADD X amount` — add to the wallet `X` refers to; if `X` is `null`, print `X is null`
- `NULL X` — `X = null`
- `SAME X Y` — print `X == Y: true` or `X == Y: false`

Afterwards print `A: <balance>` (or `A: null`), the same for `B` and `C`, and
`Distinct wallets: <k>`: how many different wallet objects the three variables refer
to. (`X` and `Y` stand for the letters used in the command.)

### Sample Input
```text
10
NEW A 100
POINT B A
ADD B 50
COPY C A
ADD C 25
SAME A B
SAME A C
NULL A
ADD A 10
POINT A C
```

### Sample Output
```text
A == B: true
A == C: false
A is null
A: 175
B: 150
C: 175
Distinct wallets: 2
```

### Solution
```java
import java.util.Scanner;

class Wallet {
    private int balance;

    Wallet(int balance) {
        this.balance = balance;
    }

    int getBalance() {
        return balance;
    }

    void add(int amount) {
        balance += amount;
    }
}

public class AliasSimulator {
    static final String[] NAMES = {"A", "B", "C"};

    static int slot(String name) {
        return name.charAt(0) - 'A';
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Wallet[] vars = new Wallet[3];
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String cmd = in.next();
            int x = slot(in.next());
            if (cmd.equals("NEW")) {
                vars[x] = new Wallet(in.nextInt());
            } else if (cmd.equals("POINT")) {
                vars[x] = vars[slot(in.next())];
            } else if (cmd.equals("COPY")) {
                int y = slot(in.next());
                if (vars[y] == null) {
                    System.out.println(NAMES[y] + " is null");
                } else {
                    vars[x] = new Wallet(vars[y].getBalance());
                }
            } else if (cmd.equals("ADD")) {
                int amount = in.nextInt();
                if (vars[x] == null) {
                    System.out.println(NAMES[x] + " is null");
                } else {
                    vars[x].add(amount);
                }
            } else if (cmd.equals("NULL")) {
                vars[x] = null;
            } else if (cmd.equals("SAME")) {
                int y = slot(in.next());
                System.out.println(NAMES[x] + " == " + NAMES[y] + ": " + (vars[x] == vars[y]));
            }
        }

        int distinct = 0;
        for (int i = 0; i < vars.length; i++) {
            if (vars[i] == null) {
                System.out.println(NAMES[i] + ": null");
                continue;
            }
            System.out.println(NAMES[i] + ": " + vars[i].getBalance());
            boolean seenBefore = false;
            for (int j = 0; j < i; j++) {
                if (vars[j] == vars[i]) {
                    seenBefore = true;
                }
            }
            if (!seenBefore) {
                distinct++;
            }
        }
        System.out.println("Distinct wallets: " + distinct);
    }
}
```

### Explanation
- `POINT` copies a reference (`vars[x] = vars[y]`), creating an alias, while `COPY`
  calls `new`, creating an independent object. That is the whole difference between
  "same object" and "equal value".
- After `POINT B A`, adding 50 through `B` also changes what `A` sees. After `COPY C A`,
  adding 25 to `C` changes only `C`.
- `NULL A` does not destroy the wallet: `B` still refers to it, so its 150 Tk survives.
- Each command checks for `null` before calling a method, so the program never throws a
  `NullPointerException`.
- Counting distinct objects uses `==` (identity): a wallet is counted only if no earlier
  variable refers to the very same object.

## Problem 8: Course Registration List
**Level:** Intermediate

### Problem Statement
During course registration a student adds and drops courses. Write a class `Course`
with a code and a credit value. Keep the registered courses in an
`ArrayList<Course>`. The credit limit is 15 (`static final`).

Read `n` commands:

- `ADD <code> <credits>` — print `Added <code>. Total credits: <t>`; refuse with
  `Refused <code>: already registered` if the code is already in the list, or
  `Refused <code>: limit is 15 credits` if the new total would exceed 15
- `DROP <code>` — print `Dropped <code>. Total credits: <t>`, or
  `Refused <code>: not registered`

At the end print `Registered courses:`, one line `  <code> (<credits>)` per course in
registration order, and `Total credits: <t>`. Write a static method
`int indexOf(ArrayList<Course> list, String code)` that returns the position or `-1`.

### Sample Input
```text
10
ADD CSE1115 3
ADD MATH2183 3
ADD CSE1116 1
ADD CSE1115 3
ADD PHY1101 3
ADD CSE2215 3
ADD ENG1011 3
DROP CSE1116
DROP BIO1000
ADD ENG1011 3
```

### Sample Output
```text
Added CSE1115. Total credits: 3
Added MATH2183. Total credits: 6
Added CSE1116. Total credits: 7
Refused CSE1115: already registered
Added PHY1101. Total credits: 10
Added CSE2215. Total credits: 13
Refused ENG1011: limit is 15 credits
Dropped CSE1116. Total credits: 12
Refused BIO1000: not registered
Added ENG1011. Total credits: 15
Registered courses:
  CSE1115 (3)
  MATH2183 (3)
  PHY1101 (3)
  CSE2215 (3)
  ENG1011 (3)
Total credits: 15
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Course {
    private final String code;
    private final int credits;

    Course(String code, int credits) {
        this.code = code;
        this.credits = credits;
    }

    String getCode() {
        return code;
    }

    int getCredits() {
        return credits;
    }
}

public class CourseRegistration {
    static final int MAX_CREDITS = 15;

    static int indexOf(ArrayList<Course> list, String code) {
        for (int i = 0; i < list.size(); i++) {
            if (list.get(i).getCode().equals(code)) {
                return i;
            }
        }
        return -1;
    }

    static int totalCredits(ArrayList<Course> list) {
        int total = 0;
        for (Course c : list) {
            total += c.getCredits();
        }
        return total;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        ArrayList<Course> courses = new ArrayList<>();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String cmd = in.next();
            String code = in.next();
            int pos = indexOf(courses, code);
            if (cmd.equals("ADD")) {
                int credits = in.nextInt();
                if (pos >= 0) {
                    System.out.println("Refused " + code + ": already registered");
                } else if (totalCredits(courses) + credits > MAX_CREDITS) {
                    System.out.println("Refused " + code + ": limit is "
                            + MAX_CREDITS + " credits");
                } else {
                    courses.add(new Course(code, credits));
                    System.out.println("Added " + code + ". Total credits: "
                            + totalCredits(courses));
                }
            } else if (pos < 0) {
                System.out.println("Refused " + code + ": not registered");
            } else {
                courses.remove(pos);
                System.out.println("Dropped " + code + ". Total credits: "
                        + totalCredits(courses));
            }
        }
        System.out.println("Registered courses:");
        for (Course c : courses) {
            System.out.println("  " + c.getCode() + " (" + c.getCredits() + ")");
        }
        System.out.println("Total credits: " + totalCredits(courses));
    }
}
```

### Explanation
- The list grows and shrinks with `add` and `remove(index)`, which an array cannot do.
- `courses.contains(new Course(code, 3))` would not work: `Course` has no custom
  `equals`, so `contains` would look for that exact new object and never find it.
  Searching by the `code` field with a loop is the correct approach for now.
- `indexOf` returns a position, which is exactly what `remove(int)` needs, and `-1`
  is a clear "not found" value.
- The total is recomputed from the list each time, so it can never drift out of sync
  with the courses actually registered. The ADD command reads its credits even when it
  is refused, so the input stays in step.

## Problem 9: Payroll Ranking
**Level:** Intermediate

### Problem Statement
Write a class `Employee` with a name, a department and a monthly salary (int Tk). Read
`n` employees (`name department salary`) into an `Employee[]`. Sort the array with a
selection sort written by you: highest salary first, and for equal salaries
alphabetical order of name (use `compareTo`). Print the ranking as
`<rank>. <name> (<department>) <salary>`.

Then read one department name and print `Department <dept>:` followed by its employees
in the sorted order as `  <name> <salary>`, or `  none`.

### Sample Input
```text
6
Rahim Sales 42000
Ayesha IT 55000
Karim IT 42000
Sadia HR 38000
Arif Sales 55000
Tanvir HR 42000
IT
```

### Sample Output
```text
1. Arif (Sales) 55000
2. Ayesha (IT) 55000
3. Karim (IT) 42000
4. Rahim (Sales) 42000
5. Tanvir (HR) 42000
6. Sadia (HR) 38000
Department IT:
  Ayesha 55000
  Karim 42000
```

### Solution
```java
import java.util.Scanner;

class Employee {
    private final String name;
    private final String department;
    private final int salary;

    Employee(String name, String department, int salary) {
        this.name = name;
        this.department = department;
        this.salary = salary;
    }

    String getName() {
        return name;
    }

    String getDepartment() {
        return department;
    }

    int getSalary() {
        return salary;
    }

    /** true when this employee should come before other in the ranking. */
    boolean ranksBefore(Employee other) {
        if (salary != other.salary) {
            return salary > other.salary;
        }
        return name.compareTo(other.name) < 0;
    }
}

public class PayrollRanking {
    static void sort(Employee[] staff) {
        for (int i = 0; i < staff.length - 1; i++) {
            int best = i;
            for (int j = i + 1; j < staff.length; j++) {
                if (staff[j].ranksBefore(staff[best])) {
                    best = j;
                }
            }
            Employee temp = staff[i];
            staff[i] = staff[best];
            staff[best] = temp;
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        Employee[] staff = new Employee[n];
        for (int i = 0; i < n; i++) {
            staff[i] = new Employee(in.next(), in.next(), in.nextInt());
        }
        String dept = in.next();

        sort(staff);
        for (int i = 0; i < staff.length; i++) {
            Employee e = staff[i];
            System.out.println((i + 1) + ". " + e.getName() + " ("
                    + e.getDepartment() + ") " + e.getSalary());
        }

        System.out.println("Department " + dept + ":");
        boolean any = false;
        for (Employee e : staff) {
            if (e.getDepartment().equals(dept)) {
                System.out.println("  " + e.getName() + " " + e.getSalary());
                any = true;
            }
        }
        if (!any) {
            System.out.println("  none");
        }
    }
}
```

### Explanation
- The ordering rule is in one method, `ranksBefore`, so the sort itself stays a plain
  selection sort. Inside `Employee`, the method may read `other.salary` directly because
  `private` means private to the class, not to the object.
- `name.compareTo(other.name) < 0` means "this name comes first alphabetically".
- The swap moves **references** inside the array; no `Employee` object is copied or
  changed.
- Filtering by department after sorting keeps the filtered list in ranking order for
  free. Department names are compared with `equals`, never `==`.

## Problem 10: Stationery Cart
**Level:** Intermediate

### Problem Statement
A campus stationery shop keeps a cart as an `ArrayList<CartItem>`. A `CartItem` has a
name, a unit price (int Tk) and a quantity, with methods `changeQuantity(int delta)`
and `subtotal()`.

Read `n` lines `name quantity price`:

- If an item with that name is already in the cart, change its quantity by `quantity`
  (which may be negative). If the quantity becomes 0 or less, remove the item and print
  `Removed <name>`. The price of an existing item does not change.
- If the item is not in the cart and `quantity` is positive, add a new item.
- If the item is not in the cart and `quantity` is 0 or negative, print
  `Cannot remove <name>: not in cart`.

Finally print `Cart:`, one line `  <name> x<qty> @ <price> = <subtotal>` per item in
the order they were first added, `Items: <count>` and `Total: Tk <total>`. Write a
static method `CartItem find(ArrayList<CartItem> cart, String name)` that returns the
item or `null`.

### Sample Input
```text
8
Notebook 3 60
Pen 5 15
Notebook 2 60
Marker 2 45
Pen -5 15
Ruler -1 20
Eraser 1 10
Marker -1 45
```

### Sample Output
```text
Removed Pen
Cannot remove Ruler: not in cart
Cart:
  Notebook x5 @ 60 = 300
  Marker x1 @ 45 = 45
  Eraser x1 @ 10 = 10
Items: 3
Total: Tk 355
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class CartItem {
    private final String name;
    private final int price;
    private int quantity;

    CartItem(String name, int quantity, int price) {
        this.name = name;
        this.quantity = quantity;
        this.price = price;
    }

    String getName() {
        return name;
    }

    int getQuantity() {
        return quantity;
    }

    void changeQuantity(int delta) {
        quantity += delta;
    }

    int subtotal() {
        return quantity * price;
    }

    String describe() {
        return name + " x" + quantity + " @ " + price + " = " + subtotal();
    }
}

public class StationeryCart {
    static CartItem find(ArrayList<CartItem> cart, String name) {
        for (CartItem item : cart) {
            if (item.getName().equals(name)) {
                return item;
            }
        }
        return null;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        ArrayList<CartItem> cart = new ArrayList<>();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String name = in.next();
            int quantity = in.nextInt();
            int price = in.nextInt();
            CartItem item = find(cart, name);
            if (item != null) {
                item.changeQuantity(quantity);     // changes the object in the list
                if (item.getQuantity() <= 0) {
                    cart.remove(item);
                    System.out.println("Removed " + name);
                }
            } else if (quantity > 0) {
                cart.add(new CartItem(name, quantity, price));
            } else {
                System.out.println("Cannot remove " + name + ": not in cart");
            }
        }

        System.out.println("Cart:");
        int total = 0;
        for (CartItem item : cart) {
            System.out.println("  " + item.describe());
            total += item.subtotal();
        }
        System.out.println("Items: " + cart.size());
        System.out.println("Total: Tk " + total);
    }
}
```

### Explanation
- `find` returns a reference to the object **inside** the list. Calling
  `item.changeQuantity(...)` on that reference changes the item in the cart; there is
  no need to put it back with `set`.
- `cart.remove(item)` removes by object. Without a custom `equals` it compares
  identities, and here that is exactly right, because `item` is the very object stored
  in the list.
- Removing happens outside any for-each loop over `cart`, so there is no
  `ConcurrentModificationException`.
- `ArrayList` keeps insertion order, so the receipt lists items in the order they were
  first added.

## Problem 11: Library Loans With Linked Objects
**Level:** Advanced

### Problem Statement
Build a small library system with three classes:

- `Member`: a name and an `ArrayList<Book>` of borrowed books (at most 2).
- `Book`: an id, a title, and a `Member borrower` reference that is `null` when the
  book is available.
- `Library`: lists of books and members, `findBook(id)` and `findMember(name)` that
  return `null` when not found, and the borrow/return rules.

Read `n` commands:

- `MEMBER <name>` and `BOOK <id> <title>` (the title is the rest of the line) add data
  and print nothing.
- `BORROW <name> <id>` prints `<name> borrowed <title>`, or the first failing rule:
  `No member <name>`, `No book <id>`, `<title> is on loan to <borrower>`,
  `<name> has reached the limit of 2 books`.
- `RETURN <id>` prints `<borrower> returned <title>`, or `No book <id>`, or
  `<title> is not on loan`.
- `REPORT` prints `Books:` with `  <id> <title> - on loan to <name>` or
  `  <id> <title> - available` for every book, then `Members:` with
  `  <name>: <titles joined by ", ">` or `  <name>: none`.

### Sample Input
```text
14
MEMBER Rahim
MEMBER Nusrat
BOOK 101 Clean Code
BOOK 102 Head First Java
BOOK 103 Discrete Mathematics
BORROW Rahim 101
BORROW Nusrat 101
BORROW Rahim 102
BORROW Rahim 103
BORROW Tanvir 103
RETURN 101
RETURN 101
BORROW Nusrat 101
REPORT
```

### Sample Output
```text

Clean Code is on loan to Rahim
Rahim borrowed Head First Java
Rahim has reached the limit of 2 books
No member Tanvir
Rahim returned Clean Code
Clean Code is not on loan
Nusrat borrowed Clean Code
Books:
  101 Clean Code - on loan to Nusrat
  102 Head First Java - on loan to Rahim
  103 Discrete Mathematics - available
Members:
  Rahim: Head First Java
  Nusrat: Clean Code
```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Member {
    static final int LIMIT = 2;
    private final String name;
    private final ArrayList<Book> loans = new ArrayList<>();

    Member(String name) {
        this.name = name;
    }

    String getName() {
        return name;
    }

    ArrayList<Book> getLoans() {
        return loans;
    }

    boolean canBorrow() {
        return loans.size() < LIMIT;
    }
}

class Book {
    private final int id;
    private final String title;
    private Member borrower;          // null while the book is on the shelf

    Book(int id, String title) {
        this.id = id;
        this.title = title;
    }

    int getId() {
        return id;
    }

    String getTitle() {
        return title;
    }

    Member getBorrower() {
        return borrower;
    }

    void setBorrower(Member borrower) {
        this.borrower = borrower;
    }
}

class Library {
    private final ArrayList<Book> books = new ArrayList<>();
    private final ArrayList<Member> members = new ArrayList<>();

    void addBook(int id, String title) {
        books.add(new Book(id, title));
    }

    void addMember(String name) {
        members.add(new Member(name));
    }

    Book findBook(int id) {
        for (Book b : books) {
            if (b.getId() == id) {
                return b;
            }
        }
        return null;
    }

    Member findMember(String name) {
        for (Member m : members) {
            if (m.getName().equals(name)) {
                return m;
            }
        }
        return null;
    }

    String borrow(String name, int id) {
        Member m = findMember(name);
        Book b = findBook(id);
        if (m == null) {
            return "No member " + name;
        }
        if (b == null) {
            return "No book " + id;
        }
        if (b.getBorrower() != null) {
            return b.getTitle() + " is on loan to " + b.getBorrower().getName();
        }
        if (!m.canBorrow()) {
            return name + " has reached the limit of " + Member.LIMIT + " books";
        }
        b.setBorrower(m);                 // book -> member
        m.getLoans().add(b);              // member -> book
        return name + " borrowed " + b.getTitle();
    }

    String giveBack(int id) {
        Book b = findBook(id);
        if (b == null) {
            return "No book " + id;
        }
        Member m = b.getBorrower();
        if (m == null) {
            return b.getTitle() + " is not on loan";
        }
        m.getLoans().remove(b);           // removes this exact Book object
        b.setBorrower(null);
        return m.getName() + " returned " + b.getTitle();
    }

    void report() {
        System.out.println("Books:");
        for (Book b : books) {
            String state = b.getBorrower() == null
                    ? "available" : "on loan to " + b.getBorrower().getName();
            System.out.println("  " + b.getId() + " " + b.getTitle() + " - " + state);
        }
        System.out.println("Members:");
        for (Member m : members) {
            String titles = "";
            for (Book b : m.getLoans()) {
                titles += titles.isEmpty() ? b.getTitle() : ", " + b.getTitle();
            }
            System.out.println("  " + m.getName() + ": " + (titles.isEmpty() ? "none" : titles));
        }
    }
}

public class LibraryLoansSystem {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Library library = new Library();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String cmd = in.next();
            if (cmd.equals("MEMBER")) {
                library.addMember(in.next());
            } else if (cmd.equals("BOOK")) {
                int id = in.nextInt();
                library.addBook(id, in.nextLine().trim());
            } else if (cmd.equals("BORROW")) {
                String name = in.next();
                System.out.println(library.borrow(name, in.nextInt()));
            } else if (cmd.equals("RETURN")) {
                System.out.println(library.giveBack(in.nextInt()));
            } else if (cmd.equals("REPORT")) {
                library.report();
            }
        }
    }
}
```

### Explanation
- The two objects refer to each other: a `Book` knows its `borrower`, and a `Member`
  keeps references to its books. Both links are changed together in `borrow` and
  `giveBack`, so they always agree.
- `borrower == null` is the natural "available" state. Every place that follows the
  reference (`getBorrower().getName()`) checks for `null` first.
- `findBook` and `findMember` return references to the stored objects, so changes made
  through them are changes to the library's data, not to copies.
- `m.getLoans().remove(b)` uses `remove(Object)`. `Book` has no custom `equals`, so the
  list removes the element that is the very same object as `b` — exactly the book being
  returned.
- `BOOK` reads the id with `nextInt()` and the title with `nextLine()`, which returns
  the rest of the same line (with a leading space removed by `trim()`).

## Problem 12: Hostel Room Allocation
**Level:** Advanced

### Problem Statement
A hostel office allocates beds. Write these classes:

- `Resident`: a name and a `Room room` reference (`null` while the resident has no bed).
- `Room`: a number and a `Resident[] beds` array whose size is the room's capacity;
  an empty bed is `null`.
- `Hostel`: an `ArrayList<Room>`, an `ArrayList<Resident>`, and the commands below.

Read `n` commands:

- `ROOM <number> <capacity>` creates a room (no output).
- `ALLOC <name> <room>`: put the resident in the first empty bed and print
  `<name> -> room <r>, bed <b>` (beds are numbered from 1). Errors, checked in this
  order: `<name> already in room <r>`, `No room <r>`, `Room <r> is full`.
- `MOVE <name> <room>`: move a resident who has a bed to the first empty bed of another
  room and print `<name> moved to room <r>, bed <b>`. Errors in order:
  `<name> has no bed`, `No room <r>`, `<name> is already in room <r>`,
  `Room <r> is full` (the resident then keeps the old bed).
- `VACATE <name>`: free the bed, print `<name> left room <r>`, or `<name> has no bed`.
- `REPORT`: one line per room in creation order,
  `Room <r>: <names or - for empty beds, separated by ", ">`, then
  `Free beds: <count>`.

The same `Resident` object must be moved, never re-created.

### Sample Input
```text
14
ROOM 201 2
ROOM 202 3
ALLOC Rahim 201
ALLOC Karim 201
ALLOC Fahim 201
ALLOC Fahim 202
ALLOC Rahim 202
ALLOC Imran 203
MOVE Karim 202
ALLOC Imran 201
VACATE Fahim
VACATE Sadia
MOVE Rahim 201
REPORT
```

### Sample Output
```text

Karim -> room 201, bed 2
Room 201 is full
Fahim -> room 202, bed 1
Rahim already in room 201
No room 203
Karim moved to room 202, bed 2
Imran -> room 201, bed 2
Fahim left room 202
Sadia has no bed
Rahim is already in room 201

Room 202: -, Karim, -

```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Resident {
    private final String name;
    private Room room;                     // null = no bed

    Resident(String name) {
        this.name = name;
    }

    String getName() {
        return name;
    }

    Room getRoom() {
        return room;
    }

    void setRoom(Room room) {
        this.room = room;
    }
}

class Room {
    private final int number;
    private final Resident[] beds;

    Room(int number, int capacity) {
        this.number = number;
        this.beds = new Resident[capacity];   // all beds empty (null)
    }

    int getNumber() {
        return number;
    }

    /** Puts r in the first empty bed; returns the bed number (1-based) or 0 if full. */
    int place(Resident r) {
        for (int i = 0; i < beds.length; i++) {
            if (beds[i] == null) {
                beds[i] = r;
                r.setRoom(this);
                return i + 1;
            }
        }
        return 0;
    }

    void removeResident(Resident r) {
        for (int i = 0; i < beds.length; i++) {
            if (beds[i] == r) {
                beds[i] = null;
            }
        }
        r.setRoom(null);
    }

    int freeBeds() {
        int free = 0;
        for (Resident r : beds) {
            if (r == null) {
                free++;
            }
        }
        return free;
    }

    String describe() {
        String text = "Room " + number + ": ";
        for (int i = 0; i < beds.length; i++) {
            text += (i > 0 ? ", " : "") + (beds[i] == null ? "-" : beds[i].getName());
        }
        return text;
    }
}

class Hostel {
    private final ArrayList<Room> rooms = new ArrayList<>();
    private final ArrayList<Resident> residents = new ArrayList<>();

    void addRoom(int number, int capacity) {
        rooms.add(new Room(number, capacity));
    }

    Room findRoom(int number) {
        for (Room room : rooms) {
            if (room.getNumber() == number) {
                return room;
            }
        }
        return null;
    }

    Resident findOrCreate(String name) {
        for (Resident r : residents) {
            if (r.getName().equals(name)) {
                return r;
            }
        }
        Resident r = new Resident(name);
        residents.add(r);
        return r;
    }

    String alloc(String name, int number) {
        Resident r = findOrCreate(name);
        Room room = findRoom(number);
        if (r.getRoom() != null) {
            return name + " already in room " + r.getRoom().getNumber();
        }
        if (room == null) {
            return "No room " + number;
        }
        int bed = room.place(r);
        if (bed == 0) {
            return "Room " + number + " is full";
        }
        return name + " -> room " + number + ", bed " + bed;
    }

    String move(String name, int number) {
        Resident r = findOrCreate(name);
        Room target = findRoom(number);
        Room old = r.getRoom();
        if (old == null) {
            return name + " has no bed";
        }
        if (target == null) {
            return "No room " + number;
        }
        if (target == old) {
            return name + " is already in room " + number;
        }
        if (target.freeBeds() == 0) {
            return "Room " + number + " is full";
        }
        old.removeResident(r);
        int bed = target.place(r);         // the same Resident object moves
        return name + " moved to room " + number + ", bed " + bed;
    }

    String vacate(String name) {
        Resident r = findOrCreate(name);
        Room room = r.getRoom();
        if (room == null) {
            return name + " has no bed";
        }
        room.removeResident(r);
        return name + " left room " + room.getNumber();
    }

    void report() {
        int free = 0;
        for (Room room : rooms) {
            System.out.println(room.describe());
            free += room.freeBeds();
        }
        System.out.println("Free beds: " + free);
    }
}

public class HostelAllocation {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Hostel hostel = new Hostel();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String cmd = in.next();
            if (cmd.equals("ROOM")) {
                hostel.addRoom(in.nextInt(), in.nextInt());
            } else if (cmd.equals("ALLOC")) {
                String name = in.next();
                System.out.println(hostel.alloc(name, in.nextInt()));
            } else if (cmd.equals("MOVE")) {
                String name = in.next();
                System.out.println(hostel.move(name, in.nextInt()));
            } else if (cmd.equals("VACATE")) {
                System.out.println(hostel.vacate(in.next()));
            } else if (cmd.equals("REPORT")) {
                hostel.report();
            }
        }
    }
}
```

### Explanation
- Each `Room` owns a `Resident[]` created with `new Resident[capacity]`, so every bed
  starts as `null` ("empty"). No `Resident` objects exist until someone is allocated.
- A `Resident` keeps a back-reference to its `Room`. Answering "where is Karim?" is then
  one method call instead of a search through every bed, and `room == null` means "no
  bed".
- `place` and `removeResident` update both directions (bed slot and `room` field), so
  the two references never disagree.
- `removeResident` finds the bed with `==` because it is looking for that exact object.
- `MOVE` checks that the target has a free bed **before** leaving the old room, so a
  failed move leaves everything unchanged. The same object is placed in the new room.
- `target == old` compares identities: two `Room` references to the same room object.

## Problem 13: Result Sheet With Ranks
**Level:** Advanced

### Problem Statement
Prepare a trimester result sheet. Read `n` (students) and `k` (subjects), then `k`

Write a class `Student` with a name and an `int[] marks`. Its constructor must store

Sort the students by total (highest first), and by name for equal totals. Use

Print `Rank Name     Total Average Grade` and one row per student with the format
`%-4d %-8s %5d %7.2f   %s`. Then print `Subject toppers:` and for each subject

### Solution
```java
import java.util.Scanner;

class Student {
    private final String name;
    private final int[] marks;

    Student(String name, int[] marks) {
        this.name = name;
        this.marks = new int[marks.length];       // own copy, not an alias
        for (int i = 0; i < marks.length; i++) {
            this.marks[i] = marks[i];
        }
    }

    String getName() {
        return name;
    }

    int mark(int subject) {
        return marks[subject];
    }

    int total() {
        int sum = 0;
        for (int m : marks) {
            sum += m;
        }
        return sum;
    }

    double average() {
        return (double) total() / marks.length;
    }

    String grade() {
        for (int m : marks) {
            if (m < 40) {
                return "F";
            }
        }
        double avg = average();
        if (avg >= 80) {
            return "A";
        } else if (avg >= 70) {
            return "B";
        } else if (avg >= 60) {
            return "C";
        }
        return "D";
    }

    boolean ranksBefore(Student other) {
        if (total() != other.total()) {
            return total() > other.total();
        }
        return name.compareTo(other.name) < 0;
    }
}

public class ResultSheet {
    static Student[] sortedCopy(Student[] list) {
        Student[] result = new Student[list.length];
        for (int i = 0; i < list.length; i++) {
            result[i] = list[i];                     // copies references only
        }
        for (int i = 0; i < result.length - 1; i++) {
            int best = i;
            for (int j = i + 1; j < result.length; j++) {
                if (result[j].ranksBefore(result[best])) {
                    best = j;
                }
            }
            Student temp = result[i];
            result[i] = result[best];
            result[best] = temp;
        }
        return result;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int k = in.nextInt();
        String[] codes = new String[k];
        for (int j = 0; j < k; j++) {
            codes[j] = in.next();
        }
        Student[] students = new Student[n];
        int[] buffer = new int[k];                   // reused for every line
        for (int i = 0; i < n; i++) {
            String name = in.next();
            for (int j = 0; j < k; j++) {
                buffer[j] = in.nextInt();
            }
            students[i] = new Student(name, buffer);
        }

        Student[] ranked = sortedCopy(students);
        System.out.println("Rank Name     Total Average Grade");
        int rank = 0;
        for (int i = 0; i < ranked.length; i++) {
            if (i == 0 || ranked[i].total() != ranked[i - 1].total()) {
                rank = i + 1;
            }
            Student s = ranked[i];
            System.out.printf("%-4d %-8s %5d %7.2f   %s%n",
                    rank, s.getName(), s.total(), s.average(), s.grade());
        }

        System.out.println("Subject toppers:");
        for (int j = 0; j < k; j++) {
            int best = 0;
            for (Student s : students) {
                best = Math.max(best, s.mark(j));
            }
            String names = "";
            for (Student s : students) {
                if (s.mark(j) == best) {
                    names += names.isEmpty() ? s.getName() : ", " + s.getName();
                }
            }
            System.out.println("  " + codes[j] + ": " + best + " (" + names + ")");
        }
    }
}
```

### Explanation
- `main` reuses one `buffer` array for every input line. If the constructor stored the
  reference (`this.marks = marks;`), all five students would share that one array and
  end up with Tanvir's marks. Copying the elements in the constructor gives each
  `Student` its own array — a direct lesson in aliasing.
- `sortedCopy` returns a new array of references, so `students` keeps the input order,
  which the subject-topper section needs.
- Ranks: the rank changes only when the total differs from the previous row; otherwise
  the student shares the previous rank. Setting `rank = i + 1` produces the skip (1, 1,
  3).
- `grade()` checks the "any mark below 40" rule first, so Tanvir gets `F` even though
  his average alone would give `D`.

## Problem 14: Bus Seat Reservation
**Level:** Advanced

### Problem Statement
An intercity bus has `r` rows with 4 seats each, labelled `A` to `D` (seat `2C` is row
2, third seat). Model the seats as a 2D array `Booking[][] seats`, where `null` means
free. A `Booking` has an auto-generated id (1, 2, 3, ... from a static counter), a
passenger name, a row, a first column and a size.

Read `r`, then `n` commands:

- `BOOK <name> <k>`: if `k` is not between 1 and 4 print `Invalid size <k>`. Otherwise
  find the first row (front to back) that has `k` adjacent free seats, use the leftmost
  such block, and print `Booking <id> for <name>: <seats separated by spaces>`. If no
  row has such a block print `No block of <k> seats for <name>` (no id is used).
- `CANCEL <id>`: free the seats and print `Cancelled booking <id> (<k> seats)`, or
  `No booking <id>`.
- `MAP`: print the header `      A B C D`, then for each row `Row <i>: ` followed by
  `X` (taken) or `.` (free) for each seat, separated by spaces.

Keep the active bookings in an `ArrayList<Booking>`.

### Sample Input
```text
3
11
BOOK Rahim 3
BOOK Nusrat 2
BOOK Karim 1
BOOK Ayesha 4
BOOK Fahim 3
CANCEL 1
BOOK Fahim 3
CANCEL 9

BOOK Mitu 2
MAP
```

### Sample Output
```text

Booking 2 for Nusrat: 2A 2B
Booking 3 for Karim: 1D
Booking 4 for Ayesha: 3A 3B 3C 3D
No block of 3 seats for Fahim
Cancelled booking 1 (3 seats)
Booking 5 for Fahim: 1A 1B 1C

```

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Booking {
    private static int nextId = 1;
    private final int id;
    private final String name;
    private final int row;
    private final int firstCol;
    private final int size;

    Booking(String name, int row, int firstCol, int size) {
        this.id = nextId;
        nextId++;
        this.name = name;
        this.row = row;
        this.firstCol = firstCol;
        this.size = size;
    }

    int getId() {
        return id;
    }

    int getRow() {
        return row;
    }

    int getFirstCol() {
        return firstCol;
    }

    int getSize() {
        return size;
    }

    String describe() {
        String text = "Booking " + id + " for " + name + ":";
        for (int c = firstCol; c < firstCol + size; c++) {
            text += " " + (row + 1) + "ABCD".charAt(c);
        }
        return text;
    }
}

class Bus {
    static final int SEATS_PER_ROW = 4;
    private final Booking[][] seats;
    private final ArrayList<Booking> bookings = new ArrayList<>();

    Bus(int rows) {
        seats = new Booking[rows][SEATS_PER_ROW];      // all null = free
    }

    /** Returns the new booking, or null when no block of k free seats exists. */
    Booking book(String name, int k) {
        for (int r = 0; r < seats.length; r++) {
            int run = 0;                               // free seats in a row so far
            for (int c = 0; c < SEATS_PER_ROW; c++) {
                run = seats[r][c] == null ? run + 1 : 0;
                if (run == k) {
                    Booking b = new Booking(name, r, c - k + 1, k);
                    for (int s = c - k + 1; s <= c; s++) {
                        seats[r][s] = b;               // every seat refers to b
                    }
                    bookings.add(b);
                    return b;
                }
            }
        }
        return null;
    }

    boolean cancel(int id) {
        for (int i = 0; i < bookings.size(); i++) {
            Booking b = bookings.get(i);
            if (b.getId() == id) {
                for (int c = b.getFirstCol(); c < b.getFirstCol() + b.getSize(); c++) {
                    seats[b.getRow()][c] = null;
                }
                bookings.remove(i);
                System.out.println("Cancelled booking " + id + " (" + b.getSize() + " seats)");
                return true;
            }
        }
        return false;
    }

    void printMap() {
        System.out.println("      A B C D");
        for (int r = 0; r < seats.length; r++) {
            String line = "Row " + (r + 1) + ":";
            for (Booking b : seats[r]) {
                line += b == null ? " ." : " X";
            }
            System.out.println(line);
        }
    }
}

public class BusReservation {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Bus bus = new Bus(in.nextInt());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String cmd = in.next();
            if (cmd.equals("BOOK")) {
                String name = in.next();
                int k = in.nextInt();
                if (k < 1 || k > Bus.SEATS_PER_ROW) {
                    System.out.println("Invalid size " + k);
                    continue;
                }
                Booking b = bus.book(name, k);
                if (b == null) {
                    System.out.println("No block of " + k + " seats for " + name);
                } else {
                    System.out.println(b.describe());
                }
            } else if (cmd.equals("CANCEL")) {
                int id = in.nextInt();
                if (!bus.cancel(id)) {
                    System.out.println("No booking " + id);
                }
            } else if (cmd.equals("MAP")) {
                bus.printMap();
            }
        }
    }
}
```

### Explanation
- `new Booking[rows][4]` creates a table of `null` references: every seat starts free,
  and no `Booking` object exists yet.
- When a booking is made, **several seats refer to the same `Booking` object**. That
  is deliberate aliasing: any seat can tell which booking it belongs to.
- The search counts a `run` of consecutive free seats in each row and restarts at `0`
  on a taken seat; when the run reaches `k`, the block ends at column `c` and starts at
  `c - k + 1`.
- The id is created only inside the `Booking` constructor, and a booking object is
  created only after a free block is found, so a failed request does not use an id.
- `cancel` sets the seats back to `null`. The `Booking` object is then unreachable and
  the garbage collector may reclaim it later.

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class Transaction {
    private final String kind;
    private final int amount;
    private final int balanceAfter;
    private final Account other;           // null unless this is a transfer

    Transaction(String kind, int amount, int balanceAfter, Account other) {
        this.kind = kind;
        this.amount = amount;
        this.balanceAfter = balanceAfter;
        this.other = other;
    }

    String describe() {
        String text = kind + " " + amount;
        if (other != null) {
            String word = kind.equals("Transfer in") ? " from " : " to ";
            text += word + other.getOwner() + " (#" + other.getId() + ")";
        }
        return text + " -> balance " + balanceAfter;
    }
}

class Account {
    private static int nextId = 1;
    private final int id;
    private final String owner;
    private int balance;
    private final ArrayList<Transaction> history = new ArrayList<>();

    Account(String owner, int opening) {
        id = nextId;
        nextId++;
        this.owner = owner;
        balance = opening;
        history.add(new Transaction("Opened", opening, balance, null));
    }

    int getId() {
        return id;
    }

    String getOwner() {
        return owner;
    }

    int getBalance() {
        return balance;
    }

    void apply(String kind, int change, Account other) {
        balance += change;
        history.add(new Transaction(kind, Math.abs(change), balance, other));
    }

    void printStatement() {
        System.out.println("Statement of #" + id + " (" + owner + ")");
        for (Transaction t : history) {
            System.out.println("  " + t.describe());
        }
        System.out.println("Closing balance: " + balance);
    }
}

class Bank {
    private final ArrayList<Account> accounts = new ArrayList<>();

    Account open(String owner, int amount) {
        Account a = new Account(owner, amount);
        accounts.add(a);
        return a;
    }

    Account find(int id) {
        for (Account a : accounts) {
            if (a.getId() == id) {
                return a;
            }
        }
        return null;
    }

    String deposit(int id, int amount) {
        Account a = find(id);
        if (a == null) {
            return "No account #" + id;
        }
        if (amount <= 0) {
            return "Amount must be positive";
        }
        a.apply("Deposit", amount, null);
        return "Deposited Tk " + amount + " to #" + id;
    }

    String withdraw(int id, int amount) {
        Account a = find(id);
        if (a == null) {
            return "No account #" + id;
        }
        if (amount <= 0) {
            return "Amount must be positive";
        }
        if (amount > a.getBalance()) {
            return "Insufficient funds in #" + id;
        }
        a.apply("Withdraw", -amount, null);
        return "Withdrew Tk " + amount + " from #" + id;
    }

    String transfer(int fromId, int toId, int amount) {
        Account from = find(fromId);
        Account to = find(toId);
        if (from == null) {
            return "No account #" + fromId;
        }
        if (to == null) {
            return "No account #" + toId;
        }
        if (from == to) {
            return "Cannot transfer to the same account";
        }
        if (amount <= 0) {
            return "Amount must be positive";
        }
        if (amount > from.getBalance()) {
            return "Insufficient funds in #" + fromId;
        }
        from.apply("Transfer out", -amount, to);
        to.apply("Transfer in", amount, from);
        return "Transferred Tk " + amount + " from #" + fromId + " to #" + toId;
    }
}

public class BankStatements {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Bank bank = new Bank();
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String cmd = in.next();
            if (cmd.equals("OPEN")) {
                String name = in.next();
                int amount = in.nextInt();
                Account a = bank.open(name, amount);
                System.out.println("Opened #" + a.getId() + " for " + name
                        + " with Tk " + amount);
            } else if (cmd.equals("DEPOSIT")) {
                int id = in.nextInt();
                System.out.println(bank.deposit(id, in.nextInt()));
            } else if (cmd.equals("WITHDRAW")) {
                int id = in.nextInt();
                System.out.println(bank.withdraw(id, in.nextInt()));
            } else if (cmd.equals("TRANSFER")) {
                int from = in.nextInt();
                int to = in.nextInt();
                System.out.println(bank.transfer(from, to, in.nextInt()));
            } else if (cmd.equals("STATEMENT")) {
                int id = in.nextInt();
                Account a = bank.find(id);
                if (a == null) {
                    System.out.println("No account #" + id);
                } else {
                    a.printStatement();
                }
            }
        }
    }
}
```

### Explanation
- A `Transaction` stores a **reference** to the other `Account`, not a copy of its
  name. The statement follows that reference to print the other owner and id.
- `find` returns `null` for an unknown id, and every operation checks for `null` before
  using the account, so bad ids produce messages instead of `NullPointerException`s.
- `from == to` uses identity: the two ids found the very same `Account` object.
- All balance changes go through `apply`, which updates the balance and records the
  history entry together, so the statement always matches the balance.
- A transfer is checked completely before either account changes; then both sides are
  updated, each history entry pointing at the other account.
- Ids come from a `static` counter (Chapter 07), shared by all accounts.
