# Practice Problems: Exception Handling

These problems practise catching built-in exceptions, throwing your own, writing
custom exception classes and tracing how exceptions travel through methods and
resources. Programs read input without prompts and print exactly the sample output.

## Problem 1: Stock Count Parser
**Level:** Basic

### Problem Statement
A shop clerk types item quantities into a stock sheet, but some entries are typing
mistakes. Read an integer `n`, then `n` tokens (words without spaces). Convert each
token with `Integer.parseInt`. If it works, add the quantity to a running total and
print `<quantity> added`. If `parseInt` throws `NumberFormatException`, print
`Invalid quantity: <token>` and continue.

At the end print `Total: <total> (<k> invalid)`, where `k` is the number of invalid
tokens.

### Sample Input
```text
5
12
seven
30
4.5
8
```

### Sample Output
```text
12 added
Invalid quantity: seven
30 added
Invalid quantity: 4.5
8 added
Total: 50 (2 invalid)
```

### Solution
```java
import java.util.Scanner;

public class StockCountParser {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int total = 0;
        int invalid = 0;
        for (int i = 0; i < n; i++) {
            String token = in.next();
            try {
                int quantity = Integer.parseInt(token);
                total += quantity;
                System.out.println(quantity + " added");
            } catch (NumberFormatException e) {
                invalid++;
                System.out.println("Invalid quantity: " + token);
            }
        }
        System.out.println("Total: " + total + " (" + invalid + " invalid)");
    }
}
```

### Explanation
Each token is read as a `String` with `next()`, so reading itself never fails. The
risky step is `Integer.parseInt`, so only that part sits in the `try` block together
with the lines that should run only on success. When `parseInt` throws, the `total +=`
line and the `added` message are skipped, and the `catch` block counts the error.
`4.5` is invalid too, because `parseInt` accepts only whole numbers. The `try`/`catch`
is inside the loop, so one bad token does not stop the rest.

## Problem 2: Shuttle Trips per Route
**Level:** Basic

### Problem Statement
The campus shuttle office plans trips. For each route it knows the number of students
and the capacity of one bus. The number of trips is the number of full buses plus one
more if some students are left over.

Write a method `static int tripsNeeded(int students, int capacity)` that computes it
with `/` and `%` (no `if` that checks the capacity). Read `n`, then `n` lines
`<route> <students> <capacity>`. For each route print `<route>: <trips> trips`. If the
capacity is 0, the method throws `ArithmeticException`; catch it in `main` and print
`<route>: capacity is 0, cannot plan`. Finally print `Total trips: <sum>` over the
routes that could be planned.

### Sample Input
```text
3
Mirpur 95 40
Uttara 60 0
Badda 80 40
```

### Sample Output
```text
Mirpur: 3 trips
Uttara: capacity is 0, cannot plan
Badda: 2 trips
Total trips: 5
```

### Solution
```java
import java.util.Scanner;

public class ShuttleTrips {
    static int tripsNeeded(int students, int capacity) {
        int trips = students / capacity;
        if (students % capacity != 0) {
            trips++;
        }
        return trips;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int totalTrips = 0;
        for (int i = 0; i < n; i++) {
            String route = in.next();
            int students = in.nextInt();
            int capacity = in.nextInt();
            try {
                int trips = tripsNeeded(students, capacity);
                totalTrips += trips;
                System.out.println(route + ": " + trips + " trips");
            } catch (ArithmeticException e) {
                System.out.println(route + ": capacity is 0, cannot plan");
            }
        }
        System.out.println("Total trips: " + totalTrips);
    }
}
```

### Explanation
Integer division and `%` by zero both throw `ArithmeticException`. The exception
starts in `tripsNeeded`, which has no `catch`, so it propagates to `main`. The `try`
in `main` catches it for that one route, and the loop continues. Because `totalTrips`
is updated inside the `try` after the call, a failed route adds nothing. In a larger
program you would rather check `capacity <= 0` at the start of `tripsNeeded` and
throw an exception with a clearer message.

## Problem 3: Library Shelf Lookup
**Level:** Basic

### Problem Statement
A small library stores book titles in an array; the index is the shelf number,
starting at 0. Read `n`, then `n` titles, one per line (titles may contain spaces).
Then read `q` and `q` shelf numbers. For each shelf number print
`Shelf <s>: <title>`. If the number is not a valid index, the array access throws
`ArrayIndexOutOfBoundsException`; catch it and print
`Shelf <s>: no such shelf (<message>)`, where `<message>` is the exception's
`getMessage()`.

### Sample Input
```text
4
Java Basics
Data Structures
Clean Code
Discrete Mathematics
4
2
7
0
-1
```

### Sample Output
```text
Shelf 2: Clean Code
Shelf 7: no such shelf (Index 7 out of bounds for length 4)
Shelf 0: Java Basics
Shelf -1: no such shelf (Index -1 out of bounds for length 4)
```

### Solution
```java
import java.util.Scanner;

public class ShelfLookup {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = Integer.parseInt(in.nextLine().trim());
        String[] shelves = new String[n];
        for (int i = 0; i < n; i++) {
            shelves[i] = in.nextLine();
        }
        int q = in.nextInt();
        for (int i = 0; i < q; i++) {
            int shelf = in.nextInt();
            try {
                System.out.println("Shelf " + shelf + ": " + shelves[shelf]);
            } catch (ArrayIndexOutOfBoundsException e) {
                System.out.println("Shelf " + shelf + ": no such shelf ("
                        + e.getMessage() + ")");
            }
        }
    }
}
```

### Explanation
The first line is read with `nextLine()` and converted with `parseInt`, so no leftover
newline disturbs the title lines that follow. Both a too-large index (7) and a
negative index (-1) throw `ArrayIndexOutOfBoundsException`, and Java's message names
the bad index and the array length. The message is printed with `getMessage()`.
Catching this exception is fine for practice, but in real code a simple range check
`0 <= shelf && shelf < shelves.length` is the better habit: the index problem is a
predictable condition, not an exceptional one.

## Problem 4: Mobile Number Validator
**Level:** Basic

### Problem Statement
Write a method `static void checkPhone(String phone)` that throws
`IllegalArgumentException` with a specific message when a mobile number is invalid.
Check the rules in this order:

1. The length must be 11, otherwise the message is
   `must have 11 characters, found <length>`.
2. Every character must be a digit, otherwise the message is
   `'<c>' is not a digit` for the first bad character.
3. The number must start with `01`, otherwise the message is `must start with 01`.

Read `n` and `n` numbers. Print `<number>: VALID` or `<number>: INVALID - <message>`.

### Sample Input
```text
4
01712345678
0171234567
0181234X678
02912345678
```

### Sample Output
```text
01712345678: VALID
0171234567: INVALID - must have 11 characters, found 10
0181234X678: INVALID - 'X' is not a digit
02912345678: INVALID - must start with 01
```

### Solution
```java
import java.util.Scanner;

public class PhoneValidator {
    static void checkPhone(String phone) {
        if (phone.length() != 11) {
            throw new IllegalArgumentException(
                    "must have 11 characters, found " + phone.length());
        }
        for (int i = 0; i < phone.length(); i++) {
            char c = phone.charAt(i);
            if (c < '0' || c > '9') {
                throw new IllegalArgumentException("'" + c + "' is not a digit");
            }
        }
        if (!phone.startsWith("01")) {
            throw new IllegalArgumentException("must start with 01");
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String phone = in.next();
            try {
                checkPhone(phone);
                System.out.println(phone + ": VALID");
            } catch (IllegalArgumentException e) {
                System.out.println(phone + ": INVALID - " + e.getMessage());
            }
        }
    }
}
```

### Explanation
`checkPhone` does not print anything and does not return a `boolean`. It either
returns normally (the number is valid) or throws with a message that explains which
rule failed. The first `throw` that runs ends the method, so only the first broken
rule is reported. `main` decides how to show the result and uses `getMessage()` to
include the reason. Separating "checking" from "reporting" this way lets the same
method be reused in a registration form, a file import or a test.

## Problem 5: Blood Donation Eligibility
**Level:** Basic

### Problem Statement
A campus blood donation camp uses two (hypothetical) rules: the donor's age must be
from 18 to 60, and the weight must be at least 50 kg.

Write a checked exception class `InvalidDonorException` (extends `Exception`) and a
method `static void checkDonor(int age, int weight) throws InvalidDonorException`. Check
the age first, then the weight. Messages: `age <age> is outside 18-60` and
`weight <w> kg is below 50 kg`.

Read `n` and `n` lines `<name> <age> <weight>`. Print `<name>: eligible` or
`<name>: not eligible, <message>`. Finally print `Eligible donors: <k> of <n>`.

### Sample Input
```text
4
Rafi 22 65
Mitu 19 45
Arif 17 70
Farhana 35 55
```

### Sample Output
```text
Rafi: eligible
Mitu: not eligible, weight 45 kg is below 50 kg
Arif: not eligible, age 17 is outside 18-60
Farhana: eligible
Eligible donors: 2 of 4
```

### Solution
```java
import java.util.Scanner;

class InvalidDonorException extends Exception {
    InvalidDonorException(String message) {
        super(message);
    }
}

public class DonorCheck {
    static void checkDonor(int age, int weight) throws InvalidDonorException {
        if (age < 18 || age > 60) {
            throw new InvalidDonorException("age " + age + " is outside 18-60");
        }
        if (weight < 50) {
            throw new InvalidDonorException("weight " + weight + " kg is below 50 kg");
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int eligible = 0;
        for (int i = 0; i < n; i++) {
            String name = in.next();
            int age = in.nextInt();
            int weight = in.nextInt();
            try {
                checkDonor(age, weight);
                eligible++;
                System.out.println(name + ": eligible");
            } catch (InvalidDonorException e) {
                System.out.println(name + ": not eligible, " + e.getMessage());
            }
        }
        System.out.println("Eligible donors: " + eligible + " of " + n);
    }
}
```

### Explanation
`InvalidDonorException` extends `Exception`, so it is checked. The method must say
`throws InvalidDonorException`, and the compiler forces `main` to catch it: remove the
`catch` and the program no longer compiles. The custom class passes the message to
`Exception` with `super(message)`, which is what `getMessage()` returns later. The
class name tells a reader exactly which problem was found, which a general
`Exception` would not.

## Problem 6: Wallet Menu with Limited Attempts
**Level:** Intermediate

### Problem Statement
A mobile wallet menu has four options: `1` Check balance, `2` Send money, `3` Pay
bill, `4` Exit. The user gets at most 3 attempts to enter a valid choice.

Write `static int parseChoice(String token)` that converts the token with
`Integer.parseInt` (which may throw `NumberFormatException`) and throws
`IllegalArgumentException` with the message `<n> is not a menu option` for numbers
outside 1-4.

Read tokens one by one. For each invalid attempt print either
`Attempt <a>: '<token>' is not a number` or `Attempt <a>: <n> is not a menu option`.
On the first valid choice print `Selected <c>: <option name>` and stop reading. If
there is no valid choice after 3 attempts (or the input ends), print
`Too many invalid attempts. Session closed.`

### Sample Input
```text
abc
7
2
```

### Sample Output
```text
Attempt 1: 'abc' is not a number
Attempt 2: 7 is not a menu option
Selected 2: Send money
```

### Solution
```java
import java.util.Scanner;

public class WalletMenu {
    static final String[] OPTIONS = {"Check balance", "Send money", "Pay bill", "Exit"};
    static final int MAX_ATTEMPTS = 3;

    static int parseChoice(String token) {
        int choice = Integer.parseInt(token);
        if (choice < 1 || choice > OPTIONS.length) {
            throw new IllegalArgumentException(choice + " is not a menu option");
        }
        return choice;
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int choice = 0;
        int attempts = 0;
        while (choice == 0 && attempts < MAX_ATTEMPTS && in.hasNext()) {
            String token = in.next();
            attempts++;
            try {
                choice = parseChoice(token);
            } catch (NumberFormatException e) {
                System.out.println("Attempt " + attempts + ": '" + token
                        + "' is not a number");
            } catch (IllegalArgumentException e) {
                System.out.println("Attempt " + attempts + ": " + e.getMessage());
            }
        }
        if (choice != 0) {
            System.out.println("Selected " + choice + ": " + OPTIONS[choice - 1]);
        } else {
            System.out.println("Too many invalid attempts. Session closed.");
        }
    }
}
```

### Explanation
This is a re-validation loop with a limit. `choice` stays 0 until `parseChoice`
returns normally, so the loop condition tells us whether a valid choice arrived.
The order of the `catch` blocks matters: `NumberFormatException` is a subclass of
`IllegalArgumentException`, so it must come first. If the general block came first,
the specific block could never run and the compiler would reject the program. Reading
tokens as `String` (instead of `nextInt()`) means a bad token is already consumed, so
there is no risk of reading the same token forever. `in.hasNext()` stops the loop
cleanly when the input ends early.

## Problem 7: Safe Line Calculator
**Level:** Intermediate

### Problem Statement
Read `n` lines, each `<a> <op> <b>` with tokens separated by single spaces. Supported
operators are `+ - * / %` on `int` values. Write a checked exception
`UnknownOperatorException` whose message is `Unknown operator: <op>`, and a method

`static int calculate(String a, String op, String b) throws UnknownOperatorException`

that parses both numbers first and then applies the operator.

For each line print `<a> <op> <b> = <result>`. On failure print
`Line <i>: <ExceptionClassName> - <message>` for a `NumberFormatException` or an
`ArithmeticException` (handled by one multi-catch block), and
`Line <i>: <message>` for an unknown operator. Finally print
`Successful: <k> of <n>`.

### Sample Input
```text
6
12 + 30
100 / 7
9 / 0
4x * 3
17 % 5
2 ^ 8
```

### Sample Output
```text
12 + 30 = 42
100 / 7 = 14
Line 3: ArithmeticException - / by zero
Line 4: NumberFormatException - For input string: "4x"
17 % 5 = 2
Line 6: Unknown operator: ^
Successful: 3 of 6
```

### Solution
```java
import java.util.Scanner;

class UnknownOperatorException extends Exception {
    UnknownOperatorException(String op) {
        super("Unknown operator: " + op);
    }
}

public class SafeCalculator {
    static int calculate(String left, String op, String right)
            throws UnknownOperatorException {
        int a = Integer.parseInt(left);
        int b = Integer.parseInt(right);
        switch (op) {
            case "+":
                return a + b;
            case "-":
                return a - b;
            case "*":
                return a * b;
            case "/":
                return a / b;
            case "%":
                return a % b;
            default:
                throw new UnknownOperatorException(op);
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int successful = 0;
        for (int i = 1; i <= n; i++) {
            String a = in.next();
            String op = in.next();
            String b = in.next();
            try {
                int result = calculate(a, op, b);
                successful++;
                System.out.println(a + " " + op + " " + b + " = " + result);
            } catch (NumberFormatException | ArithmeticException e) {
                System.out.println("Line " + i + ": " + e.getClass().getSimpleName()
                        + " - " + e.getMessage());
            } catch (UnknownOperatorException e) {
                System.out.println("Line " + i + ": " + e.getMessage());
            }
        }
        System.out.println("Successful: " + successful + " of " + n);
    }
}
```

### Explanation
`calculate` can fail in three ways. Two are Java's unchecked exceptions
(`NumberFormatException` from `parseInt`, `ArithmeticException` from `/` or `%` by
zero); one is our own checked exception, which therefore appears in the `throws`
clause. The two built-in types get the same treatment, so a multi-catch
`catch (NumberFormatException | ArithmeticException e)` avoids duplicate code, and
`e.getClass().getSimpleName()` prints the actual type of the caught object. Each
`case` ends with `return` or `throw`, so no case falls through. The custom exception
builds its message in its own constructor, so every caller gets the same wording.

## Problem 8: Withdrawals with a Daily Limit
**Level:** Intermediate

### Problem Statement
A wallet account has a balance and a daily withdrawal limit. Create a small exception
hierarchy:

- `WithdrawalException extends Exception` (abstract base class)
- `InsufficientFundsException extends WithdrawalException`, with a field `shortfall`
  and the message `balance is <b> Tk`
- `DailyLimitExceededException extends WithdrawalException` with the message
  `daily limit of <L> Tk would be exceeded, <r> Tk left today`

`Account.withdraw(int amount)` throws `IllegalArgumentException`
(`amount must be positive`) for `amount <= 0`, then checks the balance, then the
daily limit. Only a successful withdrawal changes the balance and the amount withdrawn
today.

Input: the starting balance and the daily limit, then `n` commands: `W <amount>`
(withdraw) or `NEWDAY` (reset the daily total). Output per command:
`Withdrew <a> Tk, balance <b> Tk`, `New day`, `Refused: <message>, short by <s> Tk`
(insufficient funds) or `Refused: <message>` (any other problem). Finally print
`Final balance: <b> Tk`.

### Sample Input
```text
10000 5000
7
W 3000
W 2500
W 2000
NEWDAY
W 8000
W 0
W 4000
```

### Sample Output
```text
Withdrew 3000 Tk, balance 7000 Tk
Refused: daily limit of 5000 Tk would be exceeded, 2000 Tk left today
Withdrew 2000 Tk, balance 5000 Tk
New day
Refused: balance is 5000 Tk, short by 3000 Tk
Refused: amount must be positive
Withdrew 4000 Tk, balance 1000 Tk
Final balance: 1000 Tk
```

### Solution
```java
import java.util.Scanner;

abstract class WithdrawalException extends Exception {
    WithdrawalException(String message) {
        super(message);
    }
}

class InsufficientFundsException extends WithdrawalException {
    private final int shortfall;

    InsufficientFundsException(int balance, int shortfall) {
        super("balance is " + balance + " Tk");
        this.shortfall = shortfall;
    }

    int getShortfall() {
        return shortfall;
    }
}

class DailyLimitExceededException extends WithdrawalException {
    DailyLimitExceededException(int limit, int left) {
        super("daily limit of " + limit + " Tk would be exceeded, " + left
                + " Tk left today");
    }
}

class Account {
    private int balance;
    private final int dailyLimit;
    private int withdrawnToday;

    Account(int balance, int dailyLimit) {
        this.balance = balance;
        this.dailyLimit = dailyLimit;
    }

    void withdraw(int amount) throws WithdrawalException {
        if (amount <= 0) {
            throw new IllegalArgumentException("amount must be positive");
        }
        if (amount > balance) {
            throw new InsufficientFundsException(balance, amount - balance);
        }
        if (withdrawnToday + amount > dailyLimit) {
            throw new DailyLimitExceededException(dailyLimit, dailyLimit - withdrawnToday);
        }
        balance -= amount;
        withdrawnToday += amount;
    }

    void newDay() {
        withdrawnToday = 0;
    }

    int getBalance() {
        return balance;
    }
}

public class DailyLimitWallet {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Account account = new Account(in.nextInt(), in.nextInt());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("NEWDAY")) {
                account.newDay();
                System.out.println("New day");
                continue;
            }
            int amount = in.nextInt();
            try {
                account.withdraw(amount);
                System.out.println("Withdrew " + amount + " Tk, balance "
                        + account.getBalance() + " Tk");
            } catch (InsufficientFundsException e) {
                System.out.println("Refused: " + e.getMessage() + ", short by "
                        + e.getShortfall() + " Tk");
            } catch (WithdrawalException | IllegalArgumentException e) {
                System.out.println("Refused: " + e.getMessage());
            }
        }
        System.out.println("Final balance: " + account.getBalance() + " Tk");
    }
}
```

### Explanation
The two specific exceptions share an abstract base class, so `withdraw` can declare
just `throws WithdrawalException`, and a caller can catch all withdrawal problems at
once. `main` first catches the specific `InsufficientFundsException` because it wants
the extra `shortfall` value; every other withdrawal problem falls into the general
block. That block is a multi-catch with `IllegalArgumentException`, which is allowed
because the two types are unrelated. All checks happen before any field changes, so a
refused withdrawal leaves the account exactly as it was. `NEWDAY` is a normal command,
handled with an `if`, not with an exception.

## Problem 9: Tracing Resources, catch and finally
**Level:** Intermediate

### Problem Statement
Lab equipment is modelled by a class `Device implements AutoCloseable`:

- The constructor prints `open <name>`. If the name is `broken`, it throws
  `IllegalStateException("cannot open broken")` before printing.
- `work(boolean fail)` prints `work <name>`, or throws
  `IllegalStateException("<name> failed")` when `fail` is `true`.
- `close()` prints `close <name>`.

Read `n` runs. Each run is a line `<first> <second> <mode>`, where `mode` is `ok` or
`fail`. For run `i` print `== Run <i> ==`, then open both devices in one
try-with-resources statement, call `first.work(false)` and `second.work(fail)`. A
`catch (IllegalStateException e)` prints `caught: <message>` and a `finally` block
prints `finally`.

### Sample Input
```text
3
printer scanner ok
printer scanner fail
printer broken ok
```

### Sample Output
```text
== Run 1 ==
open printer
open scanner
work printer
work scanner
close scanner
close printer
finally
== Run 2 ==
open printer
open scanner
work printer
close scanner
close printer
caught: scanner failed
finally
== Run 3 ==
open printer
close printer
caught: cannot open broken
finally
```

### Solution
```java
import java.util.Scanner;

class Device implements AutoCloseable {
    private final String name;

    Device(String name) {
        if (name.equals("broken")) {
            throw new IllegalStateException("cannot open broken");
        }
        this.name = name;
        System.out.println("open " + name);
    }

    void work(boolean fail) {
        if (fail) {
            throw new IllegalStateException(name + " failed");
        }
        System.out.println("work " + name);
    }

    @Override
    public void close() {
        System.out.println("close " + name);
    }
}

public class ResourceTrace {
    static void run(String firstName, String secondName, boolean fail) {
        try (Device first = new Device(firstName);
             Device second = new Device(secondName)) {
            first.work(false);
            second.work(fail);
        } catch (IllegalStateException e) {
            System.out.println("caught: " + e.getMessage());
        } finally {
            System.out.println("finally");
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        for (int i = 1; i <= n; i++) {
            String first = in.next();
            String second = in.next();
            boolean fail = in.next().equals("fail");
            System.out.println("== Run " + i + " ==");
            run(first, second, fail);
        }
    }
}
```

### Explanation
The three runs show the three rules of try-with-resources:

- Run 1: resources are closed in **reverse** order of opening (scanner, then printer).
- Run 2: when the body throws, both resources are still closed, and they are closed
  **before** the `catch` block runs.
- Run 3: the second constructor throws, so `second` never existed and only `first` is
  closed. A resource is closed only if it was opened.

In every run, `finally` comes last. Predicting this output by hand before running the
program is a good exam exercise.

## Problem 10: Following an Exception Through Methods
**Level:** Intermediate

### Problem Statement
A warehouse class handles orders through three methods that call each other:
`processOrder` → `reserve` → `parseQuantity`.

- `parseQuantity(String text)` prints `    parseQuantity(<text>)` (4 spaces), converts
  with `Integer.parseInt` and throws `IllegalArgumentException` with the message
  `quantity must be positive: <q>` if `q <= 0`.
- `reserve(String text)` prints `  reserve(<text>)` (2 spaces). If the quantity is
  larger than the stock it throws the checked `OutOfStockException` with the message
  `only <s> left, asked <q>`; otherwise it reduces the stock and prints
  `  reserved <q>, stock now <s>`. Its `finally` block prints `  reserve finally`.
- `processOrder(String text)` prints `processOrder(<text>)`, calls `reserve`, then
  prints `order accepted`. It catches only `NumberFormatException` and prints
  `processOrder caught: not a number`.
- `main` catches `OutOfStockException` and `IllegalArgumentException` and prints
  `main caught <SimpleClassName>: <message>`.

Input: the initial stock, `n`, then `n` quantity tokens. After all orders print
`Stock left: <s>`.

### Sample Input

```java
import java.util.Scanner;

class OutOfStockException extends Exception {
    OutOfStockException(String message) {
        super(message);
    }
}

class Warehouse {
    private int stock;

    Warehouse(int stock) {
        this.stock = stock;
    }

    int parseQuantity(String text) {
        System.out.println("    parseQuantity(" + text + ")");
        int quantity = Integer.parseInt(text);
        if (quantity <= 0) {
            throw new IllegalArgumentException("quantity must be positive: " + quantity);
        }
        return quantity;
    }

    void reserve(String text) throws OutOfStockException {
        System.out.println("  reserve(" + text + ")");
        try {
            int quantity = parseQuantity(text);
            if (quantity > stock) {
                throw new OutOfStockException("only " + stock + " left, asked " + quantity);
            }
            stock -= quantity;
            System.out.println("  reserved " + quantity + ", stock now " + stock);
        } finally {
            System.out.println("  reserve finally");
        }
    }

    void processOrder(String text) throws OutOfStockException {
        System.out.println("processOrder(" + text + ")");
        try {
            reserve(text);
            System.out.println("order accepted");
        } catch (NumberFormatException e) {
            System.out.println("processOrder caught: not a number");
        }
    }

    int getStock() {
        return stock;
    }
}

public class OrderPropagation {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Warehouse warehouse = new Warehouse(in.nextInt());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String text = in.next();
            try {
                warehouse.processOrder(text);
            } catch (OutOfStockException | IllegalArgumentException e) {
                System.out.println("main caught " + e.getClass().getSimpleName()
                        + ": " + e.getMessage());
            }
        }
        System.out.println("Stock left: " + warehouse.getStock());
    }
}
```

### Explanation
Each exception is caught by the **nearest** method on the call stack that has a
matching `catch`. `NumberFormatException` (for `x2`) is caught in `processOrder`, so
`main` never sees it, even though `main` catches its superclass
`IllegalArgumentException`. The `OutOfStockException` and the "must be positive"
`IllegalArgumentException` pass through `reserve` and `processOrder` and reach
`main`. In every failing case `order accepted` is skipped, while `reserve finally` is
always printed: `finally` runs even when the exception is not handled in that method.
`OutOfStockException` is checked, so both `reserve` and `processOrder` must declare it.

## Problem 11: Grade Book with Marks Validation
**Level:** Advanced

### Problem Statement

  (0-50). Its constructor validates the marks in this order and throws

  (`<part>` is `ct`, `mid` or `final`). `total()` returns the sum; `grade()` returns

### Sample Input

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class InvalidMarksException extends RuntimeException {
    InvalidMarksException(String message) {
        super(message);
    }
}

class Student {
    private final int id;
    private final String name;
    private final int ct;
    private final int mid;
    private final int fin;

    Student(int id, String name, int ct, int mid, int fin) {
        check("ct", ct, 20);
        check("mid", mid, 30);
        check("final", fin, 50);
        this.id = id;
        this.name = name;
        this.ct = ct;
        this.mid = mid;
        this.fin = fin;
    }

    private static void check(String part, int value, int max) {
        if (value < 0 || value > max) {
            throw new InvalidMarksException(part + " " + value + " is outside 0-" + max);
        }
    }

    int getId() {
        return id;
    }

    String getName() {
        return name;
    }

    int total() {
        return ct + mid + fin;
    }

    String grade() {
        int t = total();
        if (t >= 80) {
            return "A";
        } else if (t >= 65) {
            return "B";
        } else if (t >= 50) {
            return "C";
        }
        return "F";
    }
}

class GradeBook {
    private final ArrayList<Student> students = new ArrayList<Student>();

    void add(Student s) {
        for (Student other : students) {
            if (other.getId() == s.getId()) {
                throw new IllegalArgumentException("duplicate id " + s.getId());
            }
        }
        students.add(s);
    }

    void printReport() {
        if (students.isEmpty()) {
            System.out.println("No valid records.");
            return;
        }
        int sum = 0;
        Student top = students.get(0);
        for (Student s : students) {
            System.out.println(s.getId() + " " + s.getName() + " " + s.total()
                    + " " + s.grade());
            sum += s.total();
            if (s.total() > top.total()) {
                top = s;
            }
        }
        System.out.printf("Class average: %.2f%n", (double) sum / students.size());
        System.out.println("Top student: " + top.getName() + " (" + top.total() + ")");
    }

    int size() {
        return students.size();
    }
}

public class GradeBookApp {
    static Student parse(String line) {
        String[] f = line.trim().split(" ");
        if (f.length != 5) {
            throw new IllegalArgumentException("expected 5 fields, found " + f.length);
        }
        return new Student(Integer.parseInt(f[0]), f[1], Integer.parseInt(f[2]),
                Integer.parseInt(f[3]), Integer.parseInt(f[4]));
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = Integer.parseInt(in.nextLine().trim());
        GradeBook book = new GradeBook();
        for (int i = 1; i <= n; i++) {
            String line = in.nextLine();
            try {
                book.add(parse(line));
            } catch (NumberFormatException e) {
                System.out.println("Line " + i + ": rejected, not a number ("
                        + e.getMessage() + ")");
            } catch (InvalidMarksException | IllegalArgumentException e) {
                System.out.println("Line " + i + ": rejected, " + e.getMessage());
            }
        }
        System.out.println("Accepted " + book.size() + ", rejected " + (n - book.size()));
        book.printReport();
    }
}
```

### Explanation
Each class validates what it owns. `Student` guards its marks in the constructor
(validate early), so an invalid `Student` object can never exist. `GradeBook` guards
the rule that ids are unique, which a single student cannot know. `parse` guards the
line format. All three report problems by throwing, and only `main`, which knows the
line number, turns them into output. `NumberFormatException` is caught before the
multi-catch, because it is a subclass of `IllegalArgumentException` and needs its own
wording. `InvalidMarksException | IllegalArgumentException` is a legal multi-catch
because neither class extends the other. Since every rejected line throws before
`students.add`, the rejected count is simply `n - book.size()`.

  `<id> has <balance> Tk, cannot withdraw <amount> Tk`).

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class AccountNotFoundException extends Exception {
    AccountNotFoundException(String id) {
        super("no account with id " + id);
    }
}

class InsufficientFundsException extends Exception {
    InsufficientFundsException(String id, int balance, int amount) {
        super(id + " has " + balance + " Tk, cannot withdraw " + amount + " Tk");
    }
}

class Account {
    private final String id;
    private final String owner;
    private int balance;

    Account(String id, String owner, int balance) {
        this.id = id;
        this.owner = owner;
        this.balance = balance;
    }

    private static void requirePositive(int amount) {
        if (amount <= 0) {
            throw new IllegalArgumentException("amount must be positive, got " + amount);
        }
    }

    void deposit(int amount) {
        requirePositive(amount);
        balance += amount;
    }

    void withdraw(int amount) throws InsufficientFundsException {
        requirePositive(amount);
        if (amount > balance) {
            throw new InsufficientFundsException(id, balance, amount);
        }
        balance -= amount;
    }

    String getId() {
        return id;
    }

    String getOwner() {
        return owner;
    }

    int getBalance() {
        return balance;
    }
}

class Bank {
    private final ArrayList<Account> accounts = new ArrayList<Account>();

    void open(Account a) {
        accounts.add(a);
    }

    Account find(String id) throws AccountNotFoundException {
        for (Account a : accounts) {
            if (a.getId().equals(id)) {
                return a;
            }
        }
        throw new AccountNotFoundException(id);
    }

    void transfer(String fromId, String toId, int amount)
            throws AccountNotFoundException, InsufficientFundsException {
        Account from = find(fromId);
        Account to = find(toId);
        if (from == to) {
            throw new IllegalArgumentException("cannot transfer to the same account");
        }
        from.withdraw(amount);   // all checks happen here, before any change
        to.deposit(amount);      // cannot fail: amount is already known to be positive
    }

    void printAll() {
        System.out.println("Accounts:");
        for (Account a : accounts) {
            System.out.println(a.getId() + " " + a.getOwner() + " " + a.getBalance() + " Tk");
        }
    }
}

public class BankCommands {
    static int parseAmount(String text) {
        try {
            return Integer.parseInt(text);
        } catch (NumberFormatException e) {
            throw new IllegalArgumentException("invalid amount '" + text + "'", e);
        }
    }

    static void requireArgs(String[] p, int count) {
        if (p.length - 1 != count) {
            throw new IllegalArgumentException(p[0] + " needs " + count + " argument(s)");
        }
    }

    static String execute(Bank bank, String[] p)
            throws AccountNotFoundException, InsufficientFundsException {
        switch (p[0]) {
            case "DEPOSIT": {
                requireArgs(p, 2);
                Account a = bank.find(p[1]);
                int amount = parseAmount(p[2]);
                a.deposit(amount);
                return "deposited " + amount + " Tk to " + p[1] + ", balance "
                        + a.getBalance() + " Tk";
            }
            case "WITHDRAW": {
                requireArgs(p, 2);
                Account a = bank.find(p[1]);
                int amount = parseAmount(p[2]);
                a.withdraw(amount);
                return "withdrew " + amount + " Tk from " + p[1] + ", balance "
                        + a.getBalance() + " Tk";
            }
            case "TRANSFER": {
                requireArgs(p, 3);
                int amount = parseAmount(p[3]);
                bank.transfer(p[1], p[2], amount);
                return "moved " + amount + " Tk from " + p[1] + " to " + p[2];
            }
            case "BALANCE": {
                requireArgs(p, 1);
                Account a = bank.find(p[1]);
                return p[1] + " (" + a.getOwner() + ") has " + a.getBalance() + " Tk";
            }
            default:
                throw new IllegalArgumentException("unknown command " + p[0]);
        }
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Bank bank = new Bank();
        int m = in.nextInt();
        for (int i = 0; i < m; i++) {
            bank.open(new Account(in.next(), in.next(), in.nextInt()));
        }
        int q = in.nextInt();
        in.nextLine();
        for (int i = 0; i < q; i++) {
            String[] parts = in.nextLine().trim().split(" ");
            try {
                System.out.println("OK: " + execute(bank, parts));
            } catch (AccountNotFoundException | InsufficientFundsException e) {
                System.out.println("FAILED: " + e.getMessage());
            } catch (IllegalArgumentException e) {
                System.out.println("FAILED: " + e.getMessage());
            }
        }
        bank.printAll();
    }
}
```

### Explanation
- **Checked vs unchecked:** a missing account or low balance is an expected business
  outcome, so those are checked and every method on the path declares them. Bad
  arguments are caller mistakes, so they use the unchecked
  `IllegalArgumentException`.
- **Atomic transfer:** `transfer` finds both accounts and checks everything inside
  `from.withdraw` *before* any balance changes. If anything fails, an exception leaves
  the method with both balances untouched, as the failed `TRANSFER A102 A103 900`
  shows. `to.deposit` runs only after the withdrawal succeeded.
- **Wrapping:** `parseAmount` turns a `NumberFormatException` into an
  `IllegalArgumentException` with a clearer message and keeps the original as its
  cause.
- **Validate early:** `requireArgs` checks the argument count before any `p[i]` is
  read, so no `ArrayIndexOutOfBoundsException` can occur.
- `main` only translates exceptions into `FAILED:` lines; the rules live in `Account`
  and `Bank`. The `switch` uses braces in each case so each `a` is a separate local
  variable, and every case ends with `return` or `throw`.

## Problem 13: Student Record Importer with Error Causes
**Level:** Advanced

### Problem Statement
Import student records written as comma-separated lines `<id>,<name>,<cgpa>`.

Write a checked exception `RecordException` with a `lineNumber` field and two
constructors: `(int line, String message)` and
`(int line, String message, Throwable cause)`. An `Importer` class has
`void importLine(int lineNumber, String line) throws RecordException`, which checks in

1. Split with `line.split(",", -1)`; exactly 3 fields, else
   `expected 3 fields, found <k>`.
2. The id (trimmed) must parse with `Integer.parseInt`, else
   `id '<text>' is not a number` (with the `NumberFormatException` as cause).

4. The CGPA (trimmed) must parse with `Double.parseDouble`, else

### Sample Input

### Solution
```java
import java.util.ArrayList;
import java.util.Scanner;

class RecordException extends Exception {
    private final int lineNumber;

    RecordException(int lineNumber, String message) {
        super(message);
        this.lineNumber = lineNumber;
    }

    RecordException(int lineNumber, String message, Throwable cause) {
        super(message, cause);
        this.lineNumber = lineNumber;
    }

    int getLineNumber() {
        return lineNumber;
    }
}

class StudentRecord {
    final int id;
    final String name;
    final double cgpa;

    StudentRecord(int id, String name, double cgpa) {
        this.id = id;
        this.name = name;
        this.cgpa = cgpa;
    }
}

class Importer {
    private final ArrayList<StudentRecord> records = new ArrayList<StudentRecord>();

    void importLine(int lineNumber, String line) throws RecordException {
        String[] fields = line.split(",", -1);
        if (fields.length != 3) {
            throw new RecordException(lineNumber,
                    "expected 3 fields, found " + fields.length);
        }
        String idText = fields[0].trim();
        int id;
        try {
            id = Integer.parseInt(idText);
        } catch (NumberFormatException e) {
            throw new RecordException(lineNumber,
                    "id '" + idText + "' is not a number", e);
        }
        String name = fields[1].trim();
        if (name.isEmpty()) {
            throw new RecordException(lineNumber, "name is empty");
        }
        String cgpaText = fields[2].trim();
        double cgpa;
        try {
            cgpa = Double.parseDouble(cgpaText);
        } catch (NumberFormatException e) {
            throw new RecordException(lineNumber,
                    "CGPA '" + cgpaText + "' is not a number", e);
        }
        if (!(cgpa >= 0.0 && cgpa <= 4.0)) {
            throw new RecordException(lineNumber,
                    String.format("CGPA %.2f is outside 0.00-4.00", cgpa));
        }
        for (StudentRecord r : records) {
            if (r.id == id) {
                throw new RecordException(lineNumber, "duplicate id " + id);
            }
        }
        records.add(new StudentRecord(id, name, cgpa));
    }

    int count() {
        return records.size();
    }

    void printSummary() {
        if (records.isEmpty()) {
            return;
        }
        double sum = 0;
        StudentRecord best = records.get(0);
        for (StudentRecord r : records) {
            System.out.printf("%d %s %.2f%n", r.id, r.name, r.cgpa);
            sum += r.cgpa;
            if (r.cgpa > best.cgpa) {
                best = r;
            }
        }
        System.out.printf("Average CGPA: %.2f%n", sum / records.size());
        System.out.printf("Highest CGPA: %s (%.2f)%n", best.name, best.cgpa);
    }
}

public class RecordImport {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = Integer.parseInt(in.nextLine().trim());
        Importer importer = new Importer();
        int rejected = 0;
        for (int k = 1; k <= n; k++) {
            String line = in.nextLine();
            try {
                importer.importLine(k, line);
            } catch (RecordException e) {
                rejected++;
                String text = "Line " + e.getLineNumber() + ": " + e.getMessage();
                if (e.getCause() != null) {
                    text += " [cause: " + e.getCause().getClass().getSimpleName() + "]";
                }
                System.out.println(text);
            }
        }
        System.out.println("Imported " + importer.count() + ", rejected " + rejected);
        importer.printSummary();
    }
}
```

### Explanation
`importLine` converts every low-level problem into one domain exception,
`RecordException`, so the caller needs only one `catch`. When the problem came from
Java (`NumberFormatException`), the original exception is kept as the **cause**
through `super(message, cause)`, and `getCause()` gives it back for the report. The
extra field `lineNumber` shows that an exception is an ordinary object that can carry
any data the handler needs. `split(",", -1)` keeps empty trailing fields, so
`1006,,3.00` would give 3 fields and the clear message `name is empty`. The range
test is written as `!(cgpa >= 0.0 && cgpa <= 4.0)` so that `NaN`, which
`parseDouble` accepts, is also rejected.

```java
import java.util.Scanner;

class ExpressionException extends Exception {
    ExpressionException(String message) {
        super(message);
    }
}

class PostfixCalculator {
    private static boolean isOperator(String token) {
        return token.equals("+") || token.equals("-")
                || token.equals("*") || token.equals("/");
    }

    private static int apply(int a, int b, String op) throws ExpressionException {
        switch (op) {
            case "+":
                return a + b;
            case "-":
                return a - b;
            case "*":
                return a * b;
            default:
                if (b == 0) {
                    throw new ExpressionException("division by zero");
                }
                return a / b;
        }
    }

    private static int parseNumber(String token) throws ExpressionException {
        try {
            return Integer.parseInt(token);
        } catch (NumberFormatException e) {
            throw new ExpressionException("unknown token '" + token + "'");
        }
    }

    int evaluate(String expression) throws ExpressionException {
        String[] tokens = expression.trim().split(" ");
        int[] stack = new int[tokens.length];
        int size = 0;
        for (String token : tokens) {
            if (isOperator(token)) {
                if (size < 2) {
                    throw new ExpressionException("not enough operands for '" + token + "'");
                }
                int b = stack[size - 1];
                int a = stack[size - 2];
                size -= 2;
                stack[size] = apply(a, b, token);
                size++;
            } else {
                int value = parseNumber(token);
                stack[size] = value;
                size++;
            }
        }
        if (size != 1) {
            throw new ExpressionException(size + " values left on the stack");
        }
        return stack[0];
    }
}

public class PostfixEvaluator {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = Integer.parseInt(in.nextLine().trim());
        PostfixCalculator calculator = new PostfixCalculator();
        int evaluated = 0;
        for (int i = 0; i < n; i++) {
            String expression = in.nextLine().trim();
            try {
                int value = calculator.evaluate(expression);
                evaluated++;
                System.out.println(expression + " = " + value);
            } catch (ExpressionException e) {
                System.out.println(expression + " -> error: " + e.getMessage());
            }
        }
        System.out.println("Evaluated " + evaluated + " of " + n);
    }
}
```

### Explanation
The stack is an `int[]` with one slot per token, which is always enough because each
token pushes at most one value. Three of the four errors are found by plain checks
(`size < 2`, `b == 0`, `size != 1`) before anything can go wrong: validate early
instead of letting `ArrayIndexOutOfBoundsException` or `ArithmeticException` happen.
Only the "is this an integer?" question is answered by trying `parseInt`, because
that is the simplest reliable test. Every problem leaves `evaluate` as one checked
`ExpressionException`, so `main` has a single, clear `catch`. Note that the stack is
updated with separate statements (`stack[size] = ...; size++;`) instead of
`stack[size++] = parseNumber(token)`, so the code is easy to trace by hand.

## Problem 15: Shuttle Group Booking with Rollback
**Level:** Advanced

### Problem Statement
A campus shuttle has `S` seats numbered `1..S`. Friends book seats as a group:
either the whole group gets all requested seats, or nobody gets any.

Exceptions (all checked): `ReservationException extends Exception`, with subclasses
`InvalidSeatException` (`seat <s> does not exist (seats 1-<S>)`),
`SeatTakenException` (`seat <s> is taken by <name>`) and `NoBookingException`
(`<name> has no booking`).

Class `Shuttle` stores the passenger name of each seat (`null` = free) and has:

- `reserve(int seat, String name)` and `release(int seat)`
- `bookGroup(String name, int[] seats)`: reserves the seats one by one; if any
  reservation fails, it releases the seats it already reserved for this request and
  **rethrows** the same exception
- `cancel(String name)`: frees all seats of that name and returns how many, or throws
  `NoBookingException`
- `seatMap()`: a line like `1:Rahim 2:- 3:-`

Input: `S`, then `n` commands: `BOOK <name> <k> <s1> ... <sk>`, `CANCEL <name>` or
`SHOW`. Output: `<name>: booked <k> seat(s)`, `<name>: cancelled <c> seat(s)`,
`<name>: failed - <message>` or the seat map.

### Sample Input
```text
6
9
BOOK Rahim 2 1 2
BOOK Karim 3 3 2 4
BOOK Nusrat 2 5 9
SHOW
BOOK Mitu 2 3 3
BOOK Karim 2 3 4
CANCEL Ayesha
CANCEL Rahim
SHOW
```

### Sample Output
```text
Rahim: booked 2 seat(s)
Karim: failed - seat 2 is taken by Rahim
Nusrat: failed - seat 9 does not exist (seats 1-6)
1:Rahim 2:Rahim 3:- 4:- 5:- 6:-
Mitu: failed - seat 3 is taken by Mitu
Karim: booked 2 seat(s)
Ayesha: failed - Ayesha has no booking
Rahim: cancelled 2 seat(s)
1:- 2:- 3:Karim 4:Karim 5:- 6:-
```

### Solution
```java
import java.util.Scanner;

class ReservationException extends Exception {
    ReservationException(String message) {
        super(message);
    }
}

class InvalidSeatException extends ReservationException {
    InvalidSeatException(int seat, int seatCount) {
        super("seat " + seat + " does not exist (seats 1-" + seatCount + ")");
    }
}

class SeatTakenException extends ReservationException {
    SeatTakenException(int seat, String holder) {
        super("seat " + seat + " is taken by " + holder);
    }
}

class NoBookingException extends ReservationException {
    NoBookingException(String name) {
        super(name + " has no booking");
    }
}

class Shuttle {
    private final String[] seats;

    Shuttle(int seatCount) {
        seats = new String[seatCount];
    }

    void reserve(int seat, String name) throws ReservationException {
        if (seat < 1 || seat > seats.length) {
            throw new InvalidSeatException(seat, seats.length);
        }
        if (seats[seat - 1] != null) {
            throw new SeatTakenException(seat, seats[seat - 1]);
        }
        seats[seat - 1] = name;
    }

    void release(int seat) {
        seats[seat - 1] = null;
    }

    void bookGroup(String name, int[] wanted) throws ReservationException {
        int done = 0;
        try {
            for (int seat : wanted) {
                reserve(seat, name);
                done++;
            }
        } catch (ReservationException e) {
            for (int i = 0; i < done; i++) {
                release(wanted[i]);   // undo this request only
            }
            throw e;
        }
    }

    int cancel(String name) throws NoBookingException {
        int freed = 0;
        for (int i = 0; i < seats.length; i++) {
            if (name.equals(seats[i])) {
                seats[i] = null;
                freed++;
            }
        }
        if (freed == 0) {
            throw new NoBookingException(name);
        }
        return freed;
    }

    String seatMap() {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < seats.length; i++) {
            if (i > 0) {
                sb.append(' ');
            }
            sb.append(i + 1).append(':').append(seats[i] == null ? "-" : seats[i]);
        }
        return sb.toString();
    }
}

public class ShuttleBooking {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        Shuttle shuttle = new Shuttle(in.nextInt());
        int n = in.nextInt();
        for (int i = 0; i < n; i++) {
            String command = in.next();
            if (command.equals("SHOW")) {
                System.out.println(shuttle.seatMap());
                continue;
            }
            String name = in.next();
            try {
                if (command.equals("BOOK")) {
                    int[] wanted = new int[in.nextInt()];
                    for (int j = 0; j < wanted.length; j++) {
                        wanted[j] = in.nextInt();
                    }
                    shuttle.bookGroup(name, wanted);
                    System.out.println(name + ": booked " + wanted.length + " seat(s)");
                } else {
                    int freed = shuttle.cancel(name);
                    System.out.println(name + ": cancelled " + freed + " seat(s)");
                }
            } catch (ReservationException e) {
                System.out.println(name + ": failed - " + e.getMessage());
            }
        }
    }
}
```

### Explanation
- **Catch, clean up, rethrow:** `bookGroup` catches the failure only to undo its own
  partial work, then `throw e;` passes the same exception on. The method that knows
  *how to undo* (the shuttle) does the cleanup; the method that knows *how to report*
  (`main`) prints the message.
- `done` counts the seats reserved so far, so the rollback releases exactly those and
  never a seat held by somebody else. Karim's first request reserved seat 3 before
  seat 2 failed; the first `SHOW` proves seat 3 was released.
- Mitu's request `3 3` fails on the second 3 because her own first reservation already
  took it; rollback frees it again.
- All exception classes share the base `ReservationException`, so `main` needs one
  `catch`, and the methods can declare one type. `cancel` declares the more specific
  `NoBookingException`, which is still caught by that `catch`.
- `name.equals(seats[i])` is written with `name` first, so a free seat (`null`) never
  causes a `NullPointerException`.
