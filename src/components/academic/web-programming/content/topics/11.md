# PHP Conditions, Loops and Functions

## if, elseif, else

Same idea as JavaScript, but PHP writes **`elseif`** as one word (`else if` also works).

```php
<?php
$total = 105;

if ($total >= 120) {
    $level = "Excellent";
} elseif ($total >= 90) {
    $level = "Good";
} elseif ($total >= 60) {
    $level = "Average";
} else {
    $level = "Poor";
}
echo "Performance: $level";   // Performance: Good
```

Go from the highest range down so every value gets a level.

## Ternary and match

```php
<?php
$status = $total > 54 ? "Passed" : "Failed";

$message = match ($grade) {          // PHP 8
    "A" => "Excellent",
    "B" => "Good",
    default => "Keep trying",
};
```

```php

    case "Dhaka":
        $tax = 0.20;
        break;
    case "Chittagong":
        $tax = 0.15;
        break;
    default:
        $tax = 0;

```

## Comparing with a target (exam pattern)

```php
<?php
$total = 105;
$target = 100;
$diff = $total - $target;

if ($diff > 0) {
    echo "Above target by $diff";
} elseif ($diff < 0) {
    echo "Below target by " . abs($diff);
} else {
    echo "Target met exactly (0 difference)";
}
```

## for

```php
<?php
for ($i = 1; $i <= 5; $i++) {
    echo $i . " ";
}
// 1 2 3 4 5
```

## while and do...while

```php
<?php
$n = 1234;
$sum = 0;
while ($n > 0) {
    $sum += $n % 10;
    $n = intdiv($n, 10);
}
echo $sum;   // 10

$i = 0;
do {
    $i++;
} while ($i < 3);
echo $i;     // 3
```

## foreach

The easiest way to walk through an array (topic 12):

```php
<?php
$cts = [12, 15, 14];
foreach ($cts as $mark) {
    echo $mark . "<br>";
}
```

## Pattern: multiplication table as an HTML table

```php
<?php
$n = 5;
echo "<table border='1' cellpadding='6'>";
for ($i = 1; $i <= 10; $i++) {
    echo "<tr><td>$n x $i</td><td>" . ($n * $i) . "</td></tr>";
}
echo "</table>";
```

## Functions

```php
<?php
function average($total, $count) {
    return $total / $count;
}
echo average(14, 4);   // 3.5
```

- Default values: `function greet($name = "Student") { ... }`
- A function cannot see variables from outside unless they are passed in (or declared `global`). **Pass them as parameters.**

```php
<?php
$rate = 4.19;
function cost($units) {
    // echo $rate;  would be an "Undefined variable" warning here
    return $units * 4.19;
}
```

## Pattern: digit sum

```php
<?php
function digitSum($n) {
    $sum = 0;
    foreach (str_split((string) $n) as $d) {
        $sum += (int) $d;
    }
    return $sum;
}
echo digitSum(29);   // 11
```

## Pattern: whole units needed (ceil)

Pizzas, venues, screens, fuel modules: whenever you need "enough whole units to cover a total", divide and round **up**.

```php
<?php
$needed = 30;       // slices
$perUnit = 8;       // slices per pizza
$units = ceil($needed / $perUnit);        // 4
$leftover = $units * $perUnit - $needed;  // 2
```

## Common mistakes

- `else if` vs `elseif`: both work, but `elseif` is the PHP style.
- Using a global variable inside a function without passing it.
- Off-by-one in loops (`<` vs `<=`).
- Forgetting that `ceil()` returns a float: `ceil(30/8)` prints `4`, but `var_dump` shows `float(4)`. Cast with `(int)` if you need an integer.
