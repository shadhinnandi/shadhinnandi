# PHP Arrays and Strings

## Indexed arrays

```php
<?php
$cts = [12, 15, 14];
echo $cts[0];          // 12
echo count($cts);      // 3
$cts[] = 18;           // add to the end
array_push($cts, 10);  // also adds to the end
```

## Associative arrays (key => value)

Like a small table row: each value has a name.

```php
<?php
$rates = [
    "Dhaka" => 7.5,
    "Chattogram" => 7.0,
    "Other" => 6.5,
];
echo $rates["Dhaka"];   // 7.5

foreach ($rates as $city => $rate) {
    echo "$city: $rate<br>";
}
```

A database row from MySQLi (topic 17) is an associative array: `$row["StudentName"]`.

## Nested arrays

```php
<?php
$billRates = [
    "Dhaka" => ["Urban" => [4.19, 5.72, 6.00], "Rural" => [3.19, 4.72, 5.00]],
];
echo $billRates["Dhaka"]["Urban"][1];   // 5.72
```

## Useful array functions

| Function | Does | Example | Result |
|---|---|---|---|
| `count($a)` | Number of items | `count([1,2,3])` | `3` |
| `array_sum($a)` | Add all | `array_sum([12,15,14])` | `41` |
| `max($a)` / `min($a)` | Largest / smallest | `min([12,15,14])` | `12` |
| `in_array($x, $a)` | Is x inside? | `in_array(15, [12,15])` | `true` |
| `implode(", ", $a)` | Array to text | `implode(", ", ["a","b"])` | `"a, b"` |
| `explode(",", $s)` | Text to array | `explode(",", "a,b")` | `["a","b"]` |
| `sort($a)` | Sort ascending (numbers as numbers) | | |
| `rsort($a)` | Sort descending | | |
| `asort` / `arsort` | Sort by value, keep keys | | |
| `ksort` | Sort by key | | |
| `array_slice($a, 0, 2)` | First two items | | |
| `print_r($a)` | Show an array (debugging) | | |

Unlike JavaScript, PHP's `sort()` compares numbers **as numbers**, so `sort([10, 9, 100])` gives `[9, 10, 100]`.

## Best two out of three

```php
<?php
$cts = [12, 15, 14];
rsort($cts);                        // [15, 14, 12]
$bestTwo = $cts[0] + $cts[1];       // 29
// or: array_sum($cts) - min($cts)  // 29
$average = $bestTwo / 2;            // 14.5
```

## Strings

```php
<?php
$s = "Web Programming";
echo strlen($s);                 // 15
echo strtoupper($s);             // WEB PROGRAMMING
echo strtolower($s);             // web programming
echo ucfirst("karim");           // Karim
echo strrev("abc");              // cba
echo substr($s, 0, 3);           // Web
echo str_replace("Web", "PHP", $s); // PHP Programming
echo strpos($s, "Pro");          // 4   (false if not found)
echo trim("  hi  ");             // hi
echo str_repeat("*", 3);         // ***
echo $s[0];                      // W
```

PHP 8 also has `str_contains($s, "Pro")`, `str_starts_with`, `str_ends_with`.

## Palindrome in PHP

```php
<?php
$word = "1aBcbA1";
$lower = strtolower($word);
echo $lower === strrev($lower) ? "Yes" : "No";   // Yes
```

## Checking characters in a password

`preg_match` returns 1 when the pattern is found:

```php
<?php
$p = "aFDF@F1ds*";
$hasUpper   = preg_match('/[A-Z]/', $p);
$hasLower   = preg_match('/[a-z]/', $p);
$hasDigit   = preg_match('/[0-9]/', $p);
$hasSpecial = preg_match('/[^A-Za-z0-9]/', $p);
$endsStar   = str_ends_with($p, "*");    // or substr($p, -1) === "*"
```

Without regular expressions: loop with `ctype_upper($ch)`, `ctype_lower($ch)`, `ctype_digit($ch)`.

## Formatting numbers

```php
<?php
echo number_format(8400);          // 8,400
echo number_format(1328.7, 2);     // 1,328.70
echo round(25.6239, 2);            // 25.62
printf("%.2f", 3.14159);           // 3.14
```

## Common mistakes

- `count` vs `strlen`: `count` for arrays, `strlen` for strings.
- Expecting `sort()` to return the sorted array: it sorts **in place** and returns `true`.
- `strpos()` can return `0` (found at the start). Test with `!== false`, not with `if (strpos(...))`.
