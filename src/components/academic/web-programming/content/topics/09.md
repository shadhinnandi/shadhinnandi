# JavaScript State, Validation and Exam Patterns

## Functions

A **function** is a named block of code you can call again and again.

```javascript
function average(total, count) {   // total and count are parameters
    return total / count;          // return sends a value back
}
let avg = average(14, 4);          // 14 and 4 are arguments; avg = 3.5
```

A function called from a button usually returns nothing; it reads inputs and writes results.

## State: remembering values between clicks

Every exam Question 1 says something like "add to a **running total**", "**keep track** of the number of entries" or "store each subject". Each click runs the function again, so these values must live **outside** the function:

```javascript
let total = 0;        // survives between clicks
let count = 0;
let subjects = [];

function addStudy() {
    let hours = parseFloat(document.getElementById("hours").value);
    total += hours;   // running total
    count++;          // number of entries
    // ...
}
```

If you write `let total = 0;` **inside** the function, the total starts at 0 on every click. This is the most common reason a Question 1 loses marks.

## Validation

Check the inputs before calculating, and stop with `return` if something is wrong:

```javascript
function calculate() {
    let units = parseFloat(document.getElementById("units").value);
    let location = document.getElementById("location").value;

    if (location === "") {
        document.getElementById("result").innerHTML = "Please select a location.";
        return;                               // stop here
    }
    if (isNaN(units) || units <= 0) {
        document.getElementById("result").innerHTML = "Units must be a positive number.";
        return;
    }
    // ... safe to calculate
}
```

| Check | Code |
|---|---|
| Empty text field | `if (name.trim() === "")` |
| Not a number | `if (isNaN(n))` |
| Positive number | `if (n > 0)` |
| A radio button chosen | `document.getElementById("urban").checked \|\| document.getElementById("rural").checked` |
| A select option chosen | `if (select.value !== "")` |

## Random numbers

`Math.random()` gives a decimal from 0 up to (not including) 1. A whole number between `min` and `max` (both included):

```javascript
function randomBetween(min, max) {
    return Math.floor(Math.random() * (max - min + 1)) + min;
}
let secret = randomBetween(500, 5000);
```

## Rounding for display

```javascript
let avg = 15 / 8;              // 1.875
avg.toFixed(2);                // "1.88" (string, 2 decimals)
Math.round(avg * 100) / 100;   // 1.88 (number)
```

Show the value the question shows: if the sample prints `1.875`, do not round it.

## Pattern 1: running total with feedback (261 Set A, 252)

```javascript
const GOAL = 2000;
let total = 0;
let entries = 0;

function addCalories() {
    let cal = parseFloat(document.getElementById("calories").value);
    if (isNaN(cal) || cal < 0) {
        document.getElementById("result").innerHTML = "Enter a valid number.";
        return;
    }
    total += cal;
    entries++;

    let msg;
    if (total >= GOAL) msg = "Goal reached! Stay mindful!";
    else if (total > 1600) msg = "Almost at your limit!";
    else if (total > 800) msg = "Good progress, keep it balanced!";
    else msg = "You're off to a healthy start!";

    if (entries > 10 && total < GOAL) msg = "Be cautious of frequent snacking!";

    document.getElementById("result").innerHTML = `Total: ${total} calories<br>${msg}`;
}
```

## Pattern 2: arrays of readings with averages (261 Set B)

```javascript
let rates = [];

function save() {
    rates.push(parseFloat(document.getElementById("rate").value));
    let sum = 0;
    for (let r of rates) sum += r;
    let avg = sum / rates.length;
    document.getElementById("report").innerHTML = `Average: ${Number(avg.toFixed(2))}`;
}
```

## Pattern 3: limited attempts (243 guessing game)

```javascript
let attempts = 0;
const MAX = 5;

function guess() {
    attempts++;
    // compare...
    if (attempts >= MAX) {
        document.getElementById("guess").disabled = true;
    }
}
```

## Pattern 4: convert, calculate, classify (241 BMI)

```javascript
function calculate() {
    let cm = parseFloat(document.getElementById("height").value);
    let lb = parseFloat(document.getElementById("weight").value);
    let m = cm / 100;
    let kg = lb / 2.2046;
    let result = kg / (m * m);
    document.getElementById("result").innerHTML = `Calculation Result: ${result.toFixed(2)}`;
}
```

## How to adapt a pattern

1. List what must be **remembered between clicks** → globals above the function.
2. List the **inputs** → one `getElementById(...).value` line each, converted to numbers.
3. Do the **calculation** in the order the question lists it.
4. Translate the **feedback ranges** into an `if / else if` chain from the top.
5. Add the **special rule** last (e.g. "more than 7 sessions without reaching 20"), so it overrides the normal feedback.
6. Write every required value to the result area.

## Common mistakes

- Globals declared inside the function (state resets).
- Calculating the average before incrementing the counter (divides by the old count).
- Forgetting the special rule must win over the range message: check it **after** the ranges.
