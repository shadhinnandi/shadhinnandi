# JavaScript Strings and Patterns

## Strings

A **string** is text inside quotes: `"Hello"`, `'Hello'` or `` `Hello` ``.

```javascript
let word = "Physics";
console.log(word.length);        // 7
console.log(word[0]);            // "P"
console.log(word[word.length - 1]); // "s"
```

## Joining text

```javascript
let name = "Karim";
let msg1 = "Hello " + name + "!";   // concatenation with +
let msg2 = `Hello ${name}!`;        // template literal (backticks)
```

Remember: `"5" + 2` is `"52"` (text). `"5" - 2` is `3` (JavaScript converts for `-`, `*`, `/`). Convert with `parseInt` before adding.

## String methods

| Method | Example | Result |
|---|---|---|
| `toUpperCase()` | `"abc".toUpperCase()` | `"ABC"` |
| `toLowerCase()` | `"aBc".toLowerCase()` | `"abc"` |
| `trim()` | `"  hi  ".trim()` | `"hi"` |
| `includes(x)` | `"Cox's Beach".includes("Beach")` | `true` |
| `indexOf(x)` | `"hello".indexOf("l")` | `2` |
| `slice(a, b)` | `"Physics".slice(0, 3)` | `"Phy"` |
| `substring(a, b)` | `"Physics".substring(2, 4)` | `"ys"` |
| `replace(a, b)` | `"a-b".replace("-", "+")` | `"a+b"` |
| `split(x)` | `"a,b,c".split(",")` | `["a", "b", "c"]` |
| `endsWith(x)` | `"pass*".endsWith("*")` | `true` |
| `repeat(n)` | `"*".repeat(3)` | `"***"` |

## Reversing a string

There is no `reverse()` for strings. Split into an array, reverse, join:

```javascript
let s = "abc";
let reversed = s.split("").reverse().join("");   // "cba"
```

With a loop:

```javascript
let reversed = "";
for (let i = s.length - 1; i >= 0; i--) {
    reversed += s[i];
}
```

## Palindrome (case-insensitive)

A palindrome reads the same forwards and backwards (`1aBcbA1`).

```javascript
function isPalindrome(text) {
    let s = text.toLowerCase();
    let reversed = s.split("").reverse().join("");
    return s === reversed;
}
isPalindrome("1aBcbA1");   // true
isPalindrome("baCbb");     // false
```

`toLowerCase()` first makes `B` and `b` equal: that is what "case-insensitive" means.

## Counting characters

```javascript
let text = "Web Programming";
let vowels = 0;
for (let ch of text.toLowerCase()) {
    if ("aeiou".includes(ch)) vowels++;
}
// vowels = 4
```

## Checking what a password contains

Regular expressions (`/.../`) with `.test()` answer "does the text contain...?":

| Check | Code |
|---|---|
| An uppercase letter | `/[A-Z]/.test(p)` |
| A lowercase letter | `/[a-z]/.test(p)` |
| A digit | `/[0-9]/.test(p)` |
| A special character from `!@#$%^&*` | `/[!@#$%^&*]/.test(p)` |
| Any non-letter, non-digit | `/[^A-Za-z0-9]/.test(p)` |
| Ends with `*` | `p.endsWith("*")` |

```javascript
let p = "Strong@Pass";
let points = 0;
if (/[A-Z]/.test(p)) points += 15;
if (/[a-z]/.test(p)) points += 15;
if (/[0-9]/.test(p)) points += 20;
if (/[!@#$%^&*]/.test(p)) points += 25;
// points = 55 (no digit)
```

Without regular expressions, loop and compare characters:

```javascript
let hasUpper = false;
for (let ch of p) {
    if (ch >= "A" && ch <= "Z") hasUpper = true;
}
```

## Numbers as text

```javascript
(3.14159).toFixed(2);     // "3.14"
(1.875).toFixed(2);       // "1.88"
String(42);               // "42"
```

## Common mistakes

- Comparing without `toLowerCase()` when the question says case-insensitive.
- `s.reverse()`: strings have no reverse; split first.
- Forgetting that `toFixed()` returns a **string**; convert back with `Number()` if you calculate further.
