# HTML Basics

## What HTML is

**HTML** (HyperText Markup Language) describes what is on a page. It is made of **tags** such as `<p>` and `<input>`. Most tags have an opening and a closing tag; some (like `<input>` and `<br>`) stand alone.

## The page skeleton

Every exam page starts like this:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Page</title>
</head>
<body>
    <h1>Hello</h1>
    <p>This is a paragraph.</p>
</body>
</html>
```

- `<head>` holds information about the page (title, CSS links).
- `<body>` holds what the user sees.

## Text tags you need

| Tag | Use |
|---|---|
| `<h1>` to `<h6>` | Headings, `<h1>` is the biggest |
| `<p>` | A paragraph |
| `<br>` | A line break |
| `<strong>` | Bold text |
| `<a href="page.html">Link</a>` | A link |
| `<div>` | A block box, often used as the **result area** |
| `<label>` | Text that names an input |

## Inputs

```html
<input type="text" id="name" placeholder="Subject name">
<input type="number" id="hours" placeholder="Study hours">
<input type="password" id="pass">
<input type="email" id="mail">
```

| Type | Shows |
|---|---|
| `text` | A one-line text box |
| `number` | A box for numbers (still returns a **string** in JavaScript) |
| `password` | Hides the typed characters |
| `email` | Checks for an @ when inside a form |
| `submit` | A button that submits a form |

**Radio buttons** let the user pick **one** option. They share the same `name`:

```html
<input type="radio" name="area" id="urban" value="Urban"> Urban
<input type="radio" name="area" id="rural" value="Rural"> Rural
```

**Checkboxes** let the user pick several:

```html
<input type="checkbox" name="extras[]" value="Wifi"> Wifi
<input type="checkbox" name="extras[]" value="Meal"> Meal
```

**A dropdown** (`select`):

```html
<select id="location" name="location">
    <option value="">-- Select location --</option>
    <option value="Dhaka">Dhaka</option>
    <option value="Chattogram">Chattogram</option>
    <option value="Other">Other</option>
</select>
```

**A text area and buttons**:

```html
<textarea id="note" rows="3" cols="30"></textarea>
<button onclick="calculate()">Calculate</button>
```

## id and name: two different jobs

| Attribute | Used by | Example |
|---|---|---|
| `id` | **JavaScript**, to find the element | `document.getElementById("hours")` |
| `name` | **PHP**, to read the submitted value | `$_POST["hours"]` |

An input can have both: `<input type="number" id="hours" name="hours">`. An `id` must be **unique** on the page.

## Forms

A form sends its inputs to PHP when submitted:

```html
<form method="POST" action="">
    <label>Credits per course:</label>
    <input type="number" name="credits"><br><br>

    <label>Courses completed:</label>
    <input type="number" name="courses"><br><br>

    <input type="submit" value="Calculate">
</form>
```

- `method="POST"` sends the values in the request body. **This course always uses POST.**
- `action=""` (or leaving `action` out) sends the form to the **same file**, which is how our one-file PHP answers work.

## Tables

Tables show rows of results, especially database records:

```html
<table border="1">
    <tr><th>Name</th><th>Marks</th></tr>
    <tr><td>Karim</td><td>85</td></tr>
    <tr><td>Rahim</td><td>92</td></tr>
</table>
```

`<tr>` is a row, `<th>` a heading cell, `<td>` a data cell.

## Common mistakes

- Two elements with the same `id`: `getElementById` finds only the first.
- Forgetting `name` on an input: PHP never receives that value.
- Radio buttons with different `name`s: the user can select both.
- Putting inputs outside the form element: they are not submitted.
