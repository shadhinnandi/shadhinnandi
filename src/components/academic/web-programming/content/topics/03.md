# JavaScript Fundamentals

## What JavaScript is

**JavaScript** is a programming language that runs **inside the browser**. It can read what the user typed, calculate, and change the page without reloading it.

| | JavaScript | PHP |
|---|---|---|
| Runs | In the browser (on the user's computer) | On the server (Apache in XAMPP) |
| Starts | When the page loads or a button is clicked | When a page is requested or a form is submitted |
| Sees | The page (HTML elements) | Form data, files, the database |
| Needs a server? | No, open the .html file directly | Yes, through http://localhost |

## Where JavaScript goes

**Inside the page** with a `<script>` tag:

```html
<script>
    console.log("Hello from JavaScript");
</script>
```

**In a separate file** (what the exam papers call `script.js`):

```html
<!-- index.html, just before </body> -->
<script src="script.js"></script>
```

Put the script tag at the **end of the body**, so the inputs exist before the script runs.

## Variables

```javascript
let total = 0;          // can change later
const GOAL = 20;        // never changes
var old = "avoid";      // older style, works but prefer let / const
```

- Use **`const`** for values that never change (a goal, a price, a rate).
- Use **`let`** for everything that changes (totals, counters, inputs).
- Variable names are case-sensitive: `total` and `Total` are different.

## Data types

```javascript
let hours = 3.5;               // number (whole or decimal)
let name = "Physics";          // string (text)
let done = true;               // boolean (true or false)
let subjects = ["Math", "ICT"];// array (a list)
let empty;                     // undefined (no value yet)
```

`typeof` tells you the type: `typeof hours` is `"number"`, `typeof name` is `"string"`.

## Operators

| Kind | Operators | Example | Result |
|---|---|---|---|
| Arithmetic | `+ - * / %` | `17 % 5` | `2` (remainder) |
| Power | `**` | `2 ** 3` | `8` |
| Assignment | `= += -= *= /=` | `total += 4` | adds 4 to total |
| Increment | `++ --` | `count++` | count goes up by 1 |
| Comparison | `== === != !== < > <= >=` | `5 === "5"` | `false` |
| Logical | `&& \|\| !` | `a > 0 && b > 0` | true if both are true |

Use **`===`** (strict equal). `==` converts types first, so `5 == "5"` is `true`, which can hide bugs.

## Strings and numbers: the most common bug

Values from inputs are **strings**. `+` joins strings instead of adding:

```javascript
let a = "2";
let b = "3";
console.log(a + b);                         // "23"  (joined)
console.log(parseInt(a) + parseInt(b));     // 5     (added)
console.log(Number(a) + Number(b));         // 5
console.log(parseFloat("3.75") + 1);        // 4.75
```

| Function | Use when | Example |
|---|---|---|
| `parseInt(x)` | Whole numbers | `parseInt("42")` gives `42` |
| `parseFloat(x)` | Decimals | `parseFloat("4.5")` gives `4.5` |
| `Number(x)` | Either; empty text gives 0 | `Number("12")` gives `12` |

If the text is not a number, you get `NaN` (Not a Number). Check it with `isNaN(value)`.

## Useful Math functions

```javascript
Math.round(4.6);        // 5
Math.floor(4.6);        // 4  (round down)
Math.ceil(4.1);         // 5  (round up)
Math.abs(78 - 80);      // 2  (positive difference)
Math.max(12, 15, 14);   // 15
Math.min(12, 15, 14);   // 12
Math.random();          // a decimal from 0 up to (not including) 1
(25.623).toFixed(2);    // "25.62" (a string with 2 decimals)
```

## Common mistakes

- Adding input values without `parseInt` / `parseFloat` (you get `"23"` instead of `5`).
- Using `=` (assign) inside `if` instead of `===` (compare).
- Declaring a running total **inside** the function (it resets to 0 every click; see topic 09).
- Forgetting the semicolon is usually fine in JavaScript, but be consistent.
