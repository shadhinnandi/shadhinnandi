# JavaScript Loops

## Why loops

A loop repeats code. Use it to add many numbers, walk through an array, or build a table.

## for

Use **for** when you know how many times to repeat.

```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
// 1 2 3 4 5
```

The three parts: **start** (`let i = 1`), **condition** (`i <= 5`), **step** (`i++`).

## while

Use **while** when you repeat **until something happens**.

```javascript
let n = 1234;
let sum = 0;
while (n > 0) {
    sum += n % 10;          // last digit
    n = Math.floor(n / 10); // remove the last digit
}
console.log(sum); // 10
```

## do...while

Runs the body **at least once**, then checks.

```javascript
let tries = 0;
do {
    tries++;
} while (tries < 3);
console.log(tries); // 3
```

## break and continue

```javascript
for (let i = 1; i <= 10; i++) {
    if (i === 4) continue; // skip 4
    if (i === 7) break;    // stop the loop at 7
    console.log(i);        // 1 2 3 5 6
}
```

## Pattern: sum and average

```javascript
let marks = [80, 75, 90];
let sum = 0;
for (let i = 0; i < marks.length; i++) {
    sum += marks[i];
}
let average = sum / marks.length;   // 81.67 (approx)
```

## Pattern: multiplication table in HTML

```javascript
let n = 5;
let html = "<table border='1'>";
for (let row = 1; row <= n; row++) {
    html += "<tr>";
    for (let col = 1; col <= n; col++) {
        html += `<td>${row * col}</td>`;
    }
    html += "</tr>";
}
html += "</table>";
document.getElementById("table").innerHTML = html;
```

The **outer** loop makes rows, the **inner** loop makes the cells of one row (a nested loop).

## Pattern: a star triangle

```javascript
let out = "";
for (let i = 1; i <= 4; i++) {
    out += "*".repeat(i) + "<br>";
}
document.getElementById("pattern").innerHTML = out;
// *
// **
// ***
// ****
```

## Loop over a string

```javascript
let word = "Hello";
for (let i = 0; i < word.length; i++) {
    console.log(word[i]); // H e l l o
}
```

## Common mistakes

- `for (let i = 0; i <= arr.length; i++)`: one step too far, the last value is `undefined`. Use `<`.
- A `while` loop whose variable never changes: an **infinite loop** that freezes the page.
- Assigning to `innerHTML` inside the loop with `=`: only the last row survives. Build a string, then assign once (or use `+=`).
