# JavaScript and the Page (DOM)

## What the DOM is

The **DOM** (Document Object Model) is the page as JavaScript sees it: every HTML element is an object you can read and change. In this course we use one method to find elements: **`document.getElementById()`**.

## The three steps of every exam page

1. **Read** the input: `document.getElementById("hours").value`
2. **Calculate** in a function.
3. **Write** the result: `document.getElementById("result").innerHTML = ...`

## Complete example: add two numbers

**index.html**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Add</title>
</head>
<body>
    <input type="number" id="num1" placeholder="First number"><br><br>
    <input type="number" id="num2" placeholder="Second number"><br><br>
    <button onclick="add()">Add</button>

    <div id="output"></div>

    <script src="script.js"></script>
</body>
</html>
```

**script.js**

```javascript
function add() {
    let a = parseInt(document.getElementById("num1").value);
    let b = parseInt(document.getElementById("num2").value);

    document.getElementById("output").innerHTML = `${a} + ${b} = ${a + b}`;
}
```

Output after typing 4 and 7 and clicking Add: `4 + 7 = 11`

## Reading values

```javascript
let text = document.getElementById("name").value;              // a string
let hours = parseFloat(document.getElementById("hours").value); // a number
let location = document.getElementById("location").value;      // selected option of a <select>
let urban = document.getElementById("urban").checked;          // true / false for a radio or checkbox
```

## Writing results

`innerHTML` replaces what is inside an element. It can contain HTML:

```javascript
document.getElementById("result").innerHTML = "Total: 14 hours";
document.getElementById("result").innerHTML = "<strong>Status: Passed</strong>";
document.getElementById("result").innerHTML += "<br>One more line"; // add to the end
```

**Template literals** (backticks) put variables into text with `${ }`:

```javascript
let total = 14;
let average = 3.5;
document.getElementById("result").innerHTML = `Total: ${total} hours, Average: ${average} hours`;
```

## Connecting a button to a function

```html
<button onclick="addStudy()">Add Study</button>
```

When the button is clicked, the browser calls `addStudy()` from `script.js`. The function name in `onclick` must match exactly (case-sensitive).

## Changing other things

```javascript
document.getElementById("guess").disabled = true;   // stop further typing
document.getElementById("btn").disabled = true;     // disable a button
document.getElementById("hours").value = "";        // clear an input
document.getElementById("status").style.color = "red";
```

## alert, prompt and console.log

| Function | Shows | Use in the exam |
|---|---|---|
| `alert("text")` | A pop-up message | When the question says "display in an alert box" (242 Q1) |
| `prompt("question")` | A pop-up input, returns a string | Quick input without HTML fields |
| `console.log(x)` | Text in the console (F12) | Checking values while you debug |

## Building a list or table with a loop

```javascript
let subjects = ["Math", "Physics", "ICT"];
let html = "<ul>";
for (let i = 0; i < subjects.length; i++) {
    html += `<li>${subjects[i]}</li>`;
}
html += "</ul>";
document.getElementById("list").innerHTML = html;
```

Build the whole string first, then assign it **once** to `innerHTML`.

## Common mistakes

- `getElementByID` (capital D): the method is `getElementById`.
- Reading `.value` of a `<div>`: a div has `innerHTML`, inputs have `value`.
- The `<script src="script.js">` tag in `<head>` without `defer`: the inputs do not exist yet when the script runs. Put it at the end of `<body>`.
- Using the input's `name` in `getElementById`: it needs the `id`.
