# XAMPP and Database Setup

## What XAMPP gives you

**XAMPP** installs everything needed to run PHP and MySQL on your own computer:

| Part | What it does | Address |
|---|---|---|
| **Apache** | The web server that runs `.php` files | http://localhost |
| **MySQL / MariaDB** | The database server | port 3306 |
| **PHP** | The language Apache runs | |
| **phpMyAdmin** | A web page for managing databases | http://localhost/phpmyadmin |

XAMPP ships **MariaDB**, a drop-in replacement for MySQL. The SQL and the PHP code are the same; the control panel still calls it "MySQL".

## Installing and starting

1. Download XAMPP from apachefriends.org and install it with the default options.
2. Open the **XAMPP Control Panel** (macOS: `manager-osx` in the XAMPP folder, "Manage Servers" tab).
3. Click **Start** for **Apache** and **MySQL**. Both should turn green.
4. Open **http://localhost** to see the XAMPP dashboard, and **http://localhost/phpmyadmin** for phpMyAdmin.

## Where your files go: htdocs

Apache only serves files inside the **htdocs** folder:

| System | htdocs |
|---|---|
| Windows | `C:\xampp\htdocs\` |
| macOS | `/Applications/XAMPP/xamppfiles/htdocs/` |
| Linux | `/opt/lampp/htdocs/` |

A good layout for the exam:

```text
htdocs/
  final/
    q1/  index.html  script.js
    q2/  index.php
    q3/  index.php   setup.sql
```

`htdocs/final/q2/index.php` opens at **http://localhost/final/q2/** (`index.php` loads automatically) or **http://localhost/final/q2/index.php**.

## Default login

| Setting | XAMPP default |
|---|---|
| Server | `localhost` |
| Username | `root` |
| Password | `""` (empty) |
| Port | `3306` |

Exam answers use these defaults. A real website must never use `root` without a password.

## Database, table, row, column

| Term | Meaning | Example |
|---|---|---|
| Database | A container for related tables | `uiu_demo` |
| Table | One kind of thing, in rows and columns | `students` |
| Row (record) | One item | Karim Uddin, CSE, 3.75 |
| Column (field) | One property | `cgpa` |
| Primary key | A column that identifies each row uniquely | `id` |

## Creating a database in phpMyAdmin

1. Open http://localhost/phpmyadmin.
2. Click **New** in the left panel.
3. Type the database name (e.g. `uiu_demo`), keep collation `utf8mb4_general_ci`, click **Create**.
4. Create a table: give its name and number of columns, then fill in each column's **Name**, **Type**, **Length** and tick **A_I** (auto increment) for the id (this also makes it the primary key).
5. Click **Save**, then use the **Insert** tab to add rows.

Faster and exam-friendly: click the **SQL** tab and paste SQL.

## Creating everything with SQL

```sql
CREATE DATABASE uiu_demo;
USE uiu_demo;

CREATE TABLE departments (
    dept_code VARCHAR(10) PRIMARY KEY,
    dept_name VARCHAR(100) NOT NULL,
    building VARCHAR(20)
);

CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    dept_code VARCHAR(10),
    cgpa DECIMAL(3,2),
    credits INT,
    city VARCHAR(50),
    FOREIGN KEY (dept_code) REFERENCES departments(dept_code)
);

INSERT INTO departments (dept_code, dept_name, building) VALUES
('CSE', 'Computer Science and Engineering', 'Building A'),
('EEE', 'Electrical and Electronic Engineering', 'Building B'),
('BBA', 'Business Administration', 'Building C'),
('CE',  'Civil Engineering', 'Building D');

INSERT INTO students (name, dept_code, cgpa, credits, city) VALUES
('Karim Uddin',    'CSE', 3.75, 90,  'Dhaka'),
('Rahima Akter',   'EEE', 3.40, 75,  'Chittagong'),
('Jashim Hossain', 'CSE', 2.95, 60,  'Dhaka'),
('Faria Karim',    'BBA', 3.85, 100, 'Sylhet'),
('Nadia Islam',    'CSE', 3.10, 45,  'Khulna'),
('Tanvir Ahmed',   'EEE', 2.70, 30,  'Dhaka');
```

This **`uiu_demo`** database is the example used in topics 15 to 18. Paste it into the SQL tab once and try every query there.

## Data types you need

| Type | Stores | Example |
|---|---|---|
| `INT` | Whole numbers | `credits INT` |
| `DECIMAL(p,s)` | Exact decimals: p digits, s after the point | `cgpa DECIMAL(3,2)` holds 3.75; `price DECIMAL(10,2)` |
| `FLOAT` / `DOUBLE` | Approximate decimals | `rate_0_75 FLOAT` |
| `VARCHAR(n)` | Text up to n characters | `name VARCHAR(100)` |
| `TEXT` | Long text | `note TEXT` |
| `DATE` | `YYYY-MM-DD` | `'2024-01-03'` |
| `DATETIME` | Date and time | `'2024-01-03 14:30:00'` |

Prefer **DECIMAL** for money and ratings: `FLOAT` can store 4.3 as 4.300000190734863, which makes `WHERE Rating = 4.3` fail.

## Constraints

| Constraint | Meaning |
|---|---|
| `PRIMARY KEY` | Unique and not empty; one per table |
| `AUTO_INCREMENT` | MySQL fills in 1, 2, 3... (leave the column out of INSERT) |
| `NOT NULL` | Must have a value |
| `UNIQUE` | No two rows may share the value |
| `DEFAULT x` | Value used when none is given |
| `FOREIGN KEY ... REFERENCES` | Must match a value in another table |

## Text with an apostrophe

Strings use single quotes, so a quote **inside** the text must be doubled or escaped:

```sql
INSERT INTO places (name) VALUES ('Cox''s Bazar Beach');
INSERT INTO places (name) VALUES ('Cox\'s Bazar Beach');
```

## Export and import a .sql file

Some papers ask you to **submit the database as a .sql file**:

- **Export:** select the database in phpMyAdmin, **Export** tab, format **SQL**, click **Export**. A `uiu_demo.sql` file downloads.
- **Import:** select (or create) the database, **Import** tab, choose the file, click **Import**.

## Changing a table later

```sql
ALTER TABLE students ADD email VARCHAR(100);
ALTER TABLE students MODIFY city VARCHAR(80);
ALTER TABLE students DROP COLUMN email;
DROP TABLE students;          -- deletes the table and its data
DROP DATABASE uiu_demo;       -- deletes everything
```

## Common setup problems

| Problem | Cause | Fix |
|---|---|---|
| Apache will not start | Port 80 used by another program (Skype, IIS) | Close it, or change `Listen 80` to `8080` in `httpd.conf` and use http://localhost:8080 |
| MySQL will not start | Port 3306 used by another MySQL | Stop the other MySQL service, or change the port in `my.ini` |
| Browser shows PHP code | File opened as `file:///` | Use http://localhost/... |
| "Not Found" | File is not in htdocs, or the path is misspelt | Check the folder and the URL |
| phpMyAdmin access denied | Root password was changed | Put the password in `config.inc.php` |
