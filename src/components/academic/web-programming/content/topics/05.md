# JavaScript Conditions

## if, else if, else

A condition runs code only when something is true.

```javascript
if (condition) {
    // runs when condition is true
} else if (otherCondition) {
    // runs when the first is false and this is true
} else {
    // runs when nothing above was true
}
```

The checks run **top to bottom** and **only the first true branch runs**.

## Ranges: the most common exam pattern

Almost every Question 1 says "display feedback based on the total", e.g.

- 0 to 5 → "Start studying regularly!"
- 6 to 12 → "Good progress!"
- 13 to 19 → "Almost ready!"
- 20+ → "Weekly goal reached!"

Write it from the **top** down, so each check needs only one number:

```javascript
let feedback;
if (total >= 20) {
    feedback = "Weekly goal reached!";
} else if (total >= 13) {
    feedback = "Almost ready!";
} else if (total >= 6) {
    feedback = "Good progress!";
} else {
    feedback = "Start studying regularly!";
}
```

Why not `total >= 0 && total <= 5`, then `total >= 6 && total <= 12`? Because a value like **5.5** fits neither range and gets no message. Going from the top with `>=` covers every value.

## Comparing and combining

```javascript
if (score > 10 && score <= 20) { }   // both must be true
if (location === "" || area === "") { } // at least one is true
if (!(units > 0)) { }                // NOT
```

## Nested conditions

```javascript
if (location === "Dhaka") {
    if (area === "Urban") {
        rate = 7.5;
    } else {
        rate = 6.5;
    }
} else if (location === "Chattogram") {
    rate = area === "Urban" ? 7.0 : 6.0;
} else {
    rate = area === "Urban" ? 6.5 : 5.5;
}
```

## The ternary operator

A short `if / else` that gives a value:

```javascript
let status = total > 54 ? "Passed" : "Failed";
let answer = isPalindrome ? "Yes. It is a Palindrome." : "No. It is not a Palindrome.";
```

## switch

Useful when one variable is compared with several exact values:

```javascript
switch (grade) {
    case "A":
        msg = "Excellent";
        break;
    case "B":
        msg = "Good";
        break;
    default:
        msg = "Keep trying";
}
```

Do not forget `break`, or the next case runs too.

## Small exam patterns

**Pass or fail:**

```javascript
let status = total > 54 ? "Passed" : "Failed";
```

**Even or odd:**

```javascript
let type = n % 2 === 0 ? "Even" : "Odd";
```

**Largest of three:**

```javascript
let largest = a;
if (b > largest) largest = b;
if (c > largest) largest = c;
// or simply: Math.max(a, b, c)
```

**Grade from marks:**

```javascript
let grade;
if (marks >= 80) grade = "A+";
else if (marks >= 70) grade = "A";
else if (marks >= 60) grade = "B";
else if (marks >= 50) grade = "C";
else grade = "F";
```

## Common mistakes

- Writing `if (total = 20)`: this **assigns** 20. Compare with `===`.
- Leaving gaps between ranges (5 and 6) so decimals fall through.
- Writing `20+` as `total > 20`: 20 itself must be included, so use `>= 20`.
- Putting a later check above an earlier one (e.g. `>= 6` before `>= 13`): 15 would stop at "Good progress!".
