# CSS Basics

## What CSS is

**CSS** (Cascading Style Sheets) changes how HTML looks: colours, sizes, spacing and borders. In this course CSS is only for tidy output; no exam question asks for advanced layout.

## Three ways to add CSS

**Inline** (on one element):

```html
<p style="color: green;">Passed</p>
```

**Internal** (inside `<head>`):

```html
<style>
    p { color: green; }
</style>
```

**External** (a separate `style.css` file):

```html
<link rel="stylesheet" href="style.css">
```

## Selectors

| Selector | Selects | Example |
|---|---|---|
| `p` | Every `<p>` | `p { font-size: 18px; }` |
| `#result` | The element with `id="result"` | `#result { color: blue; }` |
| `.error` | Every element with `class="error"` | `.error { color: red; }` |
| `table, th, td` | Several at once | `table, th, td { border: 1px solid black; }` |

## Properties you will use

```css
body {
    font-family: Arial, sans-serif;
    background-color: #f5f5f5;
    margin: 20px;
}

#result {
    color: #1a5fb4;
    font-size: 18px;
    font-weight: bold;
    margin-top: 10px;
    padding: 8px;
    border: 1px solid #ccc;
}

input {
    padding: 6px;
    margin: 4px 0;
}

table {
    border-collapse: collapse;
}

th, td {
    border: 1px solid #333;
    padding: 6px 12px;
    text-align: center;
}
```

- `margin` is space **outside** the border, `padding` is space **inside** it.
- `border-collapse: collapse` joins table borders into single lines.
- `text-align: center` centres text inside a cell.

## A styled result message

```html
<style>
    .ok { color: green; }
    .bad { color: red; }
</style>

<p class="ok">Status: Passed</p>
<p class="bad">Status: Failed</p>
```

JavaScript can switch the colour when it writes a result:

```javascript
document.getElementById("status").innerHTML = "Failed";
document.getElementById("status").style.color = "red";
```

## Common mistakes

- Writing `color = red` instead of `color: red;`.
- Forgetting the `#` for an id selector or the `.` for a class selector.
- Styling the table but not `th, td`: the borders appear only around the outside.
