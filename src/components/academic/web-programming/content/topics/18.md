# PHP CRUD and the Full Workflow

**CRUD** = **C**reate, **R**ead, **U**pdate, **D**elete: the four things every database app does.

| Action | SQL | Triggered by |
|---|---|---|
| Create | `INSERT` | The add form (POST) |
| Read | `SELECT` | Every page load |
| Update | `UPDATE` | The edit form (POST) |
| Delete | `DELETE` | A Delete button (a tiny POST form) |

## The full workflow, step by step

1. **Start XAMPP**: Apache and MySQL both green.
2. **Create the database and tables**: phpMyAdmin, SQL tab, paste the `uiu_demo` script from topic 14.
3. **Check the data**: `SELECT * FROM students;` in the SQL tab.
4. **Create the project folder**: `htdocs/crud/`.
5. **Write the page**: `htdocs/crud/students.php` (below).
6. **Open it**: http://localhost/crud/students.php
7. **Test every action**: add a student, edit them, delete them, try an empty name, try a CGPA of 5.
8. **Confirm in phpMyAdmin** that the table changed the same way.
9. **Export** the database (Export tab) if the work must be submitted.

## How the single file works

```text
Page loads
  |
  |-- request method is POST?
  |     |-- action = add     -> validate -> prepared INSERT
  |     |-- action = edit    -> prepared SELECT one row -> fill the form
  |     |-- action = update  -> validate -> prepared UPDATE
  |     `-- action = delete  -> prepared DELETE
  |
  |-- SELECT all rows (always, after any change)
  `-- print the form and the table
```

- Every form posts to the **same file** (`action=""`) with **`method="POST"`**.
- A hidden input named **`action`** says which button was used.
- Edit and Delete buttons are tiny forms with a hidden **`id`**: the id travels in the POST body, never in the URL.
- Every value from the user goes through **`prepare` + `bind_param`**.
- Every value printed goes through **`htmlspecialchars`** (the `e()` helper).

## Complete CRUD page

`htdocs/crud/students.php` (tested against MariaDB 10.4 with PHP 8.2: add, invalid add, edit, update and delete all behave as described; posting the id `1 OR 1=1` deletes only student 1, because the id is cast to an integer and bound as a parameter).

```php
<?php
// students.php: add, list, edit and delete students in the uiu_demo database.
// Every action is sent with POST. Every value typed by the user goes through a prepared statement.

mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);   // turn SQL errors into clear messages
$conn = new mysqli("localhost", "root", "", "uiu_demo");
$conn->set_charset("utf8mb4");

function e($value) {
    return htmlspecialchars((string) $value);   // safe output for anything from the user or the database
}

// Departments for the drop-down and for validation.
$departments = [];
$result = $conn->query("SELECT dept_code, dept_name FROM departments ORDER BY dept_code");
while ($row = $result->fetch_assoc()) {
    $departments[$row["dept_code"]] = $row["dept_name"];
}

$message = "";
$editing = null;   // the student being edited, if any

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $action = $_POST["action"] ?? "";

    if ($action === "add" || $action === "update") {
        $name = trim($_POST["name"] ?? "");
        $dept = $_POST["dept_code"] ?? "";
        $cgpa = (float) ($_POST["cgpa"] ?? 0);
        $credits = (int) ($_POST["credits"] ?? 0);
        $city = trim($_POST["city"] ?? "");

        if ($name === "" || !isset($departments[$dept]) || $cgpa < 0 || $cgpa > 4 || $credits < 0) {
            $message = "Please enter a name, choose a department, a CGPA from 0 to 4 and credits of 0 or more.";
        } elseif ($action === "add") {
            // CREATE
            $stmt = $conn->prepare("INSERT INTO students (name, dept_code, cgpa, credits, city) VALUES (?, ?, ?, ?, ?)");
            $stmt->bind_param("ssdis", $name, $dept, $cgpa, $credits, $city);
            $stmt->execute();
            $message = "Added " . e($name) . " (id " . $conn->insert_id . ").";
        } else {
            // UPDATE
            $id = (int) ($_POST["id"] ?? 0);
            $stmt = $conn->prepare("UPDATE students SET name = ?, dept_code = ?, cgpa = ?, credits = ?, city = ? WHERE id = ?");
            $stmt->bind_param("ssdisi", $name, $dept, $cgpa, $credits, $city, $id);
            $stmt->execute();
            $message = $stmt->affected_rows === 1 ? "Updated " . e($name) . "." : "Nothing changed.";
        }
    } elseif ($action === "edit") {
        // Load one student into the form
        $id = (int) ($_POST["id"] ?? 0);
        $stmt = $conn->prepare("SELECT * FROM students WHERE id = ?");
        $stmt->bind_param("i", $id);
        $stmt->execute();
        $editing = $stmt->get_result()->fetch_assoc();
    } elseif ($action === "delete") {
        // DELETE
        $id = (int) ($_POST["id"] ?? 0);
        $stmt = $conn->prepare("DELETE FROM students WHERE id = ?");
        $stmt->bind_param("i", $id);
        $stmt->execute();
        $message = $stmt->affected_rows === 1 ? "Deleted student $id." : "No student with id $id.";
    }
}

// READ (after any change, so the table is up to date)
$students = $conn->query("SELECT * FROM students ORDER BY id");
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Students</title>
    <style>
        body { font-family: Arial, sans-serif; margin: 30px; }
        table { border-collapse: collapse; margin-top: 16px; }
        th, td { border: 1px solid #999; padding: 6px 10px; }
        th { background: #eee; }
        form.inline { display: inline; }
        .message { color: #0a6; font-weight: bold; }
    </style>
</head>
<body>
    <h1>Students</h1>

    <?php if ($message !== "") echo "<p class='message'>$message</p>"; ?>

    <h2><?= $editing ? "Edit student" : "Add a student" ?></h2>
    <form method="POST" action="">
        <input type="hidden" name="action" value="<?= $editing ? "update" : "add" ?>">
        <input type="hidden" name="id" value="<?= e($editing["id"] ?? "") ?>">

        <label>Name:</label>
        <input type="text" name="name" value="<?= e($editing["name"] ?? "") ?>" required><br><br>

        <label>Department:</label>
        <select name="dept_code" required>
            <option value="">-- Select --</option>
            <?php foreach ($departments as $code => $deptName) { ?>
                <option value="<?= e($code) ?>" <?= ($editing["dept_code"] ?? "") === $code ? "selected" : "" ?>>
                    <?= e($code) ?> (<?= e($deptName) ?>)
                </option>
            <?php } ?>
        </select><br><br>

        <label>CGPA:</label>
        <input type="number" name="cgpa" step="0.01" min="0" max="4" value="<?= e($editing["cgpa"] ?? "") ?>" required><br><br>

        <label>Credits:</label>
        <input type="number" name="credits" min="0" value="<?= e($editing["credits"] ?? "") ?>" required><br><br>

        <label>City:</label>
        <input type="text" name="city" value="<?= e($editing["city"] ?? "") ?>"><br><br>

        <button type="submit"><?= $editing ? "Save changes" : "Add student" ?></button>
        <?php if ($editing) echo '<a href="students.php">Cancel</a>'; ?>
    </form>

    <h2>All students (<?= $students->num_rows ?>)</h2>
    <table>
        <tr><th>ID</th><th>Name</th><th>Dept</th><th>CGPA</th><th>Credits</th><th>City</th><th>Actions</th></tr>
        <?php while ($row = $students->fetch_assoc()) { ?>
            <tr>
                <td><?= e($row["id"]) ?></td>
                <td><?= e($row["name"]) ?></td>
                <td><?= e($row["dept_code"]) ?></td>
                <td><?= e($row["cgpa"]) ?></td>
                <td><?= e($row["credits"]) ?></td>
                <td><?= e($row["city"]) ?></td>
                <td>
                    <form class="inline" method="POST" action="">
                        <input type="hidden" name="action" value="edit">
                        <input type="hidden" name="id" value="<?= e($row["id"]) ?>">
                        <button type="submit">Edit</button>
                    </form>
                    <form class="inline" method="POST" action="" onsubmit="return confirm('Delete this student?');">
                        <input type="hidden" name="action" value="delete">
                        <input type="hidden" name="id" value="<?= e($row["id"]) ?>">
                        <button type="submit">Delete</button>
                    </form>
                </td>
            </tr>
        <?php } ?>
    </table>
</body>
</html>
<?php
$conn->close();
```

The "Cancel" link simply reloads the page; it sends no form data.

## What each part teaches

| Part | Concept |
|---|---|
| `mysqli_report(...)` | Errors stop the script with the real SQL message |
| `e()` | `htmlspecialchars` on every output |
| `$departments` array | Validate a select value against the real list (and avoid a foreign key error) |
| `$_SERVER["REQUEST_METHOD"] === "POST"` | Only change data when a form was posted |
| Hidden `action` / `id` | One file handles every button |
| `bind_param("ssdis", ...)` | One type letter per `?` |
| `$conn->insert_id`, `affected_rows` | Feedback after a change |
| SELECT at the end | The table always shows the latest data |

## Troubleshooting

| Message or symptom | Likely cause | Fix |
|---|---|---|
| The browser shows the PHP code | Opened as `file:///` | Use http://localhost/... |
| Blank white page | A fatal error with `display_errors` off | Check `xampp/php/php.ini` (`display_errors=On`) or the Apache error log |
| `Access denied for user 'root'@'localhost'` | Wrong password | XAMPP's default password is `""` |
| `Unknown database 'uiu_demo'` | Database not created, or misspelt | Create it in phpMyAdmin; check the spelling |
| `Table 'uiu_demo.student' doesn't exist` | Wrong table name | `students`, not `student` |
| `Unknown column 'Name' in 'field list'` | Wrong column name or case | Match the CREATE TABLE exactly |
| `You have an error in your SQL syntax ... near '...'` | Typo, missing comma or quote | Look just **before** the quoted part; run the SQL in phpMyAdmin first |
| `Duplicate entry '7' for key 'PRIMARY'` | Inserting an id that exists | Leave the AUTO_INCREMENT id out of INSERT |
| `Cannot add or update a child row: a foreign key constraint fails` | `dept_code` not in `departments` | Validate against the list |
| `Call to a member function fetch_assoc() on bool` | The query failed silently | Add `mysqli_report(...)`; print `$conn->error` |
| `Undefined array key "name"` | Form field missing or misspelt, or no POST yet | Check `name=""`; use `?? ""`; check the method first |
| `$_POST` is empty | Form has no `method="POST"`, or inputs have no `name` | Add both |
| `ArgumentCountError` in `bind_param` | Type letters do not match the `?` count | One letter per `?` |
| `Call to undefined method mysqli_stmt::get_result()` | mysqlnd driver missing (not in XAMPP) | Use `bind_result()` + `fetch()` instead |
| Data changes again on refresh | The browser re-sends the POST | Expected; it asks "Resubmit?". Do not refresh after an update |
| Apache or MySQL will not start | Port 80 or 3306 busy | See topic 14 |

## Revision table

| Topic | Remember |
|---|---|
| Connect | `new mysqli("localhost", "root", "", "db")` + `mysqli_report(...)` |
| Fixed SELECT | `$conn->query($sql)`, loop `while ($row = $result->fetch_assoc())` |
| Count rows | `$result->num_rows` |
| User values | `prepare` → `bind_param` → `execute` → `get_result` |
| Type letters | `s` string, `i` integer, `d` double |
| After INSERT | `$conn->insert_id` |
| After UPDATE / DELETE | `$stmt->affected_rows` |
| Form | `method="POST"`, every input has a `name` |
| Read input | `$_POST["x"] ?? ""`, then cast or trim |
| Output | `htmlspecialchars()` |
| Group counts | `GROUP BY` + `COUNT(*)`; zero groups need a LEFT JOIN or `SUM(condition)` |
| Filter groups | `HAVING`, not `WHERE` |
| Two changes at once | `UPDATE ... SET x = CASE ... END` |
| One row by rank | `UPDATE ... ORDER BY ... LIMIT 1` |
| Apostrophe in data | `'Cox''s Bazar'` in SQL; a prepared statement handles it automatically |
| Submit the DB | phpMyAdmin → Export → SQL |
