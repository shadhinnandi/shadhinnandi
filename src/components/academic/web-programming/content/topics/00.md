# Introduction

## What this course is

**Web Programming (CSE 4165)** teaches how to build small, working web pages:

- **HTML** builds the page: text, input boxes and buttons.
- **CSS** makes it look tidy.
- **JavaScript** runs **in the browser** and reacts when the user clicks a button.
- **PHP** runs **on a server** (XAMPP on your laptop) and processes forms.
- **SQL / MySQL** stores data in tables; PHP talks to MySQL with **MySQLi**.

These notes are built from the eight final exam papers of the course (Fall 2023 to Spring 2026, nine question sets in total). Every topic teaches a skill that those papers actually test.

## The shape of every final exam

Almost every paper has the same three 10-mark questions:

| Question | What it asks | Topics to study |
|---|---|---|
| 1 | A **JavaScript** page: inputs, a button, a result area. Often keeps a running total or a counter across clicks. | 03 to 09 |
| 2 | A **PHP** program: read a form with POST, calculate (often with `ceil`), classify with `if / elseif`, print the result. | 10 to 13 |
| 3 | **PHP + MySQL**: create a database and table from a given table, then 3 to 5 tasks with `SELECT`, `UPDATE`, `GROUP BY`, `HAVING`. | 14 to 19 |

Two papers differ a little: Summer 2024 (242) has four questions for 40 marks, and Fall 2025 (253) has two PHP questions instead of a JavaScript one.

## Priority order

1. **JavaScript** (topics 03 to 09): the first 10 marks.
2. **PHP and forms** (topics 10 to 13): the second 10 marks.
3. **PHP + MySQL and SQL** (topics 14 to 19): the last 10 marks, and the hardest to guess without practice.
4. **HTML and CSS** (topics 01 and 02): only what the other three need.

## How to study a topic

Each topic has:

- a short **definition**,
- the **syntax** or a template,
- **complete examples** you can copy into a file and run,
- the **output** you should see,
- **common mistakes** that lose marks.

Type the examples yourself. Code you have typed and run once is much easier to rewrite in the exam.

Topic 19 ends with a **coverage checklist**: every question of every paper, with the topics it uses and the points where a paper's samples disagree with its own text.

## Conventions used in every answer

- JavaScript reads inputs with `document.getElementById("id").value` and writes results with `document.getElementById("id").innerHTML`.
- Numbers from inputs are converted with `parseInt()` or `parseFloat()` (input values are always strings).
- PHP forms always use `method="POST"` and read values from `$_POST`.
- A PHP answer keeps the HTML form and the PHP code in **one `.php` file**, unless the question asks for separate files.
- Database code uses **MySQLi** with `new mysqli(...)`, the style shown on the exam papers. Values typed by a user go through **prepared statements**.

## Tools you need

- A text editor (VS Code).
- A browser (Chrome or Edge).
- **XAMPP** for PHP and MySQL (topic 14 shows the setup step by step).
