## SQL in one minute

- **SQL** (Structured Query Language) talks to the database.
- Keywords are not case-sensitive (`SELECT` = `select`); write them in capitals so they stand out.
- Text values go in **single quotes**: `'Dhaka'`. Numbers do not: `3.5`.
- Each statement ends with `;`.
- Comments: `-- like this`.

## SELECT: read rows

```sql
SELECT * FROM students;                 -- every column
SELECT name, cgpa FROM students;        -- chosen columns
```

## WHERE: filter rows

```sql
SELECT name, cgpa FROM students WHERE cgpa >= 3.5;
```

```text
+-------------+------+
| name        | cgpa |
+-------------+------+
| Karim Uddin | 3.75 |
| Faria Karim | 3.85 |
+-------------+------+
```

| Operator | Meaning | Example |
|---|---|---|
| `=` | Equal (one `=` in SQL) | `city = 'Dhaka'` |
| `<>` or `!=` | Not equal | `dept_code <> 'CSE'` |
| `> < >= <=` | Compare | `credits >= 60` |
| `AND` | Both true | `city = 'Dhaka' AND cgpa > 3.0` |
| `OR` | At least one true | `dept_code = 'BBA' OR cgpa < 2.8` |
| `NOT` | Opposite | `NOT city = 'Dhaka'` |
| `BETWEEN a AND b` | From a to b, **both included** | `credits BETWEEN 45 AND 75` |
| `IN (...)` | One of a list | `city IN ('Sylhet', 'Khulna')` |
| `LIKE` | Pattern match | `name LIKE '%Karim%'` |
| `IS NULL` | No value | `city IS NULL` |

```sql
SELECT name, city FROM students WHERE city = 'Dhaka' AND cgpa > 3.0;
```

```text
+-------------+-------+
| name        | city  |
+-------------+-------+
| Karim Uddin | Dhaka |
+-------------+-------+
```

```sql
SELECT name FROM students WHERE dept_code = 'BBA' OR cgpa < 2.8;
```

```text
+--------------+
| name         |
+--------------+
| Faria Karim  |
| Tanvir Ahmed |
+--------------+
```

```sql
SELECT name, credits FROM students WHERE credits BETWEEN 45 AND 75;
```

```text
+----------------+---------+
| name           | credits |
+----------------+---------+
| Rahima Akter   |      75 |
| Jashim Hossain |      60 |
| Nadia Islam    |      45 |
+----------------+---------+
```

Mixing `AND` and `OR`: `AND` is done first. Use brackets to be clear: `WHERE (city = 'Dhaka' OR city = 'Sylhet') AND cgpa > 3.5`.

## LIKE patterns

| Pattern | Matches |
|---|---|
| `'%Karim%'` | "Karim" anywhere (Karim Uddin, Faria Karim) |
| `'R%'` | Starts with R (Rahima Akter) |
| `'%Beach'` | Ends with "Beach" |
| `'_a%'` | Second letter is a (`_` is exactly one character) |

## ORDER BY and LIMIT

```sql
SELECT name, cgpa FROM students ORDER BY cgpa DESC LIMIT 3;
```

```text
+--------------+------+
| name         | cgpa |
+--------------+------+
| Faria Karim  | 3.85 |
| Karim Uddin  | 3.75 |
| Rahima Akter | 3.40 |
+--------------+------+
```

- `ASC` (smallest first) is the default; `DESC` is largest first.
- Several columns: `ORDER BY dept_code ASC, cgpa DESC`.
- `LIMIT 3` keeps the first 3 rows; `LIMIT 1` gives "the top one".

## DISTINCT, aliases and calculated columns

```sql
SELECT DISTINCT city FROM students;     -- Dhaka, Chittagong, Sylhet, Khulna

SELECT name, credits, credits * 1500 AS fee FROM students;
```

```text
+----------------+---------+--------+
| name           | credits | fee    |
+----------------+---------+--------+
| Karim Uddin    |      90 | 135000 |
| Rahima Akter   |      75 | 112500 |
| Jashim Hossain |      60 |  90000 |
| Faria Karim    |     100 | 150000 |
| Nadia Islam    |      45 |  67500 |
| Tanvir Ahmed   |      30 |  45000 |
+----------------+---------+--------+
```

`AS fee` names the new column (an **alias**). In PHP you read it as `$row["fee"]`.

## INSERT: add rows

```sql
INSERT INTO students (name, dept_code, cgpa, credits, city)
VALUES ('Sadia Rahman', 'CSE', 3.60, 30, 'Rajshahi');
```

- List the columns, then the values **in the same order**.
- Leave out the `AUTO_INCREMENT` id; MySQL assigns the next number.
- Several rows: `VALUES (...), (...), (...);`

## UPDATE: change rows

```sql
UPDATE students SET cgpa = 3.20 WHERE id = 5;
UPDATE students SET credits = credits + 15 WHERE dept_code = 'EEE' AND credits < 50;
UPDATE students SET cgpa = cgpa + 0.10, city = 'Dhaka' WHERE id = 2;
```

**Always write the WHERE.** `UPDATE students SET cgpa = 4.00;` changes **every** row.

Percentages:

| Change | SQL |
|---|---|
| Increase by 10% | `SET price = price * 1.10` |
| Decrease by 10% | `SET price = price * 0.90` |
| Increase by 17.5% | `SET salary = salary * 1.175` |
| Add a fixed amount | `SET grade = grade + 5` |

## DELETE: remove rows

```sql
DELETE FROM students WHERE id = 6;
```

Without `WHERE`, every row is deleted. `TRUNCATE TABLE students;` empties the table and resets the auto increment counter.

## Checking an UPDATE before running it

Run a `SELECT` with the **same WHERE** first. If it shows exactly the rows you expect, change `SELECT ...` into `UPDATE ... SET ...`:

```sql
SELECT * FROM students WHERE dept_code = 'EEE' AND credits < 50;   -- Tanvir only
UPDATE students SET credits = credits + 15 WHERE dept_code = 'EEE' AND credits < 50;
```

## Clause order

```sql
SELECT columns
FROM table
WHERE row filter
ORDER BY column
LIMIT n;
```

The order is fixed: `WHERE` before `ORDER BY`, `ORDER BY` before `LIMIT`. Topic 16 adds `GROUP BY` and `HAVING`.

## Common mistakes

- Double quotes or no quotes around text (`city = Dhaka`): use `'Dhaka'`.
- `==` in SQL: comparison is a single `=`.
- `WHERE cgpa > 3.0 OR cgpa < 2.8 AND city = 'Dhaka'` without brackets: AND binds first.
- `UPDATE` or `DELETE` without `WHERE`.
- `BETWEEN 4.0 AND 4.5` includes both 4.0 and 4.5.
