# PHP Fundamentals

## What PHP is

**PHP** is a language that runs **on the server**. The browser asks for `page.php`, Apache (in XAMPP) runs the PHP code, and the browser receives only the **HTML output**. The user never sees your PHP code.

```text
Browser  --request page.php-->  Apache + PHP  --runs the code-->  HTML
Browser  <--------------------- sends back the HTML only ---------
```

## Running a PHP file

1. Start **Apache** in the XAMPP Control Panel.
2. Save the file inside the `htdocs` folder, e.g. `htdocs/final/q2.php`.
   - Windows: `C:\xampp\htdocs\final\q2.php`
   - macOS: `/Applications/XAMPP/xamppfiles/htdocs/final/q2.php`
3. Open **http://localhost/final/q2.php** in the browser.

Opening the file by double-clicking (a `file:///` address) does **not** run PHP; you will see the raw code or a download.

## PHP tags and echo

PHP code lives between `<?php` and `?>`. Everything outside is normal HTML.

```php
<!DOCTYPE html>
<html>
<body>
    <h1>My first PHP page</h1>
    <?php
        echo "Hello from PHP!";
        echo "<br>";
        echo "Today is " . date("d-m-Y");
    ?>
</body>
</html>
```

- `echo` sends text (or HTML) to the browser.
- Every statement ends with a **semicolon** `;`.
- A file that is **only** PHP may leave out the closing `?>`.

## Variables

Every variable starts with **`$`**. No `let` or `const`.

```php
<?php
$name = "Karim";      // string
$credits = 3;         // integer
$gpa = 3.75;          // float
$passed = true;       // boolean
$subjects = ["Math", "ICT"]; // array
```

Names are case-sensitive: `$total` and `$Total` are different.

## Strings: single vs double quotes

```php
<?php
$name = "Karim";
echo "Hello $name";      // Hello Karim   (double quotes read variables)
echo 'Hello $name';      // Hello $name   (single quotes do not)
echo "Hello " . $name;   // Hello Karim   (. joins strings)
echo "Total: {$name}s";  // braces mark where the variable ends
```

PHP joins strings with **`.`** (dot), not `+`. `"5" + "3"` in PHP is `8` (numbers), `"5" . "3"` is `"53"`.

## Operators

| Kind | Operators | Example | Result |
|---|---|---|---|
| Arithmetic | `+ - * / % **` | `17 % 5` | `2` |
| Join strings | `.` and `.=` | `$s .= "!"` | adds to the end |
| Assignment | `= += -= *= /=` | `$total += 4` | |
| Increment | `++ --` | `$i++` | |
| Comparison | `== === != !== < > <= >=` | `5 === "5"` | `false` |
| Logical | `&& \|\| !` (also `and`, `or`) | `$a > 0 && $b > 0` | |

## Constants

```php
<?php
define("TAX_RATE", 0.20);
const GOAL = 20;
echo TAX_RATE * 100;   // 20   (no $ for constants)
```

## Numbers and rounding

```php
<?php
echo ceil(4.1);            // 5   (round up: whole pizzas, venues, screens)
echo floor(4.9);           // 4   (round down)
echo round(25.6239, 2);    // 25.62
echo intdiv(17, 5);        // 3   (whole division)
echo abs(-7);              // 7
echo max(12, 15, 14);      // 15
echo min(12, 15, 14);      // 12
echo number_format(15000);       // 15,000
echo number_format(1328.7, 2);   // 1,328.70
echo rand(500, 5000);      // a random whole number, both ends included
```

## Converting types

```php
<?php
$a = (int) "42";        // 42
$b = (float) "3.5";     // 3.5
$c = (string) 99;       // "99"
var_dump($a);           // int(42)   shows type and value, good for debugging
```

## Comments

```php
<?php
// one line
# also one line
/* several
   lines */
```

## Mixing PHP and HTML

```php
<?php $students = 12; ?>
<p>There are <?php echo $students; ?> students.</p>
<p>There are <?= $students ?> students.</p>   <!-- short echo -->
```

## Common mistakes

- Forgetting `$` before a variable name.
- Using `+` to join strings (PHP uses `.`).
- Missing `;` at the end of a line (PHP shows a parse error with a line number).
- Opening the file as `file:///...` instead of `http://localhost/...`.
- Apache not started in XAMPP.
