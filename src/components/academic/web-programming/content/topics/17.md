# PHP and MySQLi

**MySQLi** ("MySQL improved") is the PHP extension that connects PHP to MySQL / MariaDB. It is built into XAMPP. This topic uses the **object-oriented** style (`$conn->query(...)`), the same style as the sample code printed in the exam papers. All examples use the `uiu_demo` database (topic 14).

## The flow

```text
connect  ->  send SQL  ->  read the result  ->  show it as HTML  ->  close
```

## 1. Connect

```php
<?php
$servername = "localhost";
$username = "root";
$password = "";
$dbname = "uiu_demo";

mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
$conn = new mysqli($servername, $username, $password, $dbname);
$conn->set_charset("utf8mb4");
```

- `mysqli_report(...)` makes every SQL error stop the script with a clear message (this is already the default in PHP 8.1 and later; writing it makes the behaviour explicit on any version).
- `set_charset("utf8mb4")` keeps Bangla and other characters correct.

The exam papers' sample code checks the connection by hand, which also works:

```php
<?php
$conn = new mysqli($servername, $username, $password, $dbname);
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}
```

Keep the connection in **one file** and include it from every page:

```php
<?php
// db.php
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
$conn = new mysqli("localhost", "root", "", "uiu_demo");
$conn->set_charset("utf8mb4");
```

```php
<?php
require "db.php";   // now $conn is ready
```

## 2. Fixed SQL: query()

When the SQL contains **no value from the user**, run it directly:

```php
<?php
$result = $conn->query("SELECT name, cgpa FROM students ORDER BY cgpa DESC");

echo "<p>Rows: " . $result->num_rows . "</p>";
while ($row = $result->fetch_assoc()) {
    echo $row["name"] . ": " . $row["cgpa"] . "<br>";
}
```

Output:

```text
Rows: 6
Faria Karim: 3.85
Karim Uddin: 3.75
Rahima Akter: 3.40
Nadia Islam: 3.10
Jashim Hossain: 2.95
Tanvir Ahmed: 2.70
```

| Call | Gives |
|---|---|
| `$conn->query($sql)` | A result object (SELECT) or `true` (INSERT / UPDATE / DELETE) |
| `$result->num_rows` | Number of rows in a SELECT result |
| `$result->fetch_assoc()` | The next row as `["name" => ..., "cgpa" => ...]`, or `null` at the end |
| `$result->fetch_all(MYSQLI_ASSOC)` | All rows as an array |
| `$conn->affected_rows` | Rows changed by the last INSERT / UPDATE / DELETE |
| `$conn->insert_id` | The new AUTO_INCREMENT id after an INSERT |

The keys of `$row` are the column names **or the aliases**: `SELECT COUNT(*) AS total` is read as `$row["total"]`.

## 3. Values from the user: prepared statements

**Never put a typed value straight into SQL.** This is dangerous:

```php
<?php
// UNSAFE: do not do this
$city = $_POST["city"];
$result = $conn->query("SELECT * FROM students WHERE city = '$city'");
```

If someone types `' OR '1'='1`, the SQL becomes `WHERE city = '' OR '1'='1'`, which matches **every** row. With `DELETE` it would delete everything. This is **SQL injection**.

A **prepared statement** sends the SQL with `?` placeholders first and the values separately, so a value can never change the SQL:

```php
<?php
$city = $_POST["city"] ?? "";

$stmt = $conn->prepare("SELECT name, cgpa FROM students WHERE city = ?");
$stmt->bind_param("s", $city);       // "s" = the ? is a string
$stmt->execute();
$result = $stmt->get_result();       // then use it exactly like query()

while ($row = $result->fetch_assoc()) {
    echo htmlspecialchars($row["name"]) . " (" . $row["cgpa"] . ")<br>";
}
```

With `city = Dhaka`:

```text
Karim Uddin (3.75)
Jashim Hossain (2.95)
Tanvir Ahmed (2.70)
```

### The four steps

1. **`prepare`** the SQL with a `?` for each value.
2. **`bind_param`** a type letter for each `?`, then the variables, in order.
3. **`execute`**.
4. **`get_result`** for a SELECT, or **`affected_rows`** for INSERT / UPDATE / DELETE.

| Letter | Type | Use for |
|---|---|---|
| `s` | string | Text, dates, decimals you want exact (`"3.75"`) |
| `i` | integer | Ids, counts, credits |
| `d` | double | Decimal numbers |
| `b` | blob | Binary data (rare) |

Rules:

- `bind_param` takes **variables**, not literal values: `bind_param("i", 5)` is an error. Put the value in a variable first.
- One type letter per `?`: `"ssdis"` for five placeholders.
- A `?` replaces a **value** only. Table names, column names and `ASC` / `DESC` cannot be placeholders.
- Do not put quotes around `?`: write `city = ?`, not `city = '?'`.

### INSERT, UPDATE and DELETE

```php
<?php
// INSERT
$name = "Sadia Rahman"; $dept = "CSE"; $cgpa = 3.60; $credits = 30; $city = "Rajshahi";
$stmt = $conn->prepare("INSERT INTO students (name, dept_code, cgpa, credits, city) VALUES (?, ?, ?, ?, ?)");
$stmt->bind_param("ssdis", $name, $dept, $cgpa, $credits, $city);
$stmt->execute();
echo "New id: " . $conn->insert_id;           // New id: 7

// UPDATE
$newCgpa = 3.65; $id = 7;
$stmt = $conn->prepare("UPDATE students SET cgpa = ? WHERE id = ?");
$stmt->bind_param("di", $newCgpa, $id);
$stmt->execute();
echo $stmt->affected_rows . " row updated";   // 1 row updated

// DELETE
$stmt = $conn->prepare("DELETE FROM students WHERE id = ?");
$stmt->bind_param("i", $id);
$stmt->execute();
echo $stmt->affected_rows . " row deleted";   // 1 row deleted
```

### Reusing a statement

Prepare once, execute many times with new values:

```php
<?php
$stmt = $conn->prepare("SELECT COUNT(*) AS n FROM students WHERE dept_code = ?");
$stmt->bind_param("s", $code);
foreach (["CSE", "EEE", "BBA", "CE"] as $code) {
    $stmt->execute();
    $n = $stmt->get_result()->fetch_assoc()["n"];
    echo "$code: $n<br>";
}
// CSE: 3   EEE: 2   BBA: 1   CE: 0
```

`bind_param` binds the **variable**, so changing `$code` before each `execute()` sends the new value.

### LIKE with a placeholder

Put the `%` signs in the value, not in the SQL:

```php
<?php
$search = "%" . ($_POST["search"] ?? "") . "%";
$stmt = $conn->prepare("SELECT name FROM students WHERE name LIKE ?");
$stmt->bind_param("s", $search);
```

## 4. Show a result as an HTML table

```php
<?php
function showTable($result) {
    if ($result->num_rows === 0) {
        echo "<p>No rows found.</p>";
        return;
    }
    echo "<table border='1' cellpadding='6'><tr>";
    foreach ($result->fetch_fields() as $field) {
        echo "<th>" . htmlspecialchars($field->name) . "</th>";
    }
    echo "</tr>";
    while ($row = $result->fetch_assoc()) {
        echo "<tr>";
        foreach ($row as $value) {
            echo "<td>" . htmlspecialchars((string) $value) . "</td>";
        }
        echo "</tr>";
    }
    echo "</table>";
}

showTable($conn->query("SELECT dept_code, COUNT(*) AS students FROM students GROUP BY dept_code"));
```

`fetch_fields()` gives the column names, so this one function prints **any** SELECT, including aliases like `students`. It is used in every database answer on this site.

## 5. Close

```php
<?php
$stmt->close();
$conn->close();
```

PHP closes everything at the end of the script anyway, but closing is good practice.

## Errors with try / catch

With `mysqli_report` on, a failing query throws a `mysqli_sql_exception`. Catch it when you want a friendly message, for example a duplicate key:

```php
<?php
try {
    $stmt->execute();
    echo "Saved.";
} catch (mysqli_sql_exception $e) {
    echo "Could not save: " . htmlspecialchars($e->getMessage());
}
```

## Object-oriented vs procedural MySQLi

Both styles do the same thing. Some class examples use the procedural one:

| Object-oriented | Procedural |
|---|---|
| `$conn = new mysqli($h, $u, $p, $db);` | `$conn = mysqli_connect($h, $u, $p, $db);` |
| `$conn->connect_error` | `mysqli_connect_error()` |
| `$conn->query($sql)` | `mysqli_query($conn, $sql)` |
| `$result->fetch_assoc()` | `mysqli_fetch_assoc($result)` |
| `$result->num_rows` | `mysqli_num_rows($result)` |
| `$conn->prepare($sql)` | `mysqli_prepare($conn, $sql)` |
| `$stmt->bind_param("s", $x)` | `mysqli_stmt_bind_param($stmt, "s", $x)` |
| `$stmt->execute()` | `mysqli_stmt_execute($stmt)` |
| `$stmt->get_result()` | `mysqli_stmt_get_result($stmt)` |
| `$conn->close()` | `mysqli_close($conn)` |

Pick one style and use it for the whole file.

## When to use which

| The SQL contains... | Use |
|---|---|
| Only fixed text you wrote (an exam task with fixed numbers) | `$conn->query()` is acceptable; a prepared statement is also fine |
| **Any** value from `$_POST`, a cookie, a file or another user | **Always** a prepared statement |

## Common mistakes

- `Call to a member function fetch_assoc() on bool`: the query failed (old PHP without `mysqli_report`). Turn on `mysqli_report` to see the real SQL error.
- `bind_param` with the wrong number of type letters.
- Quoting placeholders (`'?'`).
- Reading `$row["Name"]` when the column is `name` (keys are case-sensitive).
- Echoing database text without `htmlspecialchars()`.
