# JavaScript Arrays and Sorting

## What an array is

An **array** is an ordered list of values in one variable. Positions (indexes) start at **0**.

```javascript
let subjects = ["English", "Bangla", "Physics"];
console.log(subjects[0]);       // "English"
console.log(subjects.length);   // 3
subjects[1] = "Math";           // update position 1
```

## Creating and growing

```javascript
let readings = [];          // empty array
readings.push(80);          // add to the end   -> [80]
readings.push(78);          //                  -> [80, 78]
let last = readings.pop();  // remove the last  -> last = 78, readings = [80]
```

Exam questions say "keep track of every reading entered so far": that means **`push()`** into an array declared **outside** the function.

## Useful methods

| Method | Does | Example | Result |
|---|---|---|---|
| `push(x)` | Add to the end | `a.push(5)` | array grows |
| `pop()` | Remove the last | `a.pop()` | returns it |
| `includes(x)` | Is x inside? | `[1,2].includes(2)` | `true` |
| `indexOf(x)` | Position of x, or -1 | `["a","b"].indexOf("b")` | `1` |
| `join(", ")` | Array to text | `["a","b"].join(", ")` | `"a, b"` |
| `slice(a, b)` | Copy a part | `[1,2,3].slice(0, 2)` | `[1, 2]` |
| `reverse()` | Reverse in place | `[1,2,3].reverse()` | `[3, 2, 1]` |

## Sum, average, max and min

```javascript
let rates = [80, 78, 130];

let sum = 0;
for (let i = 0; i < rates.length; i++) {
    sum += rates[i];
}
let average = sum / rates.length;      // 96

let max = Math.max(...rates);          // 130  (... spreads the array)
let min = Math.min(...rates);          // 78
```

The same with a manual loop (works in every exam):

```javascript
let max = rates[0];
for (let i = 1; i < rates.length; i++) {
    if (rates[i] > max) max = rates[i];
}
```

## Searching and counting

```javascript
let marks = [45, 72, 88, 39, 91];

let found = marks.includes(88);          // true

let passed = 0;
for (let i = 0; i < marks.length; i++) {
    if (marks[i] >= 40) passed++;        // count matching values
}
// passed = 4
```

## Sorting: the trap

`sort()` without a function sorts values **as text**:

```javascript
let nums = [10, 9, 100, 25];
nums.sort();
console.log(nums);   // [10, 100, 25, 9]   wrong for numbers!
```

For numbers, give a **compare function**:

```javascript
nums.sort((a, b) => a - b);   // ascending:  [9, 10, 25, 100]
nums.sort((a, b) => b - a);   // descending: [100, 25, 10, 9]
```

Strings sort correctly with plain `sort()`:

```javascript
let names = ["Rahim", "Abdul", "Karim"];
names.sort();                 // ["Abdul", "Karim", "Rahim"]
```

`sort()` changes the **original** array. To keep the original, sort a copy: `let sorted = [...nums].sort((a, b) => a - b);`

## Best two out of three

```javascript
let cts = [12, 15, 14];
cts.sort((a, b) => b - a);          // [15, 14, 12]
let bestTwo = cts[0] + cts[1];      // 29
// or: let bestTwo = 12 + 15 + 14 - Math.min(12, 15, 14);
```

## Showing an array

```javascript
let subjects = ["English", "English", "Bangla", "Physics"];
document.getElementById("subjects").innerHTML = `Subjects: [${subjects.join(", ")}]`;
// Subjects: [English, English, Bangla, Physics]
```

## Two-dimensional arrays

An array of arrays, e.g. a small table of readings:

```javascript
let readings = [[80, 97], [78, 95]];   // [heartRate, spo2]
console.log(readings[1][0]);           // 78
```

## Common mistakes

- Declaring the array inside the function: it is empty again on every click.
- `nums.sort()` on numbers without `(a, b) => a - b`.
- Using `arr[arr.length]`: the last element is `arr[arr.length - 1]`.
