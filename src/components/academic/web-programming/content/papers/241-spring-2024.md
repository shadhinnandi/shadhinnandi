### Question
**Javascript:** Write a javascript program to calculate the formula given below. First, take height in centimetre(cm) and weight in pounds(lb), convert, calculate, and display results in the inner html.

Calculation Result = Weight in KG / (Height in metre)²

Formula to convert centrimetre to metre: metre = centrimetre / 100

Formula to convert pound to KG: KG = pound / 2.2046

If the calculation result is greater than 0 and less than 20, show a status "bad", greater than 20 to 30, show a status "not bad", for greater than 30, show a status "good"

Sample screen:

| | |
|---|---|
| Height (cm): | 177.8 |
| Weight (lb): | 178.574 |
| | `[Calculate]` |
| Calculation Result: | **25.85** |
| Status: | **not bad** |

### Solution
**Steps:** read both inputs, convert (cm ÷ 100, lb ÷ 2.2046), calculate kg ÷ m², then choose the status with an `if / else if` chain.

**index.html**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Calculation</title>
</head>
<body>
    <label>Height (cm):</label>
    <input type="number" id="height" step="any"><br><br>

    <label>Weight (lb):</label>
    <input type="number" id="weight" step="any"><br><br>

    <button onclick="calculate()">Calculate</button>

    <p>Calculation Result: <b id="result"></b></p>
    <p>Status: <b id="status"></b></p>

    <script src="script.js"></script>
</body>
</html>
```

**script.js**

```javascript
function calculate() {
    let cm = parseFloat(document.getElementById("height").value);
    let pound = parseFloat(document.getElementById("weight").value);

    if (isNaN(cm) || isNaN(pound) || cm <= 0 || pound <= 0) {
        document.getElementById("result").innerHTML = "Enter a positive height and weight.";
        document.getElementById("status").innerHTML = "";
        return;
    }

    let metre = cm / 100;
    let kg = pound / 2.2046;
    let result = kg / (metre * metre);

    let status;
    if (result > 30) {
        status = "good";
    } else if (result >= 20) {
        status = "not bad";
    } else {
        status = "bad";
    }

    document.getElementById("result").innerHTML = result.toFixed(2);
    document.getElementById("status").innerHTML = status;
}
```

**Working for the sample:**

- metre = 177.8 / 100 = 1.778, so metre² = 3.161284
- KG = 178.574 / 2.2046 = 81.0006
- Result = 81.0006 / 3.161284 = **25.62**, Status: **not bad**

**Note on the sample value:** with the formulas given in the question, the sample inputs give **25.62**, not the 25.85 printed in the screenshot (25.85 would need about 81.72 kg). The status, "not bad", is the same either way. Follow the formulas and mention the difference.

**Boundaries:** the question says "less than 20" and "greater than 20 to 30", so exactly 20 is not covered. This answer counts 20 as "not bad" (`>= 20`) so every value gets a status, and 30 itself is "not bad" ("to 30").

### Question
**PHP:** Create a cryptic sequence generator using for loop. The sequence will start with a given seed value and follow these rules:

1. The first number is the seed itself.
2. For each subsequent number in the sequence, take the previous number and add the product of its digits.
3. Repeat this process for a specified number of terms.

Now, write a PHP program that takes a seed value and the number of terms as input and generates the cryptic sequence based on the rules above. Display the sequence in a comma-separated format.

| Sample Input | Sample Output |
|---|---|
| Seed value: 7, Terms: 5 | 7, 14, 19, 29, 40 |
| Seed value: 4, Terms: 9 | 4, 8, 16, 23, 28, 38, 49, 62, 70 |

### Solution
**Read the samples first.** They add the **sum** of the digits, not the product:

| Previous | Digits | Sum | Next | Product rule would give |
|---|---|---|---|---|
| 7 | 7 | 7 | 14 | 14 |
| 14 | 1, 4 | 5 | **19** | 18 |
| 19 | 1, 9 | 10 | **29** | 28 |
| 29 | 2, 9 | 11 | **40** | 47 |

With the product rule the first sample would print `7, 14, 18, 26, 38`. The answer below uses the **sum of digits**, which reproduces both samples exactly. To follow the wording instead, change one line (shown in the comment).

**index.php**

```php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Cryptic Sequence Generator</title>
</head>
<body>
    <h2>Cryptic Sequence Generator</h2>
    <form method="POST" action="">
        <label>Seed value:</label>
        <input type="number" name="seed" min="1" required><br><br>
        <label>Terms:</label>
        <input type="number" name="terms" min="1" required><br><br>
        <input type="submit" name="generate" value="Generate">
    </form>

    <?php
    // Sum of the digits of a number, e.g. 29 -> 2 + 9 = 11
    function digitSum($number) {
        $sum = 0;
        $digits = str_split((string) $number);
        for ($i = 0; $i < count($digits); $i++) {
            $sum += (int) $digits[$i];
            // product version: start $sum at 1 and use  $sum *= (int) $digits[$i];
        }
        return $sum;
    }

    if (isset($_POST["generate"])) {
        $seed = (int) $_POST["seed"];
        $terms = (int) $_POST["terms"];

        if ($seed < 1 || $terms < 1) {
            echo "<p>Seed and terms must be positive numbers.</p>";
        } else {
            $sequence = [$seed];                          // rule 1: the seed itself
            for ($i = 1; $i < $terms; $i++) {             // rule 3: repeat
                $previous = $sequence[$i - 1];
                $sequence[] = $previous + digitSum($previous);   // rule 2
            }
            echo "<p>" . implode(", ", $sequence) . "</p>";
        }
    }
    ?>
</body>
</html>
```

**Output:**

- Seed 7, Terms 5: `7, 14, 19, 29, 40`
- Seed 4, Terms 9: `4, 8, 16, 23, 28, 38, 49, 62, 70`

### Solution
The question asks for **two** pages (index.html and bill.php), plus the database. The form posts to bill.php with **POST**.

#### How the bill is calculated (slabs)

The rates are **slabs**: the first 75 units cost the first rate, units 76 to 200 the second rate, and every unit above 200 the third rate. Check with the sample (Dhaka, Urban, 213 units):

| Slab | Units | Rate | Cost |
|---|---|---|---|
| 0-75 | 75 | 4.19 | 314.25 |
| 76-200 | 125 | 5.72 | 715.00 |
| 201-above | 13 | 6.00 | 78.00 |
| **Bill before tax** | | | **1107.25** |
| Tax (Dhaka 20%) | | | 221.45 |
| **Total bill** | | | **1328.70 BDT** |

This matches the sample output exactly.

#### Database

**electricity_bill.sql**

```sql
CREATE DATABASE IF NOT EXISTS electricity_bill;
USE electricity_bill;

CREATE TABLE bill_info (
    id INT(11) AUTO_INCREMENT PRIMARY KEY,
    location VARCHAR(100),
    area VARCHAR(100),
    rate_0_75 FLOAT,
    rate_76_200 FLOAT,
    rate_201_above FLOAT
);

INSERT INTO bill_info (location, area, rate_0_75, rate_76_200, rate_201_above) VALUES
('Dhaka',      'Urban', 4.19, 5.72, 6.00),
('Dhaka',      'Rural', 3.19, 4.72, 5.00),
('Chittagong', 'Urban', 3.50, 4.80, 5.23),
('Chittagong', 'Rural', 2.50, 3.80, 4.23);
```

The tax rates are not part of the bill_info fields in the question, so bill.php keeps them in an array.

#### Result page

**bill.php**

```php
<?php
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
$conn = new mysqli("localhost", "root", "", "electricity_bill");

$taxRates = ["Dhaka" => 0.20, "Chittagong" => 0.15];

$location = $_POST["location"] ?? "";
$area = $_POST["area"] ?? "";
$units = (float) ($_POST["units"] ?? -1);
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Your Bill</title>
</head>
<body>
<?php
if (!isset($taxRates[$location]) || $units < 0) {
    echo "<p>Please go back and enter a location, an area and the units consumed.</p>";
} else {
    // Fetch the three rates for this location and area
    $stmt = $conn->prepare("SELECT rate_0_75, rate_76_200, rate_201_above FROM bill_info WHERE location = ? AND area = ?");
    $stmt->bind_param("ss", $location, $area);
    $stmt->execute();
    $rates = $stmt->get_result()->fetch_assoc();

    if (!$rates) {
        echo "<p>No rates found for this location and area.</p>";
    } else {
        // Slab calculation
        $slab1 = min($units, 75);                   // units 0-75
        $slab2 = max(0, min($units, 200) - 75);     // units 76-200
        $slab3 = max(0, $units - 200);              // units above 200

        $bill = $slab1 * $rates["rate_0_75"]
              + $slab2 * $rates["rate_76_200"]
              + $slab3 * $rates["rate_201_above"];

        $total = $bill + $bill * $taxRates[$location];

        echo "<p>Your location: " . htmlspecialchars($location) . "</p>";
        echo "<p>Your area: " . htmlspecialchars($area) . "</p>";
        echo "<p>Unit consumed: " . $units . "</p>";
        echo "<p><b>Total bill: " . number_format($total, 2, ".", "") . " BDT</b></p>";
    }
}
$conn->close();
?>
</body>
</html>
```
