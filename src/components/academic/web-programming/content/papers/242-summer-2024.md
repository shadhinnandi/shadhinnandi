### Question
Calculate the electricity bill using location-specific rates. For Dhaka, charge 7.5 taka per unit in urban areas and 6.5 taka in rural areas. Chattogram rates are 7.0 taka (urban) and 6.0 taka (rural). Other locations use 6.5 taka (urban) and 5.5 taka (rural). Apply a surcharge to the total bill: no surcharge for bills under 500 taka, 5% for bills between 500-1000 taka, and 10% for bills over 1000 taka. Display the final amount, including surcharge, in an alert box, rounded to two decimal places. Implement input validation to ensure a location is selected, an area type (Urban or Rural) is chosen (can't select both), and the "Unit Consumed" field contains a positive number. If any validation fails, display an appropriate error message to the user.

Sample screen (index.html):

| | |
|---|---|
| Location: | `[Dhaka v]` |
| Area: | (•) Urban ( ) Rural |
| Unit Consumed: | `[213]` |
| | `[Calculate Bill]` |

### Solution
**Plan:**

1. **Validate:** a location chosen (the first option is an empty placeholder), one area chosen, units a positive number. Two **radio buttons with the same `name`** make it impossible to select both.
2. **Rate** from location and area (nested `if`).
3. **Bill** = units × rate.
4. **Surcharge:** under 500 → 0%, 500 to 1000 → 5%, over 1000 → 10%.
5. **Alert** the total with `toFixed(2)`.

**index.html**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Electricity Bill</title>
</head>
<body>
    <h2>Electricity Bill</h2>

    <label>Location:</label>
    <select id="location">
        <option value="">-- Select location --</option>
        <option value="Dhaka">Dhaka</option>
        <option value="Chattogram">Chattogram</option>
        <option value="Other">Other</option>
    </select><br><br>

    <label>Area:</label>
    <input type="radio" id="urban" name="area" value="Urban"> Urban
    <input type="radio" id="rural" name="area" value="Rural"> Rural<br><br>

    <label>Unit Consumed:</label>
    <input type="number" id="units" min="1"><br><br>

    <button onclick="calculateBill()">Calculate Bill</button>

    <p id="error"></p>

    <script src="script.js"></script>
</body>
</html>
```

**script.js**

```javascript
function calculateBill() {
    let location = document.getElementById("location").value;
    let urban = document.getElementById("urban").checked;
    let rural = document.getElementById("rural").checked;
    let units = parseFloat(document.getElementById("units").value);

    // Validation
    let error = "";
    if (location === "") {
        error = "Please select a location.";
    } else if (!urban && !rural) {
        error = "Please choose an area type (Urban or Rural).";
    } else if (urban && rural) {
        error = "Choose only one area type.";
    } else if (isNaN(units) || units <= 0) {
        error = "Unit Consumed must be a positive number.";
    }

    if (error !== "") {
        document.getElementById("error").innerHTML = error;
        alert(error);
        return;
    }
    document.getElementById("error").innerHTML = "";

    // Rate per unit
    let rate;
    if (location === "Dhaka") {
        rate = urban ? 7.5 : 6.5;
    } else if (location === "Chattogram") {
        rate = urban ? 7.0 : 6.0;
    } else {
        rate = urban ? 6.5 : 5.5;
    }

    let bill = units * rate;

    // Surcharge
    let surcharge;
    if (bill < 500) {
        surcharge = 0;
    } else if (bill <= 1000) {
        surcharge = bill * 0.05;
    } else {
        surcharge = bill * 0.10;
    }

    let total = bill + surcharge;
    alert("Total bill (including surcharge): " + total.toFixed(2) + " taka");
}
```

| Other, Urban, 50 | 50 × 6.5 = 325.00 | 0 | 325.00 taka |

### Question
Karim went up a hill for 18 minutes at a speed of 20 miles per hour (km/h). Then he came back down the same hill at a speed of 60 km/h. What was his average speed for the whole trip? (Hint: It was 30 mph.). Write a PHP function that calculates the average speed for a trip when given the time spent going uphill (in minutes), the speed going uphill (in km/h), and the speed going downhill (in km/h). The function will return the average speed as a whole number (integer) in km/h.

| Sample Input | Sample Output |
|---|---|
| calculate(18, 20, 60); (Here, 18 = time spent going uphill in minutes, 20 = speed of going uphill in km/h, 60 = speed of going downhill in km/h) | 30 |
| calculate(30, 8, 24); | 12 |

### Solution
**Average speed = total distance ÷ total time** (not the average of the two speeds).

For the sample (18 min, 20 km/h up, 60 km/h down):

- Time up = 18 / 60 = 0.3 h
- Distance up = 20 × 0.3 = 6 km, and the same 6 km down
- Time down = 6 / 60 = 0.1 h
- Average = (6 + 6) / (0.3 + 0.1) = 12 / 0.4 = **30 km/h**

Second sample: time up 0.5 h, distance 8 × 0.5 = 4 km, time down 4 / 24 = 0.1667 h, average 8 / 0.6667 = **12 km/h**.

(The question mixes "miles per hour" and "km/h"; the unit does not change the calculation, and the function uses km/h as the function description says.)

**index.php**

```php
<?php
// Average speed for a trip up and down the same hill, as a whole number (km/h)
function calculate($timeUpMinutes, $speedUp, $speedDown) {
    $timeUp = $timeUpMinutes / 60;            // minutes -> hours
    $distance = $speedUp * $timeUp;           // one way, km
    $timeDown = $distance / $speedDown;       // hours
    $average = (2 * $distance) / ($timeUp + $timeDown);
    return (int) round($average);
}
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Average Speed</title>
</head>
<body>
    <h2>Average Speed</h2>

    <p>calculate(18, 20, 60) = <?= calculate(18, 20, 60) ?></p>
    <p>calculate(30, 8, 24) = <?= calculate(30, 8, 24) ?></p>

    <form method="POST" action="">
        <label>Time uphill (minutes):</label>
        <input type="number" name="time" step="any" min="0.01" required><br><br>
        <label>Speed uphill (km/h):</label>
        <input type="number" name="up" step="any" min="0.01" required><br><br>
        <label>Speed downhill (km/h):</label>
        <input type="number" name="down" step="any" min="0.01" required><br><br>
        <input type="submit" name="submit" value="Calculate">
    </form>

    <?php
    if (isset($_POST["submit"])) {
        $time = (float) $_POST["time"];
        $up = (float) $_POST["up"];
        $down = (float) $_POST["down"];

        if ($time <= 0 || $up <= 0 || $down <= 0) {
            echo "<p>All values must be positive.</p>";
        } else {
            echo "<p>Average speed: " . calculate($time, $up, $down) . " km/h</p>";
        }
    }
    ?>
</body>
</html>
```

**Output:** `calculate(18, 20, 60) = 30` and `calculate(30, 8, 24) = 12`.

**Shortcut worth knowing:** the time cancels out. Average = 2 × up × down ÷ (up + down), e.g. 2 × 20 × 60 ÷ 80 = 30. The function still takes the time, as the question asks.

## 3 [10]
**Topics:** 12, 13

### Question
Write a program to check the strength of your password and display the result in your PHP file.

**Strong:** The password contains at least 10 characters, includes at least one uppercase letter, one lowercase letter, one digit, one special character, and ends with the symbol '*'.

**Medium:** The password contains at least 8 characters, includes at least one uppercase letter, one lowercase letter, and one digit.

**Poor:** The password at least 6 characters and includes at least one uppercase letter.

**Very Poor:** anything other than the criteria mentioned above.

Password: `[ text box ]` `[Check]`

| Sample Input | Sample Output |
|---|---|
| aFDF@F1ds* | Strong |
| af15f15a4f45af4asas12 | Very Poor |

### Solution
**Check from the strongest level down**, so a password gets the highest level it fully meets.

- `preg_match('/[A-Z]/', $p)` → has an uppercase letter (similarly `[a-z]`, `[0-9]`).
- `preg_match('/[^A-Za-z0-9]/', $p)` → has a special character (anything that is not a letter or digit).
- `substr($p, -1) === "*"` → ends with `*`.

**index.php**

```php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Password Strength</title>
</head>
<body>
    <form method="POST" action="">
        <label>Password:</label>
        <input type="password" name="password" required>
        <input type="submit" name="check" value="Check">
    </form>

    <?php
    function passwordStrength($p) {
        $length = strlen($p);
        $upper = preg_match('/[A-Z]/', $p);
        $lower = preg_match('/[a-z]/', $p);
        $digit = preg_match('/[0-9]/', $p);
        $special = preg_match('/[^A-Za-z0-9]/', $p);
        $endsWithStar = substr($p, -1) === "*";

        if ($length >= 10 && $upper && $lower && $digit && $special && $endsWithStar) {
            return "Strong";
        } elseif ($length >= 8 && $upper && $lower && $digit) {
            return "Medium";
        } elseif ($length >= 6 && $upper) {
            return "Poor";
        } else {
            return "Very Poor";
        }
    }

    if (isset($_POST["check"])) {
        $password = $_POST["password"];
        echo "<p>Strength: <b>" . passwordStrength($password) . "</b></p>";
    }
    ?>
</body>
</html>
```

The password itself is never printed back to the page.

**Results:**

| Password | Why | Output |
|---|---|---|
| aFDF@F1ds* | 10 chars, upper, lower, digit, `@`, ends with `*` | Strong |
| af15f15a4f45af4asas12 | no uppercase letter, so not even Poor | Very Poor |
| Abcdef12 | 8 chars, upper, lower, digit | Medium |
| Abcdef12@x | special but does not end with `*` | Medium |
| ABCDEF | 6 chars with uppercase | Poor |
| Ab1* | too short for every level | Very Poor |

### Question
A retail company wants a detailed sales analysis for January 2024 to gain deeper insights into their business performance. You are tasked with generating various reports using the sales table. The table structure is as follows:

| sale_id | product_id | quantity_sold | sale_date | total_price |
|---|---|---|---|---|
| 1 | 107 | 5 | 2024-01-01 | 2500.00 |
| 2 | 103 | 3 | 2024-01-02 | 900.00 |
| 3 | 103 | 2 | 2024-01-02 | 60.00 |
| 4 | 107 | 4 | 2024-01-03 | 80.00 |
| 5 | 107 | 6 | 2024-01-03 | 90.00 |

Now, do the following using MYSQL with the help of PHP where needed:

1. Find the total quantity sold and the total revenue for each product.
2. Find the two days in January 2024 with the highest total revenue. Show the sale_date and the total revenue for each day.
3. Calculate the average quantity sold per product for each product_id in January 2024, but only for products that had sales on at least two different days.

The paper also prints the same "Example Codes (MySQLi Object-oriented)" reference as Spring 2024 Question 3 (connect, INSERT, SELECT with `fetch_assoc`, UPDATE, DELETE).

### Solution
The question gives no database name, so this answer uses **`retail_db`**. Two files: the setup SQL and one PHP page.

**retail_db.sql**

```sql
CREATE DATABASE IF NOT EXISTS retail_db;
USE retail_db;

CREATE TABLE sales (
    sale_id INT PRIMARY KEY,
    product_id INT,
    quantity_sold INT,
    sale_date DATE,
    total_price DECIMAL(10,2)
);

INSERT INTO sales (sale_id, product_id, quantity_sold, sale_date, total_price) VALUES
(1, 107, 5, '2024-01-01', 2500.00),
(2, 103, 3, '2024-01-02',  900.00),
(3, 103, 2, '2024-01-02',   60.00),
(4, 107, 4, '2024-01-03',   80.00),
(5, 107, 6, '2024-01-03',   90.00);
```

#### The three queries

```sql
-- 1) total quantity and revenue per product
SELECT product_id, SUM(quantity_sold) AS total_quantity, SUM(total_price) AS total_revenue
FROM sales
GROUP BY product_id;

-- 2) two best days of January 2024
SELECT sale_date, SUM(total_price) AS total_revenue
FROM sales
WHERE sale_date BETWEEN '2024-01-01' AND '2024-01-31'
GROUP BY sale_date
ORDER BY total_revenue DESC
LIMIT 2;

-- 3) average quantity per product, only products sold on 2 or more different days
SELECT product_id, AVG(quantity_sold) AS avg_quantity
FROM sales
WHERE sale_date BETWEEN '2024-01-01' AND '2024-01-31'
GROUP BY product_id
HAVING COUNT(DISTINCT sale_date) >= 2;
```

- Task 2 groups by **day** first, then sorts the daily totals and keeps the top two.
- Task 3: `COUNT(DISTINCT sale_date)` counts **different days**. Product 103 has two sales, but both on 2024-01-02, so it is left out.

**index.php**

```php
<?php
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
$conn = new mysqli("localhost", "root", "", "retail_db");
$conn->set_charset("utf8mb4");

// Prints any SELECT result as an HTML table
function showTable($result) {
    if ($result->num_rows === 0) {
        echo "<p>No rows found.</p>";
        return;
    }
    echo "<table><tr>";
    foreach ($result->fetch_fields() as $field) {
        echo "<th>" . htmlspecialchars($field->name) . "</th>";
    }
    echo "</tr>";
    while ($row = $result->fetch_assoc()) {
        echo "<tr>";
        foreach ($row as $value) {
            echo "<td>" . htmlspecialchars((string) $value) . "</td>";
        }
        echo "</tr>";
    }
    echo "</table>";
}

$from = "2024-01-01";
$to = "2024-01-31";
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Sales Analysis, January 2024</title>
    <style>
        body { font-family: Arial, sans-serif; margin: 30px; }
        table { border-collapse: collapse; margin-bottom: 25px; }
        th, td { border: 1px solid #999; padding: 6px 12px; }
        th { background: #eee; }
    </style>
</head>
<body>
    <h1>Sales Analysis, January 2024</h1>

    <h2>1) Total quantity and revenue per product</h2>
    <?php
    showTable($conn->query(
        "SELECT product_id, SUM(quantity_sold) AS total_quantity, SUM(total_price) AS total_revenue
         FROM sales
         GROUP BY product_id"
    ));
    ?>

    <h2>2) Two days with the highest revenue</h2>
    <?php
    $stmt = $conn->prepare(
        "SELECT sale_date, SUM(total_price) AS total_revenue
         FROM sales
         WHERE sale_date BETWEEN ? AND ?
         GROUP BY sale_date
         ORDER BY total_revenue DESC
         LIMIT 2"
    );
    $stmt->bind_param("ss", $from, $to);
    $stmt->execute();
    showTable($stmt->get_result());
    ?>

    <h2>3) Average quantity per product (sold on at least two different days)</h2>
    <?php
    $stmt = $conn->prepare(
        "SELECT product_id, AVG(quantity_sold) AS avg_quantity
         FROM sales
         WHERE sale_date BETWEEN ? AND ?
         GROUP BY product_id
         HAVING COUNT(DISTINCT sale_date) >= 2"
    );
    $stmt->bind_param("ss", $from, $to);
    $stmt->execute();
    showTable($stmt->get_result());
    ?>
</body>
</html>
<?php
$conn->close();
```
