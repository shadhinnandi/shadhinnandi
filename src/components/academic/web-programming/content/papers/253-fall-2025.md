### Question
Write a PHP program to design a web page that processes a student's CT and exam marks. The page should take input from an HTML form for three CT marks, a midterm mark, and a final exam mark. The program must select the best two CT marks out of the three, calculate their average, and then compute the total marks by adding the CT average with the midterm and final exam marks. Finally, display the status as 'Passed' if the total marks > 54 otherwise display 'Failed'. For better understanding, refer to the demo input and output.

| Sample Input (html) | Sample Output (php) |
|---|---|
| CT 1: 12, CT 2: 15, CT 3: 14, Midterm Marks: 22, Final Marks: 32, `[Calculate Total]` | Best two CT's total: 29<br>Midterm marks: 22<br>Final marks: 32<br>**Total Marks = 83**<br>Status: Passed |

### Solution
**Text vs sample:** the text says "average" of the best two CTs, but the sample prints "Best two CT's **total**: 29" and Total Marks = 29 + 22 + 32 = **83**. With the average it would be 14.5 + 22 + 32 = 68.5. The answer below **follows the sample** (best-two total) and also shows the average; the comment shows the one-line change if your teacher wants the average. Mention this in the exam.

**Best two of three** = sum of all three minus the smallest: 12 + 15 + 14 − 12 = 29. (`rsort` and taking the first two works too.)

**index.php**

```php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Marks Calculator</title>
</head>
<body>
    <form method="POST" action="">
        CT 1: <input type="number" name="ct1" min="0" step="any" required><br>
        CT 2: <input type="number" name="ct2" min="0" step="any" required><br>
        CT 3: <input type="number" name="ct3" min="0" step="any" required><br>
        Midterm Marks: <input type="number" name="mid" min="0" step="any" required><br>
        Final Marks: <input type="number" name="final" min="0" step="any" required><br><br>
        <input type="submit" name="calculate" value="Calculate Total">
    </form>

    <?php
    if (isset($_POST["calculate"])) {
        $ct1 = (float) $_POST["ct1"];
        $ct2 = (float) $_POST["ct2"];
        $ct3 = (float) $_POST["ct3"];
        $mid = (float) $_POST["mid"];
        $final = (float) $_POST["final"];

        // Best two CTs: drop the smallest
        $bestTwoTotal = $ct1 + $ct2 + $ct3 - min($ct1, $ct2, $ct3);
        $ctAverage = $bestTwoTotal / 2;

        // As in the sample output (83 = 29 + 22 + 32).
        // For the "average" wording use:  $total = $ctAverage + $mid + $final;
        $total = $bestTwoTotal + $mid + $final;

        $status = $total > 54 ? "Passed" : "Failed";

        echo "<p>Best two CT's total: $bestTwoTotal<br>";
        echo "Best two CT's average: $ctAverage<br>";
        echo "Midterm marks: $mid<br>";
        echo "Final marks: $final</p>";
        echo "<p><b>Total Marks = $total</b><br>";
        echo "Status: $status</p>";
    }
    ?>
</body>
</html>
```

**Output for the sample:**

```text
Best two CT's total: 29
Best two CT's average: 14.5
Midterm marks: 22
Final marks: 32

Total Marks = 83
Status: Passed
```

Other checks: CT 5, 6, 7, mid 10, final 20 → best two 13, total 43, **Failed**. A total of exactly 54 is **Failed** (the rule is "> 54").

### Question
Write a PHP program for a simple event-planning system. The program should take three inputs from the user: **number of items sold per day**, **number of days the sale runs**, and **target number of items to be sold**. First, calculate the **total items sold** by multiplying the items sold per day with the number of days. Classify the sales performance using the following conditions:

- **Excellent:** total items sold 500 or more
- **Good:** total items sold 300 or more but less than 500
- **Average:** total items sold 150 or more but less than 300
- **Poor:** total items sold less than 150

The program should then compare the total items sold with the target number of items. Finally, display the total items sold, the performance category, the target value, and clearly state whether the sales are **above**, **below**, or **exactly at** the target, along with the difference.

| Items Sold per Day | Number of Days | Target Items | Total Items Sold | Performance | Result |
|---|---|---|---|---|---|
| 25 | 12 | 300 | 300 | Good | Target met exactly (0 difference) |
| 40 | 10 | 350 | 400 | Excellent | Above target by 50 items |
| 15 | 10 | 200 | 150 | Average | Below target by 50 items |
| 8 | 10 | 120 | 80 | Poor | Below target by 40 items |

(Sample Input taken using html form; Sample Output printed using PHP code.)

### Solution
**Steps:** total = per day × days → classify from the top (`>= 500`, `>= 300`, `>= 150`, else) → difference = total − target → above / below / exactly.

**index.php**

```php
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Event Sales</title>
    <style>
        table { border-collapse: collapse; margin-top: 15px; }
        th, td { border: 1px solid #999; padding: 6px 12px; }
    </style>
</head>
<body>
    <h2>Event Sales Planner</h2>
    <form method="POST" action="">
        <label>Items Sold per Day:</label>
        <input type="number" name="perDay" min="0" required><br><br>
        <label>Number of Days:</label>
        <input type="number" name="days" min="1" required><br><br>
        <label>Target Items:</label>
        <input type="number" name="target" min="0" required><br><br>
        <input type="submit" name="calculate" value="Calculate">
    </form>

    <?php
    if (isset($_POST["calculate"])) {
        $perDay = (int) $_POST["perDay"];
        $days = (int) $_POST["days"];
        $target = (int) $_POST["target"];

        if ($perDay < 0 || $days < 1 || $target < 0) {
            echo "<p>Please enter valid numbers.</p>";
        } else {
            $total = $perDay * $days;

            if ($total >= 500) {
                $performance = "Excellent";
            } elseif ($total >= 300) {
                $performance = "Good";
            } elseif ($total >= 150) {
                $performance = "Average";
            } else {
                $performance = "Poor";
            }

            $difference = $total - $target;
            if ($difference > 0) {
                $result = "Above target by $difference items";
            } elseif ($difference < 0) {
                $result = "Below target by " . abs($difference) . " items";
            } else {
                $result = "Target met exactly (0 difference)";
            }

            echo "<table>";
            echo "<tr><th>Total Items Sold</th><th>Performance</th><th>Target</th><th>Result</th></tr>";
            echo "<tr><td>$total</td><td>$performance</td><td>$target</td><td>$result</td></tr>";
            echo "</table>";
        }
    }
    ?>
</body>
</html>
```

**Output:**

| Input | Total | Performance | Target | Result |
|---|---|---|---|---|
| 25, 12, 300 | 300 | Good | 300 | Target met exactly (0 difference) |
| 40, 10, 350 | 400 | **Good** | 350 | Above target by 50 items |
| 15, 10, 200 | 150 | Average | 200 | Below target by 50 items |
| 8, 10, 120 | 80 | Poor | 120 | Below target by 40 items |

**Note on the second sample:** the paper prints "Excellent" for 40 × 10 = 400 items, but its own rule says Excellent is "500 or more" and Good is "300 or more but less than 500". By the rules, 400 is **Good**, and that is what the program prints. The total (400) and the result (above target by 50) match the sample. Point this out in the exam rather than changing the thresholds.

### Question
Create a database named **campus_library** and a table named **book_loans**. The table tracks student borrowing habits and book conditions.

| LoanID | StudentName | BookTitle | DaysOverdue | PenaltyFee | Status |
|---|---|---|---|---|---|
| 101 | Abdul | Data Structures | 0 | 0.00 | Returned |
| 102 | Jabbar | Operating Systems | 12 | 24.00 | Overdue |
| 103 | Barkat | Discrete Math | 5 | 10.00 | Overdue |
| 104 | Rahim | Linear Algebra | 2 | 4.00 | Overdue |
| 105 | Karim | Data Structures | 15 | 30.00 | Lost |
| 106 | Fahim | Operating Systems | 0 | 0.00 | Returned |

Answer the following queries

1. Show the total number of books for each Status (*Returned*, *Overdue*, *Lost*), but only include statuses that have more than 1 entry in the table.
2. For any student who has a Status of '*Overdue*' and DaysOverdue less than 7, change their Status to '*Grace Period*' and set their PenaltyFee to 0.
3. For students with a PenaltyFee greater than 20.00, increase their fee by 10% as a "*processing charge*," but only if the final fee does not exceed 50.00.
4. Display each BookTitle and the total PenaltyFee collected/owed for that book. Sort the results so that the book generating the most money appears at the top.

### Solution
**campus_library.sql**

```sql
CREATE DATABASE IF NOT EXISTS campus_library;
USE campus_library;

CREATE TABLE book_loans (
    LoanID INT PRIMARY KEY,
    StudentName VARCHAR(50),
    BookTitle VARCHAR(100),
    DaysOverdue INT,
    PenaltyFee DECIMAL(6,2),
    Status VARCHAR(20)
);

INSERT INTO book_loans (LoanID, StudentName, BookTitle, DaysOverdue, PenaltyFee, Status) VALUES
(101, 'Abdul',  'Data Structures',   0,  0.00, 'Returned'),
(102, 'Jabbar', 'Operating Systems', 12, 24.00, 'Overdue'),
(103, 'Barkat', 'Discrete Math',     5,  10.00, 'Overdue'),
(104, 'Rahim',  'Linear Algebra',    2,   4.00, 'Overdue'),
(105, 'Karim',  'Data Structures',   15, 30.00, 'Lost'),
(106, 'Fahim',  'Operating Systems', 0,   0.00, 'Returned');
```

#### The SQL for each task

```sql
-- 1) books per status, only statuses with more than 1 entry
SELECT Status, COUNT(*) AS TotalBooks
FROM book_loans
GROUP BY Status
HAVING COUNT(*) > 1
ORDER BY TotalBooks DESC;

-- 2) Overdue for less than 7 days -> Grace Period, fee 0 (both columns in one UPDATE)
UPDATE book_loans
SET Status = 'Grace Period', PenaltyFee = 0
WHERE Status = 'Overdue' AND DaysOverdue < 7;

-- 3) +10% processing charge for fees above 20, only if the result is at most 50
UPDATE book_loans
SET PenaltyFee = PenaltyFee * 1.10
WHERE PenaltyFee > 20 AND PenaltyFee * 1.10 <= 50;

-- 4) total fee per book, highest first
SELECT BookTitle, SUM(PenaltyFee) AS TotalPenalty
FROM book_loans
GROUP BY BookTitle
ORDER BY TotalPenalty DESC, BookTitle;
```

- Task 1 filters **groups**, so the condition goes in `HAVING`, not `WHERE`.
- Task 2 sets **two columns** in one `SET`, separated by a comma.
