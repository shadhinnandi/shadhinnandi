### Question
Create a JavaScript game where a user tries to guess a secret number generated by your code. Strategies are as follows:

**Index.html:**
Create a text filed (input type text) to take the users' guess and a submit button, below the submit button there is a label field to show the feedbacks and results.

**Script.js:**

1. Generate a random secret number between 500 and 5000.
2. Take the user's guess from the input field in the HTML file.
3. Inside a function:
   - a) Compare the user's guess to the secret number.
   - b) Display "Too high!" or "Too low!" in the feedback area of your web page.
   - c) If the guess is correct, display "Correct!" and optionally disable the input field to prevent further guesses.
   - d) Keep track of the number of guesses the user has made.
   - e) If the user runs out of guesses (after 5 attempts), display "Out of guesses!" and optionally disable the input field.

| Sample Input: User Guesses (from html) | Output/Feedback (on html file using JS file) | Result |
|---|---|---|
| 50, 25, 35, 38, 37 | (suppose random number:37) Too high!, Too low!, Too low!, Too high!, Correct! | Correct! |
| 10, 50, 90, 80, 85 | (suppose random number:82) Too low!, Too low!, Too high!, Too low!, Too high! | Out of guesses! |
| 1, 5, 10, 20, 15 | (suppose random number:15) Too low!, Too low!, Too low!, Too high!, Correct! | Correct! |

### Solution
**Key points:**

- The secret number and the guess counter are **global** (outside the function), so they survive between clicks.
- A whole number from 500 to 5000 **inclusive**: `Math.floor(Math.random() * 4501) + 500`. (`Math.random() * 4501` is 0 to 4500.99..., `floor` makes it 0 to 4500, `+ 500` makes it 500 to 5000.)
- The feedback of every guess is kept in an array, so the label shows the same list as the sample.

**index.html**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Guess the Number</title>
</head>
<body>
    <h2>Guess the secret number (500 to 5000)</h2>

    <input type="text" id="guess" placeholder="Your guess">
    <button id="submitBtn" onclick="checkGuess()">Submit</button>
    <br><br>
    <label id="feedback"></label>

    <script src="script.js"></script>
</body>
</html>
```

**script.js**

```javascript
// 1. Secret number from 500 to 5000 (both included)
let secret = Math.floor(Math.random() * 4501) + 500;
// To try the samples, replace the line above with e.g.  let secret = 37;

const MAX_ATTEMPTS = 5;
let attempts = 0;        // d) number of guesses so far
let history = [];        // feedback of every guess
let gameOver = false;

function checkGuess() {
    if (gameOver) return;    // no more guesses after the result

    // 2. Read the guess
    let guess = parseInt(document.getElementById("guess").value);

    if (isNaN(guess)) {
        document.getElementById("feedback").innerHTML = "Please enter a number.";
        return;          // not counted as an attempt
    }

    attempts++;
    let message;
    let result = "";

    // a) b) c) Compare
    if (guess > secret) {
        message = "Too high!";
    } else if (guess < secret) {
        message = "Too low!";
    } else {
        message = "Correct!";
        result = "Correct!";
    }
    history.push(message);

    // e) Out of guesses after 5 wrong attempts
    if (result === "" && attempts >= MAX_ATTEMPTS) {
        result = "Out of guesses! The number was " + secret + ".";
    }

    document.getElementById("feedback").innerHTML =
        message + "<br>" +
        "Attempts: " + attempts + " of " + MAX_ATTEMPTS + "<br>" +
        "Feedback: " + history.join(", ") +
        (result !== "" ? "<br><b>Result: " + result + "</b>" : "");

    // Game over: stop further guesses
    if (result !== "") {
        gameOver = true;
        document.getElementById("guess").disabled = true;
        document.getElementById("submitBtn").disabled = true;
    }
    document.getElementById("guess").value = "";
}
```

**Results** (secret fixed for testing):

| Secret | Guesses | Feedback shown | Result |
|---|---|---|---|
| 37 | 50, 25, 35, 38, 37 | Too high!, Too low!, Too low!, Too high!, Correct! | Correct! |
| 82 | 10, 50, 90, 80, 85 | Too low!, Too low!, Too high!, Too low!, Too high! | Out of guesses! The number was 82. |
| 15 | 1, 5, 10, 20, 15 | Too low!, Too low!, Too low!, Too high!, Correct! | Correct! |

After the result the input and the button are disabled.

**Note:** the class example uses `Math.ceil(Math.random() * 4500 + 500)`, which in practice gives 501 to 5000 (500 only when `Math.random()` returns exactly 0). The `floor` version above includes both 500 and 5000 evenly.

### Question
**PHP:**
It's the end of the Web Programming course, and we want to celebrate it by having a pizza party. You need to figure out how many pizzas to order and how many slices will be left over. Write a PHP function that takes three integers as input: the number of students in the class, the number of slices each student wants, and the number of slices each pizza has. The function should calculate the minimum number of pizzas you need to order to ensure every student gets enough pizza (you must order whole pizzas; you cannot order fractions of pizzas). The function should also calculate the number of pizza slices that will be left over after all the students have had their fill. Moreover, if the price of each pizza is 1050 BDT (irrespective of size), how much money was wasted based on the leftover slices?

| Number of Students | Slices per Student | Slices per Pizza | Total Pizzas | Leftover Slices | Wasted Money (BDT) |
|---|---|---|---|---|---|
| 10 | 3 | 8 | 4 | 2 | 262.5 |
| 7 | 2 | 6 | 3 | 4 | 700 |
| 12 | 2 | 4 | 6 | 0 | 0 |

(Sample Input from html file text fields; Sample Output printed on the PHP file.)

### Solution
**Formulas:**

- Slices needed = students × slices per student
- Pizzas = **ceil**(slices needed ÷ slices per pizza) (round **up**: whole pizzas only)
- Leftover = pizzas × slices per pizza − slices needed
- Price of one slice = 1050 ÷ slices per pizza, so wasted money = leftover × (1050 ÷ slices per pizza)

Check: 10 × 3 = 30 slices, 30 ÷ 8 = 3.75 → **4** pizzas, 32 − 30 = **2** left, 2 × 1050 ÷ 8 = **262.5** BDT.

**index.php**

```php
<?php
// Returns [pizzas, leftover slices, wasted money]
function pizzaParty($students, $slicesPerStudent, $slicesPerPizza) {
    $pricePerPizza = 1050;
    $slicesNeeded = $students * $slicesPerStudent;
    $pizzas = (int) ceil($slicesNeeded / $slicesPerPizza);
    $leftover = $pizzas * $slicesPerPizza - $slicesNeeded;
    $wasted = $leftover * ($pricePerPizza / $slicesPerPizza);
    return [$pizzas, $leftover, $wasted];
}
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Pizza Party</title>
    <style>
        table { border-collapse: collapse; margin-top: 15px; }
        th, td { border: 1px solid #999; padding: 6px 12px; }
    </style>
</head>
<body>
    <h2>Pizza Party Planner</h2>
    <form method="POST" action="">
        <label>Number of Students:</label>
        <input type="text" name="students" required><br><br>
        <label>Slices per Student:</label>
        <input type="text" name="slices" required><br><br>
        <label>Slices per Pizza:</label>
        <input type="text" name="perPizza" required><br><br>
        <input type="submit" name="calculate" value="Calculate">
    </form>

    <?php
    if (isset($_POST["calculate"])) {
        $students = (int) $_POST["students"];
        $slices = (int) $_POST["slices"];
        $perPizza = (int) $_POST["perPizza"];

        if ($students <= 0 || $slices <= 0 || $perPizza <= 0) {
            echo "<p>All three values must be positive whole numbers.</p>";
        } else {
            [$pizzas, $leftover, $wasted] = pizzaParty($students, $slices, $perPizza);

            echo "<table>";
            echo "<tr><th>Total Pizzas</th><th>Leftover Slices</th><th>Wasted Money (BDT)</th></tr>";
            echo "<tr><td>$pizzas</td><td>$leftover</td><td>" . round($wasted, 2) . "</td></tr>";
            echo "</table>";
        }
    }
    ?>
</body>
</html>
```

**Output:**

| Input | Total Pizzas | Leftover Slices | Wasted Money (BDT) |
|---|---|---|---|
| 10, 3, 8 | 4 | 2 | 262.5 |
| 7, 2, 6 | 3 | 4 | 700 |
| 12, 2, 4 | 6 | 0 | 0 |

### Question
**PHP & MYSQL:**
Create a dataset named 'uiuweb_final' and a table named 'student_final'. The student table has the following structure and values:

| StudentID | StudentName | CourseID | CourseTitle | Grade | LetterGrade |
|---|---|---|---|---|---|
| 1 | Karim Uddin | 101 | Web Programming | 85 | B |
| 2 | Rahim Ahmed | 101 | Web Programming | 92 | A |
| 3 | Jashim Hossain | 102 | Project Management | 78 | C |
| 4 | Jasica Ahmed | 101 | Web Programming | 65 | D |
| 5 | Faria Karim | 102 | Project Management | 95 | A |
| 6 | Niassoh Dihan | 103 | System Analysis and Design | 80 | B |

Now, do the following:

1. Show the total number of students who received each letter grade (A, B, C, D) across all courses.
2. If a student has a grade below 75 and their current letter grade is not 'D', change their letter grade to 'C'.
3. If a student has a grade greater than 80, add 5 bonus points to their grade, but only if the resulting grade is less than or equal to 90.
4. For each course, display the course titles and the number of students enrolled in that course, sorted by the number of students (most popular first).

### Solution
**uiuweb_final.sql**

```sql
CREATE DATABASE IF NOT EXISTS uiuweb_final;
USE uiuweb_final;

CREATE TABLE student_final (
    StudentID INT PRIMARY KEY,
    StudentName VARCHAR(100),
    CourseID INT,
    CourseTitle VARCHAR(100),
    Grade INT,
    LetterGrade CHAR(1)
);

INSERT INTO student_final (StudentID, StudentName, CourseID, CourseTitle, Grade, LetterGrade) VALUES
(1, 'Karim Uddin',    101, 'Web Programming',            85, 'B'),
(2, 'Rahim Ahmed',    101, 'Web Programming',            92, 'A'),
(3, 'Jashim Hossain', 102, 'Project Management',         78, 'C'),
(4, 'Jasica Ahmed',   101, 'Web Programming',            65, 'D'),
(5, 'Faria Karim',    102, 'Project Management',         95, 'A'),
(6, 'Niassoh Dihan',  103, 'System Analysis and Design', 80, 'B');
```

#### The SQL for each task

```sql
-- 1) students per letter grade; the list of grades makes A, B, C, D appear even with 0 students
SELECT g.LetterGrade, COUNT(s.StudentID) AS TotalStudents
FROM (SELECT 'A' AS LetterGrade UNION ALL SELECT 'B' UNION ALL SELECT 'C' UNION ALL SELECT 'D') AS g
LEFT JOIN student_final s ON s.LetterGrade = g.LetterGrade
GROUP BY g.LetterGrade
ORDER BY g.LetterGrade;

-- 2) grade below 75 and letter grade not D -> C
UPDATE student_final SET LetterGrade = 'C' WHERE Grade < 75 AND LetterGrade <> 'D';

-- 3) +5 bonus for grades above 80, only if the new grade is at most 90
UPDATE student_final SET Grade = Grade + 5 WHERE Grade > 80 AND Grade + 5 <= 90;

-- 4) students per course, most popular first
SELECT CourseTitle, COUNT(*) AS Students
FROM student_final
GROUP BY CourseID, CourseTitle
ORDER BY Students DESC;
```

The simple version of task 1, `SELECT LetterGrade, COUNT(*) FROM student_final GROUP BY LetterGrade`, gives the same answer here because every grade has at least one student; it would skip a grade with zero students.

#### The PHP page

**index.php**

```php
<?php
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
$conn = new mysqli("localhost", "root", "", "uiuweb_final");
$conn->set_charset("utf8mb4");

// Prints any SELECT result as an HTML table
function showTable($result) {
    if ($result->num_rows === 0) {
        echo "<p>No rows found.</p>";
        return;
    }
    echo "<table><tr>";
    foreach ($result->fetch_fields() as $field) {
        echo "<th>" . htmlspecialchars($field->name) . "</th>";
    }
    echo "</tr>";
    while ($row = $result->fetch_assoc()) {
        echo "<tr>";
        foreach ($row as $value) {
            echo "<td>" . htmlspecialchars((string) $value) . "</td>";
        }
        echo "</tr>";
    }
    echo "</table>";
}

$message = "";
```
