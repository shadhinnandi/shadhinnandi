### Question
**JAVASCRIPT:** Create a JavaScript application where users can test their password strength and get real-time feedback.

**index.html:**
Create a password input field (input type password), a "Check Strength" button, and below that a label field to display strength feedback and scoring results.

**script.js:**

1. Generate a target strength score of 100 points for a "Very Strong" password.
2. Take the user's password input from the HTML file.
3. Inside a function:
   - Calculate password strength based on these criteria:
     - Length: +10 points for every 2 characters (minimum 6 characters required)
     - Uppercase letters: +15 points if present
     - Lowercase letters: +15 points if present
     - Numbers: +20 points if present
     - Special characters (!@#$%^&*): +25 points if present
   - Display strength levels: "Very Weak" (0-30), "Weak" (31-50), "Medium" (51-70), "Strong" (71-90), "Very Strong" (91+)
   - If password reaches 100+ points, display "Perfect Password!" and show a success message
   - Keep track of how many attempts the user has made
   - If the user makes more than 8 attempts without reaching "Strong" level, display "Need practice!" and suggest password tips

| Sample Input | Sample Output |
|---|---|
| abc | Very Weak |
| hello123 | Weak |
| Strong@Pass | Strong |
| Perfect@Pass123 | Perfect Password! |

### Solution
**First, work out the length rule from the samples.** "+10 points for every 2 characters" could mean every 2 characters of the whole password, or every 2 characters **beyond the 6-character minimum**. Only the second reading gives the sample outputs:

| Password | Length | Other points | Length points if every 2 chars | Total | Length points beyond 6 | Total | Sample |
|---|---|---|---|---|---|---|---|
| abc | 3 | lower 15 | 0 (under 6) | 15 | 0 | 15 Very Weak | Very Weak |
| hello123 | 8 | lower 15 + digit 20 | 40 | 75 Strong | 10 | **45 Weak** | Weak |
| Strong@Pass | 11 | upper 15 + lower 15 + special 25 | 50 | 105 | 20 | **75 Strong** | Strong |
| Perfect@Pass123 | 15 | 15 + 15 + 20 + 25 | 70 | 145 | 40 | **115 Perfect** | Perfect Password! |

So: **length points = 10 × floor((length − 6) / 2)** when the length is at least 6, otherwise 0. State this reading in the exam.

**script.js**

```javascript
const TARGET = 100;          // 1. target score
let attempts = 0;            // number of checks so far
let reachedStrong = false;   // has any attempt reached "Strong" (71+)?

function checkStrength() {
    // 2. Read the password
    let password = document.getElementById("password").value;
    attempts++;

    // 3. Score
    let score = 0;
    if (password.length >= 6) {
        score += Math.floor((password.length - 6) / 2) * 10;   // +10 per 2 characters beyond the minimum 6
    }
    if (/[A-Z]/.test(password)) score += 15;
    if (/[a-z]/.test(password)) score += 15;
    if (/[0-9]/.test(password)) score += 20;
    if (/[!@#$%^&*]/.test(password)) score += 25;

    // Strength level
    let level;
    if (score >= 91) {
        level = "Very Strong";
    } else if (score >= 71) {
        level = "Strong";
    } else if (score >= 51) {
        level = "Medium";
    } else if (score >= 31) {
        level = "Weak";
    } else {
        level = "Very Weak";
    }

    if (score >= 71) {
        reachedStrong = true;
    }

    let output;
    if (score >= TARGET) {
        output = "<b>Perfect Password!</b><br>Success! Your password reached the target of " + TARGET + " points.";
    } else {
        output = "<b>" + level + "</b>";
    }

    output += "<br>Score: " + score + " / " + TARGET;
    output += "<br>Attempts: " + attempts;

    if (password.length < 6) {
        output += "<br>Use at least 6 characters.";
    }

    if (attempts > 8 && !reachedStrong) {
        output += "<br><br><b>Need practice!</b> Tips: use 10 or more characters, " +
                  "mix UPPER and lower case letters, add numbers, " +
                  "and add a special character such as ! @ # $ % ^ & *.";
    }

    document.getElementById("feedback").innerHTML = output;
}
```

### Question
**PHP:** It's time to organize the annual UIU Tech Fest, and you need to calculate the budget for venue booking. Write a PHP function that takes three integers as input: the number of expected attendees, the cost per person for venue arrangement, and the maximum capacity of available venues. The function should calculate the minimum number of venues needed to accommodate all attendees (you must book complete venues; you cannot book partial venues). The function should also calculate how many empty seats will remain after all attendees are seated. Moreover, if each venue costs 15,000 BDT regardless of occupancy, how much money is wasted on empty seats?

| Attendees | Cost per Person | Venue Capacity | Total Venues | Empty Seats | Wasted Money (BDT) |
|---|---|---|---|---|---|
| 250 | 120 | 80 | 4 | 70 | 8,400 |
| 180 | 150 | 100 | 2 | 20 | 3,000 |
| 300 | 100 | 75 | 4 | 0 | 0 |

(Sample Input from html file text fields; Sample Output printed on the PHP file.)

### Solution
**Formulas that reproduce the samples:**

- Venues = **ceil**(attendees ÷ capacity)
- Empty seats = venues × capacity − attendees
- Wasted money = empty seats × **cost per person**

Check: 250 ÷ 80 = 3.125 → **4** venues, 320 − 250 = **70** empty, 70 × 120 = **8,400**. Second row: 2 venues, 20 empty, 20 × 150 = **3,000**.

**Note on the 15,000 BDT:** the samples do **not** use it. Charging 15,000 per venue spread over its seats would give 70 × (15,000 ÷ 80) = 13,125 for the first row, not 8,400. The answer follows the samples and also prints the total venue booking cost (venues × 15,000) as extra information. Mention this in the exam.

**index.php**

```php
<?php
// Returns [venues, empty seats, wasted money, total venue cost]
function venueBudget($attendees, $costPerPerson, $capacity) {
    $venueCost = 15000;
    $venues = (int) ceil($attendees / $capacity);
    $emptySeats = $venues * $capacity - $attendees;
    $wasted = $emptySeats * $costPerPerson;
    $totalVenueCost = $venues * $venueCost;
    return [$venues, $emptySeats, $wasted, $totalVenueCost];
}
```

### Question
**PHP & MYSQL:** Create a database named 'uiutech_final' and a table named 'employee_final'. The employee table has the following structure and values:

| EmployeeID | EmployeeName | DepartmentID | DepartmentName | Salary | PerformanceRating |
|---|---|---|---|---|---|
| 1 | Arif Rahman | 201 | Software Development | 45000 | B |
| 2 | Marium Khan | 201 | Software Development | 52000 | A |
| 3 | Sabbir Hossain | 202 | Quality Assurance | 38000 | C |
| 4 | Samira Begum | 203 | UI/UX Design | 42000 | B |

Now, do the following (write full code, not just SQL queries):

1. Show the total number of employees who received each performance rating (A, B, C, D) across all departments.
2. If an employee has a salary below 40,000 BDT and their current performance rating is not 'D', change their performance rating to 'C'.
3. If an employee has a salary greater than 50,000 BDT, add a 5,000 BDT bonus to their salary, but only if the resulting salary is less than or equal to 60,000 BDT.
4. For each department, display the department names and the number of employees working in that department, sorted by the number of employees (largest department first).

The paper prints a "Sample SQL Query" box with two snippets: connect + SELECT with `fetch_assoc`, and connect + UPDATE.

### Solution
**uiutech_final.sql**

```sql
CREATE DATABASE IF NOT EXISTS uiutech_final;
USE uiutech_final;

CREATE TABLE employee_final (
    EmployeeID INT PRIMARY KEY,
    EmployeeName VARCHAR(100),
    DepartmentID INT,
    DepartmentName VARCHAR(100),
    Salary INT,
    PerformanceRating CHAR(1)
);

INSERT INTO employee_final (EmployeeID, EmployeeName, DepartmentID, DepartmentName, Salary, PerformanceRating) VALUES
(1, 'Arif Rahman',    201, 'Software Development', 45000, 'B'),
(2, 'Marium Khan',    201, 'Software Development', 52000, 'A'),
(3, 'Sabbir Hossain', 202, 'Quality Assurance',    38000, 'C'),
(4, 'Samira Begum',   203, 'UI/UX Design',         42000, 'B');
```

#### The SQL for each task

```sql
-- 1) employees per rating, including ratings with 0 employees (D)
SELECT r.PerformanceRating, COUNT(e.EmployeeID) AS TotalEmployees
FROM (SELECT 'A' AS PerformanceRating UNION ALL SELECT 'B' UNION ALL SELECT 'C' UNION ALL SELECT 'D') AS r
LEFT JOIN employee_final e ON e.PerformanceRating = r.PerformanceRating
GROUP BY r.PerformanceRating
ORDER BY r.PerformanceRating;

-- 2) salary below 40000 and rating not D -> C
UPDATE employee_final SET PerformanceRating = 'C' WHERE Salary < 40000 AND PerformanceRating <> 'D';

-- 3) +5000 for salaries above 50000, only if the result is at most 60000
UPDATE employee_final SET Salary = Salary + 5000 WHERE Salary > 50000 AND Salary + 5000 <= 60000;

-- 4) employees per department, largest first
SELECT DepartmentName, COUNT(*) AS Employees
FROM employee_final
GROUP BY DepartmentID, DepartmentName
ORDER BY Employees DESC, DepartmentName;
```

Task 1 needs the list of ratings because **nobody has a D**: a plain `GROUP BY PerformanceRating` would show only A, B and C, but the question asks for A, B, C **and D**.
