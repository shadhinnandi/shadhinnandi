### Question
Create a JavaScript application where users can track their daily calorie intake and get real-time feedback on their eating habits.

**Index.html:**
Create a number input field to enter calories consumed per meal, a **"Add Calories"** button, and below that a label field to display total calories, daily goal progress, and feedback messages

**Script.js:**

1. Set a **daily calorie goal** of **2000 calories**.
2. Take the user's calorie input from the HTML file.
3. Inside a function:
   - a) Add the entered calories to a running total.
   - b) Display the **total calories consumed so far**.
   - c) Display feedback messages based on progress:
     - 0–800 → "You're off to a healthy start!"
     - 801–1600 → "Good progress, keep it balanced!"
     - 1601–1999 → "Almost at your limit!"
     - 2000+ → "Goal reached! Stay mindful!"
   - d) Keep track of the **number of entries** the user has made
   - e) If the user logs calories **more than 10 times** without reaching the goal, display **"Be cautious of frequent snacking!"**

| Sample Input (User Calorie Input) | Sample Output (Feedback) |
|---|---|
| 300, 500, 700 | Good progress, keep it balanced! |
| 1000, 800, 300 | Goal reached! Stay mindful! |
| 12 entries, total 1500 | Be cautious of frequent snacking! |

### Solution
**Key points:**

- `GOAL`, `total` and `entries` live **outside** the function so they keep their values between clicks.
- The ranges are checked from the **top** (`>= 2000`, then `> 1600`, then `> 800`), so every total, including decimals such as 800.5, gets a message.
- Rule (e) is checked **after** the ranges so it replaces the normal message.

**index.html**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Calorie Tracker</title>
</head>
<body>
    <h2>Daily Calorie Tracker</h2>

    <input type="number" id="calories" min="0" placeholder="Calories in this meal">
    <button onclick="addCalories()">Add Calories</button>
    <br><br>
    <label id="result"></label>

    <script src="script.js"></script>
</body>
</html>
```

**script.js**

```javascript
const GOAL = 2000;   // 1. daily goal
let total = 0;       // running total
let entries = 0;     // number of entries

function addCalories() {
    // 2. Read the input
    let calories = parseFloat(document.getElementById("calories").value);

    if (isNaN(calories) || calories < 0) {
        document.getElementById("result").innerHTML = "Please enter a valid number of calories.";
        return;
    }

    // a) d)
    total += calories;
    entries++;

    // c) Feedback
    let feedback;
    if (total >= GOAL) {
        feedback = "Goal reached! Stay mindful!";
    } else if (total > 1600) {
        feedback = "Almost at your limit!";
    } else if (total > 800) {
        feedback = "Good progress, keep it balanced!";
    } else {
        feedback = "You're off to a healthy start!";
    }

    // e) More than 10 entries without reaching the goal
    if (entries > 10 && total < GOAL) {
        feedback = "Be cautious of frequent snacking!";
    }

    let progress = Math.min(100, (total / GOAL) * 100).toFixed(1);

    // b) Show everything
    document.getElementById("result").innerHTML =
        "Total calories: " + total + "<br>" +
        "Daily goal progress: " + total + " / " + GOAL + " (" + progress + "%)<br>" +
        "Entries: " + entries + "<br>" +
        feedback;

    document.getElementById("calories").value = "";
}
```

|---|---|---|

| 1000, 800, 300 | 2100 | Goal reached! Stay mindful! |
| 12 entries of 125 | 1500 | Be cautious of frequent snacking! |
| 400 | 400 | You're off to a healthy start! |
| 1000, 700 | 1700 | Almost at your limit! |

### Question
You are managing a **movie night event** where you need to calculate how many screens to rent and how much money will be wasted due to empty seats. Write a PHP function that takes three integer inputs: the total number of people attending, the seating capacity of one screen, and the ticket price per seat. The function should calculate how many **complete screens** are needed to accommodate all people (you cannot book partial screens), and how many **empty seats** will remain after everyone is seated. Furthermore, each screen has a **fixed rental cost of 25,000 BDT**, and the amount of money wasted on empty seats must be calculated based on the ticket price multiplied by the number of unused seats. The output should display the total number of screens booked, total empty seats, and total wasted money.

| Attendees | Seat Capacity | Ticket Price | Total Screens | Empty Seats | Wasted Money |
|---|---|---|---|---|---|
| 150 | 60 | 500 | 3 | 30 | 15,000 |
| 280 | 100 | 400 | 3 | 20 | 8,000 |
| 320 | 120 | 350 | 3 | 40 | 14,000 |

(Sample Input from HTML fields; Sample Output printed on the PHP file.)

### Solution
**Formulas:**

- Screens = **ceil**(attendees ÷ capacity)
- Empty seats = screens × capacity − attendees
- Wasted money = empty seats × ticket price (as the question states)
- The fixed 25,000 BDT per screen does not change the wasted money; the page shows the total rental (screens × 25,000) as extra information.

Check: 150 ÷ 60 = 2.5 → **3** screens, 180 − 150 = **30** empty, 30 × 500 = **15,000**.

**index.php**

```php
<?php
// Returns [screens, empty seats, wasted money, total rental]
function movieNight($attendees, $capacity, $ticketPrice) {
    $rentalPerScreen = 25000;
    $screens = (int) ceil($attendees / $capacity);
    $emptySeats = $screens * $capacity - $attendees;
    $wasted = $emptySeats * $ticketPrice;
    $rental = $screens * $rentalPerScreen;
    return [$screens, $emptySeats, $wasted, $rental];
}
?>
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Movie Night</title>
    <style>
        table { border-collapse: collapse; margin-top: 15px; }
        th, td { border: 1px solid #999; padding: 6px 12px; }
    </style>
</head>
<body>
    <h2>Movie Night Planner</h2>
    <form method="POST" action="">
        <label>Attendees:</label>
        <input type="number" name="attendees" min="1" required><br><br>
        <label>Seat Capacity:</label>
        <input type="number" name="capacity" min="1" required><br><br>
        <label>Ticket Price:</label>
        <input type="number" name="price" min="0" required><br><br>
        <input type="submit" name="calculate" value="Calculate">
    </form>

    <?php
    if (isset($_POST["calculate"])) {
        $attendees = (int) $_POST["attendees"];
        $capacity = (int) $_POST["capacity"];
        $price = (int) $_POST["price"];

        if ($attendees <= 0 || $capacity <= 0 || $price < 0) {
            echo "<p>Enter positive whole numbers.</p>";
        } else {
            [$screens, $empty, $wasted, $rental] = movieNight($attendees, $capacity, $price);

            echo "<table>";
            echo "<tr><th>Total Screens</th><th>Empty Seats</th><th>Wasted Money</th></tr>";
            echo "<tr><td>$screens</td><td>$empty</td><td>" . number_format($wasted) . "</td></tr>";
            echo "</table>";
            echo "<p>Screen rental: " . number_format($rental) . " BDT ($screens × 25,000)</p>";
        }
    }
    ?>
</body>
</html>
```

### Question
Create a database named **'sundarban'** and a table named **'sales_data'** with the following structure and values:

| SaleID | ProductName | CategoryID | CategoryName | Quantity | Revenue |
|---|---|---|---|---|---|
| 1 | Laptop | 301 | Electronics | 5 | 350000 |
| 2 | Mouse | 301 | Electronics | 15 | 45000 |
| 3 | Chair | 302 | Furniture | 8 | 64000 |
| 4 | Desk | 302 | Furniture | 6 | 72000 |
| 5 | Bottle | 303 | Accessories | 20 | 30000 |
| 6 | Pen | 303 | Accessories | 25 | 20000 |

Now, do the following (write full PHP–MySQL code):

1. Display the **total revenue per category** from the database.
2. If a product's revenue is below **40,000 BDT**, update its category to **"Low Performing"**.
3. For all products generating more than **70,000 BDT**, add a **10% bonus revenue** to their total.
4. Display each **product's name** along with its **category name** and a label "**Top Seller**" if its revenue is above the average revenue of its own category. Otherwise, display "**Regular Seller**".

### Solution
**sundarban.sql**

```sql
CREATE DATABASE IF NOT EXISTS sundarban;
USE sundarban;

CREATE TABLE sales_data (
    SaleID INT PRIMARY KEY,
    ProductName VARCHAR(100),
    CategoryID INT,
    CategoryName VARCHAR(100),
    Quantity INT,
    Revenue DECIMAL(12,2)
);

INSERT INTO sales_data (SaleID, ProductName, CategoryID, CategoryName, Quantity, Revenue) VALUES
(1, 'Laptop', 301, 'Electronics', 5,  350000),
(2, 'Mouse',  301, 'Electronics', 15,  45000),
(3, 'Chair',  302, 'Furniture',   8,   64000),
(4, 'Desk',   302, 'Furniture',   6,   72000),
(5, 'Bottle', 303, 'Accessories', 20,  30000),
(6, 'Pen',    303, 'Accessories', 25,  20000);
```

`DECIMAL(12,2)` keeps the 10% bonus exact.

#### The SQL for each task

```sql
-- 1) total revenue per category
SELECT CategoryID, CategoryName, SUM(Revenue) AS TotalRevenue
FROM sales_data
GROUP BY CategoryID, CategoryName;

-- 2) revenue below 40000 -> category "Low Performing"
UPDATE sales_data SET CategoryName = 'Low Performing' WHERE Revenue < 40000;

-- 3) revenue above 70000 -> +10%
UPDATE sales_data SET Revenue = Revenue * 1.10 WHERE Revenue > 70000;

-- 4) Top Seller if above the average of its own category (correlated subquery)
SELECT s.ProductName, s.CategoryName, s.Revenue,
       CASE
           WHEN s.Revenue > (SELECT AVG(s2.Revenue) FROM sales_data s2 WHERE s2.CategoryID = s.CategoryID)
           THEN 'Top Seller'
           ELSE 'Regular Seller'
       END AS Label
FROM sales_data s
ORDER BY s.SaleID;
```

- Task 2 changes the **CategoryName** only; the CategoryID (303) stays, so Bottle and Pen are still one category for task 4.
- Task 4: the inner `SELECT AVG(...)` runs **for each row**, using that row's CategoryID (`s2.CategoryID = s.CategoryID`). This is a **correlated subquery** (topic 16).
