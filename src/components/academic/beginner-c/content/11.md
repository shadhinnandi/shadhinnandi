## 1. Project 1: Number Guessing Game

A classic beginner project. The computer thinks of a random number, and the user has to guess it.

### Concepts Used
*   Variables (`int`)
*   Input/Output (`printf`, `scanf`)
*   Loops (`do-while` or `while`)
*   Conditionals (`if-else if-else`)
*   Random Number Generation (`rand()`, `srand()` from `<stdlib.h>`)

### How to Think Before Coding
1.  **Goal:** User guesses a number between 1 and 100.
2.  **Plan (Algorithm):**
    *   Generate a secret random number.
    *   Start a loop that continues as long as the user hasn't guessed correctly.
    *   Inside the loop:
        *   Ask the user for their guess.
        *   Read the guess.
        *   Compare the guess to the secret number.
        *   If the guess is too high, print "Too high!".
        *   If the guess is too low, print "Too low!".
        *   If the guess is correct, print "You got it!" and exit the loop.
    *   Keep track of the number of guesses.
    *   After the loop ends, print how many tries it took.

### Full Code (`guessing_game.c`)
```c
#include <stdio.h>
#include <stdlib.h> // For rand() and srand()
#include <time.h>   // For time()

int main() {
    int secretNumber, guess, num_guesses = 0;

    // Seed the random number generator with the current time
    // This ensures you get a different random number each time you run the program
    srand(time(0));

    // Generate a random number between 1 and 100
    secretNumber = (rand() % 100) + 1;

    printf("I have a secret number between 1 and 100.\n");
    printf("Can you guess what it is?\n");

    do {
        printf("Enter your guess: ");
        scanf("%d", &guess);
        num_guesses++;

        if (guess > secretNumber) {
            printf("Too high! Try again.\n");
        } else if (guess < secretNumber) {
            printf("Too low! Try again.\n");
        } else {
            printf("\nCongratulations! You guessed the number!\n");
            printf("It took you %d guesses.\n", num_guesses);
        }
    } while (guess != secretNumber);

    return 0;
}
```

## 2. Project 2: Simple ATM Interface

A command-line ATM that lets you check your balance, deposit money, and withdraw money.

### Concepts Used
*   Variables (`float` for balance)
*   Loops (`do-while` for the menu)
*   Conditionals (`switch` for menu choices, `if` for withdrawal check)
*   Functions (optional, but good for organizing code)

### How to Think Before Coding
1.  **Goal:** Simulate an ATM with check balance, deposit, and withdraw options.
2.  **Plan (Algorithm):**
    *   Initialize a starting balance (e.g., 1000.0).
    *   Start a `do-while` loop to show the menu repeatedly until the user chooses to exit.
    *   Inside the loop:
        *   Display the menu: 1. Check Balance, 2. Deposit, 3. Withdraw, 4. Exit.
        *   Ask for the user's choice.
        *   Use a `switch` statement to handle the choice.
        *   **Case 1:** Print the current balance.
        *   **Case 2:** Ask for the deposit amount, read it, and add it to the balance.
        *   **Case 3:** Ask for the withdrawal amount. Check if the amount is less than or equal to the balance. If yes, subtract it. If no, print an "Insufficient funds" error.
        *   **Case 4:** Print a "Thank you" message. The loop condition will handle the exit.
        *   **Default:** Print "Invalid choice."

### Full Code (`atm_interface.c`)
```c
#include <stdio.h>

void displayMenu() {
    printf("\n********** ATM MENU **********\n");
    printf("1. Check Balance\n");
    printf("2. Deposit\n");
    printf("3. Withdraw\n");
    printf("4. Exit\n");
    printf("******************************\n");
}

int main() {
    float balance = 1000.00;
    int choice;
    float amount;

    do {
        displayMenu();
        printf("Enter your choice: ");
        scanf("%d", &choice);

        switch (choice) {
            case 1:
                printf("\nYour current balance is: $%.2f\n", balance);
                break;
            case 2:
                printf("\nEnter amount to deposit: ");
                scanf("%f", &amount);
                if (amount > 0) {
                    balance += amount;
                    printf("Successfully deposited $%.2f\n", amount);
                } else {
                    printf("Invalid deposit amount.\n");
                }
                break;
            case 3:
                printf("\nEnter amount to withdraw: ");
                scanf("%f", &amount);
                if (amount > 0 && amount <= balance) {
                    balance -= amount;
                    printf("Successfully withdrew $%.2f\n", amount);
                } else if (amount > balance) {
                    printf("Insufficient funds.\n");
                } else {
                    printf("Invalid withdrawal amount.\n");
                }
                break;
            case 4:
                printf("\nThank you for using the ATM. Goodbye!\n");
                break;
            default:
                printf("\nInvalid choice. Please try again.\n");
        }

    } while (choice != 4);

    return 0;
}
```

## 3. Project 3: Rock, Paper, Scissors Game

Play the classic game against the computer.

### Concepts Used
*   Random Number Generation (`rand()`)
*   Conditionals (`if-else if-else`)
*   Loops (`while` or `do-while` to play again)
*   `switch` statement

### How to Think Before Coding
1.  **Goal:** User plays Rock, Paper, Scissors against a computer opponent.
2.  **Plan (Algorithm):**
    *   Start a loop to allow playing multiple rounds.
    *   Inside the loop:
        *   Ask the user for their choice (1=Rock, 2=Paper, 3=Scissors).
        *   Generate a random choice for the computer (1, 2, or 3).
        *   Display what the user and computer chose.
        *   Use a series of `if-else` statements to determine the winner based on the rules:
            *   Rock crushes Scissors
            *   Scissors cuts Paper
            *   Paper covers Rock
        *   Handle the case of a tie.
        *   Print the result (You Win, You Lose, or It's a Tie).
    *   Ask the user if they want to play again. If not, exit the loop.

### Full Code (`rock_paper_scissors.c`)
```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
    int playerChoice, computerChoice;
    char playAgain;

    srand(time(0));

    do {
        printf("\nChoose your weapon:\n");
        printf("1. Rock\n2. Paper\n3. Scissors\n");
        printf("Enter your choice (1-3): ");
        scanf("%d", &playerChoice);

        // Generate computer's choice (1-3)
        computerChoice = (rand() % 3) + 1;

        printf("You chose: ");
        switch(playerChoice) {
            case 1: printf("Rock\n"); break;
            case 2: printf("Paper\n"); break;
            case 3: printf("Scissors\n"); break;
        }

        printf("Computer chose: ");
        switch(computerChoice) {
            case 1: printf("Rock\n"); break;
            case 2: printf("Paper\n"); break;
            case 3: printf("Scissors\n"); break;
        }

        // Determine the winner
        if (playerChoice == computerChoice) {
            printf("It's a tie!\n");
        } else if ((playerChoice == 1 && computerChoice == 3) ||
                   (playerChoice == 2 && computerChoice == 1) ||
                   (playerChoice == 3 && computerChoice == 2)) {
            printf("You win!\n");
        } else {
            printf("You lose!\n");
        }

        printf("\nPlay again? (y/n): ");
        scanf(" %c", &playAgain);

    } while (playAgain == 'y' || playAgain == 'Y');

    printf("Thanks for playing!\n");
    return 0;
}
```

### 🟡 More Intermediate Projects

**7. Simple Library Management System**
*   **Description:** Create a system to manage a collection of books. Users should be able to add a new book, search for a book by title or author, display all books, and check out/in a book.
*   **Concepts Used:** Structs (to hold book info like title, author, id, is_checked_out), Arrays of Structs, String manipulation, Functions, File I/O (to save the library state).
*   **Plan:**
    1.  Define a `struct Book` with fields for title, author, and status.
    2.  Create a global array of `struct Book`.
    3.  Implement a main menu loop (add, search, display, check out/in, exit).
    4.  `addBook()`: Prompts for book details and adds it to the array.
    5.  `searchBook()`: Prompts for a title/author and loops through the array to find matches.
    6.  `displayAllBooks()`: Loops through the array and prints details of each book.
    7.  `checkOutIn()`: Toggles the status of a book.
    8.  (Advanced) Use `fopen()`, `fprintf()`, `fscanf()`, `fclose()` to save the book list to a file and load it on startup.

**8. Digital Clock**
*   **Description:** Display the current system time, updating it every second, right in the console.
*   **Concepts Used:** `time.h` library (`time()`, `localtime()`), Structs (`struct tm`), Loops (`while(1)`), System calls (`sleep()` or `_sleep()`).
*   **Plan:**
    1.  Include `<time.h>` and `<unistd.h>` (for `sleep` on Linux) or `<windows.h>` (for `Sleep` on Windows).
    2.  Create an infinite `while(1)` loop.
    3.  Inside the loop:
        *   Get the current time using `time()`.
        *   Convert it to a local time structure using `localtime()`.
        *   Clear the console screen (`system("clear")` or `system("cls")`).
        *   Print the formatted time (e.g., `HH:MM:SS`).
        *   Use `sleep(1)` to pause the program for one second.

**9. Quiz Game**
*   **Description:** A simple quiz with multiple-choice questions. The game should ask a series of questions, track the player's score, and display the final score at the end.
*   **Concepts Used:** Structs (to hold a question, options, and correct answer), Arrays of Structs, Functions, User Input.
*   **Plan:**
    1.  Define a `struct Question` with fields: `char* question_text`, `char* options[4]`, `int correct_option`.
    2.  Create an array of `struct Question` and initialize it with 5-10 questions.
    3.  Initialize `score = 0`.
    4.  Loop through the array of questions.
    5.  For each question:
        *   Display the question and the four options.
        *   Prompt the user for their answer (1-4).
        *   Check if the user's answer matches `correct_option`.
        *   If correct, increment the score and print "Correct!".
        *   If incorrect, print "Wrong! The correct answer was...".
    6.  After the loop, display the final score: "You got X out of Y correct."

**10. Snake Game (Console)**
*   **Description:** The classic arcade game where the player controls a snake that grows by eating "food". The game ends if the snake hits the wall or itself.
*   **Concepts Used:** 2D Arrays (for the game board), Structs (for snake segments), `conio.h` or equivalent for non-blocking keyboard input, Random number generation, Game loop logic.
*   **Plan:**
    1.  Set up a 2D char array for the game grid.
    2.  Represent the snake as an array of `struct Point {int x, int y;}`.
    3.  Randomly place food on the grid.
    4.  Start a game loop that:
        *   Clears the screen.
        *   Draws the grid, snake, and food.
        *   Checks for keyboard input to change the snake's direction.
        *   Moves the snake one step in the current direction.
        *   Checks for collisions (wall or self).
        *   Checks if food is eaten. If so, increase score, grow the snake, and place new food.
        *   Controls game speed with `sleep()`.

**11. Simple File Encryptor/Decryptor**
*   **Description:** A program that encrypts a text file using a simple Caesar cipher (shifting each letter by a fixed number of positions) and can decrypt it back.
*   **Concepts Used:** File I/O (`fgetc`, `fputc`), Command-line arguments (`argc`, `argv`), Functions.
*   **Plan:**
    1.  The program should run from the command line, e.g., `./cipher encrypt input.txt output.txt 5` (key is 5).
    2.  Open the input and output files.
    3.  Read the input file character by character in a loop until `EOF`.
    4.  For encryption, add the key to the character (`new_char = old_char + key`).
    5.  For decryption, subtract the key (`new_char = old_char - key`).
    6.  Write the new character to the output file.
    7.  Close both files.

**12. Calendar Application (Console)**
*   **Description:** A program that displays the calendar for a given month and year.
*   **Concepts Used:** Date/time logic, Loops, Functions to calculate the day of the week.
*   **Plan:**
    1.  Ask the user for the month and year.
    2.  Create a function `int getStartDay(int year, int month)` that returns the starting day of the week (0 for Sunday, 1 for Monday, etc.) for that month. This is the hardest part and involves algorithms like Zeller's congruence.
    3.  Create a function `int getDaysInMonth(...)`.
    4.  Print the calendar header ("Sun Mon Tue...").
    5.  Print leading spaces for the first day.
    6.  Loop from 1 to the number of days in the month, printing each day and adding a newline after every Saturday.

**13. Personal Diary Management System**
*   **Description:** A command-line diary where a user can add a new entry for the current date, view past entries, and search entries.
*   **Concepts Used:** File I/O (appending and reading), `time.h` library, String manipulation.
*   **Plan:**
    1.  Entries are stored in a file like `diary.txt`.
    2.  **Add Entry:**
        *   Get the current date and time.
        *   Open `diary.txt` in append mode (`"a"`).

    3.  **View Entries:** Open `diary.txt` in read mode (`"r"`) and print its entire content.

**14. Typing Speed Tester**
*   **Description:** A program that measures a user's typing speed in words per minute (WPM).
*   **Concepts Used:** `time.h` library (`time_t`), String comparison, User input.
*   **Plan:**
    1.  Have a predefined sentence or paragraph stored in a string.
    2.  Display the sentence to the user.
    3.  Record the start time using `time(NULL)`.
    4.  Prompt the user to type the sentence.
    5.  Once the user hits Enter, record the end time.
    6.  Calculate the total time taken in seconds.
    7.  Compare the user's input with the original sentence to count correct characters/words.
    8.  Calculate WPM: `(Number of words typed / time in minutes)`. A "word" is often standardized to 5 characters. WPM = `(characters typed / 5) / (seconds / 60)`.
    9.  Display the WPM and accuracy.
