# Chapter 04: Operators

Operators are the symbols that tell the compiler to perform specific mathematical or logical manipulations. They are the building blocks of expressions in C. Think of them as the verbs of the programming world.

## 1. Concept Explanation

### What are Operators?

**Simple Explanation:**
Operators are simply symbols like `+` (add), `-` (subtract), `*` (multiply), and `/` (divide). They take one or more values (operands) and produce a result.

**Real-life Analogy:**
In the math equation `5 + 3 = 8`, `5` and `3` are the operands, and `+` is the operator. The whole thing (`5 + 3`) is called an expression.

**Technical Explanation:**
An operator is a symbol that operates on a value or a variable. For example: `+` is an operator to perform addition. C has a wide range of operators, which can be classified into several types.

### Main Types of Operators

1.  **Arithmetic Operators:** For performing mathematical calculations.
2.  **Relational Operators:** For comparing two values.
3.  **Logical Operators:** For combining two or more conditions.
4.  **Assignment Operators:** For assigning values to variables.
5.  **Increment/Decrement Operators:** For increasing or decreasing a value by 1.

## 2. Syntax Section

### 1. Arithmetic Operators

| Operator | Meaning      | Example     | Result (if x=10, y=3) |
| :------- | :----------- | :---------- | :-------------------- |
| `+`      | Addition     | `x + y`     | 13                    |
| `-`      | Subtraction  | `x - y`     | 7                     |
| `*`      | Multiplication| `x * y`     | 30                    |
| `/`      | Division     | `x / y`     | 3 (integer division)  |
| `%`      | Modulus      | `x % y`     | 1 (remainder of 10/3) |

**Important Note on Division:**
*   If both operands are integers, C performs *integer division* (the fractional part is discarded). `10 / 3` is `3`.
*   If at least one operand is a float, it performs *floating-point division*. `10.0 / 3` is `3.333333`.

### 2. Relational Operators

These operators are used in decision-making and always result in either `1` (true) or `0` (false).

| Operator | Meaning                | Example   | Result (if a=5, b=10) |
| :------- | :--------------------- | :-------- | :-------------------- |
| `==`     | Equal to               | `a == b`  | 0 (false)             |
| `!=`     | Not equal to           | `a != b`  | 1 (true)              |
| `>`      | Greater than           | `a > b`   | 0 (false)             |
| `<`      | Less than              | `a < b`   | 1 (true)              |
| `>=`     | Greater than or equal to| `a >= 5`  | 1 (true)              |
| `<=`     | Less than or equal to  | `b <= 5`  | 0 (false)             |

**Common Mistake:** Using `=` (assignment) instead of `==` (comparison) is a very common and hard-to-find bug!

### 3. Logical Operators

| Operator | Meaning | Description                                   |
| :------- | :------ | :-------------------------------------------- |
| `&&`     | AND     | Returns `1` if **both** conditions are true.  |
| `||`     | OR      | Returns `1` if **at least one** condition is true. |
| `!`      | NOT     | Reverses the state. `!true` is `false`.       |

### 4. Assignment Operators

| Operator | Equivalent to | Example |
| :------- | :------------ | :------ |
| `=`      | `a = b`       | `a = b` |
| `+=`     | `a = a + b`   | `a += b`|
| `-=`     | `a = a - b`   | `a -= b`|
| `*=`     | `a = a * b`   | `a *= b`|
| `/=`     | `a = a / b`   | `a /= b`|

### 5. Increment/Decrement Operators

*   `++`: Increases the value of a variable by 1.
*   `--`: Decreases the value of a variable by 1.

`x++` is equivalent to `x = x + 1`.
`x--` is equivalent to `x = x - 1`.

## 3. Code Examples

### Example 1: Arithmetic Operators
`arithmetic.c`
```c
#include <stdio.h>

int main() {
    int a = 20, b = 5;

    printf("Addition: %d\n", a + b);       // 25
    printf("Subtraction: %d\n", a - b);    // 15
    printf("Multiplication: %d\n", a * b); // 100
    printf("Division: %d\n", a / b);       // 4
    printf("Modulus: %d\n", a % b);        // 0

    return 0;
}
```

### Example 2: Relational and Logical Operators
`relational_logical.c`
```c
#include <stdio.h>

int main() {
    int age = 25;
    int has_license = 1; // 1 for true, 0 for false

    // You can drive if you are 18 or older AND you have a license
    printf("Can drive? (0 for No, 1 for Yes): %d\n", (age >= 18 && has_license == 1));

    int has_degree = 0;
    int has_experience = 1;

    // You are eligible for a job if you have a degree OR experience
    printf("Eligible for job? %d\n", (has_degree == 1 || has_experience == 1));

    return 0;
}
```

### Example 3: Increment and Assignment
`increment_assignment.c`
```c
#include <stdio.h>

int main() {
    int score = 100;

    // Player gained 50 points
    score += 50; // score is now 150
    printf("New score: %d\n", score);

    int lives = 3;
    // Player lost a life
    lives--; // lives is now 2
    printf("Lives remaining: %d\n", lives);

    return 0;
}
```

**Problem 13: Pre-increment vs Post-increment**
*   **Statement:** Explain the difference between `++x` (pre-increment) and `x++` (post-increment). Write a small program to demonstrate this.
*   **Hint:** The difference appears when you use them inside another expression, like `y = x++`.
*   **Solution & Explanation:**
    ```c
    #include <stdio.h>
    int main() {
        int x = 10;
        int y;

        // Post-increment: x++
        // 1. The original value of x (10) is assigned to y.
        // 2. Then, x is incremented to 11.
        y = x++;
        printf("Post-increment:\n");
        printf("y = %d, x = %d\n\n", y, x); // y will be 10, x will be 11

        // Reset x for the next example
        x = 10;

        // Pre-increment: ++x
        // 1. x is incremented to 11 first.
        // 2. Then, the new value of x (11) is assigned to y.
        y = ++x;
        printf("Pre-increment:\n");
        printf("y = %d, x = %d\n", y, x); // y will be 11, x will be 11

        return 0;
    }
    ```
