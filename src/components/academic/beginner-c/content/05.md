# Chapter 05: Conditional Statements

What if we want our program to make decisions? For example, if a user's age is over 18, print "You can vote," otherwise, print "You cannot vote." This is where conditional statements come in. They allow our program to execute certain blocks of code only if a specific condition is true.

## 1. Concept Explanation

### What are Conditional Statements?

**Simple Explanation:**
Conditional statements are like forks in the road for your program. Based on a question (a condition), the program will choose to go down one path or another. The most common questions are "if" questions. "If this is true, do this. Otherwise, do that."

**Real-life Analogy:**
Imagine you're getting dressed. **If** it's raining outside, you'll take an umbrella. **Otherwise (else)**, you'll take sunglasses. You are making a decision based on a condition (the weather).

**Technical Explanation:**
Conditional statements (or selection statements) allow a program to execute different blocks of code depending on whether a certain condition evaluates to true (any non-zero value) or false (0). The primary conditional statements in C are `if`, `if-else`, `if-else if-else`, and `switch`.

## 2. Syntax Section

### 1. The `if` Statement

Executes a block of code only if the condition is true.

**Syntax:**
```c
if (condition) {
    // Code to execute if condition is true
}
```
*   `condition`: An expression that results in `true` (1) or `false` (0). Usually involves relational operators (`==`, `>`, `<`, etc.).

### 2. The `if-else` Statement

Executes one block of code if the condition is true, and a different block if it's false.

**Syntax:**
```c
if (condition) {
    // Code to execute if condition is true
} else {
    // Code to execute if condition is false
}
```

### 3. The `if-else if-else` Ladder

Used to decide among several alternatives.

**Syntax:**
```c
if (condition1) {
    // Code for condition1
} else if (condition2) {
    // Code for condition2
} else if (condition3) {
    // Code for condition3
} else {
    // Code if none of the above are true
}
```
The conditions are checked from top to bottom. As soon as a true condition is found, its block is executed, and the rest of the ladder is skipped.

### 4. The `switch` Statement

A special type of multi-way decision statement. It's useful when you want to check a single variable against a list of possible constant values.

**Syntax:**
```c
switch (variable_or_expression) {
    case value1:
        // Code for value1
        break; // 'break' is very important!
    case value2:
        // Code for value2
        break;
    default:
        // Code if no case matches
        break;
}
```
*   `break`: This keyword exits the `switch` block. If you forget it, the program will "fall through" and execute the code for the next case as well!
*   `default`: This is optional and runs if none of the other cases match.

## 3. Code Examples

### Example 1: `if-else` (Voting Age)
`voting.c`
```c
#include <stdio.h>

int main() {
    int age;
    printf("Enter your age: ");
    scanf("%d", &age);

    if (age >= 18) {
        printf("You are eligible to vote.\n");
    } else {
        printf("You are not eligible to vote yet.\n");
    }

    return 0;
}
```

### Example 2: `if-else if-else` (Grading System)
`grading.c`
```c
#include <stdio.h>

int main() {
    int score;
    printf("Enter your test score (0-100): ");
    scanf("%d", &score);

    if (score >= 90) {
        printf("Grade: A\n");
    } else if (score >= 80) {
        printf("Grade: B\n");
    } else if (score >= 70) {
        printf("Grade: C\n");
    } else if (score >= 60) {
        printf("Grade: D\n");
    } else {
        printf("Grade: F (Fail)\n");
    }

    return 0;
}
```

### Example 3: `switch` (Day of the Week)
`weekday.c`
```c
#include <stdio.h>

int main() {
    int day;
    printf("Enter day number (1-7): ");
    scanf("%d", &day);

    switch (day) {
        case 1:
            printf("Sunday\n");
            break;
        case 2:
            printf("Monday\n");
            break;
        case 3:
            printf("Tuesday\n");
            break;
        case 4:
            printf("Wednesday\n");
            break;
        case 5:
            printf("Thursday\n");
            break;
        case 6:
            printf("Friday\n");
            break;
        case 7:
            printf("Saturday\n");
            break;
        default:
            printf("Invalid day number.\n");
            break;
    }

    return 0;
}
```

**Problem 6: Leap Year**
*   **Statement:** A year is a leap year if it is divisible by 4, except for end-of-century years, which must be divisible by 400. Ask for a year and print if it's a "Leap Year" or "Not a Leap Year".
*   **Logic:** A year is a leap year if `(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int year;
        printf("Enter a year: ");
        scanf("%d", &year);
        if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
            printf("Leap Year\n");
        } else {
            printf("Not a Leap Year\n");
        }
        return 0;
    }
    ```

**Problem 8: Simple Calculator**
*   **Statement:** Ask the user for two numbers and an operator (`+`, `-`, `*`, `/`). Perform the calculation and print the result. Use a `switch` statement for the operator.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        char op;
        float n1, n2;
        printf("Enter an operator (+, -, *, /): ");
        scanf(" %c", &op);
        printf("Enter two numbers: ");
        scanf("%f %f", &n1, &n2);

        switch (op) {
            case '+':
                printf("%.1f + %.1f = %.1f\n", n1, n2, n1 + n2);
                break;
            case '-':
                printf("%.1f - %.1f = %.1f\n", n1, n2, n1 - n2);
                break;
            case '*':
                printf("%.1f * %.1f = %.1f\n", n1, n2, n1 * n2);
                break;
            case '/':
                if (n2 != 0) {
                    printf("%.1f / %.1f = %.1f\n", n1, n2, n1 / n2);
                } else {
                    printf("Error! Division by zero.\n");
                }
                break;
            default:
                printf("Error! Operator is not correct.\n");
        }
        return 0;
    }
    ```
*   **Explanation:** We use `%.1f` to show the floating-point numbers with only one digit after the decimal. We also check for division by zero, which is an invalid operation.

**Problem 12: Electricity Bill**
*   **Statement:** Calculate an electricity bill.
    *   For the first 50 units, the rate is $0.50/unit.
    *   For the next 100 units, the rate is $0.75/unit.
    *   For the next 100 units, the rate is $1.20/unit.
    *   For units above 250, the rate is $1.50/unit.
    *   An additional surcharge of 20% is added to the final bill.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        float units, bill;
        printf("Enter total units consumed: ");
        scanf("%f", &units);

        if (units <= 50) {
            bill = units * 0.50;
        } else if (units <= 150) {
            bill = (50 * 0.50) + ((units - 50) * 0.75);
        } else if (units <= 250) {
            bill = (50 * 0.50) + (100 * 0.75) + ((units - 150) * 1.20);
        } else {
            bill = (50 * 0.50) + (100 * 0.75) + (100 * 1.20) + ((units - 250) * 1.50);
        }

        bill = bill * 1.20; // Add 20% surcharge

        printf("Total electricity bill: $%.2f\n", bill);
        return 0;
    }
    ```
