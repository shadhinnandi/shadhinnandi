# Chapter 08: Functions

As our programs get bigger, putting all the code inside the `main()` function becomes messy and hard to manage. Functions are the solution! They let us break our code into smaller, reusable pieces.

## 1. Concept Explanation

### What is a Function?

**Simple Explanation:**
A function is like a mini-program within your main program. You give it a name, and it performs a specific task. You can "call" this function by its name whenever you need that task done, instead of rewriting the code for it every time.

**Real-life Analogy:**
Think about making a sandwich. The steps are "get bread," "add filling," "put slices together." You could write these steps down every time you want a sandwich. Or, you could create a "function" called `makeSandwich()`. Now, whenever you're hungry, you just think `makeSandwich()`, and you know exactly what steps to perform. You can even customize it by passing in the filling you want, like `makeSandwich("cheese")`.

**Technical Explanation:**
A function is a self-contained block of statements that performs a specific task. Every C program has at least one function, which is `main()`. Functions can take inputs (called parameters or arguments) and can return a value to the part of the code that called it.

### Why Use Functions?

*   **Reusability:** Write once, use many times.
*   **Organization:** Breaks a large program into smaller, manageable parts.
*   **Readability:** Well-named functions make code easier to understand.
*   **Debugging:** It's easier to find and fix a bug in a small function than in a giant `main()` function.

## 2. Syntax Section

A function has three parts:

1.  **Function Declaration (or Prototype):** Tells the compiler about the function's name, return type, and parameters. It's like a forward declaration.
2.  **Function Definition:** This is where the actual code for the function is written.
3.  **Function Call:** This is how you execute the function.

**General Syntax:**

```c
// 1. Function Declaration (usually at the top, after #include)
return_type function_name(parameter_type1, parameter_type2);

int main() {
    // ...
    // 3. Function Call
    variable = function_name(argument1, argument2);
    // ...
}

// 2. Function Definition (usually after main)
return_type function_name(parameter_type1 parameter_name1, parameter_type2 parameter_name2) {
    // Code to perform the task
    return value; // The value must match the return_type
}
```

*   **`return_type`**: The data type of the value the function will send back (e.g., `int`, `float`). If the function doesn't return anything, use `void`.
*   **`function_name`**: A descriptive name for the function.
*   **`parameters`**: The inputs the function needs. These are variables declared inside the parentheses.
*   **`arguments`**: The actual values you pass to the function when you call it.

## 3. Code Examples

### Example 1: A Simple Greeting Function (No Parameters, No Return)
`greet.c`
```c
#include <stdio.h>

// 1. Function Declaration
void greet();

int main() {
    printf("In main, before calling greet.\n");
    // 3. Function Call
    greet();
    printf("In main, after calling greet.\n");
    return 0;
}

// 2. Function Definition
void greet() {
    printf("Hello! Welcome to the world of functions.\n");
}
```

### Example 2: Function to Add Two Numbers (With Parameters and Return)
`add_function.c`
```c
#include <stdio.h>

// Declaration
int add(int a, int b);

int main() {
    int num1 = 10, num2 = 20;
    int result;

    // Call the function and store its return value
    result = add(num1, num2);

    printf("The sum is: %d\n", result);
    return 0;
}

// Definition
int add(int a, int b) {
    int sum = a + b;
    return sum; // Return the calculated sum
}
```

### Example 3: Function to Find the Maximum of Two Numbers
`find_max.c`
```c
#include <stdio.h>

int findMax(int x, int y); // Declaration

int main() {
    int n1, n2;
    printf("Enter two numbers: ");
    scanf("%d %d", &n1, &n2);

    int max = findMax(n1, n2); // Call

    printf("The maximum number is: %d\n", max);
    return 0;
}

int findMax(int x, int y) { // Definition
    if (x > y) {
        return x;
    } else {
        return y;
    }
}
```

**Problem 6: Prime Number Function**
*   **Statement:** Create a function `isPrime()` that takes an integer and returns `1` if it's prime, and `0` otherwise.
*   **Solution:**

**Problem 9: Reverse Number Function**
*   **Statement:** Create a function `reverseNumber()` that takes an integer and returns its reverse.
*   **Solution:**
    ```c
    #include <stdio.h>
    int reverseNumber(int n) {
        int reversed = 0, remainder;
        while (n != 0) {
            remainder = n % 10;
            reversed = reversed * 10 + remainder;
            n /= 10;
        }
        return reversed;
    }
    int main() {
        int num = 12345;
        printf("Reverse of %d is %d\n", num, reverseNumber(num));
        return 0;
    }
    ```

**Problem 10: GCD Function**
*   **Statement:** Create a function `findGCD()` that takes two integers and returns their Greatest Common Divisor.
*   **Solution:**
    ```c
    #include <stdio.h>
    int findGCD(int n1, int n2) {
        int gcd;
        for (int i = 1; i <= n1 && i <= n2; ++i) {
            if (n1 % i == 0 && n2 % i == 0)
                gcd = i;
        }
        return gcd;
    }
    int main() {
        printf("GCD of 54 and 24 is %d\n", findGCD(54, 24));
        return 0;
    }
    ```

**Problem 13: Swap two numbers using pointers**
*   **Statement:** Create a `void` function `swap()` that takes the *addresses* of two integer variables and swaps their values. This is called "pass-by-reference".
*   **Solution:**
    ```c
    #include <stdio.h>
    void swap(int *a, int *b) {
        int temp = *a;
        *a = *b;
        *b = temp;
    }
    int main() {
        int x = 10, y = 20;
        printf("Before swap: x=%d, y=%d\n", x, y);
        swap(&x, &y); // Pass the addresses of x and y
        printf("After swap: x=%d, y=%d\n", x, y);
        return 0;
    }
    ```

**Problem 14: Recursive Factorial**
*   **Statement:** A function that calls itself is recursive. Write a recursive function to find the factorial of a number. The base case is `factorial(0) = 1`.
*   **Solution:**
    ```c
    #include <stdio.h>
    long long recursiveFactorial(int n) {
        if (n >= 1)
            return n * recursiveFactorial(n - 1);
        else
            return 1; // Base case
    }
    int main() {
        printf("Factorial of 6 is %lld\n", recursiveFactorial(6));
        return 0;
    }
    ```

**Problem 15: Recursive Fibonacci**
*   **Statement:** Write a recursive function to find the Nth term of the Fibonacci sequence.
*   **Solution:**
    ```c
    #include <stdio.h>
    int fibonacci(int n) {
        if (n <= 1)
            return n;
        return fibonacci(n - 1) + fibonacci(n - 2);
    }
    int main() {
        int N = 9; // Find the 9th term
        printf("The %dth term of Fibonacci is %d\n", N, fibonacci(N));
        return 0;
    }
    ```
*   **Note:** Recursive Fibonacci is very inefficient for large numbers but is a classic example of recursion.

**Problem 16: Temperature Converter Function**
*   **Statement:** Write a function `convertTemp()` that takes a float temperature and a character `target` ('C' or 'F'). If `target` is 'C', it assumes the input temperature is Fahrenheit and converts it to Celsius. If `target` is 'F', it assumes Celsius and converts to Fahrenheit.
*   **Formulas:** `C = (F - 32) * 5/9` and `F = (C * 9/5) + 32`.
*   **Solution:**
    ```c
    #include <stdio.h>
    float convertTemp(float temp, char target) {
        if (target == 'C' || target == 'c') {
            return (temp - 32) * 5.0 / 9.0;
        } else if (target == 'F' || target == 'f') {
            return (temp * 9.0 / 5.0) + 32;
        }
        return temp; // Return original temp if target is invalid
    }
    int main() {
        printf("98.6F is %.2fC\n", convertTemp(98.6, 'C'));
        printf("37C is %.2fF\n", convertTemp(37.0, 'F'));
        return 0;
    }
    ```

**Problem 18: Armstrong Number Function**
*   **Statement:** Create a function `isArmstrong()` that takes an integer and returns `1` if it's an Armstrong number, `0` otherwise.
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <math.h>
    int isArmstrong(int num) {
        int originalNum, remainder, n = 0, result = 0;
        originalNum = num;

        // count number of digits
        while (originalNum != 0) {
            originalNum /= 10;
            ++n;
        }

        originalNum = num;

        // calculate sum of powers of digits
        while (originalNum != 0) {
            remainder = originalNum % 10;
            result += pow(remainder, n);
            originalNum /= 10;
        }

        return result == num;
    }
    int main() {
        int num = 153;
        if (isArmstrong(num)) {
            printf("%d is an Armstrong number.\n", num);
        } else {
            printf("%d is not an Armstrong number.\n", num);
        }
        return 0;
    }
    ```

**Problem 19: Perfect Number Function**
*   **Statement:** Create a function `isPerfect()` that takes an integer and returns `1` if it's a perfect number, `0` otherwise.
*   **Solution:**
    ```c
    #include <stdio.h>
    int isPerfect(int num) {
        int sum = 0;
        for (int i = 1; i <= num / 2; i++) {
            if (num % i == 0) {
                sum += i;
            }
        }
        return sum == num && num > 0;
    }
    int main() {
        int num = 28;
        if (isPerfect(num)) {
            printf("%d is a perfect number.\n", num);
        } else {
            printf("%d is not a perfect number.\n", num);
        }
        return 0;
    }
    ```

**Problem 20: Recursive Sum of Digits**
*   **Statement:** Write a recursive function `sumOfDigits()` to find the sum of digits of a number.
*   **Hint:** The sum of digits of `123` is `3 + sumOfDigits(12)`. The base case is when the number is 0.
*   **Solution:**
    ```c
    #include <stdio.h>
    int sumOfDigits(int n) {
        if (n == 0) {
            return 0; // Base case
        }
        return (n % 10) + sumOfDigits(n / 10);
    }
    int main() {
        int num = 12345;
        printf("Sum of digits of %d is %d\n", num, sumOfDigits(num));
        return 0;
    }
    ```
