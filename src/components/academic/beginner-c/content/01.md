# Chapter 01: C Basics & Your First Program

Let's get our hands dirty and write some real code! This chapter covers the absolute basics of the C language and guides you through writing, compiling, and running your first program.

## 1. Concept Explanation

### What is a C Program?

**Simple Explanation:**
A C program is a plain text file, just like a `.txt` file, but it's saved with a `.c` extension. This file contains instructions written in the C language that tell the computer what to do.

**Technical Explanation:**
A C program is composed of preprocessor commands, a `main()` function, and other user-defined functions. The `main()` function is the entry point of every C program, where the execution begins.

### What is a Compiler?

**Simple Explanation:**
Remember our dumb robot? It doesn't understand English (or C). It only understands "machine code" (1s and 0s). A compiler is a special program that acts as a translator. It takes your C code (`.c` file) and translates it into machine code (`.exe` or an executable file) that the computer can understand and run.

**Technical Explanation:**
A compiler is a computer program that translates source code written in a high-level language (like C) into a lower-level language (like machine code) to create an executable program.

**Flowchart: From Code to Output**
```
[You write C Code (hello.c)]
         |
         v
[Compiler translates the code]
         |
         v
[Executable File is created (hello.exe)]
         |
         v
[You run the executable]
         |
         v
[Computer shows the output]
```

## 2. Syntax Section: "Hello, World!"

This is the traditional first program for any new programmer. It's a simple program that just prints the text "Hello, World!" on the screen.

### The Code (`hello.c`)
```c
#include <stdio.h>

int main() {
    // This line prints the text to the screen
    printf("Hello, World!");

    return 0;
}
```

### Syntax Explained Line-by-Line

*   `#include <stdio.h>`
    *   `#include`: This is a "preprocessor directive." It tells the compiler to include a file before actually compiling.
    *   `<stdio.h>`: This is the "Standard Input/Output" library. It contains pre-written code for input/output functions, like `printf()`. We need it to print text.

*   `int main() { ... }`
    *   `main()`: This is the most important function in any C program. The program execution starts here.
    *   `int`: This is the "return type." It means the `main` function will return an integer (a whole number) when it's done.
    *   `{ ... }`: These curly braces define the beginning and end of the `main` function. All our code will go inside these.

*   `printf("Hello, World!");`
    *   `printf()`: This is a function from the `stdio.h` library that "prints formatted" text to the screen.
    *   `"Hello, World!"`: This is the "string" or text that we want to print. It must be inside double quotes.
    *   `;`: The semicolon is a statement terminator. Every statement in C must end with a semicolon. It's like a period at the end of a sentence.

*   `return 0;`
    *   `return`: This keyword exits the function.
    *   `0`: We return the value `0` to the operating system. A return value of `0` means the program ran successfully without any errors.

## 3. Code Examples

Here are a few more examples to play with.

### Example 1: Printing Your Name
`my_name.c`
```c
#include <stdio.h>

int main() {
    printf("My name is Alex.");
    return 0;
}
```
**Output:**
```
My name is Alex.
```

### Example 2: Printing Multiple Lines
`multiple_lines.c`
```c
#include <stdio.h>

int main() {
    printf("This is the first line.\n");
    printf("This is the second line.");
    return 0;
}
```
**Output:**
```
This is the first line.
This is the second line.
```
**Explanation:** The `\n` is a special "escape sequence" that means "new line." It moves the cursor to the next line before printing anything else.

### Example 3: A Simple ASCII Art
`ascii_art.c`
```c
#include <stdio.h>

int main() {
    printf("   /\\_/\\   \n");
    printf("  ( o.o )  \n");
    printf("   > ^ <   \n");
    return 0;
}
```
**Output:**
```
   / \_ / \
  ( o.o )
   > ^ <
```

### 🟢 Basic Problems

**Problem 1: Your Country**
*   **Statement:** Write a C program to print the name of your country.
*   **Input/Output:** No input. Output should be your country's name.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        printf("My country is [Your Country Name].");
        return 0;
    }
    ```
*   **Explanation:** This is a simple use of the `printf` function to display a static string.

**Problem 2: Your Favorite Quote**
*   **Statement:** Write a C program to print your favorite quote.
*   **Input/Output:** No input. Output should be the quote.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        printf("\"The only way to do great work is to love what you do.\" - Steve Jobs");
        return 0;
    }
    ```
*   **Explanation:** The `\"` is used to print a double-quote character, as it has a special meaning in C.

**Problem 3: Two Sentences**
*   **Statement:** Write a program that prints two sentences on two different lines.
*   **Input/Output:** No input.
    ```
    Hello everyone.
    Welcome to C programming.
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        printf("Hello everyone.\n");
        printf("Welcome to C programming.");
        return 0;
    }
    ```
*   **Explanation:** The `\n` newline character is used to move to the next line after the first sentence.

**Problem 4: Simple Bio**
*   **Statement:** Write a program to print your name, age, and city on separate lines.
*   **Input/Output:** No input.
    ```
    Name: John
    Age: 25
    City: New York
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        printf("Name: John\n");
        printf("Age: 25\n");
        printf("City: New York");
        return 0;
    }
    ```
*   **Explanation:** Use `\n` after each line to format the output correctly.

**Problem 5: A Star Pattern**
*   **Statement:** Write a program to print a small triangle made of stars.
*   **Input/Output:** No input.
    ```
      *
     ***
    *****
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        printf("  *\n");
        printf(" ***\n");
        printf("*****");
        return 0;
    }
    ```
*   **Explanation:** This problem demonstrates how `printf` can be used to create simple visual patterns.

### 🔴 Advanced "printf" and Escape Sequences

**Problem 11: Using Tabs**
*   **Statement:** Display a list of items and their prices, aligned using the tab character `\t`.
*   **Output:**
    ```
    Item            Price
    ----            -----
    Apple           $1.00
    Bread           $2.50
    Milk            $3.00
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        printf("Item\t\tPrice\n");
        printf("----\t\t-----\n");
        printf("Apple\t\t$1.00\n");
        printf("Bread\t\t$2.50\n");
        printf("Milk\t\t$3.00\n");
        return 0;
    }
    ```

**Problem 12: Printing File Paths**
*   **Statement:** Print a Windows-style file path that contains backslashes.
*   **Hint:** You need to "escape" the backslash character.
*   **Output:**
    ```
    The file is located at C:\Users\John\Documents\file.txt
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        printf("The file is located at C:\\Users\\John\\Documents\\file.txt\n");
        return 0;
    }
    ```

**Problem 13: A Simple Invoice**
