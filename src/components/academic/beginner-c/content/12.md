# Chapter 12: File Handling

So far, any data our program has worked with (like a user's name or a game score) disappears the moment the program closes. To store data permanently, we need to save it to a file. File handling in C allows our programs to read from and write to files on the computer's disk.

## 1. Concept Explanation

### What is File Handling?

**Simple Explanation:**
File handling is how your C program can interact with files on your computer. It's like teaching your program how to open a notebook (`.txt` file), write something in it, read what's already there, and then close it properly.

**Real-life Analogy:**
Imagine you have a physical filing cabinet.
1.  **Opening a File:** You find the right drawer and pull out a specific file folder. In C, this is the `fopen()` function. You need to specify the file's name and what you plan to do (read, write, etc.).
2.  **Reading/Writing:** You either read the documents inside the folder or add new documents to it. In C, these are functions like `fprintf()`, `fscanf()`, `fgetc()`, `fputc()`.
3.  **Closing a File:** When you're done, you put the folder back in the drawer and close it. This is crucial! In C, this is the `fclose()` function. If you don't close the file, the data might get corrupted, just like leaving a folder out might lead to lost papers.

**Technical Explanation:**
File handling in C involves using a structure called `FILE` (defined in `<stdio.h>`) which holds information about the file being accessed. A `FILE` pointer is used to point to this structure. The process involves opening a file in a specific mode, performing read/write operations, and then closing the file.

### File Modes

When you open a file with `fopen()`, you must specify a mode.

| Mode | Meaning                                                     | Behavior                                                              |
| :--- | :---------------------------------------------------------- | :-------------------------------------------------------------------- |
| `r`  | **Read**                                                    | Opens an existing file for reading. Fails if the file doesn't exist.  |
| `w`  | **Write**                                                   | Opens a file for writing. **Erases all previous content.** Creates the file if it doesn't exist. |
| `a`  | **Append**                                                  | Opens a file for writing. **Adds new content to the end.** Creates the file if it doesn't exist. |
| `r+` | Read and Write                                              | Opens for both reading and writing. Fails if the file doesn't exist.  |
| `w+` | Read and Write                                              | Opens for both. Erases previous content. Creates if non-existent.     |
| `a+` | Read and Append                                             | Opens for both. New content goes to the end. Creates if non-existent. |

## 2. Syntax Section

### The `FILE` Pointer
First, you always need a `FILE` pointer.
```c
FILE *file_pointer;
```

### Opening a File: `fopen()`
This function opens a file and returns a `FILE` pointer to it. If it fails, it returns `NULL`.
```c
// FILE *fopen(const char *filename, const char *mode);
file_pointer = fopen("data.txt", "w");

// ALWAYS check if the file opened successfully
if (file_pointer == NULL) {
    printf("Error opening file!\n");
    return 1; // Exit with an error code
}
```

### Writing to a File: `fprintf()`
Works just like `printf`, but the first argument is the `FILE` pointer.
```c
// int fprintf(FILE *stream, const char *format, ...);
fprintf(file_pointer, "Hello, this is some data.\n");
fprintf(file_pointer, "My score is %d\n", 100);
```

### Reading from a File: `fscanf()`
Works just like `scanf`, but the first argument is the `FILE` pointer.
```c
// int fscanf(FILE *stream, const char *format, ...);
int score;
char name[50];
fscanf(file_pointer, "%s %d", name, &score);
```

### Closing a File: `fclose()`
This is mandatory for saving data correctly and freeing up system resources.
```c
// int fclose(FILE *stream);
fclose(file_pointer);
```

## 3. Code Examples

### Example 1: Writing Text to a File
`write_file.c`
```c
#include <stdio.h>

int main() {
    FILE *fptr;

    // Open a file in write mode
    fptr = fopen("log.txt", "w");

    // Check if file was opened successfully
    if (fptr == NULL) {
        printf("Error! Could not open file.\n");
        return 1;
    }

    // Write some content to the file
    fprintf(fptr, "Log entry 1: Program started.\n");
    fprintf(fptr, "Log entry 2: User score is %d.\n", 95);
    fprintf(fptr, "Log entry 3: Program finished.\n");

    // Close the file
    fclose(fptr);

    printf("Data successfully written to log.txt\n");

    return 0;
}
```
**Result:** A file named `log.txt` will be created in the same directory with the log entries inside.

### Example 2: Reading Data from a File
Assume `log.txt` from the previous example exists.
`read_file.c`
```c
#include <stdio.h>

int main() {
    FILE *fptr;
    char line[200]; // Buffer to hold one line of text

    // Open file in read mode
    fptr = fopen("log.txt", "r");

    if (fptr == NULL) {
        printf("Error! Could not open file.\n");
        return 1;
    }

    printf("Reading from log.txt:\n");

    // Read the file line by line until the end is reached
    // fgets reads a line, including the newline character
    while (fgets(line, sizeof(line), fptr)) {
        printf("%s", line); // Print the line we just read
    }

    fclose(fptr);

    return 0;
}
```

### Example 3: Appending to a File
`append_file.c`
```c
#include <stdio.h>

int main() {

    fclose(fptr);

    printf("Appended data to log.txt\n");
    // You can run the read_file.c program again to see the new line.

```

**Problem 8: Count Lines, Words, and Characters**
*   **Statement:** Write a program that reads a file and counts the number of lines, words, and characters in it.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        FILE *fp = fopen("source.txt", "r");
        if (fp == NULL) return 1;
        char ch;
        int chars = 0, words = 0, lines = 0;
        while ((ch = fgetc(fp)) != EOF) {
            chars++;
            if (ch == '\n') lines++;
            if (ch == ' ' || ch == '\n') words++;
        }
        fclose(fp);
        // Add 1 to lines and words for the last ones if file not empty
        if (chars > 0) { words++; lines++; }
        printf("Chars: %d, Words: %d, Lines: %d\n", chars, words, lines);
        return 0;
    }
    ```

**Problem 13: Encrypt a File**
*   **Statement:** Encrypt a file using a simple Caesar cipher (shifting each character by a fixed number, e.g., 3).
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        FILE *fin = fopen("source.txt", "r");
        FILE *fout = fopen("encrypted.txt", "w");
        if (!fin || !fout) return 1;
        char ch;
        int shift = 3;
        while ((ch = fgetc(fin)) != EOF) {
            if (ch >= 'a' && ch <= 'z')
                fputc(((ch - 'a' + shift) % 26) + 'a', fout);
            else if (ch >= 'A' && ch <= 'Z')
                fputc(((ch - 'A' + shift) % 26) + 'A', fout);
            else
                fputc(ch, fout);
        }
        fclose(fin); fclose(fout);
        printf("File encrypted.\n");
        return 0;
    }
    ```

**Problem 14: Decrypt a File**
*   **Statement:** Write a program to decrypt the file created in the previous problem.
*   **Solution:**

        FILE *fin = fopen("encrypted.txt", "r");

                fputc(ch, fout);

**Problem 15: Simple Login System**
*   **Statement:** Create a `users.txt` file with usernames and passwords. Write a program that asks for a username and password, then checks the file to see if the user is valid.

        char username[50], password[50];

**Problem 16: Binary File I/O - Save a Struct**
*   **Statement:** Define a `struct` for a `Person` (name, age). Create an instance of this struct, and save the entire struct to a file named `person.bin` using binary write mode (`"wb"`).
*   **Concepts:** Binary files store raw bytes, not human-readable text. `fwrite()` is used to write blocks of memory.
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <string.h>

    typedef struct {
        char name[50];
        int age;
    } Person;

    int main() {
        FILE *fp = fopen("person.bin", "wb");
        if (fp == NULL) return 1;

        Person p1;
        strcpy(p1.name, "John Doe");
        p1.age = 30;

        // fwrite(&source, size_of_element, num_elements, file_pointer)
        fwrite(&p1, sizeof(Person), 1, fp);

        fclose(fp);
        printf("Struct saved to binary file.\n");
        return 0;
    }
    ```

**Problem 17: Binary File I/O - Read a Struct**
*   **Statement:** Read the `Person` struct back from the `person.bin` file created in the previous problem and print its contents.
*   **Concepts:** `fread()` is used to read blocks of memory from a binary file.
*   **Solution:**
    ```c
    #include <stdio.h>

    typedef struct {
        char name[50];
        int age;
    } Person;

    int main() {
        FILE *fp = fopen("person.bin", "rb");
        if (fp == NULL) return 1;

        Person p_read;

        // fread(&destination, size_of_element, num_elements, file_pointer)
        fread(&p_read, sizeof(Person), 1, fp);

        fclose(fp);

        printf("Read from binary file:\n");
        printf("Name: %s\n", p_read.name);
        printf("Age: %d\n", p_read.age);
        return 0;
    }
    ```

**Problem 18: Delete a Specific Line from a File**
*   **Statement:** Ask the user for a line number to delete from a file (`source.txt`). The program should create a temporary file, copy all lines except the specified one, then delete the original file and rename the temporary file.
*   **Solution:**

        rename("temp.txt", "source.txt");
