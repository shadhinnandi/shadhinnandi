# Chapter 02: Variables and Data Types

In the last chapter, we learned how to print static text. But what if we want to work with information that can change, like a user's age or the price of an item? For that, we need variables!

## 1. Concept Explanation

### What is a Variable?

**Simple Explanation:**
Imagine you have a set of labeled boxes. You can put things inside these boxes. A variable is just like one of these boxes. It has a name (a label) and it holds a value (the thing inside). You can change the value inside the box whenever you want.

**Real-life Analogy:**
Think of the contacts on your phone. You save a person's phone number with their name. The name (e.g., "Mom") is the variable name, and the phone number is the value. If your mom gets a new number, you just update the value associated with that name.

**Technical Explanation:**
A variable is a name given to a memory location. It is used to store data. Its value can be changed, and it can be reused many times.

### What are Data Types?

**Simple Explanation:**
You wouldn't store juice in a shoebox, right? You'd use a bottle. Similarly, in programming, we need to tell the computer *what kind* of data we are going to store in our variable "box". This is what a data type is.

*   For whole numbers (like 10, -5, 100), we use `int`.
*   For numbers with decimal points (like 3.14, -0.5), we use `float` or `double`.
*   For single characters (like 'A', '$', '7'), we use `char`.

**Technical Explanation:**
Data types specify the type of data that a variable can store, such as integer, floating-point, character, etc. Each data type requires a different amount of memory and has specific operations that can be performed on it.

**Common Data Types in C**

| Data Type | Keyword | Description                   | Example        |
| :-------- | :------ | :---------------------------- | :------------- |
| Integer   | `int`   | Whole numbers                 | `10`, `-99`    |
| Float     | `float` | Single-precision decimal numbers | `3.14`, `-2.5` |
| Double    | `double`| Double-precision decimal numbers | `19.99`        |
| Character | `char`  | A single character            | `'A'`, `'b'`, `'!'` |

## 2. Syntax Section

### Declaring and Initializing Variables

**Declaration:** This is when you create the box and give it a label.
```c
// Syntax: data_type variable_name;
int age;
float price;
char initial;
```

**Initialization:** This is when you put a value into the box for the first time.
```c
// Syntax: variable_name = value;
age = 25;
price = 99.95;
initial = 'J';
```

**Declaration + Initialization (Combined):** You can do both at the same time.
```c
// Syntax: data_type variable_name = value;
int age = 25;
float price = 99.95;
char initial = 'J';
```

### Using Variables with `printf()`

To print the value of a variable, we use "format specifiers" inside the `printf` string. A format specifier is a placeholder that gets replaced by the variable's value.

*   `%d` for `int`
*   `%f` for `float`
*   `%c` for `char`

```c
int age = 25;
printf("My age is %d.", age);
```
**Output:**
```
My age is 25.
```

### Example 1: Storing and Printing Age
`variables.c`

### 🟡 Intermediate Problems

**Problem 6: Temperature Conversion**
*   **Statement:** Convert a temperature from Celsius to Fahrenheit. The formula is `F = (C * 9/5) + 32`. Use `float` variables. Let Celsius be 37.
*   **Output:** `37.0 Celsius is 98.6 Fahrenheit.`
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        float celsius = 37.0;
        float fahrenheit = (celsius * 9.0/5.0) + 32; // Use 9.0/5.0 for float division
        printf("%f Celsius is %f Fahrenheit.", celsius, fahrenheit);
        return 0;
    }
    ```
*   **Explanation:** We use `9.0/5.0` instead of `9/5`. In C, `9/5` is integer division and results in `1`. Using `9.0/5.0` forces it to be floating-point division, giving the correct `1.8`.

**Problem 7: Swap Two Numbers**
*   **Statement:** Given two integer variables `a = 10` and `b = 20`, write code to swap their values. After your code, `a` should be 20 and `b` should be 10. (Hint: you might need a third, temporary variable).
*   **Output:**
    ```
    Before swap: a = 10, b = 20
    After swap: a = 20, b = 10
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int a = 10;
        int b = 20;
        int temp; // A temporary box to hold a value

        printf("Before swap: a = %d, b = %d\n", a, b);

        // Swapping logic
        temp = a;  // temp is now 10
        a = b;     // a is now 20
        b = temp;  // b is now 10

        printf("After swap: a = %d, b = %d", a, b);
        return 0;
    }
    ```
*   **Explanation:** We use a `temp` variable to hold the original value of `a` before we overwrite it with `b`'s value.

### 🔴 Hard Problems

**Problem 11: Swap Two Numbers Without a Third Variable**
*   **Statement:** This is a classic interview question. Given two integer variables `a = 10` and `b = 20`, swap their values *without* using a third temporary variable.
*   **Hint:** Use arithmetic operations. Think about how you can store the information of both `a` and `b` in one variable.
*   **Output:**
    ```
    Before swap: a = 10, b = 20
    After swap: a = 20, b = 10
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int a = 10;
        int b = 20;
        printf("Before swap: a = %d, b = %d\n", a, b);

        // Swapping logic using addition and subtraction
        a = a + b; // a is now 30 (10 + 20)
        b = a - b; // b is now 10 (30 - 20)
        a = a - b; // a is now 20 (30 - 10)

        printf("After swap: a = %d, b = %d\n", a, b);
        return 0;
    }
    ```
*   **Explanation:** This is a clever trick. First, `a` becomes the sum of both numbers. Then, `b` is updated to be the original value of `a` by subtracting the original `b` from the sum. Finally, `a` is updated to be the original value of `b` by subtracting the new `b` (which is the original `a`) from the sum.

**Problem 12: Extract Digits from a 3-Digit Number**
*   **Statement:** Given a 3-digit integer (e.g., 479), extract and print each digit separately.
*   **Hint:** Use the division (`/`) and modulo (`%`) operators.
*   **Output:**
    ```
    The number is 479.
    The first digit is 4.
    The second digit is 7.
    The third digit is 9.
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int number = 479;
        printf("The number is %d.\n", number);

        int thirdDigit = number % 10; // 479 % 10 = 9
        int secondDigit = (number / 10) % 10; // (47) % 10 = 7
        int firstDigit = number / 100; // 479 / 100 = 4

        printf("The first digit is %d.\n", firstDigit);
        printf("The second digit is %d.\n", secondDigit);
        printf("The third digit is %d.\n", thirdDigit);
        return 0;
    }
    ```

**Problem 13: Total Seconds**
*   **Statement:** Convert a given number of hours, minutes, and seconds into the total number of seconds. Let hours=2, minutes=30, seconds=45.
*   **Output:** `2 hours, 30 minutes, and 45 seconds is equal to 9045 seconds.`
*   **Solution:**
    ```c

    }
    ```

**Problem 14: Reverse a 3-Digit Number**
*   **Statement:** Take a 3-digit number and print its reverse. For example, if the input is 123, the output should be 321.
*   **Hint:** Use the same logic as extracting digits, but reconstruct the number in reverse order.
*   **Output:** `The reverse of 123 is 321.`
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int number = 123;
        int d1 = number % 10; // 3
        int d2 = (number / 10) % 10; // 2
        int d3 = number / 100; // 1
        int reversed = (d1 * 100) + (d2 * 10) + d3;
        printf("The reverse of %d is %d.", number, reversed);
        return 0;
    }
    ```
