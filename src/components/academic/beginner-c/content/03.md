# Chapter 03: Input & Output

So far, our programs have been static. The values are hard-coded directly into the program. But what makes programming powerful is creating interactive applications that can take input from a user and produce output based on that.

## 1. Concept Explanation

### What is Input and Output?

**Simple Explanation:**
*   **Input:** This is any information that you give to the program. Typing on your keyboard is the most common way to provide input.
*   **Output:** This is any information the program gives back to you. Displaying text or results on the screen is the most common form of output.

**Real-life Analogy:**
Think of an ATM.
*   **Input:** You insert your card, type your PIN, and choose an amount to withdraw.
*   **Output:** The screen displays your balance, and the machine gives you cash.

Our C programs work similarly. We can ask the user for numbers or text (input) and then show them a calculated result (output).

**Technical Explanation:**
In C, input and output operations are handled by a set of functions defined in the `<stdio.h>` library.
*   **Standard Input (stdin):** The default input stream, which is typically the keyboard.
*   **Standard Output (stdout):** The default output stream, which is typically the computer screen.

We've already used an output function: `printf()`. Now, we'll learn the primary input function: `scanf()`.

## 2. Syntax Section

### Getting Input with `scanf()`

The `scanf()` function is used to read formatted input from the standard input (keyboard).

**Syntax:**
```c
// scanf("format_specifier", &variable_name);
int age;
scanf("%d", &age);
```

**Syntax Explained Line-by-Line:**

*   `scanf()`: The name of the function.
*   `"%d"`: A format specifier. This tells `scanf` *what kind* of data to expect. It must match the data type of the variable you're storing the input in.
    *   `%d` for `int`
    *   `%f` for `float`
    *   `%c` for `char`
*   `&variable_name`: This is the crucial part.
    *   `&`: This is the "address-of" operator. It gives the memory address of the variable `age`.
    *   **Simple Explanation:** You're not just telling `scanf` the name of the box (`age`), you're telling it *exactly where to find that box in memory* so it can put the user's input directly inside it.

**Flowchart: `scanf()` in action**
```
[Program starts]
     |
     v
[printf("Enter your age: ")] (Asks the user)
     |
     v
[scanf("%d", &age)] (Program pauses and waits for user to type a number and press Enter)
     |
     v
[User types '25' and presses Enter]
     |
     v
[The value 25 is stored in the 'age' variable]
     |
     v
[Program continues...]
```

## 3. Code Examples

### Example 1: Asking for the User's Age
`ask_age.c`
```c
#include <stdio.h>

int main() {
    int age; // A box to store the user's age

    // Ask the user for input
    printf("Please enter your age: ");

    // Get the input from the keyboard and store it in the 'age' variable
    scanf("%d", &age);

    // Print a message using the value the user provided
    printf("Wow, you are %d years old!\n", age);

    return 0;
}
```
**How to Run:**
1. Compile and run the program.
2. The terminal will show `Please enter your age: `.
3. Type a number (e.g., `25`) and press `Enter`.
4. The program will then print `Wow, you are 25 years old!`.

### Example 2: Adding Two Numbers Given by the User
`add_user_input.c`
```c
#include <stdio.h>

int main() {
    int num1, num2, sum;

    printf("Enter the first number: ");
    scanf("%d", &num1);

    printf("Enter the second number: ");
    scanf("%d", &num2);

    // Calculate the sum
    sum = num1 + num2;

    printf("The sum of %d and %d is %d.\n", num1, num2, sum);

    return 0;
}
```

### Example 3: Reading a Float and a Char
`read_float_char.c`
```c
#include <stdio.h>

int main() {
    float weight;
    char grade;

    printf("Enter your weight: ");
    scanf("%f", &weight);

    printf("Enter your grade (A, B, C, etc.): ");
    // Notice the space before %c. This is important!
    // It consumes any leftover newline/whitespace characters from the previous scanf.
    scanf(" %c", &grade);

    printf("Your weight is %f and your grade is %c.\n", weight, grade);

    return 0;
}
```
**Common Mistake:** Forgetting the space `" %c"` when reading a character after a number can cause `scanf` to read the `Enter` key press instead of the character you want.

**Problem 7: Swap Two User-Input Numbers**
*   **Statement:** Ask the user for two numbers, `a` and `b`. Swap their values and print the result.
*   **Input/Output:**
    ```
    Enter value for a: 50
    Enter value for b: 99
    Before swap: a = 50, b = 99
    After swap: a = 99, b = 50
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int a, b, temp;
        printf("Enter value for a: ");
        scanf("%d", &a);
        printf("Enter value for b: ");
        scanf("%d", &b);

        printf("Before swap: a = %d, b = %d\n", a, b);

        temp = a;
        a = b;
        b = temp;

        printf("After swap: a = %d, b = %d", a, b);
        return 0;
    }
    ```

**Problem 8: Circle Area and Circumference**
*   **Statement:** Ask the user for the radius of a circle. Calculate and print both its area (`pi * r * r`) and circumference (`2 * pi * r`). Use `3.14159` for pi.
*   **Input/Output:**
    ```
    Enter the radius of the circle: 5.0
    Area: 78.539749
    Circumference: 31.415901
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        float radius, area, circumference;
        const float PI = 3.14159; // Use const for values that don't change
        printf("Enter the radius of the circle: ");
        scanf("%f", &radius);
        area = PI * radius * radius;
        circumference = 2 * PI * radius;
        printf("Area: %f\n", area);
        printf("Circumference: %f\n", circumference);
        return 0;
    }
    ```

### 🔴 Hard Problems

**Problem 11: Total Bill with Tax**
*   **Statement:** Ask the user for the price of an item and the sales tax rate (as a percentage). Calculate and print the total bill.
*   **Input/Output:**
    ```
    Enter item price: 150.00
    Enter tax rate (e.g., 8.5 for 8.5%): 8.5
    Total bill: 162.75
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        float price, taxRate, taxAmount, total;
        printf("Enter item price: ");
        scanf("%f", &price);
        printf("Enter tax rate (e.g., 8.5 for 8.5%%): ");
        scanf("%f", &taxRate);
        taxAmount = price * (taxRate / 100.0);
        total = price + taxAmount;
        printf("Total bill: %.2f", total); // .2f for clean currency output
        return 0;
    }
    ```

**Problem 12: Convert Days to Years, Weeks, Days**
*   **Statement:** Ask the user for a total number of days. Convert it into years, weeks, and remaining days. Assume a year has 365 days.
*   **Input/Output:**
    ```
    Enter total days: 400
    400 days is: 1 year(s), 1 week(s), and 5 day(s).
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int totalDays, years, weeks, remainingDays;
        printf("Enter total days: ");
        scanf("%d", &totalDays);
        years = totalDays / 365;
        remainingDays = totalDays % 365;
        weeks = remainingDays / 7;
        remainingDays = remainingDays % 7;
        printf("%d days is: %d year(s), %d week(s), and %d day(s).\n", totalDays, years, weeks, remainingDays);
        return 0;
    }
    ```

**Problem 13: Distance Between Two Points**
*   **Statement:** Ask the user for the coordinates of two points (x1, y1) and (x2, y2). Calculate the distance between them using the distance formula: `sqrt((x2-x1)^2 + (y2-y1)^2)`. You will need to include the `<math.h>` library and use the `sqrt()` and `pow()` functions.
*   **Hint:** To compile with the math library, you may need to add the `-lm` flag: `gcc your_file.c -o your_program -lm`
*   **Input/Output:**
    ```
    Enter x1: 0
    Enter y1: 0
    Enter x2: 3
    Enter y2: 4
    The distance is: 5.00
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <math.h> // Include for sqrt() and pow()

    int main() {
        float x1, y1, x2, y2, distance;
        printf("Enter x1: ");
        scanf("%f", &x1);
        printf("Enter y1: ");
        scanf("%f", &y1);
        printf("Enter x2: ");
        scanf("%f", &x2);
        printf("Enter y2: ");
        scanf("%f", &y2);

        distance = sqrt(pow(x2 - x1, 2) + pow(y2 - y1, 2));

        printf("The distance is: %.2f\n", distance);
        return 0;
    }
    ```

**Problem 14: Reading Multiple Values in One Scanf**
*   **Statement:** Ask the user to enter their age, weight, and height (in meters) all on one line, separated by spaces. Read all three values using a single `scanf` call.
*   **Input/Output:**
    ```
    Enter your age, weight, and height (e.g., 25 70.5 1.8): 30 82.2 1.75
    Age: 30, Weight: 82.20, Height: 1.75
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int age;
        float weight, height;
        printf("Enter your age, weight, and height (e.g., 25 70.5 1.8): ");
        scanf("%d %f %f", &age, &weight, &height);
        printf("Age: %d, Weight: %.2f, Height: %.2f\n", age, weight, height);
        return 0;
    }
    ```

**Problem 15: Gross Salary Calculator**
*   **Statement:** Ask for an employee's basic salary. Calculate their gross salary based on these allowances: HRA (House Rent Allowance) is 20% of basic salary, and DA (Dearness Allowance) is 40% of basic salary. Gross Salary = Basic Salary + HRA + DA.
*   **Input/Output:**
    ```
    Enter basic salary: 10000
    Gross salary is: 16000.00
    ```
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        float basic, hra, da, gross;
        printf("Enter basic salary: ");
        scanf("%f", &basic);
        hra = basic * 0.20;
        da = basic * 0.40;
        gross = basic + hra + da;
        printf("Gross salary is: %.2f\n", gross);
        return 0;
    }
    ```
