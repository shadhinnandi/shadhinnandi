# Scenario-Based Problems

These problems repeat work with `for`, `while` and `do-while`, combined with the decisions from Chapter 05. Before coding, decide three things for every loop: what it starts from, when it stops, and what changes each time. Several test cases check the edges: zero repetitions, exactly one, and inputs that must stop the loop early.

Programs read input without prompts and print exactly the sample output. Rules and rates in these problems are hypothetical.

## Problem 1: Even Roll Numbers in a Range
**Level:** Moderate

### Scenario
For a group project, a teacher puts every student with an **even** roll number between two given roll numbers into Group A. Teachers sometimes type the range backwards (larger number first), and the program should still work.

### Problem Statement
Read two whole numbers `L` and `R`. If `L` is greater than `R`, swap them. Print all even numbers from `L` to `R` (inclusive) on one line separated by single spaces, then how many there are and their sum. If there are none, the first line is `Even numbers: none`.

Print exactly:
```text
Even numbers: <list or none>
Count: <count>
Sum: <sum>
```

### Sample Input
```text
7 20
```

### Sample Output
```text
Even numbers: 8 10 12 14 16 18 20
Count: 7
Sum: 98
```

### Solution
```c
#include <stdio.h>

int main() {
    int low, high;
    scanf("%d %d", &low, &high);

    if (low > high) {           /* range typed backwards */
        int temp = low;
        low = high;
        high = temp;
    }

    int start = low;
    if (start % 2 != 0) {
        start++;                /* first even number in the range */
    }

    int count = 0, sum = 0;
    printf("Even numbers:");
    for (int n = start; n <= high; n += 2) {
        printf(" %d", n);
        count++;
        sum += n;
    }
    if (count == 0) {
        printf(" none");
    }
    printf("\n");

    printf("Count: %d\n", count);
    printf("Sum: %d\n", sum);
    return 0;
}
```

### Explanation
Instead of testing every number with `% 2`, the loop starts at the first even number and jumps by 2 (`n += 2`), so it only visits even numbers.

- Swapping uses a temporary variable; without `temp`, the first assignment would overwrite `low`.
- If `low` is odd, the first even number is `low + 1`. This also works for negative numbers: −3 % 2 is −1 (not 0), so −3 becomes −2.
- Each number is printed with a space **before** it (`" %d"`), so there is no stray space at the end of the line.

If the range contains no even number (for example 5 to 5), the loop body never runs, `count` stays 0, and `none` is printed.

### Concepts Practiced
- for loop with a step of 2
- Swapping two variables
- Counting and summing in a loop
- Handling zero iterations

## Problem 2: Youngest and Oldest Employee
**Level:** Moderate

### Scenario
The HR officer of a software company in Banani is preparing a retirement-planning report. She has the ages of the employees in one department and needs the youngest and oldest age, the average age, and how many employees are 50 or older.

### Problem Statement
Read `N` (the number of employees) and then `N` ages (whole numbers). If `N` is less than 1, print `No employees` and stop. Do not use an array: keep running values as you read.

Print exactly:
```text
Youngest: <age>
Oldest: <age>
Average age: <average, 2 decimals>
Aged 50 or above: <count>
```

### Sample Input
```text
6
34 27 45 52 23 61
```

### Sample Output
```text
Youngest: 23
Oldest: 61
Average age: 40.33
Aged 50 or above: 2
```

### Solution
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    if (n < 1) {
        printf("No employees\n");
        return 0;
    }

    int age, youngest = 0, oldest = 0, total = 0, senior = 0;
    for (int i = 0; i < n; i++) {
        scanf("%d", &age);
        if (i == 0) {
            youngest = age;
            oldest = age;
        } else {
            if (age < youngest) youngest = age;
            if (age > oldest) oldest = age;
        }
        total += age;
        if (age >= 50) senior++;
    }

    printf("Youngest: %d\n", youngest);
    printf("Oldest: %d\n", oldest);
    printf("Average age: %.2f\n", (double) total / n);
    printf("Aged 50 or above: %d\n", senior);
    return 0;
}
```

### Explanation
All four results are **running values** updated once per employee, so the ages never need to be stored:

- the first age read becomes both the youngest and the oldest so far;
- every later age is compared with both;
- the total grows by each age, and the counter grows only for ages 50 or above.

Starting `youngest` at 0 instead of the first age would be a bug: no age is smaller than 0, so the youngest would be reported as 0. The `(double)` cast avoids integer division in the average: 242 / 6 = 40.33, not 40.

### Concepts Practiced
- for loop reading N values
- Running minimum and maximum
- Conditional counting
- Type cast for the average

## Problem 3: Student Welfare Loan Schedule
**Level:** Intermediate

### Scenario
The student welfare office gives interest-free laptop loans (hypothetical scheme). A student repays a fixed amount each month; in the final month he pays only what is left. The office wants a month-by-month repayment schedule printed on the loan agreement.

### Problem Statement
Read the loan amount and the monthly installment (whole taka).

- If the installment is 0 or less, print `Invalid installment`.
- If the loan amount is 0 or less, print `Nothing to repay`.

Otherwise, repeat until the remaining amount is 0: pay the installment, or the remaining amount if it is smaller, and print one line for the month. Finish with the number of months, using `month` for 1 and `months` otherwise.

Print exactly:
```text
Month <k>: paid <paid> Tk, remaining <remaining> Tk
...
Loan cleared in <m> months
```

### Sample Input
```text
10000 3000
```

### Sample Output
```text
Month 1: paid 3000 Tk, remaining 7000 Tk
Month 2: paid 3000 Tk, remaining 4000 Tk
Month 3: paid 3000 Tk, remaining 1000 Tk
Month 4: paid 1000 Tk, remaining 0 Tk
Loan cleared in 4 months
```

### Solution
```c
#include <stdio.h>

int main() {
    int loan, installment;
    scanf("%d %d", &loan, &installment);

    if (installment <= 0) {
        printf("Invalid installment\n");
        return 0;
    }
    if (loan <= 0) {
        printf("Nothing to repay\n");
        return 0;
    }

    int remaining = loan, month = 0;
    while (remaining > 0) {
        int paid = installment;
        if (remaining < installment) {
            paid = remaining;           /* last, smaller payment */
        }
        remaining -= paid;
        month++;
        printf("Month %d: paid %d Tk, remaining %d Tk\n", month, paid, remaining);
    }

    if (month == 1) {
        printf("Loan cleared in 1 month\n");
    } else {
        printf("Loan cleared in %d months\n", month);
    }
    return 0;
}
```

### Explanation
A `while` loop fits here because the number of months is not known in advance; the loop runs **while** money is still owed.

Each month pays either the full installment or, if less is left, exactly what is left. That stops the remaining amount from ever going negative (paying 3000 when only 1000 is owed).

The installment check is essential: with an installment of 0, `remaining` would never decrease and the loop would never end. Every `while` loop needs something inside it that moves it towards its stopping condition.

### Concepts Practiced
- while loop with an unknown number of iterations
- Avoiding infinite loops
- Last-iteration adjustment
- Singular and plural output

## Problem 4: Attendance Register Summary
**Level:** Intermediate

### Scenario
A course teacher marks each class as `P` (present), `A` (absent) or `L` (late). Under the department's (hypothetical) rule, a late arrival counts as present, but **every 3 lates count as 1 absence**. A student needs at least 75% effective attendance to be eligible for the final exam.

### Problem Statement
Read `N` (number of classes) and then `N` marks, each `P`, `A` or `L`, separated by spaces.

- If `N` is less than 1, print `No classes recorded`.
- If any mark is not `P`, `A` or `L`, print `Invalid entry on day <d>` (the first such day) and stop.

Otherwise:

- effective absences = absences + (lates ÷ 3, whole number),
- effective attendance = (N − effective absences) × 100 ÷ N.

Print exactly:
```text
Present: <P count>
Late: <L count>
Absent: <A count>
Effective attendance: <percentage, 2 decimals> percent
Status: <Eligible or Not eligible>
```

### Sample Input
```text
12
P P L A P P L P L P A P
```

### Sample Output
```text
Present: 7
Late: 3
Absent: 2
Effective attendance: 75.00 percent
Status: Eligible
```

### Solution
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    if (n < 1) {
        printf("No classes recorded\n");
        return 0;
    }

    int present = 0, late = 0, absent = 0;
    char mark;
    for (int day = 1; day <= n; day++) {
        scanf(" %c", &mark);
        if (mark == 'P') {
            present++;
        } else if (mark == 'L') {
            late++;
        } else if (mark == 'A') {
            absent++;
        } else {
            printf("Invalid entry on day %d\n", day);
            return 0;
        }
    }

    int effectiveAbsent = absent + late / 3;
    double percent = (n - effectiveAbsent) * 100.0 / n;

    printf("Present: %d\n", present);
    printf("Late: %d\n", late);
    printf("Absent: %d\n", absent);
    printf("Effective attendance: %.2f percent\n", percent);
    if (percent >= 75) {
        printf("Status: Eligible\n");
    } else {
        printf("Status: Not eligible\n");
    }
    return 0;
}
```

### Explanation
The loop reads one mark per day and updates one of three counters. `" %c"` (with a space) skips the spaces and newline between marks.

The conversion uses integer division on purpose: 3 lates → 1 absence, but 2 lates → 0 absences, and 5 lates → 1 absence. With the sample there are 2 absences and 3 lates, so 3 effective absences: (12 − 3) × 100 ÷ 12 = 75.00, which is exactly the threshold, so the student is eligible.

Stopping at the first invalid mark with `return 0` means a typing mistake is reported instead of silently producing a wrong percentage.

### Concepts Practiced
- for loop reading characters
- Counters for categories
- Integer division in a rule
- Early exit on invalid data

## Problem 5: Savings Account Goal
**Level:** Intermediate

### Scenario
Sadia opens a monthly savings account (fictional terms) to save for a semester abroad. At the **start** of each month she deposits a fixed amount. At the **end** of each month the bank adds profit at one-twelfth of the yearly rate on the whole balance. She wants to know how many months it takes to reach her goal.

### Problem Statement
Read the monthly deposit, the yearly profit rate in percent, and the goal (all decimals).

- If the deposit is 0 or less, print `Monthly deposit must be positive`.

Otherwise repeat month by month: add the deposit, then multiply the balance by (1 + rate ÷ 1200). Stop when the balance reaches the goal, or after 600 months (50 years) at most. If the goal is still not reached after 600 months, print `Goal not reached within 600 months` instead of the report.

Print exactly (two decimals):
```text
Months needed: <months>
Final balance: <balance> Tk
Total deposited: <deposited> Tk
Profit earned: <profit> Tk
```

### Sample Input
```text
5000 6 61000
```

### Sample Output
```text
Months needed: 12
Final balance: 61986.20 Tk
Total deposited: 60000.00 Tk
Profit earned: 1986.20 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double deposit, yearlyRate, goal;
    scanf("%lf %lf %lf", &deposit, &yearlyRate, &goal);

    if (deposit <= 0) {
        printf("Monthly deposit must be positive\n");
        return 0;
    }

    double balance = 0, deposited = 0;
    int months = 0;
    while (balance < goal && months < 600) {
        balance += deposit;                     /* start of month */
        deposited += deposit;
        balance *= 1 + yearlyRate / 1200;       /* end-of-month profit */
        months++;
    }

    if (balance < goal) {
        printf("Goal not reached within 600 months\n");
        return 0;
    }

    printf("Months needed: %d\n", months);
    printf("Final balance: %.2f Tk\n", balance);
    printf("Total deposited: %.2f Tk\n", deposited);
    printf("Profit earned: %.2f Tk\n", balance - deposited);
    return 0;
}
```

### Explanation
The loop condition has two parts joined by `&&`: keep going while the goal is not reached **and** the safety limit has not been hit. After the loop, the program checks *which* condition stopped it.

Order inside the loop matters: the deposit is added first, so it also earns that month's profit. A 6% yearly rate is 0.5% per month, so each month the balance is multiplied by 1.005.

Without profit, 12 deposits of 5000 make only 60000, short of 61000. With profit, the balance after 12 months is 61986.20, so the goal is reached one month earlier than with a 0% rate (the test below shows 13 months).

### Concepts Practiced
- while loop with a compound condition
- Safety limit on a loop
- Compound interest step by step
- Checking why a loop ended

## Problem 6: Cash Counter with Refunds
**Level:** Challenging

### Scenario
The university bookshop's cashier types each transaction into a small program as it happens: a positive amount is a sale, a negative amount is a refund, and `0` means the shop is closing. The manager wants the day's summary at closing time.

### Problem Statement
Read whole-taka amounts until `0` is entered. Do not ask for the number of transactions in advance. Calculate:

- the number of sales and their total,
- the number of refunds and their total (as a positive amount),
- the net amount (sales − refunds),
- the largest single sale (`N/A` if there were no sales).

Print exactly:
```text
Sales: <count> (<total> Tk)
Refunds: <count> (<total> Tk)
Net: <net> Tk
Largest sale: <amount> Tk
```
or, with no sales, `Largest sale: N/A` as the last line.

### Sample Input
```text
250 -40 1200 75 -150 300 0
```

### Sample Output
```text
Sales: 4 (1825 Tk)
Refunds: 2 (190 Tk)
Net: 1635 Tk
Largest sale: 1200 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    int amount;
    int salesCount = 0, salesTotal = 0;
    int refundCount = 0, refundTotal = 0;
    int largest = 0;

    scanf("%d", &amount);
    while (amount != 0) {
        if (amount > 0) {
            if (salesCount == 0 || amount > largest) {
                largest = amount;
            }
            salesCount++;
            salesTotal += amount;
        } else {
            refundCount++;
            refundTotal += -amount;     /* store refunds as positive */
        }
        scanf("%d", &amount);
    }

    printf("Sales: %d (%d Tk)\n", salesCount, salesTotal);
    printf("Refunds: %d (%d Tk)\n", refundCount, refundTotal);
    printf("Net: %d Tk\n", salesTotal - refundTotal);
    if (salesCount > 0) {
        printf("Largest sale: %d Tk\n", largest);
    } else {
        printf("Largest sale: N/A\n");
    }
    return 0;
}
```

### Explanation
This is a **sentinel-controlled** loop: a special value (0) marks the end of the data. The first value is read before the loop, and the next value is read at the end of each iteration, so the sentinel itself is never processed as a transaction.

Inside the loop, the sign of the amount decides where it goes. The largest sale only considers sales; the `salesCount == 0` check makes the first sale the starting maximum. If no sale ever happens, `largest` is meaningless, so the program prints `N/A` rather than a misleading 0.

With the sample: sales 250 + 1200 + 75 + 300 = 1825, refunds 40 + 150 = 190, net 1635.

### Concepts Practiced
- Sentinel-controlled while loop
- Read-before-loop pattern
- Separate counters and totals
- Handling the "no data" case

## Problem 7: Lucky Bus Tickets
**Level:** Challenging

### Scenario
On the university shuttle, students joke that a 6-digit ticket is "lucky" when the sum of its first three digits equals the sum of its last three digits (for example 123402: 1+2+3 = 4+0+2). The transport office, for fun, wants to know how many lucky tickets will be issued in a range of ticket numbers.

### Problem Statement
Read two 6-digit ticket numbers `A` and `B` (100000–999999). If `A` is greater than `B`, swap them. Count the lucky tickets from `A` to `B` inclusive and print the first and last lucky ticket.

Print exactly:
```text
Lucky tickets: <count>
First: <ticket>
Last: <ticket>
```
If there are none, print only `Lucky tickets: 0`.

### Sample Input
```text
123400 123500
```

### Sample Output
```text
Lucky tickets: 3
First: 123402
Last: 123420
```

### Solution
```c
#include <stdio.h>

int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    if (a > b) {
        int t = a;
        a = b;
        b = t;
    }

    int count = 0, first = 0, last = 0;
    for (int ticket = a; ticket <= b; ticket++) {
        int left = ticket / 1000;       /* first three digits */
        int right = ticket % 1000;      /* last three digits */

        int leftSum = left / 100 + left / 10 % 10 + left % 10;
        int rightSum = right / 100 + right / 10 % 10 + right % 10;

        if (leftSum == rightSum) {
            if (count == 0) {
                first = ticket;
            }
            last = ticket;
            count++;
        }
    }

    printf("Lucky tickets: %d\n", count);
    if (count > 0) {
        printf("First: %d\n", first);
        printf("Last: %d\n", last);
    }
    return 0;
}
```

### Explanation
Splitting the ticket with `/ 1000` and `% 1000` gives two 3-digit halves (123402 → 123 and 402). The digits of each half are taken with the same `/` and `%` trick as in Chapter 04, so no inner loop is needed.

The first lucky ticket is recorded only when `count` is still 0; `last` is overwritten every time, so after the loop it holds the last one.

For the sample, the left half is always 123 (sum 6). Between 400 and 500 the right halves with digit sum 6 are 402, 411 and 420, so there are 3 lucky tickets.

The right half can have leading zeros: for 100001 it is `1` (that is, 001), and its digit sum is still 1, which the arithmetic handles correctly.

### Concepts Practiced
- for loop over a range
- Digit extraction with `/` and `%`
- Recording the first and last match
- Swapping inputs

## Problem 8: Mobile Data Pack Tracker
**Level:** Challenging

### Scenario
Rakib buys a monthly internet pack (fictional terms). He logs how many MB he uses each day. When the pack runs out, his phone switches to pay-as-you-go at 0.50 Tk per MB. He wants a day-by-day log and to know how much extra he paid.

### Problem Statement
Read the pack size in MB, the number of days `N`, and then `N` daily usage values (all whole numbers). Process the days in order:

- While the pack still has data and the day's usage fits, subtract it and print `Day <d>: used <u> MB, left <left> MB`.
- On the day the usage is more than what is left, the pack is finished and the rest is extra: print `Day <d>: used <u> MB, pack finished, extra <e> MB`.
- After the pack is finished, all usage is extra: print `Day <d>: used <u> MB, extra <u> MB`.

Finally print the total extra MB and the charge (0.50 Tk per MB, two decimals).

Print exactly:
```text
Day 1: ...
...
Extra data: <MB> MB
Extra charge: <charge> Tk
```

### Sample Input
```text
2048 6
300 450 512 600 400 250
```

### Sample Output
```text
Day 1: used 300 MB, left 1748 MB
Day 2: used 450 MB, left 1298 MB
Day 3: used 512 MB, left 786 MB
Day 4: used 600 MB, left 186 MB
Day 5: used 400 MB, pack finished, extra 214 MB
Day 6: used 250 MB, extra 250 MB
Extra data: 464 MB
Extra charge: 232.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    int left, days;
    scanf("%d %d", &left, &days);

    int extra = 0;
    for (int d = 1; d <= days; d++) {
        int used;
        scanf("%d", &used);

        if (left > 0 && used <= left) {
            left -= used;
            printf("Day %d: used %d MB, left %d MB\n", d, used, left);
        } else if (left > 0) {
            int over = used - left;
            left = 0;
            extra += over;
            printf("Day %d: used %d MB, pack finished, extra %d MB\n", d, used, over);
        } else {
            extra += used;
            printf("Day %d: used %d MB, extra %d MB\n", d, used, used);
        }
    }

    printf("Extra data: %d MB\n", extra);
    printf("Extra charge: %.2f Tk\n", extra * 0.50);
    return 0;
}
```

### Explanation
Each day falls into exactly one of three **states**: the pack has enough data, the pack runs out during this day, or the pack was already empty. An `if / else if / else` inside the loop picks the state.

Day 5 in the sample is the interesting one: 186 MB were left and 400 MB were used, so 214 MB are extra and the pack is now empty. From then on every MB is extra. Total extra = 214 + 250 = 464 MB, charged 464 × 0.50 = 232.00 Tk.

A boundary case: if a day uses **exactly** what is left, `used <= left` is true, the pack ends at 0 with no extra, and the following days are fully extra (see the last test).

### Concepts Practiced
- for loop with input inside
- State tracked across iterations
- if-else if-else inside a loop
- Running total of a derived value
