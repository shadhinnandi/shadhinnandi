# Scenario-Based Problems

Use an array whenever the program needs the values **more than once**: to compare each value with an average that is only known after reading all of them, to answer several searches, to sort, or to update a value later. Always check that the input size fits the array you declared, and remember that indexes start at 0 while people count from 1.

Programs read input without prompts and print exactly the sample output.

## Problem 1: Class Marks Analysis
**Level:** Moderate

### Scenario
After a class test, the course teacher wants a quick analysis: the class average, the highest and lowest marks with the students' roll numbers, and which students scored **above** the average. Roll numbers are simply 1, 2, 3, … in the order the marks are entered.

### Problem Statement
Read `N` (1–100) and then `N` whole-number marks. If `N` is out of range, print `Invalid number of students`.

The highest and lowest each go to the first student with that mark. Print exactly:
```text
Average: <average, 2 decimals>
Highest: <mark> (roll <r>)
Lowest: <mark> (roll <r>)
Above average: <count> (rolls <r1> <r2> ...)
```
If nobody is above the average, the last line is `Above average: 0`.

### Sample Input
```text
8
72 85 64 90 55 78 81 69
```

### Sample Output
```text
Average: 74.25
Highest: 90 (roll 4)
Lowest: 55 (roll 5)
Above average: 4 (rolls 2 4 6 7)
```

### Solution
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    if (n < 1 || n > 100) {
        printf("Invalid number of students\n");
        return 0;
    }

    int marks[100];
    int sum = 0, hi = 0, lo = 0;          /* indexes of highest and lowest */
    for (int i = 0; i < n; i++) {
        scanf("%d", &marks[i]);
        sum += marks[i];
        if (marks[i] > marks[hi]) hi = i;
        if (marks[i] < marks[lo]) lo = i;
    }

    double average = (double) sum / n;

    int above = 0;
    for (int i = 0; i < n; i++) {
        if (marks[i] > average) above++;
    }

    printf("Average: %.2f\n", average);
    printf("Highest: %d (roll %d)\n", marks[hi], hi + 1);
    printf("Lowest: %d (roll %d)\n", marks[lo], lo + 1);
    printf("Above average: %d", above);
    if (above > 0) {
        printf(" (rolls");
        for (int i = 0; i < n; i++) {
            if (marks[i] > average) printf(" %d", i + 1);
        }
        printf(")");
    }
    printf("\n");
    return 0;
}
```

### Explanation
The average is only known after **all** marks have been read, so counting the students above it needs a second pass over the data. That is exactly why the marks are kept in an array.

The program remembers the **index** of the highest and lowest mark rather than the mark itself, so it can print both the mark and the roll number (index + 1). Using `>` and `<` (not `>=`/`<=`) keeps the first student on a tie. Both indexes start at 0, so the first mark is compared with itself the first time, which is harmless.

With the sample, the total is 594, the average 74.25, and the marks 85, 90, 78 and 81 (rolls 2, 4, 6, 7) are above it.

### Concepts Practiced
- Reading into an array
- Two passes over an array
- Tracking indexes of extremes
- Index to roll number conversion

## Problem 2: Weekly Cafeteria Spending
**Level:** Moderate

### Scenario
Nusrat sets herself a daily cafeteria budget and records what she actually spent each day of the week, from Sunday to Saturday. At the weekend she reviews the week: total, daily average, the most expensive day, and the days she went over budget.

### Problem Statement
Read the daily budget and then 7 daily amounts (decimals), Sunday first. Store the amounts in an array of 7. Print the day names with a helper function `void printDay(int index)` (0 = Sunday … 6 = Saturday). The most expensive day is the first one with the highest amount; a day is over budget if it is strictly above the budget.

Print exactly:
```text
Total: <total> Tk
Daily average: <average> Tk
Most expensive: <day> (<amount> Tk)
Days over budget: <count> (<day> <day> ...)
```
If no day is over budget, the last line is `Days over budget: 0`.

### Sample Input
```text
150
120 180 95 210 150 0 160
```

### Sample Output
```text
Total: 915.00 Tk
Daily average: 130.71 Tk
Most expensive: Wednesday (210.00 Tk)
Days over budget: 3 (Monday Wednesday Saturday)
```

### Solution
```c
#include <stdio.h>

void printDay(int index) {
    switch (index) {
        case 0: printf("Sunday"); break;
        case 1: printf("Monday"); break;
        case 2: printf("Tuesday"); break;
        case 3: printf("Wednesday"); break;
        case 4: printf("Thursday"); break;
        case 5: printf("Friday"); break;
        default: printf("Saturday");
    }
}

int main() {
    double budget, spent[7];
    scanf("%lf", &budget);

    double total = 0;
    int maxDay = 0, overCount = 0;
    for (int d = 0; d < 7; d++) {
        scanf("%lf", &spent[d]);
        total += spent[d];
        if (spent[d] > spent[maxDay]) maxDay = d;
        if (spent[d] > budget) overCount++;
    }

    printf("Total: %.2f Tk\n", total);
    printf("Daily average: %.2f Tk\n", total / 7);
    printf("Most expensive: ");
    printDay(maxDay);
    printf(" (%.2f Tk)\n", spent[maxDay]);

    printf("Days over budget: %d", overCount);
    if (overCount > 0) {
        printf(" (");
        int printed = 0;
        for (int d = 0; d < 7; d++) {
            if (spent[d] > budget) {
                if (printed > 0) printf(" ");
                printDay(d);
                printed++;
            }
        }
        printf(")");
    }
    printf("\n");
    return 0;
}
```

### Explanation
The array index doubles as the day of the week, so `spent[3]` is Wednesday's spending and `printDay(3)` prints `Wednesday`. Keeping the data and the day number together this way avoids a separate list of names.

The first loop reads and summarises; the second pass lists the over-budget days, which requires the stored values. Note that 150 (Thursday) is **not** over a 150 Tk budget, because the rule says strictly above.

Average: 915 ÷ 7 = 130.714… → 130.71.

### Concepts Practiced
- Fixed-size array indexed by day
- Helper function with switch
- Two passes over an array
- Separators between listed items

## Problem 3: Student ID Lookup
**Level:** Intermediate

### Scenario
At the registration desk, a volunteer has the list of student IDs who have paid the trimester fee. Students come one by one and ask whether their payment is recorded. Because the list was merged from two offices, some IDs appear twice.

### Problem Statement
Read `N` (1–200) IDs (whole numbers), then `Q` queries. For each query, search the list from the beginning and print one of:

- `<id>: found at position <p>` (the first position, counting from 1),
- `<id>: found at position <p> (appears <k> times)` if it appears more than once,
- `<id>: not found`.

If `N` is out of range, print `Invalid list size`.

### Sample Input
```text
6
2211045 2211052 2213001 2211052 2212077 2211099
3
2211052 2213001 2211000
```

### Sample Output
```text
2211052: found at position 2 (appears 2 times)
2213001: found at position 3
2211000: not found
```

### Solution
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    if (n < 1 || n > 200) {
        printf("Invalid list size\n");
        return 0;
    }

    int ids[200];
    for (int i = 0; i < n; i++) {
        scanf("%d", &ids[i]);
    }

    int q;
    scanf("%d", &q);
    for (int k = 0; k < q; k++) {
        int target;
        scanf("%d", &target);

        int firstPos = -1, count = 0;
        for (int i = 0; i < n; i++) {
            if (ids[i] == target) {
                if (firstPos == -1) firstPos = i;
                count++;
            }
        }

        if (count == 0) {
            printf("%d: not found\n", target);
        } else if (count == 1) {
            printf("%d: found at position %d\n", target, firstPos + 1);
        } else {
            printf("%d: found at position %d (appears %d times)\n", target, firstPos + 1, count);
        }
    }
    return 0;
}
```

### Explanation
This is a **linear search**: look at every element in order and compare it with the target. The list is read once and searched many times, which is why it is stored in an array.

`firstPos` starts at −1, a value that can never be a real index, meaning "not found yet". The first match sets it; later matches only increase the count. Scanning the whole list (instead of stopping at the first match) is necessary here because duplicates must be counted.

Student IDs such as 2211052 fit comfortably in an `int`. IDs written with a leading zero (like 011221052) would lose it in an integer; Chapter 10 shows how to keep IDs as strings.

### Concepts Practiced
- Linear search
- Sentinel value −1 for "not found"
- Nested loops: queries × list
- Counting duplicates

## Problem 4: Scholarship Rank List
**Level:** Intermediate

### Scenario
The department ranks students by CGPA to award scholarships. Students with the same CGPA share a rank, and the next rank is skipped (1, 2, 2, 4), the same way sports rankings work. Among students with equal CGPA, the smaller roll number is listed first.

### Problem Statement
Read `N` (1–100) and then `N` CGPAs (two decimals); student `i` has roll number `i`. Sort the students by CGPA from highest to lowest using **bubble sort** on two parallel arrays (CGPAs and rolls). Swap only when the next CGPA is strictly higher, so equal CGPAs keep their roll order. Then print the rank list:
```text
Rank <rank>: Roll <roll> (<cgpa, 2 decimals>)
```
If `N` is out of range, print `Invalid number of students`.

### Sample Input
```text
5
3.80 3.52 3.95 3.10 3.80
```

### Sample Output
```text
Rank 1: Roll 3 (3.95)
Rank 2: Roll 1 (3.80)
Rank 2: Roll 5 (3.80)
Rank 4: Roll 2 (3.52)
Rank 5: Roll 4 (3.10)
```

### Solution
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    if (n < 1 || n > 100) {
        printf("Invalid number of students\n");
        return 0;
    }

    double cgpa[100];
    int roll[100];
    for (int i = 0; i < n; i++) {
        scanf("%lf", &cgpa[i]);
        roll[i] = i + 1;
    }

    /* bubble sort, highest CGPA first */
    for (int pass = 0; pass < n - 1; pass++) {
        for (int j = 0; j < n - 1 - pass; j++) {
            if (cgpa[j + 1] > cgpa[j]) {
                double tc = cgpa[j];
                cgpa[j] = cgpa[j + 1];
                cgpa[j + 1] = tc;

                int tr = roll[j];       /* move the roll with its CGPA */
                roll[j] = roll[j + 1];
                roll[j + 1] = tr;
            }
        }
    }

    int rank = 1;
    for (int i = 0; i < n; i++) {
        if (i > 0 && cgpa[i] != cgpa[i - 1]) {
            rank = i + 1;               /* new value: rank = position */
        }
        printf("Rank %d: Roll %d (%.2f)\n", rank, roll[i], cgpa[i]);
    }
    return 0;
}
```

### Explanation
Two **parallel arrays** keep related data at the same index: `cgpa[i]` belongs to `roll[i]`. Whenever bubble sort swaps two CGPAs, it must swap the matching rolls too, or the names would no longer match the grades.

Swapping only on a strictly higher value makes the sort **stable**: equal CGPAs never change places, so roll 1 stays ahead of roll 5.

Ranking walks the sorted list. The rank only changes when the CGPA changes, and it then jumps to the position number (`i + 1`). That gives 1, 2, 2, 4, 5: after two students share rank 2, the next student is in 4th place.

Comparing `double` values with `!=` is safe here because equal CGPAs were read from identical text and are stored identically. Values produced by calculations are a different story; there you would compare with a small tolerance.

### Concepts Practiced
- Bubble sort
- Parallel arrays
- Stable sorting
- Competition ranking with ties

## Problem 5: Grade Distribution Chart
**Level:** Intermediate

### Scenario
The exam committee wants a quick text chart of how a class's marks are spread across grade bands, to spot unusually hard or easy exams. The bands are A (80–100), B (70–79), C (60–69), D (50–59) and F (below 50).

### Problem Statement
Read `N` and then `N` marks (0–100). Count the marks in each band using an **array of 5 counters**, not five separate variables. If `N` is less than 1, print `No marks`. If a mark is outside 0–100, print `Invalid mark: <mark>` and stop.

Print one line per band, in order A, B, C, D, F: the letter, the count in a 3-character field (`%3d`), ` |`, and then a space followed by one `*` per student (nothing after `|` if the count is 0).

### Sample Input
```text
8
85 92 74 68 45 79 88 30
```

### Sample Output
```text
A   3 | ***
B   2 | **
C   1 | *
D   0 |
F   2 | **
```

### Solution
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    if (n < 1) {
        printf("No marks\n");
        return 0;
    }

    int count[5] = {0, 0, 0, 0, 0};
    char letter[5] = {'A', 'B', 'C', 'D', 'F'};

    for (int i = 0; i < n; i++) {
        int mark;
        scanf("%d", &mark);
        if (mark < 0 || mark > 100) {
            printf("Invalid mark: %d\n", mark);
            return 0;
        }

        int band;
        if (mark >= 80) band = 0;
        else if (mark >= 70) band = 1;
        else if (mark >= 60) band = 2;
        else if (mark >= 50) band = 3;
        else band = 4;

        count[band]++;
    }

    for (int b = 0; b < 5; b++) {
        printf("%c %3d |", letter[b], count[b]);
        if (count[b] > 0) {
            printf(" ");
            for (int s = 0; s < count[b]; s++) {
                printf("*");
            }
        }
        printf("\n");
    }
    return 0;
}
```

### Explanation
Instead of five variables `countA`, `countB`, …, one array `count[5]` holds all counters. The band number becomes the index, so one statement, `count[band]++`, updates the right counter. A second array, `letter`, holds the labels in the same order, so a single loop prints every row.

Initialising the array with `{0, 0, 0, 0, 0}` matters: a local array without an initialiser contains leftover garbage values.

Boundaries follow the band definitions: 80 is an A, 79 a B, 50 a D and 49 an F (see the last test).

### Concepts Practiced
- Array of counters
- Array initialisation
- Parallel arrays for labels
- Nested loop for bars

## Problem 6: Course Marks Table
**Level:** Challenging

### Scenario
A coordinator stores the marks of a section in a table: one row per student and one column per course (three courses). She needs each student's total, each course's average and best student, and the class topper.

### Problem Statement
Read `N` (1–50) and then `N` rows of 3 marks into a **2D array** `marks[50][3]`. If `N` is out of range, print `Invalid number of students`. Ties always go to the student listed first.

Print exactly:
```text
Totals: <t1> <t2> ...
Course 1: average <avg, 2 decimals>, best student <s> (<mark>)
Course 2: average <avg>, best student <s> (<mark>)
Course 3: average <avg>, best student <s> (<mark>)
Class topper: student <s> (<total>)
```

### Sample Input
```text
4
78 85 82
90 35 65
55 60 70
70 72 78
```

### Sample Output
```text
Totals: 245 190 185 220
Course 1: average 73.25, best student 2 (90)
Course 2: average 63.00, best student 1 (85)
Course 3: average 73.75, best student 1 (82)
Class topper: student 1 (245)
```

### Solution
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    if (n < 1 || n > 50) {
        printf("Invalid number of students\n");
        return 0;
    }

    int marks[50][3];
    int total[50];

    for (int i = 0; i < n; i++) {
        total[i] = 0;
        for (int j = 0; j < 3; j++) {
            scanf("%d", &marks[i][j]);
            total[i] += marks[i][j];
        }
    }

    printf("Totals:");
    for (int i = 0; i < n; i++) {
        printf(" %d", total[i]);
    }
    printf("\n");

    for (int j = 0; j < 3; j++) {           /* walk down one column */
        int sum = 0, best = 0;
        for (int i = 0; i < n; i++) {
            sum += marks[i][j];
            if (marks[i][j] > marks[best][j]) best = i;
        }
        printf("Course %d: average %.2f, best student %d (%d)\n",
               j + 1, (double) sum / n, best + 1, marks[best][j]);
    }

    int topper = 0;
    for (int i = 1; i < n; i++) {
        if (total[i] > total[topper]) topper = i;
    }
    printf("Class topper: student %d (%d)\n", topper + 1, total[topper]);
    return 0;
}
```

### Explanation
In `marks[i][j]`, `i` is the row (student) and `j` the column (course). Row results (totals) are computed while reading, because a row is read in one go. Column results need the whole table, so they are computed afterwards with the loops **swapped**: the outer loop picks a course `j`, the inner loop walks down all students `i`.

This "row-wise vs column-wise" traversal is the key idea of 2D arrays. Course 1: (78 + 90 + 55 + 70) ÷ 4 = 73.25, with student 2's 90 the best.

Every "best" search starts with index 0 and uses strict `>`, so ties go to the earlier student. The extra `total` array avoids adding up each row a second time.

### Concepts Practiced
- 2D arrays
- Row-wise and column-wise traversal
- Index of maximum in a column
- Combining 1D and 2D arrays

## Problem 7: Seminar Seat Booking
**Level:** Challenging

### Scenario
The CSE club is running a seminar in a room with `S` numbered seats. Students book and cancel seats through a simple console program. A positive number books that seat, a negative number cancels it (for example `-7` cancels seat 7), and `0` closes the booking desk.

### Problem Statement
Read `S` (1–50). If it is out of range, print `Invalid hall size`. Otherwise keep an array of booked/free flags and process requests until `0`, printing one message per request:

- `Seat <k> booked` / `Seat <k> already booked`
- `Seat <k> cancelled` / `Seat <k> was not booked`
- `Seat <k> does not exist` (for a seat number above `S`, booking or cancelling)

When the desk closes, print the seat map, 10 seats per line, `X` for booked and `.` for free, then `Booked: <b>, Free: <f>`.

### Sample Input
```text
20
5 12 5 -12 25 18 -3 1 0
```

### Sample Output
```text
Seat 5 booked
Seat 12 booked
Seat 5 already booked
Seat 12 cancelled
Seat 25 does not exist
Seat 18 booked
Seat 3 was not booked
Seat 1 booked
X...X.....
.......X..
Booked: 3, Free: 17
```

### Solution
```c
#include <stdio.h>

int main() {
    int seats;
    scanf("%d", &seats);
    if (seats < 1 || seats > 50) {
        printf("Invalid hall size\n");
        return 0;
    }

    int booked[51] = {0};       /* index 1..seats used; booked[0] unused */

    int request;
    scanf("%d", &request);
    while (request != 0) {
        int seat = request;
        if (seat < 0) {
            seat = -seat;           /* seat number without the minus sign */
        }

        if (seat > seats) {
            printf("Seat %d does not exist\n", seat);
        } else if (request > 0) {
            if (booked[seat]) {
                printf("Seat %d already booked\n", seat);
            } else {
                booked[seat] = 1;
                printf("Seat %d booked\n", seat);
            }
        } else {
            if (booked[seat]) {
                booked[seat] = 0;
                printf("Seat %d cancelled\n", seat);
            } else {
                printf("Seat %d was not booked\n", seat);
            }
        }
        scanf("%d", &request);
    }

    int count = 0;
    for (int s = 1; s <= seats; s++) {
        if (booked[s]) {
            printf("X");
            count++;
        } else {
            printf(".");
        }
        if (s % 10 == 0 || s == seats) printf("\n");
    }
    printf("Booked: %d, Free: %d\n", count, seats - count);
    return 0;
}
```

### Explanation
The array is a set of **flags**: `booked[k]` is 1 if seat `k` is taken. Declaring it with 51 elements lets seat numbers be used directly as indexes (1–50), so there is no `− 1` to forget. `= {0}` sets every element to 0.

Each request is checked in a careful order: first whether the seat exists (this prevents writing outside the array, a serious bug in C), then whether it is a booking or a cancellation, then the seat's current state.

The seat number is the request without its minus sign; the sign only says whether to book or cancel. The line break after every 10th seat (or after the last seat) comes from `s % 10 == 0 || s == seats`.

### Concepts Practiced
- Array of flags
- Bounds checking before indexing
- Sentinel-controlled loop
- Formatted grid output

## Problem 8: Shuttle On-Time Streak
**Level:** Challenging

### Scenario
The transport office records for each day whether the morning shuttle arrived on time (`1`) or late (`0`). For their monthly report they want the longest run of consecutive on-time days, the days the bus was late, and the overall on-time rate.

### Problem Statement
Read `N` (1–31) and then `N` values, each 0 or 1, into an array. If `N` is out of range, print `Invalid number of days`; if a value is not 0 or 1, print `Invalid record on day <d>` and stop.

Find the longest run of consecutive 1s (the first one if there is a tie). Print exactly:
```text
Longest on-time streak: <len> days (day <start> to day <end>)
Late on days: <d1> <d2> ...
On-time rate: <rate, 2 decimals> percent
```
If there is no on-time day, the first line is `Longest on-time streak: 0 days`. If there is no late day, the second line is `Late on days: none`.

### Sample Input
```text
14
1 1 0 1 1 1 1 0 0 1 1 1 1 0
```

### Sample Output
```text
Longest on-time streak: 4 days (day 4 to day 7)
Late on days: 3 8 9 14
On-time rate: 71.43 percent
```

### Solution
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    if (n < 1 || n > 31) {
        printf("Invalid number of days\n");
        return 0;
    }

    int record[31];
    for (int i = 0; i < n; i++) {
        scanf("%d", &record[i]);
        if (record[i] != 0 && record[i] != 1) {
            printf("Invalid record on day %d\n", i + 1);
            return 0;
        }
    }

    int best = 0, bestStart = 0;
    int current = 0, currentStart = 0;
    int onTime = 0;

    for (int i = 0; i < n; i++) {
        if (record[i] == 1) {
            if (current == 0) currentStart = i;     /* a new streak begins */
            current++;
            onTime++;
            if (current > best) {                   /* strict: keep the first on ties */
                best = current;
                bestStart = currentStart;
            }
        } else {
            current = 0;                            /* streak broken */
        }
    }

    if (best == 0) {
        printf("Longest on-time streak: 0 days\n");
    } else {
        printf("Longest on-time streak: %d days (day %d to day %d)\n",
               best, bestStart + 1, bestStart + best);
    }

    printf("Late on days:");
    if (onTime == n) {
        printf(" none");
    } else {
        for (int i = 0; i < n; i++) {
            if (record[i] == 0) printf(" %d", i + 1);
        }
    }
    printf("\n");

    printf("On-time rate: %.2f percent\n", onTime * 100.0 / n);
    return 0;
}
```

### Explanation
The scan keeps two streaks: the **current** one (reset to 0 on a late day) and the **best** one seen so far. When a 1 follows a 0 (or starts the array), `current` is 0, so that index is remembered as the start of a new streak. Whenever the current streak becomes longer than the best, the best is replaced.

In the sample there are streaks of 2 (days 1–2), 4 (days 4–7) and 4 (days 10–13). Because the comparison is strict, the second streak of 4 does not replace the first.

Day numbers are indexes + 1, and the end day of a streak is `start + length − 1` in indexes, which becomes `bestStart + best` in day numbers. The rate is 10 on-time days out of 14 = 71.43%.

- Array scan with state
- Longest run (streak) pattern
- Index and day-number conversion
- Validation while reading
