# Scenario-Based Problems

These are small projects: each combines loops, decisions, arrays, strings and functions into a complete program that processes a stream of commands or records. Plan before you code: list the data the program must remember (often a few arrays), the commands it must handle, and what is printed for each one. Then write one function or one `case` per command.

Programs read input without prompts and print exactly the sample output, so they can be checked automatically. Prices, fees and rules are fictional.

## Problem 1: Canteen Order Counter
**Level:** Moderate

### Scenario
The canteen near the CSE building takes group orders on a tablet. The cashier enters an item code and a quantity for each line of the order; `0 0` finishes the order. The menu is: 1 Khichuri (120 Tk), 2 Burger (150 Tk), 3 Tea (15 Tk), 4 Singara (10 Tk). Orders of 1000 Tk or more get a 5% discount, and 5% VAT is added after the discount.

### Problem Statement
Store the item names in an array of strings and the prices in an `int` array. Read order lines until `0 0`:

- unknown code → print `Invalid item code: <code>` and ignore the line;
- quantity 0 or less → print `Invalid quantity: <qty>` and ignore the line;
- otherwise add the quantity to that item's running count (the same item may appear more than once).

At the end, if nothing was ordered print `No items ordered`. Otherwise print one line per item that was ordered (menu order), then the bill:
```text
<name> x <qty> = <amount> Tk
...
Subtotal: <subtotal> Tk
Discount: <discount> Tk
VAT: <vat> Tk
Total: <total> Tk
```
Money in the bill uses two decimals.

### Sample Input
```text
1 2
3 4
5 1
2 0
2 3
0 0
```

### Sample Output
```text
Invalid item code: 5
Invalid quantity: 0
Khichuri x 2 = 240 Tk
Burger x 3 = 450 Tk
Tea x 4 = 60 Tk
Subtotal: 750.00 Tk
Discount: 0.00 Tk
VAT: 37.50 Tk
Total: 787.50 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    char names[4][10] = {"Khichuri", "Burger", "Tea", "Singara"};
    int prices[4] = {120, 150, 15, 10};
    int qty[4] = {0, 0, 0, 0};

    int code, amount;
    scanf("%d %d", &code, &amount);
    while (!(code == 0 && amount == 0)) {
        if (code < 1 || code > 4) {
            printf("Invalid item code: %d\n", code);
        } else if (amount <= 0) {
            printf("Invalid quantity: %d\n", amount);
        } else {
            qty[code - 1] += amount;
        }
        scanf("%d %d", &code, &amount);
    }

    int subtotal = 0;
    for (int i = 0; i < 4; i++) {
        subtotal += qty[i] * prices[i];
    }
    if (subtotal == 0) {
        printf("No items ordered\n");
        return 0;
    }

    for (int i = 0; i < 4; i++) {
        if (qty[i] > 0) {
            printf("%s x %d = %d Tk\n", names[i], qty[i], qty[i] * prices[i]);
        }
    }

    double discount = 0;
    if (subtotal >= 1000) {
        discount = subtotal * 5 / 100.0;
    }
    double vat = (subtotal - discount) * 5 / 100;
    double total = subtotal - discount + vat;

    printf("Subtotal: %.2f Tk\n", (double) subtotal);
    printf("Discount: %.2f Tk\n", discount);
    printf("VAT: %.2f Tk\n", vat);
    printf("Total: %.2f Tk\n", total);
    return 0;
}
```

### Explanation
Three arrays share the same index: `names[i]`, `prices[i]` and `qty[i]` all describe menu item `i + 1`. That lets one loop print the whole bill, and adding a fifth item would only mean extending the arrays.

Quantities are **accumulated** (`qty[code - 1] += amount`) rather than printed immediately, so repeated items are merged into one line and the bill comes out in menu order. Invalid lines are reported as they arrive and never reach the totals.

The loop stops only on `0 0`; a line like `2 0` is an invalid quantity, not the end of the order. The bill: 240 + 450 + 60 = 750, below the 1000 Tk discount threshold, so VAT is 5% of 750 = 37.50.

### Concepts Practiced
- Parallel arrays including an array of strings
- Sentinel loop with a two-value sentinel
- Accumulating counts per item
- Discount and VAT order of operations

## Problem 2: Quiz Auto-Grader
**Level:** Moderate

### Scenario
A teaching assistant runs a multiple-choice quiz with negative marking: +1 for a correct answer, −0.25 for a wrong answer, and 0 for a skipped question (marked `-`). Answer sheets are scanned into strings like `ABCAD-BA`. The assistant wants every student's score and the top scorer.

### Problem Statement
Read the answer key (one word, up to 20 characters), then `N`, then `N` lines, each with a roll number and an answer string. For each student:

- if the answer string's length differs from the key's, print `<roll>: answer sheet has wrong length`;
- otherwise print `<roll>: <c> correct, <w> wrong, <s> skipped, score <score, 2 decimals>`.

Finally print `Top scorer: <roll> (<score>)` (first one on a tie), or `No valid answer sheets` if none was valid.

### Sample Input
```text
ABCDDCBA
3
101 ABCDDCBA
102 ABCAD-BA
103 BBBBBBBB
```

### Sample Output
```text
101: 8 correct, 0 wrong, 0 skipped, score 8.00
102: 6 correct, 1 wrong, 1 skipped, score 5.75
103: 2 correct, 6 wrong, 0 skipped, score 0.50
Top scorer: 101 (8.00)
```

### Solution
```c
#include <stdio.h>
#include <string.h>

int main() {
    char key[25];
    int n;
    scanf("%24s %d", key, &n);
    int q = strlen(key);

    int bestRoll = 0, haveBest = 0;
    double bestScore = 0;

    for (int k = 0; k < n; k++) {
        int roll;
        char ans[25];
        scanf("%d %24s", &roll, ans);

        if ((int) strlen(ans) != q) {
            printf("%d: answer sheet has wrong length\n", roll);
            continue;
        }

        int correct = 0, wrong = 0, skipped = 0;
        for (int i = 0; i < q; i++) {
            if (ans[i] == '-') skipped++;
            else if (ans[i] == key[i]) correct++;
            else wrong++;
        }
        double score = correct - 0.25 * wrong;
        printf("%d: %d correct, %d wrong, %d skipped, score %.2f\n",
               roll, correct, wrong, skipped, score);

        if (!haveBest || score > bestScore) {
            haveBest = 1;
            bestScore = score;
            bestRoll = roll;
        }
    }

    if (haveBest) {
        printf("Top scorer: %d (%.2f)\n", bestRoll, bestScore);
    } else {
        printf("No valid answer sheets\n");
    }
    return 0;
}
```

### Explanation
The key and each answer sheet are compared position by position: the same index `i` refers to the same question in both strings. A skipped mark is checked **first**, so `-` is never counted as wrong.

Student 102: positions 1–3 match, position 4 is wrong (A instead of D), position 6 is skipped, and the other three match: 6 − 0.25 × 1 = 5.75.

A score can be negative (all wrong), so the best score cannot start at 0. The `haveBest` flag records whether any valid sheet has been seen; the first valid sheet always becomes the best, and later ones replace it only with a strictly higher score.

### Concepts Practiced
- Comparing two strings character by character
- Negative marking with doubles
- Flag for "no valid data yet"
- Reading words with width limits

### Test Cases

**Input**

```text
2 ----

```
**Expected Output**
```text

```

#### No valid sheets



## Problem 3: Library Fine System
**Level:** Intermediate

### Scenario
The central library records each returned book with the member type and the day of the year (1–365) the book was borrowed and returned. Students may keep a book 14 days and pay 5 Tk per late day, with a maximum fine of 300 Tk. Teachers may keep a book 30 days and pay 2 Tk per late day, with a maximum fine of 100 Tk. (Rules are fictional.)

### Problem Statement
Write three small functions that use `switch` on the member type: `int allowedDays(char type)` (returning −1 for an unknown type), `int ratePerDay(char type)` and `int maxFine(char type)`.

Read `N`, then `N` lines `type borrowDay returnDay`. For line `k` print:

- `<k>: unknown member type` if the type is not `S` or `T`;
- `<k>: invalid dates` if a day is outside 1–365 or the return day is before the borrow day;
- otherwise `<k>: kept <d> days, late <l> days, fine <f> Tk`, with ` (capped)` added when the maximum fine was applied.

Finally print `Total fines: <total> Tk`.

### Sample Input
```text
4
S 10 30
T 40 75
S 100 200
X 1 2
```

### Sample Output
```text
1: kept 20 days, late 6 days, fine 30 Tk
2: kept 35 days, late 5 days, fine 10 Tk
3: kept 100 days, late 86 days, fine 300 Tk (capped)
4: unknown member type
Total fines: 340 Tk
```

### Solution
```c
#include <stdio.h>

int allowedDays(char type) {
    switch (type) {
        case 'S': return 14;
        case 'T': return 30;
        default: return -1;
    }
}

int ratePerDay(char type) {
    switch (type) {
        case 'S': return 5;
        default: return 2;
    }
}

int maxFine(char type) {
    switch (type) {
        case 'S': return 300;
        default: return 100;
    }
}

int main() {
    int n, total = 0;
    scanf("%d", &n);

    for (int k = 1; k <= n; k++) {
        char type;
        int borrow, ret;
        scanf(" %c %d %d", &type, &borrow, &ret);

        if (allowedDays(type) < 0) {
            printf("%d: unknown member type\n", k);
            continue;
        }
        if (borrow < 1 || borrow > 365 || ret < 1 || ret > 365 || ret < borrow) {
            printf("%d: invalid dates\n", k);
            continue;
        }

        int kept = ret - borrow;
        int late = kept - allowedDays(type);
        if (late < 0) late = 0;

        int fine = late * ratePerDay(type);
        int capped = 0;
        if (fine > maxFine(type)) {
            fine = maxFine(type);
            capped = 1;
        }
        total += fine;

        printf("%d: kept %d days, late %d days, fine %d Tk", k, kept, late, fine);
        if (capped) printf(" (capped)");
        printf("\n");
    }
    printf("Total fines: %d Tk\n", total);
    return 0;
}
```

### Explanation
Each rule that depends on the member type lives in its own small function, so adding a new member type (for example staff) means adding one `case` to each function, without touching `main`. `allowedDays` returns −1 for an unknown type, which `main` uses as a validity check.

For the third record: kept 100 days, 86 days late, 86 × 5 = 430 Tk, which is above the student maximum, so the fine is 300 and marked as capped.

Validation happens before any calculation, and `continue` moves to the next record, so invalid lines never affect the total. The space in `" %c"` skips the newline left over from the previous line.

### Concepts Practiced
- Small functions with switch
- Sentinel return value (−1) for invalid input
- Caps with a flag
- Validation before calculation
- Running total across records

### Test Cases
#### On time, boundary and invalid dates
**Input**
```text
4
S 50 50
T 1 31
S 30 20
T 1 365
```
**Expected Output**
```text

2: kept 30 days, late 0 days, fine 0 Tk
3: invalid dates
4: kept 364 days, late 334 days, fine 100 Tk (capped)
Total fines: 100 Tk
```

## Problem 4: Lab Inventory Tracker
**Level:** Intermediate

### Scenario
The networking lab lends equipment (mice, keyboards, cables) to students. The lab assistant records every issue and return. The program must refuse to issue more items than are in stock, and at the end of the day it must show the stock and warn about items running low (fewer than 3 left).

### Problem Statement
Read `M` (1–20) items, each as `name stock` (the name is one word). Then read commands until `X`:

- `I id qty`: issue `qty` of item `id` (1-based). If the stock is too small, print `Cannot issue <qty> <name> (only <stock> in stock)`; otherwise print `Issued <qty> <name>`.
- `R id qty`: return items, print `Returned <qty> <name>`.
- A bad item number prints `Invalid item <id>`; a quantity of 0 or less prints `Invalid quantity`; any other command letter prints `Unknown command` (it still has an id and a quantity after it).

After `X`, print:
```text
Final stock:
<name>: <stock>
...
Low stock: <names separated by spaces, or none>
```

### Sample Input
```text
3
Mouse 10
Keyboard 5
HDMI_Cable 4
I 1 3
I 3 2
I 2 6
R 1 1
I 3 2
I 4 1
X
```

### Sample Output
```text
Issued 3 Mouse
Issued 2 HDMI_Cable
Cannot issue 6 Keyboard (only 5 in stock)
Returned 1 Mouse
Issued 2 HDMI_Cable
Invalid item 4
Final stock:
Mouse: 8
Keyboard: 5
HDMI_Cable: 0
Low stock: HDMI_Cable
```

### Solution
```c
#include <stdio.h>

int main() {
    int m;
    scanf("%d", &m);
    if (m > 20) m = 20;

    char name[20][30];
    int stock[20];
    for (int i = 0; i < m; i++) {
        scanf("%29s %d", name[i], &stock[i]);
    }

    char cmd;
    scanf(" %c", &cmd);
    while (cmd != 'X') {
        int id, qty;
        scanf("%d %d", &id, &qty);

        if (cmd != 'I' && cmd != 'R') {
            printf("Unknown command\n");
        } else if (id < 1 || id > m) {
            printf("Invalid item %d\n", id);
        } else if (qty <= 0) {
            printf("Invalid quantity\n");
        } else if (cmd == 'I') {
            if (qty > stock[id - 1]) {
                printf("Cannot issue %d %s (only %d in stock)\n", qty, name[id - 1], stock[id - 1]);
            } else {
                stock[id - 1] -= qty;
                printf("Issued %d %s\n", qty, name[id - 1]);
            }
        } else {
            stock[id - 1] += qty;
            printf("Returned %d %s\n", qty, name[id - 1]);
        }
        scanf(" %c", &cmd);
    }

    printf("Final stock:\n");
    for (int i = 0; i < m; i++) {
        printf("%s: %d\n", name[i], stock[i]);
    }

    printf("Low stock:");
    int anyLow = 0;
    for (int i = 0; i < m; i++) {
        if (stock[i] < 3) {
            printf(" %s", name[i]);
            anyLow = 1;
        }
    }
    if (!anyLow) printf(" none");
    printf("\n");
    return 0;
}
```

### Explanation
The inventory is two parallel arrays: `name[i]` (an array of strings) and `stock[i]`. Item numbers typed by the user start at 1, so every access uses `id − 1`, and the range check `1 ≤ id ≤ m` happens **before** any array access.

The command letter is read first with `" %c"`; the numbers that follow are read only for `I`/`R`-style lines. Validation is ordered from general to specific (command → item → quantity → stock), and an `else if` chain ensures one message per command.

The stock rule is the business rule: an issue that would make the stock negative is refused and nothing changes. Returns have no upper limit.

### Concepts Practiced
- Array of strings with parallel int array
- Command-processing loop
- Bounds checks before indexing
- Business rule that rejects an operation

## Problem 5: Tic-Tac-Toe Result Checker
**Level:** Intermediate

### Scenario
The CSE fest has a tic-tac-toe competition. Volunteers type the final boards into a program that announces the result. X always moves first. Some typed boards are impossible (for example, both players have three in a row), and the program must catch those too.

### Problem Statement
Read 3 lines of 3 characters each: `X`, `O` or `.` (empty). Store them in a `char board[3][4]` array. Print exactly one of:

- `Invalid board`: a character other than `X`, `O`, `.`; or the counts are impossible (X must equal O or O + 1); or both players have a line; or X has a line but X ≠ O + 1; or O has a line but X ≠ O;
- `X wins` / `O wins`;
- `Draw` (board full, no line);
- `Game in progress`.

Write a function `int hasLine(char board[3][4], char p)` that returns 1 if player `p` has three in a row (row, column or diagonal).

### Sample Input
```text
XOX
OXO
..X
```

### Sample Output
```text
X wins
```

### Solution
```c
#include <stdio.h>

int hasLine(char board[3][4], char p) {
    for (int i = 0; i < 3; i++) {
        if (board[i][0] == p && board[i][1] == p && board[i][2] == p) return 1;   /* row */
        if (board[0][i] == p && board[1][i] == p && board[2][i] == p) return 1;   /* column */
    }
    if (board[0][0] == p && board[1][1] == p && board[2][2] == p) return 1;
    if (board[0][2] == p && board[1][1] == p && board[2][0] == p) return 1;
    return 0;
}

int main() {
    char board[3][4];
    for (int i = 0; i < 3; i++) {
        scanf("%3s", board[i]);
    }

    int x = 0, o = 0;
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            char c = board[i][j];
            if (c == 'X') x++;
            else if (c == 'O') o++;
            else if (c != '.') {
                printf("Invalid board\n");
                return 0;
            }
        }
    }

    int xLine = hasLine(board, 'X');
    int oLine = hasLine(board, 'O');

    if ((x != o && x != o + 1) || (xLine && oLine)
        || (xLine && x != o + 1) || (oLine && x != o)) {
        printf("Invalid board\n");
    } else if (xLine) {
        printf("X wins\n");
    } else if (oLine) {
        printf("O wins\n");
    } else if (x + o == 9) {
        printf("Draw\n");
    } else {
        printf("Game in progress\n");
    }
    return 0;
}
```

### Explanation
Each row is read as a 3-character string, so `board[i]` needs 4 characters (3 plus `'\0'`). The `%3s` width keeps the input inside the row.

The game rules give the consistency checks:

- X moves first and players alternate, so X has either the same number of marks as O or one more.
- The game stops at the first line. If X won, X made the last move, so X = O + 1; if O won, X = O.

The sample has X = 4 and O = 3 and an X diagonal, which is consistent, so X wins. The board `XOX / OXO / O.X` would also show an X diagonal, but with X = 4 and O = 4 it could never happen in a real game, so it is invalid.

Passing the 2D array to `hasLine` lets the same function check either player.

### Concepts Practiced
- 2D char array read row by row
- Function taking a 2D array
- Counting with nested loops
- Validating a state with logical rules

## Problem 6: Mobile Wallet Simulator
**Level:** Challenging

### Scenario
To understand mobile banking, a student builds a simulator of a (fictional) wallet. Commands: `D amount` (cash in, free), `S amount` (send money, 5 Tk fee per send), `C amount` (cash out, fee 1.85% of the amount), `B` (show balance) and `Q` (quit). The balance can never go below zero, and the total sent in a day cannot exceed 25000 Tk.

### Problem Statement
Start with balance 0. Process commands until `Q`:

- `D`: add the amount; print `Deposited <a>, balance <b>`.
- `S`: if the day's sent total plus this amount exceeds 25000, print `Daily send limit exceeded`; else if amount + 5 is more than the balance, print `Insufficient balance`; else deduct it and print `Sent <a> (fee 5.00), balance <b>`.
- `C`: if amount + fee is more than the balance, print `Insufficient balance`; else deduct it and print `Cashed out <a> (fee <f>), balance <b>`.
- `B`: print `Balance: <b>`.
- An amount of 0 or less prints `Invalid amount`; an unknown letter prints `Unknown command` (it is followed by an amount).

When `Q` is read, print `Successful transactions: <n>`, `Fees paid: <total fees>` and `Final balance: <b>`. Money uses two decimals. Write one function per command.

### Sample Input
```text
D 5000
S 1200
C 1000
C 4000
B
S 30000
Q
```

### Sample Output
```text
Deposited 5000.00, balance 5000.00
Sent 1200.00 (fee 5.00), balance 3795.00
Cashed out 1000.00 (fee 18.50), balance 2776.50
Insufficient balance
Balance: 2776.50
Daily send limit exceeded
Successful transactions: 3
Fees paid: 23.50
Final balance: 2776.50
```

### Solution
```c
#include <stdio.h>

double balance = 0, sentToday = 0, feesPaid = 0;
int successful = 0;

void deposit(double amount) {
    balance += amount;
    successful++;
    printf("Deposited %.2f, balance %.2f\n", amount, balance);
}

void sendMoney(double amount) {
    double fee = 5.0;
    if (sentToday + amount > 25000) {
        printf("Daily send limit exceeded\n");
    } else if (amount + fee > balance) {
        printf("Insufficient balance\n");
    } else {
        balance -= amount + fee;
        sentToday += amount;
        feesPaid += fee;
        successful++;
        printf("Sent %.2f (fee %.2f), balance %.2f\n", amount, fee, balance);
    }
}

void cashOut(double amount) {
    double fee = amount * 1.85 / 100;
    if (amount + fee > balance) {
        printf("Insufficient balance\n");
    } else {
        balance -= amount + fee;
        feesPaid += fee;
        successful++;
        printf("Cashed out %.2f (fee %.2f), balance %.2f\n", amount, fee, balance);
    }
}

int main() {
    char cmd;
    while (scanf(" %c", &cmd) == 1 && cmd != 'Q') {
        if (cmd == 'B') {
            printf("Balance: %.2f\n", balance);
            continue;
        }

        double amount;
        scanf("%lf", &amount);

        if (cmd != 'D' && cmd != 'S' && cmd != 'C') {
            printf("Unknown command\n");
        } else if (amount <= 0) {
            printf("Invalid amount\n");
        } else if (cmd == 'D') {
            deposit(amount);
        } else if (cmd == 'S') {
            sendMoney(amount);
        } else {
            cashOut(amount);
        }
    }

    printf("Successful transactions: %d\n", successful);
    printf("Fees paid: %.2f\n", feesPaid);
    printf("Final balance: %.2f\n", balance);
    return 0;
}
```

### Explanation
The wallet's state (balance, amount sent today, fees, count) is shared by every command, so it is kept in **global variables** declared outside all functions. Each command function reads and updates that state. In larger programs you will learn to pass such data around instead, but globals keep this first version simple.

Every check uses the **total** cost: sending 1200 costs 1205; cashing out 1000 costs 1000 + 18.50. The fourth command (cash out 4000) would need 4074.00 but only 2776.50 is left, so it is refused and nothing changes. The send of 30000 fails the daily limit before the balance is even considered, as the rule order says.

`while (scanf(" %c", &cmd) == 1 && cmd != 'Q')` also stops safely if the input ends without `Q`: `scanf` returns the number of values it read, which is not 1 at the end of the input.

### Concepts Practiced
- One function per command
- Global variables for shared state
- Fees and limits checked before updating
- scanf return value in a loop condition

### Test Cases
#### Quit immediately
**Input**

## Problem 7: Train Seat Allocation
**Level:** Challenging

### Scenario
A student tour group books train seats. The (simplified) train has `C` coaches with `S` seats each. Each booking request names a preferred coach and a number of seats. The booking system fills the lowest free seats in the preferred coach first; if that coach runs out, it continues in the next coach (after the last coach it wraps to coach 1). A request is either fully booked or not booked at all.

### Problem Statement
Read `C` (1–5) and `S` (1–20), then `R` requests, each `coach count`. Use a 2D array `seat[5][20]` of booked flags. For request `k` print:

- `Request <k>: invalid coach` if the coach is outside 1–C;
- `Request <k>: invalid count` if the count is 0 or less;
- `Request <k>: not enough seats` if fewer free seats than requested exist in the whole train;
- otherwise `Request <k>: ` followed by the booked seats as `C<coach>-<seat>`, separated by spaces.

Finally print `Coach <c>: <booked>/<S> booked` for every coach.

### Sample Input
```text
3 4
4
2 3
2 2
1 4
3 4
```

### Sample Output
```text
Request 1: C2-1 C2-2 C2-3
Request 2: C2-4 C3-1
Request 3: C1-1 C1-2 C1-3 C1-4
Request 4: not enough seats
Coach 1: 4/4 booked
Coach 2: 4/4 booked
Coach 3: 1/4 booked
```

### Solution
```c
#include <stdio.h>

int seat[5][20];
int coaches, seatsPerCoach;

int freeSeats(void) {
    int count = 0;
    for (int c = 0; c < coaches; c++)
        for (int s = 0; s < seatsPerCoach; s++)
            if (!seat[c][s]) count++;
    return count;
}

int main() {
    int requests;
    scanf("%d %d %d", &coaches, &seatsPerCoach, &requests);

    for (int k = 1; k <= requests; k++) {
        int preferred, count;
        scanf("%d %d", &preferred, &count);

        if (preferred < 1 || preferred > coaches) {
            printf("Request %d: invalid coach\n", k);
            continue;
        }
        if (count <= 0) {
            printf("Request %d: invalid count\n", k);
            continue;
        }
        if (freeSeats() < count) {
            printf("Request %d: not enough seats\n", k);
            continue;
        }

        printf("Request %d:", k);
        int booked = 0;
        for (int step = 0; step < coaches && booked < count; step++) {
            int c = (preferred - 1 + step) % coaches;     /* wrap around */
            for (int s = 0; s < seatsPerCoach && booked < count; s++) {
                if (!seat[c][s]) {
                    seat[c][s] = 1;
                    booked++;
                    printf(" C%d-%d", c + 1, s + 1);
                }
            }
        }
        printf("\n");
    }

    for (int c = 0; c < coaches; c++) {
        int used = 0;
        for (int s = 0; s < seatsPerCoach; s++) used += seat[c][s];
        printf("Coach %d: %d/%d booked\n", c + 1, used, seatsPerCoach);
    }
    return 0;
}
```

### Explanation
The seat map is a 2D array of flags: `seat[c][s]` is 1 when seat `s + 1` of coach `c + 1` is booked. Global arrays start filled with zeros, so every seat starts free.

"All or nothing" is achieved by checking the total free seats **before** booking anything. Without that check, request 4 would book three seats in coach 3 and then fail, leaving the group split and partly booked.

The search starts at the preferred coach and wraps around with `% coaches`: from coach 2 in a 3-coach train it visits 2, 3, 1. Both loops also stop as soon as `booked == count`, so no extra seats are taken.

### Concepts Practiced
- 2D array of flags
- Wrap-around with modulus
- All-or-nothing check before changes
- Loop conditions with two stopping rules
- Helper function over a 2D array

## Problem 8: Inter-Department Football Table
**Level:** Challenging

### Scenario
The university sports committee runs a football league between departments. After each round, the committee publishes a points table: a win is worth 3 points, a draw 1, a loss 0. Teams are ranked by points, then goal difference, then goals scored, and finally alphabetically by name.

### Problem Statement
Read `T` (2–8) team names (one word each), then `M` match results, each `i j gi gj` (team `i` scored `gi` goals against team `j`; teams numbered from 1). A match with a bad team number, a team playing itself, or a negative score prints `Match <k>: invalid` and is ignored.

Then print the table:
```text
Team      P  W  D  L  GF  GA  GD  Pts
<name>  ...
```
using `printf("%-8s%3s%3s%3s%3s%4s%4s%4s%5s\n", ...)` for the header and `printf("%-8s%3d%3d%3d%3d%4d%4d%+4d%5d\n", ...)` for each team, sorted as described. Sort an array of team **indexes** instead of moving all the statistics around.

### Sample Input
```text
4
CSE EEE BBA CIVIL
5
1 2 2 1
3 4 0 0
1 3 1 1
2 4 3 0
4 1 1 2
```

### Sample Output
```text
Team      P  W  D  L  GF  GA  GD  Pts
CSE       3  2  1  0   5   3  +2    7
EEE       2  1  0  1   4   2  +2    3
BBA       2  0  2  0   1   1  +0    2
CIVIL     3  0  1  2   1   5  -4    1
```

### Solution
```c
#include <stdio.h>
#include <string.h>

char name[8][20];
int played[8], won[8], drawn[8], lost[8], goalsFor[8], goalsAgainst[8];

int points(int t) { return 3 * won[t] + drawn[t]; }
int goalDiff(int t) { return goalsFor[t] - goalsAgainst[t]; }

/* 1 if team a should be listed before team b */
int ranksAbove(int a, int b) {
    if (points(a) != points(b)) return points(a) > points(b);
    if (goalDiff(a) != goalDiff(b)) return goalDiff(a) > goalDiff(b);
    if (goalsFor[a] != goalsFor[b]) return goalsFor[a] > goalsFor[b];
    return strcmp(name[a], name[b]) < 0;
}

void record(int t, int scored, int conceded) {
    played[t]++;
    goalsFor[t] += scored;
    goalsAgainst[t] += conceded;
    if (scored > conceded) won[t]++;
    else if (scored == conceded) drawn[t]++;
    else lost[t]++;
}

int main() {
    int teams, matches;
    scanf("%d", &teams);
    for (int t = 0; t < teams; t++) {
        scanf("%19s", name[t]);
    }

    scanf("%d", &matches);
    for (int k = 1; k <= matches; k++) {
        int i, j, gi, gj;
        scanf("%d %d %d %d", &i, &j, &gi, &gj);
        if (i < 1 || i > teams || j < 1 || j > teams || i == j || gi < 0 || gj < 0) {
            printf("Match %d: invalid\n", k);
            continue;
        }
        record(i - 1, gi, gj);
        record(j - 1, gj, gi);
    }

    int order[8];
    for (int t = 0; t < teams; t++) order[t] = t;

    for (int pass = 0; pass < teams - 1; pass++) {          /* bubble sort of indexes */
        for (int x = 0; x < teams - 1 - pass; x++) {
            if (ranksAbove(order[x + 1], order[x])) {
                int tmp = order[x];
                order[x] = order[x + 1];
                order[x + 1] = tmp;
            }
        }
    }

    printf("%-8s%3s%3s%3s%3s%4s%4s%4s%5s\n", "Team", "P", "W", "D", "L", "GF", "GA", "GD", "Pts");
    for (int r = 0; r < teams; r++) {
        int t = order[r];
        printf("%-8s%3d%3d%3d%3d%4d%4d%+4d%5d\n", name[t], played[t], won[t], drawn[t],
               lost[t], goalsFor[t], goalsAgainst[t], goalDiff(t), points(t));
    }
    return 0;
}
```

### Explanation
Each match updates **both** teams through the same `record` function, called once from each team's point of view (scored and conceded are swapped for the second call). That avoids writing the win/draw/loss logic twice.

Sorting moves only small integers: `order[]` lists team indexes, and bubble sort rearranges it using `ranksAbove`, which applies the four tie-breakers in priority order. The statistics arrays never move, so `name[t]`, `won[t]` and the rest stay consistent automatically.

In the sample, CSE and EEE both have goal difference +2, but CSE has more points, so the GD tie-breaker is never needed. `%-8s` left-aligns the name in 8 characters, and `%+4d` always prints a sign, so the GD column reads +2, +0, −4.

### Concepts Practiced
- Several parallel arrays in a project
- Function reused from both teams' perspectives
- Multi-key comparison function
- Sorting an index array
- printf alignment with `%-8s` and `%+4d`
