# Scenario-Based Problems

These problems practise choosing the right data type, storing values in variables, calculating with them, and printing them with the right format specifier (`%d`, `%f`, `%.2f`, `%c`). Reading input comes in Chapter 03, so all values are given in the problem: store each one in a well-named variable instead of typing numbers directly into `printf`. Money is stored as `double` and printed with two decimals.

Because these programs have no input, their test cases change a value in the code (shown as **Change** `old` → `new`) and give the new expected output.

## Problem 1: Student Profile Card
**Level:** Moderate

### Scenario
The department's advising office prints a one-screen profile for each student before an advising meeting. The profile shows the roll number, section, CGPA, and how many credits are completed and remaining in a 140-credit degree.

### Problem Statement
Store the following in variables of suitable types:

- roll number: 1052
- section: `B`
- CGPA: 3.67
- credits completed: 48
- total credits required for the degree: 140

Calculate the remaining credits in a separate variable, then print exactly:
```text
Roll: <roll>
Section: <section>
CGPA: <cgpa with 2 decimals>
Credits completed: <completed>
Credits remaining: <remaining>
```

### Sample Input
No input.

### Sample Output
```text
Roll: 1052
Section: B
CGPA: 3.67
Credits completed: 48
Credits remaining: 92
```

### Solution
```c
#include <stdio.h>

int main() {
    int roll = 1052;
    char section = 'B';
    double cgpa = 3.67;
    int creditsCompleted = 48;
    int totalCredits = 140;

    int creditsRemaining = totalCredits - creditsCompleted;

    printf("Roll: %d\n", roll);
    printf("Section: %c\n", section);
    printf("CGPA: %.2f\n", cgpa);
    printf("Credits completed: %d\n", creditsCompleted);
    printf("Credits remaining: %d\n", creditsRemaining);
    return 0;
}
```

### Explanation
Each piece of data gets the type that fits it: whole numbers (`roll`, credits) are `int`, the single letter `section` is `char`, and the CGPA, which has a fractional part, is `double`.

The format specifier must match the type: `%d` for `int`, `%c` for `char`, and `%.2f` for `double` with exactly two decimal places. Using `%d` for the CGPA would print garbage, because the bits of a `double` are not an integer.

Storing `totalCredits` in a variable instead of writing `140 - 48` inside `printf` makes the program easy to update when the rule changes.

### Concepts Practiced
- int, char and double variables
- Format specifiers `%d`, `%c`, `%.2f`
- Arithmetic with variables


#### Different section and CGPA

## Problem 2: Trimester Tuition Estimate
**Level:** Moderate

### Scenario
Before registration, a student wants to estimate what she will pay this trimester. Her university (fictional figures) charges 6500 Tk per credit plus a fixed trimester fee of 7000 Tk. She has a 25% scholarship that applies to the **tuition only**, not to the trimester fee.

### Problem Statement
Store these values in variables: credits taken = 12, per-credit fee = 6500, trimester fee = 7000, scholarship percentage = 25. Calculate:

1. tuition = credits × per-credit fee
2. waiver = tuition × scholarship percentage ÷ 100
3. payable = tuition − waiver + trimester fee

Print exactly (two decimals for money):
```text
Tuition: <tuition> Tk
Waiver: <waiver> Tk
Trimester fee: <fee> Tk
Payable: <payable> Tk
```

### Sample Input
No input.

### Sample Output
```text
Tuition: 78000.00 Tk
Waiver: 19500.00 Tk
Trimester fee: 7000.00 Tk
Payable: 65500.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    int credits = 12;
    double perCredit = 6500.0;
    double trimesterFee = 7000.0;
    double scholarshipPercent = 25.0;

    double tuition = credits * perCredit;
    double waiver = tuition * scholarshipPercent / 100.0;
    double payable = tuition - waiver + trimesterFee;

    printf("Tuition: %.2f Tk\n", tuition);
    printf("Waiver: %.2f Tk\n", waiver);
    printf("Trimester fee: %.2f Tk\n", trimesterFee);
    printf("Payable: %.2f Tk\n", payable);
    return 0;
}
```

### Explanation
The key detail is the **base** of the percentage: the scholarship is 25% of the tuition (78000 Tk), not of tuition plus trimester fee. So the waiver is 78000 × 25 ÷ 100 = 19500, and the payable amount is 78000 − 19500 + 7000 = 65500.

If the waiver were (wrongly) taken on the full 85000, the student would expect to pay 63750 and be surprised at the bank.

`credits` is an `int`, but `credits * perCredit` is calculated as a `double` because one operand is a `double`.

### Concepts Practiced
- double variables for money
- Percentage of a specific base
- Mixed int and double arithmetic
- Format specifier `%.2f`

## Problem 3: Group Lunch Split
**Level:** Intermediate

### Scenario
Four friends have lunch at the campus cafeteria after a lab. They order 3 plates of chicken khichuri (120 Tk each), 2 lemonades (40 Tk each) and 4 singaras (10 Tk each). The cafeteria adds 5% VAT to the subtotal, and the friends split the final bill equally.

### Problem Statement
Store each price, each quantity, the VAT rate and the number of friends in variables. Calculate the subtotal, the VAT (5% of the subtotal), the total, and each person's share.

Print exactly:
```text
Subtotal: <subtotal> Tk
VAT: <vat> Tk
Total: <total> Tk
Each pays: <share> Tk
```
All amounts are printed with two decimals.

### Sample Input
No input.

### Sample Output
```text
Subtotal: 480.00 Tk
VAT: 24.00 Tk
Total: 504.00 Tk
Each pays: 126.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double khichuriPrice = 120, lemonadePrice = 40, singaraPrice = 10;
    int khichuriQty = 3, lemonadeQty = 2, singaraQty = 4;
    double vatPercent = 5;
    int friends = 4;

    double subtotal = khichuriPrice * khichuriQty
                    + lemonadePrice * lemonadeQty
                    + singaraPrice * singaraQty;
    double vat = subtotal * vatPercent / 100;
    double total = subtotal + vat;
    double share = total / friends;

    printf("Subtotal: %.2f Tk\n", subtotal);
    printf("VAT: %.2f Tk\n", vat);
    printf("Total: %.2f Tk\n", total);
    printf("Each pays: %.2f Tk\n", share);
    return 0;
}
```

### Explanation
The calculation follows the order a cashier would use: line totals → subtotal → VAT on the subtotal → total → split.

- Subtotal = 3 × 120 + 2 × 40 + 4 × 10 = 360 + 80 + 40 = 480
- VAT = 480 × 5 ÷ 100 = 24
- Total = 504, and each of 4 friends pays 126

Multiplication happens before addition in C (operator precedence), so the subtotal expression needs no extra brackets. Because the prices are `double`, dividing the total by the `int` number of friends gives a decimal result, not a truncated whole number.

### Concepts Practiced
- double and int variables
- Operator precedence
- Percentage calculation
- Format specifier `%.2f`

## Problem 4: Integer vs Decimal Average
**Level:** Intermediate

### Scenario
A teaching assistant calculates quiz averages with a C program and notices that a student with marks 17, 18 and 14 gets an average of exactly 16, while her calculator says 16.33. The student is not happy. You are asked to show where the difference comes from.

### Problem Statement
Store the three marks in `int` variables and their total in an `int`. Then print:

1. the average using **integer** division (`total / 3`), and
2. the average using **decimal** division, printed with two decimals.

Print exactly:
```text
Total marks: <total>
Average (int division): <int average>
Average (decimal division): <decimal average>
```

### Sample Input
No input.

### Sample Output
```text
Total marks: 49
Average (int division): 16
Average (decimal division): 16.33
```

### Solution
```c
#include <stdio.h>

int main() {
    int quiz1 = 17, quiz2 = 18, quiz3 = 14;
    int total = quiz1 + quiz2 + quiz3;

    int intAverage = total / 3;          /* both operands int: fraction dropped */
    double realAverage = total / 3.0;    /* 3.0 is a double: fraction kept */

    printf("Total marks: %d\n", total);
    printf("Average (int division): %d\n", intAverage);
    printf("Average (decimal division): %.2f\n", realAverage);
    return 0;
}
```

### Explanation
When both operands of `/` are integers, C performs integer division and **throws away** the fractional part: 49 / 3 is 16, not 16.33. It does not round; 49 / 3 would still be 16 even if the true answer were 16.99.

Writing `3.0` makes one operand a `double`, so the division is done in floating point and gives 16.333…, printed as 16.33.

A frequent bug is `double avg = total / 3;`: the division is still done with integers first (giving 16), and only then is 16 stored as 16.00. The type of the variable on the left does not change how the right side is calculated.

### Concepts Practiced
- Integer division and truncation
- Floating-point division with a double literal
- int and double variables
- Format specifiers `%d` and `%.2f`

## Problem 5: Road Trip Planner
**Level:** Intermediate

### Scenario
Four friends plan a microbus trip during the trimester break. For planning, they assume a distance of 250 km, an average speed of 50 km/h, a fuel efficiency of 12 km per litre, and a (hypothetical) fuel price of 125 Tk per litre. One mile is 1.60934 km.

### Problem Statement
Store each value in a suitably named variable and calculate:

- the distance in miles,
- the travel time in hours,
- the fuel needed in litres,
- the fuel cost, and
- the fuel cost per person for 4 people.

Print exactly (two decimals for every decimal value):
```text
Distance: <km> km (<miles> miles)
Travel time: <hours> hours
Fuel needed: <litres> litres
Fuel cost: <cost> Tk
Cost per person: <share> Tk
```

### Sample Input
No input.

### Sample Output
```text
Distance: 250.00 km (155.34 miles)
Travel time: 5.00 hours
Fuel needed: 20.83 litres
Fuel cost: 2604.17 Tk
Cost per person: 651.04 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double distanceKm = 250;
    double speedKmh = 50;
    double kmPerLitre = 12;
    double fuelPrice = 125;
    double kmPerMile = 1.60934;
    int people = 4;

    double miles = distanceKm / kmPerMile;
    double hours = distanceKm / speedKmh;
    double litres = distanceKm / kmPerLitre;
    double fuelCost = litres * fuelPrice;
    double perPerson = fuelCost / people;

    printf("Distance: %.2f km (%.2f miles)\n", distanceKm, miles);
    printf("Travel time: %.2f hours\n", hours);
    printf("Fuel needed: %.2f litres\n", litres);
    printf("Fuel cost: %.2f Tk\n", fuelCost);
    printf("Cost per person: %.2f Tk\n", perPerson);
    return 0;
}
```

### Explanation
Every quantity is a `double` because the results have fractional parts. Work out each formula from its units:

- miles = km ÷ (km per mile) = 250 ÷ 1.60934 ≈ 155.34
- hours = km ÷ (km per hour) = 5
- litres = km ÷ (km per litre) = 20.833…
- cost = litres × price = 20.833… × 125 = 2604.166… → printed as 2604.17
- per person = 2604.166… ÷ 4 = 651.041… → 651.04

The program keeps full precision in the variables and only rounds when printing. If you rounded the litres to 20.83 first and then multiplied by 125, you would get 2603.75, a different (less accurate) answer.

### Concepts Practiced
- double variables and unit conversion
- Formulas from units
- Rounding only at output with `%.2f`
- Multiple format specifiers in one printf

## Problem 6: Grades as Characters
**Level:** Challenging

### Scenario
An old grading program stores each letter grade as a single `char`. The developer remembers that characters are stored as numbers (ASCII codes) and wants to use that fact: one grade lower is simply the next letter, and the lowercase form is 32 positions further in the ASCII table.

### Problem Statement
Store the grade `'B'` in a `char` variable. Without writing any other letter in your code, calculate and print:

1. the grade itself,
2. its ASCII code,
3. the grade one step lower (the next letter),
4. its lowercase form (uppercase + 32), and
5. how many steps it is below `A` (the grade minus `'A'`).

Print exactly:
```text
Grade: <grade>
ASCII code: <code>
One grade lower: <next letter>
Lowercase form: <lowercase>
Steps below A: <steps>
```

### Sample Input
No input.

### Sample Output
```text
Grade: B
ASCII code: 66
One grade lower: C
Lowercase form: b
Steps below A: 1
```

### Solution
```c
#include <stdio.h>

int main() {
    char grade = 'B';

    char lower = grade + 1;          /* next letter in ASCII order */
    char lowercase = grade + 32;     /* 'A' is 65, 'a' is 97 */
    int steps = grade - 'A';

    printf("Grade: %c\n", grade);
    printf("ASCII code: %d\n", grade);
    printf("One grade lower: %c\n", lower);
    printf("Lowercase form: %c\n", lowercase);
    printf("Steps below A: %d\n", steps);
    return 0;
}
```

### Explanation
A `char` is stored as a small integer. The same variable prints as a letter with `%c` and as its code with `%d`:

- `'B'` is 66, so `grade + 1` is 67, which is `'C'`.
- Uppercase and lowercase letters are exactly 32 apart (`'A'` = 65, `'a'` = 97), so `66 + 32 = 98` is `'b'`.
- `grade - 'A'` is `66 − 65 = 1`: the letters are consecutive in ASCII, so subtracting `'A'` gives the position in the alphabet counted from 0.

The last trick is used all the time, for example to turn the letter of a row into an array index.

### Concepts Practiced
- char variables and ASCII codes
- Character arithmetic
- Format specifiers `%c` and `%d`

## Problem 7: Internet Package Comparison
**Level:** Challenging

### Scenario
Your hostel room-mates want to buy a mobile internet package valid for 30 days. Package A gives 25 GB for 499 Tk. Package B gives 45 GB for 699 Tk. The one with more data costs more overall, so they argue about which is the better deal. (Package details are fictional.)

### Problem Statement
Store each package's data (GB), price (Tk) and validity (30 days) in variables. Calculate for each package:

- the cost per GB, and
- the cost per day.

Then calculate how much is saved per GB by choosing Package B (A's cost per GB minus B's).

Print exactly (two decimals):
```text
Package A: <A per GB> Tk per GB, <A per day> Tk per day
Package B: <B per GB> Tk per GB, <B per day> Tk per day
Saving per GB with B: <saving> Tk
```

### Sample Input
No input.

### Sample Output
```text
Package A: 19.96 Tk per GB, 16.63 Tk per day
Package B: 15.53 Tk per GB, 23.30 Tk per day
Saving per GB with B: 4.43 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double gbA = 25, priceA = 499;
    double gbB = 45, priceB = 699;
    double days = 30;

    double perGbA = priceA / gbA;
    double perDayA = priceA / days;
    double perGbB = priceB / gbB;
    double perDayB = priceB / days;
    double saving = perGbA - perGbB;

    printf("Package A: %.2f Tk per GB, %.2f Tk per day\n", perGbA, perDayA);
    printf("Package B: %.2f Tk per GB, %.2f Tk per day\n", perGbB, perDayB);
    printf("Saving per GB with B: %.2f Tk\n", saving);
    return 0;
}
```

### Explanation
Comparing prices only (499 vs 699) is misleading because the packages give different amounts of data. A **unit price** (taka per GB) puts them on the same scale:

- A: 499 ÷ 25 = 19.96 Tk per GB
- B: 699 ÷ 45 = 15.533… Tk per GB

So B is cheaper per GB, even though it costs more per day (23.30 vs 16.63). Which is "better" depends on how much data the room-mates actually use, and the program gives them both numbers.

The saving is computed from the unrounded values: 19.96 − 15.533… = 4.4266…, printed as 4.43. Subtracting the rounded values (19.96 − 15.53) would give 4.43 here too, but in general you should round only at the end.

### Concepts Practiced
- double variables
- Unit price (rate) calculations
- Several values in one printf
- Rounding only at output

## Problem 8: Boro Bhai's Tea Stall Accounts
**Level:** Challenging

### Scenario
The elakar boro bhai runs a busy tea stall near the university gate. Today he sold 120 cups of tea at 12 Tk, 45 puris at 5 Tk and 30 singaras at 10 Tk. His costs were 650 Tk for milk and tea leaves, 300 Tk for oil and flour, and 150 Tk for gas. Being a generous boro bhai, he gives 10% of his profit to the neighbourhood football club. He asks you to "make it computer-e" (do it on the computer).

### Problem Statement
Store all quantities, prices and costs in variables. Calculate:

1. revenue (whole taka),
2. total expenses (whole taka),
3. profit = revenue − expenses,
4. the club donation = 10% of profit,
5. what boro bhai keeps = profit − donation, and
6. the profit margin = profit ÷ revenue × 100.

Print exactly:
```text
Revenue: <revenue> Tk
Expenses: <expenses> Tk
Profit: <profit> Tk
Club donation: <donation, 2 decimals> Tk
Boro bhai keeps: <kept, 2 decimals> Tk
Profit margin: <margin, 2 decimals> percent
```

### Sample Input
No input.

### Sample Output
```text
Revenue: 1965 Tk
Expenses: 1100 Tk
Profit: 865 Tk
Club donation: 86.50 Tk
Boro bhai keeps: 778.50 Tk
Profit margin: 44.02 percent
```

### Solution
```c
#include <stdio.h>

int main() {
    int teaCups = 120, teaPrice = 12;
    int puris = 45, puriPrice = 5;
    int singaras = 30, singaraPrice = 10;
    int milkAndLeaves = 650, oilAndFlour = 300, gas = 150;
    double donationPercent = 10;

    int revenue = teaCups * teaPrice + puris * puriPrice + singaras * singaraPrice;
    int expenses = milkAndLeaves + oilAndFlour + gas;
    int profit = revenue - expenses;

    double donation = profit * donationPercent / 100;
    double kept = profit - donation;
    double margin = (double) profit / revenue * 100;

    printf("Revenue: %d Tk\n", revenue);
    printf("Expenses: %d Tk\n", expenses);
    printf("Profit: %d Tk\n", profit);
    printf("Club donation: %.2f Tk\n", donation);
    printf("Boro bhai keeps: %.2f Tk\n", kept);
    printf("Profit margin: %.2f percent\n", margin);
    return 0;
}
```

### Explanation
Whole-taka amounts (revenue, expenses, profit) stay in `int` variables; values that can have paisa (donation, margin) are `double`.

- Revenue = 120 × 12 + 45 × 5 + 30 × 10 = 1440 + 225 + 300 = 1965
- Expenses = 650 + 300 + 150 = 1100, so profit = 865
- Donation = 865 × 10 ÷ 100 = 86.50, and boro bhai keeps 778.50
- Margin = 865 ÷ 1965 × 100 = 44.02…

The margin line uses `(double) profit` to convert the profit to a `double` **before** dividing. Without it, `profit / revenue` would be integer division, 865 / 1965 = 0, and the margin would print as 0.00. Since `donationPercent` is already a `double`, the donation needs no conversion.

The word `percent` is printed instead of the `%` symbol, because inside `printf` a `%` starts a format specifier.

### Concepts Practiced
- int and double variables
- Type casting with `(double)`
- Avoiding accidental integer division
- Percentage calculations
