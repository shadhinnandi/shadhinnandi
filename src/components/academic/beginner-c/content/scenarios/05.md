# Scenario-Based Problems

These problems turn written rules into decisions with `if`, `if-else`, `else if` ladders, nested conditions and `switch`. Read every rule carefully: most marks in lab exams are lost at the **boundaries** ("at least", "more than", "up to"), so the test cases check exactly those values.

Programs read input without prompts and print exactly the sample output. Unlike in earlier chapters, you should now check for invalid input where the problem asks for it. All eligibility rules, rates and benefit amounts are **hypothetical** and invented for practice; they are not the policy of any real university, utility or government programme.

## Problem 1: Character Classifier
**Level:** Moderate

### Scenario
A typing-tutor program for school children shows a message about every key pressed: whether it is a vowel or a consonant, uppercase or lowercase, a digit, or some other symbol. You are asked to write the classification part.

### Problem Statement
Read a single character (it will not be a space). Print exactly one of:

- `Uppercase vowel` / `Uppercase consonant`
- `Lowercase vowel` / `Lowercase consonant`
- `Digit`
- `Special character`

Vowels are `a e i o u` (in either case). Use character ranges such as `ch >= 'A' && ch <= 'Z'`; do not use any library functions.

### Sample Input
```text
E
```

### Sample Output
```text
Uppercase vowel
```

### Solution
```c
#include <stdio.h>

int main() {
    char ch;
    scanf(" %c", &ch);

    if (ch >= 'A' && ch <= 'Z') {
        if (ch == 'A' || ch == 'E' || ch == 'I' || ch == 'O' || ch == 'U') {
            printf("Uppercase vowel\n");
        } else {
            printf("Uppercase consonant\n");
        }
    } else if (ch >= 'a' && ch <= 'z') {
        if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u') {
            printf("Lowercase vowel\n");
        } else {
            printf("Lowercase consonant\n");
        }
    } else if (ch >= '0' && ch <= '9') {
        printf("Digit\n");
    } else {
        printf("Special character\n");
    }
    return 0;
}
```

### Explanation
The outer `else if` ladder decides the **group** (uppercase letter, lowercase letter, digit, anything else). Only after a character is known to be a letter does the inner `if` decide vowel or consonant. Splitting the decision this way avoids long conditions and makes sure a digit can never be called a consonant.

Comparisons like `ch >= 'A' && ch <= 'Z'` work because letters and digits have consecutive ASCII codes. Writing `'A'` rather than `65` makes the intent clear.

### Concepts Practiced
- if-else if ladder
- Nested if
- Logical operators `&&` and `||`
- Character ranges

## Problem 2: Final Exam Attendance Check
**Level:** Moderate

### Scenario
Before the final exam, each department publishes an attendance list. Under the (hypothetical) policy, a student with at least 75% attendance may sit the exam, a student with at least 60% but below 75% needs the advisor's approval, and anyone below 60% is barred. Sometimes the data typed by the course teacher is wrong.

### Problem Statement
Read two whole numbers: classes held and classes attended.

- If classes held is 0 or less, attended is negative, or attended is more than held, print `Invalid data` and stop.
- Otherwise calculate the attendance percentage and print it with the status.

Print exactly:
```text
Attendance: <percentage, 2 decimals> percent
Status: <status>
```
where the status is `Eligible for final exam`, `Warning: needs advisor approval`, or `Not eligible (barred)`.

### Sample Input
```text
23 18
```

### Sample Output
```text
Attendance: 78.26 percent
Status: Eligible for final exam
```

### Solution
```c
#include <stdio.h>

int main() {
    int held, attended;
    scanf("%d %d", &held, &attended);

    if (held <= 0 || attended < 0 || attended > held) {
        printf("Invalid data\n");
        return 0;
    }

    double percent = attended * 100.0 / held;
    printf("Attendance: %.2f percent\n", percent);

    if (percent >= 75) {
        printf("Status: Eligible for final exam\n");
    } else if (percent >= 60) {
        printf("Status: Warning: needs advisor approval\n");
    } else {
        printf("Status: Not eligible (barred)\n");
    }
    return 0;
}
```

### Explanation
Validation comes first, and it also protects the division: if `held` were 0, `attended * 100.0 / held` would divide by zero.

The ladder checks the highest band first. When execution reaches `else if (percent >= 60)`, we already know `percent < 75`, so the condition does not need to repeat it. Writing `100.0` makes the division decimal: 18 × 100.0 ÷ 23 = 78.26.

The boundary values matter: exactly 75% is eligible (`>=`), and exactly 60% needs approval rather than being barred.

### Concepts Practiced
- Input validation with `||`
- if-else if ladder with ordered ranges
- Avoiding division by zero
- Decimal percentage

## Problem 3: Merit Scholarship Waiver
**Level:** Intermediate

### Scenario
A private university (fictional rules) gives tuition waivers based on the previous trimester's CGPA, but only to students taking a full load of at least 12 credits this trimester:

| CGPA | Waiver |
|---|---|
| 3.90 or above | 100% |
| 3.75 to below 3.90 | 50% |
| 3.50 to below 3.75 | 25% |
| below 3.50 | 0% |

### Problem Statement
Read the CGPA (decimal), the credits taken this trimester (whole number) and the tuition amount (decimal).

If fewer than 12 credits are taken, print:
```text
Not eligible: minimum 12 credits required
Tuition to pay: <tuition> Tk
```
Otherwise print:
```text
Waiver: <percentage> percent
Waiver amount: <amount> Tk
Tuition to pay: <tuition - amount> Tk
```
Money is printed with two decimals.

### Sample Input
```text
3.80 12 78000
```

### Sample Output
```text
Waiver: 50 percent
Waiver amount: 39000.00 Tk
Tuition to pay: 39000.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double cgpa, tuition;
    int credits;
    scanf("%lf %d %lf", &cgpa, &credits, &tuition);

    if (credits < 12) {
        printf("Not eligible: minimum 12 credits required\n");
        printf("Tuition to pay: %.2f Tk\n", tuition);
        return 0;
    }

    int percent;
    if (cgpa >= 3.90) {
        percent = 100;
    } else if (cgpa >= 3.75) {
        percent = 50;
    } else if (cgpa >= 3.50) {
        percent = 25;
    } else {
        percent = 0;
    }

    double waiver = tuition * percent / 100;
    printf("Waiver: %d percent\n", percent);
    printf("Waiver amount: %.2f Tk\n", waiver);
    printf("Tuition to pay: %.2f Tk\n", tuition - waiver);
    return 0;
}
```

### Explanation
There are two separate decisions:

1. A **gate**: without 12 credits there is no waiver at all, whatever the CGPA. Handling it first with an early `return` keeps the rest of the program simple.
2. A **band** lookup: the ladder goes from the highest CGPA down, so each `else if` only needs the lower boundary.

The ladder stores the percentage in a variable instead of printing inside every branch; the calculation and printing are then written once. With the sample, 3.80 falls in the 50% band and the waiver is 78000 × 50 ÷ 100 = 39000.

### Concepts Practiced
- if-else if ladder for bands
- Early return for an eligibility gate
- Storing a decision in a variable
- Percentage calculation

## Problem 4: Slab-Based Electricity Bill
**Level:** Intermediate

### Scenario
A residential area's electricity supplier (fictional tariff) charges by **slabs**: each slab's rate applies only to the units inside that slab.

| Units | Rate |
|---|---|
| first 75 units (1–75) | 5.00 Tk per unit |
| next 125 units (76–200) | 6.00 Tk per unit |
| next 100 units (201–300) | 7.00 Tk per unit |
| above 300 units | 10.00 Tk per unit |

Every bill also has a fixed demand charge of 40 Tk, and 5% VAT is added on (energy charge + demand charge).

### Problem Statement
Read the units consumed (whole number). If it is negative, print `Invalid units`. Otherwise calculate the bill.

Print exactly (two decimals):
```text
Energy charge: <energy> Tk
Demand charge: 40.00 Tk
VAT (5 percent): <vat> Tk
Total bill: <total> Tk
```

### Sample Input
```text
260
```

### Sample Output
```text
Energy charge: 1545.00 Tk
Demand charge: 40.00 Tk
VAT (5 percent): 79.25 Tk
Total bill: 1664.25 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    int units;
    scanf("%d", &units);

    if (units < 0) {
        printf("Invalid units\n");
        return 0;
    }

    double energy;
    if (units <= 75) {
        energy = units * 5.0;
    } else if (units <= 200) {
        energy = 75 * 5.0 + (units - 75) * 6.0;
    } else if (units <= 300) {
        energy = 75 * 5.0 + 125 * 6.0 + (units - 200) * 7.0;
    } else {
        energy = 75 * 5.0 + 125 * 6.0 + 100 * 7.0 + (units - 300) * 10.0;
    }

    double demand = 40.0;
    double vat = (energy + demand) * 5 / 100;
    double total = energy + demand + vat;

    printf("Energy charge: %.2f Tk\n", energy);
    printf("Demand charge: %.2f Tk\n", demand);
    printf("VAT (5 percent): %.2f Tk\n", vat);
    printf("Total bill: %.2f Tk\n", total);
    return 0;
}
```

### Explanation
The common mistake is charging **all** units at the highest slab reached (260 × 7 = 1820). With slabs, each band is charged separately:

- first 75 units: 75 × 5 = 375
- next 125 units (76–200): 125 × 6 = 750
- remaining 60 units (201–260): 60 × 7 = 420
- energy = 1545

Each branch adds the **full** cost of every lower slab plus the part of the current slab: `(units − 200) × 7` counts only the units above 200. VAT is then 5% of 1545 + 40 = 1585, which is 79.25.

### Concepts Practiced
- if-else if ladder for slabs
- Cumulative (progressive) rate calculation
- Percentage on a combined base
- Input validation

## Problem 5: Cafeteria Ordering System
**Level:** Intermediate

### Scenario
The campus cafeteria's self-order kiosk shows a menu: 1 for Burger (150 Tk), 2 for Pizza (250 Tk), 3 for Pasta (200 Tk). A customer picks one item and a quantity. To encourage bigger orders, the cafeteria gives a 10% discount, but **only on the part of the subtotal above 500 Tk**. Then 6% VAT is added on the amount remaining after the discount.

### Problem Statement
Read the item code and the quantity (whole numbers). Use **only `switch-case`** to select the item name and price.

- If the code is not 1, 2 or 3, print `Invalid item code`.
- If the code is valid but the quantity is 0 or less, print `Invalid quantity`.

Otherwise, in this order:

1. subtotal = price × quantity
2. discount = 10% of (subtotal − 500) if the subtotal is above 500, otherwise 0
3. VAT = 6% of (subtotal − discount)
4. total = subtotal − discount + VAT

Print exactly (two decimals):
```text
Item: <name>
Subtotal: <subtotal> Tk
Discount: <discount> Tk
VAT: <vat> Tk
Total payable: <total> Tk
```

### Sample Input
```text
2 3
```

### Sample Output
```text
Item: Pizza
Subtotal: 750.00 Tk
Discount: 25.00 Tk
VAT: 43.50 Tk
Total payable: 768.50 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    int code, quantity;
    scanf("%d %d", &code, &quantity);

    double price;
    switch (code) {
        case 1:
            price = 150;
            break;
        case 2:
            price = 250;
            break;
        case 3:
            price = 200;
            break;
        default:
            printf("Invalid item code\n");
            return 0;
    }

    if (quantity <= 0) {
        printf("Invalid quantity\n");
        return 0;
    }

    double subtotal = price * quantity;
    double discount = 0;
    if (subtotal > 500) {
        discount = (subtotal - 500) * 10 / 100;
    }
    double vat = (subtotal - discount) * 6 / 100;
    double total = subtotal - discount + vat;

    switch (code) {
        case 1: printf("Item: Burger\n"); break;
        case 2: printf("Item: Pizza\n"); break;
        case 3: printf("Item: Pasta\n"); break;
    }
    printf("Subtotal: %.2f Tk\n", subtotal);
    printf("Discount: %.2f Tk\n", discount);
    printf("VAT: %.2f Tk\n", vat);
    printf("Total payable: %.2f Tk\n", total);
    return 0;
}
```

### Explanation
The worked sample shows why the order of operations must be stated precisely:

- Subtotal = 250 × 3 = 750
- Discount applies only to the amount above 500: (750 − 500) × 10% = 25
- VAT is on the discounted amount: (750 − 25) × 6% = 725 × 0.06 = 43.50
- Total = 725 + 43.50 = 768.50

Taking 10% of the whole 750 (75 Tk) or adding VAT before the discount would give different totals; neither follows the rule.

In the first `switch`, every `case` ends with `break`; without it, execution would "fall through" and code 1 would end with the pasta price. The `default` branch catches every invalid code in one place. The item name is printed with a second `switch` only after all validation has passed, so invalid orders print nothing but the error.

### Concepts Practiced
- switch-case with break and default
- Validation order
- Discount on the amount above a threshold
- VAT after discount

## Problem 6: Family Support Card
**Level:** Challenging

### Scenario
A city corporation is piloting a **fictional** "Family Support Card" that gives a monthly benefit to low-income households. The rules below are invented for this exercise and are not real government policy.

- Category A: monthly income up to 12000 Tk → 300 Tk per family member.
- Category B: income above 12000 and up to 20000 Tk → 200 Tk per member.
- Category C: income above 20000 and up to 30000 Tk, **and** at least 5 members → 150 Tk per member.
- Anyone else is not eligible.
- At most 6 members are counted, even in larger families.
- An eligible household with an elderly or disabled member gets an extra 500 Tk.

### Problem Statement
Read the number of family members (whole number), the monthly household income (decimal) and whether there is an elderly or disabled member (`Y` or `N`).

- If members is less than 1 or the income is negative, print `Invalid input`.
- If the household is not eligible, print `Not eligible`.
- Otherwise print exactly:

```text
Category: <A, B or C>
Members counted: <count>
Monthly benefit: <benefit> Tk
```

### Sample Input
```text
7 11000 Y
```

### Sample Output
```text
Category: A
Members counted: 6
Monthly benefit: 2300 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    int members;
    double income;
    char special;
    scanf("%d %lf %c", &members, &income, &special);

    if (members < 1 || income < 0) {
        printf("Invalid input\n");
        return 0;
    }

    char category;
    int ratePerMember;
    if (income <= 12000) {
        category = 'A';
        ratePerMember = 300;
    } else if (income <= 20000) {
        category = 'B';
        ratePerMember = 200;
    } else if (income <= 30000) {
        if (members >= 5) {
            category = 'C';
            ratePerMember = 150;
        } else {
            printf("Not eligible\n");
            return 0;
        }
    } else {
        printf("Not eligible\n");
        return 0;
    }

    int counted = members;
    if (counted > 6) {
        counted = 6;
    }

    int benefit = counted * ratePerMember;
    if (special == 'Y' || special == 'y') {
        benefit += 500;
    }

    printf("Category: %c\n", category);
    printf("Members counted: %d\n", counted);
    printf("Monthly benefit: %d Tk\n", benefit);
    return 0;
}
```

### Explanation
The rules are applied in a fixed order: validate, find the income category, apply the extra condition for category C (a **nested** `if`), cap the member count, then add the extra amount.

With the sample: income 11000 is category A (300 per member). The family has 7 members but only 6 are counted: 6 × 300 = 1800. There is an elderly or disabled member, so 500 is added: 2300.

Note the cap is applied **before** multiplying, and the extra 500 is added only after eligibility is confirmed, because ineligible households have already left the program through `return 0`. The test with 4 members and income 25000 shows the nested condition: the income is in range for category C, but the family is too small.

### Concepts Practiced
- if-else if ladder for income bands
- Nested if for an extra condition
- Capping a value
- Reading int, double and char together

## Problem 7: Holiday Ticket Booking
**Level:** Challenging

### Scenario
Before Eid, students go home by bus, train or launch. A travel-agent website (fictional fares) sells one-way tickets to Khulna:

| Mode | Class | Fare |
|---|---|---|
| `B` Bus | `N` Non-AC | 450 Tk |
| `B` Bus | `A` AC | 900 Tk |
| `T` Train | `S` Shovon (non-AC seat) | 350 Tk |
| `T` Train | `C` AC chair | 700 Tk |
| `L` Launch | `D` Deck | 300 Tk |
| `L` Launch | `C` Cabin | 1200 Tk |

Students with a valid student card get 20% off the fare for **bus and train only**. Every ticket has a 20 Tk booking fee (no discount on the fee).

### Problem Statement
Read four values: mode (character), class (character), number of tickets (whole number) and student card (`Y` or `N`). Use `switch` on the mode and a nested `switch` on the class.

- Unknown mode → print `Invalid mode`.
- Class not available for that mode → print `Invalid class`.
- Tickets 0 or less → print `Invalid number of tickets`.

Otherwise print exactly (two decimals for money):
```text
Ticket: <mode name> (<class name>)
Fare per ticket: <fare> Tk
Tickets: <n>
Booking fee: <fee> Tk
Total: <total> Tk
```
Mode names are `Bus`, `Train`, `Launch`; class names are `Non-AC`, `AC`, `Shovon`, `AC chair`, `Deck`, `Cabin`.

### Sample Input
```text
T C 2 Y
```

### Sample Output
```text
Ticket: Train (AC chair)
Fare per ticket: 560.00 Tk
Tickets: 2
Booking fee: 40.00 Tk
Total: 1160.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    char mode, cls, student;
    int tickets;
    scanf(" %c %c %d %c", &mode, &cls, &tickets, &student);

    double fare = 0;
    int validClass = 1;

    switch (mode) {
        case 'B':
            switch (cls) {
                case 'N': fare = 450; break;
                case 'A': fare = 900; break;
                default: validClass = 0;
            }
            break;
        case 'T':
            switch (cls) {
                case 'S': fare = 350; break;
                case 'C': fare = 700; break;
                default: validClass = 0;
            }
            break;
        case 'L':
            switch (cls) {
                case 'D': fare = 300; break;
                case 'C': fare = 1200; break;
                default: validClass = 0;
            }
            break;
        default:
            printf("Invalid mode\n");
            return 0;
    }

    if (!validClass) {
        printf("Invalid class\n");
        return 0;
    }
    if (tickets <= 0) {
        printf("Invalid number of tickets\n");
        return 0;
    }

    if (student == 'Y' && (mode == 'B' || mode == 'T')) {
        fare = fare * 80 / 100;   /* 20% student discount */
    }

    if (mode == 'B' && cls == 'N') {
        printf("Ticket: Bus (Non-AC)\n");
    } else if (mode == 'B') {
        printf("Ticket: Bus (AC)\n");
    } else if (mode == 'T' && cls == 'S') {
        printf("Ticket: Train (Shovon)\n");
    } else if (mode == 'T') {
        printf("Ticket: Train (AC chair)\n");
    } else if (cls == 'D') {
        printf("Ticket: Launch (Deck)\n");
    } else {
        printf("Ticket: Launch (Cabin)\n");
    }

    double fee = 20.0 * tickets;
    printf("Fare per ticket: %.2f Tk\n", fare);
    printf("Tickets: %d\n", tickets);
    printf("Booking fee: %.2f Tk\n", fee);
    printf("Total: %.2f Tk\n", fare * tickets + fee);
    return 0;
}
```

### Explanation
The fare table has two dimensions (mode and class), so the program uses a `switch` inside a `switch`. The same letter can mean different things in different modes: `C` is "AC chair" for trains but "Cabin" for launches, which a nested `switch` handles naturally.

Each inner `default` marks the class as invalid instead of printing immediately. All error messages are then printed in one fixed order (mode, class, tickets), so the program never prints two errors.

The discount condition combines a check of the card with a check of the mode: `student == 'Y' && (mode == 'B' || mode == 'T')`. The brackets are needed because `&&` binds more tightly than `||`.

By the time the ticket line is printed, the mode and class are known to be valid, so the final `if-else` ladder only has to tell the six valid combinations apart.

With the sample: the AC chair costs 700, the student discount makes it 560, two tickets cost 1120, the booking fee is 2 × 20 = 40, and the total is 1160.

- Nested switch-case
- default for invalid values
- Flag variable for deferred error reporting
- Combining `&&` and `||` with brackets
- if-else if ladder

## Problem 8: Ride-Share Fare with Surge and Promo
**Level:** Challenging

### Scenario
A ride-sharing app (fictional pricing) calculates a car fare in several steps. Students often book rides at rush hour, when prices go up, and use promo codes, which have their own conditions.

1. Base fare: 50 Tk.
2. Distance charge: 25 Tk per km for the first 5 km, 18 Tk per km for every km beyond 5.
3. Surge: the fare (base + distance) is multiplied by 1.5 if the pickup hour is in a peak period: 8:00–9:59 or 17:00–19:59 (hours 8, 9, 17, 18, 19).
4. Promo code (applied after surge): `0` = no promo; `1` = 10% off, maximum 40 Tk; `2` = flat 50 Tk off, only if the fare is at least 200 Tk.
5. The final fare is never below the 50 Tk minimum fare.

### Problem Statement
Read the distance in km (decimal), the pickup hour (0–23) and the promo code (0, 1 or 2).

- If the distance is negative or the hour is outside 0–23, print `Invalid input`.
- If the promo code is not 0, 1 or 2, print `Invalid promo code`.

Otherwise print exactly (two decimals):
```text
Base fare: 50.00 Tk
Distance charge: <charge> Tk
Surge: <Yes (x1.5) or No>
Fare before promo: <fare> Tk
Promo discount: <discount> Tk
Final fare: <final> Tk
```
When the minimum fare is applied, the last line is `Final fare: 50.00 Tk (minimum fare)`.

### Sample Input
```text
10 18 1
```

### Sample Output
```text
Base fare: 50.00 Tk
Distance charge: 215.00 Tk
Surge: Yes (x1.5)
Fare before promo: 397.50 Tk
Promo discount: 39.75 Tk
Final fare: 357.75 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double km;
    int hour, promo;
    scanf("%lf %d %d", &km, &hour, &promo);

    if (km < 0 || hour < 0 || hour > 23) {
        printf("Invalid input\n");
        return 0;
    }
    if (promo < 0 || promo > 2) {
        printf("Invalid promo code\n");
        return 0;
    }

    double base = 50;
    double distanceCharge;
    if (km <= 5) {
        distanceCharge = km * 25;
    } else {
        distanceCharge = 5 * 25 + (km - 5) * 18;
    }

    double fare = base + distanceCharge;
    int surge = (hour >= 8 && hour <= 9) || (hour >= 17 && hour <= 19);
    if (surge) {
        fare = fare * 1.5;
    }

    double discount = 0;
    if (promo == 1) {
        discount = fare * 10 / 100;
        if (discount > 40) {
            discount = 40;
        }
    } else if (promo == 2) {
        if (fare >= 200) {
            discount = 50;
        }
    }

    double finalFare = fare - discount;

    printf("Base fare: %.2f Tk\n", base);
    printf("Distance charge: %.2f Tk\n", distanceCharge);
    if (surge) {
        printf("Surge: Yes (x1.5)\n");
    } else {
        printf("Surge: No\n");
    }
    printf("Fare before promo: %.2f Tk\n", fare);
    printf("Promo discount: %.2f Tk\n", discount);
    if (finalFare < 50) {
        printf("Final fare: 50.00 Tk (minimum fare)\n");
    } else {
        printf("Final fare: %.2f Tk\n", finalFare);
    }
    return 0;
}
```

### Explanation
Turn each numbered rule into one block of code, in the same order:

- Distance: 10 km = 5 × 25 + 5 × 18 = 125 + 90 = 215
- Base + distance = 265; 18:00 is a peak hour, so × 1.5 = 397.50
- Promo 1: 10% of 397.50 = 39.75, which is under the 40 Tk cap
- Final: 397.50 − 39.75 = 357.75

Storing the surge decision in a variable (`surge`) lets the program both apply it and print it without repeating the long condition. A cap is just a second `if` inside the promo branch. The minimum fare is checked last, after every discount, because the rule says the **final** fare can never be below 50.

### Concepts Practiced
- Multi-step rules in a fixed order
- Nested if and else if
- Logical expressions for time ranges
- Caps and minimums
- Flag variable reused for output
