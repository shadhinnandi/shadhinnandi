# Scenario-Based Problems

So far you only know `printf`, so every problem here is about **exact output**: the right characters, spaces, line breaks and escape sequences. In a lab exam, output that is almost right is usually marked wrong, so compare your output with the sample character by character. None of these programs read input. Type all numbers as plain text; printing calculated values comes in Chapter 02.

## Problem 1: Orientation Welcome Banner
**Level:** Moderate

### Scenario
The CSE club is printing a welcome banner on the lab screens for new students' orientation day. The club secretary wants a small C program that prints the banner exactly as designed.

### Problem Statement
Write a C program that prints the banner below exactly. Use one `printf` statement per line and end every line with `\n`. The border lines contain exactly 30 `=` characters, and the title line starts with two spaces.

### Sample Input
No input.

### Sample Output
```text
==============================
  Welcome to CSE Orientation
==============================
Date: 12 January
Venue: Auditorium, Level 2
Bring your student ID card.
```

### Solution
```c
#include <stdio.h>

int main() {
    printf("==============================\n");
    printf("  Welcome to CSE Orientation\n");
    printf("==============================\n");
    printf("Date: 12 January\n");
    printf("Venue: Auditorium, Level 2\n");
    printf("Bring your student ID card.\n");
    return 0;
}
```

### Explanation
Each `printf` prints one line, and `\n` moves the cursor to the start of the next line. Leading spaces inside the quotes are printed exactly, which is how the title is pushed two characters to the right.

The usual mistakes are counting the `=` characters wrongly and forgetting a `\n`, which glues two lines together. Copy the border string once and reuse it so both borders are guaranteed identical.

### Concepts Practiced
- printf with string literals
- Newline escape sequence `\n`
- Exact output formatting

### Test Cases
#### Exact output check
The program takes no input, so the only test is an exact, character-by-character match.

**Input**
No input.

**Expected Output**
```text
==============================
  Welcome to CSE Orientation
==============================
Date: 12 January
Venue: Auditorium, Level 2
Bring your student ID card.
```

## Problem 2: Cafeteria Price Board
**Level:** Moderate

### Scenario
The cafeteria manager wants the day's price board shown on a monitor. Item names have different lengths, so typing spaces by hand keeps breaking the alignment. You suggest the tab escape sequence instead.

### Problem Statement
Print the price board below using `\t` (tab) to line up the prices. Do **not** use spaces for alignment between the columns. Assume tab stops every 8 characters, as in a standard terminal: short names need two tabs and `Khichuri` (8 letters) needs one.

The sample output below shows how the board looks in a terminal.

### Sample Input
No input.

### Sample Output
```text
ITEM		PRICE (Tk)
Khichuri	120
Burger		150
Tea		15
```

### Solution
```c
#include <stdio.h>

int main() {
    printf("ITEM\t\tPRICE (Tk)\n");
    printf("Khichuri\t120\n");
    printf("Burger\t\t150\n");
    printf("Tea\t\t15\n");
    return 0;
}
```

### Explanation
A tab does not insert a fixed number of spaces; it jumps to the next **tab stop** (columns 8, 16, 24, … with 8-character stops).

- `ITEM` ends at column 4. The first tab jumps to column 8, the second to column 16, where `PRICE` starts.
- `Khichuri` is exactly 8 characters, so it already ends at column 8. One tab jumps to column 16.
- `Burger` (6) and `Tea` (3) need two tabs each to reach column 16.

So every price starts in column 16 and the board lines up. If `Khichuri` had two tabs, its price would jump to column 24 and break the alignment.

### Concepts Practiced
- printf with string literals
- Tab escape sequence `\t` and tab stops
- Newline escape sequence `\n`

### Test Cases
#### Exact output check
Tabs must be real tab characters, not spaces.

**Input**
No input.

**Expected Output**
```text
ITEM		PRICE (Tk)
Khichuri	120
Burger		150
Tea		15
```

## Problem 3: Quoting the Instructor
**Level:** Intermediate

### Scenario
Your lab instructor writes two reminders on the board, and you are asked to show them on screen word for word. The first contains double quotes and a Windows file path with backslashes. The second shows the newline escape sequence itself.

### Problem Statement
Print the two lines below exactly. You will need escape sequences for the double quotes, the backslashes, and for printing the two characters `\` and `n` without starting a new line.

### Sample Input
No input.

### Sample Output
```text
Sir said, "Save your lab file as C:\Lab01\hello.c before you leave."
Use "\n" to start a new line.
```

### Solution
```c
#include <stdio.h>

int main() {
    printf("Sir said, \"Save your lab file as C:\\Lab01\\hello.c before you leave.\"\n");
    printf("Use \"\\n\" to start a new line.\n");
    return 0;
}
```

### Explanation
Inside a string, `"` would end the string and `\` starts an escape sequence, so both need escaping:

- `\"` prints `"`.
- `\\` prints a single `\`.

On the second line, `\\n` is `\\` (prints `\`) followed by the plain letter `n`, so the screen shows `\n` instead of moving to a new line. The final `\n` of each `printf` is a real newline.

A common bug is writing `C:\Lab01`: the compiler reads `\L` as an unknown escape sequence and warns about it, and the backslash disappears from the output.

### Concepts Practiced
- Escape sequences `\"` and `\\`
- Printing an escape sequence literally
- Newline escape sequence `\n`

### Test Cases
#### Exact output check
**Input**
No input.

**Expected Output**
```text
Sir said, "Save your lab file as C:\Lab01\hello.c before you leave."
Use "\n" to start a new line.
```

## Problem 4: Weekly Class Routine
**Level:** Intermediate

### Scenario
A first-trimester student wants her class routine printed in the terminal as a neat table, with borders, so she can screenshot it and pin it in her class group.

### Problem Statement
Print the table below exactly. Column widths are fixed:

- Day column: 9 characters of text area,
- Course column: 12 characters,
- Room column: 5 characters,

each with one space of padding on both sides, so a border segment is 11, 14 and 7 dashes. Text is left-aligned and padded with spaces.

### Sample Input
No input.

### Sample Output
```text
+-----------+--------------+-------+
| Day       | Course       | Room  |
+-----------+--------------+-------+
| Sunday    | CSE 1111     | 304   |
| Tuesday   | MATH 1151    | 512   |
| Thursday  | ENG 1011     | 210   |
+-----------+--------------+-------+
```

### Solution
```c
#include <stdio.h>

int main() {
    printf("+-----------+--------------+-------+\n");
    printf("| Day       | Course       | Room  |\n");
    printf("+-----------+--------------+-------+\n");
    printf("| Sunday    | CSE 1111     | 304   |\n");
    printf("| Tuesday   | MATH 1151    | 512   |\n");
    printf("| Thursday  | ENG 1011     | 210   |\n");
    printf("+-----------+--------------+-------+\n");
    return 0;
}
```

### Explanation
Plan the table on paper before typing. Every row has the same shape:

`| ` + text padded to the column width + ` | ` + … + ` |`

For example, `Sunday` is 6 characters, so it needs 3 spaces of padding to fill the 9-character Day column. `Thursday` is 8 characters, so it needs 1. Because every row is built from the same widths, all the `|` characters line up under the `+` corners.

Reusing the border line (copy once, paste three times) avoids small differences between borders.

### Concepts Practiced
- printf with string literals
- Planning fixed-width output
- Newline escape sequence `\n`

### Test Cases
#### Exact output check
Every line must be exactly 36 characters long.

**Input**
No input.

**Expected Output**
```text
+-----------+--------------+-------+

+-----------+--------------+-------+
| Sunday    | CSE 1111     | 304   |
| Tuesday   | MATH 1151    | 512   |

```

## Problem 5: Shuttle Bus Ticket
**Level:** Intermediate

### Scenario
The university shuttle service is testing a small ticket printer. Until the real system is ready, a C program prints a sample ticket so the transport office can check the layout.

### Problem Statement
Print the ticket below exactly. The border is made of 32 `*` characters, and every inner line starts with `*` and ends with `*` in column 32, padded with spaces. The route line contains an arrow made of a hyphen and `>`.

### Sample Input
No input.

### Sample Output
```text
********************************
*   UNIVERSITY SHUTTLE TICKET  *
*                              *
*   Route : Notun Bazar -> UIU *
*   Time  : 7:30 AM            *
*   Fare  : 20 Tk (student)    *
********************************
```

### Solution
```c
#include <stdio.h>

int main() {
    printf("********************************\n");
    printf("*   UNIVERSITY SHUTTLE TICKET  *\n");
    printf("*                              *\n");
    printf("*   Route : Notun Bazar -> UIU *\n");
    printf("*   Time  : 7:30 AM            *\n");
    printf("*   Fare  : 20 Tk (student)    *\n");
    printf("********************************\n");
    return 0;
}
```

### Explanation
Each inner line is 32 characters: one `*`, 30 characters of content, and one `*`. Count the content first, then pad it with spaces to 30. For example, `   Time  : 7:30 AM` is 18 characters, so 12 spaces follow before the closing `*`.

The characters `-`, `>`, `(`, `)` and `:` have no special meaning inside a C string, so they need no escaping. Only `"`, `\` and `%` need care inside `printf` strings.

### Concepts Practiced
- printf with string literals
- Box drawing with fixed-width lines
- Characters that need no escaping

### Test Cases
#### Exact output check
Every line must be exactly 32 characters long, with the right border aligned.

**Input**
No input.

**Expected Output**
```text
********************************
*   UNIVERSITY SHUTTLE TICKET  *
*                              *
*   Route : Notun Bazar -> UIU *
*   Time  : 7:30 AM            *
```

## Problem 6: Boro Bhai's Cha Stall Sign
**Level:** Challenging

### Scenario
The elakar boro bhai (the neighbourhood's friendly big brother) has opened a tea stall next to campus. He heard you are "a computer student" and asks you to print a sign for his stall on an old monitor: a steaming cup drawn in text, the stall's name, and his favourite slogan in quotes.

### Problem Statement
Print the sign below exactly. The cup uses backslashes, forward slashes, a backtick and an apostrophe; the slogan is surrounded by double quotes. Decide which characters need escape sequences.

### Sample Input
No input.

### Sample Output
```text
      ( (
       ) )
    .______.
    |      |]
    \      /
     `----'
  BORO BHAI'S CHA STALL
 "Cha khan, code likhun!"
```

### Solution
```c
#include <stdio.h>

int main() {
    printf("      ( (\n");
    printf("       ) )\n");
    printf("    .______.\n");
    printf("    |      |]\n");
    printf("    \\      /\n");
    printf("     `----'\n");
    printf("  BORO BHAI'S CHA STALL\n");
    printf(" \"Cha khan, code likhun!\"\n");
    return 0;
}
```

### Explanation
Go through the picture character by character and ask: "does this character mean something special inside a C string?"

- `\` (bottom-left of the cup) starts an escape sequence, so it is written `\\`.
- `"` around the slogan would end the string, so it is written `\"`.
- `/`, `` ` ``, `'`, `(`, `)`, `|`, `]`, `.` and `_` are ordinary characters inside a double-quoted string and are printed as they are.

The apostrophe in `BHAI'S` needs no escape inside a double-quoted string (it would only need one inside a single character like `'\''`).

### Concepts Practiced
- ASCII art with printf
- Escape sequences `\\` and `\"`
- Recognising which characters need escaping

### Test Cases
#### Exact output check

No input.

**Expected Output**
```text

       ) )
    .______.
    |      |]
    \      /
     `----'

 "Cha khan, code likhun!"
```

## Problem 7: Exam Hall Seat Plan
**Level:** Challenging

### Scenario
For the final exam, the exam committee wants a seat plan displayed at the hall entrance. Seats are in three rows with an aisle in the middle, the invigilator's desk is at the front, and one row is reserved for students taking a retake exam.

### Problem Statement
Print the seat plan below exactly. Seats in a block are separated by two spaces, the aisle between the two blocks is five spaces wide, and the last line contains a quoted word. Use one `printf` per line.

### Sample Input
No input.

### Sample Output
```text
         [ INVIGILATOR ]

  A1  A2  A3     A4  A5  A6
  B1  B2  B3     B4  B5  B6
  C1  C2  C3     C4  C5  C6
            ^aisle^
Row C is reserved for "retake" students.
```

### Solution
```c
#include <stdio.h>

int main() {
    printf("         [ INVIGILATOR ]\n");
    printf("\n");
    printf("  A1  A2  A3     A4  A5  A6\n");
    printf("  B1  B2  B3     B4  B5  B6\n");
    printf("  C1  C2  C3     C4  C5  C6\n");
    printf("            ^aisle^\n");
    printf("Row C is reserved for \"retake\" students.\n");
    return 0;
}
```

### Explanation
The blank line under the desk is printed with `printf("\n")`, a string containing only a newline.

Each seat row is: 2 spaces, `A1`, 2 spaces, `A2`, 2 spaces, `A3`, 5 spaces (the aisle), then the right block. Writing one row correctly and copying it for rows B and C (changing only the letter) keeps the columns aligned.

The `^aisle^` marker starts at column 13 so that it sits under the gap between the two blocks. The quotes around `retake` are printed with `\"`.

### Concepts Practiced
- printf with string literals
- Blank lines with `\n`
- Escape sequence `\"`
- Planning a grid layout

### Test Cases
#### Exact output check
Line 2 is an empty line.

**Input**
No input.

**Expected Output**
```text
         [ INVIGILATOR ]

  A1  A2  A3     A4  A5  A6
  B1  B2  B3     B4  B5  B6
  C1  C2  C3     C4  C5  C6
            ^aisle^
Row C is reserved for "retake" students.
```

## Problem 8: One-Statement Shop Receipt
**Level:** Challenging

### Scenario
Boro bhai's general store needs a receipt printed for a regular customer. A senior student challenges you: "Can you print the whole receipt with a **single** `printf` statement?" The amounts are already worked out, so you can type them as text.

### Problem Statement
Print the receipt below using **exactly one** `printf` call. All line breaks must come from `\n` inside that one string, and the closing line contains double quotes. The prices are right-aligned so that `Tk` lines up in one column.

### Sample Input
No input.

### Sample Output
```text
--- Boro Bhai General Store ---
Rice 5 kg         350 Tk
Lentils 1 kg      140 Tk
Soap x 2           90 Tk
-------------------------------
Total             580 Tk
"Thank you, come again!"
```

### Solution
```c
#include <stdio.h>

int main() {
    printf("--- Boro Bhai General Store ---\nRice 5 kg         350 Tk\nLentils 1 kg      140 Tk\nSoap x 2           90 Tk\n-------------------------------\nTotal             580 Tk\n\"Thank you, come again!\"\n");
    return 0;
}
```

### Explanation
A single string can contain any number of `\n` escape sequences, and each one starts a new line on the screen. Building the receipt this way means every line must be planned before typing, because there is only one long string.

To keep the `Tk` column aligned, each item line has the same total width (24 characters). Shorter numbers get extra spaces in front: `90` has one more space before it than `350`.

Tip for later chapters: C joins string literals that are written next to each other, so the same single `printf` can be spread over several source lines for readability, for example `printf("line 1\n" "line 2\n");`.

### Concepts Practiced
- One printf with multiple `\n` escape sequences
- Escape sequence `\"`
- Right-aligning text by padding

### Test Cases
#### Exact output check
**Input**
No input.

**Expected Output**
```text
--- Boro Bhai General Store ---
Rice 5 kg         350 Tk
Lentils 1 kg      140 Tk
Soap x 2           90 Tk
-------------------------------

"Thank you, come again!"
```
