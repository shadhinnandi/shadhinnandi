# Scenario-Based Problems

These problems read data from files, write results to new files, and append to existing files. In each problem, **File `name`** under Sample Input is a file that exists in the program's folder before it runs, and **File `name` (after running)** under Sample Output is what the file must contain afterwards. Anything else is typed at the keyboard or printed on the screen.

Every program checks the result of `fopen` (it returns `NULL` if a file cannot be opened) and closes every file it opens with `fclose`. Programs read keyboard input without prompts and print exactly the sample output.

## Problem 1: Save Registration Records
**Level:** Moderate

### Scenario
During club registration, a volunteer types each new member's student ID, first name and CGPA. At the end of the session the records must be saved to a file so that the club secretary can open it later in a spreadsheet.

### Problem Statement
Read `N`, then `N` records `id name cgpa` from the keyboard (the name is one word). Write them to `students.txt`, one record per line, as `id,name,cgpa` with the CGPA to two decimals (a simple comma-separated format). Then print `Saved <N> records to students.txt`. If the file cannot be created, print `Cannot create students.txt`.

### Sample Input
```text
3
2211045 Rahim 3.75
2211052 Nusrat 3.92
2211099 Tanvir 2.85
```

### Sample Output
```text
Saved 3 records to students.txt
```
**File `students.txt`**
```text
2211045,Rahim,3.75
2211052,Nusrat,3.92
2211099,Tanvir,2.85
```

### Solution
```c
#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);

    FILE *fp = fopen("students.txt", "w");
    if (fp == NULL) {
        printf("Cannot create students.txt\n");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        int id;
        char name[50];
        double cgpa;
        scanf("%d %49s %lf", &id, name, &cgpa);
        fprintf(fp, "%d,%s,%.2f\n", id, name, cgpa);
    }

    fclose(fp);
    printf("Saved %d records to students.txt\n", n);
    return 0;
}
```

### Explanation
`fopen("students.txt", "w")` creates the file, or empties it if it already exists. `fprintf` works exactly like `printf`, but its first argument says which file to write to.

Writing a comma between fields (CSV format) means spreadsheet programs can open the file directly and put each field in its own column.

The file is closed before the confirmation is printed: `fclose` makes sure all data has actually been written to disk. A program that forgets `fclose` can lose the last lines it wrote.

### Concepts Practiced
- fopen in write mode
- Checking for NULL
- fprintf
- fclose
- CSV-style output

## Problem 2: Class Test Marks from a File
**Level:** Moderate

### Scenario
A course teacher exports class-test marks from the university portal as a text file, one student per line: roll number and mark. She wants a quick summary without opening a spreadsheet.

### Problem Statement
Read `marks.txt` until the end of the file. Each line has `roll mark`. Print:
```text
Students: <count>
Average: <average, 2 decimals>
Highest: <mark> (roll <roll>)
Failed: <count of marks below 40>
```
If the file cannot be opened, print `Could not open marks.txt`. If it contains no records, print `No records found`. The highest mark goes to the first student with that mark.

### Sample Input
No input.

**File `marks.txt`**
```text
101 78
102 35
103 91
104 64
105 39
```

### Sample Output
```text
Students: 5
Average: 61.40
Highest: 91 (roll 103)
Failed: 2
```

### Solution
```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("marks.txt", "r");
    if (fp == NULL) {
        printf("Could not open marks.txt\n");
        return 1;
    }

    int roll, mark;
    int count = 0, sum = 0, failed = 0;
    int bestMark = 0, bestRoll = 0;

    while (fscanf(fp, "%d %d", &roll, &mark) == 2) {
        count++;
        sum += mark;
        if (mark < 40) failed++;
        if (count == 1 || mark > bestMark) {
            bestMark = mark;
            bestRoll = roll;
        }
    }
    fclose(fp);

    if (count == 0) {
        printf("No records found\n");
        return 0;
    }
    printf("Students: %d\n", count);
    printf("Average: %.2f\n", (double) sum / count);
    printf("Highest: %d (roll %d)\n", bestMark, bestRoll);
    printf("Failed: %d\n", failed);
    return 0;
}
```

### Explanation
`fscanf` returns how many values it successfully read. `while (fscanf(...) == 2)` therefore keeps reading complete records and stops at the end of the file (or at a broken line). This is the standard, safe way to read "until the end": the number of records does not have to be known in advance.

The two error situations are different and handled separately: a missing file (`fopen` returned `NULL`) and an existing but empty file (the loop never ran, `count` is 0). Checking `count` also prevents a division by zero in the average.

### Concepts Practiced
- fopen in read mode
- Reading until end of file with fscanf's return value
- Running statistics
- Missing file vs empty file

## Problem 3: Wallet Transaction Log
**Level:** Intermediate

### Scenario
A student keeps a simple digital wallet in a text file `wallet.txt`: each line is a deposit (`D`) or a withdrawal (`W`) with an amount. Every evening she runs a program that adds the day's new transactions to the file and prints the full history with the current balance. A withdrawal larger than the balance must be rejected and must **not** be saved.

### Problem Statement
1. Open `wallet.txt` for reading (if it does not exist yet, start with an empty history) and compute the current balance.
2. Read new transactions from the keyboard (`D amount` or `W amount`) until `E`. Reject a withdrawal larger than the balance with `Rejected: W <amount> (insufficient balance)`. **Append** every accepted transaction to `wallet.txt` as `<type> <amount with 2 decimals>`.
3. Re-open the file, and print `History:`, one numbered line per transaction (`Deposit` / `Withdraw` and the amount), and finally `Balance: <balance>`.

### Sample Input
```text
D 500
W 2000
W 300
E
```
**File `wallet.txt`**
```text
D 1000.00
W 250.00
```

### Sample Output
```text
Rejected: W 2000.00 (insufficient balance)
History:
1. Deposit 1000.00
2. Withdraw 250.00
3. Deposit 500.00
4. Withdraw 300.00
Balance: 950.00
```
**File `wallet.txt` (after running)**
```text
D 1000.00
W 250.00
D 500.00
W 300.00
```

### Solution
```c
#include <stdio.h>

int main() {
    char type;
    double amount, balance = 0;

    /* 1. current balance from the existing history (if any) */
    FILE *fp = fopen("wallet.txt", "r");
    if (fp != NULL) {
        while (fscanf(fp, " %c %lf", &type, &amount) == 2) {
            if (type == 'D') balance += amount;
            else balance -= amount;
        }
        fclose(fp);
    }

    /* 2. append today's accepted transactions */
    fp = fopen("wallet.txt", "a");
    if (fp == NULL) {
        printf("Cannot write wallet.txt\n");
        return 1;
    }
    while (scanf(" %c", &type) == 1 && type != 'E') {
        scanf("%lf", &amount);
        if (type == 'W' && amount > balance) {
            printf("Rejected: W %.2f (insufficient balance)\n", amount);
            continue;
        }
        if (type == 'D') balance += amount;
        else balance -= amount;
        fprintf(fp, "%c %.2f\n", type, amount);
    }
    fclose(fp);

    /* 3. print the full history */
    fp = fopen("wallet.txt", "r");
    if (fp == NULL) {
        printf("Cannot read wallet.txt\n");
        return 1;
    }
    printf("History:\n");
    int k = 0;
    while (fscanf(fp, " %c %lf", &type, &amount) == 2) {
        k++;
        if (type == 'D') printf("%d. Deposit %.2f\n", k, amount);
        else printf("%d. Withdraw %.2f\n", k, amount);
    }
    fclose(fp);
    printf("Balance: %.2f\n", balance);
    return 0;
}
```

### Explanation
The same file is opened three times in three modes, each for one job:

- `"r"` reads the existing history to rebuild the balance (a missing file is fine here: it just means a new wallet);
- `"a"` (append) adds lines at the **end** without erasing what is already there; `"w"` would have wiped the history;
- `"r"` again reads everything, old and new, to print the statement.

Each time a file is reopened, reading starts from the beginning. The rejected withdrawal is checked against the balance **including** today's earlier transactions (1250 after the deposit), and is never written to the file. The space in `" %c"` skips the newline before each type letter.

### Concepts Practiced
- Read, append and read again
- File modes `"r"`, `"a"` (and why not `"w"`)
- Rebuilding state from a file
- fscanf and fprintf with mixed types

## Problem 4: Cafeteria Sales Report
**Level:** Intermediate

### Scenario
At closing time, the cafeteria's point-of-sale system leaves a file `sales.txt`: one line per item with the item name, quantity sold and unit price. The manager wants a neat report file to print and pin up, plus a one-line confirmation on screen. Lines with an impossible quantity or price are reported and left out.

### Problem Statement
Read `sales.txt` (`name qty price` per line, the name one word). Write `report.txt` with a header, one line per valid item and a total line, using these formats:

- header: `fprintf(out, "%-12s%5s%11s\n", "ITEM", "QTY", "AMOUNT")`
- item: `fprintf(out, "%-12s%5d%11.2f\n", name, qty, qty * price)`
- total: `fprintf(out, "%-12s%5d%11.2f\n", "TOTAL", totalQty, totalAmount)`

A line with quantity ≤ 0 or a negative price prints `Skipped line <k>` on the screen. Finally print `Report written: <items> items, total <amount> Tk`. If `sales.txt` cannot be opened, print `Could not open sales.txt`.

### Sample Input
No input.

**File `sales.txt`**
```text
Burger 4 150
Tea 25 15
Khichuri 6 120
```

### Sample Output
```text
Report written: 3 items, total 1695.00 Tk
```
**File `report.txt` (after running)**
```text
ITEM          QTY     AMOUNT
Burger          4     600.00
Tea            25     375.00
Khichuri        6     720.00
TOTAL          35    1695.00
```

### Solution
```c
#include <stdio.h>

int main() {
    FILE *in = fopen("sales.txt", "r");
    if (in == NULL) {
        printf("Could not open sales.txt\n");
        return 1;
    }
    FILE *out = fopen("report.txt", "w");
    if (out == NULL) {
        printf("Could not create report.txt\n");
        fclose(in);
        return 1;
    }

    fprintf(out, "%-12s%5s%11s\n", "ITEM", "QTY", "AMOUNT");

    char name[30];
    int qty, line = 0, items = 0, totalQty = 0;
    double price, total = 0;

    while (fscanf(in, "%29s %d %lf", name, &qty, &price) == 3) {
        line++;
        if (qty <= 0 || price < 0) {
            printf("Skipped line %d\n", line);
            continue;
        }
        double amount = qty * price;
        fprintf(out, "%-12s%5d%11.2f\n", name, qty, amount);
        items++;
        totalQty += qty;
        total += amount;
    }
    fprintf(out, "%-12s%5d%11.2f\n", "TOTAL", totalQty, total);

    fclose(in);
    fclose(out);
    printf("Report written: %d items, total %.2f Tk\n", items, total);
    return 0;
}
```

### Explanation
Two files are open at once: `in` for reading and `out` for writing. Each `FILE *` variable is like a separate channel, and every `fscanf`/`fprintf` names the channel it uses. If the second `fopen` fails, the first file is closed before leaving, so nothing is left open.

The field widths make the report line up like a table: `%-12s` left-aligns the name in 12 characters, `%5d` right-aligns the quantity in 5, and `%11.2f` right-aligns the amount in 11 with two decimals. Because every line uses the same widths, the columns match the header.

### Concepts Practiced
- Reading one file while writing another
- fprintf with field widths
- Skipping invalid records
- Closing files on every exit path

## Problem 5: Attendance Defaulter List
**Level:** Intermediate

### Scenario
Before the final exam, the department office receives an attendance file for each course. The first line is the number of classes held; each following line has a roll number, a first name and the number of classes attended. Students below 75% must be listed in a separate file for the exam committee.

### Problem Statement
Read `attendance.txt`. If the total number of classes is 0 or less, print `Invalid total classes`. Otherwise write every student with attendance below 75% to `defaulters.txt` as `roll name percentage` (two decimals), in the original order, and print `Defaulters: <d> of <n> students`. If the file cannot be opened, print `Could not open attendance.txt`.

### Sample Input
No input.

**File `attendance.txt`**
```text
24
101 Rahim 22
102 Nusrat 17
103 Tanvir 18
104 Mim 10
```

### Sample Output
```text
Defaulters: 2 of 4 students
```
**File `defaulters.txt` (after running)**
```text
102 Nusrat 70.83
104 Mim 41.67
```

### Solution
```c
#include <stdio.h>

int main() {
    FILE *in = fopen("attendance.txt", "r");
    if (in == NULL) {
        printf("Could not open attendance.txt\n");
        return 1;
    }

    int total;
    if (fscanf(in, "%d", &total) != 1 || total <= 0) {
        printf("Invalid total classes\n");
        fclose(in);
        return 1;
    }

    FILE *out = fopen("defaulters.txt", "w");
    if (out == NULL) {
        printf("Could not create defaulters.txt\n");
        fclose(in);
        return 1;
    }

    int roll, attended, students = 0, defaulters = 0;
    char name[40];
    while (fscanf(in, "%d %39s %d", &roll, name, &attended) == 3) {
        students++;
        double percent = attended * 100.0 / total;
        if (percent < 75) {
            fprintf(out, "%d %s %.2f\n", roll, name, percent);
            defaulters++;
        }
    }

    fclose(in);
    fclose(out);
    printf("Defaulters: %d of %d students\n", defaulters, students);
    return 0;
}
```

### Explanation
The file has a **header line** (the number of classes) followed by records, so the program reads the header once with its own `fscanf` before the record loop. Validating it immediately protects the later division.

Exactly 75.00% (Tanvir, 18 of 24) is not below 75, so he is not a defaulter. The output file is created even when there are no defaulters; an empty file clearly means "nobody", while a missing file could mean the program never ran.

### Concepts Practiced
- Reading a header line, then records
- Filtering records into a new file
- Validating file data
- Percentages from file data

## Problem 6: Merge Section Lists
**Level:** Challenging

### Scenario
Two sections of the same course are being combined into one big class for the trimester's last weeks. Each section's ID list is stored in a file, sorted in increasing order. A few students were (by mistake) enrolled in both sections. The combined list must be sorted and contain each ID only once.

### Problem Statement
Read `section_a.txt` and `section_b.txt` (one ID per line, each file sorted, no repeats inside a file) and write `merged.txt`: all IDs in increasing order, each exactly once. Do **not** load the files into arrays: read one ID at a time from each file and merge as you go. Print:
```text
Section A: <a> IDs
Section B: <b> IDs
Merged: <m> IDs (<d> duplicates removed)
```
If either input file cannot be opened, print `Could not open input files`.

### Sample Input
No input.

**File `section_a.txt`**
```text
101
104
108
115
```

**File `section_b.txt`**
```text
102
104
109
115
120
```

### Sample Output
```text
Section A: 4 IDs
Section B: 5 IDs
Merged: 7 IDs (2 duplicates removed)
```
**File `merged.txt` (after running)**
```text
101
102
104
108
109
115
120
```

### Solution
```c
#include <stdio.h>

int main() {
    FILE *fa = fopen("section_a.txt", "r");
    FILE *fb = fopen("section_b.txt", "r");
    if (fa == NULL || fb == NULL) {
        printf("Could not open input files\n");
        if (fa != NULL) fclose(fa);
        if (fb != NULL) fclose(fb);
        return 1;
    }
    FILE *out = fopen("merged.txt", "w");
    if (out == NULL) {
        printf("Could not create merged.txt\n");
        fclose(fa);
        fclose(fb);
        return 1;
    }

    int a, b;
    int hasA = (fscanf(fa, "%d", &a) == 1);
    int hasB = (fscanf(fb, "%d", &b) == 1);
    int countA = hasA, countB = hasB, merged = 0, duplicates = 0;

    while (hasA || hasB) {
        if (hasA && (!hasB || a < b)) {             /* take from A */
            fprintf(out, "%d\n", a);
            hasA = (fscanf(fa, "%d", &a) == 1);
            countA += hasA;
        } else if (hasB && (!hasA || b < a)) {      /* take from B */
            fprintf(out, "%d\n", b);
            hasB = (fscanf(fb, "%d", &b) == 1);
            countB += hasB;
        } else {                                    /* same ID in both */
            fprintf(out, "%d\n", a);
            duplicates++;
            hasA = (fscanf(fa, "%d", &a) == 1);
            hasB = (fscanf(fb, "%d", &b) == 1);
            countA += hasA;
            countB += hasB;
        }
        merged++;
    }

    fclose(fa);
    fclose(fb);
    fclose(out);
    printf("Section A: %d IDs\n", countA);
    printf("Section B: %d IDs\n", countB);
    printf("Merged: %d IDs (%d duplicates removed)\n", merged, duplicates);
    return 0;
}
```

### Explanation
This is the **merge** step used by merge sort, done directly on files. Each file has a "current" ID (`a` and `b`) plus a flag saying whether that file still has data. At every step the smaller current ID is written and only that file moves forward. When both IDs are equal, the ID is written once and **both** files move forward, which removes the duplicate.

When one file runs out, its flag becomes 0, and the conditions `!hasB` / `!hasA` let the other file's remaining IDs flow through. Because each ID is read exactly once, the program works even for files far too large to fit in an array.

The counts are updated each time a read succeeds (`countA += hasA` adds 1 or 0).

### Concepts Practiced
- Two input files and one output file
- Merging sorted streams
- End-of-file flags
- Removing duplicates while merging

## Problem 7: Electricity Billing Batch
**Level:** Challenging

### Scenario
At the end of the month, an electricity office (fictional tariff) processes all meter readings in one batch. `readings.txt` contains one line per meter: the meter ID, the previous reading and the current reading. Valid bills go to `bills.txt`; impossible readings (current smaller than previous) go to `errors.txt` for a technician to check. The tariff is the same as in Chapter 05: first 75 units at 5 Tk, units 76–200 at 6 Tk, units 201–300 at 7 Tk, above 300 at 10 Tk, plus a 40 Tk demand charge, plus 5% VAT on (energy + demand).

### Problem Statement
Write a function `double billFor(int units)` for the tariff. Read every line of `readings.txt` and write:

- to `bills.txt`: `<meter> <units> <bill, 2 decimals>`
- to `errors.txt`: `<meter> invalid reading`

Then print:
```text
Bills: <count>
Errors: <count>
Total billed: <total> Tk
```
If `readings.txt` cannot be opened, print `Could not open readings.txt`.

### Sample Input
No input.

**File `readings.txt`**
```text
M001 1200 1460
M002 500 540
M003 900 850
M004 3000 3350
```

### Sample Output
```text
Bills: 3
Errors: 1
Total billed: 4399.50 Tk
```
**File `bills.txt` (after running)**
```text
M001 260 1664.25
M002 40 252.00
M004 350 2483.25
```
**File `errors.txt` (after running)**
```text
M003 invalid reading
```

### Solution
```c
#include <stdio.h>

double billFor(int units) {
    double energy;
    if (units <= 75) {
        energy = units * 5.0;
    } else if (units <= 200) {
        energy = 75 * 5.0 + (units - 75) * 6.0;
    } else if (units <= 300) {
        energy = 75 * 5.0 + 125 * 6.0 + (units - 200) * 7.0;
    } else {
        energy = 75 * 5.0 + 125 * 6.0 + 100 * 7.0 + (units - 300) * 10.0;
    }
    double beforeVat = energy + 40.0;
    return beforeVat + beforeVat * 5 / 100;
}

int main() {
    FILE *in = fopen("readings.txt", "r");
    if (in == NULL) {
        printf("Could not open readings.txt\n");
        return 1;
    }
    FILE *bills = fopen("bills.txt", "w");
    FILE *errors = fopen("errors.txt", "w");
    if (bills == NULL || errors == NULL) {
        printf("Could not create output files\n");
        fclose(in);
        if (bills != NULL) fclose(bills);
        if (errors != NULL) fclose(errors);
        return 1;
    }

    char meter[20];
    int previous, current, billCount = 0, errorCount = 0;
    double total = 0;

    while (fscanf(in, "%19s %d %d", meter, &previous, &current) == 3) {
        if (current < previous) {
            fprintf(errors, "%s invalid reading\n", meter);
            errorCount++;
        } else {
            int units = current - previous;
            double bill = billFor(units);
            fprintf(bills, "%s %d %.2f\n", meter, units, bill);
            billCount++;
            total += bill;
        }
    }

    fclose(in);
    fclose(bills);
    fclose(errors);
    printf("Bills: %d\n", billCount);
    printf("Errors: %d\n", errorCount);
    printf("Total billed: %.2f Tk\n", total);
    return 0;
}
```

### Explanation
The program **routes** each record to one of two output files depending on whether it is valid. That separation is common in real batch jobs: good data continues, bad data is set aside for a human, and nothing is silently lost.

The tariff calculation is the same as in Chapter 05 but packed into `billFor`, so the batch loop stays short. M002: 40 units × 5 = 200, plus 40 demand = 240, plus 5% VAT = 252.00. The total on screen adds the three bills: 1664.25 + 252.00 + 2483.25 = 4399.50.

Opening three files means three `fclose` calls, and the error path closes whichever files did open.

## Problem 8: Notice File Statistics
**Level:** Challenging

### Scenario
The department publishes notices as plain text files. Before posting, the office checks a notice's size (lines, words, characters), finds the longest line (long lines look bad on the notice board screen), and counts how often a keyword appears, for example `exams`, ignoring capital letters.

### Problem Statement
Read the keyword (one word) from the keyboard. Read `notice.txt` line by line with `fgets` (lines are at most 200 characters). A **word** is a run of letters and digits; anything else separates words (so `Mid-term` is two words). Characters are counted without the newline. Print:
```text
Lines: <lines>
Words: <words>
Characters: <characters>
Longest line: <line number> (<length> characters)
"<keyword>" appears <k> times
```
The longest line is the first one if there is a tie. For an empty file print `Longest line: none` on that line. If the file cannot be opened, print `Could not open notice.txt`.

### Sample Input
```text
exams
```
**File `notice.txt`**
```text
Mid-term exams start on 12 March.
All students must bring their ID cards.
Exams will be held in Rooms 301 and 302.
No student may enter after 15 minutes.
```

### Sample Output
```text
Lines: 4
Words: 30
Characters: 150
Longest line: 3 (40 characters)
"exams" appears 2 times
```

### Solution
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char keyword[50];
    scanf("%49s", keyword);
    for (int i = 0; keyword[i] != '\0'; i++) {
        keyword[i] = tolower((unsigned char) keyword[i]);
    }

    FILE *fp = fopen("notice.txt", "r");
    if (fp == NULL) {
        printf("Could not open notice.txt\n");
        return 1;
    }

    char line[210], word[210];
    int lines = 0, words = 0, chars = 0, longest = 0, longestLine = 0, hits = 0;

    while (fgets(line, sizeof(line), fp) != NULL) {
        int len = strlen(line);
        if (len > 0 && line[len - 1] == '\n') line[--len] = '\0';

        lines++;
        chars += len;
        if (len > longest) {
            longest = len;
            longestLine = lines;
        }

        int w = 0;                                  /* length of the current word */
        for (int i = 0; i <= len; i++) {            /* i == len handles the last word */
            if (i < len && isalnum((unsigned char) line[i])) {
                word[w++] = tolower((unsigned char) line[i]);
            } else if (w > 0) {
                word[w] = '\0';
                words++;
                if (strcmp(word, keyword) == 0) hits++;
                w = 0;
            }
        }
    }
    fclose(fp);

    printf("Lines: %d\n", lines);
    printf("Words: %d\n", words);
    printf("Characters: %d\n", chars);
    if (lines == 0) {
        printf("Longest line: none\n");
    } else {
        printf("Longest line: %d (%d characters)\n", longestLine, longest);
    }
    printf("\"%s\" appears %d times\n", keyword, hits);
    return 0;
}
```

### Explanation
`fgets` reads one line at a time, which is the natural unit for counting lines and finding the longest. After the newline is removed, `strlen` gives the visible length.

Words are found by collecting letters and digits into `word` and **finishing** a word when a separator appears. Letting the loop run one step past the end (`i <= len`) finishes a word that ends the line. Each finished word is lowercased as it is collected, so `Exams` and `exams` both match the lowercased keyword with `strcmp`.

`Mid-term` counts as two words (`mid`, `term`) under the stated rule; changing what counts as a word only means changing the `isalnum` test. The first `"` and the last `"` in the output line are printed with `\"`.

### Concepts Practiced
- Reading a file line by line with fgets
- Splitting text into words
- Case-insensitive comparison by lowercasing
- Longest line with tie rule
- Empty-file case
