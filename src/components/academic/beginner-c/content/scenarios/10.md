# Scenario-Based Problems

Strings are character arrays ending with `'\0'`. These problems practise reading text safely (`scanf("%49s", …)` with a width limit, or `fgets`), walking through a string character by character, using `<string.h>` functions (`strlen`, `strcpy`, `strcat`, `strcmp`) and `<ctype.h>` functions (`isdigit`, `isalpha`, `isupper`, `islower`, `toupper`, `tolower`).

`fgets` keeps the newline (`'\n'`) at the end of the line. Most solutions remove it first:

```c
int len = strlen(line);
if (len > 0 && line[len - 1] == '\n') {
    line[len - 1] = '\0';
}
```

Programs read input without prompts and print exactly the sample output. ID formats, department codes and mobile prefixes are defined in each problem for the exercise.

## Problem 1: Student ID Validator
**Level:** Moderate

### Scenario
A (fictional) university's student IDs have 9 digits with a meaning: the first three digits are the department code, the next two are the admission year, and the sixth digit is the admission trimester. The registration form should reject badly typed IDs and show what a valid ID means.

| Part | Digits | Meaning |
|---|---|---|
| Department | 1–3 | `011` CSE, `021` EEE, `031` BBA |
| Year | 4–5 | last two digits of the year (`22` = 2022) |
| Trimester | 6 | `1` Spring, `2` Summer, `3` Fall |
| Serial | 7–9 | any digits |

### Problem Statement
Read one ID as a word (no spaces). Check, in this order, and print the first problem found:

1. `Invalid: ID must have 9 digits` (wrong length)
2. `Invalid: ID must contain only digits`
3. `Invalid: unknown department code <ddd>`
4. `Invalid: trimester digit must be 1, 2 or 3`

For a valid ID print exactly:
```text
Valid ID
Department: <name>
Admitted: <trimester> 20<yy>
```

### Sample Input
```text
011223045
```

### Sample Output
```text
Valid ID
Department: CSE
Admitted: Fall 2022
```

### Solution
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char id[20];
    scanf("%19s", id);

    if (strlen(id) != 9) {
        printf("Invalid: ID must have 9 digits\n");
        return 0;
    }
    for (int i = 0; i < 9; i++) {
        if (!isdigit((unsigned char) id[i])) {
            printf("Invalid: ID must contain only digits\n");
            return 0;
        }
    }

    char dept[4];
    dept[0] = id[0];
    dept[1] = id[1];
    dept[2] = id[2];
    dept[3] = '\0';                 /* make it a proper string */

    if (strcmp(dept, "011") != 0 && strcmp(dept, "021") != 0 && strcmp(dept, "031") != 0) {
        printf("Invalid: unknown department code %s\n", dept);
        return 0;
    }
    if (id[5] < '1' || id[5] > '3') {
        printf("Invalid: trimester digit must be 1, 2 or 3\n");
        return 0;
    }

    printf("Valid ID\n");
    if (strcmp(dept, "011") == 0) printf("Department: CSE\n");
    else if (strcmp(dept, "021") == 0) printf("Department: EEE\n");
    else printf("Department: BBA\n");

    printf("Admitted: ");
    if (id[5] == '1') printf("Spring");
    else if (id[5] == '2') printf("Summer");
    else printf("Fall");
    printf(" 20%c%c\n", id[3], id[4]);
    return 0;
}
```

### Explanation
An ID like `011223045` is stored as **text**, not as a number: as an `int` the leading zero would disappear and `011` could no longer be told apart from `11`.

- `%19s` reads at most 19 characters, so a very long input cannot overflow the 20-byte array.
- `isdigit` checks each character; the `(unsigned char)` cast is the safe way to pass a `char` to the `<ctype.h>` functions.
- To compare the department part with `strcmp`, the first three characters are copied into a small array and **terminated with `'\0'`**; without the terminator `dept` would not be a valid string.
- The year is printed directly from the two digit characters with `%c%c`.

The checks run in a fixed order, and each failure stops the program, so exactly one message is printed.

### Concepts Practiced
- Strings as character arrays
- scanf with a width limit `%19s`
- isdigit from ctype.h
- Building a substring with `'\0'`
- strcmp

## Problem 2: Name Formatter
**Level:** Moderate

### Scenario
Students type their names into the admission form in all sorts of ways: extra spaces, ALL CAPS, all lowercase. The office needs three clean versions: the name in normal capitalisation for certificates, the initials, and the name in capitals for the ID card.

### Problem Statement
Read one line with `fgets` (up to 100 characters). Words are separated by one or more spaces, and there may be spaces at the start and end. If the line has no words, print `No name entered`. Otherwise print exactly:
```text
Formatted: <Word Word Word>
Initials: <W. W. W.>
ID card: <WORD WORD WORD>
```
Words are separated by single spaces, and each word in the formatted name has an uppercase first letter and lowercase remaining letters.

### Sample Input
```text
  rahim   UDDIN ahmed 
```

### Sample Output
```text
Formatted: Rahim Uddin Ahmed
Initials: R. U. A.
ID card: RAHIM UDDIN AHMED
```

### Solution
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char line[110];
    if (fgets(line, sizeof(line), stdin) == NULL) {
        line[0] = '\0';
    }
    int len = strlen(line);
    if (len > 0 && line[len - 1] == '\n') {
        line[--len] = '\0';
    }

    char formatted[110], initials[110], upper[110];
    int f = 0, in = 0, u = 0, words = 0;

    for (int i = 0; i < len; i++) {
        char c = line[i];
        if (c == ' ') continue;

        int startOfWord = (i == 0 || line[i - 1] == ' ');
        if (startOfWord) {
            if (words > 0) {             /* single space between words */
                formatted[f++] = ' ';
                initials[in++] = ' ';
                upper[u++] = ' ';
            }
            words++;
            formatted[f++] = toupper((unsigned char) c);
            initials[in++] = toupper((unsigned char) c);
            initials[in++] = '.';
        } else {
            formatted[f++] = tolower((unsigned char) c);
        }
        upper[u++] = toupper((unsigned char) c);
    }
    formatted[f] = '\0';
    initials[in] = '\0';
    upper[u] = '\0';

    if (words == 0) {
        printf("No name entered\n");
        return 0;
    }
    printf("Formatted: %s\n", formatted);
    printf("Initials: %s\n", initials);
    printf("ID card: %s\n", upper);
    return 0;
}
```

### Explanation
The program walks through the line once and **builds three new strings** at the same time, each with its own write position (`f`, `in`, `u`).

- Spaces in the input are skipped entirely.
- A character starts a word if it is the first character or follows a space. Only then is a single space added to the outputs (but not before the first word), which collapses any run of spaces and removes leading and trailing spaces.
- The first letter of each word goes in uppercase to the formatted name and the initials (followed by `.`); every other letter goes in lowercase to the formatted name. Everything goes in uppercase to the ID-card version.

Each output string is finished with `'\0'` before printing. The arrays are as large as the input line, so the outputs can never be longer than their arrays.

### Concepts Practiced
- fgets and removing the newline
- Building new strings character by character
- toupper and tolower
- Detecting word boundaries
- String terminator `'\0'`


## Problem 3: Password Strength Checker
**Level:** Intermediate

### Scenario
The student portal is introducing new password rules. While a student types a new password, the page shows which requirements are met and an overall strength: **Strong** if the password has at least 8 characters and contains an uppercase letter, a lowercase letter, a digit **and** a special character; **Medium** if it has at least 8 characters and 3 of those 4 kinds; otherwise **Weak**. Any character that is not a letter or digit (including a space) counts as special.

### Problem Statement
Read the password as a whole line with `fgets` (up to 64 characters; it may contain spaces). Print exactly:
```text
Length: <n>
Uppercase: <yes or no>
Lowercase: <yes or no>
Digit: <yes or no>
Special character: <yes or no>
Strength: <Strong, Medium or Weak>
```

### Sample Input
```text
Dhaka2025uiu
```

### Sample Output
```text
Length: 12
Uppercase: yes
Lowercase: yes
Digit: yes
Special character: no
Strength: Medium
```

### Solution
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

void printYesNo(const char label[], int value) {
    printf("%s: ", label);
    if (value) printf("yes\n");
    else printf("no\n");
}

int main() {
    char pw[70];
    if (fgets(pw, sizeof(pw), stdin) == NULL) {
        pw[0] = '\0';
    }
    int len = strlen(pw);
    if (len > 0 && pw[len - 1] == '\n') {
        pw[--len] = '\0';
    }

    int hasUpper = 0, hasLower = 0, hasDigit = 0, hasSpecial = 0;
    for (int i = 0; i < len; i++) {
        unsigned char c = pw[i];
        if (isupper(c)) hasUpper = 1;
        else if (islower(c)) hasLower = 1;
        else if (isdigit(c)) hasDigit = 1;
        else hasSpecial = 1;
    }

    int kinds = hasUpper + hasLower + hasDigit + hasSpecial;

    printf("Length: %d\n", len);
    printYesNo("Uppercase", hasUpper);
    printYesNo("Lowercase", hasLower);
    printYesNo("Digit", hasDigit);
    printYesNo("Special character", hasSpecial);

    if (len >= 8 && kinds == 4) {
        printf("Strength: Strong\n");
    } else if (len >= 8 && kinds >= 3) {
        printf("Strength: Medium\n");
    } else {
        printf("Strength: Weak\n");
    }
    return 0;
}
```

### Explanation
Each character falls into exactly one category, which the `if / else if` chain decides. Four **flags** record whether each category was seen at least once; because they are 0 or 1, adding them gives the number of kinds present.

`fgets` is used instead of `scanf("%s")` because a password may contain spaces, which `%s` would stop at. After the newline is removed, `strlen` gives the real length.

`printYesNo` takes a string parameter (`const char label[]`) and prints it with `%s`, which avoids repeating the same `if-else` four times. The sample has upper, lower and digit characters but no special one: 3 kinds and 12 characters make it Medium.

### Concepts Practiced
- fgets for a line with spaces
- Character classification with ctype.h
- Flags and counting kinds
- Function with a string parameter
- Combined conditions for a rating

## Problem 4: Mobile Number Validator
**Level:** Intermediate

### Scenario
A student club's registration form collects members' mobile numbers. Numbers may be typed with the country code `+88` in front. The club wants to reject invalid numbers and show each number's operator. For this exercise, use this prefix table (the third digit of the 11-digit number):

| Third digit | Operator |
|---|---|
| 3 or 7 | Grameenphone |
| 4 or 9 | Banglalink |
| 5 | Teletalk |
| 6 | Airtel |
| 8 | Robi |

### Problem Statement
Read `N`, then `N` numbers (each a word without spaces). For each number, remove a leading `+88` if present, then check in this order and print the first problem:

1. `Invalid: digits only`
2. `Invalid: must have 11 digits`
3. `Invalid: must start with 01`
4. `Invalid: unknown operator code <d>`

Otherwise print `Valid: <11-digit number> (<operator>)`.

### Sample Input
```text
4
01712345678
+8801898765432
0161234567
02112345678
```

### Sample Output
```text
Valid: 01712345678 (Grameenphone)
Valid: 01898765432 (Robi)
Invalid: must have 11 digits
Invalid: must start with 01
```

### Solution
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    int n;
    scanf("%d", &n);

    for (int k = 0; k < n; k++) {
        char input[40], number[40];
        scanf("%39s", input);

        /* remove the country code if present */
        if (input[0] == '+' && input[1] == '8' && input[2] == '8') {
            strcpy(number, input + 3);
        } else {
            strcpy(number, input);
        }

        int len = strlen(number);
        int allDigits = 1;
        for (int i = 0; i < len; i++) {
            if (!isdigit((unsigned char) number[i])) allDigits = 0;
        }

        if (!allDigits) {
            printf("Invalid: digits only\n");
        } else if (len != 11) {
            printf("Invalid: must have 11 digits\n");
        } else if (number[0] != '0' || number[1] != '1') {
            printf("Invalid: must start with 01\n");
        } else {
            switch (number[2]) {
                case '3': case '7': printf("Valid: %s (Grameenphone)\n", number); break;
                case '4': case '9': printf("Valid: %s (Banglalink)\n", number); break;
                case '5': printf("Valid: %s (Teletalk)\n", number); break;
                case '6': printf("Valid: %s (Airtel)\n", number); break;
                case '8': printf("Valid: %s (Robi)\n", number); break;
                default: printf("Invalid: unknown operator code %c\n", number[2]);
            }
        }
    }
    return 0;
}
```

### Explanation
`input + 3` means "the string starting 3 characters later", so `strcpy(number, input + 3)` copies everything after `+88`. Strings in C are arrays, and an array name used in an expression gives the address of its first character, which is why adding 3 skips three characters.

The checks run from the most basic (only digits) to the most specific (operator code), and an `else if` chain prints only the first failure. The operator is chosen with a `switch` on the third **character**; `case '3': case '7':` lets two values share one branch.

Note that `'3'` (the character) and `3` (the number) are different: the switch compares characters because `number[2]` is a `char`.

### Concepts Practiced
- strcpy and strlen
- Skipping a prefix with `input + 3`
- Validation order with else if
- switch on a character with shared cases

## Problem 5: Notice Headline Formatter
**Level:** Intermediate

### Scenario
Teachers post notices on the department board, and the headlines arrive in every style: `MID-TERM exam ROUTINE`, extra spaces, and so on. The board shows headlines in **Title Case**: each word starts with a capital letter and the rest of the word is lowercase, with single spaces between words.

### Problem Statement
Read one line with `fgets` (up to 200 characters). **Change the string in place** (do not build a second array): collapse runs of spaces into one space, remove leading and trailing spaces, and convert each word to Title Case. Characters that are not letters (digits, `-`) are kept unchanged, and a letter after a `-` stays lowercase. Then count the words.

Print exactly:
```text
Headline: <headline>
Words: <count>
```
If there are no words, the headline is printed as `(empty)`.

### Sample Input
```text
   MID-TERM   exam routine    PUBLISHED  
```

### Sample Output
```text
Headline: Mid-term Exam Routine Published
Words: 4
```

### Solution
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char s[210];
    if (fgets(s, sizeof(s), stdin) == NULL) {
        s[0] = '\0';
    }
    int len = strlen(s);
    if (len > 0 && s[len - 1] == '\n') {
        s[--len] = '\0';
    }

    int write = 0, words = 0;
    int inWord = 0;
    for (int read = 0; read < len; read++) {
        unsigned char c = s[read];
        if (c == ' ') {
            inWord = 0;
            continue;
        }
        if (!inWord) {                      /* first character of a word */
            if (words > 0) s[write++] = ' ';
            s[write++] = toupper(c);
            words++;
            inWord = 1;
        } else {
            s[write++] = tolower(c);
        }
    }
    s[write] = '\0';

    if (words == 0) {
        printf("Headline: (empty)\n");
    } else {
        printf("Headline: %s\n", s);
    }
    printf("Words: %d\n", words);
    return 0;
}
```

### Explanation
The program uses **two indexes on the same array**: `read` moves through the original text and `write` marks where the next kept character goes. Because `write` never gets ahead of `read`, characters are never overwritten before they have been read. This "compact in place" pattern is common in C.

`inWord` remembers whether the previous character was part of a word. When a word starts, a single space is written first (except before the first word), so runs of spaces collapse and leading/trailing spaces disappear. The final `'\0'` cuts off whatever was left of the old text.

`toupper` and `tolower` leave digits and `-` unchanged, so `MID-TERM` becomes `Mid-term` and `1111` stays `1111`.

### Concepts Practiced
- In-place string modification
- Read and write indexes
- State flag for word boundaries
- toupper and tolower

## Problem 6: Course Code Normalizer
**Level:** Challenging

### Scenario
The course registration system receives course codes typed in many forms: `cse1111`, `CSE 1111`, `Eee-2101`, even `C S E 1 1 1 1`. Before searching the course list, the system must convert each one to the standard form `CSE 1111` and reject anything that cannot be a course code. Valid department prefixes (for this exercise) are `CSE`, `EEE`, `MAT`, `PHY` and `ENG`.

### Problem Statement
Read the first line containing `N`, then `N` lines, each read with `fgets`. For each line:

1. Remove all spaces, hyphens and the newline.
2. What remains must be exactly 3 letters followed by 4 digits; otherwise print `<k>: Invalid course code`.
3. Convert the letters to uppercase. If they are not one of the valid departments, print `<k>: Unknown department <DEP>`.
4. Otherwise print `<k>: <DEP> <dddd>`.

`<k>` is the line number (1 to N). Read the first line with `fgets` too and convert it with `atoi`.

### Sample Input
```text
4
cse1111
CSE 2215
Eee-2101
cs1111
```

### Sample Output
```text
1: CSE 1111
2: CSE 2215
3: EEE 2101
4: Invalid course code
```

### Solution
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <ctype.h>

int isValidDepartment(const char dep[]) {
    return strcmp(dep, "CSE") == 0 || strcmp(dep, "EEE") == 0 || strcmp(dep, "MAT") == 0
        || strcmp(dep, "PHY") == 0 || strcmp(dep, "ENG") == 0;
}

int main() {
    char line[100];
    if (fgets(line, sizeof(line), stdin) == NULL) return 0;
    int n = atoi(line);

    for (int k = 1; k <= n; k++) {
        if (fgets(line, sizeof(line), stdin) == NULL) break;

        char clean[100];
        int len = 0;
        for (int i = 0; line[i] != '\0'; i++) {
            char c = line[i];
            if (c != ' ' && c != '-' && c != '\n') {
                clean[len++] = c;
            }
        }
        clean[len] = '\0';

        int ok = (len == 7);
        for (int i = 0; ok && i < 3; i++) {
            if (!isalpha((unsigned char) clean[i])) ok = 0;
        }
        for (int i = 3; ok && i < 7; i++) {
            if (!isdigit((unsigned char) clean[i])) ok = 0;
        }
        if (!ok) {
            printf("%d: Invalid course code\n", k);
            continue;
        }

        char dep[4], num[5];
        for (int i = 0; i < 3; i++) dep[i] = toupper((unsigned char) clean[i]);
        dep[3] = '\0';
        strcpy(num, clean + 3);

        if (!isValidDepartment(dep)) {
            printf("%d: Unknown department %s\n", k, dep);
        } else {
            printf("%d: %s %s\n", k, dep, num);
        }
    }
    return 0;
}
```

### Explanation
The processing is a small **pipeline**: clean → check shape → normalise → look up. Each stage only has to handle what the previous stage produced.

- Cleaning copies every character except spaces, hyphens and the newline into `clean`, so `C S E 1 1 1 1` and `Eee-2101` become `CSE1111` and `Eee2101`.
- The shape check needs length 7, letters in positions 0–2 and digits in 3–6. The `ok &&` in the loop conditions stops checking at the first failure.
- The department part is uppercased into its own small string so it can be compared with `strcmp` inside `isValidDepartment`.

Reading `N` with `fgets` + `atoi` avoids a classic bug: after `scanf("%d", &n)`, the newline is still waiting in the input, and the next `fgets` would read an empty line instead of the first course code.

### Concepts Practiced
- fgets with atoi
- Filtering characters into a new string
- isalpha, isdigit, toupper
- strcpy from an offset
- Helper function using strcmp

## Problem 7: Club Message Cipher
**Level:** Challenging

### Scenario
The programming club hides the answer to its weekly puzzle with a Caesar cipher: each letter is shifted forward in the alphabet by a secret number, wrapping from `z` back to `a`. Uppercase stays uppercase, lowercase stays lowercase, and anything that is not a letter is unchanged. Members need a tool that can both encrypt and decrypt.

### Problem Statement
The first line has a mode (`E` to encrypt, `D` to decrypt) and the shift (a whole number, possibly negative or larger than 26). The second line is the message (up to 200 characters). If the mode is not `E` or `D`, print `Invalid mode`. Otherwise print the converted message on one line.

A shift of `k` works the same as `k` modulo 26, so 29 behaves like 3 and −1 like 25. Decrypting with `k` is encrypting with `26 − k`.

### Sample Input
```text
E 3
Meet at Lab 3, 5 PM!
```

### Sample Output
```text
Phhw dw Ode 3, 5 SP!
```

### Solution
```c
#include <stdio.h>
#include <string.h>

int main() {
    char mode;
    int shift;
    char msg[210];

    scanf(" %c %d", &mode, &shift);
    fgets(msg, sizeof(msg), stdin);            /* discard the rest of line 1 */
    if (fgets(msg, sizeof(msg), stdin) == NULL) {
        msg[0] = '\0';
    }
    int len = strlen(msg);
    if (len > 0 && msg[len - 1] == '\n') {
        msg[--len] = '\0';
    }

    if (mode != 'E' && mode != 'D') {
        printf("Invalid mode\n");
        return 0;
    }

    int k = ((shift % 26) + 26) % 26;          /* 0..25, also for negative shifts */
    if (mode == 'D') {
        k = (26 - k) % 26;
    }

    for (int i = 0; i < len; i++) {
        char c = msg[i];
        if (c >= 'A' && c <= 'Z') {
            msg[i] = 'A' + (c - 'A' + k) % 26;
        } else if (c >= 'a' && c <= 'z') {
            msg[i] = 'a' + (c - 'a' + k) % 26;
        }
    }
    printf("%s\n", msg);
    return 0;
}
```

### Explanation
Each letter is converted to a position 0–25 (`c − 'A'`), shifted, wrapped with `% 26`, and converted back (`'A' + …`). For `M`: 12 + 3 = 15 → `P`; for `y`: 24 + 3 = 27 → 27 % 26 = 1 → `b`.

In C, `%` of a negative number is negative (−1 % 26 is −1), so `((shift % 26) + 26) % 26` is used to turn any shift into a value from 0 to 25. Decryption then reuses the same encryption loop with the opposite shift.

`scanf(" %c %d", …)` leaves the end of the first line in the input. The first `fgets` swallows that leftover, and the second `fgets` reads the actual message, spaces included.

### Concepts Practiced
- Character arithmetic with wrap-around
- Modulo with negative numbers
- Mixing scanf and fgets safely
- Modifying a string in place

## Problem 8: Student Email Generator
**Level:** Challenging

### Scenario
The IT office creates email accounts for new students (fictional domain `student.example.edu`). The username is the first letter of the first name, the last name with letters only, and the last three digits of the student ID, all in lowercase: Rahim Ahmed with ID 011221045 becomes `rahmed045`. Different students can produce the same username, so the second one gets `_2`, the third `_3`, and so on.

### Problem Statement
Read `N` (at most 50), then `N` lines, each with first name, last name and student ID (three words). If the ID has fewer than 3 characters or contains a non-digit, print `<first> <last> -> invalid ID`. Otherwise print:
```text
<first> <last> -> <username>@student.example.edu
```
where `<username>` is the base username, plus `_<k>` if `k − 1` earlier students in this batch already got the same base. Names are printed exactly as typed.

### Sample Input
```text
4
Rahim Ahmed 011221045
Rafiq Ahmed 011223045
nusrat JAHAN 011222117
Tanvir Hasan 01122X001
```

### Sample Output
```text
Rahim Ahmed -> rahmed045@student.example.edu
Rafiq Ahmed -> rahmed045_2@student.example.edu
nusrat JAHAN -> njahan117@student.example.edu
Tanvir Hasan -> invalid ID
```

### Solution
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    int n;
    scanf("%d", &n);
    if (n > 50) n = 50;

    char used[50][80];          /* base usernames given so far */
    int usedCount = 0;

    for (int k = 0; k < n; k++) {
        char first[50], last[50], id[20];
        scanf("%49s %49s %19s", first, last, id);

        int len = strlen(id);
        int valid = (len >= 3);
        for (int i = 0; i < len; i++) {
            if (!isdigit((unsigned char) id[i])) valid = 0;
        }
        if (!valid) {
            printf("%s %s -> invalid ID\n", first, last);
            continue;
        }

        char base[80];
        int b = 0;
        base[b++] = tolower((unsigned char) first[0]);
        for (int i = 0; last[i] != '\0'; i++) {
            if (isalpha((unsigned char) last[i])) {
                base[b++] = tolower((unsigned char) last[i]);
            }
        }
        for (int i = len - 3; i < len; i++) {
            base[b++] = id[i];
        }
        base[b] = '\0';

        int same = 0;
        for (int i = 0; i < usedCount; i++) {
            if (strcmp(used[i], base) == 0) same++;
        }
        strcpy(used[usedCount], base);
        usedCount++;

        printf("%s %s -> %s", first, last, base);
        if (same > 0) {
            printf("_%d", same + 1);
        }
        printf("@student.example.edu\n");
    }
    return 0;
}
```

### Explanation
`char used[50][80]` is an **array of strings**: 50 rows, each a character array of 80. Each new base username is compared with all earlier ones using `strcmp` and then stored with `strcpy`.

The username is built character by character into `base`: the first letter of the first name, every **letter** of the last name (so a hyphen in a name like `Al-Amin` is skipped), and the last three characters of the ID (`len − 3` up to `len − 1`). Every letter goes through `tolower`, so `JAHAN` becomes `jahan`.

Counting earlier matches gives the suffix directly: Rafiq Ahmed's base `rahmed045` matches one earlier entry, so he gets `_2`. Invalid IDs are rejected before a username is built, so they never take up a name. The `%49s` and `%19s` limits keep every word inside its array.

### Concepts Practiced
- Array of strings (2D char array)
- strcmp and strcpy for bookkeeping
- Building a string from parts
- isalpha, isdigit, tolower
- Width limits in scanf
