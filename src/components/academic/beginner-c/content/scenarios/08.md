# Scenario-Based Problems

In these problems the main goal is **structure**: split the work into functions that each do one clear job, give them meaningful names, parameters and return values, and keep `main` short. Several problems reuse the same function many times, and two use recursion.

Programs read input without prompts and print exactly the sample output. Grading scales, fees and rates are hypothetical and chosen for practice.

## Problem 1: Letter Grade Function
**Level:** Moderate

### Scenario
A course coordinator is building a small result tool. The same grading scale is needed in many places, so it must live in functions rather than be copied into `main`. The scale used in this exercise is:

| Marks | Grade | Point |
|---|---|---|
| 90–100 | A | 4.00 |
| 86–89 | A- | 3.67 |
| 82–85 | B+ | 3.33 |
| 78–81 | B | 3.00 |
| 74–77 | B- | 2.67 |
| 70–73 | C+ | 2.33 |
| 66–69 | C | 2.00 |
| 62–65 | C- | 1.67 |
| 58–61 | D+ | 1.33 |
| 55–57 | D | 1.00 |
| below 55 | F | 0.00 |

### Problem Statement
Write three functions:

- `int gradeIndex(int marks)` returns 0 for A, 1 for A-, …, 10 for F (the row of the table);
- `double gradePoint(int index)` returns the point for a row;
- `void printLetter(int index)` prints the letter for a row.

`main` reads the marks of three courses. For each course print `Course <k>: <marks> -> <letter> (<point>)`, or `Course <k>: invalid marks` if the marks are outside 0–100.

### Sample Input
```text
87 72 54
```

### Sample Output
```text
Course 1: 87 -> A- (3.67)
Course 2: 72 -> C+ (2.33)
Course 3: 54 -> F (0.00)
```

### Solution
```c
#include <stdio.h>

int gradeIndex(int marks) {
    if (marks >= 90) return 0;
    if (marks >= 86) return 1;
    if (marks >= 82) return 2;
    if (marks >= 78) return 3;
    if (marks >= 74) return 4;
    if (marks >= 70) return 5;
    if (marks >= 66) return 6;
    if (marks >= 62) return 7;
    if (marks >= 58) return 8;
    if (marks >= 55) return 9;
    return 10;
}

double gradePoint(int index) {
    switch (index) {
        case 0: return 4.00;
        case 1: return 3.67;
        case 2: return 3.33;
        case 3: return 3.00;
        case 4: return 2.67;
        case 5: return 2.33;
        case 6: return 2.00;
        case 7: return 1.67;
        case 8: return 1.33;
        case 9: return 1.00;
        default: return 0.00;
    }
}

void printLetter(int index) {
    switch (index) {
        case 0: printf("A"); break;
        case 1: printf("A-"); break;
        case 2: printf("B+"); break;
        case 3: printf("B"); break;
        case 4: printf("B-"); break;
        case 5: printf("C+"); break;
        case 6: printf("C"); break;
        case 7: printf("C-"); break;
        case 8: printf("D+"); break;
        case 9: printf("D"); break;
        default: printf("F");
    }
}

int main() {
    for (int course = 1; course <= 3; course++) {
        int marks;
        scanf("%d", &marks);

        if (marks < 0 || marks > 100) {
            printf("Course %d: invalid marks\n", course);
            continue;
        }

        int index = gradeIndex(marks);
        printf("Course %d: %d -> ", course, marks);
        printLetter(index);
        printf(" (%.2f)\n", gradePoint(index));
    }
    return 0;
}
```

### Explanation
The marks-to-row decision is written **once**, in `gradeIndex`. The other two functions only translate a row number into a point or a letter, so if the university changes a boundary, only one line changes.

Inside `gradeIndex`, each `return` leaves the function immediately, so the checks can be written from the top band down without `else`: by the time `marks >= 86` is tested, we already know `marks < 90`.

`printLetter` returns nothing (`void`); it is called for its effect (printing). `gradePoint` returns a value that is used directly inside `printf`. The `continue` in `main` skips the rest of the loop body for invalid marks.

### Concepts Practiced
- Functions with parameters and return values
- void functions
- return inside if and switch
- Calling functions from a loop
- continue

## Problem 2: Lab Task Timer
**Level:** Moderate

### Scenario
An online judge used in programming labs records how long each task took, in seconds. The lab report should show durations in a friendly form such as `1 h 2 min 5 s`, leaving out parts that are zero (`1 min`, not `0 h 1 min 0 s`).

### Problem Statement
Write a function `void printDuration(int seconds)` that prints a duration in that form (nothing else, no newline):

- print `<h> h`, `<m> min` and `<s> s`, separated by single spaces, skipping any part that is 0;
- if all parts are 0, print `0 s`.

`main` reads `N` and then `N` durations, prints each as `Task <k>: ...`, and finally the total of all durations as `Total: ...`.

### Sample Input
```text
3
3725 60 45
```

### Sample Output
```text
Task 1: 1 h 2 min 5 s
Task 2: 1 min
Task 3: 45 s
Total: 1 h 3 min 50 s
```

### Solution
```c
#include <stdio.h>

void printDuration(int seconds) {
    int h = seconds / 3600;
    int m = seconds % 3600 / 60;
    int s = seconds % 60;
    int printedSomething = 0;

    if (h > 0) {
        printf("%d h", h);
        printedSomething = 1;
    }
    if (m > 0) {
        if (printedSomething) printf(" ");
        printf("%d min", m);
        printedSomething = 1;
    }
    if (s > 0) {
        if (printedSomething) printf(" ");
        printf("%d s", s);
        printedSomething = 1;
    }
    if (!printedSomething) {
        printf("0 s");
    }
}

int main() {
    int n, total = 0;
    scanf("%d", &n);

    for (int k = 1; k <= n; k++) {
        int seconds;
        scanf("%d", &seconds);
        total += seconds;

        printf("Task %d: ", k);
        printDuration(seconds);
        printf("\n");
    }

    printf("Total: ");
    printDuration(total);
    printf("\n");
    return 0;
}
```

### Explanation
`printDuration` is written once and called `N + 1` times: once per task and once for the total. That is the main benefit of a function: the formatting rules live in one place.

The `printedSomething` flag decides whether a space is needed before the next part, so there is never a leading or double space. If nothing was printed, the duration was 0 and `0 s` is shown.

The function does not print a newline; the caller decides what comes after. Keeping functions free of surrounding text makes them reusable in other contexts (`Task 1: ...`, `Total: ...`).

- void function with a parameter
- Reusing a function many times
- Flag variable for separators
- Integer division and modulus

## Problem 3: Trimester Fee Calculator
**Level:** Intermediate

### Scenario
The accounts office wants a fee calculator built from small, testable functions. Under the (fictional) rules: tuition is 6500 Tk per credit; each lab course has a 1500 Tk lab fee; every student pays a 7000 Tk trimester fee; and a CGPA-based waiver applies to the **tuition only**, for students taking at least 12 credits: 100% for CGPA ≥ 3.90, 50% for ≥ 3.75, 25% for ≥ 3.50, otherwise 0%.

### Problem Statement
Write and use these functions:

- `double tuitionFee(int credits)`
- `int waiverPercent(double cgpa, int credits)`
- `double labFees(int labCourses)`

`main` reads credits, number of lab courses and CGPA, and prints exactly (two decimals):
```text
Tuition: <t> Tk
Waiver (<p> percent): <w> Tk
Lab fees: <l> Tk
Trimester fee: 7000.00 Tk
Total payable: <total> Tk
```

### Sample Input
```text
12 2 3.80
```

### Sample Output
```text
Tuition: 78000.00 Tk
Waiver (50 percent): 39000.00 Tk
Lab fees: 3000.00 Tk
Trimester fee: 7000.00 Tk
Total payable: 49000.00 Tk
```

### Solution
```c
#include <stdio.h>

double tuitionFee(int credits) {
    return credits * 6500.0;
}

int waiverPercent(double cgpa, int credits) {
    if (credits < 12) return 0;      /* waiver needs a full load */
    if (cgpa >= 3.90) return 100;
    if (cgpa >= 3.75) return 50;
    if (cgpa >= 3.50) return 25;
    return 0;
}

double labFees(int labCourses) {
    return labCourses * 1500.0;
}

int main() {
    int credits, labs;
    double cgpa;
    scanf("%d %d %lf", &credits, &labs, &cgpa);

    double tuition = tuitionFee(credits);
    int percent = waiverPercent(cgpa, credits);
    double waiver = tuition * percent / 100;
    double lab = labFees(labs);
    double trimesterFee = 7000.0;
    double total = tuition - waiver + lab + trimesterFee;

    printf("Tuition: %.2f Tk\n", tuition);
    printf("Waiver (%d percent): %.2f Tk\n", percent, waiver);
    printf("Lab fees: %.2f Tk\n", lab);
    printf("Trimester fee: %.2f Tk\n", trimesterFee);
    printf("Total payable: %.2f Tk\n", total);
    return 0;
}
```

### Explanation
Each fee rule has its own function, so each can be checked separately: `tuitionFee(12)` must be 78000, `waiverPercent(3.95, 9)` must be 0, and so on. `main` only reads input, combines the results and prints.

`waiverPercent` takes **two** parameters because the rule depends on both CGPA and credits. Putting the credit check inside the function (instead of in `main`) keeps the whole waiver rule in one place.

With the sample: tuition 78000, a 50% waiver of 39000, lab fees 3000, trimester fee 7000, total 49000.

### Concepts Practiced
- Functions returning double and int
- Functions with several parameters
- Splitting a calculation into small functions
- Early return

## Problem 4: Trimester GPA Calculator
**Level:** Intermediate

### Scenario
A student wants to calculate her trimester GPA. Courses have different credits (theory courses 3 credits, labs 1.5 credits), so the GPA is a **weighted** average of grade points. Failed courses (F, below 55) count in the GPA but do not add to the credits earned. Use the grading scale from Problem 1.

### Problem Statement
Write a function `double gradePointFor(int marks)` that returns the grade point for a mark (scale from Problem 1). `main` reads `N` and then `N` lines, each with the course credits (decimal) and the marks (whole number).

- If `N` is less than 1, print `No courses`.
- GPA = Σ(credits × grade point) ÷ Σ credits, printed with 2 decimals.
- Credits attempted = Σ credits; credits earned = Σ credits of courses with marks ≥ 55. Print credits with 1 decimal.

Print exactly:
```text
GPA: <gpa>
Credits attempted: <c>
Credits earned: <c>
```

### Sample Input
```text
4
3 87
3 72
1.5 91
3 54
```

### Sample Output
```text
GPA: 2.29
Credits attempted: 10.5
Credits earned: 7.5
```

### Solution
```c
#include <stdio.h>

double gradePointFor(int marks) {
    if (marks >= 90) return 4.00;
    if (marks >= 86) return 3.67;
    if (marks >= 82) return 3.33;
    if (marks >= 78) return 3.00;
    if (marks >= 74) return 2.67;
    if (marks >= 70) return 2.33;
    if (marks >= 66) return 2.00;
    if (marks >= 62) return 1.67;
    if (marks >= 58) return 1.33;
    if (marks >= 55) return 1.00;
    return 0.00;
}

int main() {
    int n;
    scanf("%d", &n);
    if (n < 1) {
        printf("No courses\n");
        return 0;
    }

    double attempted = 0, earned = 0, qualityPoints = 0;
    for (int i = 0; i < n; i++) {
        double credits;
        int marks;
        scanf("%lf %d", &credits, &marks);

        double gp = gradePointFor(marks);
        qualityPoints += credits * gp;
        attempted += credits;
        if (marks >= 55) {
            earned += credits;
        }
    }

    printf("GPA: %.2f\n", qualityPoints / attempted);
    printf("Credits attempted: %.1f\n", attempted);
    printf("Credits earned: %.1f\n", earned);
    return 0;
}
```

### Explanation
A weighted average multiplies each value by its weight before adding:

| Course | Credits | Point | Credits × Point |
|---|---|---|---|
| 87 | 3 | 3.67 | 11.01 |
| 72 | 3 | 2.33 | 6.99 |
| 91 | 1.5 | 4.00 | 6.00 |
| 54 | 3 | 0.00 | 0.00 |

Total quality points = 24.00, credits = 10.5, so GPA = 24.00 ÷ 10.5 = 2.2857… → 2.29. A simple average of the four points (2.50) would overstate the GPA because the 1.5-credit lab counts as much as a 3-credit course.

The grading logic is in `gradePointFor`, so `main` reads like the definition of GPA.

- Function returning a double
- Weighted average
- Accumulating several totals in a loop
- Reading mixed-type pairs

## Problem 5: Prime Locker Allocation
**Level:** Intermediate

### Scenario
The university gym numbers its lockers from 1 to `L`. As a fun tradition (fictional), members may only rent lockers with **prime** numbers. If a student asks for a locker that is not prime, the system offers the next prime-numbered locker instead, if one exists.

### Problem Statement
Write `int isPrime(int n)` (returns 1 or 0) and `int nextPrime(int n)` (returns the smallest prime that is ≥ `n`). `main` reads `L` and the number of requests `Q`, then `Q` requested locker numbers. For each request print one line:

- `Locker <k>: invalid request` if `k` is outside 1–L;
- `Locker <k>: granted` if `k` is prime;
- `Locker <k>: not prime, offered <p>` if the next prime `p` is ≤ L;
- `Locker <k>: no prime locker available` otherwise.

### Sample Input
```text
100 4
17 20 90 98
```

### Sample Output
```text
Locker 17: granted
Locker 20: not prime, offered 23
Locker 90: not prime, offered 97
Locker 98: no prime locker available
```

### Solution
```c
#include <stdio.h>

int isPrime(int n) {
    if (n < 2) return 0;
    for (int d = 2; d * d <= n; d++) {
        if (n % d == 0) return 0;
    }
    return 1;
}

int nextPrime(int n) {
    while (!isPrime(n)) {
        n++;
    }
    return n;
}

int main() {
    int lockers, requests;
    scanf("%d %d", &lockers, &requests);

    for (int i = 0; i < requests; i++) {
        int k;
        scanf("%d", &k);

        if (k < 1 || k > lockers) {
            printf("Locker %d: invalid request\n", k);
        } else if (isPrime(k)) {
            printf("Locker %d: granted\n", k);
        } else {
            int p = nextPrime(k);
            if (p <= lockers) {
                printf("Locker %d: not prime, offered %d\n", k, p);
            } else {
                printf("Locker %d: no prime locker available\n", k);
            }
        }
    }
    return 0;
}
```

### Explanation
`nextPrime` is built **on top of** `isPrime`: it keeps moving forward until `isPrime` says yes. Functions calling other functions is how larger programs are built from small, trusted pieces.

`isPrime` only tests divisors up to the square root (`d * d <= n`): if `n` had a divisor larger than its square root, it would also have a matching one smaller than it. It treats 0 and 1 as not prime.

`nextPrime` always finishes because there is always a larger prime. The program then checks whether that prime is still a real locker number (98 → 101, but there are only 100 lockers).

### Concepts Practiced
- Functions returning int as true/false
- A function that calls another function
- Prime test up to the square root
- if-else if chain in a loop

## Problem 6: E-Ticket Check Digit
**Level:** Challenging

### Scenario
A (fictional) railway e-ticket system adds a **check digit** to the end of every ticket number to catch typing mistakes at the gate. The check digit is the **digital root** of the rest of the number: add its digits, and if the result has more than one digit, add those digits again, until a single digit remains. For example, the rest 482531 → 4+8+2+5+3+1 = 23 → 2+3 = 5, so 4825315 is a valid ticket.

### Problem Statement
Write two **recursive** functions:

- `int digitSum(long long n)` returns the sum of the digits of `n`;
- `int digitalRoot(long long n)` returns `n` if it is a single digit (0–9), otherwise the digital root of `digitSum(n)`.

`main` reads `N` and then `N` ticket numbers (up to 18 digits, so use `long long` with `%lld`). For each ticket, the rest is `ticket / 10` and the check digit is `ticket % 10`. Print `<ticket>: valid` or `<ticket>: invalid (check digit should be <d>)`.

### Sample Input
```text
3
4825315
1234567893
99
```

### Sample Output
```text
4825315: valid
1234567893: invalid (check digit should be 9)
99: valid
```

### Solution
```c
#include <stdio.h>

int digitSum(long long n) {
    if (n == 0) {
        return 0;                               /* base case */
    }
    return (int) (n % 10) + digitSum(n / 10);   /* last digit + sum of the rest */
}

int digitalRoot(long long n) {
    if (n < 10) {
        return (int) n;                         /* base case: single digit */
    }
    return digitalRoot(digitSum(n));
}

int main() {
    int n;
    scanf("%d", &n);

    for (int i = 0; i < n; i++) {
        long long ticket;
        scanf("%lld", &ticket);

        int expected = digitalRoot(ticket / 10);
        int actual = (int) (ticket % 10);

        if (expected == actual) {
            printf("%lld: valid\n", ticket);
        } else {
            printf("%lld: invalid (check digit should be %d)\n", ticket, expected);
        }
    }
    return 0;
}
```

### Explanation
Both functions follow the recursion recipe: a **base case** that answers directly, and a **recursive case** that moves closer to the base case.

- `digitSum(482531)` = 1 + `digitSum(48253)` = 1 + 3 + `digitSum(4825)` = … = 23. Each call removes one digit, so it must reach 0.
- `digitalRoot(482531)` = `digitalRoot(23)` = `digitalRoot(5)` = 5. Each call works on a smaller number, so it must reach a single digit.

For 1234567893, the rest 123456789 has digit sum 45, whose digit sum is 9, but the last digit is 3, so the ticket is rejected. A ticket with a single digit has rest 0, whose digital root is 0.

`long long` holds numbers up to about 9.2 × 10¹⁸, which is why 10-digit tickets are safe. The `(int)` casts make it clear that a digit sum always fits in an `int`.

### Concepts Practiced
- Recursive functions with base cases
- A recursive function calling another function
- long long with `%lld`
- Digit processing with `%` and `/`

## Problem 7: Club Committee Selection
**Level:** Challenging

### Scenario
The university programming club has `n` members and must choose a committee of `r` members. The adviser asks three questions:

1. In how many ways can the committee be chosen?
2. The current president must be on the committee. In how many ways can the rest be chosen?
3. Two members (call them the rivals) refuse to work together. In how many committees are they **not both** included?

### Problem Statement
Write a **recursive** function `long long combinations(int n, int r)` using Pascal's rule:

- C(n, r) = 1 when r = 0 or r = n,
- C(n, r) = C(n − 1, r − 1) + C(n − 1, r) otherwise,

and return 0 when r < 0 or r > n.

`main` reads `n` and `r`. If `n` is not between 2 and 20, or `r` is outside 0–n, print `Invalid input`. Otherwise:

1. all committees = C(n, r)
2. with the president = C(n − 1, r − 1)
3. without both rivals together = C(n, r) − C(n − 2, r − 2)

Print exactly:
```text
Ways to choose the committee: <a>
With the president included: <b>
Without both rivals together: <c>
```

### Sample Input
```text
10 5
```

### Sample Output
```text
Ways to choose the committee: 252
With the president included: 126
Without both rivals together: 196
```

### Solution
```c
#include <stdio.h>

long long combinations(int n, int r) {
    if (r < 0 || r > n) return 0;
    if (r == 0 || r == n) return 1;
    return combinations(n - 1, r - 1) + combinations(n - 1, r);
}

int main() {
    int n, r;
    scanf("%d %d", &n, &r);

    if (n < 2 || n > 20 || r < 0 || r > n) {
        printf("Invalid input\n");
        return 0;
    }

    long long all = combinations(n, r);
    long long withPresident = combinations(n - 1, r - 1);
    long long bothRivals = combinations(n - 2, r - 2);

    printf("Ways to choose the committee: %lld\n", all);
    printf("With the president included: %lld\n", withPresident);
    printf("Without both rivals together: %lld\n", all - bothRivals);
    return 0;
}
```

### Explanation
Pascal's rule comes from looking at one particular member: either they are on the committee (choose the other `r − 1` from the remaining `n − 1`) or they are not (choose all `r` from the remaining `n − 1`). The recursion stops at the edges, where there is exactly one way (choose nobody, or choose everybody).

The other two answers reuse the same function:

- If the president is fixed on the committee, only `r − 1` seats are left for the other `n − 1` members: C(9, 4) = 126.
- Committees containing **both** rivals fill the other `r − 2` seats from `n − 2` members: C(8, 3) = 56. Subtracting them from all 252 committees leaves 196.

Returning 0 for an impossible `r` (such as `r − 2 = −2` when `r = 0`) makes these formulas work at the edges without extra `if`s.

This recursion recomputes the same values many times, so it becomes slow for large `n`; that is why `n` is limited to 20 here. In an algorithms course you will learn to store results to avoid repeated work.

### Concepts Practiced
- Recursion with two recursive calls
- Base cases and invalid-argument cases
- Reusing one function for related questions
- long long results

## Problem 8: Apartment Water Bills
**Level:** Challenging

### Scenario
An apartment building's management committee (fictional rates) charges water by slabs per flat: the first 10 units at 15 Tk per unit, the next 20 units (11–30) at 22 Tk per unit, and every unit above 30 at 35 Tk. Every flat pays at least 100 Tk. Sometimes a meter reading is entered as a negative number by mistake; such a flat is reported and left out of the totals.

### Problem Statement
Write `double waterBill(int units)` for one flat (including the 100 Tk minimum). `main` reads the number of flats and then each flat's units. Print one line per flat, then the building summary over **valid** flats only. The highest bill goes to the first flat if there is a tie. If no reading is valid, print `No valid readings` instead of the summary.

Print exactly (two decimals for money):
```text
Flat <k>: <units> units, <bill> Tk
Flat <k>: invalid reading
...
Total: <total> Tk
Highest: Flat <k> (<bill> Tk)
Average: <average> Tk
```

### Sample Input
```text
4
8 25 40 0
```

### Sample Output
```text
Flat 1: 8 units, 120.00 Tk
Flat 2: 25 units, 480.00 Tk
Flat 3: 40 units, 940.00 Tk
Flat 4: 0 units, 100.00 Tk
Total: 1640.00 Tk
Highest: Flat 3 (940.00 Tk)
Average: 410.00 Tk
```

### Solution
```c
#include <stdio.h>

double waterBill(int units) {
    double bill;
    if (units <= 10) {
        bill = units * 15.0;
    } else if (units <= 30) {
        bill = 10 * 15.0 + (units - 10) * 22.0;
    } else {
        bill = 10 * 15.0 + 20 * 22.0 + (units - 30) * 35.0;
    }
    if (bill < 100) {
        bill = 100;                 /* minimum charge */
    }
    return bill;
}

int main() {
    int flats;
    scanf("%d", &flats);

    double total = 0, highest = 0;
    int highestFlat = 0, validFlats = 0;

    for (int k = 1; k <= flats; k++) {
        int units;
        scanf("%d", &units);

        if (units < 0) {
            printf("Flat %d: invalid reading\n", k);
            continue;
        }

        double bill = waterBill(units);
        printf("Flat %d: %d units, %.2f Tk\n", k, units, bill);

        total += bill;
        validFlats++;
        if (validFlats == 1 || bill > highest) {
            highest = bill;
            highestFlat = k;
        }
    }

    if (validFlats == 0) {
        printf("No valid readings\n");
        return 0;
    }
    printf("Total: %.2f Tk\n", total);
    printf("Highest: Flat %d (%.2f Tk)\n", highestFlat, highest);
    printf("Average: %.2f Tk\n", total / validFlats);
    return 0;
}
```

### Explanation
The slab rule and the minimum charge are hidden inside `waterBill`, so `main` only deals with the building: reading, skipping invalid flats, and keeping running totals.

- Flat 1: 8 units → 120 (above the minimum).
- Flat 2: 25 units → 10 × 15 + 15 × 22 = 150 + 330 = 480.
- Flat 3: 40 units → 150 + 440 + 10 × 35 = 940.
- Flat 4: 0 units → 0, raised to the 100 Tk minimum.

`continue` skips the rest of the loop body for an invalid reading, so it is never added to the totals. The average divides by the number of **valid** flats, not by the number of flats read, and the program checks for zero valid flats before dividing.

### Concepts Practiced
- Function returning a double
- Slab calculation and minimum charge inside a function
- continue to skip invalid data
- Running total, maximum and count
