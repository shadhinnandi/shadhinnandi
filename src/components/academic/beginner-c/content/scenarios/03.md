# Scenario-Based Problems

Now your programs read data with `scanf`. Each program reads its input exactly as shown under **Sample Input** and prints exactly what is shown under **Sample Output**. Do **not** print prompts such as `Enter amount:` in these problems: like an online judge or an auto-graded lab exam, the output is compared line by line.

Money and measurements are stored as `double`. To read a `double` with `scanf`, use `%lf` (for `printf`, `%f` and `%.2f` work for both `float` and `double`). You can assume the input is valid; checking it with `if` comes in Chapter 05.

## Problem 1: Boro Bhai's Service Charge
**Level:** Moderate

### Scenario
The elakar boro bhai has opened a small restaurant, "Boro Bhai's Bhaat Ghor". He proudly announces that, "like the big restaurants in Gulshan", he will add a 10% service charge to every bill. His nephew, who runs the counter, keeps miscalculating it and asks you for a program.

### Problem Statement
Read the original bill amount (a decimal number). Calculate the 10% service charge on the original bill and the total payable amount.

Print exactly (two decimals):
```text
Original bill: <bill> Tk
Service charge (10 percent): <charge> Tk
Total payable: <total> Tk
```

### Sample Input
```text
850
```

### Sample Output
```text
Original bill: 850.00 Tk
Service charge (10 percent): 85.00 Tk
Total payable: 935.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double bill;
    scanf("%lf", &bill);

    double serviceCharge = bill * 10 / 100;
    double total = bill + serviceCharge;

    printf("Original bill: %.2f Tk\n", bill);
    printf("Service charge (10 percent): %.2f Tk\n", serviceCharge);
    printf("Total payable: %.2f Tk\n", total);
    return 0;
}
```

### Explanation
The service charge is a percentage **of the original bill**: 850 × 10 ÷ 100 = 85. The total is the bill plus the charge, 935.

`%lf` reads the number into a `double`. Writing `%f` here (which is for `float`) is a classic bug: `scanf` would store the bits in the wrong format and the program would print nonsense.

Note that `bill * 10 / 100` and `bill / 100 * 10` give the same result for `double` values, but for `int` values the second form loses the remainder of `bill / 100`. Multiplying first is the safer habit.

### Concepts Practiced
- scanf with `%lf`
- Percentage calculation
- Formatted output with `%.2f`

### Test Cases

**Expected Output**
```text

Total payable: 1357.95 Tk
```

#### Empty bill
**Input**
```text
0
```
**Expected Output**
```text

Service charge (10 percent): 0.00 Tk
Total payable: 0.00 Tk
```

## Problem 2: Lab Temperature Log
**Level:** Moderate

### Scenario
The computer lab's air conditioner panel shows the temperature in Celsius, but the lab assistant's maintenance form asks for Fahrenheit and Kelvin. He reads the panel several times a day and wants a quick converter.

### Problem Statement
Read a temperature in Celsius (a decimal number). Convert it using:

- Fahrenheit = Celsius × 9 ÷ 5 + 32
- Kelvin = Celsius + 273.15

Print exactly (two decimals):
```text
Fahrenheit: <f>
Kelvin: <k>
```

### Sample Input
```text
27.5
```

### Sample Output
```text
Fahrenheit: 81.50
Kelvin: 300.65
```

### Solution
```c
#include <stdio.h>

int main() {
    double celsius;
    scanf("%lf", &celsius);

    double fahrenheit = celsius * 9 / 5 + 32;
    double kelvin = celsius + 273.15;

    printf("Fahrenheit: %.2f\n", fahrenheit);
    printf("Kelvin: %.2f\n", kelvin);
    return 0;
}
```

### Explanation
`celsius * 9 / 5` is evaluated left to right: 27.5 × 9 = 247.5, then ÷ 5 = 49.5, plus 32 = 81.5.

Be careful with the order and the types if you write the formula differently. `9 / 5 * celsius` looks the same on paper, but `9 / 5` is integer division and equals 1, so the result would be wrong. Because `celsius` is a `double` and comes first, every step of `celsius * 9 / 5` is done in floating point.

### Concepts Practiced
- scanf with `%lf`
- Operator precedence and left-to-right evaluation
- Avoiding integer division in formulas

### Test Cases
#### Where the scales meet
**Input**
```text

```
**Expected Output**


#### Boiling point

**Expected Output**
```text

```

#### Freezing point
**Input**
```text
0
```
**Expected Output**
```text

```

## Problem 3: Retake Fee Calculator
**Level:** Intermediate

### Scenario
A student is registering for the new trimester. Some of his courses are new and some are retakes. Under his university's (fictional) rules, new courses cost the full per-credit fee, retake courses cost **half** the per-credit fee, and every student pays a fixed trimester fee.

### Problem Statement
Read four values on one line: new credits (whole number), retake credits (whole number), per-credit fee, and trimester fee (decimals). Calculate the cost of the new courses, the cost of the retake courses, and the total payable.

Print exactly (two decimals):
```text
New courses: <new cost> Tk
Retake courses: <retake cost> Tk
Trimester fee: <fee> Tk
Total payable: <total> Tk
```

### Sample Input
```text
9 3 6500 7000
```

### Sample Output
```text
New courses: 58500.00 Tk
Retake courses: 9750.00 Tk
Trimester fee: 7000.00 Tk
Total payable: 75250.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    int newCredits, retakeCredits;
    double perCredit, trimesterFee;
    scanf("%d %d %lf %lf", &newCredits, &retakeCredits, &perCredit, &trimesterFee);

    double newCost = newCredits * perCredit;
    double retakeCost = retakeCredits * perCredit * 0.5;   /* half fee */
    double total = newCost + retakeCost + trimesterFee;

    printf("New courses: %.2f Tk\n", newCost);
    printf("Retake courses: %.2f Tk\n", retakeCost);
    printf("Trimester fee: %.2f Tk\n", trimesterFee);
    printf("Total payable: %.2f Tk\n", total);
    return 0;
}
```

### Explanation
One `scanf` can read values of different types; each `%d` or `%lf` matches the variable in the same position, and spaces or new lines between the numbers are skipped.

- New: 9 × 6500 = 58500
- Retake: 3 × 6500 × 0.5 = 9750 (half the per-credit fee)
- Total: 58500 + 9750 + 7000 = 75250

A wrong `&` or a mismatched specifier (for example `%d` for `perCredit`) is the most common `scanf` bug, and the compiler with `-Wall` will usually warn you about it.

### Concepts Practiced
- Reading several values with one scanf
- Matching format specifiers to types
- Arithmetic with int and double

### Test Cases



#### Only retakes, different fees


## Problem 4: Cafeteria Order Bill
**Level:** Intermediate

### Scenario
The campus cafeteria sells burgers for 150 Tk, pizzas for 250 Tk and pasta for 200 Tk. Every order has 6% VAT added to the subtotal. The cashier enters how many of each item a customer ordered and needs the bill instantly.

### Problem Statement
Read three whole numbers: the number of burgers, pizzas and pasta plates ordered. Calculate the subtotal, the VAT (6% of the subtotal) and the total.

Print exactly:
```text
Subtotal: <subtotal> Tk
VAT (6 percent): <vat> Tk
Total: <total> Tk
```
All amounts with two decimals.

### Sample Input
```text
2 1 3
```

### Sample Output
```text
Subtotal: 1150.00 Tk
VAT (6 percent): 69.00 Tk
Total: 1219.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    int burgers, pizzas, pastas;
    scanf("%d %d %d", &burgers, &pizzas, &pastas);

    double subtotal = burgers * 150.0 + pizzas * 250.0 + pastas * 200.0;
    double vat = subtotal * 6 / 100;
    double total = subtotal + vat;

    printf("Subtotal: %.2f Tk\n", subtotal);
    printf("VAT (6 percent): %.2f Tk\n", vat);
    printf("Total: %.2f Tk\n", total);
    return 0;
}
```

### Explanation
Subtotal = 2 × 150 + 1 × 250 + 3 × 200 = 300 + 250 + 600 = 1150. VAT = 1150 × 6 ÷ 100 = 69, so the total is 1219.

The prices are written as `150.0`, `250.0` and `200.0`, so the subtotal is calculated as a `double` right away. The VAT is calculated on the subtotal only once, rather than on each item: the result is the same, but there is one place to change if the VAT rate changes.

### Concepts Practiced
- scanf with several `%d` values
- Line totals and a subtotal
- Percentage (VAT) calculation

### Test Cases



#### One of each
**Input**
```text
1 1 1
```
**Expected Output**
```text

```

## Problem 5: Ride-Share Fare Split
**Level:** Intermediate

### Scenario
Three classmates share a ride from Mohakhali to campus after an evening lab. The ride-sharing app (fictional rates) charges a base fare of 40 Tk, plus 22 Tk per kilometre, plus 3 Tk per minute of travel time. They split the fare equally.

### Problem Statement
Read the distance in kilometres (decimal), the travel time in minutes (whole number), and the number of riders (whole number, at least 1). Calculate the fare and each rider's share.

Print exactly (two decimals):
```text
Fare: <fare> Tk
Each rider pays: <share> Tk
```

### Sample Input
```text
7.5 28 3
```

### Sample Output
```text
Fare: 289.00 Tk
Each rider pays: 96.33 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double km;
    int minutes, riders;
    scanf("%lf %d %d", &km, &minutes, &riders);

    double fare = 40 + 22 * km + 3 * minutes;
    double share = fare / riders;

    printf("Fare: %.2f Tk\n", fare);
    printf("Each rider pays: %.2f Tk\n", share);
    return 0;
}
```

### Explanation
Fare = base + distance part + time part = 40 + 22 × 7.5 + 3 × 28 = 40 + 165 + 84 = 289.

Because `fare` is a `double`, `fare / riders` is a decimal division: 289 ÷ 3 = 96.333…, printed as 96.33. (In real life the riders would round up so the driver is not short by a paisa; rounding rules are a decision, which you will be able to program after Chapter 05.)

### Concepts Practiced
- scanf mixing `%lf` and `%d`
- Building a formula from fixed and variable parts
- Decimal division

### Test Cases

**Expected Output**


#### Long trip in traffic, two riders

```text

```

## Problem 6: Monthly Budget Planner
**Level:** Challenging

### Scenario
Tanvir moved to a mess near campus. Each month his family sends an allowance. He pays rent, eats every day of the month, but only travels on class days. He wants to know where his money goes, how much he can save, and how much spare money he has per day.

### Problem Statement
Read six values on one line:

1. monthly allowance,
2. rent,
3. daily food cost,
4. daily transport cost (class days only),
5. number of class days (whole number),
6. number of days in the month (whole number, at least 1).

Calculate food cost for the month (every day), transport cost (class days only), total spending (rent + food + transport), savings (allowance − spending, which may be negative), and the daily amount left (savings ÷ days in the month).

Print exactly (two decimals):
```text
Food: <food> Tk
Transport: <transport> Tk
Total spending: <spending> Tk
Savings: <savings> Tk
Daily budget left: <daily> Tk
```

### Sample Input
```text
15000 4500 180 60 20 30
```

### Sample Output
```text
Food: 5400.00 Tk
Transport: 1200.00 Tk
Total spending: 11100.00 Tk
Savings: 3900.00 Tk
Daily budget left: 130.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double allowance, rent, dailyFood, dailyTransport;
    int classDays, monthDays;
    scanf("%lf %lf %lf %lf %d %d", &allowance, &rent, &dailyFood, &dailyTransport,
          &classDays, &monthDays);

    double food = dailyFood * monthDays;
    double transport = dailyTransport * classDays;
    double spending = rent + food + transport;
    double savings = allowance - spending;
    double dailyLeft = savings / monthDays;

    printf("Food: %.2f Tk\n", food);
    printf("Transport: %.2f Tk\n", transport);
    printf("Total spending: %.2f Tk\n", spending);
    printf("Savings: %.2f Tk\n", savings);
    printf("Daily budget left: %.2f Tk\n", dailyLeft);
    return 0;
}
```

### Explanation
The trap in this problem is using the right **number of days** for each cost: food is multiplied by all 30 days, transport only by the 20 class days.

- Food = 180 × 30 = 5400; transport = 60 × 20 = 1200
- Spending = 4500 + 5400 + 1200 = 11100
- Savings = 15000 − 11100 = 3900; per day = 3900 ÷ 30 = 130

A negative saving simply means overspending, and `%.2f` prints the minus sign for you. A long `scanf` is easier to get right if the variables are listed in exactly the order the problem describes the input.

### Concepts Practiced
- Reading six values of two types with one scanf
- Multi-step calculation with intermediate variables
- Negative results

## Problem 7: Course Mark Sheet
**Level:** Challenging

### Scenario
A course teacher keeps each student's component scores as percentages (0–100) and converts them to weighted marks at the end of the trimester: attendance is worth 10 marks, class tests 20, the mid-term 30 and the final 40. Each record starts with the student's section letter and roll number.

### Problem Statement
Read the input in two lines:

1. the section (a single character) and the roll number (whole number),
2. four decimal percentages: attendance, class-test average, mid-term, final.

Convert each percentage to its weighted mark (for example, attendance mark = attendance% × 10 ÷ 100) and add them.

Print exactly (two decimals for marks):
```text
Student: <roll> (Section <section>)
Attendance: <mark> / 10
Class tests: <mark> / 20
Mid-term: <mark> / 30
Final: <mark> / 40
Total: <total> / 100
```

### Sample Input
```text
B 1052
90 75.5 68 72.25
```

### Sample Output
```text
Student: 1052 (Section B)
Attendance: 9.00 / 10
Class tests: 15.10 / 20
Mid-term: 20.40 / 30
Final: 28.90 / 40
Total: 73.40 / 100
```

### Solution
```c
#include <stdio.h>

int main() {
    char section;
    int roll;
    double attendance, classTests, midTerm, finalExam;

    scanf(" %c %d", &section, &roll);
    scanf("%lf %lf %lf %lf", &attendance, &classTests, &midTerm, &finalExam);

    double attendanceMark = attendance * 10 / 100;
    double classTestMark = classTests * 20 / 100;
    double midMark = midTerm * 30 / 100;
    double finalMark = finalExam * 40 / 100;
    double total = attendanceMark + classTestMark + midMark + finalMark;

    printf("Student: %d (Section %c)\n", roll, section);
    printf("Attendance: %.2f / 10\n", attendanceMark);
    printf("Class tests: %.2f / 20\n", classTestMark);
    printf("Mid-term: %.2f / 30\n", midMark);
    printf("Final: %.2f / 40\n", finalMark);
    printf("Total: %.2f / 100\n", total);
    return 0;
}
```

### Explanation
Each component is scaled from a percentage to its weight: `percent × weight ÷ 100`.

- 90 × 10 ÷ 100 = 9.00
- 75.5 × 20 ÷ 100 = 15.10
- 68 × 30 ÷ 100 = 20.40
- 72.25 × 40 ÷ 100 = 28.90
- Total = 73.40

The space before `%c` in `" %c"` tells `scanf` to skip any whitespace (spaces or a leftover newline) before reading the character. Without it, a `%c` that follows another input would often read the newline instead of the section letter. This is one of the most common input bugs in C.

### Concepts Practiced
- scanf with `" %c"` to skip whitespace
- Reading input over two lines
- Weighted marks from percentages
- Printing char, int and double together

## Problem 8: Laptop Installment Plan
**Level:** Challenging

### Scenario
A computer shop in Elephant Road offers students a laptop on installments. The customer pays a down payment (a percentage of the price) now. The rest is "financed": the shop adds a **flat** interest (a percentage of the financed amount, charged once) and divides the result into equal monthly installments. (The plan is fictional.)

### Problem Statement
Read four values: laptop price (decimal), down payment percentage (decimal), number of months (whole number, at least 1), and flat interest percentage (decimal). Calculate:

1. down payment = price × down% ÷ 100
2. amount financed = price − down payment
3. interest = amount financed × interest% ÷ 100
4. monthly installment = (amount financed + interest) ÷ months
5. total cost = down payment + amount financed + interest

Print exactly (two decimals):
```text
Down payment: <down> Tk
Amount financed: <financed> Tk
Interest: <interest> Tk
Monthly installment: <monthly> Tk
Total cost: <total> Tk
```

### Sample Input
```text
85000 20 12 9
```

### Sample Output
```text
Down payment: 17000.00 Tk
Amount financed: 68000.00 Tk
Interest: 6120.00 Tk
Monthly installment: 6176.67 Tk
Total cost: 91120.00 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    double price, downPercent, interestPercent;
    int months;
    scanf("%lf %lf %d %lf", &price, &downPercent, &months, &interestPercent);

    double down = price * downPercent / 100;
    double financed = price - down;
    double interest = financed * interestPercent / 100;
    double monthly = (financed + interest) / months;
    double totalCost = down + financed + interest;

    printf("Down payment: %.2f Tk\n", down);
    printf("Amount financed: %.2f Tk\n", financed);
    printf("Interest: %.2f Tk\n", interest);
    printf("Monthly installment: %.2f Tk\n", monthly);
    printf("Total cost: %.2f Tk\n", totalCost);
    return 0;
}
```

### Explanation
The interest percentage applies to the **financed amount**, not to the full price. With the sample:

- Down payment = 85000 × 20 ÷ 100 = 17000
- Financed = 68000
- Interest = 68000 × 9 ÷ 100 = 6120
- Monthly = (68000 + 6120) ÷ 12 = 6176.666… → 6176.67
- Total cost = 17000 + 68000 + 6120 = 91120, which is 6120 more than paying cash

The brackets in `(financed + interest) / months` matter: without them only `interest` would be divided by the months. The total cost is computed from the exact parts, not by multiplying the rounded installment 6176.67 by 12 (which would give 74120.04 and a wrong total).

### Concepts Practiced
- scanf with mixed types in a specific order
- Percentages of different bases
- Brackets to control evaluation order
- Avoiding rounding errors in totals
