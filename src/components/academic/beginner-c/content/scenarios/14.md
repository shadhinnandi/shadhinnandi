# Scenario-Based Problems

These are mixed, exam-style problems of the kind set in class tests, lab finals and programming assessments. Each one combines ideas from several chapters, and the problem statement does not tell you which chapter to use: deciding that is part of the exercise. Give yourself a time limit (about 30–45 minutes per problem), as in a real lab exam.

Programs read input without prompts and print exactly the sample output. All rates, fares and programme rules are hypothetical.

## Problem 1: Progressive Discount Bill
**Level:** Moderate

### Scenario
A tech shop near campus runs a "the more you buy, the more you save" offer. The discount is **progressive**, like income tax slabs: nothing on the first 1000 Tk of the subtotal, 5% on the part between 1000 and 3000 Tk, and 10% on the part above 3000 Tk. Then 7.5% VAT is added on the amount after the discount.

### Problem Statement
Read `N` and then `N` lines `price quantity` (whole taka and whole numbers). Calculate:

1. subtotal = Σ price × quantity
2. discount = 5% of the part of the subtotal between 1000 and 3000 + 10% of the part above 3000
3. VAT = 7.5% of (subtotal − discount)
4. total = subtotal − discount + VAT

Print exactly (two decimals):
```text
Subtotal: <subtotal> Tk
Discount: <discount> Tk
VAT: <vat> Tk
Total: <total> Tk
```

### Sample Input
```text
3
450 2
1200 1
300 5
```

### Sample Output
```text
Subtotal: 3600.00 Tk
Discount: 160.00 Tk
VAT: 258.00 Tk
Total: 3698.00 Tk
```

### Solution
```c
#include <stdio.h>

double progressiveDiscount(double subtotal) {
    double discount = 0;
    if (subtotal > 1000) {
        double band = (subtotal > 3000 ? 3000 : subtotal) - 1000;   /* part in 1000..3000 */
        discount += band * 5 / 100;
    }
    if (subtotal > 3000) {
        discount += (subtotal - 3000) * 10 / 100;
    }
    return discount;
}

int main() {
    int n;
    scanf("%d", &n);

    double subtotal = 0;
    for (int i = 0; i < n; i++) {
        int price, qty;
        scanf("%d %d", &price, &qty);
        subtotal += (double) price * qty;
    }

    double discount = progressiveDiscount(subtotal);
    double vat = (subtotal - discount) * 7.5 / 100;
    double total = subtotal - discount + vat;

    printf("Subtotal: %.2f Tk\n", subtotal);
    printf("Discount: %.2f Tk\n", discount);
    printf("VAT: %.2f Tk\n", vat);
    printf("Total: %.2f Tk\n", total);
    return 0;
}
```

### Explanation
With a subtotal of 3600:

- the first 1000 Tk: no discount;
- the part between 1000 and 3000 (2000 Tk): 5% = 100;
- the part above 3000 (600 Tk): 10% = 60;
- discount = 160, discounted amount = 3440, VAT = 3440 × 7.5% = 258, total = 3698.

The common mistake is applying 10% to the whole 3600 (360 Tk) because the subtotal is "in the 10% slab". Progressive slabs only apply each rate to the part inside that slab. In `progressiveDiscount`, `(subtotal > 3000 ? 3000 : subtotal)` is the conditional operator: it gives 3000 if the subtotal is larger, otherwise the subtotal itself, which caps the middle band at 2000 Tk.

### Concepts Practiced
- Progressive (slab) calculation
- Function returning a computed discount
- Conditional operator `?:`
- Order of discount and VAT

## Problem 2: Text Statistics
**Level:** Moderate

### Scenario
The CSE fest's poster designer wants to check a line of poster text before printing: how many characters of each kind it contains, how many vowels it has, and what share of it is letters.

### Problem Statement
Read one line of text (up to 200 characters) with `fgets`. Count uppercase letters, lowercase letters, digits, spaces, and other characters; count vowels (`a e i o u` in either case); and compute the percentage of characters that are letters. Print exactly:
```text
Length: <n>
Uppercase: <u>
Lowercase: <l>
Digits: <d>
Spaces: <s>
Others: <o>
Vowels: <v>
Letters: <percentage, 2 decimals> percent
```
For an empty line, print only `Empty line`.

### Sample Input
```text
UIU CSE Fest 2025: Register by 15 Oct!
```

### Sample Output
```text
Length: 38
Uppercase: 9
Lowercase: 14
Digits: 6
Spaces: 7
Others: 2
Vowels: 9
Letters: 60.53 percent
```

### Solution
```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main() {
    char text[210];
    if (fgets(text, sizeof(text), stdin) == NULL) {
        text[0] = '\0';
    }
    int len = strlen(text);
    if (len > 0 && text[len - 1] == '\n') {
        text[--len] = '\0';
    }
    if (len == 0) {
        printf("Empty line\n");
        return 0;
    }

    int upper = 0, lower = 0, digits = 0, spaces = 0, others = 0, vowels = 0;
    for (int i = 0; i < len; i++) {
        unsigned char c = text[i];
        if (isupper(c)) upper++;
        else if (islower(c)) lower++;
        else if (isdigit(c)) digits++;
        else if (c == ' ') spaces++;
        else others++;

        char lc = tolower(c);
        if (lc == 'a' || lc == 'e' || lc == 'i' || lc == 'o' || lc == 'u') vowels++;
    }

    printf("Length: %d\n", len);
    printf("Uppercase: %d\n", upper);
    printf("Lowercase: %d\n", lower);
    printf("Digits: %d\n", digits);
    printf("Spaces: %d\n", spaces);
    printf("Others: %d\n", others);
    printf("Vowels: %d\n", vowels);
    printf("Letters: %.2f percent\n", (upper + lower) * 100.0 / len);
    return 0;
}
```

### Explanation
Every character belongs to exactly one of the five groups (the `else if` chain guarantees that), so the five counts always add up to the length: 9 + 14 + 6 + 7 + 2 = 38. That makes a quick self-check when testing.

Vowels are counted separately because a vowel is **also** an uppercase or lowercase letter. Lowercasing the character first means one test covers both `A` and `a`. In the sample, the vowels are U, I, U, E, e, e, i, e, O.

The letter percentage is (9 + 14) × 100 ÷ 38 = 60.53. The empty-line check prevents a division by zero.

### Concepts Practiced
- fgets and newline removal
- Character classification
- Overlapping categories counted separately
- Self-checking counts

## Problem 3: Number Range Report
**Level:** Intermediate

### Scenario
A first-year class test asks students to analyse all whole numbers in a range. The examiner wants a program that produces the answer key automatically for any range.

### Problem Statement
Read two whole numbers `L` and `R` (swap them if `L > R`). For all numbers from `L` to `R` inclusive, print:
```text
Even: <count> (sum <sum>)
Odd: <count> (sum <sum>)
Difference (even sum - odd sum): <difference>
Perfect squares: <list, or none>
Multiples of both 3 and 5: <count>
```
A perfect square is a number `k × k` for a whole number `k ≥ 0` (so 0 counts, negative numbers never do). Do not use `sqrt`; test with whole-number arithmetic.

### Sample Input
```text
10 30
```

### Sample Output
```text
Even: 11 (sum 220)
Odd: 10 (sum 200)
Difference (even sum - odd sum): 20
Perfect squares: 16 25
Multiples of both 3 and 5: 2
```

### Solution
```c
#include <stdio.h>

int isPerfectSquare(int n) {
    if (n < 0) return 0;
    for (int k = 0; k * k <= n; k++) {
        if (k * k == n) return 1;
    }
    return 0;
}

int main() {
    int low, high;
    scanf("%d %d", &low, &high);
    if (low > high) {
        int t = low;
        low = high;
        high = t;
    }

    int evenCount = 0, oddCount = 0, multiples = 0;
    long long evenSum = 0, oddSum = 0;
    for (int x = low; x <= high; x++) {
        if (x % 2 == 0) {
            evenCount++;
            evenSum += x;
        } else {
            oddCount++;
            oddSum += x;
        }
        if (x % 15 == 0) multiples++;
    }

    printf("Even: %d (sum %lld)\n", evenCount, evenSum);
    printf("Odd: %d (sum %lld)\n", oddCount, oddSum);
    printf("Difference (even sum - odd sum): %lld\n", evenSum - oddSum);

    printf("Perfect squares:");
    int found = 0;
    for (int x = low; x <= high; x++) {
        if (isPerfectSquare(x)) {
            printf(" %d", x);
            found = 1;
        }
    }
    if (!found) printf(" none");
    printf("\n");

    printf("Multiples of both 3 and 5: %d\n", multiples);
    return 0;
}
```

### Explanation
"Multiple of both 3 and 5" is the same as "multiple of 15", because 3 and 5 share no factor; one `% 15` test replaces two tests.

`x % 2 == 0` is used for even numbers rather than `x % 2 == 1` for odd ones, because in C a negative odd number gives `x % 2 == -1`. Testing for zero works for negative numbers too.

`isPerfectSquare` tries `k = 0, 1, 2, …` while `k × k ≤ n`, so it never needs floating-point `sqrt` (whose rounding can make `sqrt(25)` come out as 4.9999…). The sums use `long long` because adding a large range of `int` values could overflow.

In the sample range, 15 and 30 are the multiples of 15; 16 and 25 are the squares.

### Concepts Practiced
- Loop over a range with several counters
- Even/odd test that works for negatives
- Perfect squares with integer arithmetic
- long long for sums
- Helper function

## Problem 4: Classroom Occupancy Report
**Level:** Intermediate

### Scenario
The facilities office is studying how classrooms are used. For each room it knows the capacity, and for each time slot of the day it has a head count of students in the room. It wants each room's utilisation, the slots where a room was overloaded (more students than seats), and the busiest slot of the day overall.

### Problem Statement
Read `R` rooms and `T` time slots (both 1–10), then the `R` capacities, then an `R × T` table of head counts (row = room, column = slot). Print:

- for each room: `Room <r>: utilisation <percent, 2 decimals> percent`, where utilisation = total students in the room ÷ (capacity × T) × 100;
- `Overloaded: ` followed by every overloaded cell as `R<room>-S<slot>`, row by row, or `none`;
- `Busiest slot: <slot> (<students> students)`: the slot with the most students across all rooms (first on a tie).

### Sample Input
```text
3 4
40 60 30
35 40 20 1
50 62 45 30
30 10 32 25
```

### Sample Output
```text
Room 1: utilisation 60.00 percent
Room 2: utilisation 77.92 percent
Room 3: utilisation 80.83 percent
Overloaded: R2-S2 R3-S3
Busiest slot: 1 (115 students)
```

### Solution
```c
#include <stdio.h>

int main() {
    int rooms, slots;
    scanf("%d %d", &rooms, &slots);
    if (rooms < 1 || rooms > 10 || slots < 1 || slots > 10) {
        printf("Invalid size\n");
        return 0;
    }

    int capacity[10], count[10][10];
    for (int r = 0; r < rooms; r++) scanf("%d", &capacity[r]);
    for (int r = 0; r < rooms; r++)
        for (int s = 0; s < slots; s++)
            scanf("%d", &count[r][s]);

    for (int r = 0; r < rooms; r++) {
        int total = 0;
        for (int s = 0; s < slots; s++) total += count[r][s];
        double util = total * 100.0 / (capacity[r] * slots);
        printf("Room %d: utilisation %.2f percent\n", r + 1, util);
    }

    printf("Overloaded:");
    int any = 0;
    for (int r = 0; r < rooms; r++) {
        for (int s = 0; s < slots; s++) {
            if (count[r][s] > capacity[r]) {
                printf(" R%d-S%d", r + 1, s + 1);
                any = 1;
            }
        }
    }
    if (!any) printf(" none");
    printf("\n");

    int bestSlot = 0, bestTotal = -1;
    for (int s = 0; s < slots; s++) {           /* column totals */
        int total = 0;
        for (int r = 0; r < rooms; r++) total += count[r][s];
        if (total > bestTotal) {
            bestTotal = total;
            bestSlot = s;
        }
    }
    printf("Busiest slot: %d (%d students)\n", bestSlot + 1, bestTotal);
    return 0;
}
```

### Explanation
The same 2D table answers three questions by walking it in different ways:

- **row by row** for each room's utilisation (room 1: 96 students over 4 slots of 40 seats = 96 ÷ 160 = 60%),
- **every cell** for overloads, comparing each count with its row's capacity,
- **column by column** for the slot totals (slot 1: 35 + 50 + 30 = 115).

Room 2 in slot 2 has 62 students for 60 seats and room 3 in slot 3 has 32 for 30, so both are listed. Utilisation can exceed 100% if a room is overloaded all day; that is useful information, not an error.

### Concepts Practiced
- 2D arrays with a parallel 1D array
- Row, cell and column traversals
- Percentages from integer data
- Maximum over column totals

```text
10

```

```text

```


## Problem 5: Student Assistance Programme
**Level:** Intermediate

### Scenario
A university trust runs a **fictional** student assistance programme. Applications are scored with points, and the points decide the assistance. These rules are invented for this exercise.

| Rule | Points |
|---|---|
| Family income per member below 5000 Tk | 40 |
| … below 8000 Tk | 25 |
| … below 12000 Tk | 10 |
| CGPA 3.50 or above | 20 |
| CGPA 3.00 to below 3.50 | 10 |
| Lives away from home (hall `H` or mess `M`) | 15 |
| Has a sibling at university (`Y`) | 10 |

60 points or more: full assistance, 6000 Tk. 40–59 points: partial, 3000 Tk. Otherwise none. Any applicant with a CGPA below 2.50 is not eligible at all.

### Problem Statement
Read `N`, then `N` applications: `id income members cgpa residence sibling` (residence `H`, `M` or `O` for home; sibling `Y` or `N`). Write functions `int incomePoints(double perMember)`, `int cgpaPoints(double cgpa)` and `int totalPoints(...)`.

For each application print one of:

- `<id>: invalid record` (members < 1, negative income, CGPA outside 0–4, or an unknown letter),
- `<id>: not eligible (CGPA below 2.50)`,
- `<id>: <p> points -> <Full|Partial|None> (<amount> Tk)`.

Finally print `Full: <f>, Partial: <p>, None: <n>` (not-eligible applicants count as None; invalid records are not counted) and `Budget used: <total> Tk`.

### Sample Input
```text
5
101 18000 5 3.6 H Y
102 30000 4 3.2 O N
103 40000 4 3.9 M N
104 9000 3 2.4 H Y
105 20000 4 2.9 O Y
```

### Sample Output
```text
101: 85 points -> Full (6000 Tk)
102: 35 points -> None (0 Tk)
103: 45 points -> Partial (3000 Tk)
104: not eligible (CGPA below 2.50)
105: 35 points -> None (0 Tk)
Full: 1, Partial: 1, None: 3
Budget used: 9000 Tk
```

### Solution
```c
#include <stdio.h>

int incomePoints(double perMember) {
    if (perMember < 5000) return 40;
    if (perMember < 8000) return 25;
    if (perMember < 12000) return 10;
    return 0;
}

int cgpaPoints(double cgpa) {
    if (cgpa >= 3.50) return 20;
    if (cgpa >= 3.00) return 10;
    return 0;
}

int totalPoints(double income, int members, double cgpa, char residence, char sibling) {
    int points = incomePoints(income / members) + cgpaPoints(cgpa);
    if (residence == 'H' || residence == 'M') points += 15;
    if (sibling == 'Y') points += 10;
    return points;
}

int main() {
    int n;
    scanf("%d", &n);
    int full = 0, partial = 0, none = 0, budget = 0;

    for (int k = 0; k < n; k++) {
        int id, members;
        double income, cgpa;
        char residence, sibling;
        scanf("%d %lf %d %lf %c %c", &id, &income, &members, &cgpa, &residence, &sibling);

        int badLetter = (residence != 'H' && residence != 'M' && residence != 'O')
                     || (sibling != 'Y' && sibling != 'N');
        if (members < 1 || income < 0 || cgpa < 0 || cgpa > 4 || badLetter) {
            printf("%d: invalid record\n", id);
            continue;
        }
        if (cgpa < 2.50) {
            printf("%d: not eligible (CGPA below 2.50)\n", id);
            none++;
            continue;
        }

        int points = totalPoints(income, members, cgpa, residence, sibling);
        if (points >= 60) {
            printf("%d: %d points -> Full (6000 Tk)\n", id, points);
            full++;
            budget += 6000;
        } else if (points >= 40) {
            printf("%d: %d points -> Partial (3000 Tk)\n", id, points);
            partial++;
            budget += 3000;
        } else {
            printf("%d: %d points -> None (0 Tk)\n", id, points);
            none++;
        }
    }

    printf("Full: %d, Partial: %d, None: %d\n", full, partial, none);
    printf("Budget used: %d Tk\n", budget);
    return 0;
}
```

### Explanation
Applicant 101: 18000 ÷ 5 = 3600 per member (40 points), CGPA 3.6 (20), lives in a hall (15), sibling at university (10): 85 points, full assistance. Applicant 105: 20000 ÷ 4 = 5000 per member is **not** below 5000, so only 25 points for income; with a 2.9 CGPA (0) and a sibling (10) the total is 35.

The CGPA gate is checked before scoring: applicant 104 would have scored 75 points, but the rule excludes them regardless. Each points table is a small function, so the scoring formula in `totalPoints` reads like the rule table.

Using per-member income (income ÷ members) rather than total income is what makes the programme fair to large families; dividing is safe because `members < 1` was rejected first.

### Concepts Practiced
- Points-based rules in functions
- Eligibility gate before scoring
- Reading mixed-type records
- Counting categories and a budget total


## Problem 6: Metro Card Daily Cap
**Level:** Challenging

### Scenario
A city's (fictional) metro line has stations numbered 1 to 16. A trip costs 5 Tk per station travelled, with a minimum fare of 20 Tk. Student cards (`S`) get 10% off every fare (after the minimum is applied); regular cards (`R`) pay full fare. To encourage metro use, there is a **daily cap**: once a card has paid 150 Tk in a day, further trips that day are free, and a trip that would cross the cap is charged only the amount left up to 150.

### Problem Statement
Read the card type (`S` or `R`), `N`, and `N` trips `from to`. A trip with a station outside 1–16, or with `from == to`, prints `Trip <k>: invalid stations` and is ignored. For each valid trip print:
```text
Trip <k>: <from> -> <to>, fare <fare>, charged <charged>
```
Finally print `Total paid: <total> Tk` and `Trips affected by cap: <count>` (trips charged less than their fare). Money uses two decimals. An unknown card type prints only `Unknown card type`.

### Sample Input
```text
R
5
1 9
9 16
16 2
2 5
5 5
```

### Sample Output
```text
Trip 1: 1 -> 9, fare 40.00, charged 40.00
Trip 2: 9 -> 16, fare 35.00, charged 35.00
Trip 3: 16 -> 2, fare 70.00, charged 70.00
Trip 4: 2 -> 5, fare 20.00, charged 5.00
Trip 5: invalid stations
Total paid: 150.00 Tk
Trips affected by cap: 1
```

### Solution
```c
#include <stdio.h>

double fareFor(int from, int to, char card) {
    int stations = from > to ? from - to : to - from;
    double fare = stations * 5.0;
    if (fare < 20) fare = 20;                 /* minimum fare */
    if (card == 'S') fare = fare * 90 / 100;  /* student discount */
    return fare;
}

int main() {
    char card;
    int n;
    scanf(" %c %d", &card, &n);
    if (card != 'S' && card != 'R') {
        printf("Unknown card type\n");
        return 0;
    }

    const double CAP = 150.0;
    double paid = 0;
    int capped = 0;

    for (int k = 1; k <= n; k++) {
        int from, to;
        scanf("%d %d", &from, &to);
        if (from < 1 || from > 16 || to < 1 || to > 16 || from == to) {
            printf("Trip %d: invalid stations\n", k);
            continue;
        }

        double fare = fareFor(from, to, card);
        double charged = fare;
        if (paid + fare > CAP) {
            charged = CAP - paid;             /* only what is left up to the cap */
            capped++;
        }
        paid += charged;
        printf("Trip %d: %d -> %d, fare %.2f, charged %.2f\n", k, from, to, fare, charged);
    }

    printf("Total paid: %.2f Tk\n", paid);
    printf("Trips affected by cap: %d\n", capped);
    return 0;
}
```

### Explanation
The fare rule and the cap rule are kept apart: `fareFor` knows nothing about the cap, and `main` only compares what has been paid with 150. Trip 4 would cost 20, but 145 has already been paid, so it is charged only 5 and the card reaches the cap. Any later trip would be charged 0 (see the second test).

The order inside `fareFor` matters: the minimum is applied first, then the student discount, so a short student trip costs 18, not 20. `from > to ? from - to : to - from` (the conditional operator) gives the distance whichever direction the passenger travels. `const double CAP` names the cap once; changing the rule means changing one line.

### Concepts Practiced
- Function for a fare rule
- Running total with a cap
- Order of minimum and discount
- Conditional operator for absolute difference
- Named constant with `const`

## Problem 7: Class Result Sheet
**Level:** Challenging

### Scenario
At the end of the trimester, the course coordinator must publish a result sheet for a section: each student's total and average over three exams, a letter grade from the average (A 80+, B 70+, C 60+, D 50+, F below 50), and a rank by total. Students with equal totals share a rank (1, 2, 2, 4), and are listed in their original order. A grade distribution goes at the bottom.

### Problem Statement
Read `N` (1–60), then `N` lines `name m1 m2 m3` (name one word, up to 15 characters). Sort an **index array** by total (highest first, stable), then print:
```text
Rank Name       Total Average Grade
<rows>
Grades: A=<a> B=<b> C=<c> D=<d> F=<f>
```
using `printf("%-5s%-10s%6s%8s%6s\n", ...)` for the header and `printf("%-5d%-10s%6d%8.2f%6c\n", ...)` for each row. If `N` is out of range, print `Invalid number of students`.

### Sample Input
```text
5
Rahim 78 85 82
Nusrat 90 88 95
Tanvir 55 48 60
Mim 85 82 78
Arif 40 35 42
```

### Sample Output
```text
Rank Name       Total Average Grade
1    Nusrat       273   91.00     A
2    Rahim        245   81.67     A
2    Mim          245   81.67     A
4    Tanvir       163   54.33     D
5    Arif         117   39.00     F
Grades: A=3 B=0 C=0 D=1 F=1
```

### Solution
```c
#include <stdio.h>

char letterFor(double average) {
    if (average >= 80) return 'A';
    if (average >= 70) return 'B';
    if (average >= 60) return 'C';
    if (average >= 50) return 'D';
    return 'F';
}

int main() {
    int n;
    scanf("%d", &n);
    if (n < 1 || n > 60) {
        printf("Invalid number of students\n");
        return 0;
    }

    char name[60][16];
    int total[60], order[60];
    for (int i = 0; i < n; i++) {
        int a, b, c;
        scanf("%15s %d %d %d", name[i], &a, &b, &c);
        total[i] = a + b + c;
        order[i] = i;
    }

    /* stable bubble sort of indexes by total, highest first */
    for (int pass = 0; pass < n - 1; pass++) {
        for (int k = 0; k < n - 1 - pass; k++) {
            if (total[order[k + 1]] > total[order[k]]) {
                int t = order[k];
                order[k] = order[k + 1];
                order[k + 1] = t;
            }
        }
    }

    int count[5] = {0, 0, 0, 0, 0};             /* A B C D F */
    printf("%-5s%-10s%6s%8s%6s\n", "Rank", "Name", "Total", "Average", "Grade");
    int rank = 1;
    for (int k = 0; k < n; k++) {
        int i = order[k];
        if (k > 0 && total[i] != total[order[k - 1]]) {
            rank = k + 1;
        }
        double average = total[i] / 3.0;
        char grade = letterFor(average);
        printf("%-5d%-10s%6d%8.2f%6c\n", rank, name[i], total[i], average, grade);

        switch (grade) {
            case 'A': count[0]++; break;
            case 'B': count[1]++; break;
            case 'C': count[2]++; break;
            case 'D': count[3]++; break;
            default: count[4]++;
        }
    }
    printf("Grades: A=%d B=%d C=%d D=%d F=%d\n", count[0], count[1], count[2], count[3], count[4]);
    return 0;
}
```

### Explanation
Sorting the **index array** `order` instead of the data keeps names and totals together without swapping strings: `order[k]` says which student is in position `k`. Because the sort only swaps when the next total is strictly larger, equal totals keep their input order (Rahim before Mim).

Ranks follow the competition rule: when the total changes, the rank jumps to the position number (`k + 1`), so after two students share rank 2 the next is rank 4.

The average is `total / 3.0`, not `total / 3`; Rahim's 245 ÷ 3 = 81.67. The grade comes from the average, and a small `switch` turns the letter into an index for the distribution counts.

### Concepts Practiced
- Array of strings with parallel arrays
- Sorting an index array (stable)
- Competition ranking
- Formatted table output
- Counting with an array and switch

## Problem 8: Cheapest Internet Bundle
**Level:** Challenging

### Scenario
A mobile operator (fictional prices) sells data packs of 30 GB for 799 Tk, 12 GB for 399 Tk, 5 GB for 199 Tk and 1 GB for 49 Tk. A student needs at least `D` GB this month and can buy any number of each pack. Buying the biggest pack is not always cheapest, so she wants a program that checks every sensible combination.

### Problem Statement
Read `D`. If `D` is 0 or less, print `Nothing to buy`; if `D` is more than 200, print `Too much data requested`. Otherwise search all combinations with nested loops:

- `a` 30 GB packs from 0 to ⌈D/30⌉, `b` 12 GB packs from 0 to ⌈D/12⌉, `c` 5 GB packs from 0 to ⌈D/5⌉,
- and as many 1 GB packs as are still needed to reach `D` (possibly 0).

Keep the cheapest combination; on equal cost, keep the one with fewer packs; if still equal, keep the one found first. Print:
```text
Need: <D> GB
<size> GB pack x <count>      (only packs with count > 0, largest first)
Total: <GB> GB for <cost> Tk
```

### Sample Input
```text
20
```

### Sample Output
```text
Need: 20 GB
12 GB pack x 1
5 GB pack x 1
1 GB pack x 3
Total: 20 GB for 745 Tk
```

### Solution
```c
#include <stdio.h>

int main() {
    int need;
    scanf("%d", &need);
    if (need <= 0) {
        printf("Nothing to buy\n");
        return 0;
    }
    if (need > 200) {
        printf("Too much data requested\n");
        return 0;
    }

    int size[4] = {30, 12, 5, 1};
    int price[4] = {799, 399, 199, 49};

    int bestCost = -1, bestPacks = 0, best[4] = {0, 0, 0, 0};

    for (int a = 0; a <= (need + 29) / 30; a++) {
        for (int b = 0; b <= (need + 11) / 12; b++) {
            for (int c = 0; c <= (need + 4) / 5; c++) {
                int remaining = need - (a * 30 + b * 12 + c * 5);
                int d = remaining > 0 ? remaining : 0;     /* 1 GB packs to top up */

                int cost = a * price[0] + b * price[1] + c * price[2] + d * price[3];
                int packs = a + b + c + d;

                if (bestCost < 0 || cost < bestCost || (cost == bestCost && packs < bestPacks)) {
                    bestCost = cost;
                    bestPacks = packs;
                    best[0] = a;
                    best[1] = b;
                    best[2] = c;
                    best[3] = d;
                }
            }
        }
    }

    printf("Need: %d GB\n", need);
    int totalGb = 0;
    for (int i = 0; i < 4; i++) {
        if (best[i] > 0) {
            printf("%d GB pack x %d\n", size[i], best[i]);
        }
        totalGb += best[i] * size[i];
    }
    printf("Total: %d GB for %d Tk\n", totalGb, bestCost);
    return 0;
}
```

### Explanation
This is an **exhaustive search** (brute force): try every combination in a bounded range and keep the best one. The bounds come from the problem: there is never a reason to buy more than ⌈D/30⌉ packs of 30 GB, because that many already cover the need. `(need + 29) / 30` is the integer way to write ⌈need/30⌉. The 1 GB packs need no loop: once `a`, `b` and `c` are chosen, the cheapest way to finish is to buy exactly the missing gigabytes.

For 20 GB, buying a 30 GB pack costs 799, two 12 GB packs 798, four 5 GB packs 796, but 12 + 5 + 3 × 1 GB = 20 GB costs 399 + 199 + 147 = 745, the cheapest. Greedy "biggest pack first" thinking would miss it, which is why checking all combinations is worthwhile when the search space is small.

The tie-breaking rule is part of the specification, and the `if` condition implements it exactly: a strictly lower cost wins; at equal cost, strictly fewer packs win; otherwise the earlier combination stays.

### Concepts Practiced
- Exhaustive search with nested loops
- Bounding a search space
- Ceiling with integer arithmetic
- Multi-level tie-breaking
- Parallel arrays for sizes and prices
