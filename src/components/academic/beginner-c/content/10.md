# Chapter 10: Strings

In C, a string is not a built-in data type like `int` or `char`. Instead, a string is simply an array of characters that ends with a special character called the "null terminator" (`\0`).

## 1. Concept Explanation

### What is a String?

**Simple Explanation:**
A string is just a sequence of characters. The word "Hello" is a string containing the characters 'H', 'e', 'l', 'l', 'o'. To tell the computer where the string ends, C automatically adds an invisible character, `\0` (the null character), at the end.

**Real-life Analogy:**
Think of a train again. Each car holds one character. The word "CAT" would be a train of 4 cars:
`[C] - [A] - [T] - [Engine Stop Signal]`
That "Engine Stop Signal" is the null terminator (`\0`). It tells any function that is reading the train, "This is the end, there are no more cars to read."

**Technical Explanation:**
A string in C is a one-dimensional array of characters terminated by a null character `\0`. The `char` type is used to store characters and letters. For example, the string "hello" is stored as an array of characters: `{'h', 'e', 'l', 'l', 'o', '\0'}`.

## 2. Syntax Section

### Declaring and Initializing Strings

There are two common ways to initialize a string.

**Syntax:**
```c
// Method 1: As a character array
char str1[] = {'H', 'e', 'l', 'l', 'o', '\0'};

// Method 2: Using a string literal (much easier and more common)
// The null terminator is added automatically.
char str2[] = "Hello";
```
Both `str1` and `str2` are identical in memory.

### Reading Strings from the User

*   **`scanf("%s", ...)`**: Reads a string, but it stops reading as soon as it encounters any whitespace (space, tab, newline). This is often not what you want.
*   **`fgets(...)`**: A safer and better function. It reads a full line of text, including spaces, until the user presses Enter.

**Syntax for `fgets`:**
```c
char myString[100]; // Create a buffer to hold the string
fgets(myString, 100, stdin);
```
*   `myString`: The char array to store the string in.
*   `100`: The maximum number of characters to read (should be the size of your array).
*   `stdin`: An abbreviation for "standard input," meaning read from the keyboard.

### String Manipulation Functions

To work with strings, we use a set of powerful functions from the `<string.h>` library. You must include it: `#include <string.h>`.

| Function      | Description                               | Example                     |
| :------------ | :---------------------------------------- | :-------------------------- |
| `strlen()`    | Calculates the **len**gth of a **str**ing (excluding `\0`) | `strlen("hello")` is 5    |
| `strcpy()`    | **C**o**p**ies one **str**ing to another  | `strcpy(dest, src)`       |
| `strcat()`    | Con**cat**enates (joins) two **str**ings  | `strcat(dest, src)`       |
| `strcmp()`    | **C**o**mp**ares two **str**ings          | `strcmp(str1, str2)`      |

**`strcmp()` Return Values:**
*   `0` if the strings are identical.
*   `< 0` if `str1` comes before `str2` alphabetically.
*   `> 0` if `str1` comes after `str2` alphabetically.

### Example 3: Using `strcat()` and `strcmp()`
`string_compare_concat.c`
```c
#include <stdio.h>
#include <string.h>

int main() {
    char str1[50] = "Hello";
    char str2[] = "World";
    char str3[] = "Hello";

    // Concatenate str2 onto str1
    strcat(str1, " "); // Add a space first
    strcat(str1, str2); // str1 is now "Hello World"
    printf("Concatenated string: %s\n", str1);

    // Compare str1 and str3
    if (strcmp(str1, str3) == 0) {
        printf("str1 and str3 are identical.\n");
    } else {
        printf("str1 and str3 are different.\n");
    }

    // Compare str3 and "Hello"
    if (strcmp(str3, "Hello") == 0) {
        printf("str3 and \"Hello\" are identical.\n");
    }

    return 0;
}
```

**Problem 6: Count Vowels and Consonants**
*   **Statement:** Count the number of vowels and consonants in a user-entered string.
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <ctype.h>
    int main() {
        char str[100];
        int vowels = 0, consonants = 0;
        printf("Enter a string: ");
        fgets(str, 100, stdin);
        for (int i = 0; str[i] != '\0'; ++i) {
            char ch = tolower(str[i]);
            if (ch >= 'a' && ch <= 'z') {
                if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u')
                    vowels++;
                else
                    consonants++;
            }
        }
        printf("Vowels: %d, Consonants: %d\n", vowels, consonants);
        return 0;
    }
    ```

**Problem 7: Reverse a String**

*   **Solution:**
    ```c
    #include <stdio.h>

    int main() {
    ```

**Problem 11: Check for Anagrams**
*   **Statement:** Two strings are anagrams if they contain the same characters in a different order (e.g., "listen" and "silent"). Check if two user-input strings are anagrams.
*   **Logic:** Sort both strings alphabetically. If the sorted strings are identical, they are anagrams.
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <string.h>
    // Helper function to sort a string
    void sortString(char *str) {
        int n = strlen(str);
        char temp;
        for (int i = 0; i < n-1; i++) {
            for (int j = i+1; j < n; j++) {
                if (str[i] > str[j]) {
                    temp = str[i];
                    str[i] = str[j];
                    str[j] = temp;
                }
            }
        }
    }
    int main() {
        char str1[100], str2[100];
        printf("Enter first string: "); scanf("%s", str1);
        printf("Enter second string: "); scanf("%s", str2);
        if (strlen(str1) != strlen(str2)) {
            printf("Not anagrams.\n");
            return 0;
        }
        sortString(str1);
        sortString(str2);
        if (strcmp(str1, str2) == 0) printf("Anagrams.\n");
        else printf("Not anagrams.\n");
        return 0;
    }
    ```

**Problem 13: Reverse Words in a Sentence**
*   **Statement:** Reverse the words in a sentence. For "C is fun", the output should be "fun is C".
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <string.h>
    int main() {
        char str[100] = "C is fun";
    ```

**Problem 15: Find a Substring**
*   **Statement:** Implement a function that finds the first occurrence of a smaller string (substring) within a larger string, similar to `strstr()`. Return the starting index or -1 if not found.
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <string.h>
    int findSubstring(char *haystack, char *needle) {
        int hLen = strlen(haystack);
        int nLen = strlen(needle);
        for (int i = 0; i <= hLen - nLen; i++) {
            int j;
            for (j = 0; j < nLen; j++) {
                if (haystack[i + j] != needle[j])
                    break;
            }
            if (j == nLen)
                return i; // Found at index i
        }
        return -1; // Not found
    }
    int main() {
        char main_str[] = "hello world";
        char sub_str[] = "world";
        int index = findSubstring(main_str, sub_str);
        if (index != -1) printf("Substring found at index %d\n", index);
        else printf("Substring not found.\n");
        return 0;
    }
    ```

**Problem 17: Find the Most Frequent Character**
*   **Statement:** Find the character that appears most frequently in a string. If there's a tie, any of the most frequent characters will do.
*   **Logic:** Use a frequency array (size 256 for all ASCII characters) to store the count of each character. Then, iterate through the frequency array to find the maximum count.
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <string.h>
    int main() {
        char str[] = "programming is fun";
        int freq[256] = {0};
        int max_freq = 0;
        char most_frequent_char;

        for (int i = 0; str[i] != '\0'; i++) {
            freq[str[i]]++;
        }

        for (int i = 0; i < 256; i++) {
            if (freq[i] > max_freq) {
                max_freq = freq[i];
                most_frequent_char = (char)i;
            }
        }
        printf("The most frequent character is '%c', appearing %d times.\n", most_frequent_char, max_freq);
        return 0;
    }
    ```

**Problem 18: Check if a String is a Valid Integer**
*   **Statement:** Determine if a given string represents a valid integer. A valid integer can have an optional leading '-' sign and must contain only digits '0'-'9' after that.
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <string.h>
    #include <ctype.h>
    int is_valid_integer(char *str) {
        int i = 0;
        if (str[0] == '-') {
            i = 1;
        }
        if (str[i] == '\0') return 0; // String is only "-" or empty
        for (; str[i] != '\0'; i++) {
            if (!isdigit(str[i])) {
                return 0; // Not a digit
            }
        }
        return 1; // All characters were digits
    }
    int main() {
        char test1[] = "12345";
        char test2[] = "-500";
        char test3[] = "12a34";
        char test4[] = "-";

        printf("%s is %s\n", test1, is_valid_integer(test1) ? "valid" : "invalid");
        printf("%s is %s\n", test2, is_valid_integer(test2) ? "valid" : "invalid");
        printf("%s is %s\n", test3, is_valid_integer(test3) ? "valid" : "invalid");
        printf("%s is %s\n", test4, is_valid_integer(test4) ? "valid" : "invalid");
        return 0;
    }
    ```

**Problem 20: Validate an IP Address**
*   **Statement:** Check if a given string is a valid IPv4 address. A valid IPv4 address consists of four octets, separated by dots. Each octet must be a number between 0 and 255.
*   **Logic:** Use `strtok()` to split the string by the '.' delimiter. Check if there are exactly 4 parts and if each part is a number between 0 and 255.
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <string.h>
    #include <stdlib.h>
    int is_valid_ip(char *ip_str) {
        char *token;
        int num, count = 0;
        char str_copy[100];
        strcpy(str_copy, ip_str); // strtok modifies the string

        token = strtok(str_copy, ".");
        while (token != NULL) {
            count++;
            num = atoi(token);
            if (num < 0 || num > 255) return 0; // Invalid range
            // Check if token contains non-digit characters (atoi would return 0)
            for(int i=0; token[i] != '\0'; i++){
                if(!isdigit(token[i])) return 0;
            }
            token = strtok(NULL, ".");
        }
        return count == 4; // Must have exactly 4 parts
    }
    int main() {
        char ip1[] = "192.168.1.1";
        char ip2[] = "256.100.50.0";
        char ip3[] = "127.0.0.1.5";
        char ip4[] = "127.0.0.a";

        printf("%s is %s\n", ip1, is_valid_ip(ip1) ? "valid" : "invalid");
        printf("%s is %s\n", ip2, is_valid_ip(ip2) ? "valid" : "invalid");
        printf("%s is %s\n", ip3, is_valid_ip(ip3) ? "valid" : "invalid");
        printf("%s is %s\n", ip4, is_valid_ip(ip4) ? "valid" : "invalid");
        return 0;
    }
    ```
