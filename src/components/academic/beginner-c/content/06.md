# Chapter 06: Loops

This is where programming gets incredibly powerful. Loops allow us to repeat a block of code multiple times without having to write it over and over. If you want to print "Hello" 100 times, you don't write 100 `printf` statements; you use a loop!

## 1. Concept Explanation

### What is a Loop?

**Simple Explanation:**
A loop is a way to tell the computer, "Do this task again and again until a certain condition is met." It automates repetitive tasks.

**Real-life Analogy:**
Imagine washing a stack of 10 dirty plates. Your process is:
1.  Pick up a plate.
2.  Scrub it.
3.  Rinse it.
4.  Place it on the drying rack.

You repeat this *loop* of actions until there are no more dirty plates left. The condition to stop is "the stack of dirty plates is empty."

**Technical Explanation:**
In programming, loops are control flow statements that allow code to be executed repeatedly based on a given condition. A loop consists of an initialization, a condition to check, an increment/decrement, and a body of code to execute.

### Types of Loops in C

1.  **`for` loop:** Used when you know exactly how many times you want to repeat the code (e.g., repeat 10 times, repeat 50 times).
2.  **`while` loop:** Used when you want to repeat as long as a condition is true, but you don't know the exact number of iterations beforehand (e.g., repeat until the user enters 'q' to quit).
3.  **`do-while` loop:** Similar to a `while` loop, but it guarantees that the code block will be executed at least once, because the condition is checked *after* the loop body.

## 2. Syntax Section

### 1. The `for` Loop

The most common loop. It's compact and easy to read for a fixed number of iterations.

**Syntax:**
```c
for (initialization; condition; increment/decrement) {
    // Code to be executed repeatedly
}
```
*   **`initialization`**: Happens only ONCE at the very beginning. Usually where you declare and initialize a counter variable (e.g., `int i = 0`).
*   **`condition`**: Checked *before* each iteration. If it's true, the loop continues. If it's false, the loop stops. (e.g., `i < 10`).
*   **`increment/decrement`**: Happens at the *end* of each iteration. Usually used to update the counter (e.g., `i++`).

### 2. The `while` Loop

The condition is checked at the beginning. If the condition is false initially, the loop will never execute.

**Syntax:**
```c
while (condition) {
    // Code to be executed
    // Don't forget to update the variable used in the condition!
}
```

### 3. The `do-while` Loop

The condition is checked at the end. The loop body will always run at least one time.

**Syntax:**
```c
do {
    // Code to be executed
    // Update the variable
} while (condition); // Note the semicolon at the end!
```

## 3. Code Examples

### Example 1: `for` Loop (Printing numbers 1 to 5)
`for_loop.c`
```c
#include <stdio.h>

int main() {
    // i starts at 1; loop continues as long as i is less than or equal to 5; i increases by 1 after each loop
    for (int i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }
    return 0;
}
```
**Output:**
```
1
2
3
4
5
```

### Example 2: `while` Loop (Counting down from 5)
`while_loop.c`
```c
#include <stdio.h>

int main() {
    int count = 5;

    while (count > 0) {
        printf("Countdown: %d\n", count);
        count--; // This is crucial! Without it, you get an infinite loop.
    }

    printf("Blast off!\n");
    return 0;
}
```

### Example 3: `do-while` Loop (Menu that repeats)
`do_while_loop.c`
```c
#include <stdio.h>

int main() {
    int choice;

    do {
        // This menu will always be shown at least once
        printf("\n--- MENU ---\n");
        printf("1. Start Game\n");
        printf("2. Show High Scores\n");
        printf("3. Quit\n");
        printf("Enter your choice: ");
        scanf("%d", &choice);

        if (choice == 1) {
            printf("Starting game...\n");
        } else if (choice == 2) {
            printf("Showing high scores...\n");
        }

    } while (choice != 3); // Loop continues as long as the user does NOT choose 3

    printf("Thanks for playing!\n");
    return 0;
}
```

**Problem 6: Factorial of a Number**

**Problem 7: Count Digits in a Number**
*   **Statement:** Ask the user for an integer and count how many digits it has.
*   **Logic:** Repeatedly divide the number by 10 until it becomes 0. Count how many times you divided.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int num, count = 0;
        printf("Enter an integer: ");
        scanf("%d", &num);
        do {
            num /= 10;
            count++;
        } while (num != 0);
        printf("Number of digits: %d\n", count);
        return 0;
    }
    ```

**Problem 8: Reverse a Number**
*   **Statement:** Ask for a number and print its reverse. (e.g., 12345 -> 54321).
*   **Logic:** Use the modulus operator (`% 10`) to get the last digit, and then build the reversed number.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int num, reversed = 0, remainder;
        printf("Enter an integer: ");
        scanf("%d", &num);
        while (num != 0) {
            remainder = num % 10;
            reversed = reversed * 10 + remainder;
            num /= 10;
        }
        printf("Reversed number = %d\n", reversed);
        return 0;
    }
    ```

**Problem 9: Check for Palindrome**
*   **Statement:** A number is a palindrome if it reads the same forwards and backward (e.g., 121, 545). Check if a user-entered number is a palindrome.
*   **Logic:** Reverse the number and check if the reversed number is equal to the original number.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int num, original, reversed = 0, remainder;
        printf("Enter an integer: ");
        scanf("%d", &num);
        original = num; // Store the original number

        while (num != 0) {
            remainder = num % 10;
            reversed = reversed * 10 + remainder;
            num /= 10;
        }

        if (original == reversed) {
            printf("%d is a palindrome.\n", original);
        } else {
            printf("%d is not a palindrome.\n", original);
        }
        return 0;
    }
    ```

**Problem 10: Fibonacci Series**
*   **Statement:** Print the Fibonacci series up to a certain number of terms entered by the user. (The series starts 0, 1, 1, 2, 3, 5, 8... where each number is the sum of the two preceding ones).
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int i, n, t1 = 0, t2 = 1, nextTerm;
        printf("Enter the number of terms: ");
        scanf("%d", &n);
        printf("Fibonacci Series: ");

        for (i = 1; i <= n; ++i) {
            printf("%d, ", t1);
            nextTerm = t1 + t2;
            t1 = t2;
            t2 = nextTerm;
        }
        return 0;
    }
    ```

### 🔴 Advanced Problems

**Problem 11: Prime Number Check**
*   **Statement:** Check if a number entered by the user is a prime number. (A prime number is only divisible by 1 and itself).
*   **Logic:** Loop from 2 up to the number/2. If the number is divisible by any of these, it's not prime.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int n, i, flag = 0;
        printf("Enter a positive integer: ");
        scanf("%d", &n);

        for (i = 2; i <= n / 2; ++i) {
            // condition for non-prime
            if (n % i == 0) {
                flag = 1;
                break;
            }
        }

        if (n == 1) {
            printf("1 is neither prime nor composite.\n");
        } else {
            if (flag == 0)
                printf("%d is a prime number.\n", n);
            else
                printf("%d is not a prime number.\n", n);
        }
        return 0;
    }
    ```

**Problem 12: Armstrong Number**
*   **Statement:** An Armstrong number is a number that is equal to the sum of cubes of its digits (e.g., 153 = 1*1*1 + 5*5*5 + 3*3*3). Check if a number is an Armstrong number.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int num, originalNum, remainder, result = 0;
        printf("Enter a three-digit integer: ");
        scanf("%d", &num);
        originalNum = num;

        while (originalNum != 0) {
            remainder = originalNum % 10;
            result += remainder * remainder * remainder;
            originalNum /= 10;
        }

        if (result == num)
            printf("%d is an Armstrong number.\n", num);
        else
            printf("%d is not an Armstrong number.\n", num);

        return 0;
    }
    ```

**Problem 13: Greatest Common Divisor (GCD)**
*   **Statement:** Find the GCD of two numbers entered by the user.
*   **Logic:** The Euclidean algorithm is efficient. But a simpler way is to loop from 1 up to the smaller of the two numbers and find the largest number that divides both.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int n1, n2, i, gcd;
        printf("Enter two integers: ");
        scanf("%d %d", &n1, &n2);

        for (i = 1; i <= n1 && i <= n2; ++i) {
            // Checks if i is a factor of both integers
            if (n1 % i == 0 && n2 % i == 0)
                gcd = i;
        }

        printf("G.C.D of %d and %d is %d\n", n1, n2, gcd);
        return 0;
    }
    ```

**Problem 14: Least Common Multiple (LCM)**
*   **Statement:** Find the LCM of two numbers.
*   **Logic:** `LCM * GCD = num1 * num2`. So, first find the GCD.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int n1, n2, i, gcd, lcm;
        printf("Enter two positive integers: ");
        scanf("%d %d", &n1, &n2);

        for (i = 1; i <= n1 && i <= n2; ++i) {
            if (n1 % i == 0 && n2 % i == 0)
                gcd = i;
        }

        lcm = (n1 * n2) / gcd;
        printf("L.C.M. of %d and %d is %d\n", n1, n2, lcm);
        return 0;
    }
    ```

**Problem 15: Print Prime Numbers in a Range**
*   **Statement:** Ask the user for two numbers (a range) and print all prime numbers within that range.
*   **Logic:** Combine the logic for finding primes with a loop that goes through the range.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int low, high, i, flag;
        printf("Enter two numbers (intervals): ");
        scanf("%d %d", &low, &high);
        printf("Prime numbers between %d and %d are: ", low, high);

        while (low < high) {
            flag = 0;
            if (low <= 1) {
                ++low;
                continue;
            }
            for (i = 2; i <= low / 2; ++i) {
                if (low % i == 0) {
                    flag = 1;
                    break;
                }
            }
            if (flag == 0)
                printf("%d ", low);
            ++low;
        }
        return 0;
    }
    ```

**Problem 18: Perfect Number**
*   **Statement:** A perfect number is a positive integer that is equal to the sum of its proper divisors (e.g., 6 = 1+2+3). Check if a number is a perfect number.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int num, sum = 0;
        printf("Enter a number: ");
        scanf("%d", &num);
        for (int i = 1; i <= num / 2; i++) {
            if (num % i == 0) {
                sum += i;
            }
        }
        if (sum == num && num > 0) {
            printf("%d is a perfect number.\n", num);
        } else {
            printf("%d is not a perfect number.\n", num);
        }
        return 0;
    }
    ```

**Problem 19: Strong Number**
*   **Statement:** A strong number is a number where the sum of the factorial of its digits equals the number itself (e.g., 145 = 1! + 4! + 5!). Check if a number is a strong number.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int num, originalNum, remainder, sum = 0;
        printf("Enter an integer: ");
        scanf("%d", &num);
        originalNum = num;

        while (num > 0) {
            remainder = num % 10;
            int fact = 1;
            for (int i = 1; i <= remainder; i++) {
                fact *= i;
            }
            sum += fact;
            num /= 10;
        }

        if (sum == originalNum) {
            printf("%d is a strong number.\n", originalNum);
        } else {
            printf("%d is not a strong number.\n", originalNum);
        }
        return 0;
    }
    ```

**Problem 20: Binary to Decimal Conversion**
*   **Statement:** Ask the user to enter a binary number (as an integer, e.g., 1011) and convert it to its decimal equivalent.
*   **Solution:**
    ```c
    #include <stdio.h>
    #include <math.h>

    int main() {
        long long n;
        printf("Enter a binary number: ");
        scanf("%lld", &n);
        int decimal = 0, i = 0, remainder;
        while (n != 0) {
            remainder = n % 10;
            n /= 10;
            decimal += remainder * pow(2, i);
            ++i;
        }
        printf("Decimal equivalent: %d\n", decimal);
        return 0;
    }
    ```
