# Chapter 09: Arrays

What if you need to store the test scores of 100 students? Would you create 100 different variables like `score1`, `score2`, `score3`...? That would be a nightmare! Arrays solve this problem by letting you store multiple values of the *same data type* in a single variable.

## 1. Concept Explanation

### What is an Array?

**Simple Explanation:**
An array is like a train. The whole train has one name (the array name, e.g., `scores`), but it's made up of many individual cars (elements), each with its own number (an index). You can access any car by using its number.

**Real-life Analogy:**
Think of a street with houses. The street name is `Oak Street` (the array name). Each house on the street has a house number: 1, 2, 3, etc. (the array indices). If you want to go to the 3rd house on Oak Street, you use the address `Oak Street, House #3`.

**Important:** In C, array numbering (indexing) starts from **0**, not 1. So the first element is at index 0, the second at index 1, and so on.

**Technical Explanation:**
An array is a collection of fixed-size, sequential elements of the same data type. The elements are stored in contiguous memory locations. An array is a derived data type in C that can store the primitive type of data such as int, char, double, float, etc.

**Flowchart: Array Access**
```
[Array 'scores' is created with 5 elements: {90, 85, 78, 92, 88}]
      |
      v
[Memory looks like this:]
[Index 0: 90] [Index 1: 85] [Index 2: 78] [Index 3: 92] [Index 4: 88]
      |
      v
[To get the 3rd score, you ask for scores[2]]
      |
      v
[The value 78 is retrieved]
```

## 2. Syntax Section

### Declaring an Array

You must specify the data type and the size of the array.

**Syntax:**
```c
// data_type array_name[array_size];
int scores[100]; // An array to hold 100 integer scores
float prices[50]; // An array to hold 50 float prices
```

### Initializing an Array

You can initialize an array at the time of declaration.

**Syntax:**
```c
// Method 1: Initialize with size
int marks[5] = {80, 85, 90, 78, 92};

// Method 2: Initialize without size (compiler calculates it)
int marks[] = {80, 85, 90, 78, 92}; // Compiler knows the size is 5
```

### Accessing Array Elements

You use the array name followed by the index in square brackets `[]`.

**Syntax:**
```c
int marks[5] = {80, 85, 90, 78, 92};

// Access the first element (at index 0)
printf("%d", marks[0]); // Prints 80

// Change the third element (at index 2)
marks[2] = 95; // The array is now {80, 85, 95, 78, 92}
```

### Arrays and Loops

Loops are perfect for working with arrays. You can loop from index `0` to `size - 1` to access every element.

```c
int marks[5] = {80, 85, 90, 78, 92};
// Loop to print all elements
for (int i = 0; i < 5; i++) {
    printf("Score at index %d is %d\n", i, marks[i]);
}
```

### Example 3: Calculating the Average of Array Elements
`average_array.c`
```c
#include <stdio.h>

int main() {
    int marks[5] = {80, 65, 70, 95, 88};
    int sum = 0;
    float average;

    for (int i = 0; i < 5; i++) {
        sum += marks[i]; // Add each mark to the sum

    // Cast sum to float for accurate division
```


**Problem 8: Sort an Array (Bubble Sort)**
*   **Statement:** Sort an array of integers in ascending order using the simple Bubble Sort algorithm.
*   **Logic:** In each pass, compare adjacent elements and swap them if they are in the wrong order. Repeat this for all elements.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int arr[5] = {5, 2, 8, 1, 4};
        int temp;
        for (int i = 0; i < 5 - 1; i++) {
            for (int j = 0; j < 5 - i - 1; j++) {
                if (arr[j] > arr[j + 1]) { // Swap
                    temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
        printf("Sorted array: ");
        for (int i = 0; i < 5; i++) printf("%d ", arr[i]);
        return 0;
    }
    ```

**Problem 10: Merge Two Sorted Arrays**
*   **Statement:** Given two sorted arrays, merge them into a third sorted array.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int arr1[3] = {1, 3, 5};
        int arr2[3] = {2, 4, 6};
        int arr3[6];
        int i = 0, j = 0, k = 0;
        while (i < 3 && j < 3) {
            if (arr1[i] < arr2[j]) arr3[k++] = arr1[i++];
            else arr3[k++] = arr2[j++];
        }
        while (i < 3) arr3[k++] = arr1[i++];
        while (j < 3) arr3[k++] = arr2[j++];

        printf("Merged array: ");
        for (i = 0; i < 6; i++) printf("%d ", arr3[i]);
        return 0;
    }
    ```

**Problem 17: Find a Pair with a Given Sum**
*   **Statement:** Given an array of integers and a target sum, find if there exists a pair of elements in the array whose sum is equal to the given sum.
*   **Logic:** Use a nested loop. The outer loop picks an element, and the inner loop checks if there's another element that adds up to the target sum.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int arr[] = {1, 4, 45, 6, 10, 8};
        int n = 6;
        int target_sum = 16;
        int found = 0;

        for (int i = 0; i < n - 1; i++) {
            for (int j = i + 1; j < n; j++) {
                if (arr[i] + arr[j] == target_sum) {
                    printf("Pair found: (%d, %d)\n", arr[i], arr[j]);
                    found = 1;
                }
            }
        }

        if (!found) {
            printf("No pair with the given sum found.\n");
        }
        return 0;
    }
    ```

**Problem 18: Leaders in an Array**
*   **Statement:** An element is a "leader" if it is greater than all the elements to its right. Find all the leaders in an array. The rightmost element is always a leader.
*   **Logic:** Scan the array from right to left. Keep track of the maximum element found so far from the right. If the current element is greater than the maximum, it's a leader.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int arr[] = {16, 17, 4, 3, 5, 2};
        int n = 6;
        int max_from_right = arr[n-1];

        printf("Leaders: %d ", max_from_right);

        for (int i = n - 2; i >= 0; i--) {
            if (arr[i] > max_from_right) {
                max_from_right = arr[i];
                printf("%d ", max_from_right);
            }
        }
        printf("\n");
        return 0;
    }
    ```

**Problem 19: Sort an Array (Insertion Sort)**
*   **Statement:** Sort an array of integers in ascending order using the Insertion Sort algorithm.
*   **Logic:** Insertion sort iterates, consuming one input element each repetition, and grows a sorted output list. At each iteration, it removes one element from the input data, finds the location it belongs within the sorted list, and inserts it there.
*   **Solution:**
    ```c
    #include <stdio.h>
    int main() {
        int arr[] = {12, 11, 13, 5, 6};
        int n = 5;
        int i, key, j;
        for (i = 1; i < n; i++) {
            key = arr[i];
            j = i - 1;

            // Move elements of arr[0..i-1], that are greater than key,
            // to one position ahead of their current position
            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j = j - 1;
            }
            arr[j + 1] = key;
        }

        printf("Sorted array: ");
        for (i = 0; i < n; i++) {
            printf("%d ", arr[i]);
        }
        printf("\n");
        return 0;
    }
    ```

**Problem 20: Intersection of Two Arrays**
*   **Statement:** Find the intersection of two arrays. The intersection contains elements that are present in both arrays.
*   **Logic:** For each element in the first array, check if it is present in the second array.
*   **Solution:**
    ```c

    int main() {
        int arr1[] = {1, 2, 4, 5, 6};
        int arr2[] = {2, 3, 5, 7};
        int n1 = 5;
        int n2 = 4;

        printf("Intersection: ");
        for (int i = 0; i < n1; i++) {
            for (int j = 0; j < n2; j++) {
                if (arr1[i] == arr2[j]) {
                    printf("%d ", arr1[i]);
                    break; // Move to the next element in arr1
                }
            }
        }
        printf("\n");
        return 0;
    }
    ```
