# MAC Table Flooding

## How a switch normally works

A switch keeps a **MAC address table** (CAM table) that maps each MAC address to a switch port. It learns entries from the source MAC of incoming frames. When a frame arrives, the switch sends it **only** to the port of the destination MAC. So normally a host cannot see other hosts' traffic.

## What is MAC table flooding?

**MAC address table flooding** is an attack that uses the **fixed size** of the switch's MAC table.

1. The attacker sends a huge number of frames, each with a **different fake source MAC address**.
2. The switch learns every fake address until the MAC table is **full**.
3. Now the switch cannot learn the real hosts' addresses. Frames for unknown destinations are treated as **unknown unicast**.
4. The switch **floods** these frames out of **all ports** except the incoming one, like a hub.
5. The attacker, connected to one port, now receives and can capture frames between other hosts on the same LAN or VLAN.

```text
Normal switch:   A ----> [Switch] ----> B only

Table full:      A ----> [Switch] ----> B
                              |-------> C
                              |-------> Attacker (copy of every frame)
```

The attack breaks **confidentiality**: it turns the switch into a hub so the attacker can sniff traffic.

## Prevention

- **Enable port security**: allow only known MAC addresses on a port.
- **Limit the number of MAC addresses per port** (for example, at most 2). Extra addresses are dropped or the port is shut down.
- **Disable unused switch ports**, so an attacker cannot simply plug in.
- **Monitor ports** for unusual behaviour, such as one port sending traffic from thousands of MAC addresses.

## Exam-ready answer

**Q. What is MAC table flooding and how is it prevented? (4 marks)**

A switch's MAC table has a fixed size. In MAC flooding the attacker sends many frames with fake source MAC addresses until the table is full. The switch can no longer learn real addresses, so it floods frames to all ports like a hub, and the attacker can capture other hosts' traffic on the LAN.

Prevention: enable port security, limit the number of MAC addresses per port, disable unused ports, and monitor ports for abnormal numbers of MAC addresses.
