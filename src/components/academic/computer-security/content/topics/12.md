# Viruses and Anti-Virus

## What is a computer virus?

A **computer virus** is a malicious program that spreads by **infecting other programs or files** and making copies of itself. A virus needs a **host** file and needs a **human to run** the infected file before it can spread.

**Example: macro virus.** A macro is a small program inside a Word or Excel document. When an infected document is opened, the virus copies itself into the global macro file and runs automatically, so every new document gets infected.

## Phases of a virus

1. **Dormant phase:** the virus exists but stays quiet to avoid detection.
2. **Propagation phase:** it copies itself into other files and systems.
3. **Triggering phase:** a condition (a date, an event, a count) activates it.
4. **Action phase:** it performs its harmful task, called the **payload** (deleting files, showing messages, stealing data).

## How viruses spread (propagation)

- **Executable file infection:** a copy is inserted into program files such as .COM and .EXE.
- **Boot sector infection:** a copy is placed in the boot sector of a disk, so it runs at start-up. Example: the Stoned virus spread through floppy disks.
- **TSR / OS routine infection:** it stays resident in memory and infects other disks and programs as they are used.
- **P2P file sharing:** infected files disguised as popular software are shared and downloaded.
- **Websites and drive-by downloads:** malware is downloaded when a user visits an infected or malicious site.

## Concealment: how viruses hide

**Concealment** means hiding the virus code so anti-virus software cannot recognise it.

| Type | How it hides | How it is detected |
|---|---|---|
| **Encrypted virus** | Body is encrypted with a random key; only a small decryption engine is visible. | Look for the decryption engine's signature. |
| **Polymorphic virus** | Encrypted, and the decryption engine itself changes in every copy. | Emulate it on a virtual CPU until it decrypts itself. |
| **Metamorphic virus** | Rewrites its whole body in each copy, keeping the same behaviour. | Hard; needs behaviour (heuristic) analysis. |

```text
Encrypted:    [ Decryption engine ][ Encrypted body ]     engine stays the same
Polymorphic:  [ Engine version 1 ][ Body, key 1 ]          engine changes every copy
              [ Engine version 2 ][ Body, key 2 ]
Metamorphic:  [ Rewritten code, same behaviour ]           whole code changes
```

**Encrypted virus in short:** the attacker keeps the main code encrypted and changes the key in each copy, so the body looks different every time. Only the small decryption routine at the start stays the same, and that routine is what scanners look for.

## Mutation (obfuscation) techniques

**Mutation** changes the virus code while keeping the same function, so signature matching fails. Examples:

- **Register swapping** (RegSwap): same code, different CPU registers.
- **Reordering subroutines** (BadBoy, Ghost).
- **Building the body instruction by instruction** at run time (Zmorph).

## Anti-virus technologies

**1. Simple scanners**

- **Signature-based detection:** a signature is a unique byte pattern of a known virus (not a digital signature). Files are compared to a database of signatures using fast pattern matching. Fast and accurate for known malware, but misses new or mutated malware.
- **Heuristic analysis:** finds new and zero-day malware by its suspicious behaviour:
  - *Code analysis:* look for suspicious instructions, such as deleting system files.
  - *Execution emulation:* run the program in an isolated environment (a sandbox or virtual machine) and watch what it does.
- **Integrity checking:** detect changed files by comparing sizes, checksums or MACs (message authentication codes). Also used to detect rootkits.

**2. Generic decryption and emulation**

The scanner emulates the CPU for a few hundred instructions so an encrypted virus decrypts itself in the emulator. The decrypted body is then matched against known signatures. It is less effective against metamorphic viruses and viruses whose code is not near the start of the file.

**3. Quarantine**

Suspicious files are moved to a secure folder and encrypted so they cannot run. They are not deleted: the user can later delete them, or restore them if they were a false positive. Useful when heuristics flag a file before a signature update is available.

## Exam-ready answers

**Q. What is a virus? Write its phases. (4 marks)**

A virus is a malicious program that attaches to other programs and copies itself when the infected program is run. Phases:
1. **Dormant:** stays hidden and idle.
2. **Propagation:** copies itself into other files and systems.
3. **Triggering:** a condition activates it.
4. **Action:** delivers the payload, the harmful action.

**Q. What is an encrypted virus and how is it detected? (4 marks)**

An encrypted virus has two parts: a small decryption engine and an encrypted body. Each copy uses a new random key, so the body looks different every time and signature scanning of the body fails.

Detection:
- Scan for the signature of the **decryption engine**, which stays the same.
- **Generic decryption / emulation:** run the file in a CPU emulator until the virus decrypts itself, then match the decrypted body.
- **Heuristic and integrity checks** to catch changed files and suspicious behaviour.

**Q. Why would a malware writer create many variants with different signatures? (3 marks)**

Signature-based anti-virus needs a new signature for every variant. Many variants that use the same vulnerability can infect more computers for longer before all signatures are added. More infected machines means more money, through stolen data, spam, ransom or renting out a botnet.
