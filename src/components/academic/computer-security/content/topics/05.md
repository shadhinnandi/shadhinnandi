# Diffie-Hellman Key Exchange

## What is Diffie-Hellman?

**Diffie-Hellman (DH)** is a method that lets two people create the **same secret key** over a public channel, **without ever sending the key itself**. The shared key is then used for encryption.

## The philosophy behind it

- **Problem it solves:** symmetric encryption needs a shared secret key, but sending that key over the Internet is unsafe (key distribution problem).
- **Idea:** each side keeps a private number and sends only a "mixed" public value. Each side then mixes the other's public value with its own private number. Both arrive at the same result, but an eavesdropper who sees only the public values cannot.
- **Why it is secure:** computing g<sup>a</sup> mod p is easy, but finding a from g<sup>a</sup> mod p is very hard for a large prime p. This is the **discrete logarithm problem**. It is a one-way function.
- **Paint analogy:** both start with the same public colour, each adds a secret colour and swaps the mix, then adds their secret colour again. Both get the same final colour; un-mixing paint is practically impossible.

## Steps

1. Both agree on public values: a large prime **p** and a **primitive root g** of p. (g is a primitive root if g<sup>1</sup>, g<sup>2</sup>, ..., g<sup>p−1</sup> mod p give every value from 1 to p − 1.)
2. A chooses a private key **S<sub>A</sub>** and sends the public key **P<sub>A</sub> = g<sup>S<sub>A</sub></sup> mod p**.
3. B chooses a private key **S<sub>B</sub>** and sends the public key **P<sub>B</sub> = g<sup>S<sub>B</sub></sup> mod p**.
4. A computes **K = P<sub>B</sub><sup>S<sub>A</sub></sup> mod p**. B computes **K = P<sub>A</sub><sup>S<sub>B</sub></sup> mod p**.
5. Both values equal g<sup>S<sub>A</sub>S<sub>B</sub></sup> mod p, so A and B now share the secret key K.

```seq
A | B
A: public p, g; private S_A; P_A = g^{S_A} mod p
B: public p, g; private S_B; P_B = g^{S_B} mod p
A -> B: P_A
B -> A: P_B
A: K = P_B^{S_A} mod p
B: K = P_A^{S_B} mod p
```

**Sending a message with the shared key** (as used in the class examples):

```calc
# Encrypt
C = K × M mod p
# Decrypt
M = K^{−1} × C mod p
```

## Worked example 1: key exchange and messages

**Anis and Boshir use DH with p = 23 and g = 5. Anis's secret key S<sub>A</sub> = 6 and Boshir's S<sub>B</sub> = 15. Anis sends M<sub>1</sub> = 9 and Boshir replies with M<sub>2</sub> = 3. Find the ciphertexts and decrypted texts and show the exchange.**

```calc
# Given
p = 23
g = 5
S_A = 6
S_B = 15
```

**Public keys**

```calc
P_A = g^{S_A} mod p
    = 5^{6} mod 23
    = 15625 mod 23
    = 8
```

```calc
P_B = g^{S_B} mod p
    = 5^{15} mod 23
    = (5^{6} mod 23)^{2} × 5^{3} mod 23
    = 8^{2} × 125 mod 23
    = 64 × 10 mod 23   [125 mod 23 = 10]
    = 640 mod 23
    = 19
```

**Shared key at both sides**

```calc
# Anis
K = P_B^{S_A} mod p
  = 19^{6} mod 23
  = (19^{2} mod 23)^{3}
  = 16^{3} mod 23   [361 mod 23 = 16]
  = 4096 mod 23
  = 2
```

```calc
# Boshir
K = P_A^{S_B} mod p
  = 8^{15} mod 23
  = (8^{2} mod 23)^{7} × 8 mod 23
  = 18^{7} × 8 mod 23   [64 mod 23 = 18]
  = (18^{2} mod 23)^{3} × 18 × 8 mod 23
  = 2^{3} × 18 × 8 mod 23   [324 mod 23 = 2]
  = 1152 mod 23
  = 2
∴ Shared key K = 2 on both sides
```

**Messages.** K<sup>−1</sup> = 2<sup>−1</sup> mod 23 = 12, because 2 × 12 = 24 and 24 mod 23 = 1.

```calc
# Anis encrypts M_1 = 9
C_1 = K × M_1 mod p
    = 2 × 9 mod 23
    = 18
# Boshir decrypts C_1
M_1 = K^{−1} × C_1 mod p
    = 2^{−1} × 18 mod 23
    = 12 × 18 mod 23
    = 216 mod 23
    = 9
# Boshir encrypts M_2 = 3
C_2 = K × M_2 mod p
    = 2 × 3 mod 23
    = 6
# Anis decrypts C_2
M_2 = K^{−1} × C_2 mod p
    = 12 × 6 mod 23
    = 72 mod 23
    = 3
```

```seq
Anis | Boshir
Anis: P_A = 8
Boshir: P_B = 19
Anis -> Boshir: P_A = 8
Boshir -> Anis: P_B = 19
Anis: K = 19^{6} mod 23 = 2
Boshir: K = 8^{15} mod 23 = 2
Anis: C_1 = 2 × 9 mod 23 = 18
Anis -> Boshir: C_1 = 18
Boshir: M_1 = 12 × 18 mod 23 = 9
Boshir: C_2 = 2 × 3 mod 23 = 6
Boshir -> Anis: C_2 = 6
Anis: M_2 = 12 × 6 mod 23 = 3
```

## Man-in-the-middle attack on Diffie-Hellman

Plain DH does not check **who** sent a public key. An attacker in the middle can replace both public keys with their own:

1. The attacker catches P<sub>A</sub> and sends its own key P<sub>T</sub> to B. It also catches P<sub>B</sub> and sends P<sub>T</sub> to A.
2. A now shares a key K<sub>AT</sub> with the attacker, and B shares a different key K<sub>BT</sub> with the attacker. Each thinks it shares a key with the other.
3. The attacker decrypts every message with one key, reads or changes it, and re-encrypts it with the other key.

**Defence:** authenticate the public keys, for example by signing them with digital signatures or using certificates from a Certification Authority (authenticated Diffie-Hellman).

## Worked example 2: MITM with Trudo

**Anis and Boshir use DH, but Trudo is in the middle. Anis sends M<sub>a</sub> = 9 as C<sub>a</sub>; Trudo decrypts it, re-encrypts it as C<sub>a,t</sub> and forwards it to Boshir. Boshir replies M<sub>b</sub> = 10 as C<sub>b</sub>; Trudo decrypts it, changes it to M<sub>t</sub> = 2, encrypts it as C<sub>t</sub> and sends it to Anis.**

| Person | Secret key | Message | p, g |
|---|---|---|---|
| Anis | s<sub>a</sub> = 5 | M<sub>a</sub> = 9 | p = 11, g = 2 |
| Boshir | s<sub>b</sub> = 4 | M<sub>b</sub> = 10 | |
| Trudo | s<sub>t</sub> = 2 | M<sub>t</sub> (modified) = 2 | |

**(a) Public keys and shared keys**

```calc
P_a = g^{s_a} mod p = 2^{5} mod 11 = 32 mod 11 = 10
P_b = g^{s_b} mod p = 2^{4} mod 11 = 16 mod 11 = 5
P_t = g^{s_t} mod p = 2^{2} mod 11 = 4
# Anis and Trudo
K_at = P_t^{s_a} mod p = 4^{5} mod 11 = 1024 mod 11 = 1   [at Anis]
K_at = P_a^{s_t} mod p = 10^{2} mod 11 = 100 mod 11 = 1   [at Trudo]
# Boshir and Trudo
K_bt = P_t^{s_b} mod p = 4^{4} mod 11 = 256 mod 11 = 3   [at Boshir]
K_bt = P_b^{s_t} mod p = 5^{2} mod 11 = 25 mod 11 = 3   [at Trudo]
```

So K<sub>at</sub> = 1 and K<sub>bt</sub> = 3. The inverses are K<sub>at</sub><sup>−1</sup> = 1 and K<sub>bt</sub><sup>−1</sup> = 3<sup>−1</sup> mod 11 = 4 (since 3 × 4 = 12 and 12 mod 11 = 1).

**(b) Ciphertexts and decrypted texts**

```calc
# Anis encrypts M_a = 9
C_a = K_at × M_a mod p = 1 × 9 mod 11 = 9
# Trudo decrypts C_a
M_a = K_at^{−1} × C_a mod p = 1 × 9 mod 11 = 9
# Trudo re-encrypts for Boshir
C_at = K_bt × M_a mod p = 3 × 9 mod 11 = 27 mod 11 = 5
# Boshir decrypts
M_a = K_bt^{−1} × C_at mod p = 4 × 5 mod 11 = 20 mod 11 = 9
# Boshir encrypts M_b = 10
C_b = K_bt × M_b mod p = 3 × 10 mod 11 = 30 mod 11 = 8
# Trudo decrypts C_b
M_b = K_bt^{−1} × C_b mod p = 4 × 8 mod 11 = 32 mod 11 = 10
# Trudo encrypts the modified message M_t = 2 for Anis
C_t = K_at × M_t mod p = 1 × 2 mod 11 = 2
# Anis decrypts
M_t = K_at^{−1} × C_t mod p = 1 × 2 mod 11 = 2
```

**(c) Message exchange**

```seq
Anis | Trudo | Boshir
Anis -> Trudo: P_a = 10
Trudo -> Boshir: P_t = 4
Boshir -> Trudo: P_b = 5
Trudo -> Anis: P_t = 4
Anis: K_at = 1
Trudo: K_at = 1; K_bt = 3
Boshir: K_bt = 3
Anis -> Trudo: C_a = 9
Trudo: M_a = 9; C_at = 5
Trudo -> Boshir: C_at = 5
Boshir: M_a = 9
Boshir -> Trudo: C_b = 8
Trudo: M_b = 10; changes it to 2; C_t = 2
Trudo -> Anis: C_t = 2
Anis: M_t = 2 (thinks Boshir sent 2)
```

Anis receives 2 instead of Boshir's real reply 10, and neither side notices.

## Exam-ready answers

**Q. Explain the philosophy behind the Diffie-Hellman key exchange. (3 marks)**

- Two parties want a shared secret key but can only talk over a public channel, so the key itself must never be sent.
- Each side keeps a private number and sends only g<sup>private</sup> mod p. Each side raises the other's public value to its own private number and both get g<sup>ab</sup> mod p.
- An eavesdropper sees g, p, g<sup>a</sup> mod p and g<sup>b</sup> mod p, but cannot find a or b because the discrete logarithm problem is very hard for large p.

**Q. Why is plain Diffie-Hellman open to a man-in-the-middle attack? (3 marks)**

Public keys are not authenticated. An attacker can replace each public key with its own, so it shares one key with A and another with B. It then decrypts, reads or changes, and re-encrypts every message. Signing the public keys or using certificates prevents this.
