# Buffer Overflow

## What is a buffer overflow?

A **buffer** is a fixed-size block of memory, such as an array. A **buffer overflow** happens when a program writes **more data than the buffer can hold**, so the extra data spills into the memory next to it.

It is caused by programs that copy input **without checking its length**, common in C and C++ with functions such as `strcpy`, `gets` and `sprintf`.

**Effects:** the program can crash (denial of service), data next to the buffer can be corrupted, and in the worst case an attacker can change which code the program runs next.

## Stack-based buffer overflow (stack smashing)

When a function is called, a **stack frame** is created. It holds the local variables (including buffers), the saved frame pointer and the **return address**, which tells the CPU where to continue when the function ends.

```text
High memory
+------------------------------+
| function arguments           |
+------------------------------+
| return address               |  <- where to go back after the function
+------------------------------+
| saved frame pointer          |
+------------------------------+
| canary (if protected)        |
+------------------------------+
| buffer[8]                    |  <- input is copied here, upward
+------------------------------+
Low memory
```

**In one line:** because the buffer sits below the return address, input longer than the buffer overwrites the saved values above it, including the **return address**, so when the function returns, control goes to an address chosen by the input instead of the real caller.

This is called **stack smashing**.

**A simple unsafe example:**

```c
void greet(char *name) {
    char buf[8];
    strcpy(buf, name);     /* no length check: input longer than 7 characters overflows buf */
    printf("Hello %s\n", buf);
}
```

**The safe version** checks the size:

```c
void greet(const char *name) {
    char buf[8];
    snprintf(buf, sizeof buf, "%s", name);   /* never writes more than 8 bytes */
    printf("Hello %s\n", buf);
}
```

## Stack canaries

A **stack canary** is a random secret value that the compiler places **between the buffer and the return address** when the function starts.

1. When the function starts, the canary value is written to the stack.
2. An overflow that reaches the return address must first overwrite the canary.
3. Before the function returns, the program checks whether the canary is unchanged.
4. If it changed, the program **stops immediately** instead of returning, so the overwritten return address is never used.

The canary is random for each run, so an attacker cannot simply rewrite the same value. (Named after the canary birds miners used as an early warning.)

## Protection against buffer overflow

- **Bounds checking:** always check input length; use safe functions (`fgets`, `strncpy`, `snprintf`) instead of `gets`, `strcpy`, `sprintf`.
- **Memory-safe languages** such as Java, Python or Rust, which check array bounds automatically.
- **Stack canaries** (compiler stack protection, e.g. `-fstack-protector`).
- **Non-executable stack (NX / DEP):** memory used for data cannot be run as code.
- **ASLR (Address Space Layout Randomization):** places the stack, heap and libraries at random addresses each run, so targets are hard to predict.
- **Code review, static analysis and fuzz testing** to find unsafe code before release.

## Exam-ready answers

**Q. Explain a buffer overflow (stack smashing) attack with an example. How can it be prevented? (3 to 5 marks)**

A buffer overflow happens when a program copies more data into a fixed-size buffer than it can hold, and the extra data overwrites nearby memory. In a stack overflow, the buffer is a local variable on the stack, below the saved frame pointer and the **return address**. Over-long input overwrites the return address, so when the function returns, control jumps to a location chosen by the attacker instead of the real caller.

Example: `char buf[8]; strcpy(buf, input);` with no length check.

Prevention:
- Check bounds and use safe functions (`fgets`, `snprintf`).
- Stack canaries to detect overwriting before return.
- Non-executable stack (NX/DEP) and ASLR.
- Memory-safe languages, code review and testing.
