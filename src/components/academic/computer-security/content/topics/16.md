# Firewalls

## What is a firewall?

A **firewall** is a set of security measures that **filters incoming and outgoing network traffic** using a predefined set of rules called **firewall policies**. It protects a private network or a single machine from unauthorised access from the wider Internet.

```text
Internet  <---->  [ Firewall: check each packet against the rules ]  <---->  Private network
```

## Working principle

Each packet passing through a firewall gets one of three outcomes:

- **Accepted:** allowed through.
- **Dropped:** blocked silently, with no reply to the sender.
- **Rejected:** blocked, and the sender is told that the packet was rejected.

Rules are based on properties of the packet, such as:

- the protocol (TCP or UDP),
- source and destination IP addresses,
- source and destination ports,
- the application payload (for example, whether it contains a virus).

## Blacklist and whitelist approaches

| | Blacklist (default-allow) | Whitelist (default-deny) |
|---|---|---|
| Rule | Allow everything except what the blacklist blocks | Block everything except what is specifically allowed |
| Advantage | Flexible; normal services are rarely disrupted | Safer; unknown traffic is blocked |
| Disadvantage | New or unexpected malicious traffic gets through | Must list all legitimate traffic in advance |

## Types of firewall

**Stateless firewall (packet filter)**

- Checks each packet **on its own**, with no memory of earlier packets.
- If a packet matches a rule, it is accepted or dropped.
- Simple and fast, but must be quite restrictive to stop attacks, because it cannot tell whether a packet belongs to a real connection.

**Stateful firewall**

- Keeps a **table of active connections** (IP addresses, ports, sequence numbers).
- Can tell whether a packet starts a new connection, belongs to an existing one, or is invalid.
- Can allow inbound TCP packets **only if they reply to a connection started from inside** the network.

| Stateless | Stateful |
|---|---|
| No memory of past packets | Remembers each connection |
| Judges each packet alone | Judges a packet as part of its connection |
| Faster, simpler | More accurate, needs more memory |
| Must be more restrictive | Allows replies to inside connections only |

## Exam-ready answers

**Q. What is a firewall? Write its working principle. (3 marks)**

A firewall filters incoming and outgoing traffic according to rules (firewall policies) to stop unauthorised access to a network or computer. Each packet is accepted, dropped or rejected based on its protocol, source and destination IP addresses, ports and sometimes its payload.

**Q. Difference between stateless and stateful firewalls. (3 marks)**

A stateless firewall checks every packet alone, with no memory of earlier packets, so it is fast but must be restrictive. A stateful firewall keeps a table of active connections and checks each packet against it, so it can allow only replies to connections started from inside the network.
