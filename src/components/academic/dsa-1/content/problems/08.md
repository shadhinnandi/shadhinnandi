# Linked Lists: Practice Problems

Build every list from your own nodes (no `std::list`) unless stated. Free the nodes you allocate.

## DSA08-E01 · Build a List at Both Ends
**Difficulty:** Easy · **Subtopic:** Head and tail insertion · **Tags:** linked list, head, tail · **Source:** Original

### Statement
Start with an empty singly linked list with head and tail pointers. Apply operations `front x` (insert at head) and `back x` (insert at tail), then print the list.

### Input
q, then q operations.

### Output
The list from head to tail.

### Constraints
- 1 ≤ q ≤ 2·10^5

### Sample Input
```text
4
back 1
back 2
front 0
back 3
```

### Sample Output
```text
0 1 2 3
```

### Sample Explanation
0 goes before 1; 3 goes after 2.

### Target
O(1) per insertion.

### Hints
1. A tail pointer makes insertion at the end O(1).
2. When the list is empty, the new node is both head and tail.

### Approach
Maintain head and tail; update both on the first insertion.

### Solution
```cpp
#include <iostream>
#include <string>
using namespace std;

struct Node { long long value; Node* next; };

int main() {
    int q;
    cin >> q;
    Node *head = nullptr, *tail = nullptr;
    while (q--) {
        string op;
        long long x;
        cin >> op >> x;
        if (op == "front") {
            head = new Node{x, head};
            if (!tail) tail = head;
        } else {
            Node* node = new Node{x, nullptr};
            if (tail) tail->next = node; else head = node;
            tail = node;
        }
    }
    for (Node* p = head; p; p = p->next) cout << p->value << (p->next ? ' ' : '\n');
    while (head) { Node* nx = head->next; delete head; head = nx; }
}
```

### Explanation
Head insertion relinks one pointer; tail insertion needs the tail pointer to avoid an O(n) walk.

### Edge Cases
- Only front insertions (tail must still be set).

### Tests
#### Fronts only
```text
3
front 1
front 2
front 3
```
```text
3 2 1
```

## DSA08-E02 · Length and Sum
**Difficulty:** Easy · **Subtopic:** Traversal · **Tags:** linked list, traversal · **Source:** Original

### Statement
Build a list from n values (in order) and print its length and the sum of its values by traversing it.

### Input
n, then n integers.

### Output
Length and sum.

### Constraints
- 1 ≤ n ≤ 2·10^5, |values| ≤ 10^9

### Sample Input
```text
4
3 -1 4 2
```

### Sample Output
```text
4 8
```

### Sample Explanation
Four nodes summing to 8.

### Target
O(n).

### Hints
1. Follow `next` until nullptr.
2. Building in order is easiest by inserting at the head in reverse, or with a tail pointer.

### Approach
Build with a tail pointer, then traverse.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

int main() {
    int n;
    cin >> n;
    Node dummy{0, nullptr};
    Node* tail = &dummy;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; tail->next = new Node{x, nullptr}; tail = tail->next; }
    long long length = 0, sum = 0;
    for (Node* p = dummy.next; p; p = p->next) { ++length; sum += p->value; }
    cout << length << ' ' << sum << '\n';
    for (Node* p = dummy.next; p;) { Node* nx = p->next; delete p; p = nx; }
}
```

### Explanation
A dummy node on the stack makes building by appending need no special case for the first node.

### Edge Cases
- n = 1.

### Tests
#### One node
```text
1
-7
```
```text
1 -7
```

## DSA08-E03 · Search a List
**Difficulty:** Easy · **Subtopic:** Sequential search · **Tags:** linked list, searching · **Source:** Original

### Statement
Build a list from n values. For each query print the 0-based position of the first node holding x, or −1.

### Input
n and values; q and queries.

### Output
One position per query.

### Constraints
- 1 ≤ n, q ≤ 2000

### Sample Input
```text
5
4 2 7 2 9
3
2
9
5
```

### Sample Output
```text
1
4
-1
```

### Sample Explanation
No random access: the search walks from the head.

### Target
O(n) per query.

### Hints
1. Walk with a counter.
2. Stop at the first match.

### Approach
Traversal with an index counter.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

int main() {
    int n;
    cin >> n;
    Node dummy{0, nullptr};
    Node* tail = &dummy;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; tail->next = new Node{x, nullptr}; tail = tail->next; }
    int q;
    cin >> q;
    while (q--) {
        long long x;
        cin >> x;
        int pos = 0, found = -1;
        for (Node* p = dummy.next; p; p = p->next, ++pos)
            if (p->value == x) { found = pos; break; }
        cout << found << '\n';
    }
    for (Node* p = dummy.next; p;) { Node* nx = p->next; delete p; p = nx; }
}
```

### Explanation
Even if the values were sorted, binary search would not help: reaching the middle node takes O(n) steps.

### Edge Cases
- Match at the head or the tail.

### Tests
#### Head
```text
2
8 9
1
8
```
```text
0
```

## DSA08-E04 · Delete Every Occurrence
**Difficulty:** Easy · **Subtopic:** Deletion with a dummy node · **Tags:** linked list, deletion, sentinel · **Source:** Original

### Statement
Build a list, delete every node with value x, and print the result (or `EMPTY`).

### Input
n and values, then x.

### Output
The remaining list.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
6
1 2 2 3 2 4
2
```

### Sample Output
```text
1 3 4
```

### Sample Explanation
Three 2s removed.

### Target
O(n).

### Hints
1. A dummy node before the head lets you delete the head like any other node.
2. Only advance when you did not delete.

### Approach
Walk with `prev`; if `prev->next` holds x, unlink and delete it.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

int main() {
    int n;
    cin >> n;
    Node dummy{0, nullptr};
    Node* tail = &dummy;
    for (int i = 0; i < n; ++i) { long long v; cin >> v; tail->next = new Node{v, nullptr}; tail = tail->next; }
    long long x;
    cin >> x;
    for (Node* prev = &dummy; prev->next;) {
        if (prev->next->value == x) {
            Node* gone = prev->next;
            prev->next = gone->next;       // unlink, then free
            delete gone;
        } else {
            prev = prev->next;
        }
    }
    if (!dummy.next) cout << "EMPTY\n";
    for (Node* p = dummy.next; p; p = p->next) cout << p->value << (p->next ? ' ' : '\n');
    for (Node* p = dummy.next; p;) { Node* nx = p->next; delete p; p = nx; }
}
```

### Explanation
Without the dummy node, deleting the head would need separate code. Saving `gone` before relinking avoids a dangling pointer.

### Edge Cases
- Every node deleted; consecutive matches; match at head.

### Tests
#### All deleted
```text
3
5 5 5
5
```
```text
EMPTY
```

## DSA08-E05 · Reverse a List
**Difficulty:** Easy · **Subtopic:** Pointer reversal · **Tags:** linked list, reversal, pointers · **Source:** Original

### Statement
Reverse a singly linked list by relinking pointers (not by copying values) and print it.

### Input
n, then n integers.

### Output
The reversed list.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
4
1 2 3 4
```

### Sample Output
```text
4 3 2 1
```

### Sample Explanation
Every next pointer is turned around.

### Target
O(n) time, O(1) extra space.

### Hints
1. Keep prev, cur and next.
2. Save cur->next before overwriting it.

### Approach
Iterative three-pointer reversal.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

int main() {
    int n;
    cin >> n;
    Node* head = nullptr;
    Node** link = &head;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; *link = new Node{x, nullptr}; link = &(*link)->next; }
    Node* prev = nullptr;
    while (head) {                       // invariant: prev = reversed prefix
        Node* nx = head->next;
        head->next = prev;
        prev = head;
        head = nx;
    }
    for (Node* p = prev; p; p = p->next) cout << p->value << (p->next ? ' ' : '\n');
    while (prev) { Node* nx = prev->next; delete prev; prev = nx; }
}
```

### Explanation
Each step moves one node from the remaining list to the front of the reversed list. Recursion would also work but uses O(n) stack.

### Edge Cases
- n = 1.

### Tests
#### Single
```text
1
9
```
```text
9
```

## DSA08-M01 · Merge Two Sorted Lists
**Difficulty:** Medium · **Subtopic:** Merging by relinking · **Tags:** linked list, merging, dummy node · **Source:** Original

### Statement
Merge two sorted lists into one sorted list by relinking their nodes.

### Input
n and the first list; m and the second list (m may be 0).

### Output
The merged list.

### Constraints
- 1 ≤ n ≤ 2·10^5, 0 ≤ m ≤ 2·10^5

### Sample Input
```text
3
1 3 5
3
2 4 6
```

### Sample Output
```text
1 2 3 4 5 6
```

### Sample Explanation
Alternating nodes.

### Target
O(n + m), O(1) extra nodes.

### Hints
1. A dummy head and a tail pointer.
2. Attach the remaining list at the end in one step.

### Approach
Relink the smaller front node each time.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

Node* readList() {
    int k;
    cin >> k;
    Node* head = nullptr;
    Node** link = &head;
    for (int i = 0; i < k; ++i) { long long x; cin >> x; *link = new Node{x, nullptr}; link = &(*link)->next; }
    return head;
}

int main() {
    Node* a = readList();
    Node* b = readList();
    Node dummy{0, nullptr};
    Node* tail = &dummy;
    while (a && b) {
        Node*& smaller = (b->value < a->value) ? b : a;
        tail->next = smaller;
        tail = smaller;
        smaller = smaller->next;
    }
    tail->next = a ? a : b;                  // attach the rest
    for (Node* p = dummy.next; p; p = p->next) cout << p->value << (p->next ? ' ' : '\n');
    for (Node* p = dummy.next; p;) { Node* nx = p->next; delete p; p = nx; }
}
```

### Explanation
No nodes are copied; ties take from the first list, keeping the merge stable.

### Edge Cases
- One list empty.

### Tests
#### Second empty
```text
2
1 2
0
```
```text
1 2
```

## DSA08-M02 · Middle Node
**Difficulty:** Medium · **Subtopic:** Slow and fast pointers · **Tags:** linked list, two pointers · **Source:** Original

### Statement
Print the value of the middle node in one pass (for even length, the second of the two middle nodes).

### Input
n, then n integers.

### Output
The middle value.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
1 2 3 4 5
```

### Sample Output
```text
3
```

### Sample Explanation
The third node.

### Target
O(n), one pass, O(1) space.

### Hints
1. Move slow one step and fast two steps.
2. When fast reaches the end, slow is in the middle.

### Approach
Tortoise and hare.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

int main() {
    int n;
    cin >> n;
    Node* head = nullptr;
    Node** link = &head;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; *link = new Node{x, nullptr}; link = &(*link)->next; }
    Node *slow = head, *fast = head;
    while (fast && fast->next) { slow = slow->next; fast = fast->next->next; }
    cout << slow->value << '\n';
    while (head) { Node* nx = head->next; delete head; head = nx; }
}
```

### Explanation
After t steps slow is at index t and fast at 2t, so slow stops at ⌊n/2⌋.

### Edge Cases
- Even length.

### Tests
#### Even
```text
4
1 2 3 4
```
```text
3
```

## DSA08-M03 · Remove the k-th from the End
**Difficulty:** Medium · **Subtopic:** Gap pointers · **Tags:** linked list, two pointers, deletion · **Source:** Original

### Statement
Remove the k-th node from the end in one pass and print the list (or `EMPTY`).

### Input
n and k, then n integers.

### Output
The resulting list.

### Constraints
- 1 ≤ k ≤ n ≤ 2·10^5

### Sample Input
```text
5 2
1 2 3 4 5
```

### Sample Output
```text
1 2 3 5
```

### Sample Explanation
The second from the end is 4.

### Target
O(n), one pass.

### Hints
1. Move a lead pointer k steps ahead of a trailing pointer.
2. Start the trailing pointer at a dummy so you stop just before the target.

### Approach
Dummy node, gap of k + 1 between pointers.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

int main() {
    int n, k;
    cin >> n >> k;
    Node dummy{0, nullptr};
    Node* tail = &dummy;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; tail->next = new Node{x, nullptr}; tail = tail->next; }
    Node *lead = &dummy, *trail = &dummy;
    for (int i = 0; i <= k; ++i) lead = lead->next;          // gap of k+1 nodes
    while (lead) { lead = lead->next; trail = trail->next; }
    Node* gone = trail->next;
    trail->next = gone->next;
    delete gone;
    if (!dummy.next) cout << "EMPTY\n";
    for (Node* p = dummy.next; p; p = p->next) cout << p->value << (p->next ? ' ' : '\n');
    for (Node* p = dummy.next; p;) { Node* nx = p->next; delete p; p = nx; }
}
```

### Explanation
When lead falls off the end, trail is exactly one node before the target. The dummy handles k = n (removing the head).

### Edge Cases
- k = n; n = 1.

### Tests
#### Remove head
```text
3 3
7 8 9
```
```text
8 9
```

## DSA08-M04 · Doubly Linked Deque
**Difficulty:** Medium · **Subtopic:** Doubly linked lists · **Tags:** doubly linked list, deque, pointers · **Source:** Original

### Statement
Implement a doubly linked list with `push_front x`, `push_back x`, `pop_front`, `pop_back` (print `EMPTY` if empty). At the end print the list forwards and backwards (`EMPTY` twice if empty).

### Input
q, then q operations.

### Output
Messages for failed pops, then the forward and backward lists.

### Constraints
- 1 ≤ q ≤ 2·10^5

### Sample Input
```text
5
push_back 1
push_back 2
push_front 0
pop_back
push_back 5
```

### Sample Output
```text
0 1 5
5 1 0
```

### Sample Explanation
2 was popped from the back.

### Target
O(1) per operation.

### Hints
1. A circular sentinel node (prev and next pointing to itself when empty) removes all special cases.
2. Insert between two known nodes: set four pointers.

### Approach
Sentinel-based doubly linked list.

### Solution
```cpp
#include <iostream>
#include <string>
using namespace std;

struct Node { long long value; Node *prev, *next; };

void insertAfter(Node* at, long long x) {
    Node* node = new Node{x, at, at->next};
    at->next->prev = node;
    at->next = node;
}

void unlink(Node* node) {
    node->prev->next = node->next;
    node->next->prev = node->prev;
    delete node;
}

int main() {
    Node sentinel{0, nullptr, nullptr};
    sentinel.prev = sentinel.next = &sentinel;      // empty circular list
    int q;
    cin >> q;
    while (q--) {
        string op;
        cin >> op;
        if (op == "push_front" || op == "push_back") {
            long long x;
            cin >> x;
            insertAfter(op == "push_front" ? &sentinel : sentinel.prev, x);
        } else if (sentinel.next == &sentinel) {
            cout << "EMPTY\n";
        } else {
            unlink(op == "pop_front" ? sentinel.next : sentinel.prev);
        }
    }
    if (sentinel.next == &sentinel) { cout << "EMPTY\nEMPTY\n"; return 0; }
    for (Node* p = sentinel.next; p != &sentinel; p = p->next) cout << p->value << (p->next != &sentinel ? ' ' : '\n');
    for (Node* p = sentinel.prev; p != &sentinel; p = p->prev) cout << p->value << (p->prev != &sentinel ? ' ' : '\n');
    for (Node* p = sentinel.next; p != &sentinel;) { Node* nx = p->next; delete p; p = nx; }
}
```

### Explanation
With a sentinel, the list is never truly empty in pointer terms, so insertion and deletion are the same four pointer updates everywhere.

### Edge Cases
- Popping from an empty list.

### Tests
#### Empty
```text
2
pop_front
pop_back
```
```text
EMPTY
EMPTY
EMPTY
EMPTY
```

## DSA08-M05 · Cycle Detection
**Difficulty:** Medium · **Subtopic:** Floyd's algorithm · **Tags:** linked list, cycle detection, two pointers · **Source:** Original

### Statement
n nodes are stored in a pool; node i's next is given (−1 for null). Starting from node 0, print `YES L` if the list has a cycle of length L, otherwise `NO`.

### Input
n, then n next indices.

### Output
`YES L` or `NO`.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
1 2 3 4 2
```

### Sample Output
```text
YES 3
```

### Sample Explanation
0 → 1 → 2 → 3 → 4 → 2: the cycle is 2, 3, 4.

### Target
O(n) time, O(1) extra space.

### Hints
1. Slow moves one step, fast two; they meet iff there is a cycle.
2. From the meeting point, walk around once to measure the length.

### Approach
Floyd's tortoise and hare, then a loop counting steps back to the meeting node.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> next(n);
    for (auto& x : next) cin >> x;
    auto step = [&](int v) { return v == -1 ? -1 : next[v]; };
    int slow = 0, fast = 0;
    do {
        slow = step(slow);
        fast = step(step(fast));
    } while (fast != -1 && slow != fast);
    if (fast == -1) { cout << "NO\n"; return 0; }
    int length = 1;
    for (int p = next[slow]; p != slow; p = next[p]) ++length;
    cout << "YES " << length << '\n';
}
```

### Explanation
Inside the cycle the gap between fast and slow shrinks by one each step, so they must meet. Indices in a pool behave exactly like pointers.

### Edge Cases
- Self-loop at node 0; immediate null.

### Tests
#### No cycle
```text
3
1 2 -1
```
```text
NO
```

## DSA08-H01 · Reverse in Groups of k
**Difficulty:** Hard · **Subtopic:** Segment reversal · **Tags:** linked list, reversal, pointers · **Source:** Original

### Statement
Reverse the list in consecutive groups of k nodes; a final group shorter than k stays as it is.

### Input
n and k, then n integers.

### Output
The resulting list.

### Constraints
- 1 ≤ k ≤ n ≤ 2·10^5

### Sample Input
```text
8 3
1 2 3 4 5 6 7 8
```

### Sample Output
```text
3 2 1 6 5 4 7 8
```

### Sample Explanation
Groups (1 2 3) and (4 5 6) are reversed; (7 8) is shorter than 3.

### Target
O(n) time, O(1) extra space.

### Hints
1. Before reversing a group, check that k nodes exist.
2. Keep a pointer to the node before the group to reconnect it.

### Approach
Iterate groups; reverse k nodes with the three-pointer method and reattach.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

int main() {
    int n, k;
    cin >> n >> k;
    Node dummy{0, nullptr};
    Node* tail = &dummy;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; tail->next = new Node{x, nullptr}; tail = tail->next; }
    Node* before = &dummy;
    for (;;) {
        Node* check = before;
        int count = 0;
        while (count < k && check->next) { check = check->next; ++count; }
        if (count < k) break;                         // short final group
        Node* first = before->next;
        Node *prev = check->next, *cur = first;       // reversed group will point to the rest
        for (int i = 0; i < k; ++i) { Node* nx = cur->next; cur->next = prev; prev = cur; cur = nx; }
        before->next = prev;                          // new group head
        before = first;                               // old first is now the group's last
    }
    for (Node* p = dummy.next; p; p = p->next) cout << p->value << (p->next ? ' ' : '\n');
    for (Node* p = dummy.next; p;) { Node* nx = p->next; delete p; p = nx; }
}
```

### Explanation
Starting `prev` at the node after the group makes the reversed group's tail connect to the rest automatically. Each node is visited a constant number of times.

### Edge Cases
- k = 1 (unchanged); k = n (whole list reversed).

### Tests
#### Whole list
```text
3 3
1 2 3
```
```text
3 2 1
```

## DSA08-H02 · Circular List Elimination
**Difficulty:** Hard · **Subtopic:** Circular linked lists · **Tags:** circular list, simulation, josephus · **Source:** Original

### Statement
People 1..n sit in a circle built as a circular linked list. Starting at person 1, count k people; the k-th leaves. Print the order in which people leave.

### Input
n and k.

### Output
The elimination order.

### Constraints
- 1 ≤ n ≤ 5000, 1 ≤ k ≤ 10^9

### Sample Input
```text
7 3
```

### Sample Output
```text
3 6 2 7 5 1 4
```

### Sample Explanation
Classic Josephus order for n = 7, k = 3.

### Target
O(n²) worst case using (k − 1) mod size steps.

### Hints
1. Keep a pointer to the node *before* the current one, so deletion is O(1).
2. Skipping k − 1 nodes is the same as skipping (k − 1) mod size.

### Approach
Circular singly linked list; walk, unlink, print.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { int id; Node* next; };

int main() {
    long long n, k;
    cin >> n >> k;
    Node* head = new Node{1, nullptr};
    Node* last = head;
    for (int i = 2; i <= n; ++i) { last->next = new Node{i, nullptr}; last = last->next; }
    last->next = head;                                  // close the circle
    Node* before = last;                                // node before person 1
    for (long long size = n; size > 0; --size) {
        for (long long s = (k - 1) % size; s > 0; --s) before = before->next;
        Node* gone = before->next;
        cout << gone->id << (size > 1 ? ' ' : '\n');
        before->next = gone->next;
        delete gone;
    }
}
```

### Explanation
A circular list models the circle directly; holding the predecessor makes removal O(1). Reducing k modulo the size avoids walking around the circle billions of times.

### Edge Cases
- n = 1; k = 1 (order 1..n).

### Tests
#### k equals one
```text
4 1
```
```text
1 2 3 4
```

## DSA08-H03 · Palindrome List in O(1) Space
**Difficulty:** Hard · **Subtopic:** Reversing half a list · **Tags:** linked list, palindrome, two pointers · **Source:** Original

### Statement
Decide whether the list's values read the same forwards and backwards using O(1) extra memory.

### Input
n, then n integers.

### Output
`YES` or `NO`.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
1 2 3 2 1
```

### Sample Output
```text
YES
```

### Sample Explanation
Symmetric values.

### Target
O(n) time, O(1) extra space.

### Hints
1. Find the middle with slow/fast pointers.
2. Reverse the second half and compare it with the first half.

### Approach
Middle, reverse, compare (then restore if needed).

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

Node* reverse(Node* head) {
    Node* prev = nullptr;
    while (head) { Node* nx = head->next; head->next = prev; prev = head; head = nx; }
    return prev;
}

int main() {
    int n;
    cin >> n;
    Node* head = nullptr;
    Node** link = &head;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; *link = new Node{x, nullptr}; link = &(*link)->next; }
    Node *slow = head, *fast = head;
    while (fast->next && fast->next->next) { slow = slow->next; fast = fast->next->next; }
    Node* second = reverse(slow->next);              // second half, reversed
    bool same = true;
    for (Node *a = head, *b = second; b; a = a->next, b = b->next)
        if (a->value != b->value) { same = false; break; }
    slow->next = reverse(second);                    // restore the list
    cout << (same ? "YES" : "NO") << '\n';
    while (head) { Node* nx = head->next; delete head; head = nx; }
}
```

### Explanation
Reversing the second half gives backwards access without a stack; restoring it keeps the list unchanged for the caller.

### Edge Cases
- n = 1; even lengths.

### Tests
#### Not a palindrome
```text
2
1 2
```
```text
NO
```

## DSA08-H04 · Add Two Big Numbers as Lists
**Difficulty:** Hard · **Subtopic:** Lists as digit sequences · **Tags:** linked list, big integers, carry · **Source:** Original

### Statement
Two non-negative numbers of up to 10^5 digits are stored as linked lists of digits, least significant first. Add them by walking both lists and print the sum.

### Input
Two digit strings (most significant first, no leading zeros unless the number is 0).

### Output
The sum.

### Constraints
- 1 ≤ length ≤ 10^5

### Sample Input
```text
999
1
```

### Sample Output
```text
1000
```

### Sample Explanation
The carry ripples through every digit.

### Target
O(n + m).

### Hints
1. Build each list by pushing digits at the head while reading left to right: that reverses them.
2. Add digit by digit with a carry; continue while either list or the carry remains.

### Approach
Digit lists, carry loop, then print the result list reversed.

### Solution
```cpp
#include <iostream>
#include <string>
using namespace std;

struct Node { int digit; Node* next; };

Node* build(const string& s) {                 // least significant digit first
    Node* head = nullptr;
    for (char c : s) head = new Node{c - '0', head};
    return head;
}

void freeList(Node* p) { while (p) { Node* nx = p->next; delete p; p = nx; } }

int main() {
    string x, y;
    cin >> x >> y;
    Node *a = build(x), *b = build(y);
    Node* result = nullptr;                    // built most significant first by head insertion
    int carry = 0;
    for (Node *p = a, *q = b; p || q || carry;) {
        int s = carry + (p ? p->digit : 0) + (q ? q->digit : 0);
        result = new Node{s % 10, result};
        carry = s / 10;
        if (p) p = p->next;
        if (q) q = q->next;
    }
    while (result->next && result->digit == 0) { Node* z = result; result = result->next; delete z; }
    for (Node* p = result; p; p = p->next) cout << p->digit;
    cout << '\n';
    freeList(a); freeList(b); freeList(result);
}
```

### Explanation
Least-significant-first order matches how addition proceeds; inserting result digits at the head yields most-significant-first output.

### Edge Cases
- Different lengths; final carry; 0 + 0.

### Tests
#### Zeros
```text
0
0
```
```text
0
```

## DSA08-H05 · Merge Sort a Linked List
**Difficulty:** Hard · **Subtopic:** Sorting lists · **Tags:** linked list, merge sort, divide and conquer · **Source:** Original

### Statement
Sort a linked list in O(n log n) by merge sort on the nodes (no copying into an array).

### Input
n, then n integers.

### Output
The sorted list.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
4 1 3 9 7
```

### Sample Output
```text
1 3 4 7 9
```

### Sample Explanation
Ascending order.

### Target
O(n log n) time, O(log n) stack.

### Hints
1. Split at the middle with slow/fast pointers.
2. Merging lists needs no extra buffer, unlike arrays.

### Approach
Recursive split, sort halves, merge by relinking.

### Solution
```cpp
#include <iostream>
using namespace std;

struct Node { long long value; Node* next; };

Node* merge(Node* a, Node* b) {
    Node dummy{0, nullptr};
    Node* tail = &dummy;
    while (a && b) {
        if (b->value < a->value) { tail->next = b; b = b->next; }
        else { tail->next = a; a = a->next; }
        tail = tail->next;
    }
    tail->next = a ? a : b;
    return dummy.next;
}

Node* sortList(Node* head) {
    if (!head || !head->next) return head;
    Node *slow = head, *fast = head->next;
    while (fast && fast->next) { slow = slow->next; fast = fast->next->next; }
    Node* second = slow->next;
    slow->next = nullptr;                       // split into two lists
    return merge(sortList(head), sortList(second));
}

int main() {
    int n;
    cin >> n;
    Node* head = nullptr;
    Node** link = &head;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; *link = new Node{x, nullptr}; link = &(*link)->next; }
    head = sortList(head);
    for (Node* p = head; p; p = p->next) cout << p->value << (p->next ? ' ' : '\n');
    while (head) { Node* nx = head->next; delete head; head = nx; }
}
```

### Explanation
T(n) = 2T(n/2) + O(n) = O(n log n); merge sort is the natural choice for lists because merging only relinks and needs no random access.

### Edge Cases
- n = 1; duplicates (stable).

### Tests
#### Reverse sorted
```text
4
4 3 2 1
```
```text
1 2 3 4
```
