## DSA09-E01 · Balanced Brackets
**Difficulty:** Easy · **Subtopic:** Bracket matching · **Tags:** stack, brackets, validation · **Source:** Original

### Statement
For each string of the characters ()[]{}, print `YES` if it is balanced, else `NO`.

### Input
T, then T strings.

### Output
`YES` or `NO` for each.

### Constraints
- 1 ≤ T ≤ 100, 1 ≤ length ≤ 10^5

### Sample Input
```text
3
{[()]}
([)]
((
```

### Sample Output
```text
YES
NO
NO
```

### Sample Explanation
In ([)] the ] meets an open (.

### Target
O(length).

### Hints
1. Push openers; a closer must match the top.
2. The stack must be empty at the end.

### Approach
Stack of expected closers.

### Solution
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        string s;
        cin >> s;
        vector<char> st;
        bool ok = true;
        for (char c : s) {
            if (c == '(') st.push_back(')');
            else if (c == '[') st.push_back(']');
            else if (c == '{') st.push_back('}');
            else if (st.empty() || st.back() != c) { ok = false; break; }
            else st.pop_back();
        }
        cout << (ok && st.empty() ? "YES" : "NO") << '\n';
    }
}
```

### Explanation
The most recently opened bracket must close first: exactly LIFO.

### Edge Cases
- A closer on an empty stack; leftover openers.

### Tests
#### Starts with closer
```text
1
)(
```
```text
NO
```

## DSA09-E02 · Reverse with a Stack
**Difficulty:** Easy · **Subtopic:** LIFO order · **Tags:** stack, strings, reversal · **Source:** Original

### Statement
Reverse a word by pushing its characters and popping them.

### Input
One word.

### Output
The reversed word.

### Constraints
- 1 ≤ length ≤ 2·10^5

### Sample Input
```text
hello
```

### Sample Output
```text
olleh
```

### Sample Explanation
The last letter pushed is the first popped.

### Target
O(n).

### Hints
1. Push every character.
2. Pop until empty.

### Approach
`std::stack<char>`.

### Solution
```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
    string s, out;
    cin >> s;
    stack<char> st;
    for (char c : s) st.push(c);
    while (!st.empty()) { out += st.top(); st.pop(); }
    cout << out << '\n';
}
```

### Explanation
Popping returns elements in reverse order of pushing.

### Edge Cases
- One character.

### Tests
#### Single
```text
a
```
```text
a
```

## DSA09-E03 · Evaluate Postfix
**Difficulty:** Easy · **Subtopic:** Postfix evaluation · **Tags:** stack, expressions, postfix · **Source:** Original

### Statement
Evaluate a postfix expression of integers and the operators + − * / (integer division truncating toward zero). The expression is valid and never divides by zero.

### Input
One line of space-separated tokens.

### Output
The value.

### Constraints
- up to 10^5 tokens; intermediate values fit in `long long`

### Sample Input
```text
5 1 2 + 4 * + 3 -
```

### Sample Output
```text
14
```

### Sample Explanation
5 + (1 + 2)·4 − 3 = 14.

### Target
O(tokens).

### Hints
1. Numbers are pushed.
2. An operator pops b (top) and then a; push a op b.

### Approach
One operand stack.

### Solution
```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string line, tok;
    getline(cin, line);
    istringstream in(line);
    vector<long long> st;
    while (in >> tok) {
        if (tok.size() == 1 && string("+-*/").find(tok[0]) != string::npos) {
            long long b = st.back(); st.pop_back();
            long long a = st.back(); st.pop_back();
            st.push_back(tok[0] == '+' ? a + b : tok[0] == '-' ? a - b : tok[0] == '*' ? a * b : a / b);
        } else {
            st.push_back(stoll(tok));
        }
    }
    cout << st.back() << '\n';
}
```

### Explanation
Postfix needs no parentheses or precedence: each operator applies to the two most recent values.

### Edge Cases
- Negative numbers as tokens (e.g. -3) are operands.

### Tests
#### Simple
```text
2 3 + 4 *
```
```text
20
```

## DSA09-E05 · Linked Stack
**Difficulty:** Easy · **Subtopic:** Linked-list implementation · **Tags:** stack, linked list, underflow · **Source:** Original

### Statement
Implement a stack with linked nodes: `push x`, `pop` (print the value or `UNDERFLOW`), `top` (print or `UNDERFLOW`), `size`.

### Input
q, then q operations.

### Output
One line per pop, top and size.

### Constraints
- 1 ≤ q ≤ 2·10^5

### Sample Input
```text
6
push 4
push 9
top
pop
pop
pop
```

### Sample Output
```text
9
9
4
UNDERFLOW
```

### Sample Explanation
The third pop finds the stack empty.

### Target
O(1) per operation.

### Hints
1. The head of the list is the top.
2. Free the node on pop.

### Approach
Singly linked list with a size counter.

### Solution
```cpp
#include <iostream>
#include <string>
using namespace std;

struct Node { long long value; Node* below; };

int main() {
    int q;
    cin >> q;
    Node* top = nullptr;
    long long size = 0;
    while (q--) {
        string op;
        cin >> op;
        if (op == "push") { long long x; cin >> x; top = new Node{x, top}; ++size; }
        else if (op == "size") cout << size << '\n';
        else if (!top) cout << "UNDERFLOW\n";
        else {
            cout << top->value << '\n';
            if (op == "pop") { Node* old = top; top = top->below; delete old; --size; }
        }
    }
    while (top) { Node* old = top; top = top->below; delete old; }
}
```

### Explanation
A linked stack never overflows (until memory runs out); each operation touches only the head.

### Edge Cases
- Pop on empty.

### Tests
#### Size
```text
3
push 1
push 2
size
```
```text
2
```

## DSA09-M01 · Infix to Postfix
**Difficulty:** Medium · **Subtopic:** Shunting-yard conversion · **Tags:** stack, expressions, precedence · **Source:** Original

### Statement
Convert an infix expression with single-letter operands, operators + − * / ^ and parentheses into postfix. ^ is right-associative; the others are left-associative.

### Input
One expression without spaces.

### Output
The postfix expression without spaces.

### Constraints
- 1 ≤ length ≤ 10^5, valid expression

### Sample Input
```text
(a+b)*c-d/e
```

### Sample Output
```text
ab+c*de/-
```

### Sample Explanation
Parentheses force a+b first; * and / bind tighter than −.

### Target
O(n).

### Hints
1. Operands go straight to the output.
2. Before pushing an operator, pop operators of higher precedence (or equal, if left-associative).
3. ')' pops until '('.

### Approach
Dijkstra's shunting-yard algorithm.

### Solution
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int prec(char op) { return op == '^' ? 3 : (op == '*' || op == '/') ? 2 : (op == '+' || op == '-') ? 1 : 0; }

int main() {
    string s, out;
    cin >> s;
    vector<char> ops;
    for (char c : s) {
        if (isalpha(static_cast<unsigned char>(c))) out += c;
        else if (c == '(') ops.push_back(c);
        else if (c == ')') {
            while (ops.back() != '(') { out += ops.back(); ops.pop_back(); }
            ops.pop_back();
        } else {
            while (!ops.empty() && ops.back() != '(' &&
                   (prec(ops.back()) > prec(c) || (prec(ops.back()) == prec(c) && c != '^'))) {
                out += ops.back();
                ops.pop_back();
            }
            ops.push_back(c);
        }
    }
    while (!ops.empty()) { out += ops.back(); ops.pop_back(); }
    cout << out << '\n';
}
```

### Explanation
The stack holds operators waiting for their right operand. Equal precedence pops first for left-associative operators (a−b−c = (a−b)−c) but not for ^ (a^b^c = a^(b^c)).

### Edge Cases
- Right associativity; nested parentheses.

### Tests
#### Power chain
```text
a^b^c
```
```text
abc^^
```

#### Minus chain
```text
a-b-c
```
```text
ab-c-
```

## DSA09-M02 · Evaluate an Infix Expression
**Difficulty:** Medium · **Subtopic:** Two-stack evaluation · **Tags:** stack, expressions, parsing · **Source:** Original

### Statement
Evaluate an infix expression of non-negative integers, + − * / (truncating division) and parentheses. Spaces may appear.

### Input
One line.

### Output
The value.

### Constraints
- length ≤ 10^5; values fit in `long long`; no division by zero; no unary minus

### Sample Input
```text
2 * (3 + 4) - 5
```

### Sample Output
```text
9
```

### Sample Explanation
2·7 − 5.

### Target
O(n).

### Hints
1. Keep a value stack and an operator stack.
2. Apply operators from the stack while they have precedence ≥ the new one.

### Approach
Shunting-yard evaluating immediately instead of producing output.

### Solution
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

vector<long long> vals;
vector<char> ops;

int prec(char op) { return (op == '*' || op == '/') ? 2 : (op == '+' || op == '-') ? 1 : 0; }

void apply() {
    long long b = vals.back(); vals.pop_back();
    long long a = vals.back(); vals.pop_back();
    char op = ops.back(); ops.pop_back();
    vals.push_back(op == '+' ? a + b : op == '-' ? a - b : op == '*' ? a * b : a / b);
}

int main() {
    string s;
    getline(cin, s);
    for (size_t i = 0; i < s.size(); ++i) {
        char c = s[i];
        if (c == ' ') continue;
        if (isdigit(static_cast<unsigned char>(c))) {
            long long v = 0;
            while (i < s.size() && isdigit(static_cast<unsigned char>(s[i]))) v = v * 10 + (s[i++] - '0');
            --i;
            vals.push_back(v);
        } else if (c == '(') ops.push_back(c);
        else if (c == ')') { while (ops.back() != '(') apply(); ops.pop_back(); }
        else {
            while (!ops.empty() && ops.back() != '(' && prec(ops.back()) >= prec(c)) apply();
            ops.push_back(c);
        }
    }
    while (!ops.empty()) apply();
    cout << vals.back() << '\n';
}
```

### Explanation
Every operator is pushed and applied once, so the evaluation is linear.

### Edge Cases
- Multi-digit numbers; division truncation.

### Tests
#### Division
```text
10/3+1
```
```text
4
```

## DSA09-M03 · Next Greater Element
**Difficulty:** Medium · **Subtopic:** Monotonic stack (extension) · **Tags:** monotonic stack, arrays · **Source:** Original

### Statement
For each element print the first larger element to its right, or −1.

### Input
n, then n integers.

### Output
n answers.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
4
4 5 2 25
```

### Sample Output
```text
5 25 25 -1
```

### Sample Explanation
2's next greater is 25.

### Target
O(n).

### Hints
1. Keep indices whose answer is unknown on a stack; their values are decreasing.
2. A new value answers every smaller value on top.

### Approach
Monotonic decreasing stack of indices.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n), ans(n, -1);
    for (auto& x : a) cin >> x;
    vector<int> st;                              // indices with decreasing values
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && a[st.back()] < a[i]) { ans[st.back()] = a[i]; st.pop_back(); }
        st.push_back(i);
    }
    for (int i = 0; i < n; ++i) cout << ans[i] << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Each index is pushed and popped once: O(n) instead of the O(n²) scan.

### Edge Cases
- Equal values are not greater.

### Tests
#### Decreasing
```text
3
3 2 1
```
```text
-1 -1 -1
```

## DSA09-M04 · Minimum Insertions to Balance
**Difficulty:** Medium · **Subtopic:** Counter as a stack · **Tags:** stack, brackets, greedy · **Source:** Original

### Statement
A string of ( and ) may be unbalanced. Print the minimum number of parentheses to insert to make it balanced.

### Input
One string.

### Output
The minimum number of insertions.

### Constraints
- 1 ≤ length ≤ 2·10^5

### Sample Input
```text
()))((
```

### Sample Output
```text
4
```

### Sample Explanation
Two unmatched ) need two (, and two unmatched ( need two ).

### Target
O(n), O(1) space.

### Hints
1. For a single bracket type, the stack only needs its size: a counter.
2. A ) with an empty stack needs an inserted (.

### Approach
Counter of open brackets plus a count of needed openers.

### Solution
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    long long open = 0, inserted = 0;
    for (char c : s) {
        if (c == '(') ++open;
        else if (open > 0) --open;
        else ++inserted;                 // unmatched ')': insert '(' before it
    }
    cout << inserted + open << '\n';     // remaining '(' need ')'
}
```

### Explanation
When the stack would hold identical items, a counter represents it fully. Each unmatched bracket needs exactly one insertion.

### Edge Cases
- Already balanced: 0.

### Tests
#### Only openers
```text
(((
```
```text
3
```

## DSA09-H01 · Largest Rectangle in a Histogram
**Difficulty:** Hard · **Subtopic:** Monotonic stack (extension) · **Tags:** monotonic stack, arrays, optimisation · **Source:** Original

### Statement
Bars of width 1 have the given heights. Print the largest rectangle area within the histogram.

### Input
n, then n heights.

### Output
The maximum area.

### Constraints
- 1 ≤ n ≤ 2·10^5, 0 ≤ h ≤ 10^9

### Sample Input
```text
6
2 1 5 6 2 3
```

### Sample Output
```text
10
```

### Sample Explanation
Heights 5 and 6 give 2 × 5.

### Target
O(n).

### Hints
1. For each bar, the widest rectangle of its height ends at the first smaller bar on each side.
2. A stack of increasing heights finds both boundaries when a bar is popped.

### Approach
Increasing stack; a sentinel height 0 at the end flushes it.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> h(n);
    for (auto& x : h) cin >> x;
    h.push_back(0);                                   // flushes the stack
    vector<int> st;
    long long best = 0;
    for (int i = 0; i <= n; ++i) {
        while (!st.empty() && h[st.back()] >= h[i]) {
            long long height = h[st.back()];
            st.pop_back();
            long long left = st.empty() ? -1 : st.back();   // first smaller bar on the left
            best = max(best, height * (i - left - 1));
        }
        st.push_back(i);
    }
    cout << best << '\n';
}
```

### Explanation
When a bar is popped, i is the first smaller bar to its right and the new top is the first smaller bar to its left. Each index is pushed and popped once. Areas reach 2·10^14.

### Edge Cases
- All equal; zero heights.

### Tests
#### Equal bars
```text
3
4 4 4
```
```text
12
```

## DSA09-H02 · Simplify a Path
**Difficulty:** Hard · **Subtopic:** Stack of components · **Tags:** stack, strings, parsing · **Source:** Original

### Statement
Simplify an absolute Unix path: `.` means the current directory, `..` the parent (staying at root if already there), and repeated slashes count as one. Print the canonical path.

### Input
One path starting with `/`.

### Output
The simplified path.

### Constraints
- 1 ≤ length ≤ 10^5

### Sample Input
```text
/a/./b/../../c/
```

### Sample Output
```text
/c
```

### Sample Explanation
a, b, back to a, back to root, then c.

### Target
O(length).

### Hints
1. Split on '/'.
2. Push names, pop on "..", ignore "." and empty parts.

### Approach
Vector as a stack of directory names.

### Solution
```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string path, part;
    cin >> path;
    istringstream in(path);
    vector<string> st;
    while (getline(in, part, '/')) {
        if (part.empty() || part == ".") continue;
        if (part == "..") { if (!st.empty()) st.pop_back(); }
        else st.push_back(part);
    }
    string out;
    for (const string& d : st) out += "/" + d;
    cout << (out.empty() ? "/" : out) << '\n';
}
```

### Explanation
Going into a directory pushes; ".." undoes the most recent push: LIFO.

### Edge Cases
- ".." at root; double slashes.

### Tests
#### Above root
```text
/../
```
```text
/
```

#### Double slashes
```text
/home//foo/
```
```text
/home/foo
```

## DSA09-H03 · Stock Span
**Difficulty:** Hard · **Subtopic:** Monotonic stack (extension) · **Tags:** monotonic stack, arrays · **Source:** Original

### Statement
The span of day i is the number of consecutive days ending at i (including i) whose price is ≤ price[i]. Print every span.

### Input
n, then n prices.

### Output
n spans.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
7
100 80 60 70 60 75 85
```

### Sample Output
```text
1 1 1 2 1 4 6
```

### Sample Explanation
Day 6 (75) covers 60, 70, 60, 75.

### Target
O(n).

### Hints
1. The span ends at the previous strictly greater price.
2. Pop all prices ≤ today; the top is then the previous greater.

### Approach
Stack of indices with decreasing prices.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> p(n);
    for (auto& x : p) cin >> x;
    vector<int> st;
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && p[st.back()] <= p[i]) st.pop_back();
        int span = st.empty() ? i + 1 : i - st.back();
        cout << span << (i + 1 < n ? ' ' : '\n');
        st.push_back(i);
    }
}
```

### Explanation
Popped days can never be the previous greater for later days, so discarding them is safe: amortised O(1).

### Edge Cases
- Increasing prices: spans 1, 2, 3, …

### Tests
#### Increasing
```text
3
1 2 3
```
```text
1 2 3
```

## DSA09-H04 · Longest Valid Parentheses
**Difficulty:** Hard · **Subtopic:** Index stack · **Tags:** stack, brackets, strings · **Source:** Original

### Statement
Print the length of the longest substring of balanced parentheses.

### Input
One string of ( and ).

### Output
The length.

### Constraints
- 1 ≤ length ≤ 2·10^5

### Sample Input
```text
)()())
```

### Sample Output
```text
4
```

### Sample Explanation
"()()" in the middle.

### Target
O(n).

### Hints
1. Push indices of '('; keep a base index of the last unmatched ')'.
2. After a match, the valid length is i − (index on top, or base).

### Approach
Stack seeded with −1 as the base.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string s;
    cin >> s;
    vector<int> st = {-1};                     // bottom: last unmatched position
    int best = 0;
    for (int i = 0; i < static_cast<int>(s.size()); ++i) {
        if (s[i] == '(') st.push_back(i);
        else {
            st.pop_back();
            if (st.empty()) st.push_back(i);   // new base
            else best = max(best, i - st.back());
        }
    }
    cout << best << '\n';
}
```

### Explanation
The stack top is always the index just before the current valid stretch, so i − top is its length.

### Edge Cases
- No valid pair: 0.

### Tests
#### Unclosed
```text
(()
```
```text
2
```

## DSA09-H05 · Decode Nested Repeats
**Difficulty:** Hard · **Subtopic:** Stack replacing recursion · **Tags:** stack, strings, recursion · **Source:** Original

### Statement
Decode a string where k[s] means s repeated k times; brackets may nest.

### Input
One encoded string.

### Output
The decoded string.

### Constraints
- decoded length ≤ 10^6, 1 ≤ k ≤ 300

### Sample Input
```text
3[a2[c]]
```

### Sample Output
```text
accaccacc
```

### Sample Explanation
2[c] = cc, a + cc = acc, repeated 3 times.

### Target
O(decoded length).

### Hints
1. On '[', push the current string and the repeat count; start a new string.
2. On ']', pop and append the current string count times.

### Approach
Explicit stack of (prefix, count) pairs instead of recursion.

### Solution
```cpp
#include <iostream>
#include <string>
#include <utility>
#include <vector>
using namespace std;

int main() {
    string s, cur;
    cin >> s;
    vector<pair<string, int>> st;
    int k = 0;
    for (char c : s) {
        if (isdigit(static_cast<unsigned char>(c))) k = k * 10 + (c - '0');
        else if (c == '[') { st.push_back({cur, k}); cur.clear(); k = 0; }
        else if (c == ']') {
            auto [prefix, times] = st.back();
            st.pop_back();
            string repeated;
            for (int i = 0; i < times; ++i) repeated += cur;
            cur = prefix + repeated;
        } else cur += c;
    }
    cout << cur << '\n';
}
```

### Explanation
The stack plays the role of the call stack in a recursive decoder: each '[' is a call, each ']' a return.

### Edge Cases
- Text outside brackets; multi-digit counts.
