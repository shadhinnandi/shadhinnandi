# Linear-Time Sorting: Practice Problems

Counting, radix and bucket sort, plus linear-time tricks that exploit small key ranges. Each works only because of an assumption about the keys; the statements say which.

## DSA16D-E01 · Counting Sort
**Difficulty:** Easy · **Subtopic:** Counting sort · **Tags:** counting sort, linear time · **Source:** Original

### Statement
Sort n integers in the range [0, k].

### Input
n and k, then n integers.

### Output
The sorted array.

### Constraints
- 1 ≤ n ≤ 10^6, 0 ≤ k ≤ 10^6

### Sample Input
```text
7 4
4 1 3 4 3 0 2
```

### Sample Output
```text
0 1 2 3 3 4 4
```

### Sample Explanation
Counts per value, then output in value order.

### Target
O(n + k).

### Hints
1. count[v] = occurrences of v.
2. Print each v count[v] times.

### Approach
Counting sort (plain version, since keys are the values themselves).

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    vector<int> count(k + 1, 0);
    for (int i = 0; i < n; ++i) { int x; cin >> x; ++count[x]; }
    int printed = 0;
    for (int v = 0; v <= k; ++v)
        for (int c = 0; c < count[v]; ++c) cout << v << (++printed < n ? ' ' : '\n');
}
```

### Explanation
No comparisons are made, so the Ω(n log n) bound does not apply; the cost is the key range k.

### Edge Cases
- k = 0.

### Tests
#### Zeros
```text
3 0
0 0 0
```
```text
0 0 0
```

## DSA16D-E02 · Stable Counting Sort of Records
**Difficulty:** Easy · **Subtopic:** Stability with prefix sums · **Tags:** counting sort, stability, prefix sums · **Source:** Original

### Statement
Records (mark 0–100, name) must be sorted by mark ascending; equal marks keep input order. Use stable counting sort and print the names.

### Input
n, then n lines mark name.

### Output
Names in order.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
4
70 ana
50 bo
70 cy
50 di
```

### Sample Output
```text
bo di ana cy
```

### Sample Explanation
bo before di, ana before cy: stable.

### Target
O(n + 101).

### Hints
1. Prefix sums of counts give each key's end position.
2. Fill from right to left to keep equal keys in order.

### Approach
Classic stable counting sort.

### Solution
```cpp
#include <iostream>
#include <string>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<pair<int, string>> a(n), out(n);
    vector<int> count(102, 0);
    for (auto& [m, s] : a) { cin >> m >> s; ++count[m]; }
    for (int v = 1; v <= 101; ++v) count[v] += count[v - 1];   // count[v] = number of keys <= v
    for (int i = n - 1; i >= 0; --i) out[--count[a[i].first]] = a[i];
    for (int i = 0; i < n; ++i) cout << out[i].second << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Scanning backwards places the last record with a key at that key's last slot, so equal keys keep their order: the property radix sort relies on.

### Edge Cases
- All marks equal: input order.

### Tests
#### All equal
```text
2
5 x
5 y
```
```text
x y
```

## DSA16D-E04 · LSD Radix Sort
**Difficulty:** Easy · **Subtopic:** Radix sort · **Tags:** radix sort, counting sort, digits · **Source:** Original

### Statement
Sort non-negative integers with LSD radix sort in base 10 (a stable counting pass per digit).

### Input
n, then n integers.

### Output
The sorted array.

### Constraints
- 1 ≤ n ≤ 2·10^5, 0 ≤ values ≤ 10^9

### Sample Input
```text
6
170 45 75 90 802 24
```

### Sample Output
```text
24 45 75 90 170 802
```

### Sample Explanation
Passes on the ones, tens, hundreds digits.

### Target
O(d·(n + 10)).

### Hints
1. Sort by the least significant digit first.
2. Each pass must be stable.

### Approach
Counting sort per digit until the largest number's digits run out.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n), out(n);
    for (auto& x : a) cin >> x;
    long long maxV = *max_element(a.begin(), a.end());
    for (long long exp = 1; maxV / exp > 0; exp *= 10) {
        int count[10] = {};
        for (long long x : a) ++count[(x / exp) % 10];
        for (int d = 1; d < 10; ++d) count[d] += count[d - 1];
        for (int i = n - 1; i >= 0; --i) out[--count[(a[i] / exp) % 10]] = a[i];   // stable
        a.swap(out);
    }
    for (int i = 0; i < n; ++i) cout << a[i] << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
After pass i, numbers are sorted by their last i digits; stability preserves that order when later digits tie.

### Edge Cases
- All zeros (no passes).

### Tests
#### Zeros
```text
2
0 0
```
```text
0 0
```

## DSA16D-E05 · Bucket Sort
**Difficulty:** Easy · **Subtopic:** Bucket sort · **Tags:** bucket sort, floating point, distribution · **Source:** Original

### Statement
Sort n real numbers in [0, 1), roughly uniformly distributed, with bucket sort (n buckets; insertion sort inside each). Print them with three decimals.

### Input
n, then n values.

### Output
The sorted values.

### Constraints
- 1 ≤ n ≤ 10^5, 0 ≤ x < 1

### Sample Input
```text
5
0.420 0.320 0.230 0.520 0.250
```

### Sample Output
```text
0.230 0.250 0.320 0.420 0.520
```

### Sample Explanation
Bucket ⌊n·x⌋ receives x.

### Target
O(n) expected.

### Hints
1. Uniform input puts about one element in each bucket.
2. Concatenate buckets in order.

### Approach
Buckets as vectors, insertion sort each.

### Solution
```cpp
#include <iomanip>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<double>> bucket(n);
    for (int i = 0; i < n; ++i) {
        double x;
        cin >> x;
        bucket[static_cast<int>(x * n)].push_back(x);
    }
    vector<double> out;
    for (auto& b : bucket) {
        for (size_t i = 1; i < b.size(); ++i)                 // insertion sort (stable)
            for (size_t j = i; j > 0 && b[j] < b[j - 1]; --j) { double t = b[j]; b[j] = b[j - 1]; b[j - 1] = t; }
        out.insert(out.end(), b.begin(), b.end());
    }
    cout << fixed << setprecision(3);
    for (int i = 0; i < n; ++i) cout << out[i] << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Expected O(n) relies on the uniform distribution; if all values fall in one bucket, it degrades to insertion sort, Θ(n²).

### Edge Cases
- All values in one bucket.

### Tests
#### One bucket
```text
3
0.900 0.910 0.905
```
```text
0.900 0.905 0.910
```

## DSA16D-M01 · Radix Sort with Negatives
**Difficulty:** Medium · **Subtopic:** Key transformation · **Tags:** radix sort, negative numbers · **Source:** Original

### Statement
Sort integers in [−10^9, 10^9] with radix sort by first shifting every key by +10^9.

### Input
n, then n integers.

### Output
The sorted array.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
-5 3 0 -12 7
```

### Sample Output
```text
-12 -5 0 3 7
```

### Sample Explanation
Shifted keys are non-negative and keep the order.

### Target
O(d·(n + b)).

### Hints
1. Adding a constant preserves order.
2. Use base 2^16 for fewer passes (keys < 2^31).

### Approach
Two passes of 16 bits on shifted keys.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<unsigned long long> a(n), out(n);
    const long long SHIFT = 1000000000;
    for (auto& x : a) { long long v; cin >> v; x = static_cast<unsigned long long>(v + SHIFT); }
    for (int shift = 0; shift < 32; shift += 16) {
        vector<int> count(65537, 0);
        for (auto x : a) ++count[((x >> shift) & 0xFFFF) + 1];
        for (int d = 1; d <= 65536; ++d) count[d] += count[d - 1];      // count[d] = start of digit d
        for (auto x : a) out[count[(x >> shift) & 0xFFFF]++] = x;      // forward fill is stable too
        a.swap(out);
    }
    for (int i = 0; i < n; ++i) cout << static_cast<long long>(a[i]) - SHIFT << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Shifting maps [−10^9, 10^9] to [0, 2·10^9] < 2^31, so two 16-bit passes suffice. Storing start positions and filling forwards is also stable.

### Edge Cases
- All negative.

### Tests
#### Negatives
```text
3
-1 -3 -2
```
```text
-3 -2 -1
```

## DSA16D-M03 · Maximum Gap
**Difficulty:** Medium · **Subtopic:** Pigeonhole buckets · **Tags:** bucket sort, pigeonhole, linear time · **Source:** Original

### Statement
Print the largest difference between consecutive elements in sorted order, in linear time.

### Input
n, then n integers.

### Output
The maximum gap (0 if n < 2).

### Constraints
- 1 ≤ n ≤ 2·10^5, 0 ≤ values ≤ 10^9

### Sample Input
```text
4
3 6 9 1
```

### Sample Output
```text
3
```

### Sample Explanation
Sorted 1 3 6 9.

### Target
O(n).

### Hints
1. With n − 1 buckets of width ⌈(max − min)/(n − 1)⌉, the maximum gap is at least the bucket width.
2. So only gaps between buckets matter: keep each bucket's min and max.

### Approach
Pigeonhole buckets storing min/max.

### Solution
```cpp
#include <algorithm>
#include <climits>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    if (n < 2) { cout << 0 << '\n'; return 0; }
    long long lo = *min_element(a.begin(), a.end()), hi = *max_element(a.begin(), a.end());
    if (lo == hi) { cout << 0 << '\n'; return 0; }
    long long width = max(1LL, (hi - lo + n - 2) / (n - 1));
    int buckets = static_cast<int>((hi - lo) / width) + 1;
    vector<long long> bMin(buckets, LLONG_MAX), bMax(buckets, LLONG_MIN);
    for (long long x : a) {
        int b = static_cast<int>((x - lo) / width);
        bMin[b] = min(bMin[b], x);
        bMax[b] = max(bMax[b], x);
    }
    long long best = 0, prevMax = lo;
    for (int b = 0; b < buckets; ++b) {
        if (bMin[b] == LLONG_MAX) continue;                // empty bucket
        best = max(best, bMin[b] - prevMax);
        prevMax = bMax[b];
    }
    cout << best << '\n';
}
```

### Explanation
Gaps inside a bucket are smaller than the width, which is at most the maximum gap, so comparing neighbouring non-empty buckets suffices.

### Edge Cases
- n = 1; all equal.

### Tests
#### Two values
```text
2
10 1
```
```text
9
```

A researcher's h-index is the largest h such that at least h papers have at least h citations. Compute it in O(n).

n, then n citation counts.

### Output
The h-index.

### Constraints
- 1 ≤ n ≤ 2·10^5, 0 ≤ citations ≤ 10^9

### Sample Input
```text

```


### Sample Explanation
Three papers have at least 3 citations.

### Target
O(n).

### Hints
1. Citations above n can be treated as n.
2. Count per value 0..n, then accumulate from the top.

### Approach
Capped counting.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> count(n + 1, 0);
    for (int i = 0; i < n; ++i) { long long c; cin >> c; ++count[min<long long>(c, n)]; }
    int atLeast = 0;
    for (int h = n; h >= 0; --h) {
        atLeast += count[h];                       // papers with >= h citations
        if (atLeast >= h) { cout << h << '\n'; return 0; }
    }
}
```

### Explanation
Capping shrinks the key range to n + 1, which makes counting sort linear even for huge values.


### Statement
Values are in [0, 10^5]. Sort them by frequency descending, ties by value ascending.

### Input
n, then n integers.

### Output

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
6
1 1 2 2 2 3
```

### Sample Output
```text

```

### Sample Explanation
2 occurs three times.

### Target
O(n + range).

### Hints
1. Count frequencies in an array.
2. Bucket the values by frequency (bucket index = frequency), scanning values in increasing order.

### Approach

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    const int MAXV = 100000;
    int n;
    cin >> n;
    vector<int> freq(MAXV + 1, 0);
    for (int i = 0; i < n; ++i) { int x; cin >> x; ++freq[x]; }

        for (int v : byFreq[f])
            for (int c = 0; c < f; ++c) cout << v << (++printed < n ? ' ' : '\n');
}
```

### Explanation
Frequencies are at most n, so they can serve as bucket indices: no comparison sort needed.


## DSA16D-H02 · Keys up to n²
**Difficulty:** Hard · **Subtopic:** Choosing the radix · **Tags:** radix sort, linear time · **Source:** Original

### Statement
n integers lie in [0, n² − 1]. Sort them in O(n) by radix sort in base n (two passes).

### Input
n, then n integers.

### Output
The sorted array.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
24 0 13 7 6
```

### Sample Output
```text
0 6 7 13 24
```

### Sample Explanation
In base 5, 24 = (4, 4) and 13 = (2, 3).

### Target
O(n).

### Hints
1. Write x = hi·n + lo with lo, hi < n.
2. Stable counting sort by lo, then by hi.

### Approach
Two base-n counting passes.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    long long n;
    cin >> n;
    vector<long long> a(n), out(n);
    for (auto& x : a) cin >> x;
    for (int pass = 0; pass < 2; ++pass) {
        vector<long long> count(n + 1, 0);
        auto digit = [&](long long x) { return pass == 0 ? x % n : x / n; };
        for (long long x : a) ++count[digit(x) + 1];
        for (long long d = 1; d <= n; ++d) count[d] += count[d - 1];
        for (long long x : a) out[count[digit(x)]++] = x;
        a.swap(out);
    }
    for (long long i = 0; i < n; ++i) cout << a[i] << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Counting sort alone would need O(n²) counters; choosing base n keeps both the number of passes (2) and the counter size (n) small.

### Edge Cases
- n = 1.

### Tests
#### One
```text

0
```

## DSA16D-H03 · First Missing Positive
**Difficulty:** Hard · **Subtopic:** Cyclic placement sort · **Tags:** linear time, in-place, array · **Source:** Original

### Statement
Print the smallest positive integer not in the array, in O(n) time and O(1) extra space.

### Input
n, then n integers.

### Output
The smallest missing positive.

### Constraints
- 1 ≤ n ≤ 2·10^5, |values| ≤ 10^9

### Sample Input
```text
4
3 4 -1 1
```

### Sample Output
```text
2
```

### Sample Explanation
1 is present, 2 is missing.

### Target
O(n), O(1) extra.

### Hints
1. The answer is in 1..n + 1.
2. Place every value v in 1..n at index v − 1 by swapping (each swap fixes one element).
3. Then the first index i with a[i] ≠ i + 1 gives the answer.

### Approach
Cyclic sort restricted to the useful range.

### Solution
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    for (int i = 0; i < n; ++i)
        while (a[i] >= 1 && a[i] <= n && a[a[i] - 1] != a[i]) swap(a[i], a[a[i] - 1]);
    int answer = n + 1;
    for (int i = 0; i < n; ++i) if (a[i] != i + 1) { answer = i + 1; break; }
    cout << answer << '\n';
}
```

### Explanation
Each swap puts at least one value in its final slot, so there are at most n swaps in total: a linear-time "sort" for keys that index directly into the array.

### Edge Cases
- 1..n all present: n + 1.

### Tests
#### Complete
```text
3
1 2 3
```
```text
4
```

#### No small values
```text
3
7 8 9
```
```text
1
```

## DSA16D-H04 · MSD Radix Sort of Strings
**Difficulty:** Hard · **Subtopic:** Most-significant-digit radix · **Tags:** radix sort, strings, recursion · **Source:** Original

### Statement
Sort lowercase strings of different lengths lexicographically with MSD radix sort (bucket by character position, recursing into buckets; a shorter string ends before longer ones).

### Input
n, then n words.

### Output
The sorted words.

### Constraints
- 1 ≤ n ≤ 10^5, total length ≤ 10^6, length ≤ 50

### Sample Input
```text
5
banana ban apple app b
```

### Sample Output
```text
app apple b ban banana
```

### Sample Explanation
Prefixes come first.

### Target
O(total characters + buckets).

### Hints
1. At depth d, bucket 0 holds strings that end at d; buckets 1..26 by character.
2. Recurse into each bucket with depth d + 1; stop on buckets of size ≤ 1.

### Approach
Recursive MSD radix sort on index ranges with an auxiliary array.

### Solution
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

vector<string> a, aux;

int charAt(const string& s, size_t d) { return d < s.size() ? s[d] - 'a' + 1 : 0; }   // 0 = end of string

void msd(int lo, int hi, size_t d) {                 // sort a[lo, hi) by characters from position d
    if (hi - lo < 2) return;
    int count[28] = {};
    for (int i = lo; i < hi; ++i) ++count[charAt(a[i], d) + 1];
    for (int c = 1; c < 28; ++c) count[c] += count[c - 1];
    int start[28];
    for (int c = 0; c < 28; ++c) start[c] = count[c];
    for (int i = lo; i < hi; ++i) aux[lo + count[charAt(a[i], d)]++] = a[i];
    for (int i = lo; i < hi; ++i) a[i] = aux[i];
    for (int c = 1; c < 27; ++c) msd(lo + start[c], lo + start[c + 1], d + 1);   // bucket 0 is finished
}

int main() {
    int n;
    cin >> n;
    a.resize(n);
    aux.resize(n);
    for (auto& s : a) cin >> s;
    msd(0, n, 0);
    for (int i = 0; i < n; ++i) cout << a[i] << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
MSD radix examines only the characters needed to tell strings apart, which suits variable-length keys; recursion depth is at most the longest length.

### Edge Cases
- Duplicate strings; prefixes.

### Tests
#### Duplicates
```text

b a b
```
```text

```

## DSA16D-H05 · Rank Transform
**Difficulty:** Hard · **Subtopic:** Compressing keys for counting sort · **Tags:** coordinate compression, sorting, counting · **Source:** Original

### Statement
Replace every value by its rank among the distinct values (smallest = 1). Ranks make huge keys suitable for counting-based algorithms.

### Input
n, then n integers.

### Output
n ranks.

### Constraints
- 1 ≤ n ≤ 2·10^5, |values| ≤ 10^18

### Sample Input
```text
4
40 10 20 40
```

### Sample Output
```text
3 1 2 3
```

### Sample Explanation
Distinct sorted values 10, 20, 40.

### Target
O(n log n) once; afterwards keys are in [1, n].

### Hints
1. Sort a copy and remove duplicates.
2. Each rank is a binary search position + 1.

### Approach
Sort, unique, lower_bound.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    vector<long long> sorted = a;
    sort(sorted.begin(), sorted.end());
    sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());
    for (int i = 0; i < n; ++i)
        cout << lower_bound(sorted.begin(), sorted.end(), a[i]) - sorted.begin() + 1 << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Compression maps any keys to the range [1, n] while preserving order, after which counting sort or counting arrays (Fenwick trees in DSA II) apply in linear space.

### Edge Cases
- All equal: all ranks 1.

### Tests
#### Negatives
```text
3
-5 1000000000000000000 -5
```
```text
1 2 1
```
