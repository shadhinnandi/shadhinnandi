# Trees and Traversals: Practice Problems

Unless stated otherwise, a binary tree is given as n, then n lines `value left right`, where left and right are child indices (0-based, −1 for none) and node 0 is the root. Recursive solutions are fine when the height is bounded as stated; otherwise use an explicit stack.

## DSA11-E01 · Three Depth-First Traversals
**Difficulty:** Easy · **Subtopic:** Preorder, inorder, postorder · **Tags:** binary tree, traversal, recursion · **Source:** Original

### Statement
Print the preorder, inorder and postorder traversals, one per line.

### Input
The tree in the standard format.

### Output
Three lines of values.

### Constraints
- 1 ≤ n ≤ 2·10^5, height ≤ 2000

### Sample Input
```text
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1
```

### Sample Output
```text
1 2 4 5 3
4 2 5 1 3
4 5 2 3 1
```

### Sample Explanation
The root 1 has children 2 and 3; node 2 has children 4 and 5.

### Target
O(n).

### Hints
1. The three orders differ only in when the root is visited.
2. Collect values into vectors, then print.

### Approach
One recursive function per order.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<long long> val;
vector<int> L, R;
vector<long long> pre, in, post;

void walk(int u) {
    if (u == -1) return;
    pre.push_back(val[u]);
    walk(L[u]);
    in.push_back(val[u]);
    walk(R[u]);
    post.push_back(val[u]);
}

void print(const vector<long long>& v) {
    for (size_t i = 0; i < v.size(); ++i) cout << v[i] << (i + 1 < v.size() ? ' ' : '\n');
}

int main() {
    int n;
    cin >> n;
    val.resize(n); L.resize(n); R.resize(n);
    for (int i = 0; i < n; ++i) cin >> val[i] >> L[i] >> R[i];
    walk(0);
    print(pre); print(in); print(post);
}
```

### Explanation
Each node is visited once; the position of the "visit" relative to the recursive calls defines the order.

### Edge Cases
- A single node; a path-shaped tree.

### Tests
#### Single node
```text
1
7 -1 -1
```
```text
7
7
7
```

## DSA11-E02 · Height, Size and Leaves
**Difficulty:** Easy · **Subtopic:** Basic tree algorithms · **Tags:** binary tree, recursion, height · **Source:** Original

### Statement
Print the height (in edges; a single node has height 0), the number of nodes reachable from the root, and the number of leaves.

### Input
The tree in the standard format.

### Output
Height, size and leaves.

### Constraints
- 1 ≤ n ≤ 2·10^5, height ≤ 2000

### Sample Input
```text
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1
```

### Sample Output
```text
2 5 3
```

### Sample Explanation
Leaves 3, 4, 5; the deepest leaves are 2 edges below the root.

### Target
O(n).

### Hints
1. height(empty) = −1 makes the formula 1 + max(...) work for leaves.
2. A leaf has no children.

### Approach
One recursive pass returning height and accumulating counts.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<int> L, R;
long long sizeCount = 0, leaves = 0;

int height(int u) {
    if (u == -1) return -1;
    ++sizeCount;
    if (L[u] == -1 && R[u] == -1) ++leaves;
    return 1 + max(height(L[u]), height(R[u]));
}

int main() {
    int n;
    cin >> n;
    L.resize(n); R.resize(n);
    for (int i = 0; i < n; ++i) { long long v; cin >> v >> L[i] >> R[i]; }
    int h = height(0);
    cout << h << ' ' << sizeCount << ' ' << leaves << '\n';
}
```

### Explanation
The −1 convention for empty trees counts edges; with 0 you would count nodes on the longest path instead.

### Edge Cases
- One node: 0 1 1.

### Tests
#### One node
```text
1
4 -1 -1
```
```text
0 1 1
```

## DSA11-E03 · Level-Order Traversal
**Difficulty:** Easy · **Subtopic:** Breadth-first traversal · **Tags:** binary tree, queue, BFS · **Source:** Original

### Statement
Print the values level by level, left to right, each level on its own line.

### Input
The tree in the standard format.

### Output
One line per level.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1
```

### Sample Output
```text
1
2 3
4 5
```

### Sample Explanation
Three levels.

### Target
O(n).

### Hints
1. Use a queue.
2. Process exactly the current queue size to finish one level.

### Approach
BFS with level boundaries.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> val(n);
    vector<int> L(n), R(n);
    for (int i = 0; i < n; ++i) cin >> val[i] >> L[i] >> R[i];
    queue<int> q;
    q.push(0);
    while (!q.empty()) {
        size_t width = q.size();
        for (size_t k = 0; k < width; ++k) {
            int u = q.front(); q.pop();
            cout << val[u] << (k + 1 < width ? ' ' : '\n');
            if (L[u] != -1) q.push(L[u]);
            if (R[u] != -1) q.push(R[u]);
        }
    }
}
```

### Explanation
The queue holds exactly one level at the start of each outer iteration, so no recursion is needed even for very deep trees.

### Edge Cases
- Single node; path-shaped tree.

### Tests
#### Right path
```text
3
1 -1 1
2 -1 2
3 -1 -1
```
```text
1
2
3
```

## DSA11-E04 · Full, Complete, Perfect
**Difficulty:** Easy · **Subtopic:** Binary tree shapes · **Tags:** binary tree, definitions, BFS · **Source:** Original

### Statement
Print three words (YES/NO): is the tree full, complete, perfect?

### Input
The tree in the standard format.

### Output
Three words.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1
```

### Sample Output
```text
YES YES NO
```

### Sample Explanation
Every node has 0 or 2 children and levels fill left to right, but the leaves are at different depths.

### Target
O(n).

### Hints
1. Full: no node has exactly one child.
2. Complete: in level order, once a missing child is seen, no later node may have a child.
3. Perfect: n = 2^(h+1) − 1 for height h.

### Approach
BFS for completeness and height; a scan for fullness.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> L(n), R(n);
    for (int i = 0; i < n; ++i) { long long v; cin >> v >> L[i] >> R[i]; }
    bool full = true;
    for (int i = 0; i < n; ++i) if ((L[i] == -1) != (R[i] == -1)) full = false;
    bool complete = true, gap = false;
    int levels = 0;
    queue<int> q;
    q.push(0);
    while (!q.empty()) {
        size_t width = q.size();
        ++levels;
        for (size_t k = 0; k < width; ++k) {
            int u = q.front(); q.pop();
            for (int c : {L[u], R[u]}) {
                if (c == -1) gap = true;
                else { if (gap) complete = false; q.push(c); }
            }
        }
    }
    bool perfect = (static_cast<long long>(n) == (1LL << levels) - 1);
    cout << (full ? "YES" : "NO") << ' ' << (complete ? "YES" : "NO") << ' ' << (perfect ? "YES" : "NO") << '\n';
}
```

### Explanation
A perfect tree with h + 1 levels has exactly 2^(h+1) − 1 nodes, and that count forces every level to be full. The completeness test is the standard "no child after a gap" rule.

### Edge Cases
- One node: all three YES.
- A root with only a left child: complete but not full.

### Tests
#### Left child only
```text
2
1 1 -1
2 -1 -1
```
```text
NO YES NO
```

## DSA11-E05 · Depths in a General Tree
**Difficulty:** Easy · **Subtopic:** General trees · **Tags:** general tree, parent array, depth · **Source:** Original

### Statement
A general tree is given by a parent array (parent of the root is −1, and every parent index is smaller than its child's). Print each node's depth, then the maximum degree (most children of any node).

### Input
n, then n parents.

### Output
Depths on one line, maximum degree on the next.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
4
-1 0 0 1
```

### Sample Output
```text
0 1 1 2
2
```

### Sample Explanation
Node 0 has two children.

### Target
O(n).

### Hints
1. Because parents come first, depth[i] = depth[parent] + 1 in index order.
2. Count children per node.

### Approach
One pass in index order.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> parent(n), depth(n, 0), children(n, 0);
    for (auto& p : parent) cin >> p;
    for (int i = 0; i < n; ++i)
        if (parent[i] != -1) { depth[i] = depth[parent[i]] + 1; ++children[parent[i]]; }
    for (int i = 0; i < n; ++i) cout << depth[i] << (i + 1 < n ? ' ' : '\n');
    cout << *max_element(children.begin(), children.end()) << '\n';
}
```

### Explanation
A parent array is a compact representation of a general tree; the ordering guarantee lets depths be filled without recursion.

### Edge Cases
- Single node: depth 0, degree 0.

### Tests
#### Single
```text
1
-1
```
```text
0
0
```

## DSA11-M01 · Iterative Inorder for Deep Trees
**Difficulty:** Medium · **Subtopic:** Iterative traversal · **Tags:** binary tree, stack, iteration · **Source:** Original

### Statement
Print the inorder traversal of a tree that can be a path of 2·10^5 nodes, without recursion.

### Input
The tree in the standard format.

### Output
The inorder sequence.

### Constraints
- 1 ≤ n ≤ 2·10^5 (any shape)

### Sample Input
```text
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1
```

### Sample Output
```text
4 2 5 1 3
```

### Sample Explanation
Left subtree, root, right subtree.

### Target
O(n) time, O(h) explicit stack.

### Hints
1. Push nodes while going left.
2. Pop, visit, then move to the right child.

### Approach
Standard stack-based inorder.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> val(n);
    vector<int> L(n), R(n);
    for (int i = 0; i < n; ++i) cin >> val[i] >> L[i] >> R[i];
    vector<int> st;
    vector<long long> out;
    int u = 0;
    while (u != -1 || !st.empty()) {
        while (u != -1) { st.push_back(u); u = L[u]; }   // go as far left as possible
        u = st.back(); st.pop_back();
        out.push_back(val[u]);
        u = R[u];
    }
    for (size_t i = 0; i < out.size(); ++i) cout << out[i] << (i + 1 < out.size() ? ' ' : '\n');
}
```

### Explanation
The explicit stack holds the ancestors whose visit is pending, exactly what the call stack would hold, but on the heap where 2·10^5 entries are no problem.

### Edge Cases
- Left-leaning path (stack grows to n).

### Tests
#### Left path
```text
3
1 1 -1
2 2 -1
3 -1 -1
```
```text
3 2 1
```

## DSA11-M02 · Rebuild from Preorder and Inorder
**Difficulty:** Medium · **Subtopic:** Traversal reconstruction · **Tags:** binary tree, reconstruction, recursion · **Source:** Original

### Statement
Distinct values; given the preorder and inorder sequences, print the postorder.

### Input
n, the preorder, the inorder.

### Output
The postorder.

### Constraints
- 1 ≤ n ≤ 2·10^5, height ≤ 2000

### Sample Input
```text
5
1 2 4 5 3
4 2 5 1 3
```

### Sample Output
```text
4 5 2 3 1
```

### Sample Explanation
1 is the root; inorder splits {4,2,5} and {3}.

### Target
O(n) with a position map.

### Hints
1. The first preorder value is the root; its inorder position splits the subtrees.
2. Store inorder positions in a hash map.

### Approach
Recursive build emitting postorder directly.

### Solution
```cpp
#include <iostream>
#include <unordered_map>
#include <vector>
using namespace std;

vector<long long> pre, post;
unordered_map<long long, int> where;
int nextPre = 0;

void build(int lo, int hi) {                       // inorder range [lo, hi)
    if (lo >= hi) return;
    long long root = pre[nextPre++];
    int mid = where[root];
    build(lo, mid);
    build(mid + 1, hi);
    post.push_back(root);
}

int main() {
    int n;
    cin >> n;
    pre.resize(n);
    for (auto& x : pre) cin >> x;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; where[x] = i; }
    build(0, n);
    for (int i = 0; i < n; ++i) cout << post[i] << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Preorder lists the root before its subtrees, so consuming it left subtree first matches the recursion; each value is handled once.

### Edge Cases
- Single node; skewed trees.

### Tests
#### Right skew
```text
3
1 2 3
1 2 3
```
```text
3 2 1
```

## DSA11-M03 · Diameter of a Binary Tree
**Difficulty:** Medium · **Subtopic:** Post-order computation · **Tags:** binary tree, recursion, height · **Source:** Original

### Statement
Print the number of edges on the longest path between any two nodes.

### Input
The tree in the standard format.

### Output
The diameter.

### Constraints
- 1 ≤ n ≤ 2·10^5, height ≤ 2000

### Sample Input
```text
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1
```

### Sample Output
```text
3
```

### Sample Explanation
4 – 2 – 1 – 3.

### Target
O(n).

### Hints
1. The longest path through a node uses the heights of both subtrees.
2. Compute heights bottom-up and update a global best.

### Approach
Postorder height with a running maximum of left + right + 2.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<int> L, R;
int best = 0;

int height(int u) {                          // edges; empty = -1
    if (u == -1) return -1;
    int hl = height(L[u]), hr = height(R[u]);
    best = max(best, hl + hr + 2);           // path bending at u
    return 1 + max(hl, hr);
}

int main() {
    int n;
    cin >> n;
    L.resize(n); R.resize(n);
    for (int i = 0; i < n; ++i) { long long v; cin >> v >> L[i] >> R[i]; }
    height(0);
    cout << best << '\n';
}
```

### Explanation
Every path has a highest node where it bends; considering every node as that point covers all paths in one traversal.

### Edge Cases
- Single node: 0.

### Tests
#### Single
```text
1
1 -1 -1
```
```text
0
```

## DSA11-M04 · Mirror and Symmetry
**Difficulty:** Medium · **Subtopic:** Structural recursion · **Tags:** binary tree, recursion, symmetry · **Source:** Original

### Statement
Print the preorder of the mirrored tree (left and right swapped everywhere), then `YES` if the original tree is symmetric (equal to its mirror), otherwise `NO`.

### Input
The tree in the standard format.

### Output
Two lines.

### Constraints
- 1 ≤ n ≤ 2·10^5, height ≤ 2000

### Sample Input
```text
7
1 1 2
2 3 4
2 5 6
3 -1 -1
4 -1 -1
4 -1 -1
3 -1 -1
```

### Sample Output
```text
1 2 3 4 2 4 3
YES
```

### Sample Explanation
The left subtree (2: 3, 4) mirrors the right subtree (2: 4, 3).

### Target
O(n).

### Hints
1. Mirror preorder: root, then right subtree, then left.
2. Symmetric: compare a's left with b's right and a's right with b's left.

### Approach
Two recursive functions.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<long long> val;
vector<int> L, R;
vector<long long> out;

void mirrorPre(int u) {
    if (u == -1) return;
    out.push_back(val[u]);
    mirrorPre(R[u]);
    mirrorPre(L[u]);
}

bool mirror(int a, int b) {
    if (a == -1 || b == -1) return a == b;
    return val[a] == val[b] && mirror(L[a], R[b]) && mirror(R[a], L[b]);
}

int main() {
    int n;
    cin >> n;
    val.resize(n); L.resize(n); R.resize(n);
    for (int i = 0; i < n; ++i) cin >> val[i] >> L[i] >> R[i];
    mirrorPre(0);
    for (size_t i = 0; i < out.size(); ++i) cout << out[i] << (i + 1 < out.size() ? ' ' : '\n');
    cout << (mirror(L[0], R[0]) ? "YES" : "NO") << '\n';
}
```

### Explanation
Symmetry is a comparison of the tree with its own mirror, done pairwise without building the mirror.

### Edge Cases
- Single node: symmetric.

### Tests
#### Asymmetric
```text
2
1 1 -1
2 -1 -1
```
```text
1 2
NO
```

## DSA11-M05 · Lowest Common Ancestor by Depths
**Difficulty:** Medium · **Subtopic:** Parent pointers · **Tags:** tree, LCA, depth · **Source:** Original

### Statement
A general tree is given by a parent array (parents have smaller indices; root 0 has parent −1). For each query (u, v) print their lowest common ancestor.

### Input
n and parents; q and q pairs.

### Output
One ancestor per query.

### Constraints
- 1 ≤ n ≤ 2·10^5, 1 ≤ q ≤ 2000

### Sample Input
```text
6
-1 0 0 1 1 2
3
3 4
3 5
4 1
```

### Sample Output
```text
1
0
1
```

### Sample Explanation
3 and 4 share parent 1; 3 and 5 meet at the root.

### Target
O(h) per query.

### Hints
1. Lift the deeper node until both have equal depth.
2. Then lift both together until they meet.

### Approach
Depths from the parent array, then walk up.

### Solution
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> parent(n), depth(n, 0);
    for (auto& p : parent) cin >> p;
    for (int i = 1; i < n; ++i) depth[i] = depth[parent[i]] + 1;
    int q;
    cin >> q;
    while (q--) {
        int u, v;
        cin >> u >> v;
        if (depth[u] < depth[v]) swap(u, v);
        while (depth[u] > depth[v]) u = parent[u];
        while (u != v) { u = parent[u]; v = parent[v]; }
        cout << u << '\n';
    }
}
```

### Explanation
Equalising depths ensures both pointers reach the LCA in the same step. Binary lifting would make this O(log n) per query (DSA II).

### Edge Cases
- One node is an ancestor of the other; u = v.

### Tests
#### Same node
```text
2
-1 0
1
1 1
```
```text
1
```

## DSA11-H01 · Maximum Path Sum
**Difficulty:** Hard · **Subtopic:** Tree dynamic computation · **Tags:** binary tree, recursion, optimisation · **Source:** Original

### Statement
Values may be negative. A path is any sequence of connected nodes (at least one). Print the maximum sum of a path.

### Input
The tree in the standard format.

### Output
The maximum path sum.

### Constraints
- 1 ≤ n ≤ 2·10^5, height ≤ 2000, |value| ≤ 10^9

### Sample Input
```text
5
-10 1 2
9 -1 -1
20 3 4
15 -1 -1
7 -1 -1
```

### Sample Output
```text
42
```

### Sample Explanation
15 + 20 + 7.

### Target
O(n).

### Hints
1. Return, for each node, the best downward path starting at it (ignoring negative child contributions).
2. The best path bending at u is value + max(0, left) + max(0, right).

### Approach
Postorder recursion with a global maximum.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<long long> val;
vector<int> L, R;
long long best;

long long down(int u) {                         // best path starting at u going down
    if (u == -1) return 0;
    long long l = max(0LL, down(L[u])), r = max(0LL, down(R[u]));
    best = max(best, val[u] + l + r);
    return val[u] + max(l, r);
}

int main() {
    int n;
    cin >> n;
    val.resize(n); L.resize(n); R.resize(n);
    for (int i = 0; i < n; ++i) cin >> val[i] >> L[i] >> R[i];
    best = val[0];
    down(0);
    cout << best << '\n';
}
```

### Explanation
A downward path can be extended upwards, a bent path cannot, so the function returns one and records the other.

### Edge Cases
- All negative: the largest single value.

### Tests
#### All negative
```text
2
-3 1 -1
-2 -1 -1
```
```text
-2
```

## DSA11-H02 · Zigzag Level Order
**Difficulty:** Hard · **Subtopic:** Level-order variants · **Tags:** binary tree, BFS, deque · **Source:** Original

### Statement
Print the levels alternately left-to-right and right-to-left, starting left-to-right at the root.

### Input
The tree in the standard format.

### Output
One line per level.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1
```

### Sample Output
```text
1
3 2
4 5
```

### Sample Explanation
Level 1 is reversed.

### Target
O(n).

### Hints
1. Do a normal level-order traversal.
2. Reverse every odd level before printing.

### Approach
BFS collecting each level into a vector.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> val(n);
    vector<int> L(n), R(n);
    for (int i = 0; i < n; ++i) cin >> val[i] >> L[i] >> R[i];
    queue<int> q;
    q.push(0);
    for (int level = 0; !q.empty(); ++level) {
        vector<long long> row;
        for (size_t k = q.size(); k > 0; --k) {
            int u = q.front(); q.pop();
            row.push_back(val[u]);
            if (L[u] != -1) q.push(L[u]);
            if (R[u] != -1) q.push(R[u]);
        }
        if (level % 2 == 1) reverse(row.begin(), row.end());
        for (size_t i = 0; i < row.size(); ++i) cout << row[i] << (i + 1 < row.size() ? ' ' : '\n');
    }
}
```

### Explanation
Only the printing order changes; the queue still processes children left to right, so each level is O(width).

### Edge Cases
- Single node.

### Tests
#### Path
```text
2
1 1 -1
2 -1 -1
```
```text
1
2
```

## DSA11-H03 · Iterative Postorder
**Difficulty:** Hard · **Subtopic:** Iterative traversal · **Tags:** binary tree, stack, iteration · **Source:** Original

### Statement
Print the postorder traversal of a tree of any shape (up to 2·10^5 deep) without recursion.

### Input
The tree in the standard format.

### Output
The postorder.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
1 1 2
2 3 4
3 -1 -1
4 -1 -1
5 -1 -1
```

### Sample Output
```text
4 5 2 3 1
```

### Sample Explanation
Children before parents.

### Target
O(n).

### Hints
1. Preorder with "root, right, left" reversed is postorder.
2. Or keep a "last visited" pointer to know when to visit a node.

### Approach
Root–right–left with a stack, then reverse the output.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> val(n);
    vector<int> L(n), R(n);
    for (int i = 0; i < n; ++i) cin >> val[i] >> L[i] >> R[i];
    vector<int> st = {0};
    vector<long long> out;
    while (!st.empty()) {
        int u = st.back(); st.pop_back();
        out.push_back(val[u]);                   // root, right, left order
        if (L[u] != -1) st.push_back(L[u]);
        if (R[u] != -1) st.push_back(R[u]);
    }
    reverse(out.begin(), out.end());             // becomes left, right, root
    for (size_t i = 0; i < out.size(); ++i) cout << out[i] << (i + 1 < out.size() ? ' ' : '\n');
}
```

### Explanation
Reversing root–right–left gives left–right–root, i.e. postorder, with an explicit stack instead of the call stack.

### Edge Cases
- Long paths.

### Tests
#### Right path
```text
3
1 -1 1
2 -1 2
3 -1 -1
```
```text
3 2 1
```

## DSA11-H04 · Expression Tree
**Difficulty:** Hard · **Subtopic:** Trees for expressions · **Tags:** expression tree, stack, recursion · **Source:** Original

### Statement
Build an expression tree from a postfix expression of integers and + − * /, then print the fully parenthesised infix form and the value (truncating division).

### Input
One line of tokens.

### Output
Infix on one line, value on the next.

### Constraints
- up to 10^4 tokens; valid; no division by zero

### Sample Input
```text
3 4 + 2 *
```

### Sample Output
```text
((3+4)*2)
14
```

### Sample Explanation
The root is *, with children + and 2.

### Target
O(tokens).

### Hints
1. Build with a stack of subtrees: an operator pops two subtrees and becomes their parent.
2. Inorder with parentheses prints infix; postorder evaluation computes the value.

### Approach
Nodes in a vector; stack of indices.

### Solution
```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

struct Node { string tok; int left, right; };
vector<Node> t;

string infix(int u) {
    if (t[u].left == -1) return t[u].tok;
    return "(" + infix(t[u].left) + t[u].tok + infix(t[u].right) + ")";
}

long long eval(int u) {
    if (t[u].left == -1) return stoll(t[u].tok);
    long long a = eval(t[u].left), b = eval(t[u].right);
    char op = t[u].tok[0];
    return op == '+' ? a + b : op == '-' ? a - b : op == '*' ? a * b : a / b;
}

int main() {
    string line, tok;
    getline(cin, line);
    istringstream in(line);
    vector<int> st;
    while (in >> tok) {
        if (tok.size() == 1 && string("+-*/").find(tok[0]) != string::npos) {
            int r = st.back(); st.pop_back();
            int l = st.back(); st.pop_back();
            t.push_back({tok, l, r});
        } else {
            t.push_back({tok, -1, -1});
        }
        st.push_back(static_cast<int>(t.size()) - 1);
    }
    int root = st.back();
    cout << infix(root) << '\n' << eval(root) << '\n';
}
```

### Explanation
Postfix order is exactly a postorder traversal of the expression tree, which is why a stack rebuilds it.

### Edge Cases
- A single number.

### Tests
#### Single number
```text
42
```
```text
42
42
```

## DSA11-H05 · Subtree Sizes in a General Tree
**Difficulty:** Hard · **Subtopic:** Bottom-up aggregation · **Tags:** general tree, parent array, iteration · **Source:** Original

### Statement
A tree is given by a parent array with parents having smaller indices. Print the size of every node's subtree, without recursion (the tree may be a path of 2·10^5 nodes).

### Input
n, then n parents.

### Output
n subtree sizes.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
4
-1 0 0 1
```

### Sample Output
```text
4 2 1 1
```

### Sample Explanation
Node 1's subtree is {1, 3}.

### Target
O(n).

### Hints
1. Children have larger indices than parents.
2. Process nodes from n − 1 down to 1, adding each size to its parent.

### Approach
Reverse index order is a valid postorder here.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> parent(n);
    for (auto& p : parent) cin >> p;
    vector<long long> size(n, 1);
    for (int i = n - 1; i >= 1; --i) size[parent[i]] += size[i];   // children are finished first
    for (int i = 0; i < n; ++i) cout << size[i] << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Since every child is processed before its parent, each size is final when it is added upwards: a postorder without recursion.

### Edge Cases
- Path-shaped tree.

### Tests
#### Path
```text
3
-1 0 1
```
```text
3 2 1
```
