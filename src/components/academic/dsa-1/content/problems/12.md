# Graphs and Representations: Practice Problems

Graphs are given as n m followed by m edges with 1-based vertices, unless stated otherwise. Choose the representation that makes the required operations cheap.

## DSA12-E01 · Vertex Degrees
**Difficulty:** Easy · **Subtopic:** Undirected graphs · **Tags:** graph, degree, edge list · **Source:** Original

### Statement
Print the degree of every vertex of an undirected graph.

### Input
n m, then m edges u v.

### Output
n degrees.

### Constraints
- 1 ≤ n ≤ 2·10^5, 0 ≤ m ≤ 2·10^5, no self-loops

### Sample Input
```text
4 4
1 2
1 3
2 3
3 4
```

### Sample Output
```text
2 2 3 1
```

### Sample Explanation
Vertex 3 touches three edges.

### Target
O(n + m).

### Hints
1. Each undirected edge adds one to both endpoints.
2. The degrees sum to 2m (handshake lemma).

### Approach
Count array.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<int> deg(n + 1, 0);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; ++deg[u]; ++deg[v]; }
    for (int u = 1; u <= n; ++u) cout << deg[u] << (u < n ? ' ' : '\n');
}
```

### Explanation
No adjacency structure is needed when only degrees are required.

### Edge Cases
- m = 0: all zeros.

### Tests
#### No edges
```text
3 0
```
```text
0 0 0
```

## DSA12-E02 · Adjacency Matrix
**Difficulty:** Easy · **Subtopic:** Matrix representation · **Tags:** graph, adjacency matrix · **Source:** Original

### Statement
Print the adjacency matrix of an undirected graph (1 for an edge, 0 otherwise).

### Input
n m, then m edges.

### Output
n rows of n numbers.

### Constraints
- 1 ≤ n ≤ 1000

### Sample Input
```text
4 4
1 2
1 3
2 3
3 4
```

### Sample Output
```text
0 1 1 0
1 0 1 0
1 1 0 1
0 0 1 0
```

### Sample Explanation
The matrix of an undirected graph is symmetric.

### Target
O(n² + m) time, O(n²) space.

### Hints
1. Set both [u][v] and [v][u].
2. n² cells: fine for n = 1000, impossible for 10^5.

### Approach
2D vector of chars.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> a(n, vector<int>(n, 0));
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; a[u - 1][v - 1] = a[v - 1][u - 1] = 1; }
    for (const auto& row : a)
        for (int j = 0; j < n; ++j) cout << row[j] << (j + 1 < n ? ' ' : '\n');
}
```

### Explanation
The matrix answers "is (u, v) an edge?" in O(1) but always costs Θ(n²) memory.

### Edge Cases
- n = 1.

### Tests
#### Single vertex
```text
1 0
```
```text
0
```

## DSA12-E03 · Edge Queries
**Difficulty:** Easy · **Subtopic:** Constant-time edge tests · **Tags:** graph, adjacency matrix, queries · **Source:** Original

### Statement
Answer q queries "is there an edge between u and v?" in an undirected graph.

### Input
n m, edges; q, then q pairs.

### Output
`YES` or `NO` per query.

### Constraints
- 1 ≤ n ≤ 2000, 1 ≤ q ≤ 2·10^5

### Sample Input
```text
4 4
1 2
1 3
2 3
3 4
3
1 2
1 4
4 3
```

### Sample Output
```text
YES
NO
YES
```

### Sample Explanation
1 and 4 are not adjacent.

### Target
O(1) per query.

### Hints
1. Many edge queries on a small graph suit a matrix.
2. Remember the symmetric entry.

### Approach
Boolean matrix.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<char>> adj(n + 1, vector<char>(n + 1, 0));
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u][v] = adj[v][u] = 1; }
    int q;
    cin >> q;
    while (q--) { int u, v; cin >> u >> v; cout << (adj[u][v] ? "YES" : "NO") << '\n'; }
}
```

### Explanation
With adjacency lists each query would cost O(degree); the matrix trades memory for O(1) queries.

### Edge Cases
- Query with u = v.

### Tests
#### Self query
```text
2 1
1 2
1
1 1
```
```text
NO
```

## DSA12-E04 · In- and Out-Degrees

### Constraints

## DSA12-E05 · Loops and Parallel Edges
**Difficulty:** Easy · **Subtopic:** Input validation · **Tags:** graph, edge list, set · **Source:** Original

### Statement
An undirected multigraph's edge list may contain self-loops and repeated edges. Print the number of self-loops and the number of extra (parallel) copies of non-loop edges.

### Input
n m, then m edges.

### Output
Self-loops and parallel copies.

### Constraints
- 1 ≤ n ≤ 2·10^5, 1 ≤ m ≤ 2·10^5

### Sample Input
```text
3 5
1 1
1 2
2 1
2 3
2 3
```

### Sample Output
```text
1 2
```

### Sample Explanation
{1,2} and {2,3} each appear twice.

### Target
O(m log m).

### Hints
1. Normalise each edge as (min, max).
2. Sort and count duplicates.

### Approach
Sorted vector of normalised pairs.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<pair<int, int>> e;
    int loops = 0;
    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;
        if (u == v) ++loops;
        else e.push_back({min(u, v), max(u, v)});
    }
    sort(e.begin(), e.end());
    long long distinct = unique(e.begin(), e.end()) - e.begin();
    cout << loops << ' ' << static_cast<long long>(e.size()) - distinct << '\n';
}
```

### Explanation
Real input is rarely clean; detecting loops and duplicates matters because many algorithms assume a simple graph.

### Edge Cases
- All edges loops.

### Tests
#### Clean graph
```text
3 2
1 2
2 3
```
```text
0 0
```

## DSA12-M01 · Sorted Adjacency Lists
**Difficulty:** Medium · **Subtopic:** Adjacency lists · **Tags:** graph, adjacency list, sorting · **Source:** Original

### Statement
Build adjacency lists of an undirected graph and print each vertex's neighbours in increasing order as `u: v1 v2 …`.

### Input
n m, then m edges.

### Output
n lines.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
4 4
3 4
2 3
1 3
1 2
```

### Sample Output
```text
1: 2 3
2: 1 3
3: 1 2 4
4: 3
```

### Sample Explanation
Edge order in the input does not matter.

### Target
O(n + m log m).

### Hints
1. vector<vector<int>> with both directions.
2. Sort each list.

### Approach
Build, sort, print.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    for (int u = 1; u <= n; ++u) {
        sort(adj[u].begin(), adj[u].end());
        cout << u << ':';
        for (int v : adj[u]) cout << ' ' << v;
        cout << '\n';
    }
}
```

### Explanation
Θ(n + m) memory, the right choice for sparse graphs; sorting makes the output deterministic.

### Edge Cases
- Isolated vertices print `u:`.

### Tests
#### Isolated vertex
```text
3 1
1 2
```
```text
1: 2
2: 1
3:
```

## DSA12-M03 · Lightest Incident Edge
**Difficulty:** Medium · **Subtopic:** Weighted graphs · **Tags:** weighted graph, edge list, minimum · **Source:** Original

### Statement
For every vertex of a weighted undirected graph, print the weight of its lightest incident edge, or −1 if it has none.

### Input
n m, then m lines u v w.

### Output
n values.

### Constraints
- 1 ≤ n, m ≤ 2·10^5, 1 ≤ w ≤ 10^9

### Sample Input
```text
4 4
1 2 5
1 3 2
2 3 7
3 4 1
```

### Sample Output
```text
2 5 1 1
```

### Sample Explanation
Vertex 2's edges weigh 5 and 7.

### Target
O(n + m).

### Hints
1. Update both endpoints with each edge.
2. Start every vertex at −1 to mark "no edge yet".

### Approach
One pass over the edge list.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<long long> best(n + 1, -1);
    for (int i = 0; i < m; ++i) {
        int u, v;
        long long w;
        cin >> u >> v >> w;
        for (int x : {u, v})
            if (best[x] == -1 || w < best[x]) best[x] = w;
    }
    for (int u = 1; u <= n; ++u) cout << best[u] << (u < n ? ' ' : '\n');
}
```

### Explanation
The edge list representation is enough for a single pass over all edges.

### Edge Cases
- Isolated vertices.

### Tests
#### Isolated
```text
3 1
1 2 9
```
```text
9 9 -1
```

## DSA12-M04 · Common Neighbours
**Difficulty:** Medium · **Subtopic:** Sorted adjacency lists · **Tags:** graph, adjacency list, two pointers · **Source:** Original

### Statement
For each query (u, v), print the number of common neighbours followed by them in increasing order.

### Input
n m, edges; q, then q pairs.

### Output
One line per query.

### Constraints
- 1 ≤ n, m ≤ 2·10^5, 1 ≤ q ≤ 1000

### Sample Input
```text
4 4
1 2
1 3
2 3
3 4
3
1 2
1 4
3 4
```

### Sample Output
```text
1 3
1 3
0
```

### Sample Explanation
1 and 2 are both adjacent to 3.

### Target
O(deg u + deg v) per query after sorting.

### Hints
1. Sort every adjacency list once.
2. Intersect two sorted lists with two pointers.

### Approach
`set_intersection` on sorted lists.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    for (auto& l : adj) sort(l.begin(), l.end());
    int q;
    cin >> q;
    while (q--) {
        int u, v;
        cin >> u >> v;
        vector<int> common;
        set_intersection(adj[u].begin(), adj[u].end(), adj[v].begin(), adj[v].end(), back_inserter(common));
        cout << common.size();
        for (int x : common) cout << ' ' << x;
        cout << '\n';
    }
}
```

### Explanation
"Friends in common" is a set intersection of neighbourhoods; sorted lists make it linear.

### Edge Cases
- No common neighbours.

### Tests
#### Same vertex
```text
3 2
1 2
1 3
1
2 3
```
```text
1 1
```

## DSA12-M05 · Grid as a Graph
**Difficulty:** Medium · **Subtopic:** Implicit graphs · **Tags:** grid, implicit graph, modelling · **Source:** Original

### Statement
In an R × C grid, `.` cells are open and `#` cells are walls. Treat open cells as vertices and side-adjacent open pairs as edges. Print the number of vertices and edges.

### Input
R C, then R rows.

### Output
Vertices and edges.

### Constraints
- 1 ≤ R, C ≤ 1000

### Sample Input
```text
3 3
..#
.#.
...
```

### Sample Output
```text
7 6
```

### Sample Explanation
Count each adjacent open pair once (right and down neighbours).

### Target
O(R·C).

### Hints
1. Only look right and down to avoid double counting.
2. No adjacency list is needed: neighbours are computed from coordinates.

### Approach
Single scan.

### Solution
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    int r, c;
    cin >> r >> c;
    vector<string> g(r);
    for (auto& row : g) cin >> row;
    long long vertices = 0, edges = 0;
    for (int i = 0; i < r; ++i)
        for (int j = 0; j < c; ++j) {
            if (g[i][j] != '.') continue;
            ++vertices;
            if (j + 1 < c && g[i][j + 1] == '.') ++edges;
            if (i + 1 < r && g[i + 1][j] == '.') ++edges;
        }
    cout << vertices << ' ' << edges << '\n';
}
```

### Explanation
A grid is a graph whose edges are implied by coordinates, which saves building any structure.

### Edge Cases
- All walls.

### Tests
#### Open square
```text
2 2
..
..
```
```text
4 4
```

## DSA12-H01 · Counting Triangles
**Difficulty:** Hard · **Subtopic:** Degree ordering · **Tags:** graph, triangles, adjacency list, optimisation · **Source:** Original

### Statement
Count the triangles (3-cycles) in a simple undirected graph.

### Input
n m, then m edges.

### Output
The number of triangles.

### Constraints
- 1 ≤ n ≤ 10^5, 0 ≤ m ≤ 10^5

### Sample Input
```text
4 4
1 2
1 3
2 3
3 4
```

### Sample Output
```text
1
```

### Sample Explanation
1–2–3.

### Target
O(m √m).

### Hints
1. Orient each edge from the lower (degree, id) endpoint to the higher one; every vertex then has O(√m) out-edges.
2. For each vertex u, mark its out-neighbours, then for each out-neighbour v count marked out-neighbours of v.

### Approach
Degree-oriented enumeration with a marker array.

### Solution
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<pair<int, int>> edges(m);
    vector<int> deg(n + 1, 0);
    for (auto& [u, v] : edges) { cin >> u >> v; ++deg[u]; ++deg[v]; }
    auto before = [&](int a, int b) { return deg[a] < deg[b] || (deg[a] == deg[b] && a < b); };
    vector<vector<int>> out(n + 1);
    for (auto [u, v] : edges) {
        if (before(u, v)) out[u].push_back(v);
        else out[v].push_back(u);
    }
    vector<int> mark(n + 1, 0);
    long long triangles = 0;
    for (int u = 1; u <= n; ++u) {
        for (int v : out[u]) mark[v] = u;
        for (int v : out[u])
            for (int w : out[v]) if (mark[w] == u) ++triangles;
    }
    cout << triangles << '\n';
}
```

### Explanation
Each triangle is counted once, at its lowest-ordered vertex. High-degree vertices have few out-edges after orientation, giving O(m√m).

### Edge Cases
- Complete graph K4: 4 triangles.

### Tests
#### K4
```text
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
```text
4
```

## DSA12-H02 · Universal Sink
**Difficulty:** Hard · **Subtopic:** Matrix representation tricks · **Tags:** adjacency matrix, elimination, directed graph · **Source:** Original

### Statement
A directed graph is given as an n × n adjacency matrix. A universal sink has in-degree n − 1 and out-degree 0. Print it (1-based) or −1, using O(n) matrix lookups after reading.

### Input
n, then the matrix.

### Output
The sink or −1.

### Constraints
- 1 ≤ n ≤ 2000

### Sample Input
```text
4
0 1 0 1
0 0 0 1
1 1 0 1
0 0 0 0
```

### Sample Output
```text
4
```

### Sample Explanation
Every vertex points to 4, and 4 points nowhere.

### Target
O(n) lookups.

### Hints
1. If a[i][j] = 1, i is not a sink; if 0, j is not a sink (unless i = j).
2. Each lookup eliminates one candidate; verify the survivor.

### Approach
Elimination walk, then verification.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> a(n, vector<int>(n));
    for (auto& row : a) for (auto& x : row) cin >> x;
    int cand = 0;
    for (int j = 1; j < n; ++j)
        if (a[cand][j]) cand = j;                    // cand has an out-edge: not a sink
    bool ok = true;
    for (int i = 0; i < n; ++i) {
        if (i == cand) continue;
        if (a[cand][i] || !a[i][cand]) ok = false;
    }
    cout << (ok ? cand + 1 : -1) << '\n';
}
```

### Explanation
Each comparison rules out one vertex, so one candidate remains after n − 1 lookups; 2(n − 1) more confirm it.

### Edge Cases
- n = 1: the single vertex is a sink.

### Tests
#### No sink
```text
2
0 1
1 0
```
```text
-1
```

#include <iostream>

## DSA12-H04 · Can This Degree Sequence Exist?
**Difficulty:** Hard · **Subtopic:** Graph theory and sorting · **Tags:** graph theory, sorting, prefix sums · **Source:** Original

### Statement
Decide whether a simple undirected graph (no loops or parallel edges) can have the given degrees.

### Input
n, then n degrees.

### Output
`YES` or `NO`.

### Constraints
- 1 ≤ n ≤ 2·10^5, 0 ≤ dᵢ ≤ n

### Sample Input
```text
5
3 3 2 2 2
```

### Sample Output
```text
YES
```

### Sample Explanation
For example a 5-cycle plus the chord between the two degree-3 vertices.

### Target
O(n log n).

### Hints
1. The sum must be even (handshake lemma).
2. Erdős–Gallai: with degrees sorted decreasingly, for every k: Σ_{i≤k} dᵢ ≤ k(k−1) + Σ_{i>k} min(dᵢ, k).
3. The right sum can be computed with a pointer over the sorted degrees and suffix sums.

### Approach
Sort descending, suffix sums, and a pointer t(k) = number of degrees ≥ k (non-increasing in k).

### Solution
```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> d(n);
    long long total = 0;
    for (auto& x : d) { cin >> x; total += x; }
    if (total % 2) { cout << "NO\n"; return 0; }
    sort(d.begin(), d.end(), greater<long long>());
    vector<long long> suffix(n + 1, 0);
    for (int i = n - 1; i >= 0; --i) suffix[i] = suffix[i + 1] + d[i];
    long long left = 0;
    int t = n;                                        // count of degrees >= k
    for (long long k = 1; k <= n; ++k) {
        left += d[k - 1];
        while (t > 0 && d[t - 1] < k) --t;
        long long bigAfter = max(0LL, static_cast<long long>(t) - k);   // indices > k with d >= k
        long long from = max(static_cast<long long>(t), k);
        long long right = k * (k - 1) + k * bigAfter + suffix[from];
        if (left > right) { cout << "NO\n"; return 0; }
    }
    cout << "YES\n";
}
```

### Explanation

## DSA12-H05 · Friends of Friends
**Difficulty:** Hard · **Subtopic:** Neighbourhoods at distance two · **Tags:** graph, adjacency list, BFS · **Source:** Original

### Statement
In a social network (undirected graph), print for each person the number of people at distance exactly 2 (friends of friends who are not already friends or themselves).

### Input
n m, then m edges.

### Output
n counts.

### Constraints
- 1 ≤ n ≤ 1000, 0 ≤ m ≤ 5000

### Sample Input
```text
4 4
1 2
1 3
2 3
3 4
```

### Sample Output
```text
1 1 0 2
```

### Sample Explanation
Person 4's friend 3 knows 1 and 2.

### Target
O(n·(n + m)).

### Hints
1. Mark u and its friends first.
2. Then scan friends' friends and count unmarked ones (marking them as you go).

### Approach
A stamp array reset by a per-vertex timestamp.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    vector<int> stamp(n + 1, 0);
    for (int u = 1; u <= n; ++u) {
        stamp[u] = u;
        for (int v : adj[u]) stamp[v] = u;
        int count = 0;
        for (int v : adj[u])
            for (int w : adj[v])
                if (stamp[w] != u) { stamp[w] = u; ++count; }
        cout << count << (u < n ? ' ' : '\n');
    }
}
```

### Explanation
Using the vertex number as a stamp avoids clearing the marker array n times. This is a depth-2 BFS from every vertex.

### Edge Cases
- Isolated vertices: 0.

```

```
