# Master Theorem: Practice Problems

Divide-and-conquer programs and the recurrences that describe them. For each one, write T(n) = aT(n/b) + f(n) and predict the cost before coding.

## DSA06-E01 · Which Case?
**Difficulty:** Easy · **Subtopic:** Applying the three cases · **Tags:** master theorem, recurrences, exact arithmetic · **Source:** Original

### Statement
For T(n) = aT(n/b) + n^d with integers a ≥ 1, b ≥ 2, d ≥ 0, print the Master Theorem case: 1 if a > b^d, 2 if a = b^d, 3 if a < b^d. Compare exactly with integers, not logarithms.

### Input
T, then T lines a b d.

### Output
The case number for each line.

### Constraints
- 1 ≤ T ≤ 10^4
- 1 ≤ a ≤ 10^9, 2 ≤ b ≤ 10, 0 ≤ d ≤ 10

### Sample Input
```text
4
2 2 1
8 2 2
2 2 2
1 2 0
```

### Sample Output
```text
2
1
3
2
```

### Sample Explanation
Merge sort (2, 2, 1): a = b^d → case 2, Θ(n log n). (8, 2, 2): 8 > 4 → case 1, Θ(n³).

### Target
O(d) per line.

### Hints
1. log_b a compared with d is the same as a compared with b^d.
2. b^d ≤ 10^10 fits in `long long`.

### Approach
Compute b^d by repeated multiplication and compare with a.

### Solution
```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        long long a, b, d;
        cin >> a >> b >> d;
        long long p = 1;
        for (long long i = 0; i < d; ++i) p *= b;      // b^d, at most 1e10
        cout << (a > p ? 1 : a == p ? 2 : 3) << '\n';
    }
}
```

### Explanation
With f(n) = n^d, case 1 needs d < log_b a (a > b^d), case 2 needs d = log_b a, case 3 needs d > log_b a; regularity a(n/b)^d ≤ k n^d holds with k = a/b^d < 1 in case 3.

### Edge Cases
- d = 0 (constant work).
- a = 1 (single subproblem).

### Tests
#### Karatsuba
```text
1
3 2 1
```
```text
1
```

## DSA06-E02 · Fast Power with Call Count
**Difficulty:** Easy · **Subtopic:** T(n) = T(n/2) + 1 · **Tags:** divide and conquer, recursion, modular arithmetic · **Source:** Original

### Statement
Compute a^e mod 10^9 + 7 with the recursion power(e) = power(e/2)² (times a if e is odd), power(0) = 1, and print the number of calls made.

### Input
a and e.

### Output
a^e mod 10^9 + 7 and the number of calls.

### Constraints
- 0 ≤ a ≤ 10^9, 0 ≤ e ≤ 10^18

### Sample Input
```text
2 10
```

### Sample Output
```text
1024 5
```

### Sample Explanation
Calls for e = 10, 5, 2, 1, 0: five calls.

### Target
O(log e).

### Hints
1. One recursive call on e/2, constant extra work: case 2 with a = 1, b = 2, d = 0.
2. Count calls with a global counter.

### Approach
Recursive square-and-multiply with a counter.

### Solution
```cpp
#include <iostream>
using namespace std;

const long long MOD = 1000000007;
long long calls = 0;

long long power(long long a, long long e) {
    ++calls;
    if (e == 0) return 1;
    long long half = power(a, e / 2);
    long long r = half * half % MOD;
    return e % 2 ? r * a % MOD : r;
}

int main() {
    long long a, e;
    cin >> a >> e;
    long long r = power(a % MOD, e);
    cout << r << ' ' << calls << '\n';
}
```

### Explanation
T(e) = T(e/2) + O(1) = Θ(log e): the number of calls is ⌊log₂ e⌋ + 2 for e ≥ 1.

### Edge Cases
- e = 0: one call, result 1.
- a = 0.

### Tests
#### Huge exponent
```text
3 1000000000000000000
```
```text
246336683 61
```

## DSA06-E03 · Divide-and-Conquer Maximum
**Difficulty:** Easy · **Subtopic:** T(n) = 2T(n/2) + 1 · **Tags:** divide and conquer, recursion, maximum · **Source:** Original

### Statement
Find the maximum of an array by splitting it in half recursively. Print the maximum and the number of recursive calls.

### Input
n, then n integers.

### Output
Maximum and call count.

### Constraints
- 1 ≤ n ≤ 2·10^5
- |aᵢ| ≤ 10^9

### Sample Input
```text
5
3 9 2 7 4
```

### Sample Output
```text
9 9
```

### Sample Explanation
A recursion tree with n leaves has 2n − 1 nodes: 9 calls.

### Target
Θ(n) time, Θ(log n) stack.

### Hints
1. a = 2, b = 2, f = O(1): case 1 gives Θ(n).
2. Base case: one element.

### Approach
`best(lo, hi)` returns a[lo] if lo == hi, else the larger of both halves.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<long long> a;
long long calls = 0;

long long best(int lo, int hi) {
    ++calls;
    if (lo == hi) return a[lo];
    int mid = lo + (hi - lo) / 2;
    return max(best(lo, mid), best(mid + 1, hi));
}

int main() {
    int n;
    cin >> n;
    a.resize(n);
    for (auto& x : a) cin >> x;
    long long m = best(0, n - 1);
    cout << m << ' ' << calls << '\n';
}
```

### Explanation
The leaves (n of them) dominate: case 1, Θ(n^(log₂ 2)) = Θ(n). Exactly 2n − 1 calls.

### Edge Cases
- n = 1: one call.

### Tests
#### Single
```text
1
-4
```
```text

```

## DSA06-E04 · The Combine Step: Merging
**Difficulty:** Easy · **Subtopic:** f(n) of merge sort · **Tags:** merging, two pointers, linear time · **Source:** Original

### Statement
Merge two sorted arrays into one sorted array in linear time.

### Input
n and the first array; m and the second array.

### Output
The merged array.

### Constraints
- 1 ≤ n, m ≤ 2·10^5
- both arrays sorted non-decreasingly, |values| ≤ 10^9

### Sample Input
```text
3
1 4 9
4
2 3 9 10
```

### Sample Output
```text
1 2 3 4 9 9 10
```

### Sample Explanation
Take the smaller front element each time.

### Target
O(n + m).

### Hints
1. Two indices, one per array.
2. Copy the leftovers when one array runs out.

### Approach
Standard merge.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    cin >> m;
    vector<long long> b(m);
    for (auto& x : b) cin >> x;
    vector<long long> out;
    out.reserve(n + m);
    int i = 0, j = 0;
    while (i < n && j < m) out.push_back(b[j] < a[i] ? b[j++] : a[i++]);   // ties from a: stable
    while (i < n) out.push_back(a[i++]);
    while (j < m) out.push_back(b[j++]);
    for (size_t k = 0; k < out.size(); ++k) cout << out[k] << (k + 1 < out.size() ? ' ' : '\n');
}
```

### Explanation
Each step outputs one element, so the merge is Θ(n + m): this is the f(n) = Θ(n) of merge sort's recurrence.

### Edge Cases
- One array entirely smaller.
- Equal values.

### Tests
#### Disjoint ranges
```text
2
1 2
2
3 4
```
```text
1 2 3 4
```

## DSA06-E05 · Counting the Recursion Tree
**Difficulty:** Easy · **Subtopic:** Leaves and levels · **Tags:** recursion tree, master theorem, counting · **Source:** Original

### Statement
For T(n) = aT(n/b) + f(n) with n = b^k, print the number of levels (k + 1), the number of leaves (a^k) and the total number of nodes (1 + a + … + a^k).

### Input
a, b and k.

### Output
Three numbers.

### Constraints
- 1 ≤ a ≤ 10, 2 ≤ b ≤ 10, 0 ≤ k ≤ 15

### Sample Input
```text
2 2 3
```

### Sample Output
```text
4 8 15
```

### Sample Explanation
n = 8: levels with 1, 2, 4, 8 nodes.

### Target
O(k).

### Hints
1. Level i has a^i nodes.
2. a^k = (b^k)^(log_b a) = n^(log_b a): the leaf count.

### Approach
Loop over levels.

### Solution
```cpp
#include <iostream>
using namespace std;

int main() {
    long long a, b, k;
    cin >> a >> b >> k;
    (void)b;                              // b only fixes n = b^k; the counts depend on a and k
    long long levelNodes = 1, total = 0;
    for (long long i = 0; i <= k; ++i) {
        total += levelNodes;
        if (i < k) levelNodes *= a;
    }
    cout << k + 1 << ' ' << levelNodes << ' ' << total << '\n';
}
```

### Explanation
The leaves number a^(log_b n) = n^(log_b a), the watershed function of the theorem. With a ≤ 10 and k ≤ 15 everything fits in `long long`.

### Edge Cases
- k = 0: one node.
- a = 1: a path.

### Tests
#### Single subproblem
```text

```


## DSA06-M01 · Counting Inversions
**Difficulty:** Medium · **Subtopic:** Merge sort, case 2 · **Tags:** merge sort, divide and conquer, counting · **Source:** Original

### Statement
Count pairs i < j with aᵢ > aⱼ. Brute force is O(n²); merge sort counts them in O(n log n).

### Input
n, then n integers.

### Output
The number of inversions.

### Constraints
- 1 ≤ n ≤ 2·10^5
- |aᵢ| ≤ 10^9

### Sample Input
```text
5
2 4 1 3 5
```

### Sample Output
```text
3
```

### Sample Explanation
(2,1), (4,1), (4,3).

### Target
O(n log n): T(n) = 2T(n/2) + Θ(n).

### Hints
1. Inversions = left-half inversions + right-half inversions + split inversions.
2. While merging, when an element of the right half is taken, every remaining left element is greater: add their count.

### Approach
Merge sort with a counter added during merging.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<long long> a, buf;

long long sortCount(int lo, int hi) {         // a[lo, hi)
    if (hi - lo < 2) return 0;
    int mid = lo + (hi - lo) / 2;
    long long inv = sortCount(lo, mid) + sortCount(mid, hi);
    int i = lo, j = mid, k = lo;
    while (i < mid && j < hi) {
        if (a[j] < a[i]) { inv += mid - i; buf[k++] = a[j++]; }   // a[i..mid-1] all > a[j]
        else buf[k++] = a[i++];
    }
    while (i < mid) buf[k++] = a[i++];
    while (j < hi) buf[k++] = a[j++];
    for (k = lo; k < hi; ++k) a[k] = buf[k];
    return inv;
}

int main() {
    int n;
    cin >> n;
    a.resize(n);
    buf.resize(n);
    for (auto& x : a) cin >> x;
    cout << sortCount(0, n) << '\n';
}
```

### Explanation
Merging costs Θ(n) and counting adds O(1) per step, so the recurrence is merge sort's: Θ(n log n). The count reaches n(n−1)/2 ≈ 2·10^10.

### Edge Cases
- Sorted: 0. Reversed: n(n−1)/2.
- Equal values are not inversions.

### Tests
#### Reversed
```text
5
5 4 3 2 1
```
```text
10
```

## DSA06-M02 · Peak Finding
**Difficulty:** Medium · **Subtopic:** T(n) = T(n/2) + 1 · **Tags:** binary search, divide and conquer · **Source:** Original

### Statement
An array has distinct values and a[−1] = a[n] = −∞. Find the index of any peak (an element larger than its neighbours). To make the answer unique, use this rule: lo = 0, hi = n − 1; while lo < hi, mid = (lo + hi)/2; if a[mid] < a[mid + 1] then lo = mid + 1 else hi = mid. Print lo.

### Input
n, then n distinct integers.

### Output
The peak index found by the rule.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
7
1 3 20 4 1 0 5
```

### Sample Output
```text
2
```

### Sample Explanation
mid = 3: 4 > 1 → hi = 3; mid = 1: 3 < 20 → lo = 2; mid = 2: 20 > 4 → hi = 2.

### Target
O(log n).

### Hints
1. If a[mid] < a[mid+1], a peak exists to the right (the values cannot rise forever).
2. Otherwise a peak exists in [lo, mid].

### Approach
Binary search following the rising slope.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    int lo = 0, hi = n - 1;                 // invariant: a peak lies in [lo, hi]
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < a[mid + 1]) lo = mid + 1;
        else hi = mid;
    }
    cout << lo << '\n';
}
```

### Explanation
The invariant holds because moving towards a larger neighbour never loses all peaks. T(n) = T(n/2) + O(1) = Θ(log n) without looking at most elements.

### Edge Cases
- n = 1.
- Strictly increasing array: the last index.

### Tests
#### Increasing
```text
4
1 2 3 4
```
```text
3
```

## DSA06-M03 · Level Costs of a Recursion Tree
**Difficulty:** Medium · **Subtopic:** Why the three cases exist · **Tags:** recursion tree, master theorem, geometric series · **Source:** Original

### Statement
For T(n) = aT(n/b) + n^d with n = b^k, level i has a^i nodes each costing (n/b^i)^d. Print the cost of every level, then which part dominates: `leaves`, `balanced` or `root`.

### Input
a, b, d and k.

### Output
k + 1 level costs on one line, then the verdict.

### Constraints
- 1 ≤ a ≤ 8, 2 ≤ b ≤ 4, 0 ≤ d ≤ 3, 0 ≤ k ≤ 8

### Sample Input
```text
2 2 2 3
```

### Sample Output
```text
64 32 16 8
root
```

### Sample Explanation
n = 8, f = n²: level costs 64, 2·16, 4·4, 8·1 shrink geometrically, so the root dominates (case 3, Θ(n²)).

### Target
O(k·d).

### Hints
1. Level i costs a^i · (b^(k−i))^d.
2. The ratio between levels is a / b^d.

### Approach
Compute each level with integer powers, then compare a with b^d.

### Solution
```cpp
#include <iostream>
using namespace std;

long long ipow(long long x, long long e) {
    long long r = 1;
    while (e-- > 0) r *= x;
    return r;
}

int main() {
    long long a, b, d, k;
    cin >> a >> b >> d >> k;
    for (long long i = 0; i <= k; ++i)
        cout << ipow(a, i) * ipow(ipow(b, k - i), d) << (i < k ? ' ' : '\n');
    long long bd = ipow(b, d);
    cout << (a > bd ? "leaves" : a == bd ? "balanced" : "root") << '\n';
}
```

### Explanation
The level costs form a geometric series with ratio a/b^d: growing (case 1, leaves), constant (case 2, ×log n), or shrinking (case 3, root). That is the whole Master Theorem.

### Edge Cases
- k = 0: one level.
- a = b^d: all levels equal.

### Tests
#### Merge sort
```text
2 2 1 3
```
```text
8 8 8 8
balanced
```

## DSA06-M04 · Fibonacci by Fast Doubling
**Difficulty:** Medium · **Subtopic:** Logarithmic divide and conquer · **Tags:** divide and conquer, recursion, modular arithmetic · **Source:** Original

### Statement
Print F(n) mod 10^9 + 7 for n up to 10^18 (F(0) = 0, F(1) = 1).

### Input
One integer n.

### Output
F(n) mod 10^9 + 7.

### Constraints
- 0 ≤ n ≤ 10^18

### Sample Input
```text
10
```

### Sample Output
```text
55
```

### Sample Explanation
F(10) = 55.

### Target
O(log n).

### Hints
1. F(2k) = F(k)·(2F(k+1) − F(k)), F(2k+1) = F(k)² + F(k+1)².
2. Compute the pair (F(k), F(k+1)) recursively from k = n/2.

### Approach
Fast doubling: T(n) = T(n/2) + O(1).

### Solution
```cpp
#include <iostream>
#include <utility>
using namespace std;

const long long MOD = 1000000007;

pair<long long, long long> fib(long long n) {       // returns (F(n), F(n+1))
    if (n == 0) return {0, 1};
    auto [f, g] = fib(n / 2);                       // F(k), F(k+1) with k = n/2
    long long c = f * ((2 * g - f + MOD) % MOD) % MOD;   // F(2k)
    long long d = (f * f + g * g) % MOD;                 // F(2k+1)
    return n % 2 ? make_pair(d, (c + d) % MOD) : make_pair(c, d);
}

int main() {
    long long n;
    cin >> n;
    cout << fib(n).first << '\n';
}
```

### Explanation
One recursive call on n/2 and constant work: case 2 with a = 1, Θ(log n), about 60 levels for 10^18.

### Edge Cases
- n = 0 and n = 1.

### Tests
#### Thousand
```text

```

## DSA06-H01 · Closest Pair of Points
**Difficulty:** Hard · **Subtopic:** T(n) = 2T(n/2) + O(n log n) or O(n) · **Tags:** divide and conquer, geometry, sorting · **Source:** Original

### Statement
Given n points with integer coordinates, print the smallest squared Euclidean distance between two different points.

### Input
n, then n lines x y.

### Output
The minimum squared distance.

### Constraints
- 2 ≤ n ≤ 10^5
- |x|, |y| ≤ 10^9

### Sample Input
```text
5
0 0
5 5
1 2
10 10
3 1
```

### Sample Output
```text
5
```

### Sample Explanation
(0,0)–(1,2) and (1,2)–(3,1) are both √5 apart.

### Target
O(n log n).

### Hints
1. Sort by x, split at the median, solve both halves, let δ be the smaller answer.
2. Only points within δ of the dividing line can do better; sort that strip by y.
3. Each strip point needs to be compared with only a constant number of following points.

### Approach
Classic recursion with a merge by y (like merge sort) so each level is O(n): T(n) = 2T(n/2) + O(n) = O(n log n).

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

using Point = pair<long long, long long>;
vector<Point> p, buf;
long long best = -1;

long long dist2(const Point& a, const Point& b) {
    long long dx = a.first - b.first, dy = a.second - b.second;
    return dx * dx + dy * dy;
}

void solve(int lo, int hi) {                       // p[lo, hi) sorted by x; on return sorted by y
    if (hi - lo <= 3) {
        for (int i = lo; i < hi; ++i)
            for (int j = i + 1; j < hi; ++j) {
                long long d = dist2(p[i], p[j]);
                if (best < 0 || d < best) best = d;
            }
        sort(p.begin() + lo, p.begin() + hi, [](const Point& a, const Point& b) { return a.second < b.second; });
        return;
    }
    int mid = lo + (hi - lo) / 2;
    long long midX = p[mid].first;
    solve(lo, mid);
    solve(mid, hi);
    merge(p.begin() + lo, p.begin() + mid, p.begin() + mid, p.begin() + hi, buf.begin() + lo,
          [](const Point& a, const Point& b) { return a.second < b.second; });
    copy(buf.begin() + lo, buf.begin() + hi, p.begin() + lo);
    vector<Point> strip;
    for (int i = lo; i < hi; ++i) {
        long long dx = p[i].first - midX;
        if (dx * dx < best) {
            for (int j = static_cast<int>(strip.size()) - 1; j >= 0; --j) {
                long long dy = p[i].second - strip[j].second;
                if (dy * dy >= best) break;           // later strip points are even farther in y
                best = min(best, dist2(p[i], strip[j]));
            }
            strip.push_back(p[i]);
        }
    }
}

int main() {
    int n;
    cin >> n;
    p.resize(n);
    buf.resize(n);
    for (auto& [x, y] : p) cin >> x >> y;
    sort(p.begin(), p.end());
    solve(0, n);
    cout << best << '\n';
}
```

### Explanation
The strip loop stops as soon as the vertical gap reaches δ, and a packing argument shows only a constant number of points can lie in a δ × 2δ box, so each level does O(n) work. Squared distances up to 8·10^18 fit in `long long`.

### Edge Cases
- Duplicate points: distance 0.
- All points on one vertical line.

### Tests
#### Duplicates
```text
3
1 1
7 7
1 1
```
```text
0
```

## DSA06-H02 · Karatsuba Multiplication
**Difficulty:** Hard · **Subtopic:** T(n) = 3T(n/2) + O(n) · **Tags:** divide and conquer, big integers, master theorem · **Source:** Original

### Statement
Multiply two non-negative integers given as decimal strings (up to 20 000 digits) using Karatsuba's algorithm.

### Input
Two lines, each a non-negative integer without leading zeros (or `0`).

### Output
Their product.

### Constraints
- 1 ≤ digits ≤ 20000

### Sample Input
```text
12345678901234567890
98765432109876543210
```

### Sample Output
```text
1219326311370217952237463801111263526900
```

### Sample Explanation
The exact product.

### Target
O(n^log₂3) ≈ O(n^1.585).

### Hints
1. Split x = x₁·B + x₀ and y = y₁·B + y₀. Then xy = z₂B² + z₁B + z₀ with z₂ = x₁y₁, z₀ = x₀y₀, z₁ = (x₁ + x₀)(y₁ + y₀) − z₂ − z₀.
2. Three half-size products instead of four: a = 3, b = 2, f = Θ(n), case 1.
3. Work on digit vectors (little-endian) and use schoolbook multiplication below about 32 digits; normalise carries at the end.

### Approach
Recursive Karatsuba on vectors of digits (coefficients may grow; carry once at the end).

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;
using Poly = vector<long long>;

Poly naiveMul(const Poly& a, const Poly& b) {
    Poly r(a.size() + b.size(), 0);
    for (size_t i = 0; i < a.size(); ++i)
        for (size_t j = 0; j < b.size(); ++j) r[i + j] += a[i] * b[j];
    return r;
}

Poly karatsuba(const Poly& a, const Poly& b) {          // a.size() == b.size()
    size_t n = a.size();
    if (n <= 32) return naiveMul(a, b);
    size_t h = n / 2;
    Poly a0(a.begin(), a.begin() + h), a1(a.begin() + h, a.end());
    Poly b0(b.begin(), b.begin() + h), b1(b.begin() + h, b.end());
    Poly z0 = karatsuba(a0, b0), z2 = karatsuba(a1, b1);
    Poly as(a1), bs(b1);
    for (size_t i = 0; i < h; ++i) { as[i] += a0[i]; bs[i] += b0[i]; }
    Poly z1 = karatsuba(as, bs);
    for (size_t i = 0; i < z1.size(); ++i) {
        if (i < z0.size()) z1[i] -= z0[i];
        if (i < z2.size()) z1[i] -= z2[i];
    }
    Poly r(2 * n, 0);
    for (size_t i = 0; i < z0.size(); ++i) r[i] += z0[i];
    for (size_t i = 0; i < z1.size() && i + h < r.size(); ++i) r[i + h] += z1[i];
    for (size_t i = 0; i < z2.size() && i + 2 * h < r.size(); ++i) r[i + 2 * h] += z2[i];
    return r;
}

int main() {
    string x, y;
    cin >> x >> y;
    size_t n = max(x.size(), y.size());
    Poly a(n, 0), b(n, 0);
    for (size_t i = 0; i < x.size(); ++i) a[i] = x[x.size() - 1 - i] - '0';
    for (size_t i = 0; i < y.size(); ++i) b[i] = y[y.size() - 1 - i] - '0';
    Poly r = karatsuba(a, b);
    long long carry = 0;
    for (auto& d : r) { d += carry; carry = d / 10; d %= 10; }
    while (carry) { r.push_back(carry % 10); carry /= 10; }
    while (r.size() > 1 && r.back() == 0) r.pop_back();
    for (size_t i = r.size(); i-- > 0;) cout << r[i];
    cout << '\n';
}
```

### Explanation
Three recursive products give a = 3, b = 2, f(n) = Θ(n): case 1, Θ(n^1.585), versus Θ(n²) for schoolbook. Coefficients stay small enough for `long long` (sums of at most 20 000 products of values below about 10^4).

### Edge Cases
- Zero factor.
- Different lengths (padded with zeros).

## DSA06-H03 · Reverse Pairs
**Difficulty:** Hard · **Subtopic:** Augmented merge sort · **Tags:** merge sort, divide and conquer, two pointers · **Source:** Original

### Statement
Count pairs i < j with aᵢ > 2·aⱼ.

### Input
n, then n integers.

### Output
The number of such pairs.

### Constraints
- 1 ≤ n ≤ 2·10^5
- |aᵢ| ≤ 10^9

### Sample Input
```text
5
1 3 2 3 1
```

### Sample Output
```text
2
```

### Sample Explanation
(3, 1) at positions (1, 4) and (3, 4).

### Target
O(n log n).

### Hints
1. Before merging two sorted halves, count split pairs with a separate two-pointer pass.
2. For each left element, the right elements with 2·aⱼ < aᵢ form a prefix that only grows.

### Approach
Merge sort; count with a monotone pointer, then merge normally.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<long long> a;

long long solve(int lo, int hi) {                    // a[lo, hi)
    if (hi - lo < 2) return 0;
    int mid = lo + (hi - lo) / 2;
    long long count = solve(lo, mid) + solve(mid, hi);
    int j = mid;
    for (int i = lo; i < mid; ++i) {                 // both halves sorted
        while (j < hi && a[i] > 2 * a[j]) ++j;
        count += j - mid;
    }
    inplace_merge(a.begin() + lo, a.begin() + mid, a.begin() + hi);
    return count;
}

int main() {
    int n;
    cin >> n;
    a.resize(n);
    for (auto& x : a) cin >> x;
    cout << solve(0, n) << '\n';
}
```

### Explanation
The counting pass is O(n) per level (j only moves forward), and so is the merge: T(n) = 2T(n/2) + Θ(n) = Θ(n log n). 2·aⱼ fits in `long long`.

### Edge Cases
- Negative values (2·aⱼ can be smaller than aⱼ).
- No pairs.


## DSA06-H04 · K-th Element of Two Sorted Arrays
**Difficulty:** Hard · **Subtopic:** Logarithmic divide and conquer · **Tags:** divide and conquer, binary search, sorted arrays · **Source:** Original

### Statement
Two sorted arrays A and B are given. For each query k, print the k-th smallest element (1-based) of their union (with duplicates), in O(log(n + m)) without merging.

### Input
n and A; m and B; q, then q values of k.

### Output
One value per query.

### Constraints
- 1 ≤ n, m ≤ 2·10^5, 1 ≤ q ≤ 10^5
- 1 ≤ k ≤ n + m

### Sample Input
```text
3
1 5 9
4
2 3 6 10
3
1
4
7
```

### Sample Output
```text
1
5
10
```

### Sample Explanation
The union is 1 2 3 5 6 9 10.

### Target
O(log(n + m)) per query.

### Hints
1. Compare A[i + k/2 − 1] and B[j + k/2 − 1]; the smaller half-block cannot contain the k-th element.
2. Discard it and look for the (k − discarded)-th element: T(k) = T(k/2) + O(1).

### Approach
Iterative version with offsets i, j into A and B.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n;
    vector<long long> A(n);
    for (auto& x : A) cin >> x;
    cin >> m;
    vector<long long> B(m);
    for (auto& x : B) cin >> x;
    int q;
    cin >> q;
    while (q--) {
        long long k;
        cin >> k;
        long long i = 0, j = 0;                     // A[0..i-1], B[0..j-1] discarded
        long long answer;
        for (;;) {
            if (i == n) { answer = B[j + k - 1]; break; }
            if (j == m) { answer = A[i + k - 1]; break; }
            if (k == 1) { answer = min(A[i], B[j]); break; }
            long long step = k / 2;
            long long ia = min<long long>(i + step, n) - 1, jb = min<long long>(j + step, m) - 1;
            if (A[ia] <= B[jb]) { k -= ia - i + 1; i = ia + 1; }   // these cannot be the k-th
            else { k -= jb - j + 1; j = jb + 1; }
        }
        cout << answer << '\n';
    }
}
```

### Explanation
Each step discards about k/2 elements that are all among the smallest k − 1, so the k-th element survives; k halves each time: O(log k).

### Edge Cases
- k = 1 or k = n + m.
- One array exhausted early.

### Tests
#### Ends
```text
1
5
1
3
2
1
2
```
```text

5
```

## DSA06-H05 · Merge k Sorted Lists by Pairing
**Difficulty:** Hard · **Subtopic:** Divide and conquer over k · **Tags:** divide and conquer, merging, recursion · **Source:** Original

### Statement
Merge k sorted lists into one sorted list by divide and conquer: merge the first half of the lists and the second half recursively, then merge the two results. Total length N.

### Input
k; then k lines, each starting with its length followed by the sorted values.

### Output
The merged list (print `EMPTY` if N = 0).

### Constraints
- 1 ≤ k ≤ 10^4, 0 ≤ N ≤ 2·10^5

### Sample Input
```text
3
3 1 4 7
2 2 9
0
```

### Sample Output
```text
1 2 4 7 9
```

### Sample Explanation
The empty list contributes nothing.

### Target
O(N log k).

### Hints
1. Merging one by one costs O(N·k) in the worst case.
2. Pairwise merging has log₂ k levels, each touching every element once.

### Approach
Recursive `mergeRange(lo, hi)` over the list indices.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <vector>
using namespace std;

vector<vector<long long>> lists;

vector<long long> mergeRange(int lo, int hi) {          // lists[lo, hi)
    if (hi - lo == 1) return lists[lo];
    int mid = lo + (hi - lo) / 2;
    vector<long long> left = mergeRange(lo, mid), right = mergeRange(mid, hi), out;
    out.reserve(left.size() + right.size());
    merge(left.begin(), left.end(), right.begin(), right.end(), back_inserter(out));
    return out;
}

int main() {
    int k;
    cin >> k;
    lists.resize(k);
    for (auto& l : lists) {
        int len;
        cin >> len;
        l.resize(len);
        for (auto& x : l) cin >> x;
    }
    vector<long long> all = mergeRange(0, k);
    if (all.empty()) cout << "EMPTY\n";
    for (size_t i = 0; i < all.size(); ++i) cout << all[i] << (i + 1 < all.size() ? ' ' : '\n');
}
```

### Explanation
The recursion over lists has depth ⌈log₂ k⌉ and each level merges a total of N elements: O(N log k). A min-heap of list heads achieves the same bound (Module 14).

### Edge Cases
- All lists empty.
- k = 1.

