# Sets and Union-Find: Practice Problems

Ordinary set operations (membership, union, intersection, difference) and Disjoint Set Union (find/union on a partition) are different tools; each problem says which it needs. DSU solutions use path compression and union by size.

## DSA17-E01 · Union and Same-Group Queries
**Difficulty:** Easy · **Subtopic:** DSU basics · **Tags:** union-find, DSU, connectivity · **Source:** Original

### Statement
n people start in their own groups. Process `union a b` and `same a b` (print `YES` or `NO`).

### Input
n and q, then q operations.

### Output
One line per `same`.

### Constraints
- 1 ≤ n, q ≤ 2·10^5

### Sample Input
```text
5 5
union 1 2
same 1 2
same 1 3
union 2 3
same 1 3
```

### Sample Output
```text
YES
NO
YES
```

### Sample Explanation
After the second union 1, 2, 3 share a group.

### Target
O(α(n)) amortised per operation.

### Hints
1. find follows parents to the root; compress the path on the way.
2. union links the smaller tree under the larger root.

### Approach
Standard DSU.

### Solution
```cpp
#include <iostream>
#include <numeric>
#include <string>
#include <utility>
#include <vector>
using namespace std;

vector<int> parent, sz;

int find(int x) {
    while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }   // path halving
    return x;
}

void unite(int a, int b) {
    a = find(a); b = find(b);
    if (a == b) return;
    if (sz[a] < sz[b]) swap(a, b);
    parent[b] = a;
    sz[a] += sz[b];
}

int main() {
    int n, q;
    cin >> n >> q;
    parent.resize(n + 1);
    sz.assign(n + 1, 1);
    iota(parent.begin(), parent.end(), 0);
    while (q--) {
        string op;
        int a, b;
        cin >> op >> a >> b;
        if (op == "union") unite(a, b);
        else cout << (find(a) == find(b) ? "YES" : "NO") << '\n';
    }
}
```

### Explanation
Union by size keeps trees shallow and path halving flattens them further: nearly constant amortised time.

### Edge Cases
- Union of already-joined people.

### Tests
#### Self
```text
2 1
same 1 1
```
```text
YES
```

Process `insert x`, `erase x`, `has x` (print `yes`/`no`) and `size` on a set of integers.

### Constraints

### Sample Input

```text
insert 5

size

```

### Sample Output
```text

```

### Sample Explanation

### Target

### Hints

2. Erasing a missing element is harmless.

### Approach
`std::unordered_set`.

### Solution
```cpp
#include <iostream>
#include <string>
#include <unordered_set>
using namespace std;

int main() {
    int q;
    cin >> q;
    unordered_set<long long> s;
    while (q--) {
        string op;
        cin >> op;
        if (op == "size") { cout << s.size() << '\n'; continue; }
        long long x;
        cin >> x;
        if (op == "insert") s.insert(x);
        else if (op == "erase") s.erase(x);
        else cout << (s.count(x) ? "yes" : "no") << '\n';
    }
}
```

### Explanation

## DSA17-E03 · Intersection of Two Lists
**Difficulty:** Easy · **Subtopic:** Intersection with hashing · **Tags:** set, intersection, hashing · **Source:** Original

### Statement
Print the distinct values present in both lists, in increasing order (or `EMPTY`).

### Input
n and A; m and B.

### Output
The intersection.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
3
4 9 5
5
9 4 9 8 4
```

### Sample Output
```text
4 9
```

### Sample Explanation
4 and 9 appear in both.

### Target
O(n + m) expected plus sorting the answer.

### Hints
1. Put A in a hash set.
2. Collect B's values found in it, removing them to avoid duplicates.

### Approach
Hash set lookup, then sort the (small) result.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <unordered_set>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n;
    unordered_set<long long> a;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; a.insert(x); }
    cin >> m;
    vector<long long> both;
    for (int i = 0; i < m; ++i) {
        long long x;
        cin >> x;
        if (a.erase(x)) both.push_back(x);       // erase returns 1 the first time only
    }
    sort(both.begin(), both.end());
    if (both.empty()) cout << "EMPTY\n";
    for (size_t i = 0; i < both.size(); ++i) cout << both[i] << (i + 1 < both.size() ? ' ' : '\n');
}
```

### Explanation
Erasing on success both records membership and prevents repeats.

### Edge Cases
- Disjoint lists.

### Tests
#### Disjoint
```text
1
1
1
2
```
```text
EMPTY
```

### Statement
Print the number of connected components of an undirected graph using DSU.

### Input
n m, then m edges.

### Output
The number of components.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
5 2
1 2
3 4
```

### Sample Output
```text
3
```

### Sample Explanation
{1, 2}, {3, 4}, {5}.

### Target
O((n + m) α(n)).

### Hints
1. Start with n components.
2. Each successful union reduces the count by one.

### Approach
DSU with a counter.

### Solution
```cpp
#include <iostream>
#include <numeric>
#include <utility>
#include <vector>
using namespace std;

vector<int> parent, sz;
int find(int x) { while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; } return x; }

int main() {
    int n, m;
    cin >> n >> m;
    parent.resize(n + 1);
    sz.assign(n + 1, 1);
    iota(parent.begin(), parent.end(), 0);

    for (int i = 0; i < m; ++i) {
        int a, b;
        cin >> a >> b;

        if (a == b) continue;
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        sz[a] += sz[b];
        --components;
    }
    cout << components << '\n';
}
```

### Explanation
DSU answers connectivity without building adjacency lists, and it works incrementally as edges arrive.

### Statement
Cables are added one by one between computers. Print the first cable (u v) that connects two computers already connected, or `NONE`.

### Input
n m, then m cables.

### Output
The redundant cable or `NONE`.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
3 3
1 2
1 3
2 3
```

### Sample Output
```text
2 3
```

### Sample Explanation
2 and 3 are already connected through 1.

### Target
O(m α(n)).

### Hints
1. If find(u) == find(v) before the union, the cable closes a cycle.
2. Stop at the first such cable; otherwise unite and continue.

### Approach
DSU, stop at the first failed union.

### Solution
```cpp
#include <iostream>
#include <numeric>
#include <utility>
#include <vector>
using namespace std;

vector<int> parent, sz;
int find(int x) { while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; } return x; }

    cin >> n >> m;
    parent.resize(n + 1);
    sz.assign(n + 1, 1);
    iota(parent.begin(), parent.end(), 0);
    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;
        int a = find(u), b = find(v);
        if (a == b) { cout << u << ' ' << v << '\n'; return 0; }
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        sz[a] += sz[b];

    cout << "NONE\n";
```

### Explanation

## DSA17-M03 · Group Sizes
**Difficulty:** Medium · **Subtopic:** DSU with sizes · **Tags:** union-find, sizes, sorting · **Source:** Original

### Statement
After processing friendship pairs, print all group sizes in decreasing order.

### Input
n m, then m pairs.

### Output
The group sizes.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
6 3
1 2
2 3
4 5
```

### Sample Output
```text
3 2 1
```

### Sample Explanation
{1,2,3}, {4,5}, {6}.

### Target
O(n log n).

### Hints
1. Keep sizes at the roots.
2. Collect the size of every root.

### Approach
DSU, then gather root sizes.

### Solution
```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <numeric>
#include <utility>
#include <vector>
using namespace std;

vector<int> parent, sz;
int find(int x) { while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; } return x; }

int main() {
    int n, m;
    cin >> n >> m;
    parent.resize(n + 1);
    sz.assign(n + 1, 1);
    iota(parent.begin(), parent.end(), 0);
    for (int i = 0; i < m; ++i) {
        int a, b;
        cin >> a >> b;
        a = find(a); b = find(b);
        if (a == b) continue;
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        sz[a] += sz[b];
    }
    vector<int> sizes;
    for (int v = 1; v <= n; ++v) if (find(v) == v) sizes.push_back(sz[v]);
    sort(sizes.begin(), sizes.end(), greater<int>());
    for (size_t i = 0; i < sizes.size(); ++i) cout << sizes[i] << (i + 1 < sizes.size() ? ' ' : '\n');
}
```

### Explanation
Only roots carry meaningful sizes; union by size updates them in O(1).

- Everyone separate: n ones.

#### Separate


## DSA17-H01 · Cheapest Network (Kruskal, extension)
**Difficulty:** Hard · **Subtopic:** Kruskal's algorithm (extension) · **Tags:** union-find, MST, greedy, sorting · **Source:** Original

### Statement
Connect n offices with cables of given costs at minimum total cost. Print the cost, or `IMPOSSIBLE` if they cannot all be connected. *Minimum spanning trees are an extension beyond the DSA I syllabus.*

### Input
n m, then m lines u v w.

### Output
The minimum cost or `IMPOSSIBLE`.

### Constraints
- 1 ≤ n ≤ 2·10^5, 0 ≤ m ≤ 2·10^5, 1 ≤ w ≤ 10^9

### Sample Input
```text
4 5
1 2 1
2 3 2
1 3 2
3 4 3
1 4 4
```

### Sample Output
```text
6
```

### Sample Explanation
Edges of cost 1, 2 and 3.

### Target
O(m log m).

### Hints
1. Sort edges by cost.
2. Take an edge if its endpoints are in different DSU sets.

### Approach
Kruskal with DSU.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <tuple>
#include <utility>
#include <vector>
using namespace std;

vector<int> parent, sz;
int find(int x) { while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; } return x; }

int main() {
    int n, m;
    cin >> n >> m;
    vector<tuple<long long, int, int>> e(m);
    for (auto& [w, u, v] : e) cin >> u >> v >> w;
    sort(e.begin(), e.end());
    parent.resize(n + 1);
    sz.assign(n + 1, 1);
    iota(parent.begin(), parent.end(), 0);
    long long cost = 0;
    int used = 0;
    for (auto [w, u, v] : e) {
        int a = find(u), b = find(v);
        if (a == b) continue;
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        sz[a] += sz[b];
        cost += w;
        ++used;
    }
    if (used == n - 1) cout << cost << '\n';
    else cout << "IMPOSSIBLE\n";
}
```

### Explanation
The cut property guarantees that the cheapest edge between two components is safe; DSU tells whether an edge joins two components.

### Edge Cases
- n = 1: cost 0.

### Tests
#### Disconnected
```text
3 1
1 2 5
```
```text
IMPOSSIBLE
```

```cpp
#include <iostream>
#include <numeric>
#include <string>
#include <vector>
using namespace std;
```

## DSA17-H03 · First Odd Cycle
**Difficulty:** Hard · **Subtopic:** DSU with parity · **Tags:** union-find, bipartite, parity · **Source:** Original

### Statement
Edges are added one by one. Print the (1-based) index of the first edge after which the graph is no longer bipartite, or 0.

### Input
n m, then m edges.

### Output
The index or 0.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
3 3
1 2
2 3
1 3
```

### Sample Output
```text
3
```

### Sample Explanation
The triangle is an odd cycle.

### Target
O(m α(n)).

### Hints
1. Store for each node the parity (colour difference) to its parent.
2. An edge inside one set with equal parities creates an odd cycle.

### Approach
DSU where find returns (root, parity) and union sets the parity so u and v differ.

### Solution
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

vector<int> parent, parity, sz;

pair<int, int> find(int x) {                    // (root, parity of x relative to root)
    int p = 0;
    vector<int> path;
    while (parent[x] != x) { path.push_back(x); p ^= parity[x]; x = parent[x]; }
    int acc = p;
    for (int v : path) {                         // compress: point straight at the root
        int next = acc ^ parity[v];
        parity[v] = acc;
        parent[v] = x;
        acc = next;
    }
    return {x, p};
}

int main() {
    int n, m;
    cin >> n >> m;
    parent.resize(n + 1);
    parity.assign(n + 1, 0);
    sz.assign(n + 1, 1);
    for (int i = 0; i <= n; ++i) parent[i] = i;
    for (int i = 1; i <= m; ++i) {
        int u, v;
        cin >> u >> v;
        auto [a, pu] = find(u);
        auto [b, pv] = find(v);
        if (a == b) {
            if (pu == pv) { cout << i << '\n'; return 0; }   // same colour, same component
            continue;
        }
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        parity[b] = pu ^ pv ^ 1;                        // make u and v different colours
        sz[a] += sz[b];
    }
    cout << 0 << '\n';
}
```

### Explanation
Parities along a path add modulo 2; an edge between equal parities closes an odd cycle. Path compression rewrites parities to be relative to the root directly.

### Edge Cases
- Even cycles never trigger.

## DSA17-H04 · Islands Appearing
**Difficulty:** Hard · **Subtopic:** Online grid connectivity · **Tags:** union-find, grid, incremental · **Source:** Original

### Statement
An R × C grid starts as water. Cells turn into land one at a time. After each, print the number of islands (4-directional).

### Input
R C k, then k cells r c (0-based, may repeat).

### Output
k counts.

### Constraints
- 1 ≤ R·C ≤ 10^6, 1 ≤ k ≤ 2·10^5

### Sample Input
```text
3 3 5
0 0
0 1
1 2
2 1
1 1
```

### Sample Output
```text
1 1 2 3 1
```

### Sample Explanation
(1,1) joins all three islands into one.

### Target
O(k α(RC)).

### Hints
1. A new land cell adds one island, then each union with a different neighbouring island removes one.
2. Ignore cells that are already land.

### Approach
DSU over cell indices r·C + c.

### Solution
```cpp
#include <iostream>
#include <numeric>
#include <utility>
#include <vector>
using namespace std;

vector<int> parent, sz;
int find(int x) { while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; } return x; }

int main() {
    int r, c, k;
    cin >> r >> c >> k;
    parent.resize(r * c);
    sz.assign(r * c, 1);
    iota(parent.begin(), parent.end(), 0);
    vector<char> land(r * c, 0);
    int islands = 0;
    const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    for (int i = 0; i < k; ++i) {
        int x, y;
        cin >> x >> y;
        int id = x * c + y;
        if (!land[id]) {
            land[id] = 1;
            ++islands;
            for (int d = 0; d < 4; ++d) {
                int nx = x + dr[d], ny = y + dc[d];
                if (nx < 0 || nx >= r || ny < 0 || ny >= c || !land[nx * c + ny]) continue;
                int a = find(id), b = find(nx * c + ny);
                if (a == b) continue;
                if (sz[a] < sz[b]) swap(a, b);
                parent[b] = a;
                sz[a] += sz[b];
                --islands;
            }
        }
        cout << islands << (i + 1 < k ? ' ' : '\n');
    }
}
```

### Explanation
Recomputing islands with BFS after each addition would cost O(RC) per step; DSU updates in near-constant time.

### Edge Cases
- Repeated cells change nothing.

### Tests
#### Repeat
```text
1 1 2
0 0
0 0
```
```text
1 1
```

## DSA17-H05 · Smallest Equivalent String
**Difficulty:** Hard · **Subtopic:** Equivalence classes with a chosen representative · **Tags:** union-find, strings, equivalence · **Source:** Original

### Statement
Strings s1 and s2 of equal length say that s1[i] and s2[i] are equivalent letters (equivalence is reflexive, symmetric, transitive). Replace every letter of base by the smallest letter equivalent to it.

### Input
s1, s2 and base.

### Output
The transformed base.

### Constraints
- 1 ≤ lengths ≤ 10^5, lowercase letters

### Sample Input
```text
parker morris parser
```

### Sample Output
```text
makkek
```

### Sample Explanation
Classes {m,p}, {a,o}, {k,r,s}, {e,i}: replace by m, a, k, e.

### Target
O(n α(26)).

### Hints
1. Union letters pairwise.
2. Always make the smaller letter the root, so the root is the representative.

### Approach
DSU on 26 letters with "smaller root wins".

### Solution
```cpp
#include <iostream>
#include <numeric>
#include <string>
#include <utility>
using namespace std;

int parent[26];
int find(int x) { while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; } return x; }

int main() {
    string s1, s2, base;
    cin >> s1 >> s2 >> base;
    iota(parent, parent + 26, 0);
    for (size_t i = 0; i < s1.size(); ++i) {
        int a = find(s1[i] - 'a'), b = find(s2[i] - 'a');
        if (a == b) continue;
        if (a > b) swap(a, b);
        parent[b] = a;                       // smaller letter becomes the root
    }
    for (char& ch : base) ch = static_cast<char>('a' + find(ch - 'a'));
    cout << base << '\n';
}
```

### Explanation
Here the union rule is chosen for the answer (smallest root) rather than balance; with only 26 elements depth is irrelevant.

### Edge Cases
- No equivalences touching base.

### Tests
#### Unrelated
```text
ab ba xyz
```
```text
xyz
```
