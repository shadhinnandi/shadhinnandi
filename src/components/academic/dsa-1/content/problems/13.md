# BFS and DFS: Practice Problems

Graphs are undirected with 1-based vertices unless stated. When an order matters, visit neighbours in increasing order. Prefer iterative DFS when the depth can reach 2·10^5.

## DSA13-E01 · BFS Order
**Difficulty:** Easy · **Subtopic:** Breadth-first search · **Tags:** BFS, queue, graph · **Source:** Original

### Statement
Print the order in which BFS from vertex 1 visits the vertices reachable from it.

### Input
n m, then m edges.

### Output
The BFS order.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
6 5
1 2
1 3
2 4
3 4
4 5
```

### Sample Output
```text
1 2 3 4 5
```

### Sample Explanation
Vertex 6 is unreachable.

### Target
O(n + m log m) (sorting neighbours).

### Hints
1. Mark a vertex when it is pushed.
2. Sort adjacency lists for a deterministic order.

### Approach
Queue-based BFS.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    for (auto& l : adj) sort(l.begin(), l.end());
    vector<char> seen(n + 1, 0);
    vector<int> order;
    queue<int> q;
    q.push(1);
    seen[1] = 1;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : adj[u]) if (!seen[v]) { seen[v] = 1; q.push(v); }
    }
    for (size_t i = 0; i < order.size(); ++i) cout << order[i] << (i + 1 < order.size() ? ' ' : '\n');
}
```

### Explanation
Vertices leave the queue in order of distance from 1; each vertex and edge is handled once.

### Edge Cases
- Isolated start vertex.

### Tests
#### Alone
```text
2 0
```
```text
1
```

## DSA13-E02 · DFS Order
**Difficulty:** Easy · **Subtopic:** Depth-first search · **Tags:** DFS, recursion, graph · **Source:** Original

### Statement
Print the order in which recursive DFS from vertex 1 first visits vertices.

### Input
n m, then m edges.

### Output
The DFS order.

### Constraints
- 1 ≤ n ≤ 2000, m ≤ 10^5

### Sample Input
```text
6 5
1 2
1 3
2 4
3 4
4 5
```

### Sample Output
```text
1 2 4 3 5
```

### Sample Explanation
From 4, DFS goes to 3 before backtracking to 5.

### Target
O(n + m).

### Hints
1. Visit, mark, then recurse into unvisited neighbours.
2. Depth is at most n = 2000 here, so recursion is safe.

### Approach
Recursive DFS with sorted neighbours.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<vector<int>> adj;
vector<char> seen;
vector<int> order;

void dfs(int u) {
    seen[u] = 1;
    order.push_back(u);
    for (int v : adj[u]) if (!seen[v]) dfs(v);
}

int main() {
    int n, m;
    cin >> n >> m;
    adj.resize(n + 1);
    seen.assign(n + 1, 0);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    for (auto& l : adj) sort(l.begin(), l.end());
    dfs(1);
    for (size_t i = 0; i < order.size(); ++i) cout << order[i] << (i + 1 < order.size() ? ' ' : '\n');
}
```

### Explanation
DFS explores as deep as possible before backtracking; the call stack holds the current path.

### Edge Cases
- Isolated start.

### Tests
#### Path
```text
3 2
3 2
2 1
```
```text
1 2 3
```

## DSA13-E03 · Connected Components
**Difficulty:** Easy · **Subtopic:** Disconnected graphs · **Tags:** BFS, components, graph · **Source:** Original

### Statement
Print the number of connected components.

### Input
n m, then m edges.

### Output
The number of components.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
6 5
1 2
1 3
2 4
3 4
4 5
```

### Sample Output
```text
2
```

### Sample Explanation
{1, 2, 3, 4, 5} and {6}.

### Target
O(n + m).

### Hints
1. Start a traversal from every unvisited vertex.
2. Count the starts.

### Approach
Repeated BFS.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    vector<char> seen(n + 1, 0);
    int components = 0;
    for (int s = 1; s <= n; ++s) {
        if (seen[s]) continue;
        ++components;
        queue<int> q;
        q.push(s);
        seen[s] = 1;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int v : adj[u]) if (!seen[v]) { seen[v] = 1; q.push(v); }
        }
    }
    cout << components << '\n';
}
```

### Explanation
Each traversal marks exactly one component; total work stays O(n + m).

### Edge Cases
- No edges: n components.

### Tests
#### No edges
```text
3 0
```
```text
3
```

## DSA13-E04 · Shortest Hops
**Difficulty:** Easy · **Subtopic:** Unweighted shortest paths · **Tags:** BFS, shortest path, graph · **Source:** Original

### Statement
Print the minimum number of edges from vertex 1 to every vertex (−1 if unreachable).

### Input
n m, then m edges.

### Output
n distances.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
6 5
1 2
1 3
2 4
3 4
4 5
```

### Sample Output
```text
0 1 1 2 3 -1
```

### Sample Explanation
5 is reached via 4.

### Target
O(n + m).

### Hints
1. dist[v] = dist[u] + 1 when v is discovered.
2. −1 doubles as "not visited".

### Approach
BFS from 1.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    vector<int> dist(n + 1, -1);
    queue<int> q;
    dist[1] = 0;
    q.push(1);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); }
    }
    for (int u = 1; u <= n; ++u) cout << dist[u] << (u < n ? ' ' : '\n');
}
```

### Explanation
BFS processes vertices in non-decreasing distance, so the first time a vertex is reached is along a shortest path.

### Edge Cases
- Unreachable vertices.

### Tests
#### Two vertices
```text
2 1
2 1
```

```text
0 1
```

## DSA13-E05 · Is There a Route?
**Difficulty:** Easy · **Subtopic:** Reachability · **Tags:** BFS, components, queries · **Source:** Original

### Statement
Answer q queries "can you travel from s to t?".

### Input
n m, edges; q, then q pairs.

### Output
`YES` or `NO` per query.

### Constraints
- 1 ≤ n, m, q ≤ 2·10^5

### Sample Input
```text
6 5
1 2
1 3
2 4
3 4
4 5
2
1 5
1 6
```

### Sample Output
```text
YES
NO
```

### Sample Explanation
6 is in another component.

### Target
O(n + m + q).

### Hints
1. Label every vertex with its component id once.
2. Same id means reachable.

### Approach
Component labelling, then O(1) queries.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    vector<int> comp(n + 1, 0);
    int id = 0;
    for (int s = 1; s <= n; ++s) {
        if (comp[s]) continue;
        comp[s] = ++id;
        queue<int> q;
        q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int v : adj[u]) if (!comp[v]) { comp[v] = id; q.push(v); }
        }
    }
    int q;
    cin >> q;
    while (q--) { int s, t; cin >> s >> t; cout << (comp[s] == comp[t] ? "YES" : "NO") << '\n'; }
}
```

### Explanation
Preprocessing once avoids a BFS per query.

### Edge Cases
- s = t.

### Tests
#### Same vertex
```text
2 0
1
2 2
```
```text
YES
```

## DSA13-M01 · Counting Islands
**Difficulty:** Medium · **Subtopic:** Flood fill · **Tags:** grid, flood fill, BFS · **Source:** Original

### Statement
In a grid of 1 (land) and 0 (water), count the islands (land cells connected up/down/left/right).

### Input
R C, then R rows of digits without spaces.

### Output
The number of islands.

### Constraints
- 1 ≤ R, C ≤ 1000

### Sample Input
```text
4 5
11000
11000
00100
00011
```

### Sample Output
```text
3
```

### Sample Explanation
A 2×2 island, a single cell, and a pair.

### Target
O(R·C).

### Hints
1. Each unvisited land cell starts a new flood fill.
2. Use an explicit queue to avoid deep recursion.

### Approach
BFS flood fill on the implicit grid graph.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <string>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int r, c;
    cin >> r >> c;
    vector<string> g(r);
    for (auto& row : g) cin >> row;
    int islands = 0;
    const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    for (int i = 0; i < r; ++i)
        for (int j = 0; j < c; ++j) {
            if (g[i][j] != '1') continue;
            ++islands;
            queue<pair<int, int>> q;
            q.push({i, j});
            g[i][j] = '0';                                  // mark by sinking the land
            while (!q.empty()) {
                auto [x, y] = q.front(); q.pop();
                for (int d = 0; d < 4; ++d) {
                    int nx = x + dr[d], ny = y + dc[d];
                    if (nx >= 0 && nx < r && ny >= 0 && ny < c && g[nx][ny] == '1') { g[nx][ny] = '0'; q.push({nx, ny}); }
                }
            }
        }
    cout << islands << '\n';
}
```

### Explanation
Counting islands is counting connected components of the grid graph.

### Edge Cases
- All water; one huge island.

### Tests
#### All land
```text
2 2
11
11
```
```text
1
```

## DSA13-M02 · Escape the Maze
**Difficulty:** Medium · **Subtopic:** BFS on grids · **Tags:** grid, BFS, shortest path · **Source:** Original

### Statement
In a maze with walls `#`, open cells `.`, a start `S` and an exit `E`, print the minimum number of moves (up/down/left/right) from S to E, or −1.

### Input
R C, then the maze.

### Output
The minimum moves or −1.

### Constraints
- 1 ≤ R, C ≤ 1000

### Sample Input
```text
3 3
S#.
...
#.E
```

### Sample Output
```text
4
```

### Sample Explanation
Down, right, right, down.

### Target
O(R·C).

### Hints
1. BFS from S on the grid; walls are not vertices.
2. Store distances in a grid initialised to −1.

### Approach
Grid BFS.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <string>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int r, c;
    cin >> r >> c;
    vector<string> g(r);
    for (auto& row : g) cin >> row;
    vector<vector<int>> dist(r, vector<int>(c, -1));
    queue<pair<int, int>> q;
    int ex = -1, ey = -1;
    for (int i = 0; i < r; ++i)
        for (int j = 0; j < c; ++j) {
            if (g[i][j] == 'S') { dist[i][j] = 0; q.push({i, j}); }
            if (g[i][j] == 'E') { ex = i; ey = j; }
        }
    const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        for (int d = 0; d < 4; ++d) {
            int nx = x + dr[d], ny = y + dc[d];
            if (nx < 0 || nx >= r || ny < 0 || ny >= c || g[nx][ny] == '#' || dist[nx][ny] != -1) continue;
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    cout << dist[ex][ey] << '\n';
}
```

### Explanation
Every move costs one, so BFS distance is the minimum number of moves.

### Edge Cases
- Exit walled off: −1.

### Tests
#### Blocked
```text
1 3
S#E
```
```text
-1
```

## DSA13-M03 · Two Teams (Bipartite Check)
**Difficulty:** Medium · **Subtopic:** BFS colouring · **Tags:** BFS, bipartite, colouring · **Source:** Original

### Statement
Can the vertices be split into two teams so that every edge joins different teams? Print `YES` or `NO`.

### Input
n m, then m edges.

### Output
`YES` or `NO`.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
6 5
1 2
1 3
2 4
3 4
4 5
```

### Sample Output
```text
YES
```

### Sample Explanation
Teams {1, 4} and {2, 3, 5} (6 can go anywhere).

### Target
O(n + m).

### Hints
1. Colour the start 0; neighbours get the opposite colour.
2. An edge between equal colours means an odd cycle: impossible.

### Approach
BFS 2-colouring of every component.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    vector<int> colour(n + 1, -1);
    bool ok = true;
    for (int s = 1; s <= n && ok; ++s) {
        if (colour[s] != -1) continue;
        colour[s] = 0;
        queue<int> q;
        q.push(s);
        while (!q.empty() && ok) {
            int u = q.front(); q.pop();
            for (int v : adj[u]) {
                if (colour[v] == -1) { colour[v] = 1 - colour[u]; q.push(v); }
                else if (colour[v] == colour[u]) ok = false;
            }
        }
    }
    cout << (ok ? "YES" : "NO") << '\n';
}
```

### Explanation
BFS levels alternate colours; a conflict edge closes an odd cycle, which no 2-colouring allows.

### Edge Cases
- Triangle: NO.

### Tests
#### Triangle
```text
3 3
1 2
2 3
3 1
```
```text
NO
```

## DSA13-M04 · Undirected Cycle
**Difficulty:** Medium · **Subtopic:** Cycle detection · **Tags:** DFS, cycle, graph · **Source:** Original

### Statement
Print `YES` if the simple undirected graph contains a cycle, else `NO`.

### Input
n m, then m edges.

### Output
`YES` or `NO`.

### Constraints
- 1 ≤ n, m ≤ 2·10^5, no self-loops or parallel edges

### Sample Input
```text
6 5
1 2
1 3
2 4
3 4
4 5
```

### Sample Output
```text
YES
```

### Sample Explanation
1–2–4–3–1.

### Target
O(n + m).

### Hints
1. During traversal, reaching a visited vertex that is not your parent means a cycle.
2. Use an iterative traversal storing each vertex's parent.

### Approach
BFS with parents.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    vector<int> parent(n + 1, -1);
    vector<char> seen(n + 1, 0);
    bool cycle = false;
    for (int s = 1; s <= n && !cycle; ++s) {
        if (seen[s]) continue;
        seen[s] = 1;
        queue<int> q;
        q.push(s);
        while (!q.empty() && !cycle) {
            int u = q.front(); q.pop();
            for (int v : adj[u]) {
                if (!seen[v]) { seen[v] = 1; parent[v] = u; q.push(v); }
                else if (v != parent[u]) cycle = true;
            }
        }
    }
    cout << (cycle ? "YES" : "NO") << '\n';
}
```

### Explanation
In a forest every non-tree edge is absent; any edge to an already-seen non-parent vertex creates a second route, hence a cycle. (A forest has exactly n − components edges.)

### Edge Cases
- A tree: NO.

### Tests
#### Tree
```text
4 3
1 2
2 3
2 4
```
```text
NO
```

## DSA13-M05 · Directed Cycle
**Difficulty:** Medium · **Subtopic:** DFS colours · **Tags:** DFS, directed graph, cycle · **Source:** Original

### Statement
Print `YES` if the directed graph contains a directed cycle, else `NO`.

### Input
n m, then m directed edges.

### Output
`YES` or `NO`.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
3 3
1 2
2 3
3 1
```

### Sample Output
```text
YES
```

### Sample Explanation
1 → 2 → 3 → 1.

### Target
O(n + m).

### Hints
1. Colours: white (unvisited), gray (on the current DFS path), black (finished).
2. An edge to a gray vertex closes a cycle. Use an explicit stack of (vertex, next edge index).

### Approach
Iterative DFS with three colours.

### Solution
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); }
    vector<int> colour(n + 1, 0);                  // 0 white, 1 gray, 2 black
    bool cycle = false;
    for (int s = 1; s <= n && !cycle; ++s) {
        if (colour[s]) continue;
        vector<pair<int, size_t>> st = {{s, 0}};
        colour[s] = 1;
        while (!st.empty() && !cycle) {
            auto& [u, i] = st.back();
            if (i < adj[u].size()) {
                int v = adj[u][i++];
                if (colour[v] == 1) cycle = true;
                else if (colour[v] == 0) { colour[v] = 1; st.push_back({v, 0}); }
            } else {
                colour[u] = 2;
                st.pop_back();
            }
        }
    }
    cout << (cycle ? "YES" : "NO") << '\n';
}
```

### Explanation
Gray vertices are exactly the current path; an edge back to the path is a directed cycle. The explicit stack avoids recursion depth limits.

### Edge Cases
- DAG: NO; self-loop: YES.

### Tests
#### Chain
```text
3 2
1 2
2 3
```
```text
NO
```

## DSA13-H01 · Fire Spread
**Difficulty:** Hard · **Subtopic:** Multi-source BFS · **Tags:** BFS, grid, multi-source · **Source:** Original

### Statement
A grid has burning cells (2), dry cells (1) and empty cells (0). Each minute, fire spreads from every burning cell to adjacent dry cells. Print the minutes until every dry cell burns, or −1 if some never burns.

### Input
R C, then R rows of space-separated values.

### Output
Minutes or −1.

### Constraints
- 1 ≤ R, C ≤ 1000

### Sample Input
```text
3 3
2 1 1
1 1 0
0 1 1
```

### Sample Output
```text
4
```

### Sample Explanation
The bottom-right cell burns last, at minute 4.

### Target
O(R·C).

### Hints
1. Put all burning cells in the queue at distance 0 at once.
2. The answer is the largest distance reached; check for unreached dry cells.

### Approach
Multi-source BFS.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int r, c;
    cin >> r >> c;
    vector<vector<int>> g(r, vector<int>(c)), dist(r, vector<int>(c, -1));
    queue<pair<int, int>> q;
    for (int i = 0; i < r; ++i)
        for (int j = 0; j < c; ++j) {
            cin >> g[i][j];
            if (g[i][j] == 2) { dist[i][j] = 0; q.push({i, j}); }
        }
    const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    int minutes = 0;
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        minutes = max(minutes, dist[x][y]);
        for (int d = 0; d < 4; ++d) {
            int nx = x + dr[d], ny = y + dc[d];
            if (nx < 0 || nx >= r || ny < 0 || ny >= c || g[nx][ny] != 1 || dist[nx][ny] != -1) continue;
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    for (int i = 0; i < r; ++i)
        for (int j = 0; j < c; ++j)
            if (g[i][j] == 1 && dist[i][j] == -1) { cout << -1 << '\n'; return 0; }
    cout << minutes << '\n';
}
```

### Explanation
Starting from all sources at once equals BFS from a virtual super-source joined to every fire, so distances are minutes to the nearest fire.

### Edge Cases
- No dry cells: 0; unreachable dry cell: −1.

### Tests
#### Cut off
```text
1 3
2 0 1
```
```text
-1
```

## DSA13-H02 · Print a Shortest Route
**Difficulty:** Hard · **Subtopic:** Path reconstruction · **Tags:** BFS, parent array, shortest path · **Source:** Original

### Statement
Print the number of edges on a shortest path from 1 to n and the path itself. Use BFS with neighbours in increasing order and keep the first parent found; print −1 if n is unreachable.

### Input
n m, then m edges.

### Output
The length, then the vertices of the path.

### Constraints
- 2 ≤ n ≤ 2·10^5, m ≤ 2·10^5

### Sample Input
```text
6 6
1 2
1 3
2 4
3 4
4 5
5 6
```

### Sample Output
```text
4
1 2 4 5 6
```

### Sample Explanation
4 is discovered first from 2.

### Target
O(n + m log m).

### Hints
1. Record parent[v] when v is discovered.
2. Walk parents back from n and reverse.

### Approach
BFS with a parent array.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    for (auto& l : adj) sort(l.begin(), l.end());
    vector<int> parent(n + 1, 0), dist(n + 1, -1);
    queue<int> q;
    dist[1] = 0;
    q.push(1);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) if (dist[v] == -1) { dist[v] = dist[u] + 1; parent[v] = u; q.push(v); }
    }
    if (dist[n] == -1) { cout << -1 << '\n'; return 0; }
    vector<int> path;
    for (int v = n; v != 1; v = parent[v]) path.push_back(v);
    path.push_back(1);
    reverse(path.begin(), path.end());
    cout << dist[n] << '\n';
    for (size_t i = 0; i < path.size(); ++i) cout << path[i] << (i + 1 < path.size() ? ' ' : '\n');
}
```

### Explanation
Parents form a BFS tree, and every tree path from the root is a shortest path.

### Edge Cases
- Unreachable target.

### Tests
#### Unreachable

```text
1 2
```
```text

```

## DSA13-H03 · Word Ladder
**Difficulty:** Hard · **Subtopic:** BFS on implicit graphs · **Tags:** BFS, strings, implicit graph · **Source:** Original

### Statement
Transform the start word into the end word by changing one letter at a time; every intermediate word (and the end word) must be in the dictionary. Print the number of words in the shortest sequence (including start and end), or 0.

### Input
start and end; k, then k dictionary words (all the same length).

### Output
The sequence length or 0.

### Constraints
- 1 ≤ length ≤ 10, 1 ≤ k ≤ 5000

### Sample Input
```text
hit cog
6
hot dot dog lot log cog
```

### Sample Output
```text
5
```

### Sample Explanation
hit → hot → dot → dog → cog.

### Target
O(k · length · 26 · log k).

### Hints
1. Words are vertices; one-letter changes are edges, generated on the fly.
2. Remove words from the dictionary set when visited.

### Approach
BFS over words with a `set` of unvisited words.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <set>
#include <string>
#include <utility>
using namespace std;

int main() {
    string start, finish;
    int k;
    cin >> start >> finish >> k;
    set<string> unvisited;
    for (int i = 0; i < k; ++i) { string w; cin >> w; unvisited.insert(w); }
    queue<pair<string, int>> q;
    q.push({start, 1});
    unvisited.erase(start);
    int answer = 0;
    while (!q.empty() && !answer) {
        auto [w, d] = q.front(); q.pop();
        if (w == finish) { answer = d; break; }
        for (size_t i = 0; i < w.size(); ++i) {
            string next = w;
            for (char c = 'a'; c <= 'z'; ++c) {
                next[i] = c;
                auto it = unvisited.find(next);
                if (it != unvisited.end()) { unvisited.erase(it); q.push({next, d + 1}); }
            }
        }
    }
    cout << answer << '\n';
}
```

### Explanation
The graph is never built explicitly: neighbours are generated by trying all one-letter changes, and BFS gives the fewest steps.

### Edge Cases
- End word missing from the dictionary: 0.

### Tests
#### Missing end
```text
hit cog
2
hot dot
```
```text
0
```

## DSA13-H04 · Largest Group
**Difficulty:** Hard · **Subtopic:** Iterative DFS at scale · **Tags:** DFS, stack, components · **Source:** Original

### Statement
Print the number of connected components and the size of the largest one, using iterative DFS (the graph may be a single path of 2·10^5 vertices).

### Input
n m, then m edges.

### Output
Components and largest size.

### Constraints
- 1 ≤ n, m ≤ 2·10^5

### Sample Input
```text
6 5
1 2
1 3
2 4
3 4
4 5
```

### Sample Output
```text
2 5
```

### Sample Explanation
The big component has 5 vertices.

### Target
O(n + m).

### Hints
1. Replace recursion with an explicit `vector` stack.
2. Count vertices as they are first visited.

### Approach
Iterative DFS from each unvisited vertex.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) { int u, v; cin >> u >> v; adj[u].push_back(v); adj[v].push_back(u); }
    vector<char> seen(n + 1, 0);
    int components = 0, largest = 0;
    for (int s = 1; s <= n; ++s) {
        if (seen[s]) continue;
        ++components;
        int size = 0;
        vector<int> st = {s};
        seen[s] = 1;
        while (!st.empty()) {
            int u = st.back(); st.pop_back();
            ++size;
            for (int v : adj[u]) if (!seen[v]) { seen[v] = 1; st.push_back(v); }
        }
        largest = max(largest, size);
    }
    cout << components << ' ' << largest << '\n';
}
```

### Explanation
The explicit stack lives on the heap, so even a 2·10^5-vertex path cannot overflow the call stack.

### Edge Cases
- Single vertex.

### Tests
#### Long path
```text
4 3
1 2
2 3
3 4
```
```text

```

## DSA13-H05 · Knight Moves
**Difficulty:** Hard · **Subtopic:** BFS on a state space · **Tags:** BFS, grid, implicit graph · **Source:** Original

### Statement
On an N × N board, print the minimum number of knight moves from (r1, c1) to (r2, c2) (0-based), or −1.

### Input
N, then r1 c1 r2 c2.

### Output
The minimum moves or −1.

### Constraints
- 1 ≤ N ≤ 1000

### Sample Input
```text
8
0 0 7 7
```

### Sample Output
```text
6
```

### Sample Explanation
Corner to corner on a chessboard takes 6 moves.

### Target
O(N²).

### Hints
1. Squares are vertices; the 8 knight moves are edges.
2. BFS stops when the target is dequeued.

### Approach
Grid BFS with knight offsets.

### Solution
```cpp
#include <iostream>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n, r1, c1, r2, c2;
    cin >> n >> r1 >> c1 >> r2 >> c2;
    vector<vector<int>> dist(n, vector<int>(n, -1));
    const int dr[] = {1, 2, 2, 1, -1, -2, -2, -1}, dc[] = {2, 1, -1, -2, -2, -1, 1, 2};
    queue<pair<int, int>> q;
    dist[r1][c1] = 0;
    q.push({r1, c1});
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        for (int d = 0; d < 8; ++d) {
            int nx = x + dr[d], ny = y + dc[d];
            if (nx < 0 || nx >= n || ny < 0 || ny >= n || dist[nx][ny] != -1) continue;
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    cout << dist[r2][c2] << '\n';
}
```

### Explanation
Each move costs one, so BFS distances are minimal. Small boards can make squares unreachable (the centre of 3 × 3).

### Edge Cases
- Start equals target: 0; unreachable: −1.

### Tests
#### Centre of 3x3
```text
3
0 0 1 1
```
```text
-1
```

#### Same square
```text
5
2 2 2 2
```
```text
0
```
