## DSA05-E01 · Insertion Sort Trace
**Difficulty:** Easy · **Subtopic:** Loop invariants · **Tags:** insertion sort, invariant, tracing · **Source:** Original

### Statement
Sort the array with insertion sort and print the array after each pass of the outer loop (j = 1 … n − 1). Each line shows that the prefix a[0..j] is sorted: the loop invariant in action.

### Input
n, then n integers.

### Output
n − 1 lines, the array after each pass.

### Constraints
- 2 ≤ n ≤ 1000
- |aᵢ| ≤ 10^9

### Sample Input
```text
4
4 3 2 1
```

### Sample Output
```text
3 4 2 1
2 3 4 1
1 2 3 4
```

### Sample Explanation
After pass j the first j + 1 elements are sorted.

### Target
O(n²) time, O(1) extra space.

### Hints
1. Save a[j] as key, shift larger elements of the sorted prefix one place right.
2. Drop key into the gap, then print.

### Approach
Standard insertion sort with a print after each outer iteration.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    for (int j = 1; j < n; ++j) {          // invariant: a[0..j-1] sorted
        long long key = a[j];
        int i = j;
        while (i > 0 && a[i - 1] > key) { a[i] = a[i - 1]; --i; }
        a[i] = key;
        for (int k = 0; k < n; ++k) cout << a[k] << (k + 1 < n ? ' ' : '\n');
    }
}
```

### Explanation
Initialisation: a[0..0] is sorted. Maintenance: inserting key into the sorted prefix keeps it sorted. Termination: j = n, so the whole array is sorted.

### Edge Cases
- Already sorted input: every line equals the input.
- Duplicates stay in their original order (stable).

### Tests
#### Sorted input
```text
3
1 2 3
```
```text
1 2 3
1 2 3
```

## DSA05-E02 · Selection Sort Counts
**Difficulty:** Easy · **Subtopic:** Exact operation counts · **Tags:** selection sort, counting, invariant · **Source:** Original

### Statement
Run selection sort (for each i, find the minimum of a[i..n−1] and swap it into position i, swapping only if it is not already there). Print the sorted array, the number of comparisons and the number of swaps.

### Input
n, then n integers.

### Output
The sorted array on one line; then comparisons and swaps.

### Constraints
- 1 ≤ n ≤ 2000
- |aᵢ| ≤ 10^9

### Sample Input
```text
5
3 1 2 5 4
```

### Sample Output
```text
1 2 3 4 5
10 3
```

### Sample Explanation
Comparisons are always n(n−1)/2 = 10. Swaps happen at i = 0, 1 and 3.

### Target
O(n²) time.

### Hints
1. The inner loop compares a[k] with the current minimum for k = i+1 … n−1.
2. Count a swap only when the minimum index differs from i.

### Approach
Nested loops with two counters.

### Solution
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    long long comparisons = 0, swaps = 0;
    for (int i = 0; i + 1 < n; ++i) {       // invariant: a[0..i-1] holds the i smallest, sorted
        int m = i;
        for (int k = i + 1; k < n; ++k) {
            ++comparisons;
            if (a[k] < a[m]) m = k;
        }
        if (m != i) { swap(a[i], a[m]); ++swaps; }
    }
    for (int k = 0; k < n; ++k) cout << a[k] << (k + 1 < n ? ' ' : '\n');
    cout << comparisons << ' ' << swaps << '\n';
}
```

### Explanation
The comparison count does not depend on the data: Σ (n − 1 − i) = n(n−1)/2, so selection sort is Θ(n²) in every case, but it performs at most n − 1 swaps.

### Edge Cases
- n = 1: 0 comparisons, 0 swaps.
- Sorted input: 0 swaps.

### Tests
#### Single element
```text
1
7
```
```text
7
0 0
```

## DSA05-E03 · Linear Recurrence by Iteration
**Difficulty:** Easy · **Subtopic:** Recurrence relations · **Tags:** recurrence, iteration, modular arithmetic · **Source:** Original

### Statement
T(0) = c and T(k) = a·T(k−1) + b. Print T(n) modulo 1 000 000 007.

### Input
a, b, c and n.

### Output
T(n) mod 10^9 + 7.

### Constraints
- 0 ≤ a, b, c ≤ 10^9
- 0 ≤ n ≤ 10^6

### Sample Input
```text
2 1 0 10
```

### Sample Output
```text
1023
```

### Sample Explanation
T(n) = 2T(n−1) + 1 with T(0) = 0 gives 2^n − 1 = 1023 (the Tower of Hanoi recurrence).

### Target
O(n) time.

### Hints
1. Unroll the recurrence with a loop, keeping only the previous value.
2. Reduce modulo after every multiplication.

### Approach
Iterate n times: t = (a·t + b) mod p.

### Solution
```cpp
#include <iostream>
using namespace std;

int main() {
    const long long MOD = 1000000007;
    long long a, b, c, n;
    cin >> a >> b >> c >> n;
    long long t = c % MOD;
    for (long long k = 1; k <= n; ++k) t = ((a % MOD) * t + b) % MOD;   // product < 1e18
    cout << t << '\n';
}
```

### Explanation
Expansion turns the recurrence into a loop. For a = 2, b = 1 the closed form 2^n − 1 can be proved by induction.

### Edge Cases
- n = 0: answer c mod p.
- a = 0: T(n) = b for n ≥ 1.

### Tests
#### Powers of three
```text
3 0 1 5
```
```text
243
```

#### Counting
```text
1 1 0 1000000
```
```text
1000000
```

## DSA05-E04 · Binary Search Steps
**Difficulty:** Easy · **Subtopic:** Binary search invariant · **Tags:** binary search, invariant, counting · **Source:** Original

### Statement
Use the binary search from the lesson (lo = 0, hi = n − 1, while lo ≤ hi, mid = lo + (hi − lo)/2). For each query print the index found (or −1) and the number of loop iterations.

### Input
n, n sorted distinct integers, q, then q queries.

### Output
For each query: index and iterations.

### Constraints
- 1 ≤ n, q ≤ 2·10^5
- |values| ≤ 10^9

### Sample Input
```text
7
1 3 5 7 9 11 13
3
7
1
4
```

### Sample Output
```text
3 1
0 3
-1 3
```

### Sample Explanation
7 is the first midpoint. For 1: mids 3, 1, 0. For 4: mids 3, 1, 2, then the range is empty.

### Target
O(log n) per query.

### Hints
1. Count one iteration each time the loop body runs.
2. Invariant: if x is present it lies in a[lo..hi].

### Approach
Implement the loop exactly and count.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    int q;
    cin >> q;
    while (q--) {
        long long x;
        cin >> x;
        int lo = 0, hi = n - 1, found = -1, steps = 0;
        while (lo <= hi) {                 // invariant: x, if present, is in a[lo..hi]
            ++steps;
            int mid = lo + (hi - lo) / 2;
            if (a[mid] == x) { found = mid; break; }
            if (a[mid] < x) lo = mid + 1;
            else hi = mid - 1;
        }
        cout << found << ' ' << steps << '\n';
    }
}
```

### Explanation
The range at least halves each iteration, so there are at most ⌊log₂ n⌋ + 1 iterations.

### Edge Cases
- n = 1.
- x outside the range of values.

### Tests
#### Single element
```text
1
5
2
5
6
```
```text
0 1
-1 1
```

## DSA05-E05 · Integer Square Root
**Difficulty:** Easy · **Subtopic:** Invariant-based search · **Tags:** binary search, invariant, overflow · **Source:** Original

### Statement
For each n print ⌊√n⌋ using integer binary search (floating-point `sqrt` can be off by one for large n).

### Input
T, then T integers.

### Output
⌊√n⌋ for each.

### Constraints
- 1 ≤ T ≤ 10^5
- 0 ≤ n ≤ 10^18

### Sample Input
```text
3
15
1000000000000000000
999999999999999999
```

### Sample Output
```text
3
1000000000
999999999
```

### Sample Explanation
3² = 9 ≤ 15 < 16 = 4².

### Target
O(log n) per query.

### Hints
1. Keep the invariant lo² ≤ n < hi².
2. Test mid ≤ n / mid instead of mid·mid ≤ n to avoid overflow.

### Approach
lo = 0, hi = 2·10^9; while hi − lo > 1, move lo or hi to mid.

### Solution
```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        long long n;
        cin >> n;
        long long lo = 0, hi = 2000000000;        // invariant: lo*lo <= n < hi*hi
        while (hi - lo > 1) {
            long long mid = lo + (hi - lo) / 2;
            if (mid <= n / mid) lo = mid;         // mid*mid <= n, no overflow
            else hi = mid;
        }
        cout << lo << '\n';
    }
}
```

### Explanation
The invariant holds initially (0 ≤ n < 4·10^18) and each step keeps it; when hi = lo + 1, lo is ⌊√n⌋.

### Edge Cases
- n = 0 and n = 1.
- Perfect squares.

### Tests
#### Zero and one
```text
2
0
1
```
```text

1
```

## DSA05-M01 · Recursion Tree Cost
**Difficulty:** Medium · **Subtopic:** Recursion trees · **Tags:** recurrence, recursion tree, divide and conquer · **Source:** Original

### Statement
Compute T(n) exactly for T(1) = 1 and T(n) = 2T(⌊n/2⌋) + n.

### Input
T, then T values n.

### Output
T(n) for each.

### Constraints
- 1 ≤ T ≤ 10^4
- 1 ≤ n ≤ 10^15

### Sample Input
```text
3
1
8
1000000000000000
```

### Sample Output
```text
1
32
49337097826861056
```

### Sample Explanation
T(8) = 2T(4) + 8 = 2(2T(2) + 4) + 8 = 32 = n(log₂ n + 1).

### Target
O(log n) per query.

### Hints
1. Both recursive calls have the same argument: compute it once.
2. Depth is about log₂ n, so recursion is safe.

### Approach
`T(n) = n <= 1 ? 1 : 2*T(n/2) + n`.

### Solution
```cpp
#include <iostream>

long long T(long long n) { return n <= 1 ? 1 : 2 * T(n / 2) + n; }

int main() {
    int t;
    cin >> t;
    while (t--) {
        long long n;
        cin >> n;
        cout << T(n) << '\n';
    }
}
```

### Explanation
The recursion tree has about log₂ n levels each costing about n, so T(n) = Θ(n log n); exact values confirm it.

### Edge Cases
- n = 1.
- Odd n (floors).

## DSA05-M02 · Merge Sort Worst-Case Comparisons
**Difficulty:** Medium · **Subtopic:** Recurrences with floors and ceilings · **Tags:** recurrence, merge sort, memoisation · **Source:** Original

### Statement
Merge sort's worst-case comparisons satisfy W(1) = 0, W(n) = W(⌈n/2⌉) + W(⌊n/2⌋) + n − 1. Print W(n).

### Input
T, then T values n.

### Output
W(n) for each.

### Constraints
- 1 ≤ T ≤ 1000
- 1 ≤ n ≤ 10^16

### Sample Input
```text
3
4
10
10000000000000000
```

### Sample Output
```text
5
25
521985601490518017
```

### Sample Explanation
W(4) = 2W(2) + 3 = 2·1 + 3 = 5.

### Target
O(log n) distinct states per query.

### Hints
1. At each depth only two different sizes appear (⌈⌉ and ⌊⌋ differ by at most 1).
2. Memoise results in a map.

### Approach
Recursive function with `map<long long,long long>` cache.

### Solution
```cpp
#include <iostream>
#include <map>
using namespace std;

map<long long, long long> memo;

long long W(long long n) {
    if (n <= 1) return 0;
    auto it = memo.find(n);
    if (it != memo.end()) return it->second;
    long long r = W((n + 1) / 2) + W(n / 2) + n - 1;
    memo[n] = r;
    return r;
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        long long n;
        cin >> n;
        cout << W(n) << '\n';
    }
}
```

### Explanation
Without memoisation the recursion would make Θ(n) calls; with it each level contributes at most two new sizes, so O(log n) work. W(n) = n⌈log₂ n⌉ − 2^⌈log₂ n⌉ + 1, which is Θ(n log n).

### Edge Cases
- n = 1: 0.
- n = 5: 8.

### Tests
#### Five
```text
1

```


## DSA05-M03 · Dutch National Flag
**Difficulty:** Medium · **Subtopic:** Multi-region invariants · **Tags:** partition, invariant, two pointers · **Source:** Original

### Statement
Sort an array of 0s, 1s and 2s in one pass with O(1) extra space (no counting pass).

### Input
n, then n values from {0, 1, 2}.

### Output
The sorted array.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
6
2 0 2 1 1 0
```

### Sample Output
```text
0 0 1 1 2 2
```

### Sample Explanation
All 0s, then 1s, then 2s.

### Target
O(n) time, O(1) space, one pass.

### Hints
1. Keep three regions: a[0..low−1] = 0, a[low..mid−1] = 1, a[high+1..] = 2; a[mid..high] unknown.
2. Look at a[mid]: 0 → swap with low; 1 → advance; 2 → swap with high (do not advance mid).

### Approach
Dijkstra's three-way partition with pointers low, mid, high.

### Solution
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (auto& x : a) cin >> x;
    int low = 0, mid = 0, high = n - 1;
    while (mid <= high) {                     // a[mid..high] is still unclassified
        if (a[mid] == 0) swap(a[low++], a[mid++]);
        else if (a[mid] == 1) ++mid;
        else swap(a[mid], a[high--]);         // the swapped-in value is unknown: recheck it
    }
    for (int k = 0; k < n; ++k) cout << a[k] << (k + 1 < n ? ' ' : '\n');
}
```

### Explanation
Each step shrinks the unknown region by one while preserving the three-region invariant; when it is empty the array is sorted. This partition is the basis of three-way quick sort.

### Edge Cases
- All the same value.
- n = 1.

### Tests
#### All twos
```text
3
2 2 2
```
```text
2 2 2
```

## DSA05-M04 · Calls of Naive Fibonacci
**Difficulty:** Medium · **Subtopic:** Recurrence for running time · **Tags:** recurrence, induction, recursion · **Source:** Original

### Statement
The naive function `fib(n) = n < 2 ? n : fib(n−1) + fib(n−2)` makes C(n) calls (counting the first), where C(0) = C(1) = 1 and C(n) = C(n−1) + C(n−2) + 1. Print C(n) without making those calls.

### Input
One integer n.

### Output
C(n).

### Constraints
- 0 ≤ n ≤ 80

### Sample Input
```text
10
```

### Sample Output
```text
177
```

### Sample Explanation
C(n) = 2F(n+1) − 1, and F(11) = 89, so C(10) = 177.

### Target
O(n) time.

### Hints
1. Iterate the recurrence for C directly.
2. Prove C(n) = 2F(n+1) − 1 by induction.

### Approach
Keep the last two values of C.

### Solution
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long prev = 1, cur = 1;          // C(0), C(1)
    for (int i = 2; i <= n; ++i) {
        long long next = cur + prev + 1;
        prev = cur;
        cur = next;
    }
    cout << (n == 0 ? prev : cur) << '\n';
}
```

### Explanation
Induction: C(n) = (2F(n) − 1) + (2F(n−1) − 1) + 1 = 2F(n+1) − 1. Since F grows like φ^n, the naive algorithm is exponential.

### Edge Cases
- n = 0 and n = 1: 1 call.

### Tests
#### Zero

```text
1
```

#### Eighty
```text

```

## DSA05-M05 · Valid Stack Sequence
**Difficulty:** Medium · **Subtopic:** Data structure invariants · **Tags:** stack, simulation, invariant · **Source:** Original

### Statement
The numbers 1, 2, …, n are pushed onto a stack in this order, and pops may happen at any time. Decide whether the given permutation can be the order of pops.

### Input
n, then a permutation of 1..n.

### Output
`YES` or `NO`.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
4 5 3 2 1
```

### Sample Output
```text
YES
```

### Sample Explanation
Push 1–4, pop 4, push 5, pop 5, then pop 3, 2, 1.

### Target
O(n) time.

### Hints
1. Simulate: push numbers until the top equals the next value to pop.
2. If the next value is already below the top, it is impossible.

### Approach
For each target, push 1..target if not yet pushed; then the top must equal target.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> st;
    int nextPush = 1;
    bool ok = true;
    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        while (nextPush <= x) st.push_back(nextPush++);
        if (st.empty() || st.back() != x) ok = false;   // x is buried: impossible
        else st.pop_back();
    }
    cout << (ok ? "YES" : "NO") << '\n';
}
```

### Explanation
Invariant: the stack holds exactly the pushed, not-yet-popped numbers in increasing order. A value can only leave from the top, so the simulation is forced and decides feasibility.

### Edge Cases
- n = 1.
- The reverse order n..1 is always valid.

### Tests
#### Impossible
```text
5
4 3 5 1 2
```
```text
NO
```

## DSA05-H01 · Total Binary Search Iterations
**Difficulty:** Hard · **Subtopic:** Recurrences for average cost · **Tags:** recurrence, binary search, memoisation · **Source:** Original

### Statement
Binary search (lo = 0, hi = n − 1, mid = (lo + hi)/2) is run once for every element of a sorted array of n distinct values. Print the total number of loop iterations over all n searches (the internal path length of the search tree plus n).

### Input
T, then T values n.

### Output
The total for each n.

### Constraints
- 1 ≤ T ≤ 1000
- 1 ≤ n ≤ 10^16

### Sample Input
```text
4
1
3
7
10
```

### Sample Output
```text
1
5
17
29
```

### Sample Explanation
For n = 3: the middle element needs 1 iteration, the other two need 2 each: 5.

### Target
O(log n) states per query.

### Hints
1. Every search passes the root (1 iteration each, n in total); then it continues in the left part of size ⌊(n−1)/2⌋ or the right part of size n − 1 − that.
2. S(n) = n + S(left) + S(right), S(0) = 0. Memoise.

### Approach
Memoised recursion; only O(log n) distinct sizes occur.

### Solution
```cpp
#include <iostream>
#include <map>
using namespace std;

map<long long, long long> memo;

long long S(long long n) {
    if (n <= 0) return 0;
    auto it = memo.find(n);
    if (it != memo.end()) return it->second;
    long long left = (n - 1) / 2;
    long long r = n + S(left) + S(n - 1 - left);
    memo[n] = r;
    return r;
}

int main() {
    int t;
    cin >> t;
    while (t--) {
        long long n;
        cin >> n;
        cout << S(n) << '\n';
    }
}
```

### Explanation
S(n)/n is the average number of iterations for a successful search, about log₂ n − 1, matching the Θ(log n) bound.

### Edge Cases
- n = 1.
- Sizes 2^k − 1 give perfect trees.

### Tests
#### Huge
```text

10000000000000000
```


## DSA05-H02 · Binary Counter Flips
**Difficulty:** Hard · **Subtopic:** Amortised analysis by induction · **Tags:** amortised analysis, bits, induction · **Source:** Original

### Statement
A binary counter starts at 0 and is incremented n times. Each increment flips the trailing 1s to 0 and one 0 to 1. Print the total number of bit flips.

### Input
One integer n.

### Output
The total number of flips.

### Constraints
- 1 ≤ n ≤ 10^18

### Sample Input
```text
4
```

### Sample Output
```text
7
```

### Sample Explanation
0→1 (1 flip), 1→10 (2), 10→11 (1), 11→100 (3): 7.

### Target
O(log n).

### Hints
1. Bit k flips once every 2^k increments: ⌊n / 2^k⌋ times.
2. The sum equals 2n − popcount(n).

### Approach
Print 2n − popcount(n).

### Solution
```cpp
#include <iostream>
using namespace std;

int main() {
    unsigned long long n;
    cin >> n;
    int ones = 0;
    for (unsigned long long x = n; x; x &= x - 1) ++ones;
    cout << 2 * n - ones << '\n';                 // sum of floor(n / 2^k)
}
```

### Explanation
Σₖ ⌊n/2^k⌋ = 2n − popcount(n), provable by induction on n. So n increments cost fewer than 2n flips: O(1) amortised each, although one increment can flip Θ(log n) bits.

### Edge Cases
- n = 1: one flip.
- n = 10^18: 2n fits in unsigned 64 bits.

#### Huge


## DSA05-H03 · Unequal Split Recurrence
**Difficulty:** Hard · **Subtopic:** Recursion trees with unequal splits · **Tags:** recurrence, memoisation, recursion tree · **Source:** Original

### Statement
U(n) = 1 for n ≤ 2, and U(n) = U(⌊n/3⌋) + U(⌊2n/3⌋) + n. The Master Theorem does not apply. Compute U(n) exactly.

### Input
T, then T values n.

### Output
U(n) for each.

### Constraints
- 1 ≤ T ≤ 100
- 1 ≤ n ≤ 10^12

### Sample Input
```text
3
3
10
100
```

### Sample Output
```text
5
28
612
```

### Sample Explanation
U(3) = U(1) + U(2) + 3 = 5.

### Target
Memoised recursion: at most a few thousand distinct states.

### Hints
1. Many branches reach the same arguments; cache them.
2. The recursion tree has levels costing at most n and depth log_{3/2} n: Θ(n log n).

### Approach
Map-memoised recursion; 2n/3 is computed as 2·n/3 in `long long`.

### Solution
```cpp
#include <iostream>
#include <map>
using namespace std;

map<long long, long long> memo;

long long U(long long n) {

    if (it != memo.end()) return it->second;
    long long r = U(n / 3) + U(2 * n / 3) + n;

int main() {
    int t;
    cin >> t;
    while (t--) {
        long long n;
        cin >> n;
        cout << U(n) << '\n';
    }
}
```

### Explanation
Each level of the tree sums to at most n, and the longest path follows the 2/3 branch for log_{3/2} n levels, so U(n) = Θ(n log n): confirmed numerically.

### Edge Cases
- n ≤ 2: 1.
- Large n: about 1000 cached states.

## DSA05-H04 · Find the Duplicate
**Difficulty:** Hard · **Subtopic:** Proof by contradiction (pigeonhole) · **Tags:** cycle detection, pigeonhole, invariant · **Source:** Original

### Statement
An array holds n + 1 integers, each between 1 and n, and exactly one value is repeated (possibly several times). Find it without modifying the array and with O(1) extra memory.

### Input
n, then n + 1 integers.

### Output
The repeated value.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
4
1 3 4 2 2
```

### Sample Output
```text
2
```

### Sample Explanation
2 appears twice.

### Target
O(n) time, O(1) extra space.

### Hints
1. Pigeonhole: n + 1 values in n slots must repeat (proof by contradiction).
2. Treat i → a[i] as a linked list starting at index 0; the duplicate is the entry of its cycle.
3. Floyd's tortoise and hare finds the cycle entry.

### Approach
Phase 1: slow moves one step, fast two, until they meet. Phase 2: restart slow at 0, move both one step; they meet at the duplicate.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n + 1);
    for (auto& x : a) cin >> x;
    int slow = a[0], fast = a[a[0]];
    while (slow != fast) { slow = a[slow]; fast = a[a[fast]]; }   // meet inside the cycle
    slow = 0;
    while (slow != fast) { slow = a[slow]; fast = a[fast]; }       // meet at the cycle entry
    cout << slow << '\n';
}
```

### Explanation
Index 0 is never a value, so the path from 0 must eventually enter a cycle; the cycle's entry has two incoming edges, i.e. two indices with the same value: the duplicate. Floyd's algorithm finds that entry using two pointers only.

### Edge Cases
- n = 1: both values are 1.
- The duplicate appears many times.

### Tests
#### Repeated many times
```text
3
3 1 3 3
```
```text
3
```

## DSA05-H05 · Maximum Circular Subarray
**Difficulty:** Hard · **Subtopic:** Invariant-based scans · **Tags:** Kadane, invariant, arrays · **Source:** Original

### Statement
The array is circular (the last element is followed by the first). Print the largest sum of a non-empty contiguous segment.

### Input
n, then n integers.

### Output
The maximum sum.

### Constraints
- 1 ≤ n ≤ 2·10^5
- |aᵢ| ≤ 10^9

### Sample Input
```text
3
5 -3 5
```

### Sample Output
```text
10
```

### Sample Explanation
The wrapping segment 5, 5 (last then first) sums to 10.

### Target
O(n) time.

### Hints
1. A non-wrapping best segment is Kadane's answer.
2. A wrapping segment is the total minus a non-wrapping minimum segment.
3. If every value is negative, the wrapping formula would choose the empty segment; use Kadane's answer.

### Approach
Run Kadane for the maximum and the minimum; answer max(best, total − worst) unless all values are negative.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    long long total = 0, curMax = 0, curMin = 0, best = a[0], worst = a[0];
    for (long long x : a) {
        total += x;
        curMax = max(curMax + x, x);       // invariant: best sum ending here
        best = max(best, curMax);
        curMin = min(curMin + x, x);       // smallest sum ending here
        worst = min(worst, curMin);
    }
    long long answer = (best < 0) ? best : max(best, total - worst);
    cout << answer << '\n';
}
```

### Explanation
Kadane's invariant: curMax is the best sum of a segment ending at the current position. Removing the minimum segment from the circle leaves the best wrapping segment.

### Edge Cases
- All negative: the largest element.
- n = 1.

### Tests
#### All negative
```text
3
-3 -2 -3
```
```text
-2
```
