# Binary Search Trees: Practice Problems

Unless stated otherwise, the BST is built by inserting the given keys in order into an empty tree (duplicates ignored). An ordinary BST can degenerate into a path, so these solutions use iterative loops and store nodes in a vector.

## DSA15-E01 · Insert and Inorder
**Difficulty:** Easy · **Subtopic:** BST insertion · **Tags:** BST, insertion, inorder · **Source:** Original

### Statement
Insert the keys into a BST and print its inorder traversal.

### Input
n, then n keys.

### Output
The inorder sequence.

### Constraints
- 1 ≤ n ≤ 2·10^5 (any insertion order)

### Sample Input
```text
7
50 30 70 20 40 60 80
```

### Sample Output
```text
20 30 40 50 60 70 80
```

### Sample Explanation
Inorder of a BST is sorted.

### Target
O(n·h) insertion, O(n) traversal.

### Hints
1. Walk down from the root: left if smaller, right if larger.
2. Use an explicit stack for inorder.

### Approach
Vector-based nodes, iterative insert and traversal.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };
vector<Node> t;

void insert(long long k) {
    if (t.empty()) { t.push_back({k}); return; }
    int u = 0;
    for (;;) {
        if (k == t[u].key) return;
        int& next = k < t[u].key ? t[u].left : t[u].right;
        if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); return; }
        u = next;
    }
}

int main() {
    int n;
    cin >> n;
    t.reserve(n);
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(k); }
    vector<int> st;
    vector<long long> out;
    int u = 0;
    while (u != -1 || !st.empty()) {
        while (u != -1) { st.push_back(u); u = t[u].left; }
        u = st.back(); st.pop_back();
        out.push_back(t[u].key);
        u = t[u].right;
    }
    for (size_t i = 0; i < out.size(); ++i) cout << out[i] << (i + 1 < out.size() ? ' ' : '\n');
}
```

### Explanation
`reserve` prevents reallocation while `next` refers into the vector. Inorder visits left subtree, node, right subtree: sorted order by the BST property.

### Edge Cases
- Duplicates; sorted input (degenerate tree).

### Tests
#### Duplicates
```text
4
5 5 3 5
```
```text
3 5
```

## DSA15-E02 · Search
**Difficulty:** Easy · **Subtopic:** BST search · **Tags:** BST, search · **Source:** Original

### Statement
Build the BST and answer membership queries.

### Input
n and keys; q and queries.

### Output
`YES` or `NO` per query.

### Constraints
- 1 ≤ n ≤ 2·10^5, 1 ≤ q ≤ 2·10^5, keys in random-like order

### Sample Input
```text
7
50 30 70 20 40 60 80
2
40
45
```

### Sample Output
```text
YES
NO
```

### Sample Explanation
45 would be between 40 and 50.

### Target
O(h) per query.

### Hints
1. Each comparison discards one subtree.
2. Stop at −1 (not found).

### Approach
Iterative search.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };
vector<Node> t;

void insert(long long k) {
    if (t.empty()) { t.push_back({k}); return; }
    int u = 0;
    for (;;) {
        if (k == t[u].key) return;
        int& next = k < t[u].key ? t[u].left : t[u].right;
        if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); return; }
        u = next;
    }
}

int main() {
    int n;
    cin >> n;
    t.reserve(n);
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(k); }
    int q;
    cin >> q;
    while (q--) {
        long long x;
        cin >> x;
        int u = 0;
        while (u != -1 && t[u].key != x) u = x < t[u].key ? t[u].left : t[u].right;
        cout << (u != -1 ? "YES" : "NO") << '\n';
    }
}
```

### Explanation
Search follows one root-to-leaf path: O(h), which is O(log n) only if the tree is reasonably balanced.

### Edge Cases
- Querying the root.

### Tests
#### Root
```text
1
9
1
9
```
```text
YES
```

## DSA15-E03 · Minimum and Maximum
**Difficulty:** Easy · **Subtopic:** Extreme keys · **Tags:** BST, minimum, maximum · **Source:** Original

### Statement
Print the smallest and largest key of the BST.

### Input
n, then n keys.

### Output
min and max.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
7
50 30 70 20 40 60 80
```

### Sample Output
```text
20 80
```

### Sample Explanation
Leftmost and rightmost nodes.

### Target
O(h).

### Hints
1. Keep going left for the minimum.
2. Keep going right for the maximum.

### Approach
Two walks from the root.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };
vector<Node> t;

void insert(long long k) {
    if (t.empty()) { t.push_back({k}); return; }

    for (;;) {
        if (k == t[u].key) return;
        int& next = k < t[u].key ? t[u].left : t[u].right;
        if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); return; }
        u = next;
    }
}

int main() {
    int n;
    cin >> n;
    t.reserve(n);
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(k); }
    int lo = 0, hi = 0;
    while (t[lo].left != -1) lo = t[lo].left;
    while (t[hi].right != -1) hi = t[hi].right;
    cout << t[lo].key << ' ' << t[hi].key << '\n';
}
```

### Explanation
No smaller key can be to the right of any node on the leftmost path, so the leftmost node is the minimum.

## DSA15-E04 · Height Depends on Order
**Difficulty:** Easy · **Subtopic:** Degenerate trees · **Tags:** BST, height, worst case · **Source:** Original

### Statement
Print the height (in edges) of the BST built from the given insertion order.

### Input
n, then n keys.

### Output
The height.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
5
1 2 3 4 5
```

### Sample Output
```text
4
```

### Sample Explanation
Sorted insertions make a path: every operation becomes O(n).

### Target
O(n·h).

### Hints
1. Track each new node's depth during insertion.
2. The height is the maximum depth.

### Approach
Record depth at insertion time.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };

int main() {
    int n;
    cin >> n;
    vector<Node> t;
    t.reserve(n);
    int height = 0;
    for (int i = 0; i < n; ++i) {
        long long k;
        cin >> k;
        if (t.empty()) { t.push_back({k}); continue; }
        int u = 0, depth = 0;
        for (;;) {
            if (k == t[u].key) break;
            int& next = k < t[u].key ? t[u].left : t[u].right;
            ++depth;
            if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); height = max(height, depth); break; }
            u = next;
        }
    }
    cout << height << '\n';
}
```

### Explanation
The same keys can give height ⌊log₂ n⌋ or n − 1 depending on order: an ordinary BST does not guarantee O(log n). Sorted input with n = 2·10^5 costs about 2·10^10 steps, which is why the test uses small n.

### Edge Cases
- Balanced order: height 2 for 7 keys.

### Tests
#### Balanced order
```text
7
50 30 70 20 40 60 80
```
```text
2
```

## DSA15-E05 · Count Keys in a Range
**Difficulty:** Easy · **Subtopic:** Range traversal · **Tags:** BST, range query, pruning · **Source:** Original

### Statement
Print how many keys lie in [lo, hi].

### Input
n and keys, then lo hi.

### Output
The count.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
7
50 30 70 20 40 60 80
25 65
```

### Sample Output
```text
4
```

### Sample Explanation
30, 40, 50, 60.

### Target
O(h + answer) with pruning.

### Hints
1. Skip the left subtree when the node's key < lo, and the right subtree when key > hi.
2. Count the node itself only when lo ≤ key ≤ hi.

### Approach
Iterative traversal with pruning.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };
vector<Node> t;

void insert(long long k) {
    if (t.empty()) { t.push_back({k}); return; }
    int u = 0;
    for (;;) {
        if (k == t[u].key) return;
        int& next = k < t[u].key ? t[u].left : t[u].right;
        if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); return; }
        u = next;
    }
}

int main() {
    int n;
    cin >> n;
    t.reserve(n);
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(k); }
    long long lo, hi;
    cin >> lo >> hi;
    long long count = 0;
    vector<int> st = {0};
    while (!st.empty()) {
        int u = st.back(); st.pop_back();
        if (u == -1) continue;
        if (t[u].key >= lo && t[u].key <= hi) ++count;
        if (t[u].key > lo) st.push_back(t[u].left);     // smaller keys may still be in range
        if (t[u].key < hi) st.push_back(t[u].right);
    }
    cout << count << '\n';
}
```

### Explanation
The ordering property lets whole subtrees be skipped, unlike a plain tree traversal.

### Edge Cases
- Empty range.

### Tests
#### Nothing in range
```text
3
10 5 15
11 14
```
```text
0
```

## DSA15-M01 · Delete Keys
**Difficulty:** Medium · **Subtopic:** The three deletion cases · **Tags:** BST, deletion, successor · **Source:** Original

### Statement
Build the BST, delete the given keys (ignoring keys not present), and print the inorder (or `EMPTY`).

### Input
n and keys; d and keys to delete.

### Output
The inorder after deletions.

### Constraints
- 1 ≤ n ≤ 2000, height ≤ 2000

### Sample Input
```text
7
50 30 70 20 40 60 80
3
30 20 70
```

### Sample Output
```text
40 50 60 80
```

### Sample Explanation
30 (two children) is replaced by its successor 40; 20 is a leaf; 70 is replaced by 80.

### Target
O(h) per deletion.

### Hints
1. Leaf: remove. One child: splice it up. Two children: copy the inorder successor, then delete the successor.
2. Recursion returning the new subtree root keeps the code short.

### Approach
Recursive delete on pointer-based nodes (unique_ptr).

### Solution
```cpp
#include <iostream>
#include <memory>
#include <vector>
using namespace std;

struct Node {
    long long key;
    unique_ptr<Node> left, right;
    explicit Node(long long k) : key(k) {}
};

void insert(unique_ptr<Node>& t, long long k) {
    if (!t) { t = make_unique<Node>(k); return; }
    if (k < t->key) insert(t->left, k);
    else if (k > t->key) insert(t->right, k);
}

void erase(unique_ptr<Node>& t, long long k) {
    if (!t) return;
    if (k < t->key) { erase(t->left, k); return; }
    if (k > t->key) { erase(t->right, k); return; }
    if (!t->left) { t = std::move(t->right); return; }
    if (!t->right) { t = std::move(t->left); return; }
    Node* s = t->right.get();
    while (s->left) s = s->left.get();
    t->key = s->key;
    erase(t->right, s->key);
}

void inorder(const Node* t, vector<long long>& out) {
    if (!t) return;
    inorder(t->left.get(), out);
    out.push_back(t->key);
    inorder(t->right.get(), out);
}

int main() {
    int n;
    cin >> n;
    unique_ptr<Node> root;
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(root, k); }
    int d;
    cin >> d;
    for (int i = 0; i < d; ++i) { long long k; cin >> k; erase(root, k); }
    vector<long long> out;
    inorder(root.get(), out);
    if (out.empty()) cout << "EMPTY\n";
    for (size_t i = 0; i < out.size(); ++i) cout << out[i] << (i + 1 < out.size() ? ' ' : '\n');
}
```

### Explanation
The successor is the smallest key in the right subtree, so placing it at the deleted node keeps the ordering; it has no left child, so deleting it is an easy case.

### Edge Cases
- Deleting the root; deleting everything.

### Tests
#### Delete all
```text
2
5 3
2
5 3
```
```text
EMPTY
```

## DSA15-M02 · Predecessor and Successor
**Difficulty:** Medium · **Subtopic:** Order queries · **Tags:** BST, successor, predecessor · **Source:** Original

### Statement
For each query x (not necessarily a key), print the largest key < x and the smallest key > x (`NONE` when absent).

### Input
n and keys; q and queries.

### Output
Two values per query.

### Constraints
- 1 ≤ n, q ≤ 2·10^5 (random-like order)

### Sample Input
```text
7
50 30 70 20 40 60 80
3
45
80
10
```

### Sample Output
```text
40 50
70 NONE
NONE 20
```

### Sample Explanation
45 lies between 40 and 50.

### Target
O(h) per query.

### Hints
1. Walk from the root: going right means the current key is a predecessor candidate; going left makes it a successor candidate.
2. If x itself is a key, look at the maximum of its left subtree and the minimum of its right subtree.

### Approach
One walk per query tracking both candidates.

### Solution
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };
vector<Node> t;

void insert(long long k) {
    if (t.empty()) { t.push_back({k}); return; }
    int u = 0;
    for (;;) {
        if (k == t[u].key) return;
        int& next = k < t[u].key ? t[u].left : t[u].right;
        if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); return; }
        u = next;
    }
}

int main() {
    int n;
    cin >> n;
    t.reserve(n);
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(k); }
    int q;
    cin >> q;
    while (q--) {
        long long x;
        cin >> x;
        bool hasPred = false, hasSucc = false;
        long long pred = 0, succ = 0;
        for (int u = 0; u != -1;) {
            if (t[u].key < x) { pred = t[u].key; hasPred = true; u = t[u].right; }
            else if (t[u].key > x) { succ = t[u].key; hasSucc = true; u = t[u].left; }
            else {                                     // x is a key: look inside its subtrees
                for (int v = t[u].left; v != -1; v = t[v].right) { pred = t[v].key; hasPred = true; }
                for (int v = t[u].right; v != -1; v = t[v].left) { succ = t[v].key; hasSucc = true; }
                break;
            }
        }
        cout << (hasPred ? to_string(pred) : "NONE") << ' ' << (hasSucc ? to_string(succ) : "NONE") << '\n';
    }
}
```

### Explanation
Each turn of the walk narrows the interval of possible answers; the last candidate recorded on each side is the closest.

### Edge Cases
- x equal to a key; x beyond all keys.

### Tests
#### Existing key
```text
3
10 5 15
1
10
```
```text
5 15
```

## DSA15-M03 · Is It a BST?
**Difficulty:** Medium · **Subtopic:** BST validation · **Tags:** BST, validation, bounds · **Source:** Original

### Statement
A binary tree is given as n lines `key left right` (0-based child indices, −1 for none, root 0). Print `YES` if it is a BST with distinct keys, else `NO`.

### Input
The tree.

### Output
`YES` or `NO`.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
4
10 1 2
5 -1 -1
15 3 -1
6 -1 -1
```

### Sample Output
```text
NO
```

### Sample Explanation
6 is in 10's right subtree, so it must be greater than 10, even though it is smaller than its parent 15.

### Target
O(n).

### Hints
1. Checking each node only against its children is not enough.
2. Pass down an allowed open interval (low, high).

### Approach
Iterative DFS with bounds.

### Solution
```cpp
#include <climits>
#include <iostream>
#include <tuple>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> key(n);
    vector<int> L(n), R(n);
    for (int i = 0; i < n; ++i) cin >> key[i] >> L[i] >> R[i];
    bool ok = true;
    vector<tuple<int, long long, long long>> st = {{0, LLONG_MIN, LLONG_MAX}};
    while (!st.empty() && ok) {
        auto [u, lo, hi] = st.back();
        st.pop_back();
        if (u == -1) continue;
        if (key[u] <= lo || key[u] >= hi) { ok = false; break; }
        st.push_back({L[u], lo, key[u]});
        st.push_back({R[u], key[u], hi});
    }
    cout << (ok ? "YES" : "NO") << '\n';
}
```

### Explanation
Every ancestor constrains a node; the interval collects all those constraints. (Keys equal to LLONG_MIN/MAX are excluded by the input range.)

### Edge Cases
- Single node; deep paths.

### Tests
#### Valid
```text
3
10 1 2
5 -1 -1
15 -1 -1
```
```text
YES
```

```cpp
void insert(long long k) {
```

## DSA15-M05 · Balanced BST from Sorted Keys
**Difficulty:** Medium · **Subtopic:** Avoiding degeneracy · **Tags:** BST, divide and conquer, balanced tree · **Source:** Original

### Statement
Build a height-balanced BST from strictly increasing keys by always choosing the middle element (lower middle, index (lo + hi)/2) as the root, and print its preorder.

### Input
n, then n sorted keys.

### Output
The preorder.

### Constraints
- 1 ≤ n ≤ 2·10^5

### Sample Input
```text
7
1 2 3 4 5 6 7
```

### Sample Output
```text
4 2 1 3 6 5 7
```

### Sample Explanation
4 is the middle; 2 and 6 the middles of the halves.

### Target
O(n), height ⌈log₂(n+1)⌉ − 1.

### Hints
1. Root = middle, left subtree from the left half, right from the right half.
2. Preorder can be printed during construction.

### Approach
Divide and conquer: T(n) = 2T(n/2) + O(1).

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<long long> a, pre;

void build(int lo, int hi) {                 // a[lo..hi]
    if (lo > hi) return;
    int mid = lo + (hi - lo) / 2;
    pre.push_back(a[mid]);
    build(lo, mid - 1);
    build(mid + 1, hi);
}

int main() {
    int n;
    cin >> n;
    a.resize(n);
    for (auto& x : a) cin >> x;
    build(0, n - 1);
    for (int i = 0; i < n; ++i) cout << pre[i] << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Splitting in half keeps the height logarithmic, so all later operations are O(log n). Inserting the same sorted keys one by one would build a path.

### Edge Cases
- n = 1; even n.

### Tests
#### Even count
```text
4
1 2 3 4
```
```text
2 1 3 4
```

## DSA15-H01 · Lowest Common Ancestor in a BST
**Difficulty:** Hard · **Subtopic:** Using the ordering · **Tags:** BST, LCA, search · **Source:** Original

### Statement
For each query of two existing keys, print their lowest common ancestor.

### Input
n and keys; q and pairs.

### Output
One key per query.

### Constraints
- 1 ≤ n, q ≤ 2·10^5 (random-like order)

### Sample Input
```text
7
50 30 70 20 40 60 80
3
20 40
20 80
60 80
```

### Sample Output
```text
30
50
70
```

### Sample Explanation
The paths to 20 and 80 split at the root.

### Target
O(h) per query.

### Hints
1. If both keys are smaller than the node, go left; if both larger, go right.
2. Otherwise the node separates them: it is the LCA.

### Approach
Single walk from the root.

### Solution
```cpp
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };
vector<Node> t;

void insert(long long k) {
    if (t.empty()) { t.push_back({k}); return; }
    int u = 0;
    for (;;) {
        if (k == t[u].key) return;
        int& next = k < t[u].key ? t[u].left : t[u].right;
        if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); return; }
        u = next;
    }
}

int main() {
    int n;
    cin >> n;
    t.reserve(n);
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(k); }
    int q;
    cin >> q;
    while (q--) {
        long long a, b;
        cin >> a >> b;
        if (a > b) swap(a, b);
        int u = 0;
        while (true) {
            if (b < t[u].key) u = t[u].left;
            else if (a > t[u].key) u = t[u].right;
            else break;                              // a <= key <= b
        }
        cout << t[u].key << '\n';
    }
}
```

### Explanation
Unlike a general tree, the BST order tells us which way both keys lie, so no parent pointers or depths are needed.

### Edge Cases
- One key is an ancestor of the other.

## DSA15-H02 · Two Keys with a Given Sum
**Difficulty:** Hard · **Subtopic:** Inorder plus two pointers · **Tags:** BST, inorder, two pointers · **Source:** Original

### Statement
Print `YES` if two different keys of the BST sum to S, else `NO`.

### Input
n and keys, then S.

### Output
`YES` or `NO`.

### Constraints
- 2 ≤ n ≤ 2·10^5

### Sample Input
```text
7
50 30 70 20 40 60 80
100
```

### Sample Output
```text
YES
```

### Sample Explanation
20 + 80, 30 + 70 or 40 + 60.

### Target
O(n).

### Hints
1. Inorder gives a sorted array.
2. Two pointers from both ends.

### Approach
Iterative inorder then two pointers.

### Solution
```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };
vector<Node> t;

void insert(long long k) {
    if (t.empty()) { t.push_back({k}); return; }
    int u = 0;
    for (;;) {
        if (k == t[u].key) return;
        int& next = k < t[u].key ? t[u].left : t[u].right;
        if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); return; }
        u = next;
    }
}

int main() {
    int n;
    cin >> n;
    t.reserve(n);
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(k); }
    long long s;
    cin >> s;
    vector<long long> sorted;
    vector<int> st;
    int u = 0;
    while (u != -1 || !st.empty()) {
        while (u != -1) { st.push_back(u); u = t[u].left; }
        u = st.back(); st.pop_back();
        sorted.push_back(t[u].key);
        u = t[u].right;
    }
    bool found = false;
    for (size_t i = 0, j = sorted.size() - 1; i < j;) {
        long long sum = sorted[i] + sorted[j];
        if (sum == s) { found = true; break; }
        if (sum < s) ++i; else --j;
    }
    cout << (found ? "YES" : "NO") << '\n';
}
```

### Explanation
The BST gives sorted order for free; two pointers then solve two-sum in linear time.

### Edge Cases
- Using the same key twice is not allowed.

### Tests
#### Impossible
```text
3
10 5 15
40
```
```text
NO
```

## DSA15-H03 · Rebuild from Preorder
**Difficulty:** Hard · **Subtopic:** BST reconstruction · **Tags:** BST, preorder, recursion · **Source:** Original

### Statement
The preorder of a BST with distinct keys is given. Print its postorder in O(n).

### Input
n, then n keys.

### Output
The postorder.

### Constraints
- 1 ≤ n ≤ 2·10^5, height ≤ 2000

### Sample Input
```text
6
8 5 1 7 10 12
```

### Sample Output
```text
1 7 5 12 10 8
```

### Sample Explanation
8 is the root; 5, 1, 7 form its left subtree.

### Target
O(n).

### Hints
1. Consume preorder keys while they fit within the allowed (low, high) bounds.
2. Emit a key after both subtrees are built.

### Approach
Recursive build with an upper bound only.

### Solution
```cpp
#include <climits>
#include <iostream>
#include <vector>
using namespace std;

vector<long long> pre, post;
size_t pos = 0;

void build(long long bound) {                         // consume keys < bound
    if (pos == pre.size() || pre[pos] > bound) return;
    long long root = pre[pos++];
    build(root);                                      // left subtree: keys < root
    build(bound);                                     // right subtree: root < keys < bound
    post.push_back(root);
}

int main() {
    int n;
    cin >> n;
    pre.resize(n);
    for (auto& x : pre) cin >> x;
    build(LLONG_MAX);
    for (int i = 0; i < n; ++i) cout << post[i] << (i + 1 < n ? ' ' : '\n');
}
```

### Explanation
Preorder plus the BST property determines the tree; each key is consumed once.

### Edge Cases
- Increasing preorder (right path).

### Tests
#### Single
```text
1
4
```

## DSA15-H04 · Floor and Ceiling
**Difficulty:** Hard · **Subtopic:** Closest-key queries · **Tags:** BST, floor, ceiling · **Source:** Original

### Statement
For each query x, print the floor (largest key ≤ x) and ceiling (smallest key ≥ x), using `NONE` when absent.

### Input
n and keys; q and queries.

### Output
Two values per query.

### Constraints
- 1 ≤ n, q ≤ 2·10^5 (random-like order)

### Sample Input
```text
7
50 30 70 20 40 60 80
2
45
85
```

### Sample Output
```text
40 50
80 NONE
```

### Sample Explanation
No key is ≥ 85.

### Target
O(h) per query.

### Hints
1. An exact match is both floor and ceiling.
2. Track the best candidate on each side while walking.

### Approach
One walk per query.

### Solution
```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };
vector<Node> t;

void insert(long long k) {
    if (t.empty()) { t.push_back({k}); return; }
    int u = 0;
    for (;;) {
        if (k == t[u].key) return;
        int& next = k < t[u].key ? t[u].left : t[u].right;
        if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); return; }
        u = next;
    }
}

int main() {
    int n;
    cin >> n;
    t.reserve(n);
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(k); }
    int q;
    cin >> q;
    while (q--) {
        long long x;
        cin >> x;
        string fl = "NONE", ce = "NONE";
        for (int u = 0; u != -1;) {
            if (t[u].key == x) { fl = ce = to_string(x); break; }
            if (t[u].key < x) { fl = to_string(t[u].key); u = t[u].right; }
            else { ce = to_string(t[u].key); u = t[u].left; }
        }
        cout << fl << ' ' << ce << '\n';
    }
}
```

### Explanation
Same walk as the successor query, but inclusive; this is what `std::set::lower_bound` does on a balanced tree.

### Edge Cases
- Exact matches.

### Tests
#### Exact
```text
3
10 5 15
1
5
```
```text
5 5
```

## DSA15-H05 · Greater-Sum Transformation
**Difficulty:** Hard · **Subtopic:** Reverse inorder · **Tags:** BST, inorder, accumulation · **Source:** Original

### Statement
Replace every key by the sum of all keys greater than or equal to it, then print the new values in the original inorder positions.

### Input
n, then n keys.

### Output
The transformed inorder sequence.

### Constraints
- 1 ≤ n ≤ 2·10^5, |keys| ≤ 10^9

### Sample Input
```text
7
50 30 70 20 40 60 80
```

### Sample Output
```text
350 330 300 260 210 150 80
```

### Sample Explanation
80 stays 80; 70 becomes 70 + 80; and so on.

### Target
O(n).

### Hints
1. Visit keys in decreasing order: right, node, left.
2. Keep a running sum.

### Approach
Iterative reverse inorder.

### Solution
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

struct Node { long long key; int left = -1, right = -1; };
vector<Node> t;

void insert(long long k) {
    if (t.empty()) { t.push_back({k}); return; }
    int u = 0;
    for (;;) {
        if (k == t[u].key) return;
        int& next = k < t[u].key ? t[u].left : t[u].right;
        if (next == -1) { next = static_cast<int>(t.size()); t.push_back({k}); return; }
        u = next;
    }
}

int main() {
    int n;
    cin >> n;
    t.reserve(n);
    for (int i = 0; i < n; ++i) { long long k; cin >> k; insert(k); }
    vector<long long> out;
    vector<int> st;
    long long running = 0;
    int u = 0;
    while (u != -1 || !st.empty()) {
        while (u != -1) { st.push_back(u); u = t[u].right; }
        u = st.back(); st.pop_back();
        running += t[u].key;
        out.push_back(running);
        u = t[u].left;
    }
    reverse(out.begin(), out.end());                  // back to increasing key order
    for (size_t i = 0; i < out.size(); ++i) cout << out[i] << (i + 1 < out.size() ? ' ' : '\n');
}
```

### Explanation
Reverse inorder visits keys from largest to smallest, so the running sum is exactly the sum of keys ≥ the current one.

### Edge Cases
- Negative keys.

### Tests
#### Single key
```text
1
-5
```
```text
-5
```
