# Module 16B: Merge Sort

## Learning objectives

- Implement top-down merge sort and the merge step.
- Derive T(n) = 2T(n/2) + n = Θ(n log n).
- Explain stability and the O(n) extra space.

## Prerequisites

[Module 06](topic:master-theorem), [Module 04](topic:asymptotic-analysis) and [Module 05](topic:correctness-and-recurrences).

## Intuition

Split the array in half, sort each half recursively, then merge the two sorted halves by repeatedly taking the smaller front element.

## Merge

Two indices i, j into the sorted halves; copy the smaller of a[i], a[j] (taking from the **left** on ties, which keeps the sort stable) into a buffer; append the leftovers. Cost: Θ(n) for n elements.

## Recurrence

T(n) = 2T(n/2) + Θ(n). By the Master Theorem case 2 (a = b = 2, f = n), T(n) = Θ(n log n) in every case.

## Properties

| Property | Merge sort |
|---|---|
| Time | Θ(n log n) best, average, worst |
| Extra space | Θ(n) buffer + O(log n) stack |
| Stable | Yes |
| In place | No (array version) |
| Good for | linked lists (merge needs no buffer), external sorting, counting inversions |

## Complexity analysis

Θ(n log n) time in all cases; Θ(n) auxiliary space; stable.

## Implementation (C++17)

```cpp
#include <iostream>
#include <vector>
using namespace std;

void mergeSort(vector<int>& a, vector<int>& buf, int lo, int hi) {   // sorts a[lo, hi)
    if (hi - lo < 2) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(a, buf, lo, mid);
    mergeSort(a, buf, mid, hi);
    int i = lo, j = mid, k = lo;
    while (i < mid && j < hi) buf[k++] = (a[j] < a[i]) ? a[j++] : a[i++];   // ties take left: stable
    while (i < mid) buf[k++] = a[i++];
    while (j < hi) buf[k++] = a[j++];
    for (k = lo; k < hi; ++k) a[k] = buf[k];
}

int main() {
    vector<int> a = {38, 27, 43, 3, 9, 82, 10};
    vector<int> buf(a.size());
    mergeSort(a, buf, 0, static_cast<int>(a.size()));
    for (int x : a) cout << x << ' ';
    cout << '\n';
}
```

## Common mistakes and edge cases

- Taking from the right on ties (breaks stability).
- Allocating a new buffer at every call (slow).
- Off-by-one in the split with inclusive bounds.

## Key takeaways

- Divide, sort halves, merge in linear time.
- Θ(n log n) guaranteed, stable, Θ(n) extra space.
