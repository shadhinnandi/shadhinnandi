# Module 13: Graph Traversals: BFS and DFS

## Learning objectives

- Implement BFS with a queue and DFS recursively and with an explicit stack.
- Use visited arrays, handle disconnected graphs and count components.
- Find shortest paths in unweighted graphs with BFS, detect cycles, and flood-fill grids.

## Prerequisites

[Module 10](topic:queues), [Module 09](topic:stacks), [Module 12](topic:graphs).

## Intuition

BFS explores in rings: all vertices 1 edge away, then 2 edges, and so on, like ripples. DFS goes as deep as possible before backtracking, like exploring a maze with one hand on the wall.

## Breadth-first search

Push the source into a queue with dist = 0; repeatedly pop u and push every unvisited neighbour v with dist[v] = dist[u] + 1. Because vertices leave the queue in non-decreasing distance order, **dist is the minimum number of edges** from the source (unweighted shortest paths).

## Depth-first search

Visit u, mark it, recurse into each unvisited neighbour. The iterative version replaces recursion with an explicit stack, which avoids stack overflow on deep graphs (n = 10^6 in a path).

## Visited state and disconnected graphs

Mark a vertex when it is **first discovered** (when pushed, for BFS) so it is never queued twice. To cover a disconnected graph, start a new traversal from every unvisited vertex; the number of starts is the number of connected components.

## Cycle detection

- Undirected: an edge to a visited vertex that is not the parent means a cycle.
- Directed: an edge to a vertex currently on the recursion stack (colour gray) means a cycle.

## Grids and flood fill

A grid is an implicit graph: each cell's neighbours are up/down/left/right. Flood fill (count islands, paint regions) is BFS or DFS from each unvisited land cell.

## BFS vs DFS

| | BFS | DFS |
|---|---|---|
| Structure | queue | stack / recursion |
| Finds | shortest paths (unweighted), levels | components, cycles, topological order |
| Memory | O(width) | O(depth) |

## Complexity analysis

Both BFS and DFS run in O(n + m) with adjacency lists (each vertex and edge handled a constant number of times), O(n²) with a matrix; extra space O(n).

## Implementation (C++17)

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {                                   // n m, m undirected edges (1-based), then source s
    int n, m;
    cin >> n >> m;
    vector<vector<int>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    int s;
    cin >> s;
    vector<int> dist(n + 1, -1);               // -1 = not discovered
    queue<int> q;
    dist[s] = 0;
    q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u])
            if (dist[v] == -1) {               // mark on discovery
                dist[v] = dist[u] + 1;
                q.push(v);
            }
    }
    for (int u = 1; u <= n; ++u) cout << dist[u] << (u < n ? ' ' : '\n');
}
```

**Input:**

```text
5 4
1 2
2 3
3 4
1 5
1
```

**Output:**

```text
0 1 2 3 1
```

## Common mistakes and edge cases

- Marking visited when popping instead of when pushing (duplicates in the queue).
- Using BFS distances on weighted graphs (wrong; needs Dijkstra, DSA II).
- Deep recursive DFS overflowing the stack.
- Forgetting unvisited components.

## Key takeaways

- BFS = queue = shortest edge counts.
- DFS = stack/recursion = components, cycles.
- Both are O(n + m) with adjacency lists.
- Mark on discovery; loop over all vertices for disconnected graphs.
