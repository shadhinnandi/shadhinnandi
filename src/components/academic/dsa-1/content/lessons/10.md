# Module 10: Queues

## Learning objectives

- Implement the Queue ADT with arrays (circular) and linked lists.
- Use wraparound indexing and detect overflow and underflow.
- Use deques and priority queues and compare implementations.

## Prerequisites

[Module 09](topic:stacks) and [Module 02](topic:abstract-data-types).

## Intuition

A queue is first in, first out (FIFO), like a line at a bank counter: join at the rear, leave from the front.

## Operations

| Operation | Meaning | Cost |
|---|---|---|
| enqueue(x) | add at the rear | O(1) |
| dequeue() | remove from the front (underflow if empty) | O(1) |
| front(), rear() | read the ends | O(1) |

## Circular queue

A plain array queue wastes the space before `front`. A circular queue wraps around: `rear = (rear + 1) % capacity`. Keep a `count` to tell full (count = capacity, overflow) from empty (count = 0, underflow).

```text
capacity 5, front = 3, count = 3:  [ c | . | . | a | b ]   order: a, b, c
```

## Deque and priority queue

- **Deque**: insert/delete at both ends in O(1) (circular buffer or doubly linked list; `std::deque`).
- **Priority queue**: dequeue returns the highest-priority element, not the oldest; implemented by a binary heap in O(log n) ([Module 14](topic:heaps)).

## Implementation trade-offs

| Implementation | enqueue/dequeue | Memory |
|---|---|---|
| Circular array | O(1) | fixed (or doubling) |
| Linked list (head + tail) | O(1) | pointer per node |
| Two stacks | O(1) amortised | two arrays |

## Applications

BFS ([Module 13](topic:bfs-dfs)), printer and CPU scheduling, buffering streams, simulations of service lines.

## Complexity analysis

enqueue, dequeue, front: O(1); circular array space O(capacity); priority queue O(log n) per operation.

## Implementation (C++17)

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

class CircularQueue {
    vector<int> buf;
    int head = 0, count = 0;               // element i at (head + i) % capacity
public:
    explicit CircularQueue(int capacity) : buf(capacity) {}
    bool enqueue(int x) {
        if (count == static_cast<int>(buf.size())) return false;     // overflow
        buf[(head + count) % buf.size()] = x;
        ++count;
        return true;
    }
    bool dequeue(int& out) {
        if (count == 0) return false;                                // underflow
        out = buf[head];
        head = (head + 1) % static_cast<int>(buf.size());
        --count;
        return true;
    }
};

int main() {
    CircularQueue q(3);
    for (int x : {1, 2, 3, 4}) if (!q.enqueue(x)) cout << "overflow on " << x << '\n';
    int v;
    while (q.dequeue(v)) cout << v << ' ';
    cout << '\n';
}
```

## Common mistakes and edge cases

- Confusing full and empty when front == rear (keep a count).
- Forgetting the modulus on wraparound.
- Using a vector with erase(begin()) as a queue: O(n) per dequeue.

## Key takeaways

- FIFO: enqueue at the rear, dequeue at the front.
- Circular arrays give O(1) operations without shifting.
- A deque supports both ends; a priority queue orders by priority.
