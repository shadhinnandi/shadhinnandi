## Intuition

Two different problems share the word "set". The **Set ADT** stores distinct elements and answers membership, union and intersection. **Disjoint Set Union** maintains a partition of elements into groups and answers "are x and y in the same group?" while groups merge. They are not interchangeable.

## Set ADT implementations

| Operation | Sorted array | Hash set (`unordered_set`) | Balanced BST (`set`) |
|---|---|---|---|
| insert / erase | O(n) | O(1) expected | O(log n) |
| contains | O(log n) | O(1) expected | O(log n) |
| union / intersection / difference of sizes n, m | O(n + m) merge | O(n + m) expected | O(n + m) by merging inorder |
| ordered iteration | yes | no | yes |

## Disjoint Set Union (Union-Find)

- **make-set(x):** parent[x] = x.
- **find(x):** follow parents to the root (the group's representative). **Path compression** points every visited node directly at the root.
- **union(x, y):** link the roots; **union by size/rank** attaches the smaller tree under the larger.

With both optimisations, a sequence of m operations takes O(m · α(n)), where α is the inverse Ackermann function (≤ 4 for any practical n): effectively constant amortised time.

## Applications

Connected components under edge insertions, connectivity queries, cycle detection in undirected graphs, and **Kruskal's minimum spanning tree** (extension: sort edges by weight, add an edge if its endpoints are in different sets).

## Complexity analysis

Hash set O(1) expected per operation; tree set O(log n); sorted-array set operations O(n + m); DSU O(α(n)) amortised per operation with both optimisations, O(n) space.

## Implementation (C++17)

```cpp
#include <iostream>
#include <numeric>
#include <utility>
#include <vector>
using namespace std;

struct DSU {
    vector<int> parent, size;
    explicit DSU(int n) : parent(n), size(n, 1) { iota(parent.begin(), parent.end(), 0); }   // make-set
    int find(int x) {
        while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }   // path halving
        return x;
    }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;                  // already in the same set
        if (size[a] < size[b]) swap(a, b);         // union by size
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};

int main() {
    DSU d(6);
    d.unite(0, 1); d.unite(2, 3); d.unite(1, 3);
    cout << (d.find(0) == d.find(2) ? "connected" : "separate") << '\n';
    cout << (d.find(4) == d.find(5) ? "connected" : "separate") << '\n';
}
```

## Common mistakes and edge cases

- Using DSU to compute set intersections (it cannot).
- Linking non-root nodes in union.
- Forgetting path compression and getting O(n) finds on long chains.
- Expecting a hash set to iterate in sorted order.

## Key takeaways

- Set ADT: membership and set algebra; choose hash, tree or sorted array.
- DSU: partition with find and union; near-constant amortised time.
- DSU powers connectivity queries and Kruskal's algorithm.
